Borrow checker adalah fitur khas Rust yang mencegah data race dan use-after-free tanpa garbage collector. Memahaminya membuat kode lebih aman.

## Dua Aturan Emas

1. Boleh punya **banyak** immutable reference (`&T`) secara bersamaan
2. Atau **tepat satu** mutable reference (`&mut T`) — tidak boleh bersama yang lain

```rust
let mut x = 5;
let a = &x;
let b = &x;      // boleh
// let c = &mut x; // error saat a dan b masih aktif
println!("{} {}", a, b);
```

## Slice

```rust
let angka = [1, 2, 3, 4, 5];
let bagian = &angka[1..4]; // [2, 3, 4]
```

Slice adalah *fat pointer*: berisi alamat awal dan panjang. `&str` juga slice dari UTF-8.

## Lifetime

```rust
fn terpanjang<'a>(a: &'a str, b: &'a str) -> &'a str {
    if a.len() > b.len() { a } else { b }
}
```

Anotasi `'a` mengatakan hasil hidup setidaknya selama input. Kompiler menolak jika referensi yang dikembalikan bisa lebih pendek.

## Elision

Untuk satu input reference, lifetime hasil bisa disimpulkan:

```rust
fn pertama(s: &str) -> &str { &s[0..1] } // tanpa anotasi
```

## Interior Mutability

`RefCell<T>` memindahkan aturan borrowing ke runtime:

```rust
use std::cell::RefCell;
let nilai = RefCell::new(5);
*nilai.borrow_mut() += 1;
```

Panic terjadi jika aturan dilanggar saat runtime. Gunakan hanya saat pola borrowing static terlalu kaku.

<div class="note">💡 Error borrow checker sering selesai dengan mengubah **struktur** kode, bukan menambah `clone()`. Clone hanya saat memang perlu kepemilikan baru.</div>
