Rust mewarisi operator yang familier dari bahasa C, tetapi dengan aturan tipe yang ketat. Kompiler menolak operasi yang mencampur tipe tanpa konversi eksplisit.

## Aritmetika

| Operator | Arti | Contoh | Hasil |
|---|---|---|---|
| `+` | Tambah | `7 + 2` | `9` |
| `-` | Kurang | `7 - 2` | `5` |
| `*` | Kali | `7 * 2` | `14` |
| `/` | Bagi | `7 / 2` | `3` (integer) |
| `%` | Sisa | `7 % 2` | `1` |

Untuk desimal, gunakan tipe `f64`:

```rust
let hasil = 7.0 / 2.0; // 3.5
```

## Perbandingan

`==`, `!=`, `>`, `<`, `>=`, `&lt;=` menghasilkan `bool`. Membandingkan `i32` dengan `i64` adalah error — samakan tipe dulu dengan `as`.

## Logika

- `&&` — AND (short-circuit)
- `||` — OR (short-circuit)
- `!` — NOT

## Bitwise

`&`, `|`, `^`, `!`, `<<`, `>>`. Operator `!` pada integer membalik semua bit, bukan negasi logika.

```rust
let flag = 0b0001 | 0b0010; // 0b0011
```

## Cast dengan `as`

```rust
let i = 42i32;
let f = i as f64;
let u = -1 as u8; // 255 (pembungkusan!)
```

Hati-hati: `as` bisa memotong nilai atau membungkusnya. Untuk konversi yang aman, pakai `try_into()`:

```rust
use std::convert::TryInto;
let n: Result<u8, _> = 300i32.try_into(); // Err
```

## Operator Overload

Rust membolehkan trait seperti `Add` diimplementasikan untuk tipe buatan sendiri, sehingga `+` bisa dipakai pada tipe tersebut.

<div class="note">💡 Debug build Rust melakukan pengecekan overflow dan akan panic pada `i32::MAX + 1`. Mode release memotong nilai — aktifkan <code>overflow-checks = true</code> bila perlu.</div>
