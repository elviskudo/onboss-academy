Iterator adalah tulang punggung pemrosesan data di Rust. Mereka **lazy**, komposabel, dan sering dioptimasi sampai tidak ada alokasi tambahan.

## Adapter Umum

| Adapter | Fungsi |
|---|---|
| `map` | Ubah tiap elemen |
| `filter` | Saring elemen |
| `take` / `skip` | Ambil/lewati n elemen |
| `zip` | Gabungkan dua iterator |
| `enumerate` | Tambah indeks |
| `chain` | Sambungkan iterator |
| `fold` | Akumulasi |
| `find` | Cari elemen pertama |

```rust
let hasil: Vec<i32> = (1..20)
    .filter(|n| n % 3 == 0)
    .map(|n| n * n)
    .take(3)
    .collect();
```

## collect()

```rust
let v: Vec<i32> = (1..4).collect();
let s: String = ['a', 'b'].iter().collect();
let set: HashSet<i32> = [1, 1, 2].into_iter().collect();
```

Tipe hasil biasanya ditentukan oleh anotasi variabel.

## fold vs sum

```rust
let total: i32 = (1..5).sum();
let total2 = (1..5).fold(0, |acc, x| acc + x);
```

`sum()` adalah shortcut untuk pola fold paling umum.

## Iterator Kustom

```rust
struct Hitungan(i32, i32);

impl Iterator for Hitungan {
    type Item = i32;
    fn next(&mut self) -> Option<i32> {
        if self.0 > self.1 { return None; }
        let v = self.0;
        self.0 += 1;
        Some(v)
    }
}
```

Cukup mengimplementasikan `next()`. Method lain seperti `map` otomatis tersedia.

## .into_iter(), .iter(), .iter_mut()

- `iter()` — pinjam immutable
- `iter_mut()` — pinjam mutable
- `into_iter()` — mengambil kepemilikan

<div class="note">💡 Rantai iterator sering lebih cepat daripada loop manual karena kompiler bisa meleburkan adapter menjadi satu pass tanpa alokasi perantara.</div>
