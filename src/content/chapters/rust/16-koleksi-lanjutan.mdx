Selain `Vec` dan `HashMap`, pustaka standar Rust menyediakan koleksi untuk kebutuhan khusus. Memilih yang tepat menghemat waktu dan memori.

## Ringkasan

| Koleksi | Ciri | Kompleksitas khas |
|---|---|---|
| `Vec<T>` | Array dinamis | akses O(1), tambah akhir O(1) |
| `VecDeque<T>` | Antrean dua ujung | push/pop depan-belakang O(1) |
| `LinkedList<T>` | Linked list | jarang dipakai |
| `HashMap<K,V>` | Pasangan kunci–nilai | rata-rata O(1) |
| `BTreeMap<K,V>` | Kunci terurut | O(log n), iterasi urut |
| `HashSet<T>` | Nilai unik | mirip HashMap |
| `BTreeSet<T>` | Unik & terurut | mirip BTreeMap |
| `BinaryHeap<T>` | Max-heap | ambil terbesar O(log n) |

## VecDeque

```rust
use std::collections::VecDeque;
let mut q = VecDeque::new();
q.push_back("A");
q.push_front("Z");
println!("{:?}", q.pop_front()); // Some("Z")
```

## BinaryHeap

```rust
use std::collections::BinaryHeap;
let mut h = BinaryHeap::new();
for n in [3, 1, 7] { h.push(n); }
println!("{:?}", h.pop()); // Some(7)
```

Untuk min-heap, bungkus nilai dengan `Reverse<T>`.

## Iterator Adapter

```rust
let hasil: Vec<i32> = (1..10)
    .filter(|x| x % 2 == 0)
    .map(|x| x * x)
    .collect();
```

Iterator bersifat **lazy**: `filter` dan `map` tidak jalan sampai `collect()` atau `for` mengonsumsinya.

## entry API

```rust
use std::collections::HashMap;
let mut hitung = HashMap::new();
for kata in ["a", "b", "a"] {
    *hitung.entry(kata).or_insert(0) += 1;
}
```

<div class="note">💡 `HashMap` mengacak urutan iterasi. Jika output harus stabil (misal untuk laporan), pakai `BTreeMap`.</div>
