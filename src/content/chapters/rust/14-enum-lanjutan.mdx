Enum di Rust jauh lebih kuat daripada enum di kebanyakan bahasa. Tiap varian boleh membawa data, sehingga kamu bisa memodelkan domain dengan presisi.

## Enum dengan Data

```rust
enum IpAddress {
    V4(u8, u8, u8, u8),
    V6(String),
}

let alamat = IpAddress::V4(192, 168, 1, 1);
```

Bandingkan dengan dua struct terpisah: satu enum membuat pemanggilan kode harus menangani semua varian.

## Option&lt;T&gt;

```rust
let maybe: Option<i32> = Some(5);

match maybe {
    Some(n) => println!("{}", n),
    None => println!("tidak ada"),
}
```

Rust tidak punya `null`. `Option<T>` membuat ketiadaan nilai menjadi eksplisit dan harus ditangani.

## Result&lt;T, E&gt;

```rust
use std::fs::read_to_string;

fn baca(path: &str) -> Result<String, std::io::Error> {
    let isi = read_to_string(path)?;
    Ok(isi.to_uppercase())
}
```

`?` hanya bisa dipakai pada fungsi yang mengembalikan `Result` (atau `Option`).

## Destructuring

```rust
enum Perintah { Pindah { x: i32, y: i32 }, Berhenti }

match perintah {
    Perintah::Pindah { x, y } => println!("{},{}", x, y),
    Perintah::Berhenti => {}
}
```

## Parser Parsing

```rust
fn dari_teks(s: &str) -> Option<i32> {
    s.parse().ok()
}
```

`ok()` mengubah `Result` menjadi `Option` dengan membuang detail error.

<div class="note">💡 Hindari <code>unwrap()</code> di kode produksi kecuali kamu benar-benar yakin nilainya ada. Gunakan <code>expect("alasan")</code> agar panic lebih informatif saat debugging.</div>
