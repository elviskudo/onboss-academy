`match` adalah salah satu fitur paling kuat di Rust. Ia bukan sekadar switch — ia mencocokkan **pola** dan dijamin mencakup semua kemungkinan.

## Match dengan Pola

```rust
match kode {
    200 => "OK",
    404 => "Tidak ditemukan",
    500..=599 => "Error server",
    _ => "Lainnya",
}
```

Rentang `..=` dan `_` (wildcard) membantu menyusun cabang.

## Guard

```rust
match nilai {
    Some(n) if n % 2 == 0 => println!("genap {}", n),
    Some(n) => println!("ganjil {}", n),
    None => {}
}
```

Guard dievaluasi setelah pola cocok.

## if let & while let

```rust
if let Some(nama) = maybe_nama {
    println!("Halo {}", nama);
}

while let Some(item) = antrean.pop() {
    proses(item);
}
```

Keduanya mengabaikan pola lain — ringkas, tetapi kurang eksplisit daripada `match`.

## loop sebagai Expression

```rust
let hasil = loop {
    let n = hitung();
    if n > 10 { break n; }
};
```

Berbeda dengan `while`, `loop` bisa mengembalikan nilai lewat `break nilai`.

## Label

```rust
'cari: for i in 0..10 {
    for j in 0..10 {
        if i * j == 42 { break 'cari; }
    }
}
```

<div class="note">💡 Karena match wajib exhaustive, kompiler akan mengingatkanmu saat ada varian enum baru yang belum ditangani — ini fitur keamanan yang sangat berguna.</div>
