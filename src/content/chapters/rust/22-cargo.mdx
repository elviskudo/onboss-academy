Cargo adalah build system sekaligus package manager Rust. Hampir semua proyek Rust dimulai dengan `cargo new`.

## Membuat Proyek

```bash
cargo new belajar-rust
cd belajar-rust
cargo run
```

Struktur:

```
belajar-rust/
  Cargo.toml
  src/main.rs
  target/
```

## Cargo.toml

```toml
[package]
name = "belajar-rust"
version = "0.1.0"
edition = "2021"

[dependencies]
serde = { version = "1", features = ["derive"] }
rand = "0.8"
```

Versi mengikuti aturan semver. `"1"` berarti kompatibel dengan 1.x.

## Fitur

```toml
[features]
default = ["json"]
json = ["serde/json"]
```

Aktifkan dengan `cargo build --features json` atau matikan default dengan `--no-default-features`.

## Perintah Penting

| Perintah | Fungsi |
|---|---|
| `cargo build` | Kompilasi debug |
| `cargo build --release` | Kompilasi optimasi |
| `cargo run` | Build + jalankan |
| `cargo test` | Jalankan test |
| `cargo check` | Cek tanpa menghasilkan binary |
| `cargo fmt` | Format kode |
| `cargo clippy` | Lint saran idiom |
| `cargo doc --open` | Dokumentasi |

## Profil

```toml
[profile.release]
opt-level = 3
lto = true
strip = true
```

## Workspace

```toml
[workspace]
members = ["api", "core", "cli"]
```

Workspace memungkinkan beberapa crate berbagi `Cargo.lock` dan target build.

<div class="note">💡 Jalankan <code>cargo check</code> saat iterasi — jauh lebih cepat daripada <code>cargo build</code> karena hanya memeriksa tipe tanpa linking.</div>
