Modul membantu mengatur kode agar tetap rapi seiring proyek bertumbuh. Sistem modul Rust juga menentukan **visibilitas** — apa yang boleh diakses dari luar.

## Modul Dasar

```rust
mod matematika {
    pub fn tambah(a: i32, b: i32) -> i32 { a + b }
    fn rahasia() {} // privat
}

fn main() {
    println!("{}", matematika::tambah(2, 3));
}
```

## Pemisahan File

```
src/
  main.rs
  kalkulator.rs
  kalkulator/
    operasi.rs
```

```rust
// main.rs
mod kalkulator;

// kalkulator.rs
pub mod operasi;
```

## use

```rust
use std::collections::HashMap;
use crate::kalkulator::operasi::tambah;
use super::util::helper;
```

`use` membuat path lebih pendek. Untuk menghindari bentrok, gunakan `as`:

```rust
use std::io::Result as IoResult;
```

## Visibilitas

| Modifier | Jangkauan |
|---|---|
| (tanpa `pub`) | Modul saat ini + turunan |
| `pub` | Publik |
| `pub(crate)` | Seluruh crate saat ini |
| `pub(super)` | Modul induk saja |
| `pub(in path)` | Path tertentu |

## Re-export

```rust
pub use self::operasi::tambah;
```

Ini memindahkan API ke level lebih tinggi agar pemakai tidak perlu tahu struktur internal.

<div class="note">💡 Mulailah dengan satu file. Pecah menjadi modul saat file mulai sulit dibaca — bukan sekadar karena aturan "satu file satu modul".</div>
