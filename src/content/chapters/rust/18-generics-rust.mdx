Generic membuat fungsi dan tipe bisa dipakai ulang untuk banyak tipe dengan tetap aman. Rust mengimplementasikannya lewat **monomorphization**: kompiler menghasilkan versi kode untuk tiap tipe yang dipakai.

## Fungsi Generic

```rust
fn pertama<T>(data: &[T]) -> Option<&T> {
    data.first()
}
```

Tidak ada biaya runtime — tidak seperti `dyn Trait`.

## Struct Generic

```rust
struct Kotak<T> { isi: T }

impl<T> Kotak<T> {
    fn baru(isi: T) -> Self { Kotak { isi } }
    fn ambil(&self) -> &T { &self.isi }
}
```

## Trait Bound

```rust
fn tampil<T: std::fmt::Debug>(x: &T) {
    println!("{:?}", x);
}

// bentuk where lebih rapi untuk banyak bound
fn hitung<T>(x: T) -> T
where
    T: Copy + PartialOrd,
{
    x
}
```

## Multiple Type Parameter

```rust
fn pasangan<A, B>(a: A, b: B) -> (A, B) { (a, b) }
```

## Const Generic

```rust
struct Buffer<const N: usize> { data: [u8; N] }

let b = Buffer::<16> { data: [0; 16] };
```

## PhantomData

```rust
use std::marker::PhantomData;
struct Pemberi<T> { id: i32, _tipe: PhantomData<T> }
```

Ini memberi tahu kompiler bahwa struct "seolah" memiliki `T`, berguna untuk pointer atau indeks bertipe.

<div class="note">💡 Trade-off monomorphization: binary bisa lebih besar. Jika ukuran menjadi masalah, pertimbangkan <code>dyn Trait</code> untuk batas API yang jelas.</div>
