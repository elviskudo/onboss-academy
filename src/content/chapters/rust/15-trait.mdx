Trait adalah cara Rust mendefinisikan **perilaku bersama**. Mirip interface, tetapi bisa membawa implementasi default dan digunakan sebagai bound generic.

## Mendefinisikan & Mengimplementasi

```rust
trait Ringkas {
    fn ringkas(&self) -> String;
    fn panjang(&self) -> usize {
        self.ringkas().len()
    }
}

struct Berita { judul: String }

impl Ringkas for Berita {
    fn ringkas(&self) -> String {
        self.judul.chars().take(20).collect()
    }
}
```

## Trait Bound

```rust
fn cetak<T: Ringkas>(item: &T) {
    println!("{}", item.ringkas());
}

// Alternatif dengan where:
fn cetak2<T>(item: &T)
where T: Ringkas,
{
    println!("{}", item.ringkas());
}
```

## Derive

```rust
#[derive(Debug, Clone, PartialEq)]
struct Titik { x: i32, y: i32 }
```

Macro derive menghasilkan implementasi otomatis untuk trait yang umum.

## Trait Object

```rust
fn suara_semua(items: &[Box<dyn Suara>]) {
    for i in items { println!("{}", i.bersuara()); }
}
```

`dyn` dipakai saat tipe konkret baru diketahui saat runtime. Trade-off-nya: alokasi heap dan dispatch dinamis. `impl Trait` lebih cepat bila tipe tetap diketahui saat compile.

## Blanket Implementation

```rust
impl<T: Display> Ringkas for T {
    fn ringkas(&self) -> String { format!("{}", self) }
}
```

Semua tipe yang bisa ditampilkan otomatis mendapat implementasi `Ringkas`.

<div class="note">💡 Mulailah dengan generic + <code>impl Trait</code>. Pakai <code>dyn Trait</code> hanya saat kamu benar-benar butuh koleksi berisiต่าง tipe.</div>

Tambahkan struct baru yang mengimplementasikan trait `Suara`.

    fn bersuara(&self) -> String;
    fn deskripsi(&self) -> String {

struct Kucing;

impl Suara for Anjing {
    fn bersuara(&self) -> String { String::from("Woof!") }

fn main() {
    tampil(&Anjing);
    tampil(&Kucing);
    let kumpulan: Vec<Box<dyn Suara>> = vec![Box::new(Anjing), Box::new(Kucing)];
