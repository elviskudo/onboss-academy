Aturan pertama Rust: **data tidak berubah kecuali kamu minta secara eksplisit**. Ini sumber keamanan Rust.

## 4 Cara Mendeklarasikan Nilai

| Cara | Sintaks | Mutabilitas | Kapan dipakai |
| --- | --- | --- | --- |
| `let` | `let x = 5;` | Immutable | Default — mulai dari sini |
| `let mut` | `let mut x = 5;` | Mutable | Nilai pasti akan berubah |
| `const` | `const MAKS: i32 = 100;` | Selalu immutable | Konstanta global, tipe wajib |
| `static` | `static NAMA: &str = "...";` | Selalu immutable | Nilai hidup sepanjang program |

## let dan let mut

```rust
let jumlah = 5;
println!("{}", jumlah);

// jumlah = 6;   // error: tidak bisa mengubah nilai immutable

let mut total = 0;
total += jumlah;
println!("{}", total);
```

Mulailah dengan `let`. Tambahkan `mut` hanya jika nilai memang harus berubah — kebiasaan ini membuat kode lebih mudah dipikirkan.

## const

```rust
const MAKS: i32 = 100;
const NAMA: &str = "OnBoss";

println!("{} {}", MAKS, NAMA);
```

`const` ditulis dengan huruf besar sebagian, tipe wajib disebut, dan nilainya harus bisa dihitung saat kompilasi. Beda dengan `let`: `const` tidak bisa di-shadow dan hidup di seluruh skupnya.

## Shadowing

```rust
let nilai = "20";
let nilai: i32 = nilai.parse().unwrap();

println!("{}", nilai + 1);
```

Shadowing membolehkan kamu mengubah nilai (bahkan tipe) dengan nama yang sama — berguna saat mengubah bentuk data di tengah jalan. Beda dengan `mut`: `mut` mengubah isi variabel yang sama, shadowing membuat variabel baru bernama sama.

## Umur dan Cakupan

```rust
let luar;
{
    let dalam = 10;
    luar = dalam;
    println!("di dalam: {}", dalam);
}
println!("di luar: {}", luar);
```

Variabel hidup dari baris deklarasi sampai akhir bloknya. Setelah itu Rust membuangnya otomatis (Drop) — inilah sebabnya Rust tidak membutuhkan garbage collector.

## Aturan Penamaan

Snake case untuk variabel dan fungsi (`total_skor`), PascalCase untuk tipe (`Siswa`), UPPER_CASE untuk `const` (`MAKS`). Compiler hanya memberi peringatan (warning), bukan error, untuk penamaan yang tidak sesuai.

## Di Dunia Nyata

- **Counter form**: input jumlah pesanan `let mut qty = 1;` lalu `qty += 1` saat tombol tambah ditekan
- **Konstanta aplikasi**: `const PAJAK_PPN: f64 = 0.11;` dipakai di seluruh modul billing
- **Parse input**: `let teks = input; let angka: i32 = teks.parse()...;` — ubah string jadi angka lewat shadowing
- **State halaman**: `mut scroll_y` yang terus diperbarui saat user scroll
- **Batas konfigurasi**: `static MAX_KONEKSI: usize = 100;` untuk limit server

<div class="note">💡 Jika Rust menolak perubahan pada variabel, biasanya itu bukan bug compiler — periksa apakah deklarasimu memang seharusnya let mut.</div>
