Rust tidak punya perulangan berbasis index paksa. Semuanya berjalan di atas **range atau iterator**.

## 3 Kata Kunci Perulangan

| Kata kunci | Bentuk | Kapan dipakai |
| --- | --- | --- |
| `for` | `for x in iter { }` | Rentang & koleksi — paling sering |
| `while` | `while kondisi { }` | Jumlah iterasi belum diketahui |
| `loop` | `loop { }` + `break` | Butuh kendali penuh / nilai dari break |

## for dengan Range

```rust
for i in 1..=3 {
    println!("Perulangan ke- {}", i);
}
```

`1..=3` berarti 1 sampai 3 termasuk. Tanpa tanda `=`, batas atas tidak ikut diambil (`1..3` berhenti di 2).

## Melintasi Koleksi

```rust
let buah = ["Apel", "Mangga", "Jeruk"];

for b in buah.iter() {
    println!("{}", b);
}

for (i, b) in buah.iter().enumerate() {
    println!("index {} = {}", i, b);
}
```

`.iter()` meminjam tiap elemen, `.enumerate()` menambahkan index di depannya. Untuk mengubah isi saat iterasi, ganti dengan `.iter_mut()`.

## while

```rust
let mut hitung = 3;
while hitung > 0 {
    println!("sisa {}", hitung);
    hitung -= 1;
}
```

Saat jumlah iterasi tidak diketahui dari awal, `while` adalah pilihan yang jelas.

## loop dan break

```rust
let mut total = 0;
loop {
    total += 1;
    if total >= 5 {
        break;
    }
}
println!("total = {}", total);
```

`loop` berjalan tanpa batas sampai `break` dieksekusi — cocok ketika kondisi berhenti baru diketahui di tengah perulangan.

## break dengan Nilai

```rust
let mut i = 1;
let hasil = loop {
    i += 1;
    if i > 10 {
        break i * 2;
    }
};
println!("hasil loop = {}", hasil);
```

`loop` bisa menghasilkan nilai lewat `break`, sesuatu yang tidak dimiliki `for` dan `while`.

## 4 Pola Klasik

- **Akumulasi**: `total += nilai` di dalam `for`
- **Cari pertama**: `if ketemu { break; }` — berhenti begitu ketemu
- **Filter → baru**: `.filter(|x| ...).collect()` menghasilkan Vec baru
- **Hitung frekuensi**: `*peta.entry(k).or_insert(0) += 1;` pada HashMap

```rust
let angka = vec![3, 8, 3, 1, 8, 3];
let ganjil: Vec<i32> = angka.iter().filter(|n| **n % 2 == 1).cloned().collect();
println!("ganjil: {:?}", ganjil);
```

## Di Dunia Nyata

- **Animasi game**: `loop` dengan `break` menunggu input pemain sebelum frame berikutnya
- **Retry jaringan**: `for percobaan in 0..3 { ... }` mengulang request yang gagal
- **Progres download**: `while sisa > 0 { unduh_chunk() }` sampai byte habis
- **Rekap data**: `.iter().map().filter().collect()` merapikan daftar transaksi
- **Rate limiter**: `loop` + `Instant::now()` membatasi 100 request per detik

<div class="note">💡 Gunakan for untuk rentang dan koleksi, while untuk kondisi berjalan, dan loop hanya saat butuh kendali penuh. Ketiganya menutup hampir semua kebutuhan perulangan.</div>
