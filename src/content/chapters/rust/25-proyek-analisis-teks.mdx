Proyek penutup menggabungkan hampir semua yang sudah kamu pelajari: struct, enum, generic, iterator, error handling, dan modul.

## Struktur

```
src/
  main.rs
  analisis.rs
```

```rust
// analisis.rs
use std::collections::HashMap;

#[derive(Debug)]
pub struct Statistik {
    pub kata: usize,
    pub unik: usize,
    pub karakter: usize,
}

pub fn analisis(teks: &str) -> Statistik {
    let kata: Vec<&str> = teks.split_whitespace().collect();
    let unik = kata.iter().collect::<HashMap<_, _>>().len();
    Statistik {
        kata: kata.len(),
        unik,
        karakter: teks.chars().count(),
    }
}
```

## Generic Helper

```rust
pub fn teratas<T: std::fmt::Display>(data: &[T], n: usize) -> Vec<String> {
    data.iter()
        .take(n)
        .map(|x| x.to_string())
        .collect()
}
```

## Error Handling

```rust
pub fn dari_file(path: &str) -> Result<Statistik, std::io::Error> {
    let isi = std::fs::read_to_string(path)?;
    Ok(analisis(&isi))
}
```

## Main

```rust
mod analisis;

fn main() {
    let teks = "Rust itu aman dan Rust itu cepat";
    let s = analisis::analisis(teks);
    println!("kata: {}, unik: {}, karakter: {}", s.kata, s.unik, s.karakter);
}
```

## Test

