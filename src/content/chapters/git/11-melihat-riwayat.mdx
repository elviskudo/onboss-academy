Riwayat Git bukan sekadar daftar commit — ia adalah **peta perubahan** yang bisa ditelusuri.

## Log yang Berguna

```bash
git log --oneline --graph --all
git log --author="Sinta" --since="2 weeks ago"
git log --oneline -- src/app.js
git log -p -2
```

| Opsi | Fungsi |
|---|---|
| `--oneline` | satu baris per commit |
| `--graph` | visualisasi branch |
| `--all` | semua branch, bukan hanya aktif |
| `-p` | tampilkan patch |
| `--stat` | ringkasan jumlah baris |
| `-- path` | filter berdasarkan file |

## Membaca Diff

```bash
git diff              # working tree vs index
git diff --staged     # index vs HEAD
git diff HEAD         # working tree vs HEAD
git diff HEAD~1 HEAD  # dua commit terakhir
```

Tanda `+` berarti penambahan, `-` berarti penghapusan. Baris yang berubah ditampilkan sebagai pasangan.

## Menelusuri Asal Baris

```bash
git blame src/main.py
git log -S "fungsi_penting" --oneline
```

`-S` mencari commit yang menambah atau menghapus teks tertentu — sangat membantu saat mencari kapan bug mulai muncul.

<div class="note">💡 `git reflog` mencatat semua pergerakan HEAD, termasuk commit yang “hilang” setelah reset. Sering kali itu penyelamat saat perubahan tampaknya menghilang.</div>

## Ringkasan Perintah

```bash
git show <hash>       # detail satu commit
git show --stat HEAD  # ringkasan file yang berubah
git log --follow -- nama_file  # riwayat termasuk rename
```
