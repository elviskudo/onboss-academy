Git menyimpan preferensi dalam tiga level: **system**, **global**, dan **local**. Urutan prioritasnya dari yang paling umum ke paling spesifik.

## Tiga Level Konfigurasi

```bash
git config --system core.longpaths true   # semua user di mesin
git config --global user.name "Nama"      # satu user, semua repo
git config --local user.email "x@y.com"   # satu repo saja
```

| Level | Cakupan | File |
|---|---|---|
| system | seluruh mesin | `/etc/gitconfig` |
| global | satu akun pengguna | `~/.gitconfig` |
| local | satu repositori | `.git/config` |

## Identitas Penulis

```bash
git config --global user.name "Sinta Rahma"
git config --global user.email "sinta@perusahaan.id"
```

Nilai ini melekat pada setiap commit. Untuk repo dengan identitas berbeda (misalnya kontribusi open-source), gunakan konfigurasi local.

## Konfigurasi Berguna Lainnya

```bash
git config --global core.editor "code --wait"
git config --global init.defaultBranch main
git config --global pull.rebase false
git config --global core.autocrlf input
```

<div class="note">💡 `core.autocrlf` penting saat tim campur Windows dan Linux/macOS. Tanpa pengaturan ini, perubahan akhir baris bisa membuat seluruh file terlihat berubah.</div>

## Melihat dan Menghapus

```bash
git config --list --show-origin
git config --get user.name
git config --unset user.email
```

Selalu periksa dengan `--show-origin` ketika nilai yang muncul tidak sesuai harapan — bisa jadi ada pengaturan local yang menimpa global.
