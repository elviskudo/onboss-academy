**Pull request (PR)** adalah sarana kolaborasi: Anda mengusulkan perubahan, rekan meninjau, lalu perubahan digabung setelah disetujui.

## Alur Singkat

```bash
git switch -c fitur/ekspor-pdf
# kerjakan perubahan
git add .
git commit -m "feat: tambah ekspor PDF"
git fetch origin
git rebase origin/main
git push -u origin fitur/ekspor-pdf
```

Kemudian buat PR lewat antarmuka hosting.

## Isi Deskripsi yang Baik

```text
## Apa yang berubah
Menambahkan ekspor laporan ke PDF.

## Mengapa
Permintaan tim keuangan agar laporan bisa dibagikan tanpa Excel.

## Cara menguji
1. Buka halaman laporan.
2. Klik "Ekspor PDF".
3. Pastikan angka sudah sesuai.

## Catatan
Belum mendukung grafik interaktif.
```

## Peran Reviewer

- Periksa logika, bukan hanya gaya kode.
- Ajukan pertanyaan bila niat perubahan tidak jelas.
- Bedakan komentar wajib dan saran opsional.
- Setujui hanya setelah tes dan konflik selesai.

## Opsi Merge

| Opsi | Efek |
|---|---|
| Merge commit | mempertahankan seluruh riwayat branch |
| Squash and merge | satu commit di target |
| Rebase and merge | commit dipindah linear ke target |

<div class="note">💡 PR yang bagus menghormati waktu reviewer. Uji sendiri dulu, jelaskan konteks, dan pecah perubahan besar menjadi beberapa PR.</div>

## Setelah Merge

```bash
git switch main
git pull origin main
git branch -d fitur/ekspor-pdf
git push origin --delete fitur/ekspor-pdf
```

Hapus branch lokal dan remote agar daftar branch tetap bersih.
