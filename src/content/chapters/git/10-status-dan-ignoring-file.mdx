`git status` adalah kebiasaan paling penting dalam penggunaan Git. Ia memberitahu **di mana posisi kita** sebelum melakukan perubahan berikutnya.

## Membaca Status

```bash
git status
git status --short
```

| Status | Arti |
|---|---|
| Untracked | file baru belum dikenal Git |
| Changes not staged | file berubah belum masuk index |
| Changes to be committed | sudah staged, siap commit |
| nothing to commit | working tree bersih |

## Menulis .gitignore

```gitignore
# dependensi
node_modules/
vendor/

# rahasia dan lokal
.env
.env.local
*.pem

# hasil build
dist/
build/
*.log

# editor
.idea/
.DS_Store
```

Aturan pola:

- `*` mencocokkan karakter apa pun dalam satu level.
- `**` mencocokkan direktori bertingkat.
- `/` di awal berarti relatif terhadap root repo.
- `/` di akhir berarti direktori.
- `!` membalik pengecualian, misalnya `!important.log`.

## File Sudah Ter-Track

.gitignore **hanya mencegah file baru masuk**. File yang sudah terlanjur di-commit tetap dipantau.

```bash
git rm --cached .env
echo ".env" >> .gitignore
git commit -m "Hentikan tracking file .env"
```

<div class="note">💡 Simpan `.env.example` berisi nama variabel tanpa nilainya. Tim tahu konfigurasi apa yang dibutuhkan tanpa membocorkan kunci asli.</div>

## Debug Pola

```bash
git check-ignore -v path/to/file
git status --ignored
```

Perintah ini menunjukkan aturan mana yang menyebabkan sebuah file diabaikan.
