Interactive rebase memberi kendali atas **riwayat commit sebelum dibagikan**. Gunakan untuk merapikan commit coba-coba menjadi unit kerja yang masuk akal.

## Memulai

```bash
git log --oneline -5
git rebase -i HEAD~4
```

Editor akan menampilkan daftar commit dari yang tertua ke terbaru.

## Aksi Utama

| Aksi | Singkatan | Efek |
|---|---|---|
| pick | p | pakai commit apa adanya |
| reword | r | ubah pesan |
| edit | e | berhenti untuk mengubah isi |
| squash | s | gabung ke commit sebelumnya |
| fixup | f | gabung, buang pesan |
| drop | d | hapus commit |

## Contoh Hasil

```text
Sebelum:
a1b2  Tambah form login
d4e5  Perbaiki typo label
h7i8  Tambah validasi
l0m1  Commit coba-coba

Sesudah:
p9q8  Tambah form login dan validasi (perbaikan typo)
```

## Menangani Konflik

```bash
# edit file yang konflik
git add file_yang_diperbaiki
git rebase --continue

# atau membatalkan
git rebase --abort
```

Rebase bisa berhenti beberapa kali bila konflik muncul di beberapa commit.

<div class="note">💡 Aturan emas: **jangan rebase commit yang sudah di-push ke branch bersama**. Gunakan revert untuk membatalkan perubahan yang sudah dibagikan.</div>

## Alternatif Lebih Aman

Bila ingin menggabungkan beberapa commit terakhir tanpa editor interaktif:

```bash
git reset --soft HEAD~3
git commit -m "Satu commit gabungan"
```

Ini menggeser HEAD tanpa menghapus perubahan di working tree.
