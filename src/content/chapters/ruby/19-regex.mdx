Ruby memiliki sintaks regex yang ringkas dan terintegrasi. Regex adalah objek `Regexp`, sehingga bisa disimpan dan dipakai ulang.

## Literal & Operator

```ruby
teks = "Belajar Ruby 2024"
p teks =~ /Ruby/      # 8
p teks.match?(/Ruby/) # true (Ruby 2.4+)
p teks !~ /Java/      # true
```

Gunakan `match?` jika hanya butuh `true/false` — lebih cepat karena tidak membuat objek `MatchData`.

## Method Umum

```ruby
teks.scan(/\d+/)            # semua angka
teks.sub(/Ruby/, "Go")      # ganti pertama
teks.gsub(/Ruby/, "Go")     # ganti semua
teks.split(/\s+/)           # pecah berdasarkan spasi
```

## Capture Group

```ruby
m = "Rani, 22".match(/(\w+), (\d+)/)
puts m[1] # Rani
puts m[2] # 22
```

## Named Capture

```ruby
m = "Rani, 22".match(/(?<nama>\w+), (?<umur>\d+)/)
puts m[:nama]
puts m[:umur]
```

## Flag

| Flag | Arti |
|---|---|
| `i` | Abaikan huruf besar-kecil |
| `m` | Titik mencocokkan newline |
| `x` | Perbolehkan spasi & komentar dalam pola |

```ruby
pola = /
  \A        # awal string
  \w+       # nama
  @
  \w+\.\w+  # domain
  \z        # akhir string
/ix
```

<div class="note">💡 Regex literal dengan `/.../` perlu escape garis miring. Untuk pola yang banyak memuat `/`, pakai `%r{...}`.</div>
