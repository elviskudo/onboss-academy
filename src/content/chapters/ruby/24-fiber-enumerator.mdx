Fiber dan Enumerator memberi kontrol halus atas alur eksekusi. Mereka jadi dasar fitur async di beberapa library Ruby.

## Fiber

```ruby
fiber = Fiber.new do
  puts "mulai"
  Fiber.yield 10
  puts "lanjut"
  Fiber.yield 20
  puts "selesai"
end

puts fiber.resume # mulai, lalu 10
puts fiber.resume # lanjut, lalu 20
puts fiber.resume # selesai
```

`resume` menjalankan sampai `Fiber.yield` atau blok selesai. Memanggil fiber yang sudah mati memicu `FiberError`.

## Generator

```ruby
def angka_ganjil
  Fiber.new do
    1.step(by: 2).each { |n| Fiber.yield n }
  end
end

g = angka_ganjil
3.times { print g.resume, " " }
```

Fiber bisa menghasilkan deret tak hingga tanpa menyimpan semua nilai.

## Enumerator

```ruby
e = (1..Float::INFINITY).each
puts e.next
puts e.next
puts e.rewind
puts e.next
```

`next`, `rewind`, dan `peek` mengontrol iterasi dari luar.

## enum_for

```ruby
class Kata
  def setiap_kata
    yield "satu"
    yield "dua"
  end
end

e = Kata.new.enum_for(:setiap_kata)
puts e.next
puts e.next
```

## Lazy Enumerator

```ruby
e = (1..Float::INFINITY).lazy.select(&:even?)
puts e.first(3).inspect
```

<div class="note">💡 Fiber tidak membuat thread baru — semua berjalan di thread yang sama. Jangan pakai untuk paralelisme; gunakan untuk kontrol alur.</div>
