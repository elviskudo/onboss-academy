Ruby hanya mengizinkan **satu class induk**. Untuk berbagi perilaku ke banyak class tanpa duplikat, Ruby mengandalkan module — inilah alternatif pewarisan yang justru lebih sering dipakai daripada inheritance itu sendiri.

## 2 Peran Module

| Peran | Fungsi | Contoh |
| --- | --- | --- |
| **Mixin** — memasukkan method ke class | Berbagi perilaku lintas class | `include Lacak` |
| **Namespace** — wadah konstanta & method | Menghindari tabrakan nama antar library | `Hitung::Geometri` |

```ruby
module Util
  def self.kali(a, b)
    a * b
  end
end

puts Util.kali(6, 7)   # 42
```

Module **tidak bisa dibuat instance** sebagai objek bisnis (`Modul.new` error untuk module murni) — ia hanya wadah method, konstanta, dan atribut class.

## 3 Cara Memasukkan Module

```ruby
module Sapa
  def halo
    "Halo, saya #{self.class}"
  end
end

class Manusia
  include Sapa     # 1. instance method — method module jadi milik objek
end

class Robot
  prepend Sapa     # 2. method module diutamakan sebelum method class
end

class Admin
  def self.profil   # 3. extend — method module jadi class method
    "admin panel"
  end
  extend Sapa
end
```

| Cara | Method masuk sebagai | Urutan vs method class |
| --- | --- | --- |
| `include` | Instance method | Method class menang bila nama sama |
| `prepend` | Instance method | Module menang, lalu `super` ke class |
| `extend` | Class method | Dipanggil lewat class, bukan objek |

Satu class boleh `include` **banyak module tanpa batas** — inilah keunggulan utama dibanding pewarisan yang cuma boleh satu.

## Mixin Bawaan Ruby: Enumerable & Comparable

Ruby sendiri memakai pola ini: `Array`, `Hash`, dan `Range` sama-sama `include Enumerable`, sehingga mereka otomatis mendapat `map`, `select`, `reduce`, `sort_by`, dan puluhan method lain dari satu definisi. `Comparable` melakukan hal yang sama untuk `+`, `<=>`, `min`, `max` pada Integer, String, dan Time.

## Instance Method dari Module

```ruby
module Area
  def luas
    panjang * lebar
  end
end

class PersegiPanjang
  include Area
  attr_reader :panjang, :lebar

  def initialize(panjang, lebar)
    @panjang = panjang
    @lebar = lebar
  end
end

puts PersegiPanjang.new(4, 6).luas   # 24
```

## Namespace dengan ::

```ruby
module Hitung
  module Geometri
    def self.lingkaran(r)
      3.14 * r * r
    end
  end
end

puts Hitung::Geometri.lingkaran(7)   # 153.86
```

Tanda `::` menavigasi isi module — dua library boleh punya method `hitung` asal modulenya berbeda.

## Class, Mixin, atau Namespace?

| Situasi | Pilih | Alasan |
| --- | --- | --- |
| Data + perilaku khusus satu objek | Class | Ada state yang berubah per objek |
| Perilaku bisa dipakai class mana pun | Module (mixin) | Tanpa hubungan pewarisan |
| Mengelompokkan fungsi/util | Module (namespace) | Nama tidak menyebar ke mana-mana |
| Menambah perilaku ke method class yang sudah ada | `prepend` | Bisa mengubah perilaku tanpa menyentuh kode asli |

## Di Dunia Nyata

- **Pencatatan waktu**: module `DicatatWaktu` menambah `created_at`/`updated_at` ke model `Artikel`, `Komentar`, dan `Pengguna` sekaligus.
- **Hak akses role**: `include BerhakAkses` memberi method `boleh_hapus?` ke seluruh controller tanpa menulis ulang.
- **Validasi format**: module `FormatRupiah` menyediakan `rupiah` di view helper, mailer, dan API serializer.
- **Log debugging**: `prepend CetakLog` memanggil method asli lalu mencatat durasinya — semua class yang include langsung ter-log.
- **Library pihak ketiga**: `Money`, `Geocoder`, dan `Pagy` dipakai sebagai namespace/`include` tanpa mewarisi class kamu.

<div class="note">💡 Pertanyaan praktisnya sederhana: kalau perilaku itu milik satu objek dan butuh state-nya, taruh di class. Kalau bisa dipakai class mana pun tanpa hubungan pewarisan, taruh di module. Dan bila hanya mengelompokkan fungsi tanpa instance sama sekali, module murni dengan `def self.` adalah jawabannya.</div>
