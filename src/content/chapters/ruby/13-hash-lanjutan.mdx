Hash adalah struktur kunci–nilai yang sangat fleksibel. Hampir setiap program Ruby memakainya — dari konfigurasi sampai parameter fungsi.

## Symbol vs String

```ruby
data = { nama: "Rani" }    # symbol key
data2 = { "nama" => "Rani" } # string key

puts data[:nama]
puts data2["nama"]
```

Symbol lebih hemat memori dan lebih cepat dibandingkan string untuk kunci.

## Nilai Default

```ruby
hitung = Hash.new(0)
hitung[:apel] += 1
puts hitung[:jeruk] # 0
```

Untuk default dinamis, gunakan blok:

```ruby
data = Hash.new { |hash, key| hash[key] = [] }
data[:daftar] << "item"
```

## fetch

```ruby
data.fetch(:nama)          # error bila tidak ada
data.fetch(:kota, "Unknown") # pakai default
```

Lebih aman daripada `data[:kota]` yang diam-diam mengembalikan `nil`.

## merge & dig

```ruby
a = { warna: "merah", ukuran: "M" }
b = { warna: "biru", berat: 1 }
puts a.merge(b) # { warna: "biru", ukuran: "M", berat: 1 }

nested = { user: { alamat: { kota: "Bandung" } } }
puts nested.dig(:user, :alamat, :kota)
puts nested.dig(:user, :hp, :nomor).inspect # nil
```

## Enumerasi

```ruby
data.each do |kunci, nilai|
  puts "#{kunci}: #{nilai}"
end

data.keys
data.values
data.select { |k, v| v.is_a?(Integer) }
data.transform_values(&:to_s)
```

<div class="note">💡 Sejak Ruby 1.9, hash menjaga urutan penyisipan. Kamu bisa memakainya sebagai struktur data kecil yang tetap terurut.</div>
