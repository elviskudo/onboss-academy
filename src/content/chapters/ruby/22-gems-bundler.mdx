Gem adalah paket Ruby. Bundler mengelola gem per proyek supaya semua orang memakai versi yang sama.

## Gem Global

```bash
gem install rubocop
gem list
gem uninstall rubocop
```

## Gemfile

```ruby
source "https://rubygems.org"

ruby "3.2.0"

gem "rake", "~> 13.0"
gem "sinatra"

group :development, :test do
  gem "rspec"
end
```

## Perintah Bundler

| Perintah | Fungsi |
|---|---|
| `bundle install` | Pasang dependensi |
| `bundle update` | Perbarui versi |
| `bundle exec ruby app.rb` | Jalankan dengan versi terkunci |
| `bundle list` | Tampilkan gem aktif |
| `bundle show nama` | Lokasi gem |
| `bundle init` | Buat Gemfile baru |

## Version Constraint

| Operator | Arti |
|---|---|
| `= 1.2.3` | Tepat |
| `~> 2.1` | `>= 2.1, &lt; 3.0` |
| `~> 2.1.4` | `>= 2.1.4, &lt; 2.2` |
| `>= 1.0` | Minimal |

## Gem Lokal

```ruby
gem "nama_gem", path: "./lib/nama_gem"
gem "nama_gem", git: "https://github.com/..."
```

## Membuat Gem

```bash
bundle gem nama_gem
```

Perintah ini membuat struktur dasar: `lib/`, `spec/`, dan gemspec.

<div class="note">💡 Selalu jalankan aplikasi dengan <code>bundle exec</code> saat proyek memakai Bundler. Ini mencegah Ruby memuat versi gem global yang berbeda.</div>
