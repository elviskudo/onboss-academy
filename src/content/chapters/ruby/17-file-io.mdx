Ruby memperlakukan file sebagai objek `File` (turunan `IO`). Ada API singkat untuk sekali baca/tulis dan API blok untuk kontrol penuh.

## Sekali Jalan

```ruby
File.write("catatan.txt", "Isi awal")
puts File.read("catatan.txt")
baris = File.readlines("catatan.txt")
```

## File.open dengan Blok

```ruby
File.open("data.txt", "w") do |f|
  f.puts "Baris satu"
  f.puts "Baris dua"
end
```

File ditutup otomatis saat blok selesai — lebih aman daripada menutup manual.

| Mode | Arti |
|---|---|
| `"r"` | Baca (default) |
| `"w"` | Tulis, timpa |
| `"a"` | Tambah di akhir |
| `"r+"` | Baca + tulis |
| `"b"` | Mode biner |

## Membaca per Baris

```ruby
File.foreach("data.txt").with_index(1) do |baris, n|
  puts "#{n}: #{baris.chomp}"
end
```

`foreach` tidak memuat seluruh file ke memori.

## Pathname

```ruby
require "pathname"
path = Pathname.new("data") + "user.json"
puts path.extname      # ".json"
puts path.basename     # "user.json"
```

## CSV

```ruby
require "csv"
CSV.open("orang.csv", "w") do |csv|
  csv << ["nama", "umur"]
  csv << ["Rani", 22]
end
```

<div class="note">💡 Selalu tentukan encoding saat membaca data non-ASCII: <code>File.read("data.txt", encoding: "UTF-8")</code>.</div>
