Minitest adalah framework test ringan yang sudah tersedia bersama Ruby. Untuk proyek kecil, ini sering lebih dari cukup.

## Test Pertama

```ruby
require "minitest/autorun"

class TesKalkulator < Minitest::Test
  def test_tambah
    assert_equal 5, 2 + 3
  end

  def test_hasil_kosong
    assert_nil [].first
  end
end
```

Jalankan dengan `ruby tes.rb`.

## Assertion Umum

| Assertion | Fungsi |
|---|---|
| `assert` | Nilai truthy |
| `assert_equal` | Sama |
| `assert_nil` | Bernilai nil |
| `assert_raises` | Exception tertentu |
| `refute` | Nilai falsy |
| `assert_in_delta` | Desimal dalam toleransi |

```ruby
assert_raises(ZeroDivisionError) { 1 / 0 }
```

## setup & teardown

```ruby
def setup
  @kalkulator = Kalkulator.new
end

def teardown
  @kalkulator = nil
end
```

Keduanya dijalankan untuk setiap test, menjaga isolasi antar kasus.

## Test-Driven Development

1. Tulis test yang gagal (*red*)
2. Tulis kode minimum agar lolos (*green*)
3. Perbaiki struktur tanpa mengubah perilaku (*refactor*)

Siklus ini membuat kode lebih kecil dan lebih percaya diri saat diubah.

## RSpec (Opsional)

```ruby
RSpec.describe Kalkulator do
  it "menjumlahkan dua angka" do
    expect(described_class.new.tambah(2, 3)).to eq(5)
  end
end
```

RSpec lebih ekspresif tapi butuh gem tambahan.

<div class="note">💡 Satu test sebaiknya menguji satu perilaku. Jika nama test perlu kata "dan", pertimbangkan untuk memecahnya.</div>
