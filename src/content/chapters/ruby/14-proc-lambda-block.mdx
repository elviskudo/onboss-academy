Ruby memakai block di mana-mana — terutama pada iterator. Memahami perbedaan block, Proc, dan lambda membuat kode lebih fleksibel.

## Block

```ruby
def sapa
  yield "Rani"
end

sapa { |nama| puts "Halo #{nama}" }
```

Block adalah potongan kode yang dilewatkan ke method. Ia bukan objek sampai diubah menjadi `Proc`.

## Block sebagai Objek

```ruby
def jalankan(&blok)
  blok.call(5)
end

jalankan { |x| puts x * x }
```

Ampersand mengubah block menjadi `Proc`.

## Proc vs Lambda

| Aspek | Proc | Lambda |
|---|---|---|
| Cek jumlah argumen | Tidak | Ya |
| `return` | Keluar dari method pemanggil | Keluar dari lambda |
| Dibuat dengan | `Proc.new {}` | `-> {}` / `lambda {}` |

```ruby
p = Proc.new { |x, y| puts x }
p.call(1)     # y = nil, tidak error

l = ->(x, y) { puts x }
l.call(1)     # ArgumentError
```

## Closure

```ruby
def pembuat(n)
  ->(x) { x + n }
end

tambah5 = pembuat(5)
puts tambah5.call(10) # 15
```

Lambda mengingat variabel dari scope saat ia dibuat — itulah closure.

## Kapan Memakai Mana

- **Block** — untuk iterator dan callback sekali pakai
- **Proc** — saat ingin menyimpan block dan memanggilnya berkali-kali
- **Lambda** — saat ingin perilaku seperti method (cek argumen & return)

<div class="note">💡 Hati-hati memakai <code>return</code> di Proc yang dibuat di dalam method — ia akan mencoba keluar dari method tersebut dan bisa memicu LocalJumpError.</div>
