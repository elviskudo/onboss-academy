Metaprogramming berarti menulis kode yang memanipulasi kode lain. Ruby sangat kuat di sini — Rails dibangun di atas kemampuan ini.

## define_method

```ruby
class Kalkulator
  [:tambah, :kurang].each do |nama|
    define_method(nama) do |a, b|
      nama == :tambah ? a + b : a - b
    end
  end
end
```

Method dibuat saat kelas dimuat, bukan ditulis satu per satu.

## method_missing

```ruby
class Proxy
  def initialize(target) = @target = target

  def method_missing(nama, *args, &blok)
    if @target.respond_to?(nama)
      @target.public_send(nama, *args, &blok)
    else
      super
    end
  end

  def respond_to_missing?(nama,privat = false)
    @target.respond_to?(nama, privat) || super
  end
end
```

Selalu panggil `super` jika tidak bisa ditangani agar error tetap masuk akal.

## Introspection

```ruby
obj.methods.grep(/nama/)
obj.instance_variables
obj.class.ancestors
obj.respond_to?(:each)
```

## class_eval

```ruby
Kelas.class_eval do
  attr_accessor :nama
end
```

## Kapan Dipakai

Metaprogramming hebat untuk framework dan DSL, tapi bisa membuat kode sulit dilacak. Gunakan hanya saat memang ada pengulangan pola yang sulit dihindari.

<div class="note">💡 Setiap method dinamis yang dibuat lewat method_missing sebaiknya juga dikenali oleh respond_to_missing?. Tanpa itu, library lain akan mengira method itu tidak ada.</div>
