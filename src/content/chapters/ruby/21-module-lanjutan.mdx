Modul di Ruby punya dua peran: namespace untuk konstanta dan wadah method yang bisa dicampukkan (mixin). Memahami `include`, `prepend`, dan `extend` penting untuk rancangan API.

## include

```ruby
module BisaLari
  def lari = "sedang lari"
end

class Manusia
  include BisaLari
end

Manusia.ancestors # [Manusia, BisaLari, Object, ...]
```

Method kelas menang atas method modul.

## prepend

```ruby
module Log
  def proses
    puts "mulai"
    super
  end
end

class Kerja
  prepend Log
  def proses = puts("kerja")
end
```

`prepend` menaruh modul sebelum kelas, jadi method modul bisa memanggil `super` ke method kelas — pola populer untuk decorator.

## extend

```ruby
module Utilitas
  def bantu = "membantu"
end

class Layanan
  extend Utilitas
end

Layanan.bantu # class method
```

## Hook

```ruby
module Terlaporkan
  def self.included(base)
    base.extend(ClassMethods)
  end

  module ClassMethods
    def daftar = @daftar ||= []
  end
end
```

Hook `included`, `extended`, dan `prepended` dipanggil otomatis saat modul dipakai.

## Namespace

```ruby
modul Onboss
  VERSION = "1.0"
  module Util
    def self.nama = "Onboss"
  end
end
```

<div class="note">💡 `include` menambah method sebagai instance method; `extend` menambah sebagai singleton method. Beda keduanya sering membingungkan pemula.</div>
