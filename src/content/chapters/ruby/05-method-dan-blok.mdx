Method mengemas logika agar bisa dipakai ulang, blok menambahkan perilaku fleksibel ke method tersebut. Inilah wujud "function" di Ruby — dan cara utama Ruby menghindari duplikasi tanpa inheritance.

## 5 Bentuk Definisi Method

| Bentuk | Sintaks | Kapan dipakai |
| --- | --- | --- |
| Instance method | `def lulus?` | Perilaku tiap objek |
| Class method | `def self.hitung` | Utility tanpa objek, factory |
| Setter | `def harga=(nilai)` | Menambah validasi saat atribut ditulis |
| Predicate | `def aktif?` | Selalu mengembalikan true/false |
| Bang method | `def simpan!` | Versi yang menimpa data / berisiko gagal |

```ruby
def sapa
  puts "Selamat belajar Ruby!"
end

sapa   # kurung boleh kosong
```

Method ditutup `end`, dipanggil tanpa tanda kurung bila tanpa argumen.

## 6 Jenis Parameter

| # | Jenis | Contoh | Fungsi |
| --- | --- | --- | --- |
| 1 | Positional wajib | `def luas(p, l)` | Argumen tetap berurutan |
| 2 | Default / opsional | `def sapa(nama, salam = "Halo")` | Argumen boleh dilewat |
| 3 | Keyword argument | `def pindah(alamat:, kurir: "JNE")` | Pemanggil menulis nama argumen |
| 4 | Variadic (splat) | `def jumlah(*angka)` | Menerima argumen tak terbatas |
| 5 | Double splat | `def konfigurasi(**opsi)` | Kumpulan keyword jadi hash |
| 6 | Block (`&blok`) | `def dengan_blok(&b)` | Blok diterima sebagai objek |

```ruby
def sapa(nama, salam = "Halo")
  "#{salam}, #{nama}!"
end

def pindah(alamat:, kurir: "JNE")
  "#{kurir} → #{alamat}"
end

def jumlah(*angka)
  angka.sum
end

puts sapa("Sari")
puts pindah(alamat: "Bandung")
puts jumlah(1, 2, 3, 4)
```

Memanggil dengan keyword eksplisit membuat kode pemanggil terbaca tanpa menghafal urutan argumen.

## Return: Implisit dan Eksplisit

```ruby
def tambah(a, b)
  a + b          # nilai ekspresi terakhir = nilai kembalian
end

def batas_umur(usia)
  return "tolak" if usia < 17   # keluar lebih awal
  "terima"
end

hasil = tambah(3, 4)   # 7
```

`return` hanya dibutuhkan untuk keluar lebih awal. Tanpa `return`, method tetap mengembalikan `nil` bila tidak ada ekspresi bermakna — Ruby tidak punya tipe "void".

## Blok, yield, dan Proc

```ruby
def ulang_kali(n)
  n.times { yield }
end

ulang_kali(3) { puts "blok dijalankan" }

def aman
  yield if block_given?
end
```

2 sintaks blok: `{ ... }` untuk satu-dua baris dan `do ... end` untuk blok panjang. 2 jenis objek blok: `proc` (argument lunak, gaya blok) dan `lambda`/`->` (argument ketat, punya return sendiri). Blok bersifat **closure** — ia menangkap variabel di sekitarnya saat dibuat:

```ruby
faktor = 3
kali = ->(n) { n * faktor }
puts kali.call(5)   # 15
```

`map`, `select`, dan `reduce` adalah higher-order method: menerima logika (blok) sebagai argumen.

## Di Dunia Nyata

- **Format uang berulang**: `def rupiah(n)` mengubah `1_250_000` jadi `"Rp1.250.000"` — dipanggil dari 20 tempat cetak struk.
- **Validasi form reusable**: `def wajib_ada(isi, nama)` dipakai untuk nama, email, dan alamat tanpa menyalif-if.
- **Enkripsi password**: `def hash_password(opsi)` membungkus logika bcrypt sekali untuk seluruh aplikasi.
- **Generator laporan**: method `laporan(bulan:) { |baris| ... }` menerima blok penulis — CSV, JSON, atau teks tinggal ganti bloknya.
- **Query aman**: method `cari(kata)` berisi `where("nama ILIKE ?", "%#{kata}%")` — SQL injection dicegah dari satu titik saja.

<div class="note">💡 Method di Ruby tidak pernah "tidak mengembalikan apa-apa": ia selalu mengembalikan nilai ekspresi terakhir (atau `nil`). Karena itu `if`, `case`, dan `begin` bisa langsung ditugaskan ke variabel — manfaatkan ini alih-alih menulis variabel sementara di tiap cabang.</div>
