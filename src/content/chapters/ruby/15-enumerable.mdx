Modul `Enumerable` adalah salah satu alasan Ruby terasa menyenangkan. Cukup dengan `each`, sebuah kelas mendapat puluhan method pemrosesan data.

## Method Inti

| Method | Fungsi |
|---|---|
| `map` / `collect` | Ubah tiap elemen |
| `select` / `filter` | Saring elemen |
| `reject` | Kebalikan select |
| `find` | Elemen pertama yang cocok |
| `reduce` / `inject` | Akumulasi |
| `sort_by` | Urutkan berdasarkan kunci |
| `group_by` | Kelompokkan |
| `each_with_index` | Sertakan indeks |
| `partition` | Pisahkan jadi dua array |

```ruby
kata = %w[apel jeruk mangga anggur]
puts kata.group_by { |k| k.length }
puts kata.sort_by { |k| k.length }
```

## Symbol to Proc

```ruby
puts %w[1 2 3].map(&:to_i)  # [1, 2, 3]
```

`&:to_i` adalah versi pendek dari `{ |x| x.to_i }`.

## Lazy Enumerator

```ruby
hasil = (1..1_000_000)
  .lazy
  .select { |n| n.prime? }
  .map { |n| n * n }
  .first(5)
```

Tanpa `lazy`, Ruby akan memproses semua jutaan elemen. Dengan lazy, hanya yang dibutuhkan yang dihitung.

## Enumerable Kustom

```ruby
class Kumpulan
  include Enumerable
  def initialize(data) = @data = data
  def each(&blok) = @data.each(&blok)
end

puts Kumpulan.new([3, 1, 2]).sort # [1, 2, 3]
```

Cukup implementasikan `each`; method lain otomatis tersedia.

<div class="note">💡 `map!` dan `select!` mengubah array aslinya. Tanpa tanda seru, method mengembalikan array baru dan yang lama tetap utuh.</div>
