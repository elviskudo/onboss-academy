Program yang berguna perlu menyimpan data antar kali jalan. Ruby menawarkan API file yang sangat ringkas — dan proyek mini di bagian akhir merangkai seluruh materi: array, method, blok, dan file.

## 8 Mode Pembukaan File

| Mode | Baca | Tulis | Perilaku saat file sudah ada |
| --- | --- | --- | --- |
| `"r"` | ya | tidak | Default — baca apa adanya |
| `"r+"` | ya | ya | Baca/tulis, isi lama utuh kecuali ditimpa |
| `"w"` | tidak | ya | **Kosongkan seluruh isi lama** |
| `"w+"` | ya | ya | Kosongkan, lalu boleh baca |
| `"a"` | tidak | ya | Menambah di akhir file |
| `"a+"` | ya | ya | Menambah di akhir, isi lama tetap terbaca |
| `"x"` | tidak | ya | Error bila file sudah ada (buat eksklusif) |
| `"x+"` | ya | ya | Sama, untuk file yang belum boleh ada |

## 10 Method Berkas yang Paling Sering Dipakai

| # | Method | Fungsi | # | Method | Fungsi |
| --- | --- | --- | --- | --- | --- |
| 1 | `File.read` | Baca seluruh isi → String | 6 | `File.size` | Ukuran dalam byte |
| 2 | `File.write` | Tulis/timpa dalam satu baris | 7 | `File.delete` | Hapus berkas |
| 3 | `File.open` | Buka dengan blok (auto-close) | 8 | `File.rename` | Ganti nama / pindah |
| 4 | `File.exist?` | Cek keberadaan | 9 | `File.foreach` | Iterasi per baris |
| 5 | `File.readlines` | Baca → array of String | 10 | `File.expand_path` | Path absolut |

```ruby
if File.exist?("data.txt")
  puts File.read("data.txt")
else
  puts "File tidak ditemukan"
end

File.write("keluaran.txt", "Baris pertama\nBaris kedua\n")

File.open("berita.txt", "a") do |f|
  f.puts "Baris ketiga — mode append"
end
```

Blok pada `File.open` **menutup file otomatis**, termasuk saat terjadi error di dalamnya — tanpa blok, kamu wajib memanggil `close` sendiri di `ensure`.

## Membaca Per Baris

```ruby
File.foreach("data.txt").with_index(1) do |baris, nomor|
  puts "#{nomor}: #{baris}"
end
```

`foreach`/`each_line` cocok untuk file log puluhan megabyte: hanya satu baris yang berada di memori pada satu waktu.

## 3 Penanganan Kegagalan Berkas

```ruby
# 1. Cek keberadaan dulu
puts File.read("konfigurasi.yml") if File.exist?("konfigurasi.yml")

# 2. Tangkap error eksplisit
begin
  File.read("wajib.txt")
rescue Errno::ENOENT
  puts "File tidak ditemukan"
end

# 3. Beri nilai cadangan
isi = File.exist?("cache.txt") ? File.read("cache.txt") : "{}"
```

## Proyek Mini: Daftar Tugas Bertahan

```ruby
require "json"

FILE = "daftar.json"

def muat
  File.exist?(FILE) ? JSON.parse(File.read(FILE)) : []
end

def simpan(daftar)
  File.write(FILE, JSON.pretty_generate(daftar))
end

daftar = muat
daftar << "Belajar variabel Ruby" unless daftar.include?("Belajar variabel Ruby")
daftar << "Pahami blok dan method"
daftar << "Buat proyek kecil"

simpan(daftar)

puts "Tersimpan #{daftar.length} tugas:"
daftar.each_with_index { |t, i| puts "#{i + 1}. #{t}" }
```

Alurnya: **baca → ubah di memori → tulis kembali**. Saat program dijalankan ulang, `JSON.parse` mengembalikan daftar persis seperti terakhir disimpan.
