Ruby punya banyak cara untuk menulis percabangan. Pilih yang paling enak dibaca — bahasa ini memang mengutamakan kenyamanan penulis (*developer happiness*).

## case/when

```ruby
case nilai
when 90..100
  puts "A"
when 75...90
  puts "B"
when 0...75
  puts "C"
else
  puts "Nilai di luar rentang"
end
```

`..` termasuk batas akhir, `...` tidak. Karena `when` memakai `===`, kamu bisa memakai regex dan class:

```ruby
case input
when /\A\d+\z/ then puts "angka"
when String     then puts "teks"
end
```

## unless

```ruby
unless login?
  puts "Silakan masuk dulu"
end
```

Sama dengan `if !login?`, tapi lebih mudah dibaca.

## Modifier

```ruby
puts "panjang" if teks.length > 10
puts "gagal" unless berhasil
```

Cocok untuk satu baris aksi sederhana.

## Ternary

```ruby
status = umur >= 18 ? "dewasa" : "anak"
```

## Truthiness

Di Ruby, hanya `false` dan `nil` yang bernilai palsu. `0`, `""`, dan `[]` semuanya **truthy** — berbeda dengan JavaScript atau Python.

<div class="note">💡 Hati-hati dengan <code>and</code>/<code>or</code>: prioritasnya lebih rendah daripada <code>=</code>. Lebih aman memakai <code>&amp;&amp;</code> dan <code>||</code> dalam ekspresi biasa.</div>
