Ruby memperlakukan hampir semua hal sebagai objek, termasuk angka. Operator adalah method khusus yang bisa di-override pada kelas buatanmu.

## Aritmetika

| Operator | Arti | Contoh | Hasil |
|---|---|---|---|
| `+` | Tambah | `7 + 2` | `9` |
| `-` | Kurang | `7 - 2` | `5` |
| `*` | Kali | `7 * 2` | `14` |
| `/` | Bagi | `7 / 2` | `3` |
| `%` | Sisa | `7 % 2` | `1` |
| `**` | Pangkat | `2 ** 3` | `8` |

Gunakan `.to_f` atau literal desimal untuk hasil pecahan:

```ruby
puts 7 / 2.0  # 3.5
```

## Perbandingan

`==`, `!=`, `>`, `<`, `>=`, `&lt;=`, dan `&lt;=>` (spaceship). Operator `&lt;=>` mengembalikan `-1`, `0`, atau `1` dan dipakai oleh `sort`.

```ruby
puts 5 <=> 10  # -1
puts [3, 1, 2].sort # [1, 2, 3]
```

## Logika

`&&`, `||`, `!` — atau bentuk kata `and`, `or`, `not` yang prioritasnya lebih rendah. `&&` dan `||` bersifat short-circuit.

## Safe Navigation

```ruby
puts nama&.upcase  # nil, tanpa NoMethodError
```

`&.` memanggil method hanya jika penerimanya bukan `nil`.

## Operator Sebagai Method

```ruby
class Titik
  def +(other)
    Titik.new(@x + other.x)
  end
end
```

Karena operator adalah method, kamu bisa mendefinisikan perilaku `+`, `==`, `[]`, dan lain-lain pada kelas sendiri.

<div class="note">💡 Bedakan `==` (nilai sama) dengan `equal?` (objek yang benar-benar sama). Untuk objek string, `"a" == "a"` true meski dua objek berbeda.</div>
