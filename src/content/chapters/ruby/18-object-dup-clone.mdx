Ruby menyalin objek dengan `dup` atau `clone`, membekukannya dengan `freeze`, dan bisa menyerialisasinya memakai `Marshal`.

## dup vs clone

```ruby
a = [1, 2]
b = a.dup
c = a.clone

a.freeze
# b << 3        # boleh
# c << 3        # FrozenError: clone ikut beku
```

`clone` lebih konservatif: ia membawa status beku dan singleton method.

## Shallow vs Deep Copy

```ruby
asal = [[1], [2]]
salinan = asal.dup
salinan[0] << 99
p asal # [[99], [2]] — array dalam masih dibagi
```

Untuk salinan dalam, serialisasi sering dipakai:

```ruby
salinan = Marshal.load(Marshal.dump(asal))
```

## freeze

```ruby
TEKS = "konstanta".freeze
TEKS << "x" # FrozenError
```

Freeze bersifat satu arah — tidak ada `unfreeze`. Constant di Ruby tidak otomatis beku, jadi `freeze` sering ditambahkan.

## Marshal

```ruby
data = { nama: "Rani", umur: 22 }
biner = Marshal.dump(data)
kembali = Marshal.load(biner)
```

Marshal hanya untuk Ruby-ke-Ruby dan **jangan pernah** memuat data dari sumber tak dipercaya — bisa mengeksekusi objek berbahaya saat load.

## JSON sebagai Alternatif

Untuk pertukaran dengan bahasa lain, gunakan JSON:

```ruby
require "json"
JSON.generate(data)
JSON.parse(json)
```

<div class="note">💡 Method dengan tanda seru seperti <code>upcase!</code> mengubah objek langsung. Versi tanpa tanda seru mengembalikan objek baru — lebih aman tapi sedikit lebih banyak alokasi.</div>
