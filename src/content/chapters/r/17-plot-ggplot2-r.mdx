**ggplot2** memakai *grammar of graphics*: plot dibangun dari lapisan-lapisan independen. Data dipetakan ke estetika, lalu geometri menentukan bentuk visualnya.

## Anatomi Plot

```r
library(ggplot2)
ggplot(data = df, aes(x = umur, y = pendapatan, color = kelas)) +
  geom_point(size = 2, alpha = 0.7) +
  labs(title = "Umur vs Pendapatan", x = "Umur (tahun)", y = "Pendapatan (juta)") +
  theme_minimal()
```

`aes()` memetakan **kolom**; argumen di luar `aes()` seperti `size = 2` adalah nilai **tetap**.

## Memilih Geom

| Pertanyaan | Geom |
| --- | --- |
| Distribusi angka | `geom_histogram()`, `geom_density()` |
| Hubungan dua angka | `geom_point()`, `geom_smooth()` |
| Perbandingan kategori | `geom_col()`, `geom_boxplot()` |
| Perubahan waktu | `geom_line()` |
| Proporsi | `geom_bar(position = "fill")` |

```r
 ggplot(df, aes(x = kategori)) + geom_bar(fill = "steelblue")
 ggplot(df, aes(x = nilai)) + geom_histogram(bins = 20)
 ggplot(df, aes(x = tanggal, y = omzet)) + geom_line()
```

## Facet dan Tema

```r
ggplot(df, aes(x = bulan, y = omzet)) +
  geom_col() +
  facet_wrap(~ wilayah, scales = "free_y") +
  theme_bw() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))
```

`facet_grid(baris ~ kolom)` cocok untuk dua faktor sekaligus; `facet_wrap` untuk satu faktor dengan banyak level.

## Skala dan Warna

```r
ggplot(df, aes(x = nilai, fill = kelas)) +
  geom_histogram(position = "dodge", bins = 15) +
  scale_fill_brewer(palette = "Set2")
```

Untuk warna yang konsisten antar plot, gunakan `scale_color_manual(values = c(A = "#E69F00", B = "#56B4E9"))`.

## Menyimpan Plot

```r
ggsave("hasil.png", width = 8, height = 5, dpi = 300)
ggsave("hasil.svg", plot = p, width = 8, height = 5)
```

Simpan SVG untuk publikasi digital, PNG untuk slide. Atur `dpi` minimal 300 bila akan dicetak.

## Di Dunia Nyata

- **Eksplorasi awal**: histogram mengungkap distribusi dan pencilan sebelum modeling.
- **Laporan bulanan**: `geom_col()` + `facet_wrap(~cabang)` memberi satu panel per cabang.
- **Diagnostik model**: `geom_point(aes(x = fitted, y = resid))` memeriksa pola residual.
- **Dashboard**: kombinasikan dengan Shiny agar pengguna bisa mengubah filter.

<div class="note">💡 Mulailah dari pertanyaan, bukan dari jenis grafik. "Apakah omzet naik tiap bulan?" mengarah ke `geom_line()`, sedangkan "kategori mana terbesar?" mengarah ke `geom_col()`.</div>
