**dplyr** menyediakan kata kerja (verbs) yang mudah dibaca untuk manipulasi data. Filosofinya: satu fungsi melakukan satu hal, lalu dirangkai dengan pipe.

## Tujuh Verb Inti

| Verb | Tugas |
| --- | --- |
| `filter()` | menyaring baris |
| `select()` | memilih kolom |
| `mutate()` | membuat/mengubah kolom |
| `arrange()` | mengurutkan baris |
| `summarise()` | meringkas menjadi satu baris per grup |
| `group_by()` | menentukan grup |
| `distinct()` | membuang baris duplikat |

```r
library(dplyr)
hasil <- data.frame(nama = c("Ana", "Budi", "Rani"),
                    nilai = c(80, 92, 85)) %>%
  filter(nilai >= 85) %>%
  mutate(predikat = ifelse(nilai >= 90, "A", "B")) %>%
  arrange(desc(nilai)) %>%
  select(nama, nilai, predikat)
```

## Pipe: %>% dan |>

```r
# gaya klasik (butuh library dplyr/magrittr)
df %>% filter(nilai > 80) %>% summarise(rata = mean(nilai))

# pipe native R 4.1+, tidak perlu paket tambahan
df |> filter(nilai > 80) |> summarise(rata = mean(nilai))
```

`%>%` menyisipkan data sebagai argumen pertama. `|>` adalah versi bawaan R dengan keterbatasan: tidak bisa memakai `.` sebagai placeholder di semua posisi.

## Ringkasan per Grup

```r
penjualan %>%
  group_by(wilayah, tahun) %>%
  summarise(total = sum(omzet),
            rata  = mean(omzet),
            n     = n(),
            .groups = "drop")
```

Argumen `.groups = "drop"` melepaskan grouping setelah ringkasan agar operasi berikutnya tidak terkejut. `n()` menghitung jumlah baris dalam grup.

## Join dengan dplyr

```r
pesanan %>% left_join(pelanggan, by = "id_pelanggan")
pesanan %>% inner_join(produk, by = "id_produk")
```

| Fungsi | Baris yang dipertahankan |
| --- | --- |
| `inner_join` | hanya yang cocok di kedua tabel |
| `left_join` | semua baris tabel kiri |
| `right_join` | semua baris tabel kanan |
| `full_join` | semua baris kedua tabel |
| `anti_join` | baris kiri yang tidak punya pasangan |

<div class="note">💡 Sebelum join, cek tipe kolom kuncinya. `id` bertipe character di satu tabel dan integer di tabel lain sering menghasilkan semua `NA` tanpa peringatan yang jelas.</div>

## Helper yang Sering Dipakai

```r
df %>% slice_max(nilai, n = 3)       # 3 nilai terbesar
df %>% count(kelas)                  # frekuensi per kategori
df %>% mutate(z = (nilai - mean(nilai)) / sd(nilai))  # standardisasi
df %>% rename(skor = nilai)          # ganti nama kolom
df %>% relocate(nama, .before = 1)   # pindahkan kolom ke depan
```

## Di Dunia Nyata

- **Dashboard penjualan**: `group_by(bulan) %>% summarise(total)` sebagai dasar grafik.
- **Data pelanggan**: `left_join` menggabungkan transaksi dengan profil pelanggan.
- **Pembersihan**: `distinct(id, .keep_all = TRUE)` membuang duplikat.
- **Analisis kohort**: `mutate()` membuat kolom bulan pertama.transaksi untuk dikelompokkan.
