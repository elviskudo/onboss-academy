Matriks adalah vektor dengan atribut `dim` berupa dua bilangan: jumlah baris dan kolom. Semua elemennya harus bertipe sama. Array adalah generalisasi matriks untuk tiga dimensi atau lebih.

## Membuat Matriks

```r
m <- matrix(1:6, nrow = 2)             # diisi per kolom
m2 <- matrix(1:6, nrow = 2, byrow = TRUE)
rbind(c(1, 2), c(3, 4))                # gabung sebagai baris
cbind(c(1, 2), c(3, 4))                # gabung sebagai kolom
```

```text
matrix(1:6, nrow=2)     matrix(..., byrow=TRUE)
     [,1] [,2] [,3]          [,1] [,2] [,3]
[1,]    1    3    5      [1,]    1    2    3
[2,]    2    4    6      [2,]    4    5    6
```

## Mengindeks

| Bentuk | Arti |
| --- | --- |
| `m[1, 2]` | baris 1, kolom 2 |
| `m[1, ]` | seluruh baris pertama |
| `m[, 2]` | seluruh kolom kedua |
| `m[c(1,3), ]` | baris 1 dan 3 |
| `m[-1, ]` | semua baris kecuali yang pertama |
| `m[m > 3]` | elemen yang memenuhi syarat |

```r
m <- matrix(1:6, nrow = 2, byrow = TRUE)
m[2, 3]      # 6
m[, 2]       # 2 5
m[m > 4]     # 5 6
```

## Operasi Matriks

```r
A <- matrix(c(1, 2, 3, 4), 2)
B <- matrix(c(5, 6, 7, 8), 2)
A + B        # penjumlahan elemen
A * B        # perkalian elemen
A %*% B      # perkalian matriks
t(A)         # transpose
diag(3)      # matriks identitas 3x3
solve(A)     # invers (harus singular-free)
```

Perkalian `%*%` mensyaratkan kolom matriks pertama sama dengan baris matriks kedua.

## Array Multidimensi

```r
a <- array(1:24, dim = c(3, 4, 2))
a[1, 2, 1]     # baris 1, kolom 2, lapisan 1
dim(a)         # 3 4 2
```

Array sering dipakai untuk data spatiotemporal: dimensi pertama lokasi, kedua waktu, ketiga variabel.

## Nama Baris dan Kolom

```r
m <- matrix(1:4, 2, dimnames = list(c("Utara", "Selatan"),
                                    c("Q1", "Q2")))
m["Utara", "Q2"]
rownames(m); colnames(m)
```

<div class="note">💡 Gunakan `drop = FALSE` saat mengambil satu kolom agar hasilnya tetap matriks, misalnya `m[, 1, drop = FALSE]`. Ini penting bila fungsi berikutnya menuntut input berupa matriks 2 dimensi.</div>

## Di Dunia Nyata

- **Tabel absensi**: baris = mahasiswa, kolom = pertemuan.
- **Matriks kovarians**: dasar analisis portofolio dan PCA.
- **Citra digital**: matriks berisi intensitas piksel; array menambah kanal warna.
- **Sistem persamaan**: `solve(A, b)` menyelesaikan `Ax = b`.
