**Operator** adalah simbol yang meminta R melakukan kalkulasi atau perbandingan. Hasilnya selalu berupa vektor — bahkan untuk satu angka.

## Aritmetika

| Operator | Arti | Contoh | Hasil |
| --- | --- | --- | --- |
| `+` | tambah | `7 + 3` | 10 |
| `-` | kurang | `7 - 3` | 4 |
| `*` | kali | `7 * 3` | 21 |
| `/` | bagi | `7 / 3` | 2.333 |
| `%%` | sisa bagi | `7 %% 3` | 1 |
| `%/%` | bagi bulat | `7 %/% 3` | 2 |
| `^` / `**` | pangkat | `2 ^ 3` | 8 |

```r
7 %% 3   # sisa
7 %/% 3  # hasil bagi dibulatkan ke bawah
2 ** 10  # pangkat, sama dengan 2^10
```

## Perbandingan

Operator `==`, `!=`, `<`, `>`, `&lt;=`, `>=` menghasilkan `TRUE` atau `FALSE`. Bedanya dengan banyak bahasa lain, `==` boleh membandingkan angka dengan string karena R melakukan *coercion*: `"7" == 7` bernilai `TRUE`. Bila itu tidak diinginkan, gunakan `===` jika tersedia melalui paket atau bandingkan tipe secara eksplisit dengan `identical("7", 7)`.

```r
identical(7, 7L)   # FALSE: numeric vs integer
7 == 7L            # TRUE: nilai sama setelah coercion
```

## Logika

| Operator | Cara kerja |
| --- | --- |
| `&` | AND untuk setiap pasangan elemen |
| `|` | OR untuk setiap pasangan elemen |
| `!` | negasi |
| `&&` | AND, hanya elemen pertama, evaluasi singkat |
| `||` | OR, hanya elemen pertama, evaluasi singkat |

Gunakan `&&` / `||` di dalam `if`, sedangkan `&` / `|` saat memfilter vektor atau kolom data frame.

```r
usia <- c(17, 25, 40)
usia >= 18 & usia < 30   # FALSE TRUE FALSE
```

## Penugasan dan Prioritas

`<-` adalah penugasan paling umum di R; `=` juga dipakai terutama untuk argumen fungsi. `->` menulis ke arah sebaliknya. Prioritasnya: kurung → pangkat → kali/bagi → tambah/kurang → perbandingan → logika → penugasan.

<div class="note">💡 R memakai `<-` karena panah menunjukkan nilai "mengalir" ke nama variabel. Komunitas R sangat konsisten memakai `<-` di skrip, jadi gaya ini sebaiknya diikuti.</div>

## Di Dunia Nyata

- **Penentuan diskon**: `total > 100000 & member == TRUE` menentukan siapa mendapat potongan harga.
- **Pembagian kelompok umur**: `usia %/% 10 * 10` mengubah usia menjadi kelas dekade.
- **Validasi input**: `is.na(x) | x &lt; 0` menandai data yang perlu diperbaiki.
- **Pengecekan singkat**: `if (!is.null(file) && file.exists(file))` menghindari error saat file belum ada.
