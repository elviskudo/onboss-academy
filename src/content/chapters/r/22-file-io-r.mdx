## CSV dan TSV

```r
df <- read.csv("data.csv", header = TRUE, stringsAsFactors = FALSE)
write.csv(df, "bersih.csv", row.names = FALSE)

tab <- read.delim("data.tsv", quote = "")
```

`row.names = FALSE` mencegah kolom nomor baris tambahan muncul saat file ditulis ulang — kesalahan klasik yang menghasilkan kolom `X` di file berikutnya.

## Argumen yang Sering Dibutuhkan

| Argumen | Fungsi |
| --- | --- |
| `sep` | pemisah antar kolom |
| `header` | apakah ada baris judul |
| `na.strings` | teks yang dianggap missing |
| `fileEncoding` | encoding sumber |
| `colClasses` | paksa tipe kolom |
| `check.names = FALSE` | jangan ubah nama kolom |
| `quote` | karakter pembungkus teks |

```r
df <- read.csv("data.csv", na.strings = c("", "NA", "-"),
               colClasses = c(id = "character", tanggal = "character"),
               fileEncoding = "UTF-8")
```

## Excel

```r
library(readxl)
df <- read_excel("laporan.xlsx", sheet = "Data", skip = 2)
excel_sheets("laporan.xlsx")
```

`skip` berguna bila baris judul bukan di baris pertama, misalnya ada judul laporan dan tanggal di atasnya.

## RDS dan RData

```r
saveRDS(model, "model.rds")
model2 <- readRDS("model.rds")

save(df, model, file = "sesi.RData")
load("sesi.RData")
```

`saveRDS()` menyimpan **satu** objek dan memberi nama saat dibaca. `save()` menyimpan **beberapa** objek beserta nama aslinya dan mengembalikannya ke lingkungan saat `load()`.

## Path yang Aman

```r
file.path("data", "2026", "penjualan.csv")
list.files("data", pattern = "\.csv$", full.names = TRUE)
```

`file.path()` membuat path sesuai platform. `full.names = TRUE` menghasilkan path lengkap sehingga `lapply()` bisa langsung membaca semua file.

<div class="note">💡 Simpan data mentah apa adanya dan tulis hasil pembersihan ke file baru. Menimpa sumber asli membuat proses tidak bisa diaudit ulang.</div>

## Di Dunia Nyata

- **Ekspor ERP**: CSV dengan `;` sebagai pemisah pada sistem Eropa.
- **Laporan Excel**: `read_excel` untuk sheet yang diberi jumlah baris header.
- **Model produksi**: `saveRDS` menyimpan model yang akan dimuat API.
- **Batch processing**: `list.files` + `lapply` memproses ratusan file sekaligus.
