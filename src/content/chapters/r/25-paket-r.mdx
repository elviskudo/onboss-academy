Kekuatan R ada pada ekosistem paketnya. Ribuan paket tersedia di CRAN, Bioconductor, dan GitHub. Mengelolanya dengan rapi membuat analisis tetap bisa dijalankan bulan depan.

## Pasang dan Muat

```r
install.packages("dplyr")
library(dplyr)

# tanpa memuat seluruh paket ke namespace
dplyr::mutate(df, baru = lama * 2)
```

`install.packages()` cukup sekali per mesin. `library()` dilakukan setiap sesi baru. `require()` mirip `library()` tetapi mengembalikan `TRUE`/`FALSE` dan sering dipakai di dalam fungsi.

## Sumber Paket

| Sumber | Cara |
| --- | --- |
| CRAN | `install.packages("nama")` |
| CRAN archive | `remotes::install_version("nama", "1.2.3")` |
| GitHub | `remotes::install_github("user/repo")` |
| Bioconductor | `BiocManager::install("nama")` |

<div class="note">💡 Paket dari GitHub belum tentu stabil. Untuk pekerjaan produksi, catat commit hash atau versi rilis tertentu.</div>

## Namespace dan Konflik Nama

```r
stats::filter
dplyr::filter
```

Dua fungsi bernama `filter` bisa berasal dari paket berbeda. Jika dua paket dimuat dan nama bentrok, R memberi peringatan saat startup. Operator `::` menghilangkan keraguan.

## Informasi Paket

```r
packageVersion("dplyr")
installed.packages()[1:3, c("Package", "Version")]
sessionInfo()
help(package = "dplyr")
vignette("dplyr")
```

`sessionInfo()` mencatat versi R, paket, dan sistem operasi — lampirkan ini saat melaporkan bug.

## Proyek Terisolasi dengan renv

```r
renv::init()        # mulai proyek, salin paket ke cache proyek
renv::install("dplyr")
renv::snapshot()    # tulis versi ke renv.lock
renv::restore()     # pasang versi sesuai lock di mesin lain
```

`renv.lock` berisi versi dan sumber setiap paket. Simpan file ini di version control bersama kode, bukan `renv/library/`.

## Memperbarui dengan Aman

```r
old.packages()                # paket yang punya versi baru
update.packages(ask = FALSE)
renv::update()                # di proyek ber-renv
```

Perbarui di lingkungan uji dulu. Perubahan versi bisa mengubah default fungsi dan hasil analisis tanpa peringatan.

## Di Dunia Nyata

- **Tim analitik**: `renv.lock` memastikan semua orang memakai versi yang sama.
- **Deploy model**: Docker image memuat paket sesuai lock file.
- **Audit**: `sessionInfo()` dalam laporan membuktikan versi apa yang dipakai.
- **Eksperimen**: satu proyek memakai paket versi lama, proyek lain versi baru tanpa konflik.
