**List** adalah kontainer paling fleksibel di R: tiap elemennya boleh berupa vektor, matriks, data frame, atau list lain. Data frame sebenarnya adalah list khusus dengan kolom berpanjang sama.

## Membuat List

```r
profil <- list(
  nama = "Andi",
  umur = 25,
  nilai = c(80, 85, 90),
  alamat = list(kota = "Bandung", kode = 40211)
)
```

Elemen bisa bernama atau tidak. Nama memudahkan akses dan membuat struktur terdokumentasi sendiri.

## Tiga Cara Mengambil Elemen

| Cara | Hasil |
| --- | --- |
| `profil[1]` | list berisi satu elemen |
| `profil[[1]]` | nilai asli elemen pertama |
| `profil$nama` | nilai komponen bernama `nama` |
| `profil[["umur"]]` | bentuk aman untuk nama dinamis |

```r
profil[[3]]        # vektor c(80, 85, 90)
profil$alamat$kota # "Bandung"
key <- "umur"; profil[[key]]  # 25
```

<div class="note">💡 `[ ]` selalu mengembalikan list, sehingga `profil[1] + 1` akan error. Gunakan `[[ ]]` bila kamu ingin nilai di dalamnya.</div>

## Menambah dan Menghapus

```r
profil$email <- "andi@example.com"
profil[["umur"]] <- 26
profil$nama <- NULL      # menghapus elemen bernama nama
```

Menetapkan elemen ke `NULL` menghapusnya; menetapkannya ke `list(NULL)` menyisipkan elemen kosong.

## Iterasi dengan apply-family

```r
lapply(profil, class)       # list berisi tipe tiap elemen
sapply(profil, length)      # vektor panjang tiap elemen
vapply(profil, length, integer(1))  # lebih aman: tipe hasil dipaksa
```

`vapply()` lebih ketat daripada `sapply()` karena hasilnya harus sesuai template yang diberikan — sangat berguna dalam fungsi yang dipakai ulang.

## Merapikan List

```r
unlist(profil$nilai)     # vektor dari elemen list
str(profil)              # ringkasan struktur bertingkat
names(profil)            # daftar nama komponen
```

`str()` adalah sahabat saat menerima JSON dari API: ia memperlihatkan seluruh kedalaman struktur dalam satu tampilan ringkas.

## Di Dunia Nyata

- **Respons API**: JSON yang dibaca `jsonlite::fromJSON()` menjadi list bersarang.
- **Hasil pemodelan**: objek `lm` adalah list berisi koefisien, residual, dan diagnostik.
- **Konfigurasi**: satu list menampung parameter, path, dan credential (tentu terpisah dari kode).
- **Multiple output**: fungsi yang mengembalikan beberapa tabel sekaligus.
