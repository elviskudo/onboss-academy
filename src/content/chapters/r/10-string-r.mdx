Teks di R disimpan sebagai vektor `character`. Satunama pun sebenarnya vektor panjang satu, sehingga hampir semua operasi string bekerja secara vektorised.

## Membuat dan Menggabungkan

```r
nama <- "Rizky"
sapaan <- paste("Halo", nama)          # "Halo Rizky"
lengkap <- paste("Depan", "Belakang", sep="-")
vectorized <- paste0("item", 1:3)      # "item1" "item2" "item3"
```

`paste()` menyisipkan spasi secara default; `paste0()` langsung menggabungkan tanpa pemisah.

## Fungsi Penting

| Fungsi | Fungsi singkat |
| --- | --- |
| `nchar(x)` | jumlah karakter tiap elemen |
| `substr(x, awal, akhir)` | mengambil bagian tertentu |
| `strsplit(x, pola)` | memecah menjadi potongan |
| `toupper` / `tolower` | mengubah huruf |
| `trimws(x)` | membuang spasi tepi |
| `sub` / `gsub` | mengganti pola |
| `grepl(pola, x)` | cek keberadaan pola |

```r
trimws("  R  ")            # "R"
substr("2026-11-20", 1, 4) # "2026"
grepl("R", "Belajar R")    # TRUE
```

## Regular Expression Sederhana

```r
teks <- c("a101", "b52", "c7")
grepl("[0-9]{3}", teks)          # hanya a101
gsub("[0-9]+", "N", teks)        # "aN" "bN" "cN"
```

Karakter `[0-9]` berarti digit, `+` berarti satu atau lebih, `{3}` berarti tepat tiga. Pola ini dipakai `grep`, `grepl`, `sub`, `gsub`, dan `gregexpr`.

## Encoding

Teks Indonesia modern umumnya UTF-8. Bila membaca file dengan tanda baca atau emoji yang rusak, tentukan encoding saat import: `read.csv("data.csv", fileEncoding = "UTF-8")`. Fungsi `Encoding(x)` melaporkan penanda encoding yang melekat pada vektor.

<div class="note">💡 `nchar()` menghitung karakter, bukan byte. Untuk emoji atau aksara ber-byte ganda, `length(charToRaw(s))` bisa lebih besar dari `nchar(s)`.</div>

## Di Dunia Nyata

- **Membersihkan nama**: `trimws()` dan `gsub("\s+", " ", nama)` merapikan spasi ganda.
- **Ekstraksi tahun**: `substr(tanggal, 1, 4)` dari format ISO.
- **Pencarian data**: `df[grepl("jakarta", tolower(df$kota)), ]`.
- **Menyeragamkan kode**: `toupper(kode)` sebelum menggabungkan dua sumber data.
