R Markdown menggabungkan narasi dan kode dalam satu dokumen. Saat dirender, kode dijalankan ulang dan hasilnya disisipkan — laporan selalu selaras dengan data terbaru.

## Struktur Dokumen

````text
---
title: "Laporan Penjualan"
author: "Tim Analitik"
output: html_document
---

```{r setup, include=FALSE}
knitr::opts_chunk$set(echo = TRUE, warning = FALSE)
```

## Ringkasan

```{r}
summary(penjualan)
```
````

Bagian antara tiga tanda `---` pertama adalah YAML metadata. Sisanya markdown biasa dengan chunk kode.

## Opsi Chunk

| Opsi | Efek |
| --- | --- |
| `echo=FALSE` | kode tidak ditampilkan |
| `include=FALSE` | chunk dijalankan tapi seluruhnya disembunyikan |
| `eval=FALSE` | kode ditampilkan tanpa dijalankan |
| `fig.width`, `fig.height` | ukuran gambar |
| `cache=TRUE` | menyimpan hasil agar render berikut cepat |

## Reproducibility

```r
set.seed(123)
sumber <- "data/mentah.csv"
```

Tiga kebiasaan yang menentukan laporan benar-benar bisa diulang:

1. Simpan data mentah dan tentukan path relatif terhadap dokumen.
2. Lock versi paket — `sessionInfo()` atau `renv::snapshot()`.
3. Hindari angka yang ditulis manual; hitung dari data di chunk.

## Parameter dan Format

```yaml
params:
  bulan: "2026-11"
  wilayah: "Semua"
```

Nilai parameter dipakai dengan `params$bulan`, lalu render dengan:

```r
rmarkdown::render("laporan.Rmd",
                  params = list(bulan = "2026-12"),
                  output_file = "laporan-desember.html")
```

## Output yang Didukung

| Output | Kebutuhan |
| --- | --- |
| `html_document` | bawaan, paling mudah |
| `pdf_document` | LaTeX terpasang |
| `word_document` | pandoc |
| `github_document` | markdown untuk README |

<div class="note">💡 `knitr::kable(df)` mengubah data frame menjadi tabel markdown/HTML yang rapi, jauh lebih baik daripada `print(df)` di dalam laporan.</div>

## Di Dunia Nyata

- **Laporan bulanan**: satu Rmd dirender ulang tiap awal bulan dengan parameter berbeda.
- **Notebook riset**: narasi menjelaskan mengapa suatu uji dipilih.
- **Dokumentasi model**: cara memuat model dan contoh prediksi hidup berdampingan.
- **Pengajaran**: mahasiswa melihat kode dan hasilnya dalam satu halaman.
