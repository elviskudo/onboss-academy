Regresi linear berganda memperkirakan hubungan antara satu variabel respons dan beberapa prediktor. Tujuannya bisa prediksi, bisa juga memahami besaran pengaruh setelah faktor lain dikendalikan.

## Membangun Model

```r
model <- lm(harga ~ luas + kamar + lokasi, data = provinsi)
summary(model)
```

Formula `y ~ x1 + x2` dibaca "y dimodelkan dari x1 dan x2". Intersep ditambahkan otomatis; untuk memaksa melalui nol tulis `y ~ 0 + x1`.

## Membaca Ringkasan

| Bagian | Arti praktis |
| --- | --- |
| Estimate | perubahan y per satu unit x, dengan variabel lain tetap |
| Std. Error | ketidakpastian estimasi koefisien |
| t value | estimate dibagi SE |
| Pr(>t) | p-value uji koefisien ≠ 0 |
| Multiple R-squared | proporsi variansi yang dijelaskan |
| Residual SE | kesalahan prediksi tipikal dalam unit y |

Koefisien `luas = 1,8` berarti setiap tambah satu meter persegi menaikkan harga sekitar 1,8 juta **dengan kamar dan lokasi sama**.

## Variabel Kategori

```r
model <- lm(harga ~ luas + lokasi, data = df)
model.matrix(~ luas + lokasi, data = df)
```

Faktor otomatis Diubah menjadi dummy. Level pertama menjadi baseline; `contrasts(df$lokasi)` menampilkan pengkodeannya.

## Interaksi

```r
model <- lm(omzet ~ iklan * kanal, data = df)
```

Tanda `*` berarti `iklan + kanal + iklan:kanal`. Interaksi menjawab: apakah efek iklan berbeda antara kanal online dan offline?

## Diagnostik

```r
par(mfrow = c(2, 2))
plot(model, which = 1:4)
```

Empat grafik standar: residual vs fitted (linearitas), QQ plot (normalitas), scale-location (homoskedastisitas), dan residual vs leverage (pengaruh).

```r
car::vif(model)     # multikolinearitas; > 5 perlu perhatian
```

## Prediksi

```r
data_baru <- data.frame(luas = 80, kamar = 3, lokasi = "Pusat")
predict(model, newdata = data_baru, interval = "prediction", level = 0.95)
```

`interval = "confidence"` memberi rentang untuk **rata-rata** respons; `"prediction"` memberi rentang untuk **satu observasi baru** — lebih lebar karena termasuk error individu.

<div class="note">💡 Korelasi tinggi antar prediktor tidak merusak prediksi, tetapi membuat koefisien individu tidak stabil. Jika tujuanmu interpretasi, periksa VIF dan pertimbangkan menggabungkan variabel.</div>

## Di Dunia Nyata

- **Harga properti**: luas, jumlah kamar, dan lokasi sebagai prediktor.
- **Penjualan**: belanja iklan dan promosi untuk mengukur efek masing-masing.
- **Kesehatan**: usia, BMI, dan merokok untuk memodelkan tekanan darah.
- **Operasional**: jumlah pesanan dan jam kerja untuk memprediksi biaya.
