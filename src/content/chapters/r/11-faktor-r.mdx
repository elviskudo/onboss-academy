**Faktor** merepresentasikan data kategori. Faktor menyimpan kode bilangan bulat di belakang layar dan daftar *level* yang memberi makna pada kode tersebut. Ini menghemat memori dan memberi tahu fungsi statistik bahwa sebuah kolom bukan angka.

## Membuat Faktor

```r
status <- factor(c("Aktif", "Nonaktif", "Aktif"))
levels(status)          # "Aktif" "Nonaktif"
as.integer(status)      # 1 2 1 (kode internal)
```

Secara default level diurutkan alfabetis. Untuk urutan khusus:

```r
mutu <- factor(c("B", "A", "C"), levels = c("A", "B", "C"))
```

## Faktor Berurutan

```r
kepuasan <- factor(c("Setuju", "Netral", "Setuju"),
                   levels = c("Tidak setuju", "Netral", "Setuju"),
                   ordered = TRUE)
kepuasan[1] > kepuasan[2]   # TRUE
```

`ordered = TRUE` memungkinkan perbandingan `<` dan `>` serta dipakai beberapa prosedur statistik seperti regresi ordinal.

## Mengubah dan Menambah Level

```r
f <- factor(c("Merah", "Biru"))
levels(f) <- c("Merah", "Biru", "Hijau")   # level baru ditambahkan
f <- droplevels(f)                          # buang level tak terpakai
```

Saat menggabungkan dua data frame yang levelnya berbeda, `levels<-` atau `fct_expand()` dari **forcats** mencegah kategori hilang.

## Jebakan Konversi

```r
nilai <- factor(c("10", "20", "30"))
as.numeric(nilai)                 # 1 2 3 — bukan 10 20 30
as.numeric(as.character(nilai))   # 10 20 30 — cara benar
```

<div class="note">💡 Jika kolom dibaca sebagai faktor padahal isinya angka, perbaiki sejak import: `read.csv(..., stringsAsFactors = FALSE)`. Sejak R 4.0-default memang sudah `FALSE`, tetapi data lama atau paket tertentu masih bisa menghasilkan faktor.</div>

## Di Dunia Nyata

- **Survei**: skala Likert disimpan sebagai faktor berurutan agar analisis menghormati urutan.
- **Visualisasi**: `ggplot()` mengelompokkan warna menurut level faktor.
- **Tabel silang**: `table(jenis, wilayah)` memakai level sebagai baris/kolom.
- **Model**: `lm()` otomatis membuat *dummy variable* dari faktor.
