Fungsi R adalah objek. Ia bisa disimpan dalam variabel, dimasukkan ke list, dan dikirim ke fungsi lain. Lingkungan tempat fungsi dibuat ikut bersamanya.

## Dasar dan Default

```r
luas <- function(panjang, lebar = 2) panjang * lebar
luas(5)        # 10
luas(5, 3)     # 15
luas(lebar = 3, panjang = 5)
```

## Argumen ...

```r
rata_aman <- function(..., na.rm = TRUE) {
  nilai <- c(...)
  mean(nilai, na.rm = na.rm)
}
rata_aman(1, 2, NA, 4)
```

`...` sering diteruskan ke fungsi lain: `plot(x, ...)` memungkinkan pengguna menambahkan `col`, `main`, dan sebagainya tanpa fungsi kita mendefinisikan semuanya.

## Evaluasi Malas

```r
f <- function(x) {
  cat("Fungsi dipanggil\n")
  42
}
g <- function(arg) 10      # arg tidak pernah dipakai
g(f())                     # tidak mencetak apa pun
```

Karena `arg` tidak dibaca, `f()` tidak pernah berjalan. Sifat ini menghemat komputasi, tetapi bisa mengejutkan bila efek samping diharapkan.

## Closure

```r
pembuat <- function(offset) {
  function(x) x + offset
}
tambah5 <- pembuat(5)
tambah5(10)     # 15
environment(tambah5)
```

`tambah5` menyimpan `offset` dari lingkungan induk meskipun `pembuat()` sudah selesai. Ini dasar pembuatan fungsi yang dikonfigurasi sekali lalu dipakai berulang.

## Fungsi Orde Tinggi

```r
Filter(function(x) x %% 2 == 0, 1:10)
Map(function(a, b) a + b, 1:3, 10:12)
Reduce(function(acc, x) acc * x, 1:5)
```

`Filter` menyaring, `Map` menerapkan fungsi ke beberapa vektor sejajar, `Reduce` menggabungkan elemen secara berurutan.

## Validasi Argumen

```r
skor <- function(x) {
  stopifnot(is.numeric(x), all(x >= 0), all(x <= 100))
  mean(x)
}
```

`stopifnot()` singkat dan jelas untuk invariant. Untuk pesan error yang ramah pengguna, gunakan `stop("nilai harus 0–100")`. Gunakan `warning()` bila masalah tidak membatalkan hasil.

<div class="note">💡 Fungsi yang baik memiliki satu tanggung jawab. Bila fungsi mulai memuat logika filter, agregasi, dan plotting sekaligus, pecah menjadi beberapa fungsi agar bisa diuji terpisah.</div>

## Di Dunia Nyata

- **Pipelines**: setiap langkah adalah fungsi kecil yang bisa dipanggil ulang.
- **Shiny**: `server <- function(input, output, session)` memakai closure untuk menyimpan state.
- **Statistik khusus**: closure membuat generator distribusi dengan parameter tetap.
- **API client**: fungsi pembuat menangkap base URL dan token, lalu mengembalikan fungsi `get()`/`post()`.
