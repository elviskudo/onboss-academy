R interpreted, tetapi fungsi intinya ditulis dalam C/Fortran. Kunci kinerja adalah memakai fungsi vectorised dan memberi ukuran memori di awal.

## Vectorization

```r
x <- 1:1e6
system.time(y <- x^2)              # cepat
system.time(z <- sapply(x, function(v) v^2))  # jauh lebih lambat
```

Operasi `x^2`, `x + 1`, `log(x)`, dan `ifelse()` berjalan satu kali di lapisan C. `sapply` memanggil fungsi R satu juta kali.

## Jangan Menambah Vektor di Loop

```r
# lambat: vektor tumbuh terus
v <- c()
for (i in 1:10000) v <- c(v, i)

# cepat: ukuran disiapkan sekali
v <- numeric(10000)
for (i in seq_along(v)) v[i] <- i
```

Setiap `c(v, i)` menyalin seluruh vektor. Untuk 10.000 elemen, biayanya kuadratik.

## Fungsi yang Sering Lebih Cepat

| Hindari | Gunakan |
| --- | --- |
| `sapply(x, f)` bila f vectorised | `f(x)` |
| loop untuk jumlah | `sum()`, `mean()` |
| loop untuk filter | `x[x > 0]` |
| loop membangun string | `paste0(..., collapse = "")` |
| `merge` di dalam loop | `rbindlist` / join sekali |

```r
do.call(rbind, daftar_df)          # base R
data.table::rbindlist(daftar_df)   # biasanya lebih cepat
```

## Mengukur, Bukan Menebak

```r
system.time({
  hasil <- sqrt(1:1e7)
})

library(profvis)
profvis({ jalankan_analisis() })
```

Ukur dulu sebelum mengoptimalkan. Sering kali 80% waktu dihabiskan pada satu baris yang tidak kamu duga.

## Paralel Sederhana

```r
library(foreach)
library(doParallel)
cl <- makeCluster(4)
registerDoParallel(cl)
hasil <- foreach(i = 1:100, .combine = c) %dopar% mahal(i)
stopCluster(cl)
```

Paralel bukan gratis: ada biaya mengirim data ke worker. Cocok untuk tugas berat per iterasi, bukan untuk operasi kecil jutaan kali.

<div class="note">💡 Kode yang mudah dibaca hampir selalu lebih berharga daripada kode yang 10% lebih cepat. Optimalkan hanya bagian yang terbukti menjadi bottleneck.</div>

## Di Dunia Nyata

- **Jutaan transaksi**: filter vectorised menggantikan loop harian.
- **Simulasi Monte Carlo**: `replicate()` atau foreach untuk ribuan iterasi.
- **ETL harian**: prealokasi dan `data.table` mempercepat penggabungan tabel.
- **API internal**: cache hasil perhitungan mahal agar tidak diulang.
