Data **tidy** memiliki tiga sifat: setiap variabel satu kolom, setiap observasi satu baris, dan setiap sel satu nilai. `tidyr` membantu mengubah data mentah ke bentuk itu.

## Lebar ke Panjang

```r
library(tidyr)
lebar <- data.frame(kota = c("Bandung", "Surabaya"),
                    jan = c(100, 120),
                    feb = c(110, 130))

panjang <- lebar %>%
  pivot_longer(cols = c(jan, feb),
               names_to = "bulan",
               values_to = "omzet")
```

Sekarang `bulan` dan `omzet` masing-masing satu kolom — bentuk yang disukai `ggplot()` dan `group_by()`.

## Panjang ke Lebar

```r
panjang %>%
  pivot_wider(names_from = bulan, values_from = omzet)
```

Bila sebuah kombinasi muncul lebih dari sekali, tentukan agregasi: `values_fn = sum`. Tanpa itu `pivot_wider` akan mengingatkan adanya duplikat.

## Memisah dan Menggabungkan Kolom

```r
data.frame(nama = c("Ana-Sari", "Budi-Santu")) %>%
  separate(nama, into = c("depan", "belakang"), sep = "-")

data.frame(depan = c("Ana"), belakang = c("Sari")) %>%
  unite(nama, depan, belakang, sep = " ")
```

`separate_wider_delim()` adalah versi baru yang lebih eksplisit untuk kasus kompleks.

## Menangani Nilai Hilang

| Fungsi | Efek |
| --- | --- |
| `drop_na()` | buang baris yang memuat NA |
| `replace_na(x, 0)` | isi NA dengan nilai tetap |
| `fill(col, .direction = "down")` | isi NA dari nilai sebelumnya |
| `complete()` | tambahkan kombinasi yang hilang sebagai baris baru |

```r
df %>% fill(kelas, .direction = "down") %>% replace_na(list(nilai = 0))
```

`fill()` berguna pada tabel yang baris pertamanya berisi label grup dan baris berikutnya kosong, misalnya hasil ekspor dari spreadsheet.

## Bersarang dan Meratakan

```r
df %>% nest(data = -kota)        # satu baris per kota, kolom data berisi data frame
df_nested %>% unnest(data)       # kembali ke bentuk panjang
```

Nest berguna saat ingin melatih satu model per kota: `mutate(model = map(data, ~lm(y ~ x, .x)))`.

## Di Dunia Nyata

- **Data survei**: kolom `q1, q2, q3` diubah menjadi `pertanyaan` + `jawaban` sebelum dibuat grafik.
- **Penjualan bulanan**: format lebar per bulan dirapikan sebelum agregasi tahunan.
- **Alamat**: `separate()` memecah "kota, provinsi" menjadi dua kolom.
- **Time series**: `complete()` menambahkan tanggal yang tidak muncul agar grafik tidak melompat.
