SELECT adalah perintah SQL yang paling sering dipakai.Ia menjawab pertanyaan sederhana sampai analitik kompleks dengan satu bahasa deklaratif.

## Bentuk Paling Sederhana

```sql
SELECT nama, jabatan FROM karyawan;
SELECT * FROM karyawan;
```

`SELECT *` nyaman untuk eksplorasi, tetapi di aplikasi production sebaiknya sebutkan kolom yang benar-benar dipakai: lebih ringan dan tidak rusak saat tabel mendapat kolom baru.

## Alias

```sql
SELECT nama AS nama_karyawan,
       gaji * 12 AS gaji_tahunan
FROM karyawan;
```

Alias membuat hasil lebih mudah dibaca dan memberi nama kolom pada tabel turunan. `AS` boleh dihilangkan di banyak database, tapi menuliskannya lebih jelas.

## DISTINCT

```sql
SELECT DISTINCT dept FROM karyawan;
SELECT DISTINCT dept, jabatan FROM karyawan;
```

`DISTINCT` bekerja pada **seluruh kombinasi kolom** yang disebutkan, bukan hanya kolom pertama. Dua karyawan dengan dept sama tapi jabatan beda tetap menghasilkan dua baris.

## Urutan Logis Eksekusi

Meskipun ditulis lebih dulu, `SELECT` secara logis berjalan setelah `FROM` dan `WHERE`:

```text
FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT
```

Itulah sebabnya alias yang dibuat di `SELECT` belum bisa dipakai di `WHERE`, tetapi boleh dipakai di `ORDER BY`.

## MemBatasi Hasil

```sql
SELECT nama, gaji
FROM karyawan
ORDER BY gaji DESC
LIMIT 3;
```

Selalu pasangkan `LIMIT` dengan `ORDER BY` bila ingin hasil yang deterministik. Tanpa urutan, database bebas mengembalikan baris mana pun.

<div class="note">💡 Gunakan `SELECT COUNT(*)` untuk memastikan berapa baris yang akan terpengaruh sebelum menjalankan UPDATE atau DELETE.</div>

## Di Dunia Nyata

- **Endpoint API**: `SELECT id, nama, email` lebih aman daripada `*` karena field sensitif tidak ikut terkirim.
- **Dropdown UI**: `SELECT DISTINCT kota` mengisi pilihan filter.
- **Leaderboard**: `ORDER BY skor DESC LIMIT 10` menampilkan 10 teratas.
- **Export**: alias memberi nama header yang rapi di file CSV.
