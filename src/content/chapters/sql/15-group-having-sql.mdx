GROUP BY mengubah baris detail menjadi ringkasan per kategori. HAVING adalah filter untuk ringkasan itu — bukan untuk baris mentah.

## Agregat yang Sering Dipakai

| Fungsi | Arti | Perlakuan NULL |
| --- | --- | --- |
| `COUNT(*)` | jumlah baris | tetap dihitung |
| `COUNT(kolom)` | jumlah nilai non-NULL | diabaikan |
| `SUM` | total | NULL bila semua NULL |
| `AVG` | rata-rata | NULL diabaikan |
| `MIN` / `MAX` | nilai ekstrem | NULL diabaikan |

```sql
SELECT COUNT(*) AS total,
       COUNT(dept) AS punya_dept,
       AVG(gaji) AS rata_gaji
FROM karyawan;
```

## GROUP BY

```sql
SELECT dept, COUNT(*) AS jumlah, AVG(gaji) AS rata
FROM karyawan
GROUP BY dept;
```

Hasilnya satu baris per departemen. Kolom `dept` harus muncul di `GROUP BY`; kolom lain hanya boleh muncul lewat fungsi agregat.

## WHERE vs HAVING

```sql
SELECT dept, COUNT(*) AS jumlah, AVG(gaji) AS rata
FROM karyawan
WHERE gaji >= 8000000        -- filter baris dulu
GROUP BY dept
HAVING COUNT(*) >= 2         -- lalu filter grup
ORDER BY rata DESC;
```

`WHERE gaji >= ...` membuang baris sebelum dihitung, sehingga rata-rata berubah. `HAVING COUNT(*) >= 2` hanya membuang grup yang terlalu kecil setelah dihitung.

## GROUP BY Beberapa Kolom

```sql
SELECT dept, jabatan, COUNT(*) AS jumlah
FROM karyawan
GROUP BY dept, jabatan
ORDER BY dept, jumlah DESC;
```

Setiap kombinasi unik `dept + jabatan` menjadi satu grup. Ini dasar tabel pivot dan laporan silang.

## DISTINCT vs GROUP BY

`SELECT DISTINCT dept` dan `SELECT dept FROM ... GROUP BY dept` menghasilkan daftar yang sama. Pilih DISTINCT untuk deduplikasi sederhana; GROUP BY bila ada agregat.

<div class="note">💡 `HAVING AVG(gaji) > 10000000` boleh ditulis di banyak database tanpa mengulang `AVG` di SELECT. Namun untuk keterbacaan, sertakan agregat itu di SELECT sehingga pembaca melihat angka yang menjadi dasar filter.</div>

## Di Dunia Nyata

- **Dashboard SDM**: jumlah karyawan dan rata-rata gaji per departemen.
- **E-commerce**: total penjualan per kategori dengan minimal 10 transaksi.
- **Log aplikasi**: hitung error per endpoint lalu ambil yang > 100.
- **Absensi**: jumlah hadir per mahasiswa, lalu filter yang kurang dari 80%.
