Bagian penutup ini merangkum pola yang paling sering dipakai dan memberi arah belajar berikutnya. Simpan halaman ini sebagai daftar cepat saat menulis query.

## Daftar Perintah Inti

| Kategori | Perintah |
| --- | --- |
| DDL | CREATE, ALTER, DROP |
| DML | SELECT, INSERT, UPDATE, DELETE |
| Filter | WHERE, AND, OR, IN, BETWEEN, LIKE, IS NULL |
| Agregat | COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING |
| Gabung | INNER/LEFT/RIGHT/FULL JOIN, UNION |
| Perantara | CTE (WITH), subquery, view |
| Transaksi | BEGIN, COMMIT, ROLLBACK, SAVEPOINT |
| Performa | EXPLAIN, CREATE INDEX |
| Keamanan | GRANT, REVOKE, prepared statement

## Template Query Umum

```sql
WITH langkah1 AS (
  SELECT kolom, COUNT(*) AS jumlah
  FROM tabel
  WHERE kondisi
  GROUP BY kolom
)
SELECT kolom, jumlah,
       CASE WHEN jumlah >= 10 THEN 'Tinggi' ELSE 'Rendah' END AS kategori
FROM langkah1
WHERE jumlah > 0
ORDER BY jumlah DESC
LIMIT 20;
```

## Urutan Eksekusi Logis

```text
FROM → JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT
```

Urutan ini menjelaskan mengapa alias dari SELECT belum tersedia di WHERE, dan mengapa HAVING datang setelah agregasi.

## Rencana Latihan

1. Kuasai SELECT, WHERE, ORDER BY, dan LIMIT.
2. Latih agregasi dengan GROUP BY dan HAVING.
3. Pahami perbedaan INNER dan LEFT JOIN sampai bisa menjelaskan anti join.
4. Biasakan CTE untuk query bertahap.
5. Pelajari index dengan EXPLAIN.
6. Terapkan transaksi dan prepared statement di proyek nyata.

## Kapan Pindah ke Dialek Khusus

Setelah fondasi kuat, pilih salah satu:

- **PostgreSQL**: fitur JSONB, window function lengkap, ekstensi.
- **MySQL**: ekosistem web luas, replication.
- **SQL Server**: integration dengan stack Microsoft.
- **SQLite**: embedded, mobile, pengujian ringan.
- **BigQuery/Snowflake**: analitik berskala besar.

<div class="note">💡 Query yang benar hari ini bisa menjadi lambat besok saat data tumbuh 10 kali lipat. Biasakan mengukur dengan volume data yang realistis sejak awal.</div>

## Di Dunia Nyata

- **Analis data**: 80% pekerjaan harian adalah SELECT + agregasi + join.
- **Backend engineer**: query parametris, transaksi, dan index.
- **Data engineer**: pipeline, materialized view, dan optimasi biaya.
- **Product manager**: memahami definisi metrik di balik dashboard.
