Transaksi mengelompokkan beberapa perubahan menjadi satu unit logis. Transfer uang adalah contoh klasik: debet dan kredit harus berhasil berdua atau gagal berdua.

## ACID Singkat

| Huruf | Nama | Makna praktis |
| --- | --- | --- |
| A | Atomicity | semua perintah berhasil atau tidak sama sekali |
| C | Consistency | data tetap mematuhi aturan/constraint |
| I | Isolation | transaksi paralel tidak saling mengganggu |
| D | Durability | setelah COMMIT, data bertahan walau server mati

## Perintah Transaksi

```sql
BEGIN;
UPDATE rekening SET saldo = saldo - 100000 WHERE id = 1;
UPDATE rekening SET saldo = saldo + 100000 WHERE id = 2;
COMMIT;
```

Jika salah satu UPDATE gagal, jalankan `ROLLBACK;` agar saldo tidak setengah berubah.

## SAVEPOINT

```sql
BEGIN;
INSERT INTO log VALUES ('awal');
SAVEPOINT sebelum_opsi;
INSERT INTO log VALUES ('opsi');
ROLLBACK TO sebelum_opsi;   -- batalkan 'opsi' saja
COMMIT;                      -- 'awal' tetap tersimpan
```

SAVEPOINT berguna saat satu transaksi besar memiliki bagian yang boleh gagal tanpa membatalkan semuanya.

## Autocommit

Kebanyakan database menjalankan autocommit: setiap statement langsung menjadi transaksi tersendiri. Begitu `BEGIN` atau `START TRANSACTION` dipakai, autocommit ditunda sampai `COMMIT`/`ROLLBACK`.

```sql
-- MySQL
START TRANSACTION;
...
COMMIT;
```

## Timeout dan Lock

Transaksi yang dibiarkan terbuka terlalu lama bisa mengunci baris dan menghalangi transaksi lain. Selalu tutup dengan COMMIT atau ROLLBACK secepat mungkin, terutama di kode aplikasi yang menangani error.

```text
BEGIN → kerja → (sukses ? COMMIT : ROLLBACK)
```

<div class="note">💡 Jangan menyimpan hasil SELECT atau meminta input pengguna di tengah transaksi. Semakin lama transaksi terbuka, semakin besar risiko lock dan conflict.</div>

## Di Dunia Nyata

- **Transfer saldo**: dua UPDATE dalam satu transaksi.
- **Pemesanan tiket**: kurangi stok + buat pesanan + catat pembayaran.
- **Import data**: ROLLBACK bila baris ke-500 gagal validasi.
- **Migration**: ubah struktur dan data lama dalam satu unit.
