CTE adalah tabel sementara bernama yang hidup hanya selama satu query. Ia membuat logika query berlapis menjadi seperti resep: langkah satu, langkah dua, lalu hasil akhir.

## Sintaks Dasar

```sql
WITH rata_dept AS (
  SELECT dept, AVG(gaji) AS rata
  FROM karyawan
  GROUP BY dept
)
SELECT k.nama, k.gaji, rata_dept.rata
FROM karyawan k
JOIN rata_dept ON k.dept = rata_dept.dept
WHERE k.gaji > rata_dept.rata;
```

Bandingkan dengan subquery di FROM: isi query sama, tetapi CTE ditempatkan di atas sehingga urutan membaca mengikuti urutan berpikir.

## Beberapa CTE

```sql
WITH total AS (
  SELECT SUM(gaji) AS semua FROM karyawan
),
tinggi AS (
  SELECT SUM(gaji) AS bagian FROM karyawan WHERE gaji >= 10000000
)
SELECT ROUND(tinggi.bagian * 100.0 / total.semua, 1) AS persen
FROM total, tinggi;
```

CTE kedua boleh merujuk CTE pertama, tetapi tidak boleh merujuk CTE yang didefinisikan setelahnya.

## CTE Rekursif

```sql
WITH RECURSIVE angka(n) AS (
  SELECT 1
  UNION ALL
  SELECT n + 1 FROM angka WHERE n < 5
)
SELECT n FROM angka;
```

Bagian pertama disebut *anchor*, bagian kedua *recursive member*. Kondisi `WHERE n &lt; 5` adalah rem agar rekursi berhenti.

## CTE vs Subquery vs Tabel Sementara

| Mekanisme | Umur | Cocok untuk |
| --- | --- | --- |
| Subquery | satu ekspresi | nilai tunggal / daftar kecil |
| CTE | satu statement | langkah perantara yang dibaca ulang |
| TEMP TABLE | satu sesi | hasil dipakai banyak statement |

CTE tidak selalu lebih cepat — di beberapa database ia dimaterialisasi, di lain di-inline. Untuk performa, ukur dengan EXPLAIN.

<div class="note">💡 Beri nama CTE sesuai arti bisnisnya, misalnya `rata_per_dept`, bukan `q1` atau `temp`. Query yang dibaca tim lain jadi jauh lebih mudah dipelihara.</div>

## Di Dunia Nyata

- **Laporan bertahap**: hitung total, lalu persentase, lalu format akhir.
- **Hierarki**: `WITH RECURSIVE` menelusuri atasan → bawahan.
- **Deret tanggal**: mengisi tanggal yang kosong sebelum digabung dengan transaksi.
- **Debugging**: jalankan satu CTE secara terpisah untuk memeriksa hasil perantara.
