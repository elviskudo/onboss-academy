Laporan bisnis yang baik menjawab satu pertanyaan dengan metrik yang jelas. Kita akan merangkai CTE, agregasi, CASE, dan COALESCE menjadi satu query yang mudah dipelihara.

## 1. Tentukan Pertanyaan

Contoh: *"Unit mana yang punya jumlah karyawan paling banyak, berapa rata-rata gajinya, dan bagaimana kategorinya?"*

Métriknya: jumlah karyawan, rata-rata gaji, kategori besaran tim, dan persentase terhadap total.

## 2. Susun Langkah dengan CTE

```sql
WITH per_dept AS (
  SELECT dept, COUNT(*) AS jumlah, AVG(gaji) AS rata
  FROM karyawan
  GROUP BY dept
),
total AS (
  SELECT COUNT(*) AS semua FROM karyawan
)
SELECT dept, jumlah, ROUND(rata) AS rata,
       CASE WHEN jumlah >= 3 THEN 'Besar' ELSE 'Kecil' END AS ukuran
FROM per_dept
ORDER BY jumlah DESC;
```

Setiap CTE bisa dijalankan sendiri saat debugging. Ini jauh lebih mudah daripada subquery bersarang lima tingkat.

## 3. Tambahkan Persentase

```sql
WITH per_dept AS (
  SELECT dept, COUNT(*) AS jumlah FROM karyawan GROUP BY dept
),
total AS (SELECT COUNT(*) AS semua FROM karyawan)
SELECT dept, jumlah,
       ROUND(jumlah * 100.0 / total.semua, 1) AS persen
FROM per_dept, total
ORDER BY persen DESC;
```

Perkalian dengan `100.0` memaksa pembagian desimal. Di banyak database, `jumlah / semua` dengan dua integer menghasilkan integer.

## 4. Tangani Data Kosong

```sql
SELECT dept,
       COALESCE(ROUND(AVG(gaji)), 0) AS rata
FROM karyawan
GROUP BY dept;
```

Bila grup tidak punya gaji valid, AVG menghasilkan NULL. COALESCE mencegah grafik menampilkan ruang kosong.

## 5. Validasi Hasil

- Cek total baris: apakah jumlah per group sama dengan total keseluruhan?
- Cek NULL: apakah ada kolom yang seharusnya tidak NULL?
- Cek kasus ekstrem: tabel kosong, satu grup, atau semua nilai sama.
- Bandingkan dengan perhitungan manual untuk sampel kecil.

<div class="note">💡 Pisahkan query menjadi CTE juga membantu reviewer memvalidasi logika bisnis tanpa harus memahami seluruh query sekaligus.</div>

## Di Dunia Nyata

- **Dashboard SDM**: ringkasan karyawan per departemen.
- **Laporan penjualan**: omzet per wilayah dengan kategori performa.
- **Absensi**: persentase kehadiran per kelas.
- **Operasional**: jumlah tiket per prioritas dan SLA.
