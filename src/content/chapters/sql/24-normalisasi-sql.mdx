Normalisasi adalah proses menyusun tabel agar data tidak berulang tanpa alasan. Ia mencegah tiga anomali: insert (tidak bisa menambah data tanpa data lain), update (satu fakta harus diubah di banyak tempat), dan delete (menghapus satu hal menghilangkan fakta lain).

## Dependensi Fungsional

Notasi `A → B` berarti nilai A menentukan nilai B secara unik. Misalnya `nim → nama` karena satu NIM hanya dimiliki satu mahasiswa.

```text
(nim, kode_mk) → nilai
nim → nama, alamat
kode_mk → nama_mk, sks
```

## 1NF — Nilai Atomik

```text
-- SALAH
siswa: | 1 | Ana | Matematika, Fisika |

-- BENAR
siswa:    | 1 | Ana |
pendaftaran: | 1 | Matematika |
             | 1 | Fisika   |
```

## 2NF — Bergantung pada Seluruh Kunci

Jika kunci primer komposit `(nim, kode_mk)`, kolom `nama` yang hanya bergantung pada `nim` harus dipindah ke tabel `mahasiswa`.

```sql
CREATE TABLE mahasiswa (nim TEXT PRIMARY KEY, nama TEXT);
CREATE TABLE nilai (nim TEXT, kode_mk TEXT, skor INTEGER,
                    PRIMARY KEY (nim, kode_mk));
```

## 3NF — Tidak Bergantung pada Non-Kunci

```text
-- SALAH: kota → provinsi, sementara kota bukan kunci
karyawan(id, nama, kota, provinsi)

-- BENAR
karyawan(id, nama, kota)
wilayah(kota PRIMARY KEY, provinsi)
```

## Denormalisasi

Normalisasi hingga 3NF adalah target umum aplikasi transaksional. Sistem analitik sering menyimpan salinan `nama_produk` di tabel fakta penjualan agar tidak perlu join setiap laporan — itu denormalisasi sadar, bukan kesalahan desain.

| Kebutuhan | Pilihan |
| --- | --- |
| Transaksi (insert/update sering) | Normalisasi |
| Laporan (baca jutaan baris) | Denormalisasi / star schema |

<div class="note">💡 Denormalisasi menciptakan dua sumber kebenaran. Jika dipakai, siapkan proses yang jelas untuk menyinkronkan salinan.</div>

## Di Dunia Nyata

- **E-commerce**: produk, kategori, dan varian dipisah agar harga tidak duplikat.
- **Akademik**: mahasiswa, mata kuliah, dan nilai adalah tiga tabel berbeda.
- **Analitik**: tabel fakta penjualan menyimpan salinan nama cabang untuk kecepatan.
- **Migration**: normalisasi sering dilakukan saat sistem lama mulai bermasalah.
