Game kuis memanfaatkan hampir semua fitur dasar Scratch: daftar, variabel, operator, pesan, dan percabangan.

## Struktur Data

```text
soal  = [Ibukota Indonesia?, 2+2=?, Warna langit?]
kunci = [Jakarta, 4, Biru]
```

## Alur Satu Putaran

```text
pilih index acak -> tampilkan soal -> tunggu jawaban
-> bandingkan dengan kunci -> ubah skor -> index berikutnya
```

## Masukan Jawaban

Gunakan blok `tanya [...] dan tunggu`; jawaban tersimpan di pelapor `(jawaban)`. Untuk pilihan ganda, minta pemain menekan tombol 1–4 dan simpan ke variabel `pilih`.

## Menghindari Pengulangan

```text
[tambahkan (i) ke [terpakai]]
[jika <([terpakai] berisi (i))> [pilih index lain]]
```

## Penutup

Tampilkan skor akhir, lalu kirim pesan `ulang` yang mereset skor, daftar terpakai, dan index ke keadaan awal.

<div class="note">💡 Simpan soal dan kunci sebagai daftar terpisah. Mengubah satu soal tidak akan menggeser kunci bila kedua daftar tetap sejajar.</div>
