Proyek yang rapi lebih mudah dikembangkan. Scratch menyediakan komentar, pengelompokan sprite, dan nama yang bisa disesuaikan.

## Menulis Komentar

Klik kanan sebuah blok → **Add Comment**. Tulis penjelasan singkat, lalu klik warna komentar untuk mengubahnya. Komentar bisa dilipat agar tidak mengganggu tampilan.

## Struktur Proyek yang Sehat

```text
Sprite: Pemain
  - gerak, skor, nyawa

Sprite: Musuh (duplikat x3)
  - jalur gerak, tabrakan

Panggung
  - backdrop, variabel global, pesan
```

## Prinsip Penamaan

| Objek | Nama buruk | Nama baik |
|---|---|---|
| Sprite | Sprite2 | musuh-kiri |
| Variabel | x | skor-putaran |
| Pesan | pesan1 | mulai-putaran |
| Kostum | kostum4 | lari-2 |

## Merapikan Script

- Letakkan blok `ketika bendera diklik` di bagian atas.
- Kelompokkan skrip terkait bersebelahan.
- Hapus blok eksperimen yang sudah tidak dipakai.
- Simpan versi cadangan sebelum perubahan besar.

<div class="note">💡 Gunakan menu File → Save as untuk menyalin proyek sebelum bereksperimen. Scratch menyimpan versi local di browser, jadi named copy sangat membantu.</div>
