Animasi pada Scratch pada dasarnya adalah rangkaian perubahan kecil. Tidak perlu pustaka khusus—cukup loop, jeda, dan perubahan posisi atau ukuran.

## Prinsip Animasi

```text
perubahan kecil + jeda pendek + pengulangan = ilusi gerak
```

## Contoh Gerak Halus

```text
[ulangi 30 [
  [geser x sebesar 8]
  [geser y sebesar 3]
  [tunggu 0,03 detik]
]]
```

## Interpolasi Posisi

```text
[atur [x] ke [0]]
[ulangi sampai <(x) = [200]> [
  [atur x ke (x)]
  [ubah [x] sebesar 10]
  [tunggu 0,02 detik]
]]
```

## Efek Napas

Gabungkan `ubah ukuran sebesar 5` dan `-5` dalam dua loop berurutan untuk efek membesar-mengecil.

<div class="note">💡 Scratch memperbarui layar sekitar 30 frame per detik. Jeda di bawah 0,03 detik umumnya tidak terlihat lebih halus.</div>
