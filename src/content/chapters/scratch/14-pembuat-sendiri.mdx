Blok buatan sendiri adalah cara Scratch mendukung fungsi. Kamu memberi nama, menambahkan parameter, lalu mengisi tubuh blok itu sekali saja.

## Membuat Blok

1. Buka kategori **Blok Saya** lalu klik **Buat blok**.
2. Beri nama, misalnya `Kedip`.
3. Tambahkan input bila perlu, misalnya `jumlah` dan `waktu`.
4. Tulis skrip di bawah header definisi.
5. Panggil blok dari tempat mana pun.

## Contoh: Kedip

```text
[definisi Kedip(jumlah, jeda)]
[ulangi (jumlah) [
   [ubah efek [kecerahan] sebesar 25]
   [tunggu (jeda) detik]
   [ubah efek [kecerahan] sebesar -25]
   [tunggu (jeda) detik]
]]
```

## Input Teks dan Angka

Klik tombol `+` saat menambah input untuk memberi nama. Saat blok dipanggil, isi nilainya. Di dalam definisi, nama input tampil sebagai pelapor oval.

## Kapan Memakai Run without Screen Refresh

Aktifkan untuk blok yang hanya menghitung atau mengatur variabel. Jangan aktifkan bila blok berisi animasi yang perlu terlihat—layar tidak akan diperbarui sampai blok selesai.

<div class="note">💡 Beri nama blok dengan kata kerja: `GambarKotak`, `HitungSkor`, `ResetPosisi`. Nama yang jelas menggantikan banyak komentar.</div>
