Proyek akhir menggabungkan seluruh keterampilan: perencanaan, desain, pemrograman, pengujian, dan komunikasi.

## Tahapan

```text
1. Tujuan dan aturan
2. Daftar fitur
3. Desain sprite dan panggung
4. Implementasi bertahap
5. Uji coba dan perbaikan
6. Dokumentasi dan presentasi
```

## Contoh Rencana

| Fitur | Blok utama |
|---|---|
| Gerak pemain | tombol dan geser x |
| Koin | klon dan hapus klon |
| Skor | variabel dan ubah |
| Waktu | waktu sejak bendera diklik |
| Akhir | pesan dan backdrop |

## Uji Coba

```text
[ ] Tombol ditekan cepat tidak merusak keadaan
[ ] Skor tidak negatif
[ ] Waktu habis menghentikan permainan
[ ] Semua klon terhapus saat ulang
[ ] Suara tidak bertumpuk
```

## Presentasi

Tunjukkan tujuan, demo singkat, lalu jelaskan satu keputusan desain yang menarik—misalnya mengapa kamu memilih klon daripada beberapa sprite identik.

<div class="note">💡 Proyek yang selesai dan bisa dimainkan lebih berharga daripada proyek ambisius yang ditinggalkan setengah jadi.</div>
