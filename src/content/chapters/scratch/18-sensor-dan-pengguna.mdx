Sensor membuat proyek merespons dunia luar: keyboard, mouse, sprite lain, warna, dan bahkan mikrofon atau kamera.

## Input Langsung

```text
[tombol [spasi] ditekan?]
[mouse down?]
(mouse x) (mouse y)
[ikuti [pointer mouse]]
```

## Tabrakan

```text
[menyentuh [musuh]?]
[menyentuh [tepi]?]
[menyentuh [warna merah]?]
(jarak ke [pemain])
```

## Contoh: Musuh Mengikuti Pemain

```text
[ulangi sampai <(jarak ke [pemain]) < 20> [
  [hadap [pemain]]
  [geser 2 langkah]
  [tunggu 0,05 detik]
]]
```

## Deteksi Warna

Klik ikon pipet pada blok warna lalu pilih warna dari panggung. Metode ini sensitif terhadap pencahayaan/efek grafis, jadi hindari mengubah warna sprite yang sedang dideteksi.

<div class="note">💡 Izinkan akses mikrofon/kamerahanya saat proyek benar-benar memakainya, dan beri tahu pengguna bahwa perangkat sedang aktif.</div>
