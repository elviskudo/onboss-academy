Waktu mengatur ritme proyek. Scratch menyediakan blok tunggu, pelapor waktu, dan perulangan berbasis kondisi.

## Blok Waktu

```text
[tunggu 1 detik]
(waktu sejak bendera diklik)
[ulangi sampai <waktu > 30> [ ... ]]
```

## Hitung Mundur

```text
[atur [sisa] ke [10]]
[ulangi sampai <(sisa) = [0]> [
  [tunggu 1 detik]
  [ubah [sisa] sebesar -1]
]]
```

## Timer sebagai Skor

Beberapa game memberi skor berdasarkan kecepatan:

```text
[atur [waktu-mulai] ke (waktu sejak bendera diklik)]
// setelah selesai
[atur [durasi] ke ((waktu sejak bendera diklik) - (waktu-mulai))]
```

## Jeda Kecil dalam Animasi

```text
[ulangi 20 [
  ganti kostum ke [berikutnya]
  tunggu 0,05 detik
]]
```

<div class="note">💡 Jangan mengandalkan `tunggu 1 detik` untuk timing yang sangat presisi—Scratch memperbarui panggung sekitar 30 kali per detik, jadi jeda dibulatkan ke frame terdekat.</div>
