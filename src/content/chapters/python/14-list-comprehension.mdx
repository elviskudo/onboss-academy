Comprehension adalah cara membangun list, dict, atau set dari iterable dalam satu baris yang masih terbaca.

## Bentuk Dasar

```python
kuadrat = [x * x for x in range(6)]
# [0, 1, 4, 9, 16, 25]
```

Bagian `x * x` adalah ekspresi hasil; `for x in ...` adalah loop; `if` opsional adalah filter.

## Filter & Ekspresi Bersyarat

```python
genap = [x for x in range(20) if x % 2 == 0]
label = ["genap" if x % 2 == 0 else "ganjil" for x in range(5)]
```

Perhatikan posisi `if`: setelah `for` = filter; sebelum `for` = pilih nilai (ternary).

## Nested Loop

```python
pasangan = [(a, b) for a in [1, 2] for b in ["x", "y"]]
# [(1,'x'), (1,'y'), (2,'x'), (2,'y')]
```

Urutan `for` sama seperti loop bersarang biasa: yang pertama jadi loop luar.

## Dict & Set Comprehension

```python
{chr(k): k for k in range(65, 70)}   # {'A':65, ...}
{x % 3 for x in range(10)}           # {0, 1, 2}
```

## Generator Expression

```python
gen = (x * x for x in range(1_000_000))
print(next(gen), next(gen))   # 1, 4
```

Generator menghasilkan nilai satu per satu saat diminta — cocok untuk data besar. `sum(x for x in data)` sering lebih hemat memori daripada `sum([x for x in data])`.

<div class="note">💡 Comprehension bagus untuk transformasi sederhana. Kalau sudah butuh 2+ `if`, nested yang dalam, atau efek samping, kembalikan ke loop `for` biasa agar tetap mudah dibaca.</div>
