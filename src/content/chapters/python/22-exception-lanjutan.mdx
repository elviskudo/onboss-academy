## Struktur Lengkap

```python
try:
    hasil = risiko()
except ValueError as e:
    print("Nilai salah:", e)
except (TypeError, KeyError):
    print("Tipe/kunci bermasalah")
else:
    print("Sukses:", hasil)
finally:
    print("Cleanup selalu jalan")
```

Urutan `except` penting: tangkap yang **paling spesifik dulu**. `except Exception` terakhir sebagai jaring pengaman.

## raise

```python
def bagi(a, b):
    if b == 0:
        raise ValueError("pembagi tidak boleh nol")
    return a / b
```

Boleh juga melempar ulang exception yang tertangkap dengan `raise` (tanpa argumen) — jejak asli tetap terjaga.

## Custom Exception

```python
class ErrorValidasi(Exception):
    def __init__(self, field, pesan):
        self.field = field
        super().__init__(f"{field}: {pesan}")

raise ErrorValidasi("email", "format tidak valid")
```

Buat exception sendiri bila caller perlu membedakan kegagalan bisnis dari kegagalan teknis.

## Chaining

```python
try:
    data = json.loads(teks)
except json.JSONDecodeError as e:
    raise ConfigError("config rusak") from e
```

`from e` menghasilkan `__cause__`, sehingga traceback menampilkan "The above exception was the direct cause...".

## Context Manager Sendiri

```python
from contextlib import contextmanager

@contextmanager
def transaksi(nama):
    print("mulai", nama)
    try:
        yield
        print("commit")
    except Exception:
        print("rollback")
        raise

with transaksi("bayar"):
    proses_bayar()
```

<div class="note">💡 Jangan menelan exception dengan <code>except: pass</code>. Setidaknya log alasannya. Error yang disembunyikan berubah menjadi bug yang muncul jauh dari sumbernya.</div>
