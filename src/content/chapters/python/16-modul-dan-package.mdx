Modul memecah program besar menjadi file-file kecil yang bisa dipakai ulang. Package adalah direktori berisi kumpulan modul.

## Cara Import

```python
import math                 # math.sqrt(...)
import math as m            # m.sqrt(...)
from math import sqrt       # sqrt(...)
from math import sqrt as akar
from math import *          # hindari: mencemari namespace
```

## Apa yang Terjadi Saat Import?

Python mencari modul di `sys.path`, lalu **mengeksekusi seluruh isi file sekali saja** (hasilnya di-cache di `sys.modules`). Import kedua tidak mengulang eksekusi.

## Modul sebagai Script

```python
# utils.py
def bantu():
    return "halo"

if __name__ == "__main__":
    print(bantu())   # hanya saat `python utils.py`
```

Saat di-import, `__name__` adalah `"utils"`, sehingga blok uji tidak jalan.

## Struktur Package

```
proyek/
├── app/
│   ├── __init__.py
│   ├── utils.py
│   └── models/
│       ├── __init__.py
│       └── user.py
└── main.py
```

```python
from app.utils import bantu
from app.models.user import User
```

## Modul Standar yang Sering Dipakai

| Modul | Fungsi |
|---|---|
| `math` | operasi matematika |
| `random` | angka acak & pilihan |
| `datetime` | tanggal & waktu |
| `os` / `pathlib` | sistem file |
| `json` | parse/serialisasi JSON |
| `re` | regular expression |
| `collections` | struktur data tambahan |

<div class="note">💡 Hindari nama file yang sama dengan modul standar (misal <code>math.py</code> atau <code>json.py</code>) — Python akan memuat file kamu instead of pustaka bawaan dan bug-nya sulit dilacak.</div>
