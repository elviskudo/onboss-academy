## Struktur Data

Katalog memakai dictionary bertingkat. Kode produk menjadi kunci agar pencarian tidak perlu memeriksa seluruh list.

```python
produk = {
    "K01": {"nama": "Kopi", "harga": 18000, "stok": 10},
    "K02": {"nama": "Roti", "harga": 12000, "stok": 8},
}

kode = "K01"
if kode in produk:
    item = produk[kode]
    print(item["nama"], item["harga"])
```

Keranjang memakai list karena satu transaksi berisi urutan item. Setiap item adalah dictionary agar nama, harga, dan jumlah tetap berkelompok.

## Pecah Menjadi Function

Gunakan function berdasarkan satu tanggung jawab. Empat function inti cukup untuk versi pertama:

1. `tampilkan_katalog()` menampilkan produk.
2. `tambah_ke_keranjang()` memvalidasi kode dan jumlah.
3. `hitung_total()` menghitung subtotal.
4. `simpan_transaksi()` menulis riwayat ke JSON.

```python
def hitung_total(keranjang):
    total = 0
    for item in keranjang:
        total += item["harga"] * item["jumlah"]
    return total


def hitung_diskon(total):
    if total >= 100000:
        return total * 0.10
    if total >= 50000:
        return total * 0.05
    return 0
```

Function menerima data melalui parameter dan mengembalikan nilai dengan `return`. Jangan mencampur input, perhitungan, dan penyimpanan dalam satu function karena sulit diuji.

## Validasi Input

Input dari pengguna selalu berupa string. Konversi hanya setelah isi diperiksa dan tangani nilai yang tidak valid dengan `try/except`.

```python
def baca_jumlah():
    while True:
        try:
            jumlah = int(input("Jumlah: "))
            if jumlah > 0:
                return jumlah
            print("Jumlah harus lebih dari nol.")
        except ValueError:
            print("Masukkan angka bulat.")
```

Validasi bisnis berbeda dari validasi tipe. `"2"` bisa dikonversi menjadi integer, tetapi jumlah `0`, kode yang tidak ada, atau stok yang kurang tetap harus ditolak.

## Alur Program

Menu utama menggunakan `while` karena aplikasi berjalan sampai pengguna memilih keluar. Percabangan `if/elif` memilih aksi berdasarkan input.

```python
def tampilkan_menu():
    print("1. Katalog")
    print("2. Keranjang")
    print("3. Bayar")
    print("0. Keluar")

while True:
    tampilkan_menu()
    pilihan = input("Pilih: ").strip()

    if pilihan == "1":
        print("Menampilkan katalog")
    elif pilihan == "2":
        print("Menampilkan keranjang")
    elif pilihan == "3":
        print("Memproses pembayaran")
    elif pilihan == "0":
        break
    else:
        print("Pilihan tidak tersedia.")
```

`break` menghentikan loop utama. Gunakan `continue` jika ingin menolak satu input lalu kembali ke awal loop.

## Pembayaran dan Stok

Urutan aman pembayaran adalah: hitung subtotal, hitung diskon, hitung total akhir, validasi uang, baru kurangi stok. Jangan mengurangi stok sebelum seluruh transaksi dipastikan valid.

```python
def proses_pembayaran(total, uang):
    if uang < total:
        raise ValueError("Uang pembayaran kurang")
    return uang - total

try:
    kembalian = proses_pembayaran(85000, 100000)
    print("Kembalian:", kembalian)
except ValueError as error:
    print("Gagal:", error)
```

Untuk program nyata, pembaruan stok dan penyimpanan transaksi sebaiknya dilakukan sebagai satu operasi yang tidak boleh setengah berhasil.

## Simpan dan Baca JSON

JSON cocok untuk project mini karena sederhana dan tersedia melalui standard library. `json.dump()` menulis object Python ke file, sedangkan `json.load()` membacanya kembali.

```python
import json
from datetime import datetime

transaksi = {
    "waktu": datetime.now().isoformat(timespec="seconds"),
    "items": keranjang,
    "total": total,
}

with open("transaksi.json", "w", encoding="utf-8") as file:
    json.dump(transaksi, file, indent=2, ensure_ascii=False)
```

Gunakan `with open(...)` supaya file ditutup otomatis meskipun terjadi error. Jangan menyimpan data kartu atau password dalam file JSON biasa.

## Pengujian Skenario

Sebelum dianggap selesai, jalankan minimal tujuh skenario:

| Skenario | Ekspektasi |
| --- | --- |
| Kode produk valid | Item masuk keranjang |

| Jumlah melebihi stok | Transaksi ditolak |
| Total melewati batas diskon | Diskon sesuai aturan |

| File laporan belum ada | Program membuat file baru |
