Selain operator aritmetika dan perbandingan dasar, Python punya operator identitas, keanggotaan, dan bitwise.

## Identitas vs Kesamaan

```python
a = [1, 2]
b = [1, 2]
c = a
print(a == b)   # True  → isinya sama
print(a is b)   # False → objek berbeda
print(a is c)   # True  → nama yang sama
```

Gunakan `is` hanya untuk singleton seperti `None`: `if x is None:`.

## Keanggotaan

```python
"ka" in "kampus"        # True (substring)
"merah" not in ["biru", "hijau"]  # True
"user" in {"user": 1}   # True (cek key dict)
```

## Bitwise

| Operator | Nama | Contoh `6`(110) & `3`(011) |
|---|---|---|
| `&` | AND | `2` (010) |
| `|` | OR | `7` (111) |
| `^` | XOR | `5` (101) |
| `~` | NOT | `-7` |
| `<<` / `>>` | Geser kiri/kanan | `6 <&lt; 1` = 12 |

Berguna untuk flag, mask, dan optimasi level rendah.

## Precedence (Prioritas)

Dari tertinggi ke terendah: `()` → `**` → unari `+ - ~` → `* / // %` → `+ -` → `<&lt; >>` → `&` → `^` → `|` → perbandingan → `not` → `and` → `or`.

```python
hasil = 2 + 3 * 4 ** 2   # 2 + 3*16 = 50
print(-2 ** 2)           # -4, bukan 4!
```

<div class="note">💡 Pangkat (`**`) lebih kuat dari minus unari, tapi kurang kuat dari kurung. Kalau ragu, tulis kurung eksplisit — pembaca kode juga akan lebih mudah.</div>
