Iterator adalah objek yang bisa di-loop. Generator adalah cara paling mudah membuat iterator buatan sendiri.

## Protokol Iterator

```python
data = [1, 2, 3]
it = iter(data)
print(next(it))  # 1
print(next(it))  # 2
```

`for x in data` sebenarnya memanggil `iter(data)` lalu `next(...)` berulang sampai `StopIteration`.

## Membuat Iterator Sendiri

```python
class Hitung:
    def __init__(self, awal, akhir):
        self.n = awal
        self.akhir = akhir

    def __iter__(self):
        return self

    def __next__(self):
        if self.n > self.akhir:
            raise StopIteration
        v = self.n
        self.n += 1
        return v
```

## Generator dengan yield

```python
def deret(n):
    for i in range(n):
        yield i * i

print(list(deret(5)))  # [0, 1, 4, 9, 16]
```

Saat `yield` dijalankan, state fungsi **disimpan**. Eksekusi lanjut dari titik itu saat `next()` dipanggil lagi. Ini berbeda dengan `return` yang mengakhiri fungsi.

## Generator Expression

```python
gen = (x * 2 for x in range(1_000_000))
print(sum(gen))   # tidak pernah membuat list 1 juta elemen
```

## send() & yield from

```python
def echo():
    pesan = yield "siap"
    while pesan:
        pesan = yield f"kamu bilang: {pesan}"

g = echo()
print(next(g))            # siap
print(g.send("halo"))     # kamu bilang: halo
```

`yield from` mendelegasikan ke generator lain — berguna untuk pipeline.

<div class="note">💡 Generator hanya bisa diiterasi <b>satu kali</b>. Setelah habis, kamu harus membuat ulang. Kalau butuh beberapa kali iterasi, kembalikan list atau simpan hasilnya.</div>
