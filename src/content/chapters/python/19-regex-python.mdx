Regular expression (regex) adalah mini-bahasa untuk mencocokkan pola teks. Modul `re` sudah bawaan Python.

## Fungsi Utama

| Fungsi | Hasil |
|---|---|
| `re.match(pola, s)` | Match hanya di awal |
| `re.search(pola, s)` | Match pertama di mana saja |
| `re.findall(pola, s)` | Semua match sebagai list string |
| `re.finditer(pola, s)` | Semua match sebagai iterator objek |
| `re.sub(pola, ganti, s)` | Ganti semua match |
| `re.split(pola, s)` | Potong string |

## Dasar Pola

```python
r"[A-Za-z]+"   # satu atau lebih huruf
r"\d{4}"       # tepat 4 digit
r"\s+"         # satu atau lebih spasi/tab
r"^Halo"       # diawali Halo
r"rak$"        # diakhiri rak
r"kol(a|e)r"   # grup pilihan
```

Gunakan **raw string** `r"..."` agar backslash tidak diartikan ulang oleh Python.

## Group

```python
m = re.search(r"(\w+)@(\w+)\.com", "sari@sekolah.com")
print(m.group(0))  # sari@sekolah.com
print(m.group(1))  # sari
print(m.groups())  # ('sari', 'sekolah')
```

## Flag

```python
re.findall("halo", teks, re.IGNORECASE)
re.findall(".", teks, re.DOTALL)      # titik ikut cocok newline
re.findall("^a", teks, re.MULTILINE)  # ^ untuk tiap baris
```

## Kompilasi untuk Pemakaian Berulang

```python
email = re.compile(r"^[\w.]+@[\w.]+\.\w+$")
print(bool(email.match("sari@sekolah.com")))  # True
for item in daftar:
    print(email.match(item))
```

<div class="note">💡 Regex mudah menjadi sulit dibaca. Untuk pola panjang, pakai `re.VERBOSE` dan tulis komentar di dalam pola. Untuk parsing HTML, gunakan parser HTML — bukan regex.</div>
