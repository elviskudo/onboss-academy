Looping mengulang kode tanpa menyalin-nyalin. Python hanya punya **2 bentuk perulangan** — `for` dan `while` — plus `break`/`continue` dan comprehension untuk kasus ringkas.

## for

```python
for i in range(5):        # 0..4
    print(i)

for b in ["a", "b"]:      # list
    print(b)

for huruf in "Python":    # string = iterable
    print(huruf)

for k, v in {"a": 1}.items():   # dict → kunci & nilai
    print(k, v)
```

## while

```python
saldo = 100
while saldo > 0:
    saldo -= 30
    print("Sisa:", saldo)
```

Pastikan kondisi bisa jadi False — kalau tidak, infinite loop!

## break, continue, else-di-loop

```python
for i in range(10):
    if i == 3:
        continue   # lompati 3
    if i == 6:
        break      # berhenti di 6
    print(i)       # 0,1,2,4,5

# else pada loop: jalan kalau loop selesai TANPA break
for n in range(2, 10):
    if n % 7 == 0:
        break
else:
    print("tidak ada kelipatan 7")
```

## Kapan Pakai Mana

| Bentuk | Kapan dipakai | Contoh |
|---|---|---|
| `for x in iterable` | jumlah iterasi sudah jelas / data terurut | semua baris list |
| `for i in range(n)` | iterasi berbasis angka | tabel perkalian |
| `while kondisi` | berhenti bergantung kondisi, bukan jumlah | antrian belum kosong |
| `while True + break` | tunggu input valid (tidak ada do-while) | ulangi sampai benar |
| comprehension | transformasi/filtrasi data → list baru | ambil nilai > 80 |

## Pola Klasik

```python
# 1. akumulasi
total = sum(harga for harga in daftar_harga)

# 2. cari pertama → break
for s in siswa:
    if s["nilai"] < 70:
        print("Remedial:", s["nama"]); break

# 3. filter → list baru
tidak_lulus = [s for s in siswa if s["nilai"] < 70]

# 4. hitung frekuensi
frek = {}
for k in "mississippi":
    frek[k] = frek.get(k, 0) + 1
```

## enumerate, zip

```python
for i, buah in enumerate(["apel", "jeruk"], start=1):
    print(i, buah)

for nama, nilai in zip(["Sari", "Budi"], [90, 85]):
    print(nama, nilai)
```

`enumerate` saat butuh index tanpa hitung manual, `zip` saat menggabungkan 2 list paralel.

## List Comprehension

```python
kuadrat = [n * n for n in range(1, 6)]        # [1,4,9,16,25]
genap = [n for n in range(10) if n % 2 == 0]

# dict & set comprehension juga ada
skor = {m: 90 for m in ["A", "B"]}
genap_unik = {n % 3 for n in range(10)}
```

Ada 4 jenis comprehension: `[]` list, `{}` dict, `{}` set, dan `()` generator (hemat memori, dievaluasi lazy).
