Bekerja dengan file adalah kebutuhan sehari-hari: log, konfigurasi, laporan CSV. Python memudahkannya lewat `pathlib` dan context manager.

## pathlib

```python
from pathlib import Path

p = Path("dokumen") / "laporan.txt"
print(p.name)       # laporan.txt
print(p.suffix)     # .txt
print(p.parent)     # dokumen
p.parent.mkdir(parents=True, exist_ok=True)
```

Operator `/` menggabungkan path dengan benar di Windows maupun Unix — tidak perlu peduli `\` atau `/`.

## Mode File

| Mode | Arti |
|---|---|
| `r` | baca (default) |
| `w` | tulis, timpa isi lama |
| `a` | tambah di akhir |
| `x` | buat hanya jika belum ada |
| `b` | biner |
| `+` | baca sekaligus tulis |

```python
with open("catatan.txt", "a", encoding="utf-8") as f:
    f.write("Baris baru
")
```

## Baca Baris per Baris

```python
with open("besar.log", encoding="utf-8") as f:
    for baris in f:
        if "ERROR" in baris:
            print(baris.strip())
```

Jangan `.read()` seluruh file besar — iterasi baris jauh lebih hemat memori.

## CSV

```python
import csv

with open("nilai.csv", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["nama"])
```

`newline=""` mencegah baris kosong ganda di Windows.

## Direktori

```python
for file in Path(".").glob("*.py"):
    print(file)

for file in Path(".").rglob("*.mdx"):   # rekursif
    print(file)

p.rename("baru.txt")
p.unlink()          # hapus file
```

<div class="note">💡 Selalu pakai <code>with</code> saat membuka file. Context manager menutup file secara otomatis walaupun exception terjadi di tengah blok — mencegah file terkunci atau buffer belum tersiram.</div>
