Decorator membungkus fungsi atau class untuk menambah perilaku tanpa mengubah kode aslinya. Ini fondasi banyak framework Python (Flask, FastAPI, pytest).

## Dekorator Manual

```python
def sapa(f):
    def bungkus(nama):
        print("Sebelum panggil")
        hasil = f(nama)
        print("Sesudah panggil")
        return hasil
    return bungkus

def halo(nama):
    return f"Halo {nama}"

halo = sapa(halo)
```

## Sintaks @

```python
@sapa
def halo(nama):
    return f"Halo {nama}"
```

Dua bentuk di atas identik. Dekorator dijalankan **saat fungsi didefinisikan**, bukan saat dipanggil.

## Menjaga Metadata

Tanpa `wraps`, `halo.__name__` berubah jadi `"bungkus"`. Gunakan:

```python
from functools import wraps

def sapa(f):
    @wraps(f)
    def bungkus(*args, **kwargs):
        return f(*args, **kwargs)
    return bungkus
```

## Dekorator Bertingkat

```python
@auth
@cache
def ambil_data(id):
    ...
```

Urutan penerapan: dari bawah ke atas (`cache` dulu, lalu `auth`). Urutan pemanggilan: dari atas ke bawah.

## Dekorator dengan Argumen

```python
def ulang(n):
    def dekorator(f):
        @wraps(f)
        def bungkus(*a, **kw):
            for _ in range(n):
                hasil = f(*a, **kw)
            return hasil
        return bungkus
    return dekorator

@ulang(3)
def coba():
    print("dijalankan")
```

## Decorator pada Class

```python
@dataclass
class Titik:
    x: int
    y: int
```

`dataclass` otomatis membuat `__init__`, `__repr__`, dan `__eq__` — contoh dekorator dari pustaka standar.

<div class="note">💡 Decorator paling cocok untuk <b>concern melintang</b>: logging, timing, validasi token, retry, cache. Jangan dipakai untuk logika bisnis inti — tetap tulis fungsi biasa agar alur mudah diikuti.</div>
