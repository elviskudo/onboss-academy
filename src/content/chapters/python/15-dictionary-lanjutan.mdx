Dictionary adalah struktur kunci–nilai yang paling sering dipakai setelah list. Python menyediakan banyak helper agar kode tetap ringkas dan aman.

## Akses Aman

```python
data = {"nama": "Sari"}
print(data["nama"])          # Sari
print(data["umur"])          # KeyError!
print(data.get("umur", 0))   # 0 → lebih aman
```

## Menambah & Memperbarui

```python
data.update({"kota": "Bandung", "umur": 20})
data |= {"aktif": True}      # Python 3.9+

data.setdefault("login", 0)
data["login"] += 1           # pola penghitung yang aman
```

## Iterasi

```python
for k in data:            # key
for v in data.values():   # nilai
for k, v in data.items(): # pasangan — paling sering dipakai
```

`keys()`, `values()`, `items()` mengembalikan **view**: perubahan dict langsung terlihat, tanpa menyalin seluruh isi.

## Urutan & Copy

Sejak 3.7, dict menjaga urutan sisipan. Ini berguna saat menghasilkan JSON atau laporan yang konsisten.

```python
a = {"x": 1}
b = a            # referensi yang sama
c = a.copy()     # shallow copy
d = dict(a)      # shallow copy juga
```

Untuk nested dict, pakai `copy.deepcopy()` agar objek dalam tidak ikut berbagi.

## Dict Comprehension

```python
sku = ["A-1", "B-2"]
harga = {k: 10000 for k in sku}
```

<div class="note">💡 Kunci dict harus <b>hashable</b> (string, angka, tuple berisi nilai hashable). List tidak bisa jadi kunci. Kalau butuh beberapa nilai per kunci, simpan list/dict sebagai <i>nilai</i>.</div>
