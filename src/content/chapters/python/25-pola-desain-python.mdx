Design pattern adalah solusi umum untuk masalah yang berulang. Python sering bisa memakai fitur bahasa (fungsi kelas satu, decorator) agar polanya lebih pendek daripada versi Java/C++.

## Strategy

```python
from abc import ABC, abstractmethod

class Diskon(ABC):
    @abstractmethod
    def hitung(self, total): ...

class DiskonMember(Diskon):
    def hitung(self, total): return total * 0.9

class TanpaDiskon(Diskon):
    def hitung(self, total): return total

def checkout(total, strategi):
    return strategi.hitung(total)
```

Algoritma bisa diganti tanpa mengubah `checkout`.

## Factory

```python
def buat_koneksi(jenis):
    if jenis == "mysql":
        return KoneksiMySQL()
    if jenis == "postgres":
        return KoneksiPostgres()
    raise ValueError(jenis)
```

Memusatkan pembuatan object membuat kode pemanggil tidak tahu detail class konkret.

## Observer

```python
class Subjek:
    def __init__(self): self._observer = []

    def tambah(self, o): self._observer.append(o)

    def kirim(self, pesan):
        for o in self._observer:
            o(pesan)

subjek = Subjek()
subjek.tambah(lambda p: print("Log:", p))
subjek.tambah(lambda p: print("Notif:", p))
subjek.kirim("stok habis")
```

Callback sederhana sering cukup tanpa class Observer formal.

## Singleton (Idiom Python)

```python
class Konfigurasi:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance.data = {}
        return cls._instance

a = Konfigurasi()
b = Konfigurasi()
print(a is b)  # True
```

Untuk kasus sederhana, modul Python sudah otomatis singleton — cukup simpan state di level modul.

## Repository

```python
class UserRepository:
    def __init__(self, db): self.db = db

    def cari(self, id):
        return self.db.query("SELECT * FROM users WHERE id=?", (id,))

class UserService:
    def __init__(self, repo): self.repo = repo
```

Service tidak perlu tahu apakah data berasal dari SQL, API, atau cache.

<div class="note">💡 Jangan memaksakan pattern di awal. Tulis kode langsung dulu; saat muncul duplikasi atau coupling yang menyakitkan, baru refactor ke pattern yang sesuai. Pattern adalah alat, bukan target.</div>
