Class di TypeScript menambahkan anotasi tipe dan modifier ke fitur class JavaScript. Pemahaman yang baik membantu membangun domain model yang rapi.

## Abstract Class

```ts
abstract class Bentuk {
  constructor(public readonly nama: string) {}

  abstract luas(): number; // wajib diimplementasikan turunan

  deskripsi(): string {
    return `${this.nama}: ${this.luas().toFixed(2)}`;
  }
}

class Lingkaran extends Bentuk {
  constructor(private jari: number) {
    super("Lingkaran");
  }

  override luas(): number {
    return Math.PI * this.jari ** 2;
  }
}
```

Abstract method tidak punya implementasi dan memaksa turunan mengisinya.

## Modifier Akses

| Modifier | Akses |
|----------|-------|
| `public` | Semua tempat (default) |
| `private` | Hanya class itu sendiri |
| `protected` | Class + turunan |
| `readonly` | Hanya di constructor |

Parameter property (`constructor(public nama: string)`) sekaligus mendeklarasikan dan menetapkan properti.

## override & noImplicitOverride

```ts
class Induk {
  jalankan(): void {}
}

class Anak extends Induk {
  override jalankan(): void { } // ✅
  jalan(): void {}              // ⚠️ typo, bukan override
}
```

Dengan `noImplicitOverride: true`, lupa menulis `override` menjadi error — mencegah bug karena salah eja nama method.

## Getter & Setter

```ts
class Suhu {
  private _celsius = 0;

  get celsius(): number { return this._celsius; }

  set celsius(v: number) {
    if (v < -273) throw new Error("Di bawah nol mutlak");
    this._celsius = v;
  }

  get fahrenheit(): number {
    return this._celsius * 9 / 5 + 32;
  }
}
```

TypeScript menyimpulkan tipe getter dari return type. Getter dan setter bisa punya tipe berbeda (T ≥ 4.3).

## Static Members & Block

```ts
class Konfigurasi {
  static readonly versi = "1.0";
  static daftar: string[] = [];

  static {
    Konfigurasi.daftar.push("awal");
  }
}
```

## implements Interface

```ts
interface BisaSimpan {
  simpan(): void;
}

class Database implements BisaSimpan {
  simpan(): void { console.log("tersimpan"); }
}
```

Interface hanya mendefinisikan kontrak; class boleh punya anggota tambahan.

<div class="note">💡 Hindari `private` berlebihan pada model data sederhana. Ia menyulitkan serialisasi dan testing. Pakai `readonly` bila hanya ingin mencegah perubahan.</div>

## Di Dunia Nyata

- Abstract base class dipakai pada repository: `UserRepo extends BaseRepo<User>`.
- Getter menghitung turunan seperti `totalHarga` tanpa menyimpan data duplikat.
- Static block menginisialisasi registry plugin saat class dimuat.
