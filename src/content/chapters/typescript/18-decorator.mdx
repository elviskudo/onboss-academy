Decorator adalah fungsi yang dijalankan saat class atau anggotanya didefinisikan. Ia dipakai oleh framework seperti Angular dan NestJS untuk dependency injection, routing, dan validasi.

## Mengaktifkan

```json
{
  "compilerOptions": {
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true
  }
}
```

Opsi `emitDecoratorMetadata` menyimpan informasi tipe parameter ke metadata runtime — dibutuhkan oleh container DI.

## Jenis Decorator

| Jenis | Kapan jalan | Parameter |
|-------|-------------|-----------|
| Class | Saat class didefinisikan | constructor |
| Method | Saat method didefinisikan | target, key, descriptor |
| Property | Saat properti didefinisikan | target, key |
| Parameter | Saat parameter didefinisikan | target, key, index |
| Accessor | Saat getter/setter didefinisikan | descriptor |

## Contoh: Logging Method

```ts
function Log(target: object, key: string, descriptor: PropertyDescriptor) {
  const asli = descriptor.value;
  descriptor.value = function (...args: unknown[]) {
    console.log(`[LOG] ${key} dipanggil dengan`, args);
    return asli.apply(this, args);
  };
  return descriptor;
}

class Kalkulator {
  @Log
  tambah(a: number, b: number) {
    return a + b;
  }
}
```

## Decorator Factory

```ts
function Rute(path: string) {
  return function (target: object, key: string) {
    Reflect.defineMetadata("rute", path, target, key);
  };
}

class Controller {
  @Rute("/user")
  ambilUser() {}
}
```

Fungsi luar menerima konfigurasi, fungsi dalam menjadi decorator sungguhan.

## Decorator Class

```ts
function Komponen(nama: string) {
  return <T extends { new (...args: any[]): {} }>(ctor: T) => {
    return class extends ctor {
      static namaKomponen = nama;
    };
  };
}

@Komponen("KartuProduk")
class Kartu {}
```

## Status Standar

Decorator JavaScript (Stage 3) sudah berbeda dari implementasi eksperimen TypeScript. TypeScript 5 mendukung standar baru lewat opsi `experimentalDecorators: false`, tapi banyak library masih mengandalkan model lama.

<div class="note">💡 Decorator menambah kompleksitas dan bisa menyembunyikan perilaku. Pakai hanya kalau ekosistemmu (Angular/NestJS) memang membutuhkannya.</div>

## Di Dunia Nyata

- `@Injectable()` menandai class yang bisa disuntikkan dependensinya.
- `@Get('/user')` mendaftarkan handler rute di NestJS.
- `@Input()` di Angular menandai properti yang bisa menerima nilai dari komponen induk.
