Declaration merging adalah kemampuan TypeScript menggabungkan beberapa deklarasi dengan nama yang sama menjadi satu definisi. Ini terdengar aneh, tapi merupakan fondasi banyak pola ekosistem.

## Interface Bisa Di-merge

```ts
interface User {
  nama: string;
}

interface User {
  umur: number;
}

const u: User = { nama: "Sari", umur: 20 };
```

Aturannya: anggota harus kompatibel. Kalau kamu mendeklarasikan `nama: number` di salah satunya, akan muncul error.

```ts
interface User { nama: string }
interface User { nama: number } // ❌ Subsequent property declarations...
```

## Type Alias Tidak Bisa

```ts
type A = { x: number };
type A = { y: number }; // ❌ Duplicate identifier
```

Karena itu, kalau kamu merancang API publik yang mungkin diperluas, pilih `interface`.

## Function Overload Merging

```ts
function format(x: number): string;
function format(x: Date): string;
function format(x: number | Date): string {
  return String(x);
}
```

Deklarasi overload di atas digabung dengan implementasi menjadi satu fungsi dengan dua signature.

## Module Augmentation

```ts
// types/array.d.ts
declare global {
  interface Array<T> {
    keUnik(): T[];
  }
}

export {};
```

Setelah itu kamu bisa memanggil `[1,1,2].keUnik()` — tapi ingat, kamu tetap harus mengimplementasikan methodnya di runtime.

## Augmenting Modul Pihak Ketiga

```ts
import "express";

declare module "express-serve-static-core" {
  interface Request {
    user?: { id: string };
  }
}
```

Ini cara standar menambah tipe `req.user` pada Express setelah middleware auth.

## Namespace Merging

```ts
class Widget {
  static versi = "1.0";
}

namespace Widget {
  export const bawaan = "default";
}

Widget.versi;   // dari class
Widget.bawaan;  // dari namespace
```

<div class="note">💡 Modifikasi tipe global berdampak ke seluruh proyek. Simpan di folder `types/` dan beri nama jelas supaya tidak membingungkan tim.</div>

## Di Dunia Nyata

- `@types/express` memakai augmentation untuk menambah `req.user`.
- Library UI menambah opsi ke interface konfigurasi tanpa merusak versi sebelumnya.
- Deklarasi CSS module memakai wildcard module: `declare module "*.module.css" { ... }`.
