Proyek penutup ini merangkai generics, literal type, Result, dan async/await menjadi sebuah API client kecil yang aman dan enak dipakai.

## Definisi Rute

```ts
const RUTE = {
  user: "/api/user",
  produk: "/api/produk",
  pesanan: "/api/pesanan"
} as const;

type NamaRute = keyof typeof RUTE;
// "user" | "produk" | "pesanan"
```

Dengan `as const`, nilai rute tidak melebar jadi `string`, sehingga `keyof` menghasilkan union yang presisi.

## Tipe Domain & Hasil

```ts
interface User { id: number; nama: string }
interface Produk { id: number; nama: string; harga: number }

type PetaData = {
  user: User;
  produk: Produk[];
  pesanan: { id: number; total: number }[];
};

type Hasil<T> =
  | { ok: true; data: T }
  | { ok: false; error: string };
```

## Client Generic

```ts
async function request<K extends NamaRute>(
  rute: K
): Promise<Hasil<PetaData[K]>> {
  try {
    const res = await fetch(RUTE[rute]);
    if (!res.ok) {
      return { ok: false, error: `HTTP ${res.status}` };
    }
    const data = (await res.json()) as PetaData[K];
    return { ok: true, data };
  } catch (err) {
    const pesan = err instanceof Error ? err.message : "Error jaringan";
    return { ok: false, error: pesan };
  }
}
```

Karena `K` adalah nama rute, TypeScript menyimpulkan tipe hasilnya:

```ts
const user = await request("user");
if (user.ok) {
  console.log(user.data.nama); // data: User
}

const produk = await request("produk");
if (produk.ok) {
  console.log(produk.data[0].harga); // data: Produk[]
}
```

Kalau kamu menulis `request("pengguna")` (typo), compiler langsung menolak.

## Menambah Opsi Request

```ts
interface Opsi {
  method?: "GET" | "POST";
  body?: unknown;
  signal?: AbortSignal;
}

async function request<K extends NamaRute>(
  rute: K,
  opsi: Opsi = {}
): Promise<Hasil<PetaData[K]>> {
  const res = await fetch(RUTE[rute], {
    method: opsi.method ?? "GET",
    headers: { "Content-Type": "application/json" },
    body: opsi.body ? JSON.stringify(opsi.body) : undefined,
    signal: opsi.signal
  });
  // ...
}
```

## Validasi Runtime

Tambahkan Zod supaya assertion `as PetaData[K]` tidak berbohong:

```ts
const skema = {
  user: z.object({ id: z.number(), nama: z.string() }),
  produk: z.array(z.object({ id: z.number(), nama: z.string(), harga: z.number() }))
};

const hasil = skema[rute].safeParse(await res.json());
if (!hasil.success) return { ok: false, error: "Data tidak sesuai skema" };
return { ok: true, data: hasil.data as PetaData[K] };
```

## Penggunaan di UI

```ts
async function tampilkanNama() {
  const hasil = await request("user");
  const el = document.querySelector("#nama");
  if (!el) return;
  el.textContent = hasil.ok ? hasil.data.nama : `Gagal: ${hasil.error}`;
}
```

<div class="note">💡 Pola ini—konstanta `as const`, peta tipe, generic function, dan Result—adalah fondasi banyak SDK modern. Begitu kamu menguasainya, membaca kode library jauh lebih mudah.</div>

## Rangkuman Seri

Dari tipe dasar sampai generics lanjutan, TypeScript pada dasarnya punya satu tujuan: **membuat kesalahan terlihat lebih awal**. Setiap fitur yang kamu pelajari adalah alat untuk menyatakan niat dengan lebih jelas kepada kompiler dan kepada rekan tim.
