Sekarang gabungkan semua materi: interface, union, generic kecil, dan class — menjadi aplikasi kasir sederhana yang berjalan di konsol.

## Peta Materi ke Proyek

| Bagian proyek | Konsep yang dipakai | Dari bab |
|---------------|---------------------|----------|
| `interface Item`, `interface Struk` | Type alias & interface | 5 |
| `subtotal()` + `reduce()` | Function tipe, array method | 3 & 4 |
| `hitungTotal()` dengan diskon | Operator, percabangan | 2 |

Urutan membangun yang terbukti: **tipe data dulu → fungsi murni → class yang menyimpan state → UI/konsol**. Dengan urutan ini, setiap lapis bisa diuji sendiri sebelum lapis berikutnya ditulis.

## Model Data

```typescript
interface Item {
  nama: string;
  harga: number;
  qty: number;
}

interface Struk {
  items: Item[];
  diskonPersen: number;
}
```

Semua fungsi berikutnya bekerja di atas kontrak ini — bukan objek tanpa bentuk.

## Menghitung Total

```typescript
function subtotal(items: Item[]): number {
  return items.reduce((sum, item) => sum + item.harga * item.qty, 0);
}

function hitungTotal(struk: Struk): number {
  const sub = subtotal(struk.items);
  return sub - (sub * struk.diskonPersen) / 100;
}

const struk: Struk = {
  items: [
    { nama: "Kopi", harga: 25000, qty: 2 },
    { nama: "Roti", harga: 15000, qty: 1 },
  ],
  diskonPersen: 10,
};

console.log("Total:", hitungTotal(struk));
```

## Class Kasir

```typescript
class Kasir {
  private struk: Struk = { items: [], diskonPersen: 0 };

  tambahItem(nama: string, harga: number, qty: number): void {
    const ada = this.struk.items.find((i) => i.nama === nama);
    if (ada) ada.qty += qty;
    else this.struk.items.push({ nama, harga, qty });
  }

  setDiskon(persen: number): void {
    this.struk.diskonPersen = persen;
  }

  total(): number {
    return hitungTotal(this.struk);
  }

  cetak(): void {
    console.log("--- STRUK ---");
    for (const i of this.struk.items) {
      console.log(i.nama, "x" + i.qty, "=", i.harga * i.qty);
    }
    console.log("Diskon:", this.struk.diskonPersen + "%");
    console.log("TOTAL:", this.total());
  }
}
```

## Menjalankan Aplikasi

```typescript
const kasir = new Kasir();
kasir.tambahItem("Kopi", 25000, 2);
kasir.tambahItem("Roti", 15000, 1);
kasir.setDiskon(10);
kasir.cetak();
```

Ide lanjutan (latihan): tambah method `hapusItem(nama)`, simpan ke `localStorage`, dan tampilkan pajak PPN 11%.

## Di Dunia Nyata

- **POS restoran**: `tambahItem` dipanggil tiap kali kasir menekan menu — item sama otomatis menumpuk qty-nya.
- **Diskon member** diatur lewat `setDiskon()` — angka `0` sampai `100` divalidasi sebelum mengubah state.
- **Struk digital** dicetak dari `cetak()` — format konsisten karena semua baca dari satu `struk` privat.
- **Toko online** memakai pola identik: `subtotal()` untuk keranjang, `hitungTotal()` untuk halaman checkout.
- **Pengujian unit**: `subtotal()` bisa diuji tanpa membuat instance `Kasir` — itulah gunanya fungsi murni terpisah.
