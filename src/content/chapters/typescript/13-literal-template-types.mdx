Tipe literal membatasi nilai ke satu kemungkinan tertentu. Bila digabung dengan union, kamu bisa memodelkan domain aplikasi dengan sangat presisi.

## Literal Type Dasar

```ts
type Arah = "utara" | "selatan" | "timur" | "barat";
type Level = 1 | 2 | 3;
type Aktif = true; // hanya true

function arahKeDerajat(a: Arah): number {
  switch (a) {
    case "utara": return 0;
    case "timur": return 90;
    case "selatan": return 180;
    case "barat": return 270;
  }
}
```

Karena semua kasus tercakup, TypeScript tahu fungsi di atas selalu mengembalikan `number`.

## as const

```ts
const warna = ["merah", "biru"]; // string[]
const warnaKaku = ["merah", "biru"] as const; // readonly ["merah", "biru"]

type Warna = typeof warnaKaku[number]; // "merah" | "biru"
```

Pola `typeof array[number]` adalah cara populer membuat union dari daftar konstanta.

```ts
const STATUS = {
  MENUNGGU: "menunggu",
  SUKSES: "sukses",
  GAGAL: "gagal"
} as const;

type Status = typeof STATUS[keyof typeof STATUS];
```

## Template Literal Types

```ts
type EventName = `on${Capitalize<string>}`;
type RuteApi = `/api/${string}`;
type Kelas = `btn-\${"primary" | "danger"}`;
// "btn-primary" | "btn-danger"
```

TypeScript juga menyediakan utility string intrinsik: `Uppercase<T>`, `Lowercase<T>`, `Capitalize<T>`, `Uncapitalize<T>`.

```ts
type Metode = "get" | "post";
type Handler = `handle${Capitalize<Metode>}`;
// "handleGet" | "handlePost"
```

## Combined dengan Generics

```ts
type EventMap = {
  klik: { x: number; y: number };
  ketik: { teks: string };
};

type Handler<E extends keyof EventMap> = (data: EventMap[E]) => void;
type SemuaHandler = {
  [K in keyof EventMap as `on${Capitalize<K>}`]: Handler<K>;
};
// onClick, onKetik
```

## Kapan Pakai vs Enum

Literal union lebih ringan daripada `enum` karena tidak menghasilkan kode JavaScript tambahan. Enum tetap berguna kalau kamu ingin nilai numerik atau iterasi runtime.

<div class="note">💡 Tanpa `as const`, objek `{ mode: "gelap" }` memiliki tipe `{ mode: string }`, bukan `{ mode: "gelap" }`. Itu sebabnya union bisa "hilang" kalau lupa.</div>

## Di Dunia Nyata

- Status request API didefinisikan sebagai literal union agar typo terdeteksi.
- Nama kelas utilitas (`btn-primary`, `text-lg`) dibangun dengan template literal type.
- Konstanta konfigurasi memakai `as const` supaya nilai tidak melebar.
