Module memecah kode menjadi file-file yang bisa saling mengimpor. TypeScript mengikuti standar ES module, dengan tambahan pemeriksaan tipe lintas file.

## export / import

```ts
// matematika.ts
export const PI = 3.14;
export function luasLingkaran(r: number) { return PI * r ** 2; }
export default function jumlah(a: number, b: number) { return a + b; }

// app.ts
import jumlah, { PI, luasLingkaran } from "./matematika";
import * as matematika from "./matematika";
```

Default export cukup satu per file. Named export bisa banyak dan lebih mudah di-refactor karena nama harus sama saat diimpor.

## Type-Only Import

```ts
import type { Pengguna } from "./tipe";
import { type Pengguna, ambilData } from "./api";
```

`import type` dihapus total saat kompilasi. Ini mencegah import runtime yang sebenarnya tidak diperlukan dan menghindari circular dependency pada tipe.

## Barrel File

```ts
// components/index.ts
export { Button } from "./Button";
export { Card } from "./Card";
export type { ButtonProps } from "./Button";
```

Lalu konsumen cukup:

```ts
import { Button, Card } from "@/components";
```

Hati-hati: barrel yang terlalu besar bisa memperlambat build karena bundler harus mengevaluasi banyak file.

## Ekstensi File dalam Import

```ts
import { helper } from "./helper";       // ✅ dengan bundler
import { helper } from "./helper.js";    // ✅ wajib di Node ESM murni
```

TypeScript tidak menulis ulang ekstensi. Kalau targetnya Node.js ESM, kamu tetap perlu menulis `.js` pada import meski file sumbernya `.ts`.

## Deklarasi Global

```ts
declare global {
  interface Window {
    __APP_CONFIG__: { apiUrl: string };
  }
}
export {}; // membuat file jadi module
```

Tanpa `export {}`, file dianggap script global.

## Dynamic Import

```ts
const { default: Chart } = await import("./Chart");
```

Dynamic import menghasilkan chunk terpisah — dasar dari code splitting.

<div class="note">💡 Aktifkan `verbatimModuleSyntax: true` kalau ingin TypeScript lebih ketat soal membedakan import tipe dan nilai. Ini sejalan dengan perilaku ESM modern.</div>

## Di Dunia Nyata

- Proyek React memakai barrel di folder `components/` dan `hooks/`.
- Monorepo memakai `paths` di tsconfig untuk import internal.
- Type-only import mencegah bundle menyertakan kode yang tidak dipakai.
