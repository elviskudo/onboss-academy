TypeScript tidak mengubah cara kerja Promise — ia hanya memastikan tipe nilai yang kamu terima dan kembalikan konsisten.

## Mengetik Promise

```ts
function ambilAngka(): Promise<number> {
  return new Promise(resolve => setTimeout(() => resolve(42), 100));
}

async function ambilTeks(): Promise<string> {
  return "halo"; // otomatis dibungkus Promise
}
```

## async/await

```ts
interface User { id: number; nama: string }

async function ambilUser(id: number): Promise<User> {
  const res = await fetch(`/api/users/${id}`);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return (await res.json()) as User;
}
```

`as User` di sini adalah assertion karena `res.json()` bertipe `Promise<any>`. Lebih baik lagi, validasi dengan type guard atau library seperti Zod.

## Awaited & ReturnType

```ts
type Hasil = Awaited<ReturnType<typeof ambilUser>>; // User
```

Ini sangat berguna saat kamu ingin menyimpan tipe hasil sebuah fungsi async tanpa mendeklarasikan ulang.

## Promise.all / allSettled / race

```ts
const [user, postingan] = await Promise.all([
  ambilUser(1),
  ambilPostingan(1)
]);
// user: User, postingan: Postingan[]

const hasil = await Promise.allSettled([p1, p2]);
// ({ status: "fulfilled"; value: T } | { status: "rejected"; reason: any })[]
```

`all` gagal kalau salah satu gagal. `allSettled` menunggu semuanya selesai apa pun hasilnya.

## Error Handling

```ts
try {
  const data = await ambilUser(1);
} catch (err) {
  if (err instanceof Error) console.error(err.message);
}
```

Dengan `useUnknownInCatchVariables` (aktif di `strict`), `err` bertipe `unknown`.

## Top-Level Await

```ts
const config = await fetch("/config.json").then(r => r.json());
```

Bisa dipakai di modul ESM dengan `module: ESNext` / `ES2022`. Tidak bisa di CommonJS.

<div class="note">💡 Jangan menulis fungsi `async` hanya untuk mengembalikan nilai sinkron. Itu menambah microtask tanpa manfaat.</div>

## Di Dunia Nyata

- React Query/SWR menyimpulkan tipe data dari fungsi query async.
- `Awaited<ReturnType<typeof action>>` dipakai untuk tipe state hasil server action.
- `Promise.all` mempercepat fetch beberapa resource independen.

## Try it Yourself

Ubah `Promise.all` menjadi `Promise.allSettled` untuk melihat perubahan tipe hasil.
