PHP menyediakan class `DateTime` dan `DateTimeImmutable` untuk bekerja dengan waktu. Keduanya jauh lebih aman daripada manipulasi timestamp manual.

## Membuat Objek Tanggal

```php
<?php
date_default_timezone_set('Asia/Jakarta');

$sekarang = new DateTime();                  // waktu sekarang
$tertentu = new DateTime('2026-03-08 10:30'); // dari string
$dariFormat = DateTime::createFromFormat('d/m/Y', '08/03/2026');
$timestamp = new DateTime('@' . time());      // dari Unix timestamp
```

`DateTimeImmutable` memiliki API sama, tetapi method seperti `modify()` mengembalikan objek baru.

## Memformat

```php
<?php
$d = new DateTimeImmutable('2026-03-08 14:30:00');

echo $d->format('Y-m-d');           // 2026-03-08
echo $d->format('l, d F Y');        // Minggu, 08 Maret 2026
echo $d->format('H:i:s');           // 14:30:00
echo $d->format('c');               // 2026-03-08T14:30:00+07:00
```

Karakter format umum: `Y` (tahun), `m` (bulan), `d` (hari), `l` (nama hari), `F` (nama bulan), `H` (jam 24 jam), `i` (menit), `s` (detik), `U` (timestamp).

## Modifikasi

```php
<?php
$d = new DateTimeImmutable('2026-03-08');

$besok   = $d->modify('+1 day');
$lusa    = $d->modify('+2 days');
$bulanDepan = $d->modify('+1 month');
$awalBulan = $d->modify('first day of this month');
$akhirBulan = $d->modify('last day of this month');

echo $d->format('Y-m-d');        // tetap 2026-03-08
echo $besok->format('Y-m-d');    // 2026-03-09
```

## Selisih Waktu

```php
<?php
$a = new DateTimeImmutable('2026-01-01');
$b = new DateTimeImmutable('2026-03-08');

$selisih = $a->diff($b);
echo $selisih->days;  // 66
echo $selisih->format('%m bulan, %d hari');
```

## Zona Waktu

```php
<?php
$jakarta = new DateTimeZone('Asia/Jakarta');
$utc     = new DateTimeZone('UTC');

$d = new DateTimeImmutable('now', $jakarta);
echo $d->format('Y-m-d H:i e');

$diUtc = $d->setTimezone($utc);
echo $diUtc->format('Y-m-d H:i e');
```

Simpan waktu di database dalam **UTC**, lalu konversi ke zona pengguna saat ditampilkan.

## Fungsi legacy

```php
<?php
echo date('Y-m-d');             // format waktu sekarang
echo strtotime('+3 days');      // timestamp dari string relatif
echo mktime(12, 0, 0, 3, 8, 2026);
```

Masih umum, tapi `DateTime` lebih fleksibel untuk logika kompleks.

<div class="note">💡 `modify('+1 month')` dari 31 Januari bisa menghasilkan 3 Maret karena Februari tidak punya hari ke-31. Gunakan `add(new DateInterval('P1M'))` dengan hati-hati atau uji kasus ujung bulan.</div>

## Di Dunia Nyata

- Menampilkan "2 jam lalu" dari selisih `diff()`.
- Menjadwalkan email dengan `modify('+3 days')`.
- Konversi waktu meeting antar zona dengan `setTimezone()`.
