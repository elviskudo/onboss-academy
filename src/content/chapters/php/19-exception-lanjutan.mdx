Penanganan error yang baik membuat aplikasi gagal dengan anggun, bukan menampilkan stack trace ke pengguna.

## try / catch / finally

```php
<?php
try {
    $file = fopen("data.txt", "r");
    if (!$file) {
        throw new RuntimeException("Gagal membuka file");
    }
    echo fread($file, filesize("data.txt"));
} catch (RuntimeException $e) {
    echo "Error: " . $e->getMessage();
} finally {
    if (isset($file) && is_resource($file)) {
        fclose($file);
    }
    echo "\nOperasi selesai";
}
```

`finally` dijalankan baik ada exception maupun tidak.

## Multiple Catch

```php
<?php
try {
    // ...
} catch (InvalidArgumentException $e) {
    echo "Input salah: " . $e->getMessage();
} catch (PDOException $e) {
    echo "Database error";
} catch (Throwable $e) {
    echo "Error tak terduga";
}
```

Urutan penting: tangkap yang paling spesifik dulu. `Throwable` di terakhir sebagai jaring pengaman.

## Custom Exception

```php
<?php
class ValidasiException extends Exception {
    public function __construct(
        public string $field,
        string $pesan
    ) {
        parent::__construct("$field: $pesan");
    }
}

function validasiUmur(int $umur): void {
    if ($umur < 0 || $umur > 150) {
        throw new ValidasiException("umur", "di luar rentang");
    }
}
```

## Error vs Exception

```php
<?php
try {
    $x = 1 / 0; // DivisionByZeroError di PHP 8
} catch (DivisionByZeroError $e) {
    echo "Tidak bisa dibagi nol";
}
```

Sejak PHP 7, error fatal tertentu menjadi `Error` yang bisa ditangkap. Keduanya mengimplementasikan `Throwable`.

## Handler Global

```php
<?php
set_exception_handler(function (Throwable $e) {
    error_log($e->getMessage() . " di " . $e->getFile() . ":" . $e->getLine());
    http_response_code(500);
    echo "Terjadi kesalahan. Silakan coba lagi.";
});

set_error_handler(function ($level, $message, $file, $line) {
    throw new ErrorException($message, 0, $level, $file, $line);
});
```

## Mode Debug vs Produksi

```php
<?php
ini_set('display_errors', '0');   // produksi: jangan tampilkan ke pengguna
ini_set('log_errors', '1');
error_log("Error: " . $e->getMessage());
```

Di development, `display_errors = 1` membantu debugging. Di produksi, selalu matikan dan arahkan ke log.

<div class="note">💡 Jangan menggunakan exception untuk alur normal (misalnya "data tidak ditemukan"). Untuk kondisi yang wajar, kembalikan `null` atau Result object.</div>

## Di Dunia Nyata

- Framework menangkap exception dan merender halaman error 500 yang ramah.
- Validasi form mengumpulkan error per field lalu ditampilkan kembali.
- Job worker mencatat exception lalu melanjutkan antrian berikutnya.
