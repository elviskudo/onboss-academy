Konstanta mirip variabel, tetapi nilainya **tidak bisa diubah** setelah didefinisikan. Cocok untuk konfigurasi yang tidak bergantung pada input.

## define() vs const

```php
<?php
define("APP_NAME", "OnBoss Academy");
const MAX_ITEM = 10;

echo APP_NAME; // OnBoss Academy
echo MAX_ITEM; // 10
```

| Aspek | `define()` | `const` |
|-------|-----------|---------|
| Waktu dibuat | Runtime | Compile time |
| Bisa di dalam if | Ya | Tidak (kecuali blok kondisional khusus) |
| Nama dinamis | Ya | Tidak |
| Nilai array | PHP 7+ | PHP 5.6+ |
| Di dalam class | Tidak | Ya |

```php
<?php
if (true) {
    define("MODE", "dev"); // ✅
    // const MODE = "dev"; // ❌ di dalam if tidak diperbolehkan
}

$nama = "DINAMIS";
define($nama, 42); // ✅ nama konstanta dari variabel
echo DINAMIS;
```

## Konstanta Class

```php
<?php
class Produk {
    const PPN = 0.11;
    const SATUAN = "pcs";

    public function hargaSetelahPajak(float $harga): float {
        return $harga * (1 + self::PPN);
    }
}

echo Produk::PPN;
echo Produk::SATUAN;
```

Akses memakai `::` (scope resolution operator). Di dalam class gunakan `self::`, `static::`, atau `parent::`.

## Magic Constants

| Konstanta | Isi |
|-----------|-----|
| `__LINE__` | Nomor baris saat ini |
| `__FILE__` | Path lengkap file |
| `__DIR__` | Direktori file |
| `__FUNCTION__` | Nama fungsi |
| `__CLASS__` | Nama class |
| `__METHOD__` | Nama class + method |
| `__NAMESPACE__` | Namespace saat ini |

```php
<?php
echo "Error di " . __FILE__ . " baris " . __LINE__;
```

Nilainya berubah tergantung lokasi pemakaian — itulah sebabnya disebut *magic*.

## Konstanta vs Environment Variable

Untuk konfigurasi yang berbeda per lingkungan (development/production), gunakan `getenv()` atau file `.env`, bukan konstanta:

```php
<?php
$dbHost = getenv("DB_HOST") ?: "localhost";
define("DB_HOST", $dbHost);
```

<div class="note">💡 `define()` menghasilkan konstanta global. `const` di dalam namespace akan menjadi `Namespace\NAMA`, jadi pemanggilannya juga perlu diawali namespace.</div>

## Di Dunia Nyata

- Versi aplikasi, batas upload, dan nama session disimpan sebagai konstanta.
- `PHP_EOL` menjaga format log tetap benar di berbagai sistem operasi.
- Konstanta class dipakai untuk status: `Order::STATUS_LUNAS`.
