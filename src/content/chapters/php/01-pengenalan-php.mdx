PHP adalah bahasa **backend** paling mapan di web: WordPress, Laravel, dan Wikipedia memakainya — sekitar sepertiga situs di internet diproses PHP. Chapter ini memetakan wajah dasarnya sebelum masuk ke tipe data dan OOP.

## Hello World

```php
<?php
echo "Halo, Dunia!";
```

Tag `<?php ... ?>` menandai bagian yang diproses server. Di luar tag itu, teks dikirim mentah ke browser sebagai HTML — jadi satu file boleh mencampur HTML dan PHP.

## 3 Tag PHP

| Tag | Fungsi | Status |
| --- | --- | --- |
| `<?php ... ?>` | Blok kode standar | **Wajib — pakai ini** |
| `<?= ekspresi ?>` | Singkatan dari `echo` | Selalu aktif, aman dipakai |
| `<? ... ?>` | Short tag | Nonaktif di konfigurasi modern — hindari |

## 3 Bentuk Komentar

```php
<?php
// satu baris
# juga satu baris (gaya lama)
/* komentar
   multi baris */
```

## 3 Fungsi Output

| Fungsi | Perilaku | Kapan dipakai |
| --- | --- | --- |
| `echo "teks"` | Cetak, boleh banyak argumen, tanpa nilai kembalian | Output normal ke halaman |
| `print "teks"` | Sama seperti echo, selalu mengembalikan `1` | Jarang — echo lebih umum |
| `var_dump($x)` | Tampilkan tipe + nilai + panjang | Debugging |

```php
<?php
$nama = "Sari";
$umur = 20;
$aktif = true;

echo "Halo $nama, umurmu $umur tahun", "\n";
echo "Status: ", ($aktif ? "aktif" : "nonaktif"), "\n";
var_dump($umur);        // int(20)
```

## Variabel dan Tipe

```php
<?php
$nama = "Sari";    // semua variabel diawali $
$umur = 20;
$aktif = true;

echo "Halo $nama, umurmu $umur tahun";
```

PHP bersifat **loosely typed**: tipe mengikuti nilai dan bisa berubah di tengah jalan. Sejak PHP 7 kamu bisa menambahkan `declare(strict_types=1);` plus type declaration agar kesalahan tipe langsung jadi fatal error — akan dibahas di chapter Function.

## 3 Cara Menjalankan PHP

```bash
php namafile.php            # 1. CLI — skrip biasa
php -S localhost:8000       # 2. web server bawaan untuk belajar
# 3. Apache/Nginx + PHP-FPM di server produksi
```

Yang kamu lakukan di editor OnBoss setara opsi 1. Di produksi, PHP dijalankan server web yang merespons request HTTP, lalu hasil HTML dikirim ke browser.

## Kenapa PHP Populer?

- **Hosting murah dan tersedia di mana-mana** — hampir semua shared hosting siap pakai.
- **Framework matang**: Laravel, Symfony, CodeIgniter.
- **Ekosistem CMS**: WordPress menguasai pasar CMS dunia.
- **API & backend**: dipadukan database MySQL/PostgreSQL dengan ORM seperti Eloquent.

## Di Dunia Nyata

- **Halaman profil kampus** — HTML statis plus `<?= $siswa['nama'] ?>` untuk menampilkan data dari database.
- **Endpoint API belanja** — file `api/produk.php` mengembalikan JSON daftar produk untuk aplikasi mobile.
- **Form pendaftaran sekolah** — data POST divalidasi PHP lalu disimpan ke MySQL.
- **Blog WordPress** — seluruh instalasi adalah PHP: tema, plugin, dan admin panelnya.
- **Skrip cron laporan** — `php laporan.php` dijadwalkan tiap malam mengirim ringkasan penjualan ke email.

<div class="note">💡 Setiap file PHP yang berisi kode harus dibuka dengan `<?php`. Lupa tag ini membuat seluruh isi file dikirim sebagai teks biasa dan browser menampilkannya mentah — termasuk kredensial database yang ada di dalamnya. Kalau yakin butuh singkatan, `<?= ... ?>` tetap aman walau short tag dimatikan.</div>
