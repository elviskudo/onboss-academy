Saat aplikasi bertambah besar, nama class seperti `User`, `Product`, atau `Config` mudah bentrok. **Namespace** memberi "folder logika" untuk mengatasi ini.

## Deklarasi

```php
<?php
namespace App\Models;

class User {
    public function __construct(public string $nama) {}
}

function formatUser(User $u): string {
    return strtoupper($u->nama);
}
```

Namespace dideklarasikan di awal file. Semua class, fungsi, dan konstanta setelahnya menjadi milik namespace tersebut.

## Menggunakan Namespace Lain

```php
<?php
namespace App\Controllers;

use App\Models\User;
use App\Services\EmailService as Mailer;

class UserController {
    public function __construct(
        private User $user,
        private Mailer $mailer
    ) {}
}
```

`use` hanya membuat alias — file tetap perlu di-autoload.

## Tiga Cara Referensi

```php
<?php
namespace App\Utils;

new \App\Models\User("Sari"); // fully qualified
new User("Sari");                 // relatif ke App\Utils
use App\Models\User;
new User("Sari");                 // lewat alias
```

Aturan resolusi: nama tanpa awalan `\` dicari relatif terhadap namespace saat ini, lalu jatuh ke global bila tidak ada.

## Namespace Global

```php
<?php
namespace {
    // kode global di sini
}
```

Kalau一处 file berisi beberapa namespace, gunakan kurawal blok seperti contoh di atas.

## Autoload PSR-4 dengan Composer

```json
{
  "autoload": {
    "psr-4": {
      "App\\": "src/"
    }
  }
}
```

Setelah `composer dump-autoload`, class `App\Models\User` otomatis dicari di `src/Models/User.php`.

```php
<?php
require __DIR__ . '/vendor/autoload.php';

$user = new App\Models\User("Sari");
```

## Sub-Namespace

```php
<?php
namespace App\Models;

echo __NAMESPACE__; // "App\Models"
```

<div class="note">💡 Nama namespace memakai backslash (`\\`), bukan slash (`/`). Di dalam string PHP, backslash harus ditulis dua kali: `"App\\Models\\User"`.</div>

## Di Dunia Nyata

- Framework modern (Laravel, Symfony) memakai PSR-4 secara menyeluruh.
- `App\Services`, `App\Repositories`, `App\Http` adalah struktur folder umum.
- Konflik dengan class bawaan PHP dihindari dengan namespace aplikasi sendiri.
