HTTP itu stateless — setiap request berdiri sendiri. **Session** dan **cookie** memberi aplikasi ingatan antar-request.

## Session

```php
<?php
session_start();

$_SESSION['nama'] = 'Sari';
$_SESSION['keranjang'] = [1, 2, 3];

echo $_SESSION['nama'];
unset($_SESSION['nama']); // hapus satu kunci
```

Alurnya:

1. `session_start()` membuat/membaca ID session.
2. ID dikirim ke browser sebagai cookie `PHPSESSID`.
3. Data session disimpan di server (default: file di `/tmp`).

## Menangani Login

```php
<?php
session_start();

if (isset($_POST['nama'])) {
    $_SESSION['user'] = trim($_POST['nama']);
    session_regenerate_id(true); // cegah session fixation
}

if (isset($_SESSION['user'])) {
    echo "Selamat datang, " . htmlspecialchars($_SESSION['user']);
} else {
    echo "Silakan login";
}
```

## Logout

```php
<?php
session_start();

$_SESSION = [];

if (ini_get("session.use_cookies")) {
    $params = session_get_cookie_params();
    setcookie(session_name(), '', time() - 42000,
        $params["path"], $params["domain"],
        $params["secure"], $params["httponly"]
    );
}

session_destroy();
```

## Cookie

```php
<?php
setcookie('tema', 'gelap', [
    'expires'  => time() + (30 * 86400),
    'path'     => '/',
    'domain'   => 'example.com',
    'secure'   => true,
    'httponly' => true,
    'samesite' => 'Lax'
]);

echo $_COOKIE['tema'] ?? 'terang';
```

Atribut penting:

| Atribut | Fungsi |
|---------|--------|
| `expires` | Waktu kedaluwarsa |
| `path` | Cakupan URL |
| `secure` | Hanya HTTPS |
| `httponly` | Tidak bisa dibaca JS |
| `samesite` | Perlindungan CSRF |

## Perbandingan

| Aspek | Session | Cookie |
|-------|---------|--------|
| Lokasi data | Server | Browser |
| Kapasitas | Besar | ±4 KB |
| Umur | Sampai dihapus/expire | Diatur expires |
| Dikirim tiap request | Hanya ID | Semua isi |

<div class="note">💡 `session_start()` harus dipanggil sebelum apa pun yang dikirim ke output (termasuk whitespace). Kalau muncul error "headers already sent", cek baris sebelum tag `<?php`.</div>

## Di Dunia Nyata

- Keranjang belanja disimpan di session sebelum checkout.
- Token "remember me" disimpan sebagai cookie HttpOnly dengan expiry 30 hari.
- Preferensi tema disimpan cookie agar bisa dibaca JS ringan di frontend.
