```php

$isi = file_get_contents("catatan.txt");
echo $isi;

// menambah tanpa menimpa — perlu FILE_APPEND
file_put_contents("catatan.txt", "Baris ketiga\n", FILE_APPEND);

    echo ($i + 1) . ": " . trim($b) . "\n";

```

Selalu periksa hasil `file_get_contents()` — ia mengembalikan `false` saat file tidak ada, bukan exception.

## 4 Blok Penanganan Error

```php
<?php
function bagi($a, $b): float {
    if ($b == 0) {
        throw new InvalidArgumentException("Pembagi tidak boleh nol");
    }
    return $a / $b;
}

try {
    echo bagi(10, 2);
    echo bagi(10, 0);
} catch (InvalidArgumentException $e) {
    echo "Terjebak: " . $e->getMessage();
} finally {
    echo "Selesai diproses";
}
```

| Blok | Fungsi |
| --- | --- |
| `throw` | Melempar error — eksekusi berhenti dan mencari `catch` terdekat |
| `try` | Kode yang rawan gagal |
| `catch` | Menangkap; boleh ditumpuk untuk banyak tipe (yang generik di akhir) |
| `finally` | Selalu berjalan — tempat menutup file/koneksi |

PHP 7 memecah `Throwable` jadi **2 cabang**: `Exception` (kegagalan bisnis: data tidak valid, file tidak ada) dan `Error` (kesalahan coding: `TypeError`, `DivisionByZeroError`). Menangkap `Throwable` mencakup keduanya.

## Pesan Error yang Aman

```php
<?php
try {
    $data = file_get_contents("config.json");
    if ($data === false) {
        throw new RuntimeException("Gagal memuat config");
    }
} catch (RuntimeException $e) {
    error_log($e->getMessage());               // 1. detail → log server
    echo "Terjadi kesalahan. Silakan coba lagi."; // 2. pesan ramah → user
}
```

3 aturan: pesan umum ke user, detail ke `error_log`, dan `display_errors = Off` di produksi.

## Cek Berkas dan Folder

```php
<?php
var_dump(file_exists("data.txt"));   // bool
var_dump(is_file("data.txt"));
var_dump(is_dir("folder"));
var_dump(is_writable("folder"));     // penting sebelum menulis
```

## Di Dunia Nyata

- **Menyimpan unggahan**: cek `is_uploaded_file()` + `move_uploaded_file()` ke luar folder publik.
- **Log aplikasi harian**: `file_put_contents("log/app-" . date("Y-m-d") . ".log", $pesan, FILE_APPEND | LOCK_EX)`.
- **Membaca konfigurasi**: `file_get_contents` + `json_decode` saat boot; gagal → `RuntimeException` yang menghentikan aplikasi jelas, bukan error aneh di tengah.
- **Rotasi backup**: `copy("db.sqlite", "backup/db-" . date("Ymd") . ".sqlite")` lalu `unlink` file lama.
- **Ekspor laporan CSV**: `fopen` mode `w`, `fputcsv` per baris, `fclose` di `finally`.

<div class="note">💡 Jangan pernah menampilkan `getMessage()` mentah dari error sistem ke user di produksi. Path file dan stack trace adalah peta bagi penyerang — catat detail lengkap ke log (`error_log`) dan tampilkan hanya pesan ramah. Error yang detailnya disembunyikan dari user tetap harus terlihat jelas olehmu di log.</div>
