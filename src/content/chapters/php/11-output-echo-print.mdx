Output adalah jembatan antara logika PHP dan apa yang dilihat pengguna. PHP bisa mencetak ke halaman HTML, ke terminal, atau ke file log.

## echo vs print

```php
<?php
echo "Halo";
echo "Dunia", " lagi"; // beberapa argumen boleh

print "Halo";
// print "a", "b"; // ❌ tidak boleh lebih dari satu argumen
```

| Aspek | echo | print |
|-------|------|-------|
| Jenis | Language construct | Fungsi |
| Nilai balik | none | `1` |
| Beberapa argumen | Boleh | Tidak |
| Kecepatan | Sedikit lebih cepat | Sedikit lebih lambat |

## Interpolasi String

```php
<?php
$nama = "Sari";
$umur = 20;

echo "Halo, $nama! Umur $umur tahun.\n"; // kutip ganda → variabel dibaca
echo 'Halo, $nama!';                      // kutip tunggal → teks apa adanya
echo "Nilai: {$umur}th\n";               // kurawal memisahkan variabel
```

Kurawal `{}` penting kalau variabel diikuti huruf, misalnya `"{$umur}th"` supaya tidak dibaca sebagai variabel `$umurth`.

## Concatenation

```php
<?php
echo "Halo " . $nama . "!";
echo "Total: " . (10 + 5); // hasil hitungan harus pakai tanda kurung
```

Operator `.` juga bisa dipakai sebagai `.=`:

```php
$pesan = "Halo";
$pesan .= " dunia!";
```

## Debugging Output

```php
<?php
$data = ["nama" => "Sari", "skor" => [8, 9]];

print_r($data);                    // manusia-friendly
var_dump($data);                   // lengkap dengan tipe dan panjang
error_log(print_r($data, true));   // kirim ke log, bukan ke layar
```

Argumen kedua `print_r` bernilai `true` membuat hasil dikembalikan sebagai string, bukan langsung dicetak.

## Escape Karakter

| Kode | Arti |
|------|------|
| `\n` | Baris baru (di kutip ganda) |
| `\t` | Tab |
| `\"` | Tanda kutip ganda |
| `\\` | Backslash |
| `\$` | Tanda dolar literal |

<div class="note">💡 Di browser, `\n` tidak membuat baris baru karena HTML memakai `<br>`. Gunakan `nl2br()` kalau ingin newline tampil sebagai baris baru di halaman.</div>

## Di Dunia Nyata

- Template PHP sering memakai `<?= $nama ?>` — shorthand untuk `<?php echo $nama ?>`.
- Output JSON dari API memakai `json_encode()`, bukan `echo` langsung pada array.
- Logging error memakai `error_log()` agar tidak mengganggu tampilan pengguna.
