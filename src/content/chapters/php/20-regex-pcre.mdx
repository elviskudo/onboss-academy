PHP memakai mesin regex **PCRE** (Perl Compatible Regular Expressions). Fungsi-fungsinya diawali `preg_`.

## Fungsi Utama

| Fungsi | Fungsi |
|--------|--------|
| `preg_match()` | Cari kecocokan pertama |
| `preg_match_all()` | Semua kecocokan |
| `preg_replace()` | Ganti teks |
| `preg_split()` | Pecah string |
| `preg_quote()` | Escape karakter khusus |
| `preg_last_error()` | Error regex terakhir |

## Delimiter

```php
<?php
preg_match('/halo/i', 'Halo Dunia'); // slash
preg_match('#https?://#', $url);     // # lebih nyaman untuk URL
preg_match('~\d+~', 'abc123');      // tilde juga valid
```

Delimiter bisa karakter non-alphanumerik apa pun. Pilih yang tidak banyak muncul dalam pola agar tidak perlu escape.

## Contoh Pencarian

```php
<?php
$teks = "Produk: Kopi (12), Teh (8)";

if (preg_match('/(\w+)\s*\((\d+)\)/', $teks, $m)) {
    echo $m[1]; // Kopi
    echo $m[2]; // 12
}

preg_match_all('/\d+/', $teks, $semua);
print_r($semua[0]); // ["12", "8"]
```

## Regex Dasar

| Pola | Arti |
|------|------|
| `\d` | Digit |
| `\w` | Huruf, angka, underscore |
| `\s` | Spasi |
| `.` | Karakter apa pun kecuali newline |
| `^` / `$` | Awal / akhir string |
| `+` `*` `?` | Quantifier |
| `[abc]` | Salah satu dari a, b, c |
| `(...)` | Grup capture |
| `\b` | Batas kata |

## Validasi Input

```php
<?php
$email = "sari@example.com";
$polas = [
    'email' => '/^[^\s@]+@[^\s@]+\.[^\s@]+$/',
    'telepon' => '/^(\+62|0)8[0-9]{8,11}$/',
    'kode' => '/^[A-Z]{2}-\d{4}$/'
];

foreach ($polas as $nama => $pola) {
    printf("%s: %s\n", $nama, preg_match($pola, $email) ? 'valid' : 'tidak valid');
}
```

## preg_replace dengan Callback

```php
<?php
$teks = "harga 10000 dan 20000";
$hasil = preg_replace_callback('/\d+/', function ($m) {
    return number_format((int) $m[0], 0, ',', '.');
}, $teks);
// harga 10.000 dan 20.000
```

## Modifiers Umum

| Modifier | Arti |
|----------|------|
| `i` | Case-insensitive |
| `m` | `^`/`$` per baris |
| `s` | `.` termasuk newline |
| `u` | Mode UTF-8 |

Untuk teks Indonesia dengan karakter seperti `é`, selalu pakai modifier `u`.

<div class="note">💡 Regex bukan parser HTML. Gunakan `DOMDocument` atau library HTML parser untuk memproses markup.</div>

## Di Dunia Nyata

- Membersihkan slug: `preg_replace('/[^a-z0-9]+/', '-', strtolower($judul))`.
- Validasi kode pos dan nomor telepon.
- Router framework memakai regex untuk mencocokkan pola URL.
