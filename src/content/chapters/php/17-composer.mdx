Composer adalah package manager standar PHP. Ia mengunduh library, mengelola versi, dan menyediakan autoloading otomatis.

## File composer.json

```json
{
  "name": "onboss/belajar-php",
  "description": "Proyek belajar PHP",
  "type": "project",
  "require": {
    "php": ">=8.1",
    "monolog/monolog": "^3.0",
    "vlucas/phpdotenv": "^5.6"
  },
  "require-dev": {
    "phpunit/phpunit": "^10.0"
  },
  "autoload": {
    "psr-4": {
      "App\\": "src/"
    },
    "files": ["src/helpers.php"]
  },
  "scripts": {
    "test": "phpunit",
    "serve": "php -S localhost:8000 -t public"
  }
}
```

## Perintah Penting

| Perintah | Fungsi |
|----------|--------|
| `composer init` | Membuat composer.json interaktif |
| `composer require paket` | Tambah dependensi |
| `composer install` | Pasang sesuai lockfile |
| `composer update` | Update versi sesuai constraint |
| `composer dump-autoload` | Regenerate autoloader |
| `composer show` | Lihat paket terpasang |
| `composer validate` | Cek keabsahan composer.json |

## Constraint Versi

| Notasi | Arti |
|--------|------|
| `^3.0` | >=3.0.0 dan &lt;4.0.0 |
| `~3.2` | >=3.2 dan &lt;4.0 |
| `3.2.*` | Patch apa pun di 3.2 |
| `>=8.1` | PHP 8.1 atau lebih baru |
| `dev-main` | Branch development |

## Autoloading

```php
<?php
require __DIR__ . '/vendor/autoload.php';

$log = new Monolog\Logger('app');
```

Cukup satu `require` — Composer yang mencari file class sesuai aturan PSR-4.

Setelah menambah namespace atau file helper baru:

```bash
composer dump-autoload -o
```

Flag `-o` mengoptimalkan dengan menghasilkan classmap.

## Script Composer

```bash
composer test
composer serve
```

Script memudahkan tim menjalankan perintah yang sama tanpa menghafal argumen panjang.

## vendor/ dan .gitignore

Folder `vendor/` **tidak** disimpan di Git. Yang disimpan adalah `composer.json` dan `composer.lock`. Saat deploy, jalankan `composer install --no-dev --optimize-autoloader`.

<div class="note">💡 Selalu commit composer.lock untuk aplikasi. Tanpa itu, tiap installation bisa mendapat versi berbeda dan perilakunya berubah-ubah.</div>

## Di Dunia Nyata

- Laravel dibangun di atas Composer dengan ratusan paket.
- `phpdotenv` memuat `.env` menjadi `$_ENV`/`getenv()`.
- `monolog` mencatat log aplikasi ke file, Slack, atau syslog.
