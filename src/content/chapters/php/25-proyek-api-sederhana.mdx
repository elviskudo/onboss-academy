Proyek penutup merangkai hampir semua materi sebelumnya: session tidak dipakai di sini, tapi routing, PDO, JSON, validasi, dan exception bekerja bersama.

## Struktur

```
api/
  index.php       → front controller
  config.php      → koneksi PDO
  src/
    ProdukRepository.php
```

## Front Controller

```php
<?php
// api/index.php
require __DIR__ . '/config.php';

header('Content-Type: application/json; charset=utf-8');

$method = $_SERVER['REQUEST_METHOD'];
$path   = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);

function respons(int $kode, array $data): never {
    http_response_code($kode);
    echo json_encode($data, JSON_UNESCAPED_UNICODE);
    exit;
}

try {
    if ($method === 'GET' && $path === '/api/produk') {
        $repo = new ProdukRepository($pdo);
        respons(200, ['data' => $repo->semua()]);
    }

    if ($method === 'POST' && $path === '/api/produk') {
        $body = json_decode(file_get_contents('php://input'), true, 512, JSON_THROW_ON_ERROR);

        $nama = trim($body['nama'] ?? '');
        $harga = (int) ($body['harga'] ?? 0);

        if ($nama === '' || $harga <= 0) {
            respons(422, ['error' => 'nama dan harga wajib valid']);
        }

        $repo = new ProdukRepository($pdo);
        $id = $repo->buat($nama, $harga);
        respons(201, ['id' => $id, 'nama' => $nama]);
    }

    respons(404, ['error' => 'Endpoint tidak ditemukan']);
} catch (JsonException $e) {
    respons(400, ['error' => 'JSON tidak valid']);
} catch (Throwable $e) {
    error_log($e->getMessage());
    respons(500, ['error' => 'Kesalahan server']);
}
```

## Repository

```php
<?php
class ProdukRepository {
    public function __construct(private PDO $pdo) {}

    public function semua(): array {
        return $this->pdo
            ->query('SELECT id, nama, harga FROM produk ORDER BY id DESC')
            ->fetchAll(PDO::FETCH_ASSOC);
    }

    public function buat(string $nama, int $harga): int {
        $stmt = $this->pdo->prepare(
            'INSERT INTO produk (nama, harga) VALUES (?, ?)'
        );
        $stmt->execute([$nama, $harga]);
        return (int) $this->pdo->lastInsertId();
    }
}
```

## Menguji API

```bash
curl http://localhost:8000/api/produk
curl -X POST http://localhost:8000/api/produk   -H 'Content-Type: application/json'   -d '{"nama":"Kopi","harga":25000}'
```

## Catatan Keamanan

- Selalu gunakan prepared statement.
- Validasi dan sanitasi semua input.
- Jangan tampilkan `getMessage()` mentah di produksi — cukup log di server.
- Tambahkan autentikasi (API key/JWT) untuk endpoint sensitif.

<div class="note">💡 Fungsi `respons()` di atas memakai return type `never` (PHP 8.1+) karena selalu diakhiri `exit` — sinyal bagus untuk compiler dan pembaca kode.</div>

## Rangkuman Seri

Dari variabel dasar hingga REST API, PHP menyediakan semuanya tanpa framework. Begitu fondasi ini kuat, mempelajari Laravel atau Symfony menjadi jauh lebih mudah karena konsepnya sama — hanya dibungkus dengan struktur yang lebih rapi.
