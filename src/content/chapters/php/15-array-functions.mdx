Array adalah struktur data paling penting di PHP. Fungsi bawaan yang tepat bisa menggantikan puluhan baris loop.

## Fungsi Dasar

| Fungsi | Fungsi |
|--------|--------|
| `count()` | Jumlah elemen |
| `array_push()` / `$arr[]` | Tambah di akhir |
| `array_pop()` | Ambil elemen terakhir |
| `array_shift()` | Ambil elemen pertama |
| `array_unshift()` | Tambah di awal |
| `in_array()` | Cek keberadaan nilai |
| `array_search()` | Cari kunci berdasarkan nilai |
| `array_key_exists()` | Cek keberadaan kunci |
| `array_merge()` | Gabungkan array |
| `range()` | Buat array rentang |

## Sorting

```php
<?php
$angka = [3, 1, 2];
sort($angka);               // [1,2,3], key di-index ulang
rsort($angka);              // descending

$nama = ["Budi", "Andi", "Sari"];
sort($nama, SORT_STRING);
asort($nama);               // sort by value, key dipertahankan
ksort($data);               // sort by key
usort($produk, fn($a, $b) => $a['harga'] <=> $b['harga']);
```

Operator spaceship `&lt;=>` mengembalikan -1, 0, atau 1 — sangat cocok untuk callback sorting.

## Map, Filter, Reduce

```php
<?php
$angka = [1, 2, 3, 4];

$digandakan = array_map(fn($n) => $n * 2, $angka);
$genap = array_filter($angka, fn($n) => $n % 2 === 0);
$total = array_reduce($angka, fn($carry, $n) => $carry + $n, 0);
```

| Fungsi | Hasil |
|--------|-------|
| `array_map` | Array baru, panjang sama |
| `array_filter` | Array dengan elemen lolos syarat |
| `array_reduce` | Satu nilai akumulasi |

`array_filter` mempertahankan kunci asli — gunakan `array_values()` kalau ingin index ulang.

## Array Asosiatif

```php
<?php
$user = ["nama" => "Sari", "umur" => 20];

echo $user["nama"];
$user["email"] = "sari@example.com";
unset($user["umur"]);

print_r(array_keys($user));
print_r(array_values($user));
```

## Segmentasi

```php
<?php
$daftar = [1, 2, 3, 4, 5];

array_slice($daftar, 1, 3);        // [2,3,4]
array_splice($daftar, 1, 2);       // menghapus dan mengembalikan [2,3]
array_chunk($daftar, 2);           // [[1,2],[3,4],[5]]
array_reverse($daftar);
array_unique([1, 1, 2]);           // [1,2]
```

## Arrow Function (PHP 7.4+)

```php
<?php
$faktor = 3;
$hasil = array_map(fn($x) => $x * $faktor, [1, 2, 3]);
```

Arrow function otomatis menangkap variabel dari scope luar, tidak seperti `function () use ($faktor)`.

<div class="note">💡 `sort()` mengubah array asli. Simpan ke variabel baru atau pakai `array_slice()` dulu kalau data awal masih diperlukan.</div>

## Di Dunia Nyata

- Menghitung total belanja dengan `array_reduce`.
- Mengurutkan produk berdasarkan harga dengan `usort`.
- Membuat pagination dengan `array_slice($data, $offset, $limit)`.
