PHP hanya mendukung single inheritance — sebuah class punya satu induk. **Trait** dan **interface** melengkapi kekurangan ini dengan cara berbeda.

## Interface = Kontrak

```php
<?php
interface BisaBayar {
    public function bayar(float $jumlah): bool;
    public function riwayat(): array;
}

class Dompet implements BisaBayar {
    public function bayar(float $jumlah): bool {
        return $jumlah > 0;
    }

    public function riwayat(): array {
        return [];
    }
}
```

Semua method interface bersifat publik dan harus diimplementasikan. Interface bisa有多个, dipisah koma:

```php
class Dompet implements BisaBayar, BisaEkspor {}
```

Interface juga bisa mewaris dari interface lain dengan `extends`.

## Trait = Kode Siap Pakai

```php
<?php
trait Timestampable {
    public string $dibuat;

    public function setDibuat(string $waktu): void {
        $this->dibuat = $waktu;
    }
}

trait Loggable {
    public function log(string $pesan): void {
        echo "[LOG] " . date('H:i:s') . " $pesan\n";
    }
}

class Artikel {
    use Timestampable, Loggable;
}

$a = new Artikel();
$a->setDibuat('2026-01-01');
$a->log('Artikel dibuat');
```

Trait tidak bisa di-instantiasi, tapi method-nya menjadi bagian dari class.

## Konflik Method

```php
<?php
trait A {
    public function jalankan(): string { return "A"; }
}
trait B {
    public function jalankan(): string { return "B"; }
}

class C {
    use A, B {
        A::jalankan insteadof B;
        B::jalankan as jalankanB;
    }
}
```

`insteadof` memilih mana yang dipakai; `as` membuat alias untuk yang lain.

## Mengubah Visibilitas

```php
<?php
class Rahasia {
    use Loggable {
        log as protected;
    }
}
```

## Interface vs Abstract Class

| Aspek | Interface | Abstract class |
|-------|-----------|----------------|
| Implementasi | Tidak ada | Boleh ada |
| Multiple | Boleh banyak | Satu saja |
| Properti | Tidak bisa | Bisa |
| Konstanta | Bisa (PHP 8.2+) | Bisa |

Gunakan interface untuk "bisa melakukan apa", abstract class untuk "bagian bersama dari siapa".

<div class="note">💡 Trait sebaiknya tidak menyimpan state yang kompleks. Kalau mulai butuh properti dan konstruktor, pertimbangkan komposisi atau abstract class.</div>

## Di Dunia Nyata

- Laravel memakai trait `SoftDeletes` untuk menambah perilaku hapus lembut pada model.
- Interface `JsonSerializable` memungkinkan class mengatur hasil `json_encode()`.
- Repository pattern mendefinisikan interface `UserRepository` agar mudah di-mock saat testing.
