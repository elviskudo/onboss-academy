Superglobal adalah array bawaan PHP yang otomatis tersedia di seluruh skrip. Memahaminya penting karena hampir semua input aplikasi web lewat jalur ini.

## Daftar Superglobal

| Superglobal | Isi |
|-------------|-----|
| `$_GET` | Data dari URL query string |
| `$_POST` | Data dari form method POST |
| `$_REQUEST` | Gabungan GET, POST, cookie (jarang disarankan) |
| `$_SERVER` | Informasi server & request |
| `$_FILES` | File yang di-upload |
| `$_COOKIE` | Cookie dari browser |
| `$_SESSION` | Data sesi pengguna |
| `$_ENV` | Variabel lingkungan |
| `$GLOBALS` | Semua variabel global |

## Membaca $_GET Aman

```php
<?php
// URL: /produk.php?id=12&q=kopi
$id  = isset($_GET['id']) ? (int) $_GET['id'] : 0;
$q   = $_GET['q'] ?? '';
$hal = max(1, (int) ($_GET['hal'] ?? 1));
```

Operator null coalescing `??` menyederhanakan pengecekan `isset`. Selalu cast ke tipe yang diharapkan sebelum dipakai.

## Informasi $_SERVER yang Sering Dipakai

```php
<?php
$_SERVER['REQUEST_METHOD'];   // GET / POST
$_SERVER['REQUEST_URI'];      // /path?query=1
$_SERVER['HTTP_HOST'];        // domain
$_SERVER['REMOTE_ADDR'];      // IP klien
$_SERVER['HTTP_USER_AGENT'];  // identitas browser
$_SERVER['HTTPS'];            // ada atau tidak
$_SERVER['SCRIPT_NAME'];      // path skrip
```

`REMOTE_ADDR` bisa bukan IP asli kalau aplikasi di balik proxy — perhatikan header `X-Forwarded-For` dengan hati-hati (bisa dipalsukan).

## Superglobal di Fungsi

```php
<?php
function tampilkanUser(): void {
    echo $_GET['nama'] ?? 'Anonim'; // langsung bisa, tanpa global
}
```

Berbeda dengan variabel global biasa yang butuh `global $var;` di dalam fungsi.

## Filtrasi Input

```php
<?php
$nama = trim($_POST['nama'] ?? '');
$email = filter_input(INPUT_POST, 'email', FILTER_VALIDATE_EMAIL);
$id = filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT);

if ($email === false) {
    echo "Email tidak valid";
}
```

Gunakan `htmlspecialchars()` saat mencetak nilai ke HTML:

```php
echo htmlspecialchars($nama, ENT_QUOTES, 'UTF-8');
```

<div class="note">💡 `$_REQUEST` menggabungkan sumber input dan urutannya bisa diatur php.ini. Lebih baik eksplisit: pakai `$_GET` atau `$_POST` sesuai kebutuhan.</div>

## Di Dunia Nyata

- Routing sederhana memakai `$_SERVER['REQUEST_URI']`.
- Form login membaca `$_POST['email']` dan `$_POST['password']`.
- File konfigurasi membedakan environment dari `$_SERVER['HTTP_HOST']`.
