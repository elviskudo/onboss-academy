PHP tidak mewajibkan deklarasi tipe, tetapi tetap punya 8 tipe data yang jelas di balik layar. Memahaminya mencegah bug perhitungan dan konversi yang menyesatkan — terutama karena PHP suka mengonversi otomatis.

## 8 Tipe Data PHP

| # | Tipe | Kelompok | Contoh | Kapan dipakai |
| --- | --- | --- | --- | --- |
| 1 | `string` | scalar | `"Halo"`, `'Halo'` | Teks, JSON, HTML |
| 2 | `int` | scalar | `42`, `-7` | Hitungan bulat, id, kuantitas |
| 3 | `float` | scalar | `3.14` | Desimal, rata-rata |
| 4 | `bool` | scalar | `true`, `false` | Hasil perbandingan |
| 5 | `array` | compound | `["a", "b"]` | Daftar, kunci-nilai, tabel |
| 6 | `object` | compound | `new Siswa()` | Instans dari class |
| 7 | `resource` | khusus | handle `fopen()` | Koneksi file/db yang terbuka |
| 8 | `null` | khusus | `null` | "tidak ada nilai" |

```php
<?php
$teks    = "Halo";    // string
$angka   = 42;        // int
$desimal = 3.14;      // float
$benar   = true;      // bool
$kosong  = null;      // null

var_dump($angka);     // int(42)
echo gettype($teks);  // string
```

**Nilai default**: variabel yang belum pernah ditugaskan dibaca sebagai `null` dan memunculkan warning — selalu inisialisasi. Array tanpa kunci yang ada juga `null` (peringatan *undefined array key*).

## 4 Jenis Scope

| # | Scope | Deklarasi | Cakupan |
| --- | --- | --- | --- |
| 1 | Local | `$nama = ...` di dalam fungsi | Hanya di dalam fungsi itu |
| 2 | Global | `global $konfig;` lalu pakai | Seluruh program |
| 3 | Static | `static $jumlah = 0;` | Bertahan antar pemanggilan fungsi |
| 4 | Magic | `$this` | Objek yang sedang berjalan (di dalam class) |

```php
<?php
function hitung() {
    static $panggilan = 0;   // tidak direset tiap panggilan
    $panggilan++;
    return $panggilan;
}
echo hitung(), hitung();     // 12
```

## Single vs Double Quote

```php
<?php
$nama = "Sari";
echo "Halo $nama\n";     // Halo Sari + baris baru
echo 'Halo $nama';       // literal: Halo $nama
```

Interpolasi `$variabel` dan escape `\n` hanya bekerja di kutip ganda.

## 6 Casting

| Cast | Fungsi | Contoh | Hasil |
| --- | --- | --- | --- |
| `(int)` | Ke bilangan bulat | `(int) "12abc"` | `12` |
| `(float)` | Ke desimal | `(float) "3.5"` | `3.5` |
| `(string)` | Ke teks | `(string) 99` | `"99"` |
| `(bool)` | Ke boolean | `(bool) ""` | `false` |
| `(array)` | Ke array | `(array) 5` | `[5]` |
| `(object)` | Ke object | `(object) ["a" => 1]` | objek dengan properti `a` |

## Type Juggling: Konversi Otomatis

```php
<?php
var_dump("10" + 5);        // int(15)
var_dump("12abc" + 5);     // int(17) + warning non-numeric
var_dump(true + true);     // int(2)
var_dump(10 / 3);          // float(3.333...) — beda dengan Ruby
```

Jebakan klasik: `0 == "abc"` dan `0 == ""` **false di PHP 8** (di PHP 7 masih true), sedangkan `"5" == "5.0"` tetap **true** karena keduanya string numerik. Selalu bandingkan dengan `===` bila tipe ikut berarti.

## 2 Cara Membuat Konstanta

```php
<?php
define("PPN", 0.11);
const NAMA_APLIKASI = "OnBoss";

echo PPN * 100000;              // 11000
echo NAMA_APLIKASI;
```

Konstanta tidak diawali `$` dan tidak boleh diubah; `define()` dipakai saat runtime (misal dari file konfigurasi), `const` hanya di scope file/class.

## Di Dunia Nyata

- **Input form**: `(int) ($_POST['qty'] ?? 0)` — string `"3"` dari form jadi angka aman sebelum dikali harga.
- **Konfigurasi aplikasi**: `const BASE_URL = "https://..."` dipakai seluruh modul tanpa risiko tertimpa.
- **Perhitungan pajak/PPN**: `$total + $total * PPN` dengan PPN sebagai konstanta — satu sumber kebenaran.
- **Flag status**: `$aktif = (bool) $row['aktif']` saat membaca kolom `0/1` dari database.
- **Membaca query string**: `filter_var($_GET['halaman'] ?? 1, FILTER_VALIDATE_INT)` menolak nilai yang bukan angka.

<div class="note">💡 PHP mengonversi tipe secara diam-diam (type juggling): `"10" + 5` jadi 15, tapi `"dua" + 5` memicu warning dan dianggap 0. Konversi yang aman hanya terjadi di **batas data tak terpercaya** — cast atau `filter_var` begitu data masuk dari form/URL, lalu gunakan `===` di seluruh kondisi di dalam logika.</div>
