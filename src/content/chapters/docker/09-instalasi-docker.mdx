Docker Engine terdiri dari **daemon** (`dockerd`), **CLI** (`docker`), dan API. Di Linux daemon berjalan sebagai layanan sistem; di macOS dan Windows ia hidup di dalam mesin virtual ringan yang dikelola Docker Desktop.

## Linux

```bash
curl -fsSL https://get.docker.com | sh
sudo systemctl enable --now docker
sudo usermod -aG docker $USER   # logout/login agar grup aktif
docker run hello-world
```

 paket dari repositori distro juga bisa dipakai, tetapi script resmi memberi versi yang lebih mutakhir.

## macOS dan Windows

Pasang **Docker Desktop** dari situs resminya. Setelah instalasi, buka aplikasi sampai statusnya *Running*. Buka Terminal atau PowerShell lalu jalankan `docker --version`. Arsitektur Apple Silicon perlu memilih image `linux/arm64` atau memakai emulasi untuk `linux/amd64`.

## Verifikasi dan Informasi

```bash
docker version        # client + server
docker info           # detail daemon
docker run hello-world
```

Perintah terakhir menarik image dari registry, membuat container, lalu mencetak pesan sukses. Bila gagal, periksa apakah daemon berjalan dan apakah mesin punya akses internet.

<div class="note">💡 Menambahkan user ke grup `docker` setara dengan memberi hak root: socket `/var/run/docker.sock` bisa dipakai untuk mounting folder sistem. Berikan hanya pada akun yang benar-benar dipercaya.</div>
