Alur kerja harian Docker berputar pada beberapa perintah. Menguasainya membuat eksperimen jadi cepat: tarik image, jalankan, amati, lalu bersihkan.

## Image vs Container

| Perintah | Objek | Fungsi |
|---|---|---|
| `docker pull nginx:alpine` | Image | Unduh image ke mesin lokal |
| `docker images` | Image | Lihat image tersimpan |
| `docker run ...` | Container | Buat container baru dari image |
| `docker ps -a` | Container | Lihat semua container, aktif dan mati |
| `docker rm` | Container | Hapus container yang sudah berhenti |
| `docker rmi` | Image | Hapus image lokal yang tidak dipakai |

## Menjalankan Container

```bash
docker run -d --name web -p 8080:80 nginx:alpine
docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'
```

`-d` = detached, `--name` = nama yang mudah diingat, `-p host:container` = pemetaan port. Tanpa `-p`, container tetap berjalan tetapi port-nya tidak bisa diakses dari host.

## Siklus Hidup Container

```bash
docker stop web      # kirim SIGTERM, tunggu, lalu SIGKILL
docker start web     # jalankan lagi dengan konfigurasi semula
docker restart web   # stop + start
docker pause web     # bekukan proses (SIGSTOP)
docker unpause web
docker rm -f web     # paksa hapus meski masih jalan
```

Container yang dihapus kehilangan seluruh perubahan pada lapisan writable-nya. Data yang ingin bertahan harus disimpan di volume atau bind mount.

## Logs dan Inspeksi

```bash
docker logs -f web          # ikuti log seperti tail -f
docker logs --tail 50 web
docker inspect web          # detail JSON konfigurasi & jaringan
docker top web              # proses di dalam container
docker stats --no-stream    # pemakaian CPU/memori
```

`docker inspect` sangat berguna saat port tidak terhubung atau environment variable tidak terbaca.

## Membersihkan yang Menumpuk

```bash
docker container prune   # hapus container yang berhenti
docker image prune -a    # hapus image tanpa container
docker system df         # lihat pemakaian disk
docker system prune      # bersihkan semua resource tidak terpakai
```

<div class="note">💡 `docker system prune` tidak menghapus volume secara default. Tambahkan `--volumes` hanya jika kamu yakin tidak ada data penting di dalamnya.</div>
