## Warna

CSS menerima warna dalam beberapa format:

```css
color: red;                  /* nama warna */
color: #4F46E5;              /* HEX */
color: rgb(79, 70, 229);     /* RGB */
color: hsl(245, 75%, 59%);   /* Hue-Saturation-Lightness */
color: rgb(79 70 229 / 0.8); /* dengan transparansi */
```

HSL paling mudah disetel: ubah `hue` untuk ganti warna, `lightness` untuk terang/gelap.

Ada **5 format warna modern yang umum**:

| Format | Contoh | Kekuatan | Kapan dipakai |
|--------|--------|----------|---------------|
| Keyword | `red` | Mudah dibaca | Demo cepat |
| HEX | `#4F46E5` | Ringkas, umum di desain | Token warna solid |
| RGB(A) | `rgb(79 70 229 / .8)` | Kanal & alpha jelas | Transparansi |
| HSL(A) | `hsl(245 75% 59%)` | Mudah ubah hue/lightness | Variasi tema |
| `currentColor` | `border-color: currentColor` | Mengikuti warna teks | Ikon/border adaptif |

## Tipografi

```css
body {
  font-family: 'Plus Jakarta Sans', system-ui, sans-serif;
  font-size: 16px;
  line-height: 1.7;
  color: #17181D;
}

h1 {
  font-size: 2.5rem;   /* 2.5 × font root */
  font-weight: 800;
  letter-spacing: -0.02em;
}

.italic { font-style: italic; }
```

### Font Shorthand

```css
font: italic 700 16px/1.6 'Inter', sans-serif;
/* gaya | ketebalan | ukuran/baris | keluarga */
```

<div class="note">💡 Selalu akhiri daftar <code>font-family</code> dengan generic: <code>sans-serif</code>, <code>serif</code>, atau <code>monospace</code> — jaring pengaman jika font utama gagal dimuat.</div>

## Jarak Teks

```css
p {
  margin-bottom: 1rem;    /* jarak luar */
  letter-spacing: 0.05em; /* jarak antar huruf */
  text-transform: uppercase;
  text-decoration: underline;
}
```

## Di Dunia Nyata

- **Portal berita** — `line-height` lega dan lebar `65ch` menjaga artikel nyaman dibaca
- **Brand perusahaan** — HEX/token memastikan warna identitas sama di tombol dan heading
- **Dashboard data** — warna status selalu dibantu teks/ikon agar tidak bergantung pada warna
- **Aplikasi multibahasa** — font fallback menampilkan aksara yang tidak tersedia di font utama
