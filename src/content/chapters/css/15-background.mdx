Properti `background` bukan hanya soal warna. Kamu bisa menumpuk warna, gambar, gradien, dan mengatur bagaimana semuanya diposisikan.

## Properti Background Inti

| Properti | Fungsi | Nilai umum |
|----------|--------|------------|
| `background-color` | Warna dasar | `#fff`, `transparent` |
| `background-image` | Gambar/gradien | `url(...)`, `linear-gradient(...)` |
| `background-repeat` | Pengulangan | `repeat`, `no-repeat`, `repeat-x` |
| `background-position` | Posisi awal | `center`, `top right`, `50% 20%` |
| `background-size` | Ukuran | `cover`, `contain`, `100px auto` |
| `background-attachment` | Perilaku saat scroll | `scroll`, `fixed`, `local` |
| `background-origin` | Titik awar ukuran | `border-box`, `padding-box`, `content-box` |

## Shorthand

```css
.hero {
  background: #222 url('pemandangan.jpg') center / cover no-repeat fixed;
}
```

Urutan shorthand yang aman: `color image position / size repeat attachment origin clip`. Tanda `/` memisahkan posisi dan ukuran.

## Beberapa Gambar Sekaligus

CSS mendukung multiple background — gambar pertama berada paling depan:

```css
.hero {
  background-image:
    linear-gradient(rgb(0 0 0 / 0.45), rgb(0 0 0 / 0.45)),
    url('pemandangan.jpg');
  background-size: cover, cover;
  background-position: center, center;
}
```

Teknik ini sering dipakai supaya teks tetap terbaca di atas foto tanpa menambah elemen overlay.

## cover vs contain

- `cover` — gambar memenuhi seluruh area, rasio terjaga, bagian tertentu bisa terpotong.
- `contain` — seluruh gambar terlihat, area kosong bisa tersisa.

<div class="note">💡 Gambar latar tidak punya teks alternatif. Kalau gambar membawa informasi (grafik, teks), pakai elemen `<img>` dengan atribut `alt`.</div>

## Di Dunia Nyata

- Header situs memakai `cover` + gradien gelap agar judul tetap kontras.
- Pola subtil memakai gambar kecil dengan `repeat` (noise, dots, grid).
- Ikon CSS sering dibuat dari gambar kecil dengan `no-repeat` dan `background-position` (sprite).
- Halaman login memakai `fixed` supaya latar tidak ikut bergeser saat form panjang digulir.
