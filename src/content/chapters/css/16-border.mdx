**Border** adalah garis di tepi kotak elemen — tepat di luar padding dan di dalam margin. Border bisa jadi pemisah halus, penanda status, atau elemen dekoratif itu sendiri.

## Tiga Komponen Border

```css
.kotak {
  border-width: 2px;
  border-style: solid;
  border-color: #4F46E5;
}
```

Ketiganya bisa dirangkum:

```css
.kotak { border: 2px solid #4F46E5; }
```

Urutannya bebas, tapi kebiasaan orang: **lebar → gaya → warna**.

## Gaya Garis

| Nilai | Tampilan |
|-------|----------|
| `solid` | Garis penuh |
| `dashed` | Putus-putus panjang |
| `dotted` | Titik-titik |
| `double` | Dua garis paralel |
| `groove` / `ridge` | Efek timbul/cekung |
| `inset` / `outset` | Efek tertanam |
| `none` / `hidden` | Tanpa garis |

## Border per Sisi

```css
.kartu {
  border: 1px solid #E5E7EB;
  border-top: 4px solid #4F46E5;   /* aksen atas */
  border-right: none;              /* sisi kanan polos */
}
```

Nilai juga bisa ditulis empat arah sekaligus dalam satu properti: `border-width: 1px 2px 3px 4px` mengikuti pola **atas kanan bawah kiri** (searah jarum jam).

## Sudut Membulat

```css
.kartu   { border-radius: 16px; }
.pil     { border-radius: 999px; } /* bentuk pil */
.avatar  { border-radius: 50%; }   /* lingkaran sempurna */
.izin    { border-radius: 16px 16px 0 0; } /* hanya atas */
```

Nilai persen dihitung terhadap lebar dan tinggi elemen, jadi `50%` pada kotak berukuran sama menghasilkan lingkaran.

## Border sebagai Gambar

`border-image` memungkinkan potongan gambar dipakai menjadi sudut dan sisi:

```css
.frame {
  border: 12px solid transparent;
  border-image: url('bingkai.png') 30 round;
}
```

Fitur ini kuat tapi jarang dipakai karena sulit responsif — ketahui saja keberadaannya.

<div class="note">💡 Border ikut menambah ukuran elemen saat `box-sizing: content-box`. Beralih ke `border-box` membuat lebar total tetap sesuai angka yang kamu tulis.</div>

## Di Dunia Nyata

- Kartuproduk memakai border tipis + radius agar terasa "mengambang".
- Field error ditandai `border-color: #DC2626` dan ring merah saat fokus.
- Garis putus-putus pada area drop-file memberi kesan "taruh di sini".
- Avatar pengguna dipotong lingkaran dengan `border-radius: 50%`.
