Properti `display` menentukan **bagaimana sebuah elemen berpartisipasi dalam layout**. Mengubahnya bisa mengubah seluruh perilaku elemen tanpa mengubah HTML-nya.

## Nilai yang Paling Sering Dipakai

| Nilai | Perilaku | Contoh elemen default |
|-------|----------|-----------------------|
| `block` | Baris baru, penuh lebar | `div`, `p`, `h1`, `section` |
| `inline` | Mengikuti alur teks | `span`, `a`, `strong`, `em` |
| `inline-block` | Ikut alur teks, tapi bisa diatur lebar/tinggi | — |
| `flex` | Kontainer flex (satu dimensi) | — |
| `grid` | Kontainer grid (dua dimensi) | — |
| `none` | Tidak dirender sama sekali | — |
| `contents` | Elemen sendiri hilang, anak tetap tampil | — |

## Block vs Inline

```css
.blok   { display: block; background: #DBEAFE; }
.inline { display: inline; background: #FEF3C7; }
```

Elemen **block** selalu mulai di baris baru dan lebarnya mengikuti induk. Elemen **inline** hanya selebar isinya dan **tidak mematuhi** `width`/`height`.

```css
span { width: 300px; } /* ❌ diabaikan selama display masih inline */
```

## inline-block

```css
.chip {
  display: inline-block;
  width: 120px;
  padding: 8px;
  margin: 4px;
  text-align: center;
}
```

Catatan: spasi antar tag inline-block di HTML muncul sebagai jarak kecil. Supaya hilang, induknya bisa memakai `font-size: 0` lalu mengembalikan font pada anaknya — atau lebih baik, pakai flex + `gap`.

## Menyembunyikan Elemen

| Cara | Ruang tetap? | Bisa dianimasikan? |
|------|--------------|--------------------|
| `display: none` | Tidak | Sulit |
| `visibility: hidden` | Ya | Terbatas |
| `opacity: 0` | Ya | Ya |
| `position: absolute; left: -9999px` | Tidak (keluar alur) | — |

Untuk konten yang hanya boleh dibaca pembaca layar (tidak terlihat), pakai kelas `.sr-only` dengan clip, bukan `display: none`.

## display: contents

```css
.wrapper { display: contents; }
```

Elemen wrapper "lenyap" dari layout, anak-anaknya seolah menjadi anak langsung induknya. Berguna untuk grid yang ingin mengabaikan pembungkus tambahan, tapi punya catatan aksesibilitas pada beberapa browser lama.

<div class="note">💡 Sejak CSS Display Module Level 3, `display` bisa menerima dua nilai: `display: inline flex` atau `display: block grid`. Nilai pertama mengatur perilaku elemen terhadap luar, nilai kedua mengatur layout anaknya.</div>

## Di Dunia Nyata

- Navigasi horizontal: `li { display: inline-block; }` atau `ul { display: flex; }`.
- Tooltip muncul saat hover: awalnya `display: none`, lalu `display: block`.
- Ikon inline di dalam teks memakai `display: inline-block` agar bisa dirotasi.
- Modal ditutup dengan `display: none` pada overlay.
