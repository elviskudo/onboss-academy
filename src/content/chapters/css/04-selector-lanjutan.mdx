## Combinator (Penggabung Selector)

```css
.kartu .harga { }      /* .harga di dalam .kartu */
.kartu > .judul { }    /* .judul anak langsung .kartu */
h2 + p { }             /* p tepat setelah h2 */
h2 ~ p { }             /* p setelah h2 di level sama */
```

CSS punya **4 combinator utama**:

| Combinator | Arti | Contoh | Kapan dipakai |
|------------|------|--------|---------------|
| Spasi | Semua keturunan | `.card p` | Isi komponen |
| `>` | Anak langsung | `nav > a` | Struktur satu tingkat |
| `+` | Saudara tepat berikut | `h2 + p` | Paragraf pembuka |
| `~` | Semua saudara berikut | `input:checked ~ label` | UI berbasis state |

## Pseudo-class (Kondisi)

```css
a:hover { }        /* saat disorot */
a:visited { }      /* sudah dikunjungi */
li:first-child { } /* anak pertama */
li:nth-child(2n) { } /* baris genap */
input:focus { }    /* sedang fokus */
.disabled { opacity: 0.5; pointer-events: none; }
```

Contoh zebra table:

```css
tr:nth-child(even) { background: #F3F4F6; }
```

## Pseudo-element (Bagian Virtual)

```css
p::before { content: "→ "; color: #4F46E5; }
p::first-line { font-weight: bold; }
p::selection { background: #C7D2FE; }
```

## Attribute Selector

```css
input[type="text"]  { }
a[href^="https"]    { }  /* diawali https */
a[href$=".pdf"]     { }  /* berakhiran .pdf */
img[alt*="logo"]    { }  /* mengandung "logo" */
```

## Specificity

Specificity dihitung dalam **3 kolom**: ID, class/atribut/pseudo-class, lalu elemen/pseudo-element. `#app .card p` bernilai `1-1-1`; `.card p` bernilai `0-1-1`. Nilai lebih kiri menang; jika sama, aturan yang ditulis belakangan menang.

## Di Dunia Nyata

- **Form login** — `input:focus` menampilkan border jelas saat keyboard aktif
- **Tabel laporan** — `tr:nth-child(even)` membuat baris zebra lebih mudah dibaca
- **Link PDF** — `a[href$=".pdf"]::after` menambah ikon otomatis
- **Menu dropdown** — child combinator mencegah gaya submenu bocor ke semua keturunan

<div class="note">💡 Jaga specificity tetap rendah dengan selector class pendek. Jangan tambah ID atau nesting panjang hanya untuk "mengalahkan" aturan lain — itu memulai perang specificity yang berakhir dengan `!important` di mana-mana.</div>
