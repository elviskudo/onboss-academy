CSS (*Cascading Style Sheets*) adalah bahasa yang mengatur **tampilan** halaman: warna, font, jarak, layout, animasi.

## Tiga Cara Memasang CSS

**1. Inline** (di elemen — praktis tapi sulit dirawat):

```html
<p style="color: red;">Merah</p>
```

**2. Internal** (tag `<style>` di `<head>`):

```html
<style>
  p { color: blue; }
</style>
```

**3. Eksternal** (file terpisah — paling direkomendasikan):

```html
<link rel="stylesheet" href="style.css">
```

```css
/* style.css */
p {
  color: blue;
}
```

| Cara | Scope | Kelebihan | Kapan dipakai |
|------|-------|-----------|---------------|
| Inline | Satu elemen | Cepat untuk nilai dinamis | Email HTML / eksperimen |
| Internal | Satu dokumen | Satu file mudah dicoba | Prototipe kecil |
| External | Banyak halaman | Cache dan mudah dirawat | Hampir semua proyek nyata |

CSS memiliki **lebih dari 500 properti standar/eksperimental**, tetapi sekitar **30–50 properti inti** sudah cukup untuk mayoritas antarmuka. Setiap aturan tersusun dari selector dan satu atau lebih deklarasi `property: value`.

## Anatomi Rule CSS

```css
selector {
  property: value;
}
```

Contoh nyata:

```css
h1 {
  color: #4F46E5;
  font-size: 32px;
  margin-top: 20px;
}
```

- **Selector** — elemen mana yang kena gaya
- **Property** — aspek yang diatur (`color`, `font-size`, …)
- **Value** — nilainya

## Cara Memilih Elemen

```css
p            { }  /* semua <p> */
.judul       { }  /* class="judul" */
#header      { }  /* id="header" */
p.judul      { }  /* <p> yang punya class judul */
a:hover      { }  /* link saat disorot kursor */
```

## Cascade: Urutan Kekuatan

1. `!important` (hindari jika bisa)
2. Inline style
3. ID selector
4. Class selector
5. Tag selector

Kalau dua aturan berebut elemen yang sama, yang **lebih spesifik** menang.

## Di Dunia Nyata

- **Design system** — file eksternal menjaga warna tombol konsisten di ratusan halaman
- **Dashboard admin** — selector class membedakan kartu sukses, peringatan, dan gagal
- **Artikel media** — cascade memberi tipografi dasar lalu tema rubrik menimpanya
- **Email promosi** — inline CSS dipakai karena dukungan stylesheet klien email terbatas

<div class="note">💡 Cascade bukan sekadar "yang terakhir menang": browser menilai origin, importance, specificity, lalu source order. Gunakan class dengan specificity rendah agar aturan mudah ditimpa tanpa `!important`.</div>
