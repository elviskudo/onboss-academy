Selector tidak hanya berdiri sendiri — kamu juga bisa memanfaatkan **hubungan antar elemen** di pohon DOM. Empat combinator inti memberi kontrol yang jauh lebih presisi daripada sekadar class.

## Empat Jenis Combinator

| Combinator | Nama | Contoh | Arti |
|------------|------|--------|------|
| spasi | Descendant | `div p` | Semua `p` di dalam `div`, berapa level pun |
| `>` | Child | `div > p` | Hanya `p` anak langsung |
| `+` | Adjacent sibling | `h2 + p` | `p` tepat setelah `h2` |
| `~` | General sibling | `h2 ~ p` | Semua `p` setelah `h2` dalam induk sama |

```css
/* semua tautan di dalam navigasi */
nav a { color: white; }

/* hanya li anak langsung dari ul utama */
ul.menu > li { display: inline-block; }

/* paragraf pertama setelah judul */
h2 + p { font-size: 1.1rem; }

/* semua paragraf setelah judul */
h2 ~ p { color: #6B7280; }
```

## Dampak pada Spesifisitas

Combinator **tidak menambah nilai spesifisitas**. `ul li` tetap bernilai dua tag, sama seperti `div p`. Yang berubah hanya cakupan elemen yang cocok, bukan kekuatannya.

```css
.card p      { color: black; }  /* 1 class + 1 tag */
section > p  { color: gray;  }  /* 2 tag — kalah */
```

## Contoh Nyata: Daftar Bersarang

Bayangkan menu dengan submenu. `nav li` akan mewarnai **semua** item termasuk submenu; `nav > ul > li` hanya item level pertama. Memilih yang tepat menghindari efek "meluber" ke dalam subtree.

<div class="note">💡 Combinator `+` dan `~` hanya melihat saudara yang berada **setelah** elemen pertama, bukan sebelum. CSS tidak punya "previous sibling" standar (`:has()` baru bisa membantu kasus tertentu).</div>

## Di Dunia Nyata

- Memberi jarak hanya pada item setelah yang pertama: `li + li { margin-top: 8px; }`.
- Menandai field yang langsung mengikuti label: `label + input`.
- Menata submenu tanpa menambah class di setiap level: `.menu ul li a`.
- Membuka gaya khusus saat checkbox dicentang: `input:checked + label`.
