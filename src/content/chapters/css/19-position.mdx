Secara default, elemen mengikuti alur dokumen dari atas ke bawah. Properti `position` memberi kamu kontrol untuk menggeser atau mengunci elemen keluar dari alur itu.

## Lima Nilai Position

| Nilai | Keluar alur? | Acuan | Kegunaan |
|-------|--------------|-------|----------|
| `static` | Tidak | Alur normal | Default |
| `relative` | Tidak | Posisi aslinya | Menggeser sedikit, jadi acuan anak absolute |
| `absolute` | Ya | Induk terdekat yang diposisikan | Tooltip, badge, dropdown |
| `fixed` | Ya | Viewport | Navbar, tombol mengambang |
| `sticky` | Tidak (sampai titik tertentu) | Viewport + alur | Header yang menempel |

## Properti Offset

`top`, `right`, `bottom`, `left` menentukan geseran. `z-index` mengatur urutan tumpukan (semakin besar semakin depan).

```css
.induk {
  position: relative;        /* jadi acuan untuk anak */
}
.badge {
  position: absolute;
  top: -8px;
  right: -8px;
  z-index: 5;
}
```

## Contoh: Badge pada Kartu

```html
<div class="produk">
  <img src="sepatu.jpg" alt="Sepatu">
  <span class="badge">Diskon 20%</span>
</div>
```

```css
.produk { position: relative; display: inline-block; }
.badge {
  position: absolute;
  top: 8px;
  left: 8px;
  background: #DC2626;
  color: white;
  padding: 4px 8px;
  border-radius: 4px;
}
```

## Sticky yang Sering Disalahpahami

```css
thead th {
  position: sticky;
  top: 0;
  background: white;
  z-index: 2;
}
```

Sticky tetap menempati ruang aslinya. Ia baru "menempel" saat posisi scroll melewati `top: 0`. Syarat penting: induknya tidak boleh punya `overflow: hidden` atau `overflow: auto` yang membatasi area lengket.

## Fixed dan Viewport

```css
.chat-button {
  position: fixed;
  bottom: 24px;
  right: 24px;
  z-index: 50;
}
```

Elemen fixed tidak ikut bergulir dan tidak memengaruhi layout saudara-saudaranya. Hati-hati di perangkat mobile — tombol fixed bisa menutupi konten atau keyboard.

<div class="note">💡 `z-index` bekerja dalam **stacking context**. Elemen dengan `z-index: 9999` di dalam konteks yang rendah tetap berada di bawah elemen dari konteks yang lebih tinggi.</div>

## Di Dunia Nyata

- Dropdown menu memakai `absolute` di bawah tombol yang `relative`.
- Header situs memakai `sticky` supaya tetap terlihat saat artikel panjang.
- Tombol "Kembali ke atas" memakai `fixed`.
- Overlay modal memakai `fixed; inset: 0` untuk menutup seluruh layar.
