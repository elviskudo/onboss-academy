Dua konsep ini sering muncul bersama saat membangun UI bertumpuk: **z-index** menentukan siapa di depan, **overflow** menentukan apa yang terjadi saat isi terlalu besar.

## Tumpukan dan Stacking Context

```css
.latar   { position: relative; z-index: 1; }
.konten  { position: relative; z-index: 2; }
.tooltip { position: absolute; z-index: 10; }
```

Tiga aturan penting:

1. `z-index` hanya bekerja pada elemen dengan `position` selain `static`, atau pada flex/grid item.
2. Nilai bisa negatif (misalnya `z-index: -1` untuk latar di belakang konten).
3. Setiap **stacking context** bersifat mandiri — anak tidak bisa "menembus" konteks induknya.

```css
.induk { opacity: 0.99; }     /* tanpa sadar membuat context baru */
.anak  { z-index: 99999; }    /* tetap kalah dari elemen di context atas */
```

Properti yang diam-diam membuat context baru: `opacity` &lt; 1, `transform`, `filter`, `backdrop-filter`, `isolation: isolate`, `mix-blend-mode`, dan `position: fixed`.

## Nilai Overflow

| Nilai | Perilaku |
|-------|----------|
| `visible` | Default, konten boleh keluar |
| `hidden` | Dipotong, tanpa scrollbar |
| `scroll` | Scrollbar selalu tampil |
| `auto` | Scrollbar muncul saat perlu |
| `clip` | Mirip hidden, tapi tidak bisa discroll programatik |

Bisa dipisah per sumbu: `overflow-x`, `overflow-y`.

```css
.panel {
  max-height: 240px;
  overflow-y: auto;
  overscroll-behavior: contain; /* hentikan chain scroll ke halaman */
}
```

## Teks Terpotih Elegan

```css
.judul-panjang {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  max-width: 240px;
}
```

Kombinasi ini mengganti akhiran teks dengan `…` — sangat berguna pada kartu dan tabel.

## Overflow sebagai Clearfix Tidak Langsung

`overflow: hidden` pernah dipakai untuk "membersihkan" float, tapi efek sampingnya memotong dropdown. Sekarang lebih baik pakai `display: flow-root` pada induk.

<div class="note">💡 `overflow: hidden` pada `<body>` sering dipakai saat modal terbuka supaya halaman tidak ikut bergulir. Simpan nilai scroll sebelumnya agar bisa dikembalikan saat modal ditutup.</div>

## Di Dunia Nyata

- Modal dan dropdown memakai z-index bertingkat: overlay 100, dialog 110, tooltip 120.
- Kolom tabel dengan teks panjang memakai ellipsis.
- Panel log memakai `overflow-y: auto` agar riwayat bisa digulir mandiri.
- Karousel memotong slide di luar area dengan `overflow: hidden`.
