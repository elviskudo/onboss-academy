**Pseudo-class** adalah selector yang memilih elemen berdasarkan *keadaan* atau posisinya — bukan dari nama class atau id. Penulisannya memakai satu titik dua (`:`).

## State Interaktif yang Paling Umum

| Pseudo-class | Aktif saat |
|--------------|------------|
| `:hover` | Kursor berada di atas elemen |
| `:focus` | Elemen sedang menerima fokus keyboard/klik |
| `:active` | Tombol mouse sedang ditekan |
| `:visited` | Tautan sudah pernah dikunjungi |
| `:disabled` | Form field dinonaktifkan |
| `:checked` | Checkbox/radio dicentang |

```css
button:hover  { background: #4338CA; transform: translateY(-1px); }
button:active { transform: translateY(1px); }
input:focus   { outline: 3px solid #C7D2FE; border-color: #4F46E5; }
input:disabled{ opacity: 0.55; cursor: not-allowed; }
```

## Pseudo-class Berbasis Posisi

```css
li:first-child  { font-weight: 700; }
li:last-child   { border-bottom: 0; }
li:nth-child(3) { color: #DC2626; }
li:nth-child(2n)   { background: #F9FAFB; } /* genap */
li:nth-child(2n+1) { background: white;    } /* ganjil */
li:nth-last-child(2) { opacity: 0.7; }
```

Rumus `an+b` di `nth-child` membaca: `a` adalah langkah, `n` mulai dari 0, lalu ditambah `b`. Jadi `3n+1` berarti posisi 1, 4, 7, 10, dan seterusnya.

## Pseudo-class Struktural Lain

- `:only-child` — satu-satunya anak di induknya.
- `:empty` — elemen tanpa anak dan tanpa teks.
- `:not(.kelas)` — semua elemen **kecuali** yang cocok.
- `:is(h1, h2, h3)` — ringkasan selector list dengan spesifisitas mengikuti argumen paling spesifik.

```css
.card:not(.featured) { opacity: 0.85; }
:is(h1, h2, h3) { font-family: Georgia, serif; }
```

<div class="note">💡 Urutan matters pada tautan: tulis `:link`, lalu `:visited`, lalu `:hover`, lalu `:active` (LVHA). Kalau `:hover` ditulis sebelum `:visited`, aturan visited akan menimpanya.</div>

## Di Dunia Nyata

- Baris tabel bergaris (zebra striping) memakai `:nth-child(even)`.
- Indikator bintang pada field wajib memakai `:required`.
- Menu dropdown terbuka memakai `:hover` pada induk + `> ul`.
- Tombol "Lanjut" berubah warna saat `input:valid` bersebelahan dengannya.
