Sebelum Flexbox dan Grid ada, **float** adalah andalan untuk membuat layout kolom. Kini perannya menyempit, tapi tetap penting untuk efek teks mengelilingi gambar.

## Cara Kerja Float

```css
.gambar {
  float: left;
  width: 160px;
  margin: 0 16px 8px 0;
}
```

Elemen yang diapungkan dikeluarkan dari alur normal **sebagian** — teks dan elemen inline di sekitarnya tetap mengalir mengikuti sisinya.

```html
<img class="gambar" src="peta.jpg" alt="Peta wisata">
<p>Teks artikel akan mengalir di sebelah kanan gambar…</p>
```

## Clear

```css
.footer { clear: both; }
```

`clear` memaksa elemen turun di bawah float sebelumnya. Nilainya: `left`, `right`, `both`, `none`.

## Masalah Klasik: Induk Collapse

Kalau semua anak mengapung, induk bisa "runtuh" tingginya menjadi nol. Dulu dipakai trik clearfix:

```css
.induk::after {
  content: "";
  display: table;
  clear: both;
}
```

Sekarang cukup:

```css
.induk { display: flow-root; }
```

## inline-block untuk Baris Item

```css
.menu li {
  display: inline-block;
  width: 120px;
  vertical-align: top;
  margin-right: 8px;
}
```

Kelemahan: spasi antar tag di HTML ikut terhitung, dan `vertical-align` perlu diatur supaya item dengan tinggi beda tidak bertumpuk aneh. Flexbox menyelesaikan keduanya dengan `gap` dan `align-items`.

<div class="note">💡 Pelajari float tetap tahu, tapi jangan pakai untuk layout baru. Gunakan Flexbox untuk baris/kolom satu dimensi dan Grid untuk dua dimensi.</div>

## Perbandingan Cepat

| Kebutuhan | Float | inline-block | Flexbox | Grid |
|-----------|-------|--------------|---------|------|
| Teks mengelilingi gambar | ✅ | ❌ | ❌ | ❌ |
| Baris tombol | ⚠️ | ✅ | ✅ | ✅ |
| Kolom responsif | ⚠️ | ⚠️ | ✅ | ✅ |
| Alignment vertikal | ❌ | ⚠️ | ✅ | ✅ |
| Gap otomatis | ❌ | ❌ | ✅ | ✅ |

## Di Dunia Nyata

- Artikel berita dengan gambar kecil di samping paragraf pertama.
- Klien email tetap memakai tabel dan inline-block karena dukungan flex masih terbatas di klien email.
- Kode lama yang belum dimigrasi masih penuh clearfix — mengenalinya membantu saat maintenance.
