## Transisi

```css
.tombol {
  transition: background-color 0.25s ease, transform 0.25s ease;
}
.tombol:hover {
  background-color: #4338CA;
  transform: translateY(-2px);
}
```

Singkatnya: `transition: properti durasi easing;`

Transisi punya **4 komponen**:

| Komponen | Fungsi | Contoh | Praktik baik |
|----------|--------|--------|--------------|
| Property | Nilai yang dianimasikan | `transform` | Hindari `all` |
| Duration | Lama perubahan | `200ms` | UI umumnya 150–300ms |
| Timing function | Kurva kecepatan | `ease-out` | Cocokkan dengan gerak |
| Delay | Jeda sebelum mulai | `50ms` | Pakai hemat |

## Animasi dengan Keyframes

```css
@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(16px); }
  to   { opacity: 1; transform: translateY(0); }
}

.judul {
  animation: fadeInUp 0.6s ease both;
}
```

## Transform

```css
.rotate  { transform: rotate(8deg); }
.scaling { transform: scale(1.05); }
.moving  { transform: translateX(20px); }
.skewing { transform: skewX(-10deg); }
```

## Di Dunia Nyata

- **Tombol checkout** — transisi warna memberi respons visual tanpa menghambat aksi
- **Accordion FAQ** — animasi tinggi/opasitas menjelaskan konten sedang membuka
- **Notifikasi** — keyframe singkat masuk lalu berhenti; bukan bergerak terus menerus
- **Skeleton loading** — animasi halus memberi tanda proses sambil data dimuat

<div class="note">💡 Animasikan `transform` dan `opacity` bila memungkinkan karena browser dapat memprosesnya tanpa menghitung ulang layout. Selalu hormati `prefers-reduced-motion` untuk pengguna yang sensitif terhadap gerakan.</div>
