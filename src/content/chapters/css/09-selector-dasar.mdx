Setiap aturan CSS diawali **selector** — petunjuk kepada browser tentang elemen mana yang boleh dihias. Menguasai selector berarti menguasai "siapa yang kena gaya".

## Empat Selector Paling Awal

| Selector | Contoh | Artinya |
|----------|--------|---------|
| Tag / type | `h1` | Semua elemen `<h1>` |
| Class | `.kartu` | Elemen dengan `class="kartu"` |
| ID | `#header` | Elemen dengan `id="header"` (unik) |
| Universal | `*` | Semua elemen apa pun |

```css
h1            { color: navy; }
.kartu        { padding: 16px; }
#header       { background: #111827; }
*             { margin: 0; padding: 0; }
```

## Menggabungkan Selector

Koma berarti "atau" — aturan yang sama dipakai bersama:

```css
h1, h2, h3 {
  font-family: Georgia, serif;
  letter-spacing: -0.02em;
}
```

Sementara itu, penyambungan tanpa spasi berarti "dan":

```css
p.intro        { font-size: 1.15rem; }  /* <p class="intro"> */
#header .logo  { width: 120px; }        /* .logo di dalam #header */
```

<div class="note">💡 ID lebih spesifik daripada class, dan class lebih spesifik daripada tag. Kalau dua aturan bertabrakan, yang paling spesifik menang — bukan sekadar yang ditulis terakhir.</div>

## Kapan Memakai Mana?

- **Tag** untuk gaya dasar seluruh dokumen, misalnya mengatur `line-height` semua paragraf.
- **Class** untuk komponen yang bisa dipakai berulang: tombol, kartu, label status.
- **ID** untuk satu area unik seperti anchor navigasi atau elemen yang dipetakanJavaScript.
- **Universal** dengan hati-hati — sering dipakai bersama `box-sizing` untuk reset.
