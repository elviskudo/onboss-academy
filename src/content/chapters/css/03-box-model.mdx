Setiap elemen HTML adalah sebuah **kotak** (*box*) yang tersusun dari beberapa lapis.

## Anatomi Box Model

```
┌────────── margin ──────────┐
│ ┌──────── border ────────┐ │
│ │ ┌──── padding ───────┐ │ │
│ │ │      content       │ │ │
│ │ └────────────────────┘ │ │
│ └────────────────────────┘ │
└────────────────────────────┘
```

```css
.kartu {
  width: 300px;
  padding: 24px;
  border: 2px solid #E8E5DF;
  margin: 16px auto;
  border-radius: 12px;
}
```

Box model punya **4 lapisan**, dari dalam ke luar:

| Lapisan | Properti | Fungsi | Kapan dipakai |
|---------|----------|--------|---------------|
| Content | `width`, `height` | Area isi | Ukuran konten |
| Padding | `padding` | Ruang dalam border | Napas dalam kartu/tombol |
| Border | `border` | Batas visual | Pemisah/status |
| Margin | `margin` | Ruang luar | Jarak antar elemen |

## `box-sizing: border-box`

Secara default, `width` hanya mengukur content — padding dan border *menambah* lebar total. Kalau bingung, nyalakan ini sekali untuk semua:

```css
*, *::before, *::after {
  box-sizing: border-box;
}
```

Sekarang `width: 300px` = total lebar kotak 300px.

## Margin Collapse

Margin antar-elemen vertikal yang berdempetan **akan menggabungkan diri** (ambil nilai terbesar), bukan dijumlahkan. Itulah kenapa dua `<p>` tidak punya jarak dobel.

## Shadow

```css
box-shadow: 0 4px 12px rgb(0 0 0 / 0.08);
/* geser-x geser-y blur spread warna */
```

## Di Dunia Nyata

- **Kartu produk** — padding memberi ruang isi, border menegaskan batas, margin memisahkan kartu
- **Form checkout** — `border-box` mencegah input 100% meluber karena padding
- **Avatar profil** — `border-radius: 50%` membentuk lingkaran dari gambar persegi
- **Modal** — shadow membedakan lapisan dialog dari halaman di belakangnya

<div class="note">💡 Pasang `box-sizing: border-box` secara global di awal proyek. Dengan begitu `width` selalu berarti ukuran akhir elemen (termasuk padding dan border), sehingga perhitungan layout jauh lebih mudah.</div>
