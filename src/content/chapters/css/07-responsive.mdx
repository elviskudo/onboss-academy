## Aturan Emas Responsif

1. Selalu pakai `meta viewport` (sudah ada di template bab HTML)
2. Gunakan satuan relatif: `%`, `fr`, `rem`, `vw`
3. Gambar: `max-width: 100%; height: auto;`
4. Layout: Flex/Grid dengan wrap/auto-fit dulu, media query sebagai pelengkap

Responsif bertumpu pada **4 alat inti**: viewport meta, unit relatif, layout fleksibel, dan media/container query.

| Alat | Fungsi | Contoh | Prioritas |
|------|--------|--------|-----------|
| Viewport meta | Samakan viewport dengan perangkat | `width=device-width` | Wajib di HTML |
| Unit relatif | Skala mengikuti konteks | `%`, `rem`, `vw` | Default ukuran |
| Flex/Grid | Layout cair | `auto-fit`, `wrap` | Sebelum breakpoint |
| Media query | Perubahan pada kondisi | `min-width: 48rem` | Saat desain pecah |

## Sintaks Media Query

```css
/* lebar layar ≥ 768px */
@media (min-width: 768px) {
  .sidebar { width: 280px; }
}

/* rentang layar */
@media (min-width: 600px) and (max-width: 900px) {
  .judul { font-size: 1.5rem; }
}

/* mode gelap preferensi sistem */
@media (prefers-color-scheme: dark) {
  body { background: #17181D; color: #E5E7EB; }
}

/* kurangi animasi (aksesibilitas) */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
```

## Mobile-First dalam Praktik

```css
/* dasar: HP */
.kartu-list { display: grid; grid-template-columns: 1fr; gap: 16px; }

/* ≥ 700px: dua kolom */
@media (min-width: 700px) {
  .kartu-list { grid-template-columns: 1fr 1fr; }
}

/* ≥ 1024px: tiga kolom */
@media (min-width: 1024px) {
  .kartu-list { grid-template-columns: repeat(3, 1fr); }
}
```

Atau tanpa media query sama sekali dengan `repeat(auto-fit, minmax(240px, 1fr))`.

## Di Dunia Nyata

- **Katalog toko** — satu kolom HP berubah menjadi tiga kolom ketika kartu mulai terlalu lebar
- **Artikel berita** — gambar tidak meluber dan font memakai `clamp()` agar tetap nyaman
- **Dashboard** — sidebar pindah ke bawah konten pada layar sempit
- **Aplikasi aksesibel** — animasi dinonaktifkan untuk pengguna `prefers-reduced-motion`

<div class="note">💡 Breakpoint bukan daftar tipe perangkat. Mulai dari layar sempit, lebarkan sampai konten terlihat buruk, lalu tambahkan breakpoint tepat di sana; desain baru tetap aman saat ukuran perangkat masa depan berubah.</div>
