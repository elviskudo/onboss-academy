Kalau pseudo-class memilih **elemen berdasarkan state**, **pseudo-element** memilih *bagian dari* elemen. Kamu bisa menyisipkan konten dekoratif tanpa menambah markup HTML.

## Daftar Pseudo-Element Inti

| Pseudo-element | Fungsi |
|----------------|--------|
| `::before` | Menyisipkan konten sebelum isi elemen |
| `::after` | Menyisipkan konten setelah isi elemen |
| `::first-letter` | Huruf pertama baris pertama |
| `::first-line` | Baris pertama teks |
| `::selection` | Tampilan teks saat disorot |
| `::placeholder` | Teks petunjuk pada input |

## Aturan Emas: content

Pseudo-element tidak akan muncul tanpa deklarasi `content`. Untuk dekorasi murni, pakai string kosong:

```css
.kartu::before {
  content: "";
  display: block;
  width: 40px;
  height: 4px;
  background: #4F46E5;
  margin-bottom: 12px;
}
```

## Contoh Pemakaian

```css
/* label badge di pojok kartu */
.badge::after {
  content: "BARU";
  position: absolute;
  top: 8px;
  right: 8px;
  font-size: 10px;
  padding: 2px 6px;
  border-radius: 999px;
  background: #DC2626;
  color: white;
}

/* drop cap pada artikel */
.artikel > p:first-of-type::first-letter {
  font-size: 3.2rem;
  float: left;
  line-height: 1;
  margin: 4px 8px 0 0;
  color: #4F46E5;
}

input::placeholder { color: #9CA3AF; font-style: italic; }
```

<div class="note">💡 Konten buatan pseudo-element tidak bisa dipilih dengan mouse dan tidak masuk ke pembaca layar. Jangan pakai `content` untuk informasi penting — tetap tulis di HTML.</div>

## Kapan Tidak Memakainya

- Ikon penting yang harus bisa dibaca pembaca layar → pakai elemen SVG atau teks sungguhan.
- Konten yang perlu di-copy pengguna → taruh di markup.
- Efek yang butuh interaksi kompleks → lebih baik pakai elemen nyata.

## Di Dunia Nyata

- Garis dekoratif di atas kartu profil tanpa div tambahan.
- Panah kecil pada tombol dropdown (`::after` + border transparan).
- Counter otomatis pada daftar langkah (`content: counter(langkah)`).
- Menata warna highlight saat pengguna menyeleksi teks artikel.
