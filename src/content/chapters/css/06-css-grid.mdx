## Dasar Grid

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 16px;
}
```

Grid memiliki **2 sumbu sekaligus** (baris dan kolom) serta **4 konsep struktur**: container, track, line, dan cell/area.

| Konsep | Arti | Contoh | Kapan dipakai |
|--------|------|--------|---------------|
| Track | Satu baris/kolom | `1fr 2fr` | Ukuran layout |
| Line | Garis pembatas track | `1 / -1` | Menentukan bentang |
| Cell | Perpotongan baris-kolom | Satu kartu | Penempatan dasar |
| Area | Beberapa cell bernama | `grid-area: sidebar` | Layout halaman |

## Unit `fr`

`1fr` = satu bagian dari sisa ruang. Kolom `2fr 1fr` berarti lebar 2:1.

## Baris dan Kolom

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: 80px 1fr;
  gap: 12px;
}
```

## Spanning (Membentang)

```css
.judul { grid-column: 1 / -1; } /* bentang semua kolom */
.hero  { grid-column: span 2; }
```

## Layout Responsif Tanpa Media Query

```css
.galeri {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 20px;
}
```

Kolom otomatis: 4 di layar lebar, 2 di tablet, 1 di HP.

## Grid vs Flex — Kapan Pakai Mana?

| Gunakan **Grid** | Gunakan **Flex** |
|---|---|
| Layout halaman utuh | Sekumpulan item sejajar |
| Formulir label + input | Navbar kiri-kanan |
| Gallery foto | Kartu dalam satu baris |

## Di Dunia Nyata

- **Galeri foto** — `auto-fit + minmax()` menambah/mengurangi kolom tanpa breakpoint
- **Dashboard** — kartu metrik membentang dua kolom, grafik memakai seluruh baris
- **Layout artikel** — sidebar 240px dan isi `1fr` tetap stabil di desktop
- **Form data** — label dan input sejajar dalam dua track yang konsisten

<div class="note">💡 Pilih Grid ketika hubungan baris DAN kolom penting; pilih Flex ketika hanya satu arah yang penting. Keduanya bukan saingan: Grid sering mengatur halaman, Flex mengatur isi komponennya.</div>
