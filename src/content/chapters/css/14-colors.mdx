CSS menyediakan beberapa cara menulis warna. Semua bisa dipakai di properti `color`, `background-color`, `border-color`, dan sejenisnya.

## Lima Cara Menulis Warna

| Cara | Contoh | Catatan |
|------|--------|---------|
| Nama | `tomato`, `rebeccapurple` | Mudah dibaca, terbatas |
| Hex | `#4F46E5`, `#fff` | Paling umum di desain web |
| RGB | `rgb(79, 70, 229)` | Nilai 0–255 |
| RGBA | `rgba(0, 0, 0, 0.5)` | Ada channel alpha |
| HSL | `hsl(243, 75%, 59%)` | Mudah diatur tone-nya |

Sintaks modern juga memperbolehkan `rgb(79 70 229 / 0.5)` tanpa `a` pada nama fungsinya.

## Memahami HSL

- **Hue** (0–360): posisi di roda warna — 0 merah, 120 hijau, 240 biru.
- **Saturation** (0–100%): seberapa pekat warnanya.
- **Lightness** (0–100%): 0 hitam, 50 warna murni, 100 putih.

```css
.biru-laut   { color: hsl(200 80% 40%); }
.biru-pucat  { color: hsl(200 80% 85%); }
 Merah-gelap { color: hsl(0 70% 30%); }
```

Menggeser lightness jauh lebih mudah daripada menebak hex baru saat membuat variasi warna.

## Transparansi

```css
.overlay {
  background: rgb(17 24 39 / 0.65);
}
```

`opacity` berbeda dengan alpha: `opacity` membuat **seluruh elemen** (termasuk anaknya) transparan, sedangkan alpha hanya memengaruhi warna itu sendiri.

```css
.kartu { opacity: 0.6; }          /* teks di dalam ikut transparan */
.kartu { background: rgb(0 0 0 / 0.6); } /* teks tetap tajam */
```

## currentColor

```css
.ikon {
  border: 2px solid currentColor;
  fill: currentColor;
}
```

Nilai ini mengikuti `color` elemen, berguna supaya ikon SVG dan border selaras dengan warna teks tanpa menulis ulang warna.

<div class="note">💡 Kontras adalah soal aksesibilitas, bukan selera. Teks abu-abu terang di latar putih sering gagal standar WCAG AA (minimal 4.5:1 untuk teks normal).</div>

## Di Dunia Nyata

- Palet warna didefinisikan sekali di `:root` lalu dipakai lewat CSS variable.
- Status aplikasi memakai hijau (`#16A34A`), kuning (`#F59E0B`), merah (`#DC2626`) secara konsisten.
- Overlay modal memakai alpha hitam supaya konten di belakang masih terlihat samar.
