Flexbox menyelesaikan 90% kebutuhan layout sehari-hari: navbar, card sejajar, form rapi, footer bawah.

## Dasar

```css
.container {
  display: flex;
  justify-content: space-between; /* sumbu utama */
  align-items: center;            /* sumbu silang */
  gap: 16px;
}
```

```
main axis (justify-content)  →
┌──────────────────────────────┐ ↕ cross (align-items)
│  [A]      [B]      [C]       │
└──────────────────────────────┘
```

## Properti Kontainer

```css
display: flex;
flex-direction: row | column;
flex-wrap: wrap;
justify-content: flex-start | center | space-between | space-around;
align-items: stretch | center | flex-start | flex-end;
align-content: /* saat wrap, jarak antar baris */;
gap: 12px;
```

Ada **6 properti kontainer inti** pada contoh di atas: `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, `align-content`, dan `gap` (selain pengaktif `display`).

| Properti | Sumbu/objek | Fungsi | Kapan dipakai |
|----------|-------------|--------|---------------|
| `flex-direction` | Utama | Menentukan row/column | Navbar vs stack |
| `justify-content` | Utama | Distribusi ruang | Kiri-kanan/center |
| `align-items` | Silang | Alignment satu baris | Center vertikal |
| `flex-wrap` | Kontainer | Pindah baris saat sempit | Chip/kartu |
| `gap` | Antara item | Jarak konsisten | Semua layout flex |

## Properti Item

```css
flex-grow: 1;   /* ikut tumbuh makan ruang sisa */
flex-shrink: 0; /* tidak boleh menyusut */
flex-basis: 200px;
flex: 1 0 200px; /* shorthand grow shrink basis */
order: 2;       /* ubah urutan tampil */
```

## Pola Umum

**Kartu sejajar otomatis sama tinggi:**

```css
.cards { display: flex; gap: 20px; }
.card  { flex: 1; display: flex; flex-direction: column; }
```

**Nav kiri-kanan:**

```css
nav { display: flex; justify-content: space-between; align-items: center; }
```

## Di Dunia Nyata

- **Navbar** — logo dan menu dipisahkan `space-between`, seluruhnya center vertikal
- **Kartu harga** — item flex tumbuh sama lebar dan tombol didorong ke bawah
- **Toolbar editor** — tombol dibungkus dengan `flex-wrap` ketika layar menyempit
- **Form pencarian** — input `flex: 1` mengambil sisa ruang di samping tombol

<div class="note">💡 `justify-content` selalu mengikuti main axis, bukan selalu horizontal. Begitu `flex-direction: column`, justify menjadi vertikal dan align menjadi horizontal — ini sumber kebingungan flexbox paling umum.</div>
