Memilih satuan yang tepat membuat desain lebih mudah dirawat. CSS menyediakan satuan **absolut** dan **relatif**, ditambah fungsi matematika untuk menggabungkannya.

## Satuan Absolut vs Relatif

| Satuan | Jenis | Keterangan |
|--------|-------|------------|
| `px` | Absolut | Paling umum, 1 unit = 1 CSS pixel |
| `pt`, `in`, `cm`, `mm` | Absolut | Lebih cocok untuk cetak |
| `em` | Relatif | Terhadap font-size elemen sendiri |
| `rem` | Relatif | Terhadap font-size `<html>` |
| `%` | Relatif | Terhadap nilai induk (konteksnya beda-beda) |
| `vw`, `vh` | Relatif | 1% lebar/tinggi viewport |
| `vmin`, `vmax` | Relatif | Lebih kecil/besar dari vw dan vh |
| `ch`, `ex` | Relatif | Lebar karakter "0" / tinggi huruf x |
| `fr` | Relatif | Bagian ruang bebas pada Grid |

## em vs rem

```css
html { font-size: 16px; }
.parent { font-size: 20px; }
.anak-em  { font-size: 1.5em; }  /* 30px → ikut parent */
.anak-rem { font-size: 1.5rem; } /* 24px → ikut root */
```

Efek berlipat pada `em` bisa menguntungkan (padding tombol mengikuti ukuran teksnya) tapi berbahaya pada nested yang dalam. Untuk tipografi global, `rem` lebih aman.

## Fungsi Matematika

```css
.lebar {
  width: calc(100% - 48px);       /* kurangi padding tetap */
}
.judul {
  font-size: clamp(1.5rem, 1rem + 2vw, 2.5rem);
}
.gambar {
  width: min(100%, 400px);        /* tidak lebih dari 400px */
}
.panel {
  min-height: max(240px, 40vh);   /* minimal 240px */
}
```

`clamp(min, preferred, max)` pada dasarnya gabungan `max()` dan `min()` — sangat berguna untuk tipografi dan jarak responsif tanpa media query.

## Persentase Itu Kontekstual

```css
.anak { width: 50%; }        /* 50% lebar induk */
.induk { padding: 10%; }     /* padding % mengikuti LEBAR induk, bukan tinggi! */
.teks { font-size: 120%; }   /* mengikuti font-size induk */
```

Karena `padding` persen selalu berdasarkan lebar, `%` bisa memberi hasil mengejutkan pada container tinggi.

## Viewport Unit dan Mobile

`100vh` pada browser mobile sering terkena dynamically shrinking address bar. Alternatif modern:

```css
.hero {
  min-height: 100svh; /* small viewport height */
  min-height: 100dvh; /* dynamic viewport height */
}
```

<div class="note">💡 Perhatikan spasi di sekitar operator pada `calc`: `calc(100%-20px)` tidak valid. Harus ditulis `calc(100% - 20px)`.</div>

## Di Dunia Nyata

- Sidebar memakai `width: clamp(220px, 25vw, 300px)`.
- Input memakai `width: calc(100% - 24px)` agar tidak keluar dari padding.
- Hero memakai `min-height: 100svh` supaya tidak tertutup bilah alamat ponsel.
- Jarak antar bagian memakai `gap: clamp(1rem, 3vw, 2rem)`.
