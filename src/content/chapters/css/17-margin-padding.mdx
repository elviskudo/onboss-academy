Dua properti ini mengatur "napas" desain: **padding** memberi ruang di dalam, **margin** memberi ruang di luar. Tertukar keduanya adalah kesalahan klasik pemula.

## Perbedaan Mendasar

| Aspek | Padding | Margin |
|-------|---------|--------|
| Posisi | Antara konten dan border | Di luar border |
| Latar | Mengikuti warna latar elemen | Transparan |
| Bisa diklik | Ya (bagian dari elemen) | Tidak |
| Collapsing | Tidak | Ya (vertikal) |
| Negatif | Tidak | Boleh |

## Pola Penulisan Nilai

```css
/* 1 nilai → semua sisi */
margin: 16px;

/* 2 nilai → atas/bawah, kiri/kanan */
padding: 12px 24px;

/* 3 nilai → atas, kiri/kanan, bawah */
margin: 8px 16px 24px;

/* 4 nilai → atas, kanan, bawah, kiri */
padding: 4px 8px 12px 16px;
```

Selalu ingat arah **searah jarum jam** mulai dari atas.

## Memusatkan Elemen

```css
.kotak {
  width: 320px;
  margin-left: auto;
  margin-right: auto;
}
```

Ini hanya bekerja kalau elemen punya lebar tertentu dan `display`-nya bukan inline. Untuk flexbox, gunakan `justify-content: center` pada induknya.

## Margin Collapsing

Dua elemen bersebelahan dengan `margin-bottom: 20px` dan `margin-top: 30px` tidak menghasilkan 50px, melainkan **30px** (nilai terbesar). Ini terjadi hanya pada **sumbu vertikal** dan hanya untuk margin, bukan padding.

```css
.section { margin-bottom: 20px; }
.section + .section { margin-top: 30px; } /* jarak akhir 30px */
```

Cara menghindarinya: pakai padding, flex/grid `gap`, atau `display: flow-root` pada induk.

## box-sizing

```css
*, *::before, *::after { box-sizing: border-box; }
```

Dengan `border-box`, `width: 300px` sudah termasuk padding dan border. Tanpa itu, padding menambah total lebar dan layout容易 meledak.

<div class="note">💡 Gunakan `gap` pada flex/grid untuk jarak antar item. Selain lebih rapi, gap tidak ikut collapsing dan tidak perlu selector `+` untukitem pertama/terakhir.</div>

## Di Dunia Nyata

- Tombol memakai padding `10px 18px` supaya area klik nyaman (minimal 44px tinggi untuk aksesibilitas).
- Kartu memakai margin `auto` agar berada di tengah kontainer.
- Reset CSS global memakai `margin: 0` pada `body`, `h1`, dan `p` supaya jarawal konsisten.
