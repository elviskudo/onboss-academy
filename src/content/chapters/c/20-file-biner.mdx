File biner menyimpan byte mentah, tanpa konversi teks. Ini dipakai untuk gambar, audio, dan data terstruktur yang efisien.

## Mode Biner

```c
FILE *f = fopen("data.bin", "wb");   /* write binary */
FILE *g = fopen("data.bin", "rb");   /* read binary */
```

Di Windows, mode teks mengubah `
` menjadi `
`. Mode biner mencegah itu — penting agar data tidak berubah.

## fread / fwrite

```c
size_t n = fwrite(&obj, sizeof obj, 1, f);
size_t m = fread(&obj, sizeof obj, 1, f);
```

Selalu cek nilai kembaliannya; bisa lebih kecil dari jumlah item yang diminta saat file rusak atau habis.

## Masalah Portabilitas

1. **Padding**: compiler bisa menyisipkan byte antar field struct.
2. **Endianness**: x86 little-endian, beberapa ARM big-endian.
3. **Ukuran tipe**: `long` 4 byte di Windows, 8 byte di Linux 64-bit.

Solusi: gunakan tipe berukuran tetap dari `<stdint.h>` (`uint32_t`, `int64_t`) dan serialisasi field satu per satu bila format harus lintas platform.

## Ukuran File

```c
fseek(f, 0, SEEK_END);
long ukuran = ftell(f);
rewind(f);
```

<div class="note">💡 Untuk pertukaran data antar sistem, format tekstual seperti JSON/CSV sering lebih aman daripada dump struct biner. Biner pilihannya kalau performa dan ukuran benar-benar kritikal.</div>
