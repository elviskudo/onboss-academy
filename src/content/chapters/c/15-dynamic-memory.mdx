C tidak punya garbage collector. Kamu bertanggung jawab penuh atas memori heap: mengalokasi, memakai, lalu mengembalikannya.

## malloc / calloc / realloc / free

```c
int *p = malloc(10 * sizeof *p);    /* belum diinisialisasi */
int *q = calloc(10, sizeof *q);     /* semua 0 */

if (p == NULL) { /* alokasi gagal */ }

int *tmp = realloc(p, 20 * sizeof *p);
if (tmp) p = tmp; else free(p);

free(p);
free(q);
```

Selalu cek hasil alokasi. Gunakan `sizeof *pointer` daripada `sizeof(int)` — kalau tipe berubah, ukuran ikut benar.

## Kesalahan Umum

| Bug | Gejala |
|---|---|
| Lupa `free` | memory leak |
| `free` dua kali | crash/heap corruption |
| Pakai setelah `free` | undefined behavior |
| Write melewati batas | buffer overflow |
| `realloc` langsung ke pointer asli | kehilangan blok saat gagal |

## Stack vs Heap

```c
void f(void) {
    int lokal[10];        /* stack, otomatis hilang */
    int *heap = malloc(10 * sizeof(int)); /* heap, harus di-free */
    free(heap);
}
```

Stack cepat tapi kecil dan masa hidupnya singkat. Heap lebih besar dan fleksibel, tapi lebih lambat serta perlu manajemen manual.

## Pola Aman

```c
#define AMAN_FREE(p) do { free(p); (p) = NULL; } while (0)
```

Makro ini memastikan pointer tidak menjadi dangling setelah dibebaskan.

<div class="note">💡 Gunakan tools seperti <b>Valgrind</b> atau AddressSanitSanitizer (`-fsanitize=address`) saat development. Mereka bisa menemukan leak dan akses memori ilegal yang tidak terlihat saat program tampak normal.</div>
