Stack dan queue adalah struktur data linear dengan aturan akses yang berbeda. Keduanya bisa dibangun dari array maupun linked list.

## Stack (LIFO)

```c
int tumpukan[100];
int top = -1;

void push(int v) {
    if (top < 99) tumpukan[++top] = v;
}
int pop(void) {
    if (top >= 0) return tumpukan[top--];
    return -1;   /* penanda kosong */
}
```

Kegunaan: undo/redo, evaluasi ekspresi, call stack, DFS.

## Queue (FIFO)

```c
int q[100], front = 0, rear = 0;

void enqueue(int v) { q[rear++] = v; }
int dequeue(void)   { return q[front++]; }
```

Versi naif di atas membuang ruang di depan. Gunakan **circular queue**:

```c
rear = (rear + 1) % MAX;
front = (front + 1) % MAX;
```

## Prioritas Queue

Elemen dengan prioritas tinggi keluar lebih dulu. Implementasi sederhana: array terurut; implementasi efisien: binary heap (O(log n)).

## Linked List vs Array

| Struktur | Keuntungan linked |
|---|---|
| Stack | ukuran fleksibel, tidak overflow sampai memori habis |
| Queue | tidak perlu circular trick |

<div class="note">💡 Dalam praktik, pakai array/circular buffer kalau ukuran maksimumnya diketahui — lebih sederhana dan lebih ramah cache. Linked list berguna kalau ukuran sangat dinamis.</div>
