C memberi dua alat untuk membuat kode lebih mudah dibaca: `typedef` (nama tipe baru) dan `enum` (konstanta bernama).

## typedef

```c
typedef unsigned long Uang;
Uang harga = 15000UL;
```

Typedef sangat membantu pada tipe panjang seperti pointer fungsi:

```c
typedef int (*Banding)(const void *, const void *);
Banding cmp = banding_int;
```

## enum

```c
enum Status { MENUNGGU, BERJALAN, SELESAI = 10, GAGAL };

enum Status s = BERJALAN;   /* 1 */
printf("%d\n", SELESAI);   /* 10, GAGAL = 11 */
```

Enum hanya gula sintaks untuk konstanta integer — tidak ada pengecekan tipe ketat seperti Java.

## typedef + struct

```c
typedef struct {
    int x, y;
} Titik;

Titik asal = {0, 0};
```

Tanpa typedef, setiap deklarasi harus ditulis `struct Titik asal;`.

## Kapan Memakai

| Kasus | Pilihan |
|---|---|
| Konstanta terkait | `enum` |
| Makro sederhana | `#define` |
| Nama tipe panjang | `typedef` |
| Konstanta dengan tipe/ukuran tertentu | `typedef enum` + Cast |

<div class="note">💡 Beri nama enum dengan huruf kapital seperti konstanta (`MERAH`, `BARU`). Ini konvensi yang sudah lama dipakai di kode C dan membedakannya dari variabel biasa.</div>
