Alih-alih membuat `nilai1`, `nilai2`, `nilai3`… C menyimpan **semua data dalam satu array** dengan indeks. Array adalah struktur data paling dasar di C — dan di baliknya selalu ada pointer.

## Deklarasi & Akses

```c
int nilai[5];              // 5 slot, belum diisi (garbage!)
int skor[4] = {80, 90, 75, 88};   // inisialisasi sekaligus
char huruf[3] = {'A', 'B', 'C'};
int semuaNol[5] = {0};     // trik: seluruh elemen diisi 0

nilai[0] = 70;             // ubah elemen pertama
printf("%d\n", skor[2]);   // 75
```

Ukuran array harus **konstan** saat deklarasi; jumlah nilai dalam kurung kurawal sebaiknya tidak melebihi ukurannya. Indeks valid: `0` sampai `ukuran - 1` — C **tidak memeriksa** batas, akses di luar batas = undefined behavior (bisa crash, bisa merusak data lain diam-diam).

## Menelusuri Array

```c
int total = 0;
for (int i = 0; i < 4; i++) {
    total += skor[i];
}
printf("Jumlah = %d\n", total);

int jumlah = sizeof(skor) / sizeof(skor[0]);  // = 4
printf("Jumlah elemen = %d\n", jumlah);
```

`sizeof(skor) / sizeof(skor[0])` adalah cara baku menghitung panjang array **di dalam fungsi tempat array dideklarasikan**. Saat array dikirim ke function, sizeof hanya mengembalikan ukuran pointer (8 byte) — panjang harus dikirim manual.

## Mencari Nilai Maksimum

```c
int data[5] = {12, 45, 7, 88, 33};
int maks = data[0];
for (int i = 1; i < 5; i++) {
    if (data[i] > maks) maks = data[i];
}
printf("Maks = %d\n", maks);   // 88
```

Pola "asumsikan pertama, lalu bandingkan" ini dipakai hampir di semua kompetisi pemrograman.

## Bubble Sort — Mengurutkan Array

```c
int a[5] = {5, 3, 8, 1, 2};
for (int i = 0; i < 4; i++) {
    for (int j = 0; j < 4 - i; j++) {
        if (a[j] > a[j + 1]) {        // tukar jika urutan terbalik
            int t = a[j];
            a[j] = a[j + 1];
            a[j + 1] = t;
        }
    }
}
// a kini = {1, 2, 3, 5, 8}
```

Bubble sort paling sederhana untuk data kecil; untuk data besar, pakai `qsort` dari `<stdlib.h>` dengan function pointer pembanding.

## Array Dua Dimensi

```c
int matriks[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int b = 0; b < 2; b++) {
    for (int k = 0; k < 3; k++) {
        printf("%d ", matriks[b][k]);
    }
    printf("\n");
}
printf("Baris: %d, Kolom: %d\n",
       (int)(sizeof(matriks)/sizeof(matriks[0])),            // 2
       (int)(sizeof(matriks[0])/sizeof(matriks[0][0])));    // 3
```

Cocok untuk tabel data, papan permainan, atau grid koordinat. Di memori, 2D array hanyalah blok datar berurutan baris demi baris (row-major).

## Array ke Function

```c
int jumlah(int arr[], int panjang) {
    int total = 0;
    for (int i = 0; i < panjang; i++) total += arr[i];
    return total;
}
```

Array dikirim beserta **panjangnya** — di dalam fungsi, parameter `arr[]` sebenarnya hanya berupa pointer ke elemen pertama (setara `int *arr`). Karena itu fungsi bisa mengubah isi array asli tanpa pointer eksplisit.

## Ringkasan Operasi Array

| Operasi | Cara | Catatan |
|---|---|---|
| Deklarasi | `int a[5];` | ukuran konstan saat deklarasi |
| Inisialisasi | `int a[3] = {1,2,3};` | `{0}` = semua nol |
| Akses elemen | `a[i]` | indeks 0..n-1, tanpa cek batas |
| Panjang | `sizeof(a)/sizeof(a[0])` | hanya berlaku di scope deklarasi |
| 2 dimensi | `int m[2][3]` | m[baris][kolom], row-major |
| Ke function | `f(a, n)` | dikirim sebagai pointer + panjang |
| Dinamis | `malloc(n * sizeof(int))` | wajib `free` |

## Array Dinamis (Pratinjau)

```c
#include <stdlib.h>

int *data = malloc(n * sizeof(int));  // alokasikan n slot saat runtime
if (data == NULL) return 1;
// ... pakai data[0..n-1] ...
free(data);                           // wajib dilepas
```

Untuk data yang ukurannya baru diketahui saat program berjalan, array statis tidak cukup — `malloc`/`free` dibahas tuntas di chapter Pointer.

## Di Dunia Nyata

- **Menyimpan nilai ujian 40 siswa**: satu `int nilai[40]` — rata-rata, min, maks dihitung satu loop.
- **Papan catur 8×8**: `char papan[8][8]` menyimpan karakter bidak, dicetak dua loop bersarang.
- **Filter data harga di bawah budget**: loop menyalin elemen lolos filter ke array baru dengan counter terpisah.
- **Histogram huruf pada teks**: `int frek[26] = {0}` menghitung kemunculan A–Z — array jadi counter langsung.
- **Buffer sirkular audio**: array 44100 elemen menampung sampel 1 detik, indeks berputar dengan `% n`.

<div class="note">💡 Selalu sertakan variabel panjang saat mengoper array. C tidak menyimpan ukuran array di memori, sehingga membaca melewati batas tidak memunculkan error — hanya hasil yang salah atau crash yang tidak bisa ditebak. Ukuran tetap, akses cepat, nol proteksi: itulah array C.</div>
