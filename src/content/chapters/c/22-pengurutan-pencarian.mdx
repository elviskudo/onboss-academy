Algoritma dasar sorting dan searching muncul di hampir setiap technical interview. C cocok untuk mempelajarinya karena kamu melihat langsung memori dan indeks.

## Bubble Sort

```c
for (int i = 0; i < n-1; i++)
    for (int j = 0; j < n-1-i; j++)
        if (a[j] > a[j+1]) {
            int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
        }
```

Sederhana tapi lambat. Berguna hanya untuk belajar.

## Selection Sort

```c
for (int i = 0; i < n-1; i++) {
    int min = i;
    for (int j = i+1; j < n; j++)
        if (a[j] < a[min]) min = j;
    if (min != i) { int t=a[i]; a[i]=a[min]; a[min]=t; }
}
```

Jumlah swap paling sedikit di antara sort O(n²).

## Insertion Sort

Membangun bagian terurut satu elemen demi satu. Stabil dan cepat untuk data kecil/hampir terurut.

## Binary Search

```c
int l = 0, r = n - 1;
while (l <= r) {
    int m = l + (r - l) / 2;
    if (a[m] == x) { ketemu; break; }
    if (a[m] < x) l = m + 1;
    else r = m - 1;
}
```

Gunakan `l + (r-l)/2` daripada `(l+r)/2` untuk menghindari overflow pada array besar.

## qsort

```c
#include <stdlib.h>

int banding(const void *a, const void *b) {
    int x = *(const int*)a, y = *(const int*)b;
    return (x > y) - (x < y);   /* aman dari overflow */
}
qsort(arr, n, sizeof arr[0], banding);
```

<div class="note">💡 Dalam kode produksi, pakai `qsort` (atau implementasi library) daripada menulis sort sendiri. Tulis manual hanya untuk belajar atau kalau ada constraint khusus.</div>
