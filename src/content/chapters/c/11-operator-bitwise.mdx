Operator bitwise bekerja langsung pada representasi biner integer. Ia penting untuk pemrograman sistem, driver, dan optimasi tertentu.

## Operator Dasar

| Operator | Nama | Contoh (a=6, b=3) |
|---|---|---|
| `&` | AND | `2` |
| `|` | OR | `7` |
| `^` | XOR | `5` |
| `~` | NOT (komplemen) | `~6` |
| `<<` | shift kiri | `12` |
| `>>` | shift kanan | `1` |

```c
int x = 5;        /* 0000 0101 */
x = x | (1 << 3); /* nyalakan bit ke-3 → 13 */
x = x & ~(1 << 3);/* matikan bit ke-3 → 5  */
```

## Flag Bit

```c
#define BACA  (1 << 0)   /* 1 */
#define TULIS (1 << 1)   /* 2 */
#define EXEC  (1 << 2)   /* 4 */

int izin = BACA | TULIS;

if (izin & TULIS) printf("boleh tulis\n");
```

Pola ini jauh lebih hemat memori daripada tiga variabel `int` terpisah.

## Konstanta Biner

C standar (C99) belum punya literal `0b1010` — itu ekstensi GCC/Clang. Untuk portabilitas, pakai heksadesimal: `0x0A`.

## Hati-hati Signed Shift

```c
int neg = -8;
printf("%d\n", neg >> 1);  /* implementasi-defined */
```

Geser nilai **unsigned** bila kamu menginginkan perilaku logika yang pasti.

<div class="note">💡 Jangan tertukar `&` dengan `&&`. `if (a & b)` melakukan bitwise dan hasilnya bisa bukan 0/1; `if (a && b)` menghasilkan boolean with short-circuit.</div>
