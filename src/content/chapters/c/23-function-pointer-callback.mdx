Function pointer membuat C bisa melakukan apa yang di bahasa lain disebut callback, strategy, dan polymorphism ringan.

## Sintaks

```c
int (*op)(int, int);     /* pointer ke fungsi (int,int)->int */
int *f(int);             /* fungsi yang mengembalikan int* — BEDA */
```

Kurung di sekitar `*op` menentukan bahwa `op` adalah pointer, bukan fungsi.

## typedef

```c
typedef int (*Operasi)(int, int);

Operasi o1 = tambah;
Operasi o2 = kali;
```

Jauh lebih mudah dibaca daripada menulis ulang deklarasi panjang.

## qsort Comparator

```c
int banding_string(const void *a, const void *b) {
    const char *sa = *(const char * const *)a;
    const char *sb = *(const char * const *)b;
    return strcmp(sa, sb);
}
```

Perhatikan tipe cast-nya — `qsort` memberi pointer ke elemen array.

## Tabel Dispatch

```c
typedef void (*Aksi)(void);

void bantuan(void) { printf("...\n"); }
void keluar(void)  { exit(0); }

Aksi tabel[] = { bantuan, keluar };
const char *nama[] = {"help", "exit"};

for (int i = 0; i < 2; i++)
    if (strcmp(input, nama[i]) == 0) { tabel[i](); break; }
```

Menambah perintah cukup menambah baris tabel — tidak perlu `if/else` panjang.

<div class="note">💡 Function pointer tidak membawa state. Kalau callback butuh konteks, kirim struktur berisi data lewat parameter `void *userdata` — pola yang dipakai banyak library C.</div>
