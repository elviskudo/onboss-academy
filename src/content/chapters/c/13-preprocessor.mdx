Preprocessor berjalan **sebelum** compiler. Ia memproses direktif yang diawali `#`: menyertakan file, mengganti teks, dan memilih bagian kode mana yang ikut dikompilasi.

## #define

```c
#define PI 3.14159
#define MAKS(a, b) ((a) > (b) ? (a) : (b))
```

Kurung sangat penting. Tanpa kurung, `MAKS(1+2, 3)` bisa menjadi `1 + 2 > 3 ? ...` dengan hasil salah.

## #include

```c
#include <stdio.h>   /* header sistem */
#include "util.h"     /* header lokal proyek */
```

Tanda `<>` mencari di include path sistem; `""` mencari di direktori file sumber dulu.

## Header Guard

```c
#ifndef UTIL_H
#define UTIL_H

void bantu(void);

#endif
```

Tanpa guard, dua kali `#include "util.h"` menyebabkan deklarasi duplikat. Alternatif modern: `#pragma once` (didukung GCC/Clang/MSVC).

## Conditional Compilation

```c
#ifdef DEBUG
    printf("nilai x = %d\n", x);
#endif

#if defined(__linux__)
    /* kode khusus Linux */
#elif defined(_WIN32)
    /* kode khusus Windows */
#endif
```

## Makro vs Fungsi

| Aspek | Makro | Fungsi |
|---|---|---|
| Waktu | preprocessing | runtime |
| Tipe | tidak dicek | dicek compiler |
| Efek samping | bisa evaluasi ganda | sekali |
| Debug | sulit | mudah |

Untuk ekspresi kompleks, `static inline` sering lebih aman daripada makro.

<div class="note">💡 Hati-hati makro dengan argumen bertambah: `#define KUADAT(x) ((x)*(x))` membuat `KUADAT(i++)` menaikkan `i` dua kali. Pakai fungsi inline bila ragu.</div>
