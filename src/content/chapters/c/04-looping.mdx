Perulangan adalah cara C mengerjakan **ribuan operasi dengan beberapa baris kode**. C mendukung **3 bentuk perulangan**: `for`, `while`, dan `do-while` — semuanya memakai kondisi `int` (non-zero = lanjut).

## Loop for

```c
for (int i = 1; i <= 5; i++) {
    printf("Perulangan ke-%d\n", i);
}
```

Tiga bagian `inisialisasi; kondisi; update` bisa dikosongkan — misal `for (;;)` untuk loop tanpa batas yang harus dihentikan `break`. Pakai `for` saat jumlah iterasi diketahui dari counter atau indeks array.

```c
int angka[] = {10, 20, 30};
int n = sizeof(angka) / sizeof(angka[0]);
for (int i = 0; i < n; i++) {         // pola for berbasis indeks
    printf("%d\n", angka[i]);
}
```

## while & do-while

```c
int saldo = 100;
while (saldo > 0) {            // dicek SEBELUM isi loop — bisa 0 kali
    printf("Sisa: %d\n", saldo);
    saldo -= 30;
}

int coba = 0;                  // do-while: isi jalan dulu
do {
    coba++;
    printf("Percobaan %d\n", coba);
} while (coba < 3);
```

| Bentuk | Kapan dicek | Minimal jalan | Contoh use case |
|---|---|---|---|
| `for` | tiap awal iterasi | 0 kali | telusuri array 0..n-1 |
| `while` | sebelum isi | 0 kali | baca data sampai penanda berhenti |
| `do-while` | sesudah isi | **1 kali** | menu interaktif yang pasti tampil |

```c
for (;;) {                    // infinite loop eksplisit
    // ... kerja ...
    if (selesai) break;       // satu-satunya jalan keluar
}
```

## Break & Continue

```c
for (int i = 1; i <= 10; i++) {
    if (i == 4) continue;      // lewati angka 4
    if (i > 6) break;          // berhenti setelah 6
    printf("%d ", i);
}
printf("\n");                  // cetak: 1 2 3 5 6
```

`break` keluar dari loop terdekat; `continue` melewati sisa iterasi lalu lanjut. Dalam loop bersarang, `break`/`continue` hanya memengaruhi **satu** level loop tempatnya berada (tidak ada label seperti Java).

## Perulangan Bersarang

```c
for (int b = 1; b <= 3; b++) {
    for (int k = 1; k <= 3; k++) {
        printf("*");
    }
    printf("\n");
}
```

Menghasilkan pola bintang 3×3. Variabel loop luar dan dalam harus memakai nama berbeda agar tidak saling menimpa.

## 4 Pola Klasik

```c
// 1. Akumulasi
int total = 0;
for (int i = 0; i < n; i++) total += data[i];

// 2. Cari pertama (dengan flag + break)
int pertama = -1;
for (int i = 0; i < n; i++) {
    if (data[i] < 0) { pertama = data[i]; break; }
}

// 3. Filter → array baru (butuh counter terpisah)
int hasil[100], m = 0;
for (int i = 0; i < n; i++) {
    if (data[i] >= 75) hasil[m++] = data[i];
}

// 4. Hitung frekuensi
int ganjil = 0;
for (int i = 0; i < n; i++) {
    if (data[i] % 2 != 0) ganjil++;
}
```

Off-by-one adalah bug paling umum: gunakan `< n`, bukan `<= n`, ketika indeks berbasis 0.

## Menghitung dengan Loop

```c
int n = 10, faktorial = 1;
for (int i = 1; i <= n; i++) {
    faktorial *= i;
}
printf("%d! = %d\n", n, faktorial);  // 10! = 3628800
```

## Di Dunia Nyata

- **Menampilkan daftar harga produk**: loop for menelusuri array harga, mencetak nomor urut + nama + harga rapi.
- **Validasi input PIN**: do-while meminta input ulang sampai PIN benar atau percobaan habis.
- **Menghitung bunga majemuk 12 bulan**: while mengulang `saldo = saldo * (1 + bunga)` dengan counter bulan.
- **Mencari baris data log yang cocok**: for + `continue` melewati baris yang tidak mengandung kata kunci error.
- **Fibonacci untuk prediksi populasi**: dua variabel ditukar tiap iterasi sampai mencapai batas tertentu.

<div class="note">💡 Perhatikan overflow: <code>int</code> berhenti di sekitar 2,1 miliar. Faktorial cepat melampaui batas itu — gunakan <code>long long</code> untuk hasil besar, dan pastikan selalu ada update yang membuat kondisi loop menuju 0 (false) agar tidak infinite loop.</div>
