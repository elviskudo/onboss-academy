Function memecah program menjadi **bagian-bagian kecil yang fokus pada satu tugas** — lebih mudah diuji dan dipakai ulang. Di C, function adalah satu-satunya unit eksekusi: tidak ada method, tidak ada class.

## Mendefinisikan & Memanggil

```c
#include <stdio.h>

int luasPersegi(int sisi) {     // definisi
    return sisi * sisi;
}

void tampilkan(int nilai) {     // tanpa nilai kembalian
    printf("Nilai: %d\n", nilai);
}

int main(void) {
    printf("Luas: %d\n", luasPersegi(5));  // pemanggilan
    tampilkan(90);
    return 0;
}
```

Struktur: `<tipe_kembalian> <nama>(<parameter>) { ... }`. Parameter boleh 0 — tulis `(void)` agar eksplisit kosong: `int main(void)`. C **tidak punya** parameter default, named parameter, maupun overloading — beda nama function untuk beda keperluan.

## Prototype

```c
int hitung(int a, int b);       // prototype di bagian atas file

int main(void) {
    printf("%d\n", hitung(3, 4));
    return 0;
}

int hitung(int a, int b) {      // definisi boleh di bawah
    return a * 2 + b;
}
```

Prototype memungkinkan function saling memanggil tanpa peduli urutan definisinya — dan menjadi dasar pemisahan `.c` + `.h` di proyek multi-file.

## Pass by Value

```c
void gagalUbah(int x) {
    x = 999;              // hanya mengubah salinan
}

int main(void) {
    int a = 1;
    gagalUbah(a);
    printf("%d\n", a);     // tetap 1
    return 0;
}
```

Untuk benar-benar mengubah data asli, kirim **alamatnya** dengan pointer:

```c
void berhasilUbah(int *x) {
    *x = 999;             // menulis lewat alamat — variabel asli berubah
}
// pemanggilan: berhasilUbah(&a);
```

Pola "output parameter" ini standar di C, menggantikan kemampuan mengembalikan banyak nilai.

## Array sebagai Parameter

```c
int jumlah(int arr[], int panjang) {
    int total = 0;
    for (int i = 0; i < panjang; i++) total += arr[i];
    return total;
}
```

Saat array dikirim ke function, yang dikirim sebenarnya **pointer ke elemen pertama** — tidak ada salinan isi, dan ukuran array tidak ikut. Karena itu panjang selalu dikirim terpisah sebagai parameter kedua.

## Static Lokal & Variabel Global

```c
void hitungPanggilan(void) {
    static int hitung = 0;   // static: bertahan antar pemanggilan
    hitung++;
    printf("Dipanggil %d kali\n", hitung);
}
// pemanggilan 3x: 1, 2, 3
```

`static` lokal menyimpan state antar pemanggilan tanpa membuka akses ke seluruh program. Variabel **global** (di luar semua function) terlihat dari mana saja — gunakan hemat karena menyulitkan debugging: siapa pun bisa mengubahnya diam-diam.

## Rekursi

```c
long long faktorial(int n) {
    if (n <= 1) return 1;          // basis: titik berhenti
    return n * faktorial(n - 1);   // panggil diri sendiri
}
// faktorial(5) = 5 * 4 * 3 * 2 * 1 = 120
```

Rekursi tanpa basis = crash (stack overflow). C memanggil lewat stack — setiap level memakan memori. Untuk perhitungan linear, loop biasanya lebih hemat; rekursi dipakai untuk tree traversal dan divide-and-conquer.

## Function Pointer — Polimorfisme ala C

C **tidak punya OOP**, tapi punya **function pointer**: variabel yang menyimpan alamat function, bisa dipanggil lewat pointer dan ditukar saat runtime. Inilah mekanisme pengganti method override di bahasa prosedural:

```c
#include <stdio.h>

int tambah(int a, int b) { return a + b; }
int kurang(int a, int b) { return a - b; }

int hitung(int (*op)(int, int), int a, int b) {   // parameter = function pointer
    return op(a, b);                              // "memanggil method" lewat pointer
}

int main(void) {
    int (*pilih)(int, int) = tambah;   // pointer menunjuk tambah
    printf("%d\n", hitung(tambah, 10, 3));  // 13
    pilih = kurang;                          // tukar perilaku → polimorfisme
    printf("%d\n", hitung(pilih, 10, 3));    // 7
    return 0;
}
```

Pola ini menjadi dasar `qsort` (stdlib) dan vtable pattern pada chapter Struct — persis konsep yang di Java dilakukan interface.

## Variadic (Singkat)

`printf` sendiri adalah variadic: `int printf(const char *fmt, ...)`. Membaca argumen variadic memakai `<stdarg.h>` (`va_list`, `va_arg`) — jarang dibuat sendiri, cukup pahami bahwa `...` = jumlah parameter tak terbatas.

## Ringkasan Bentuk Function di C

| Bentuk | Sintaks | Kapan dipakai |
|---|---|---|
| Biasa | `int f(int a, int b)` | default — pass by value |
| Tanpa parameter | `int f(void)` | tanpa input, tulis `void` eksplisit |
| Array parameter | `int f(int arr[], int n)` | proses banyak data + panjang terpisah |
| Pointer parameter | `void f(int *x)` | ubah nilai pemanggil / hemat salinan struct |
| Function pointer | `void f(int (*op)(int,int))` | callback, strategi bisa ditukar |
| Variadic | `int f(const char *fmt, ...)` | jumlah argumen tak terbatas ala `printf` |
| Static lokal | `static int lokal = 0;` di dalam f | simpan state antar pemanggilan |
| Rekursif | `f memanggil f` dengan basis | tree, divide-and-conquer |

## Di Dunia Nyata

- **Validator form login**: function `int validasi(const char *user, const char *pass)` dipakai ulang di CLI, GUI, dan API handler.
- **Kalkulator interaktif**: function pointer `int (*op)(int,int)` dipilih sesuai operator yang diketik user.
- **Modul kalkulasi pajak**: prototype di `pajak.h` memungkinkan 5 file `.c` memanggil `hitungPPh` tanpa peduli urutan kompilasi.
- **Statistik pembacaan sensor**: `static int hitung` mencatat berapa kali function dipanggil sepanjang program hidup.
- **Sorting data mahasiswa**: mengirim function pembanding ke `qsort` — satu algoritma, kriteria banding apa pun.
