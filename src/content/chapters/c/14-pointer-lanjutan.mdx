Pointer adalah variabel yang menyimpan alamat memori. Bab 08 memperkenalkan dasarnya; sekarang kita masuk ke pola yang lebih advanced.

## Aritmetika Pointer

```c
int arr[4] = {10, 20, 30, 40};
int *p = arr;

printf("%d\n", *(p + 2));   /* 30 */
printf("%ld\n", (long)((p+1) - p));  /* 1 elemen */
```

`p + 1` maju `sizeof(*p)` byte, bukan 1 byte. Inilah sebabnya `arr[i]` setara `*(arr + i)`.

## Pointer ke Pointer

```c
void ubah(int **pp) {
    *pp = malloc(sizeof(int));
    **pp = 99;
}

int *p = NULL;
ubah(&p);
printf("%d\n", *p);
free(p);
```

Berguna bila fungsi perlu **mengganti alamat** yang disimpan pointer pemanggil.

## void Pointer

```c
void *mem = malloc(16);
int *i = mem;      /* di C, cast implisit boleh */
int *j = (int *)mem; /* di C++ wajib cast */
```

`void *` tidak bisa diinkrementasi atau di-dereference langsung karena ukuran tipenya tidak diketahui.

## Function Pointer

```c
int max(int a, int b) { return a > b ? a : b; }
int min(int a, int b) { return a < b ? a : b; }

int (*pilih)(int, int) = max;
printf("%d\n", pilih(3, 5));

pilih = min;
printf("%d\n", pilih(3, 5));
```

Function pointer adalah dasar callback, qsort comparator, dan plugin sederhana.

## const dengan Pointer

```c
const int *p;    /* nilai tidak bisa diubah lewat p */
int * const p;   /* alamat p tidak bisa diubah */
const int * const p; /* keduanya tidak bisa */
```

<div class="note">💡 Baca deklarasi dari kanan ke kiri: `int * const p` = "p adalah const pointer ke int". Kebiasaan ini menyelamatkanmu dari bug di kode sistem.</div>
