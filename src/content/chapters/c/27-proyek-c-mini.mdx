Proyek ini merangkum seluruh bab sebelumnya: struct, array, string, I/O, dan memori. Hasilnya adalah pencatat nilai sederhana yang bisa dikembangkan.

## Fitur

1. Input nama dan nilai siswa.
2. Tampilkan daftar dalam urutan tertentu.
3. Simpan ke file teks/CSV.
4. Menu: tambah, lihat, urutkan, keluar.

## Struktur Data

```c
typedef struct {
    char nama[32];
    int nilai;
} Siswa;

typedef struct {
    Siswa *item;
    int jumlah;
    int kapasitas;
} Daftar;
```

Strategi pertumbuhan kapasitas:

```c
if (d->jumlah == d->kapasitas) {
    int baru = d->kapasitas ? d->kapasitas * 2 : 4;
    Siswa *tmp = realloc(d->item, baru * sizeof *d->item);
    if (!tmp) return 0;      /* gagal, data lama tetap aman */
    d->item = tmp;
    d->kapasitas = baru;
}
```

## Pemisahan Modul

```
proyek/
├── siswa.h       ← deklarasi struct & fungsi
├── siswa.c       ← implementasi CRUD
├── util.h        ← helper input aman
├── util.c
├── main.c        ← menu
└── Makefile
```

## Makefile Minimal

```make
app: main.o siswa.o util.o
	gcc $^ -o $@

%.o: %.c
	gcc -Wall -Wextra -c $< -o $@

clean:
	rm -f *.o app
```

## Input Aman

Selalu buang newline setelah `scanf`, atau lebih baik baca semua input dengan `fgets` lalu parse dengan `sscanf`.

<div class="note">💡 Kembangkan proyek ini bertahap: pertama console saja, lalu tambahkan penyimpanan file, baru sorting dan pencarian. Setiap tahap harus bisa dikompilasi dan dijalankan sebelum lanjut.</div>
