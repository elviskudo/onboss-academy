Bit field memungkinkan struct menyimpan integer dengan jumlah bit tertentu. Ini menghemat memori saat banyak field kecil dibutuhkan.

## Sintaks

```c
struct Header {
    unsigned versi  : 4;   /* 0..15 */
    unsigned tipe   : 3;   /* 0..7  */
    unsigned flag   : 1;   /* 0/1   */
};
```

Compiler mengemas field-field itu ke dalam unit penyimpanan (biasanya `unsigned int`).

## Aturan

- Tipe yang diizinkan: `int`, `unsigned int`, `_Bool` (implementasi-defined untuk tipe lain).
- Lebar bit tidak boleh melebihi ukuran tipe dasar.
- Field tanpa nama bisa dipakai sebagai padding: `unsigned : 2;`.
- Tidak bisa mengambil alamat dengan `&`.

## Portabilitas

Urutan pengemasan (dari bit rendah atau tinggi), alignment, dan apakah `int` signed/unsigned semuanya **implementation-defined**. Jangan pakai bit field untuk format data yang dikirim antar platform — gunakan mask bitwise eksplisit.

```c
/* portable */
uint8_t mode = (nilai >> 2) & 0x07;
nilai = (nilai & ~0x1C) | (mode << 2);
```

## Kapan Dipakai

| Gunakan bit field | Gunakan bitwise manual |
|---|---|
| Register hardware lokal | Protokol jaringan |
| Flag internal | Format file lintas platform |
| Kode C single-platform | Library publik |

<div class="note">💡 Bit field menghemat memori, tapi bisa membuat kode lebih sulit di-debug. Pakai hanya kalau penghematan memori benar-benar berarti (misal jutaan objek atau embedded system).</div>
