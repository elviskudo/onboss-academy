Linked list adalah kumpulan node yang saling terhubung lewat pointer. Ia adalah dasar banyak struktur data lain: stack, queue, graph adjacency list.

## Struktur Node

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

`struct Node *next` boleh self-referential karena compiler hanya butuh ukuran pointer, bukan ukuran struktur lengkap.

## Operasi Dasar

```c
void push_depan(Node **head, int v) {
    Node *n = malloc(sizeof *n);
    if (!n) exit(1);
    n->data = v;
    n->next = *head;
    *head = n;
}

int hapus_nilai(Node **head, int v) {
    Node *cur = *head, *prev = NULL;
    while (cur && cur->data != v) {
        prev = cur; cur = cur->next;
    }
    if (!cur) return 0;
    if (prev) prev->next = cur->next;
    else *head = cur->next;
    free(cur);
    return 1;
}
```

Kenapa `Node **`? Karena fungsi mungkin perlu mengganti `head` itu sendiri.

## Traversal

```c
for (Node *p = head; p != NULL; p = p->next)
    printf("%d ", p->data);
```

## Variasi

| Jenis | Ciri |
|---|---|
| Singly | satu arah |
| Doubly | punya `prev` & `next` |
| Circular | node terakhir menunjuk head |
| Sentinel | node dummy di depan menyederhanakan kasus kosong |

## Perbandingan dengan Array

| Aspek | Array | Linked List |
|---|---|---|
| Akses indeks | O(1) | O(n) |
| Insert awal | O(n) | O(1) |
| Memori | kontigu | tersebar |
| Cache | ramah | kurang ramah |

<div class="note">💡 Selalu bersihkan list sebelum program keluar. Lakukan traversal dan `free()` setiap node — ini latihan terbaik untuk memahami kepemilikan memori di C.</div>
