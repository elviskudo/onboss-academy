Program yang hanya mencetak ke layar **kehilangan datanya saat ditutup**. File membuat hasil kerja bertahan. Bab ini menutup kurikulum C: dari file I/O sampai proyek mini yang memadukan struct, array, function, dan file.

## Membuka & Menutup File

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("data.txt", "w");   // buat/tulis
    if (fp == NULL) {
        printf("Gagal membuka file\n");
        return 1;
    }
    fprintf(fp, "Baris pertama\n");
    fclose(fp);                          // WAJIB ditutup
    return 0;
}
```

`FILE *` adalah pointer ke struktur internal stdio yang menyimpan posisi baca/tulis. **4 mode fopen** yang wajib hafal:

| Mode | Arti | File harus ada? | Isi lama |
|---|---|---|---|
| `"r"` | baca | ya | dipertahankan |
| `"w"` | tulis | tidak (dibuat) | **dihapus/hangus** |
| `"a"` | tambah di akhir | tidak (dibuat) | dipertahankan |
| `"r+"` | baca dan tulis | ya | dipertahankan |

Selalu periksa `fp == NULL` — file bisa gagal dibuka karena izin, path salah, atau disk penuh.

## Membaca File

```c
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) return 1;

char baris[100];
while (fgets(baris, sizeof(baris), fp) != NULL) {
    printf("%s", baris);      // fgets menyimpan newline di akhir
}
fclose(fp);
```

`fgets` membaca per baris, membatasi sesuai ukuran buffer (aman), dan mengembalikan `NULL` di akhir file. **Jangan pernah pakai `gets`** — sudah dihapus dari standar C karena tanpa batas buffer.

## fscanf & Membaca Terstruktur

```c
FILE *fp = fopen("siswa.csv", "r");
char nama[30];
int nim, nilai;
while (fscanf(fp, " %29[^,],%d,%d", nama, &nim, &nilai) == 3) {
    printf("%s (NIM %d): %d\n", nama, nim, nilai);
}
fclose(fp);
```

`%[^,]` membaca semua karakter sampai koma — trik CSV sederhana. Return value = jumlah field yang berhasil dibaca; loop berhenti saat tidak lagi 3.

## Menulis Data Terstruktur

```c
fprintf(fp, "%s,%d,%d\n", m.nama, m.nim, m.nilai);
// hasil di file: Sari,12345,90
```

Format CSV seperti ini mudah dibaca kembali dengan `fscanf`. Untuk angka desimal gunakan `%.2f`, untuk lebar kolom `%10d` — sama seperti printf.

## Pola Lengkap: Tulis → Tutup → Buka → Baca

```c
// tulis
FILE *w = fopen("nilai.txt", "w");
fprintf(w, "80\n90\n75\n");
fclose(w);                       // flush & tutup

// baca
FILE *r = fopen("nilai.txt", "r");
int v, total = 0;
while (fscanf(r, "%d", &v) == 1) total += v;
fclose(r);
printf("Total: %d\n", total);    // Total: 245
```

Urutan kerja file yang benar: **buka → periksa NULL → proses → tutup**. Lupa `fclose` membuat buffer stdio belum tertulis ke disk.

## Proyek Mini: Absensi dengan Persistensi

Rancangan program — memadukan seluruh materi bab 1–9:

1. **Struct** `Peserta { nama, hadir }` merepresentasikan satu record.
2. **Array of struct** menyimpan daftar peserta di memori.
3. **Function** `tambah`, `tampilkan`, `hitungKehadiran` mengoperasikannya (data lewat pointer).
4. **File CSV** menyimpan hasil — program bisa membacanya kembali setelah dijalankan ulang.

Jalankan contoh di bawah, lalu lanjutkan dengan fitur **membaca kembali file** ke array of struct saat program dimulai. Untuk proyek multi-file: pisahkan struct ke `peserta.h`, function ke `peserta.c`, dan `main` ke `main.c`, lalu kompilasi bersama: `gcc main.c peserta.c -o absensi`.

## Di Dunia Nyata

- **Log monitoring server**: program menulis timestamp + status ke `monitor.log` dengan mode `"a"` — insinyur memeriksa riwayat kegagalan.
- **Konfigurasi aplikasi**: file `config.txt` dibaca saat startup dengan `fscanf` — port, path, dan timeout diubah tanpa mengompilasi ulang.
- **Backup data klinik**: array of struct pasien diserialisasi ke CSV tiap malam — data aman walau listrik padam.
- **Sistem kasir POS**: struk thermal dicetak lewat `fprintf` ke file perangkat (`/dev/usb/lp0`) — pola yang sama dengan file biasa.
- **Leaderboard game offline**: skor pemain ditambah (`"a"`) ke `skor.txt`, lalu dibaca ulang dan diurutkan saat game dibuka.
