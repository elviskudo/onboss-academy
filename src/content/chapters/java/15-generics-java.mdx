Generics membuat collection dan class bisa dipakai untuk banyak tipe tanpa mengorbankan keamanan tipe.

## Kenapa Generics?

```java
List daftar = new ArrayList();      // raw type (hindari)
daftar.add("teks");
daftar.add(123);                    // compile OK, runtime bahaya
String s = (String) daftar.get(1);  // ClassCastException!

List<String> aman = new ArrayList<>();
aman.add("teks");
// aman.add(123);  ← error saat COMPILE
```

## Class Generik

```java
class Pasangan<K, V> {
    private K kunci;
    private V nilai;

    Pasangan(K kunci, V nilai) {
        this.kunci = kunci;
        this.nilai = nilai;
    }

    K kunci() { return kunci; }
    V nilai() { return nilai; }
}

Pasangan<String, Integer> p = new Pasangan<>("nilai", 90);
```

Diamond operator `<>` (Java 7+) menghindari pengulangan tipe di sisi kanan.

## Method Generik

```java
public static <T> T pertama(List<T> list) {
    return list.isEmpty() ? null : list.get(0);
}
```

## Bounded Type

```java
class Statistik<T extends Number> {
    double rata(List<T> data) {
        double total = 0;
        for (T n : data) total += n.doubleValue();
        return total / data.size();
    }
}
```

`T extends Number` juga bisa berupa `T extends Number & Comparable<T>` (batas jamak dengan interface).

## Wildcard

| Wildcard | Makna | Kegunaan |
|---|---|---|
| `List<?>` | tipe apa pun | konsumsi netral |
| `List<? extends T>` | T atau turunan | **produser** (baca) |
| `List<? super T>` | T atau induk | **konsumen** (tulis) |

```java
public static double jumlah(List<? extends Number> data) { ... }  // baca
public static void tambah(List<? super Integer> data, int n) {
    data.add(n);  // aman
}
```

## Type Erasure

Saat kompilasi, `List<String>` berubah menjadi `List` biasa. Itu sebabnya kamu tidak bisa `new T()` atau mengecek `obj instanceof List<String>` —Informasi tipe hilang di runtime.

<div class="note">💡 Ingat pepatah <b>PECS</b>: <i>Producer extends, Consumer super</i>. Kalau method hanya membaca dari parameter, pakai `? extends`; kalau hanya menulis ke parameter, pakai `? super`.</div>
