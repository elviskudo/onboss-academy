`String` di Java adalah object **immutable**. Setiap kali kamu menulis `s += "x"`, JVM membuat String baru dan membuang yang lama. Dalam loop panjang ini sangat boros.

## StringBuilder

```java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i).append(",");
}
String hasil = sb.toString();
```

Method umum:

| Method | Fungsi |
|---|---|
| `append(...)` | tambah di akhir (bisa dirantai) |
| `insert(pos, ...)` | sisipkan di posisi |
| `replace(a, b, s)` | ganti rentang |
| `delete(a, b)` | hapus rentang |
| `reverse()` | balik urutan |
| `capacity()` / `ensureCapacity(n)` | kelola ukuran buffer |

## StringBuilder vs StringBuffer

```java
StringBuilder cepat = new StringBuilder();   // single-thread → pilih ini
StringBuffer aman = new StringBuffer();       // multi-thread → sinkron
```

Kebanyakan kode aplikasi berjalan di satu thread per request, sehingga `StringBuilder` adalah pilihan default.

## String.join & String.format

```java
String gabung = String.join(", ", "merah", "hijau", "biru");
String teks = String.format("Nama: %s, Nilai: %d", nama, nilai);
```

Untuk Template yang lebih kompleks, pertimbangkan `String.formatted()` (Java 15+).

<div class="note">💡 Compiler modern kadang mengoptimalkan `s += x` di dalam ekspresi tunggal menjadi StringBuilder otomatis. Tapi di dalam loop, optimasi itu tidak terjadi — tetap tulis StringBuilder secara eksplisit.</div>
