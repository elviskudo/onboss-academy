Bab terakhir memadukan **collection** yang sudah dipelajarinya menjadi satu program konsol yang benar-benar berguna. Collection Framework Java adalah pustaka wadah data siap pakai — tidak perlu menulis ulang list dan map dari nol.

## Hirarki Collection Framework

Java punya **4 interface utama** di `java.util.Collection` plus **1 interface pemetaan** terpisah (`Map`):

| Interface | Ciri | Implementasi populer | Urutan? | Duplikat? |
|---|---|---|---|---|
| `List` | berurutan, berindeks | `ArrayList`, `LinkedList` | ya | ya |
| `Set` | tanpa duplikat | `HashSet`, `TreeSet` | tergantung | **tidak** |
| `Queue` | antrean (FIFO) | `ArrayDeque`, `PriorityQueue` | ya | tergantung |
| `Deque` | dua ujung | `ArrayDeque` | ya | tergantung |
| `Map` | kunci → nilai | `HashMap`, `TreeMap` | tergantung | kunci unik |

Panduan cepat: butuh list berindeks → `List`; butuh keunikan → `Set`; butuh antrean/proses berurutan → `Queue`; butuh lookup kunci → `Map`.

## ArrayList: 12 Method Inti

```java
import java.util.ArrayList;

ArrayList<String> tugas = new ArrayList<>();
tugas.add("Belajar Java");
tugas.add("Review pull request");
tugas.add(1, "Kerjakan latihan");     // sisipkan di tengah

System.out.println(tugas.size());     // 3
System.out.println(tugas.get(0));
tugas.set(0, "Belajar Java SE");      // ganti elemen indeks 0
tugas.remove(0);                      // hapus berdasarkan indeks
tugas.remove("Review pull request");  // hapus berdasarkan isi

for (int i = 0; i < tugas.size(); i++) {
    System.out.println((i + 1) + ". " + tugas.get(i));
}
```

Keduabelas method yang wajib dikuasai: `add`, `add(i,e)`, `get`, `set`, `remove(int)`, `remove(Object)`, `size`, `contains`, `indexOf`, `isEmpty`, `clear`, `sort` (Java 8+).

## HashMap untuk Data Berpasangan

```java
import java.util.HashMap;

HashMap<String, Integer> skor = new HashMap<>();
skor.put("Sari", 90);
skor.put("Budi", 85);

System.out.println(skor.get("Sari"));      // 90
System.out.println(skor.containsKey("Budi")); // true
System.out.println(skor.getOrDefault("Rina", 0)); // 0 jika tak ada

for (String nama : skor.keySet()) {
    System.out.println(nama + " → " + skor.get(nama));
}
for (Integer nilai : skor.values()) {
    System.out.println("Nilai: " + nilai);
}
for (var entri : skor.entrySet()) {         // kunci + nilai sekaligus
    System.out.println(entri.getKey() + " = " + entri.getValue());
}
```

Kunci unik, nilai boleh diubah berkali-kali — cocok untuk kamus, penghitung kata, atau konfigurasi. Karena HashMap tidak berurutan, gunakan `TreeMap` bila butuh iterasi terurut berdasarkan kunci.

## Pola Program: Input → Proses → Output

```java
ArrayList<Integer> angka = new ArrayList<>();
angka.add(5);
angka.add(8);
angka.add(3);

int total = 0;
for (int n : angka) total += n;                 // proses
System.out.println("Total = " + total);         // output
```

Walau tanpa input keyboard, pola ini tetap berlaku: data disiapkan, diolah, lalu ditampilkan. Semua proyek di bawah memakai kerangka yang sama.

## Proyek Mini: Manajemen Tugas

Rancang dulu sebelum mengetik kode:

1. `ArrayList<String> daftar` menyimpan judul tugas (penomoran otomatis).
2. `HashMap<String, Boolean> status` menyimpan selesai/belum per judul.
3. Method `tambah`, `selesai`, `tampilkan`, `hapus` mengoperasikannya.
4. `hitungProgres` menghitung persentase selesai — memadukan koleksi + looping.

Jalankan contoh di bawah, lalu tambahkan fitur **hapus tugas** dan **hitung progres persen** sebagai latihan. Perhatikan penggunaan `Boolean.TRUE.equals(...)` — aman dari NPE dibanding `status.get(t)` yang bisa null.

## Di Dunia Nyata

- **To-do list app**: ArrayList judul + HashMap status — model data inti Todoist/Any.do versi mini.
- **Sistem nilai kelas**: HashMap `nama → nilai`, iterasi `entrySet()` untuk hitung rata-rata dan cari peringkat.
- **Shopping cart**: `ArrayList<Produk>` dengan `add`/`remove` saat user menambah/menghapus item.
- **Counter frekuensi kata**: HashMap `kata → jumlah` — dasar analisis sentimen sederhana dan word cloud.
- **Validasi username unik**: `HashSet<String> terdaftar` menolak duplikat secara struktural — tanpa pengecekan manual.
