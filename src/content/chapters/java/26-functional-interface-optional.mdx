Java modern mendorong gaya lebih deklaratif: Optional untuk nilai yang bisa tidak ada, method reference, dan pipeline Stream.

## Optional

```java
Optional<User> user = repository.cari(id);

user.ifPresent(u -> System.out.println(u.nama()));
String nama = user.map(User::nama).orElse("Anonim");
```

## Membuat Optional

```java
Optional.of("ada");            // harus non-null
Optional.ofNullable(bisaNull); // aman
Optional.empty();              // kosong
```

## orElse vs orElseGet vs orElseThrow

```java
String a = opt.orElse(buatDefaultMahal());   // dipanggil selalu
String b = opt.orElseGet(() -> buatDefaultMahal()); // hanya jika kosong
String c = opt.orElseThrow(() -> new NotFoundException());
```

Gunakan `orElseGet` bila pembuatan default mahal (query, I/O).

## Hindari Pola Ini

```java
if (opt.isPresent()) { return opt.get(); }  // ← sama saja dengan null check
```

Lebih baik: `map`, `filter`, `ifPresent`, `orElse`.

## Default & Static Method di Interface

```java
interface Pembayaran {
    double total();

    default double pajak() { return total() * 0.1; }

    static String deskripsi() { return "Modul pembayaran"; }
}
```

Default method memungkinkan menambah method ke interface tanpa memaksa semua implementasi berubah — kunci evolusi API JDK.

<div class="note">💡 Optional paling cocok sebagai <b>return value</b>. Jangan dipakai sebagai field atau parameter method — itu menambah objek wrapper tanpa manfaat besar dan membuat API lebih berisik.</div>
