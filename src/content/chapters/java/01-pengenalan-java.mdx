Java adalah bahasa berorientasi objek yang berjalan di **JVM**: satu kode dikompilasi sekali, dijalankan di sistem operasi mana pun. Chapter ini memetakan anatomi bahasa sebelum kamu menyentuh tipe data, operator, dan OOP di bab-bab berikutnya.

## Sekilas Sejarah

Java lahir tahun 1991 di Sun Microsystems (tim Green Project, dipimpin James Gosling), dirilis publik pada 1995. Filosofi awalnya sederhana: perangkat konsumen berbeda-beda, tapi kodenya harus bisa jalan di mana saja. Prinsip itulah yang melahirkan slogan **Write Once, Run Anywhere (WORA)**. Oracle mengakuisisi Sun pada 2010; hari ini Java dipakai di server-side, aplikasi Android, sistem bank, dan big data (Apache Hadoop, Elasticsearch).

## Hello World

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Halo, Dunia!");
    }
}
```

Nama file **wajib sama** dengan nama class publik: `Main.java`. `println` mencetak lalu ganti baris, `print` berhenti di akhir teks.

## Kompilasi & Eksekusi

```bash
javac Main.java
java Main
```

Langkah pertama menghasilkan `Main.class` (bytecode), langkah kedua menjalankannya lewat JVM. Beda dengan bahasa yang dikompilasi langsung ke kode mesin (C/C++) atau diinterpretasi baris demi baris (Python), Java menempatkan JVM di tengah sebagai lapisan portabilitas.

## Anatomi Program

```java
public class Main {                      // satu class publik per file
    public static void main(String[] args) {   // titik masuk program
        int umur = 20;                    // deklarasi + nilai awal
        System.out.println("Umur: " + umur);
    }
}
```

Lima kata kunci yang wajib kamu pahami di sini:

| Kata Kunci | Arti | Fungsi |
|---|---|---|
| `public` | akses terbuka | class/method bisa dipakai dari package lain |
| `class` | wadah objek | tempat field dan method didefinisikan |
| `static` | milik class | bisa dipanggil tanpa membuat object |
| `void` | tanpa kembalian | method tidak mengembalikan nilai |
| `String[] args` | argumen CLI | parameter yang dikirim dari baris perintah |

## Paradigma & Sifat Bahasa

Java adalah bahasa **berorientasi objek penuh**: hampir semua kode harus berada di dalam class (kecuali static initializer). Ia juga **statis tipenya** — tipe dicek saat kompilasi, bukan saat runtime, sehingga banyak bug tertangkap sebelum program dijalankan. Java punya **garbage collector** yang membuang object yang tak terpakai secara otomatis, dan **membuang pointer aritmetika** ala C demi keamanan memori.

## JVM: Write Once, Run Anywhere

Java tidak mem-pesan langsung ke CPU. Ia mengompilasi ke **bytecode** yang dijalankan JVM, sehingga file `.class` yang sama jalan di Windows, macOS, dan Linux.

| Komponen | Isi | Kapan dipakai |
|---|---|---|
| **JDK** | javac, debugger, JRE, tool library | saat menulis & mengompilasi kode |
| **JRE** | library standar + JVM | saat hanya menjalankan aplikasi |
| **JVM** | mesin bytecode, garbage collector | ada di dalam JDK dan JRE |

Alur lengkapnya: `.java` → **javac** → `.class` (bytecode) → **JVM** → kode mesin CPU.

## Di Dunia Nyata

- **Backend perbankan**: core system bank (misalnya untuk transfer dan mutasi rekening) umum ditulis Java karena tipenya ketat dan ada mekanisme exception yang rapi.
- **Aplikasi Android**: sejak Android Studio resmi, bahasa utama pengembangan Android adalah Java (dan Kotlin) yang berjalan di mesin virtual (ART, turunan konsep JVM).
- **Server REST API**: framework seperti Spring Boot menjadi tulang punggung ribuan layanan mikroservis e-commerce dan logistik.
- **Big data & search**: Elasticsearch dan Hadoop berbasis JVM sehingga bisa memproses terabyte data lintas platform.
- **Desktop enterprise**: aplikasi point-of-sale dan sistem gudang sering dibangun dengan Java Swing/JavaFX yang dibundel bersama JVM-nya sendiri.

<div class="note">💡 Bedakan: <b>JDK</b> (tool kompilasi + runtime, dipasang saat belajar), <b>JRE</b> (hanya runtime), <b>JVM</b> (mesin bytecode di dalam keduanya). Menulis kode butuh JDK; jalankan <code>java -version</code> untuk memastikan terpasang sebelum latihan pertama.</div>
