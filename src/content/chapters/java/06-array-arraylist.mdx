Array menyimpan **sekumpulan data bertipe sama** dalam satu nama — jauh lebih rapi daripada membuat `nilai1`, `nilai2`, `nilai3`… Bab ini membandingkan dua wadah utama Java: array (statis) dan ArrayList (dinamis).

## Deklarasi & Akses Array

```java
int[] nilai = {80, 90, 75, 88};   // array literal
String[] nama = new String[3];     // array kosong, isi 3 slot (null)
nilai[0] = 85;                     // ubah elemen pertama
System.out.println(nilai[2]);      // 75
System.out.println(nilai.length);  // 4 — atribut, bukan method()
```

Setiap akses memakai indeks `0` sampai `length - 1`. Indeks di luar batas = `ArrayIndexOutOfBoundsException`. Java **tidak** memeriksa batas array diam-diam seperti Python — salah indeks langsung error, yang justru membantu menemukan bug.

## Menelusuri Array

```java
int total = 0;
for (int i = 0; i < nilai.length; i++) {
    total += nilai[i];
}
for (int n : nilai) {              // for-each: lebih ringkas
    System.out.println(n);
}
```

## 6 Method Utility `java.util.Arrays`

| Method | Fungsi | Contoh hasil |
|---|---|---|
| `Arrays.sort(a)` | urutkan ascending | `{88,90}` → `{88, 90}` |
| `Arrays.binarySearch(a, x)` | cari indeks (array harus terurut) | `2` atau `-(posisi sisip)-1` |
| `Arrays.fill(a, v)` | isi semua elemen dengan v | `{0,0,0}` |
| `Arrays.equals(a, b)` | bandingkan isi dua array | `true`/`false` |
| `Arrays.copyOf(a, n)` | salin dengan panjang baru | array baru |
| `Arrays.toString(a)` | ubah ke teks berformat | `"[80, 90, 75]"` |

```java
int[] data = {42, 7, 19};
Arrays.sort(data);                              // {7, 19, 42}
System.out.println(Arrays.toString(data));     // [7, 19, 42]
System.out.println(Arrays.binarySearch(data, 19)); // 1
```

## Array Dua Dimensi

```java
int[][] matriks = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(matriks[1][2]); // 6
System.out.println(matriks.length); // 2 baris
System.out.println(matriks[0].length); // 3 kolom
```

Cocok untuk tabel, grid, atau papan permainan seperti tic-tac-toe.

## ArrayList: Wadah Dinamis

```java
import java.util.ArrayList;

ArrayList<String> kota = new ArrayList<>();
kota.add("Jakarta");        // tambah di akhir
kota.add("Bandung");
kota.add(1, "Surabaya");    // sisipkan di indeks 1
kota.remove("Surabaya");    // hapus berdasarkan isi (return boolean)
kota.remove(0);             // hapus berdasarkan indeks (return elemen)
System.out.println(kota.size() + " kota: " + kota.get(0));
System.out.println(kota.contains("Bandung"));  // true
System.out.println(kota.indexOf("Bandung"));   // 1, -1 jika tak ada
kota.clear();               // kosongkan
```

**10 method ArrayList yang paling sering dipakai**: `add`, `add(index, e)`, `get`, `set`, `remove`, `size`, `contains`, `indexOf`, `isEmpty`, `clear`. Catat: `size()` adalah method, `length` adalah atribut — ini sumber salah tulis paling umum.

```java
ArrayList<Integer> angka = new ArrayList<>();
angka.add(10);              // autoboxing: int → Integer
int pertama = angka.get(0); // unboxing: Integer → int
```

Karena generic `<Integer>`, ArrayList tidak menerima primitif langsung — autoboxing menanganinya otomatis.

## Array vs ArrayList vs Map — Kapan Mana?

| Kondisi | Pilihan | Alasan |
|---|---|---|
| Ukuran tetap, tipe sama, akses cepat by index | **array** | hemat memori, cepat, ada `length` bawaan |
| Ukuran berubah, sering tambah/hapus | **ArrayList** | dinamis, banyak method siap pakai |
| Cari "nilai dari kunci" (nama → skor) | **HashMap** | pencarian hampir O(1) |
| Data beda tipe jadi satu entitas | **object/class** | field terdeskripsi jelas |

## Kejatuhan Umum

```java
String[] nama = new String[3];
// semua elemen = null, bukan string kosong!
// nama[0].length() → NullPointerException
System.out.println(new int[]{1,2} == new int[]{1,2}); // false — dua objek berbeda
```

Array bersifat **mutable** (isi bisa diganti via index), tapi **panjangnya immutable**. Untuk membandingkan isi dua array pakai `Arrays.equals`, bukan `==`.

## Di Dunia Nyata

- **Menyimpan nilai 30 siswa satu kelas**: `double[] nilai = new double[30]` — rata-rata, min, maks dihitung satu loop.
- **Keranjang belanja**: `ArrayList<Produk> keranjang` — user bebas menambah/menghapus item saat checkout.
- **Papan tic-tac-toe 3×3**: `String[][] papan = new String[3][3]` — cek menang lewat baris/kolom/diagonal.
- **Log server dengan batas memori**: `ArrayList` dengan `remove(0)` saat melebihi 1000 entri (ring buffer sederhana).
- **Leaderboard turnamen**: `Arrays.sort` pada array skor lalu cetak 10 teratas — dasar fitur ranking game.

<div class="note">💡 Array cocok untuk data berukuran tetap (koordinat, matriks, buffer). ArrayList untuk daftar yang sering bertambah — seperti daftar tugas atau keranjang belanja. Di bawah kap, ArrayList hanyalah array yang diganti ukurannya saat penuh — jadi untuk data ratusan ribu elemen dengan akses random, array mentah tetap lebih cepat.</div>
