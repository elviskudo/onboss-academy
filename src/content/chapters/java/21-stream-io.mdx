Stream adalah abstraksi aliran data. Java punya dua keluarga besar: **byte stream** (`InputStream`/`OutputStream`) untuk data biner, dan **character stream** (`Reader`/`Writer`) untuk teks.

## Peta Kelas

| Kebutuhan | Byte | Character |
|---|---|---|
| File | FileInputStream | FileReader |
| Buffer | BufferedInputStream | BufferedReader |
| Konversi | InputStreamReader | — |
| Cetak | PrintStream | PrintWriter |
| Object | ObjectInputStream | — |

## Membaca Teks Baris per Baris

```java
try (BufferedReader r = new BufferedReader(new FileReader("data.txt"))) {
    r.lines().forEach(System.out::println);
}
```

`FileReader` memakai charset default platform — untuk hasil konsisten, gunakan `Files.newBufferedReader(path, StandardCharsets.UTF_8)`.

## Menulis

```java
try (PrintWriter out = new PrintWriter("hasil.txt", "UTF-8")) {
    out.println("Baris satu");
    out.printf("Nilai: %d%n", 90);
}
```

## Copy Biner

```java
try (InputStream in = new FileInputStream("a.png");
     OutputStream out = new FileOutputStream("b.png")) {
    in.transferTo(out);   // Java 9+
}
```

## Serialisasi

```java
class Siswa implements Serializable {
    private static final long serialVersionUID = 1L;
    String nama;
}

try (ObjectOutputStream o = new ObjectOutputStream(new FileOutputStream("siswa.bin"))) {
    o.writeObject(new Siswa());
}
```

Serialisasi Java punya risiko keamanan saat membaca data tidak tepercaya — untuk pertukaran antar sistem, lebih baik JSON.

<div class="note">💡 Selalu tutup stream, terutama yang menulis — buffer yang belum di-flush bisa membuat file kosong atau terpotong. try-with-resources adalah jawabannya.</div>
