API `java.time` (Java 8) menggantikan `Date` dan `Calendar` yang rawan bug dan mutable. Semua kelas di sini **immutable** dan thread-safe.

## Kelas Inti

| Kelas | Isi | Contoh |
|---|---|---|
| `LocalDate` | tanggal | `2026-11-20` |
| `LocalTime` | jam | `14:30:00` |
| `LocalDateTime` | keduanya | `2026-11-20T14:30` |
| `ZonedDateTime` | + zona | `...+07:00[Asia/Jakarta]` |
| `Instant` | timestamp UTC | mesin/timezone |

```java
LocalDate hari = LocalDate.of(2026, 11, 20);
LocalTime jam = LocalTime.of(9, 30);
LocalDateTime rapat = LocalDateTime.of(hari, jam);
```

## Manipulasi

```java
LocalDate besok = hari.plusDays(1);
LocalDate kemarin = hari.minusWeeks(1);
LocalDate akhirBulan = hari.with(TemporalAdjusters.lastDayOfMonth());
```

Karena immutable, setiap operasi mengembalikan objek **baru** — objek asli tidak berubah.

## Selisih

```java
Period p = Period.between(ultah, LocalDate.now());
long hari = ChronoUnit.DAYS.between(ultah, LocalDate.now());

Duration d = Duration.between(mulai, selesai);
System.out.println(d.toHours());
```

## Format & Parse

```java
DateTimeFormatter f = DateTimeFormatter.ofPattern("dd/MM/yyyy");
String teks = LocalDate.now().format(f);
LocalDate balik = LocalDate.parse("20/11/2026", f);
```

## Zona Waktu

```java
ZonedDateTime jakarta = ZonedDateTime.now(ZoneId.of("Asia/Jakarta"));
Instant UTC = Instant.now();
```

Selalu simpan timestamp di database sebagai UTC; konversi ke zona lokal hanya saat ditampilkan.

<div class="note">💡 Jangan pakai `SimpleDateFormat` di kode baru — kelas itu mutable dan tidak thread-safe. `DateTimeFormatter` adalah penggantinya yang immutable.</div>
