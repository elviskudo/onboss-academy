Hampir setiap program memproses teks — nama file, pesan chat, data CSV. Java punya **ratusan method String**; yang penting hafal yang paling sering dipakai dan memahami sifat immutability-nya.

## String Itu Immutable

```java
String a = "Halo";
String b = a.toUpperCase();   // a TETAP "Halo", b = "HALO"
String c = a + " Dunia";      // object String BARU dibuat
```

String tidak bisa diubah setelah dibuat. Setiap operasi menghasilkan object baru. Konsekuensi: String aman dipakai bersama (thread-safe, bisa jadi HashMap key), tapi penyusunan berulang dalam loop boros memori — pakai StringBuilder.

## 15 Method String Wajib

```java
String teks = "Belajar Java";
teks.length();            // 11
teks.charAt(0);           // 'B'
teks.substring(7);        // "Java" — mulai indeks 7
teks.substring(0, 6);     // "Belajar" — [0, 6)
teks.indexOf("Java");     // 7, -1 jika tidak ada
teks.lastIndexOf('a');    // 9
teks.contains("ava");     // true
teks.startsWith("Bel");   // true
teks.endsWith("Java");    // true
teks.toUpperCase();       // "BELAJAR JAVA"
teks.toLowerCase();       // "belajar java"
teks.replace('a', 'o');   // "Belajar Jovo"
teks.replace("Java", "C");// ganti substring
teks.isBlank();           // false
teks.isEmpty();           // false (kosong ≠ blank)
```

Tabel ringkas pemakaian:

| Method | Fungsi | Kapan dipakai |
|---|---|---|
| `length()` | jumlah karakter | validasi panjang PIN/nama |
| `charAt(i)` | karakter ke-i | cek awalan/huruf pertama |
| `substring(a,b)` | potong teks | ekstrak tanggal, kode voucher |
| `indexOf(s)` | posisi substring | cari delimiter, validasi format |
| `contains/startsWith/endsWith` | cek keberadaan | filter prefix, extension file |
| `replace(a,b)` | ganti karakter/substring | bersihkan data, mask nomor |
| `toUpperCase/toLowerCase` | normalisasi huruf | perbandingan case-insensitive |
| `trim()` | buang spasi ujung | bersihkan input user |
| `split(regex)` | teks → array | parse CSV, tokenisasi |
| `equals/equalsIgnoreCase` | bandingkan isi | autentikasi, pencocokan menu |

## Trim, Split & Join

```java
String data = "Sari,Budi,Rina";
String[] nama = data.split(",");
System.out.println(nama[1]);                 // Budi
System.out.println(nama.length);             // 3

String gabung = String.join(" | ", nama);    // Sari | Budi | Rina
String berantakan = "  halo  ";
System.out.println("[" + berantakan.trim() + "]");  // [halo]
```

`split` menerima **regex** — untuk memisah berdasarkan titik koma atau tanda kurung, sisipkan escape: `split("[.,;]")`.

## equals vs ==

```java
String a = new String("java");
String b = new String("java");
System.out.println(a == b);          // false — dua object berbeda
System.out.println(a.equals(b));     // true  — isi sama
System.out.println(a.equalsIgnoreCase("JAVA")); // true
System.out.println(a.compareTo("jb")); // -1 — urutan leksikografis
```

`==` membandingkan referensi memori; `equals` membandingkan isi. Untuk String literal interned, hasil `==` bisa kebetulan true — jangan mengandalkannya. `compareTo` dipakai saat mengurutkan daftar nama.

## StringBuilder (Mutable)

```java
StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 3; i++) {
    sb.append("ke-").append(i).append(" ");
}
String hasil = sb.toString();   // "ke-1 ke-2 ke-3 "
sb.reverse();                   // mutasi in-place
sb.insert(0, ">> ");            // sisipkan di awal
```

StringBuilder punya `append`, `insert`, `reverse`, `delete`, `substring` — tapi **tidak** punya `equals` (bandingkan via `toString()` dulu). Untuk teks multi-thread, `StringBuffer` (sinkron) lebih aman tapi lebih lambat.

## Di Dunia Nyata

- **Masking nomor rekening**: `noRek.substring(0, 4) + "****" + noRek.substring(noRek.length()-4)` menampilkan hanya 4 digit terakhir.
- **Validasi email**: `email.contains("@") && email.endsWith(".com") && !email.isBlank()` — penyaringan awal sebelum kirim OTP.
- **Parsing log server**: `log.split(" ")` memecah `"192.168.1.1 - - [tanggal] \"GET /api\""` menjadi field-field untuk analisis.
- **Search & replace massal (CMS)**: `konten.replace("produk lama", "produk baru")` saat rename brand di ribuan artikel.
- **Merakit laporan CSV**: StringBuilder menggabungkan baris demi baris dalam loop 10.000 data — 10× lebih cepat daripada `+=` pada String.

<div class="note">💡 String <b>immutable</b>: setiap method menghasilkan string baru. Loop <code>teks = teks + "x"</code> ratusan kali membuang object lama dan memicu garbage collector — gunakan StringBuilder. Ringkasan aman: <b>baca pakai String, rakit pakai StringBuilder</b>.</div>
