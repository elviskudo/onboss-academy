Array multidimensi di Java adalah **array of arrays**. Ini penting untuk matriks, grid game, dan tabel data.

## Array 2D

```java
int[][] m = new int[3][4];   // 3 baris, 4 kolom
m[0][1] = 7;

int[][] literal = {
    {1, 2, 3},
    {4, 5, 6}
};
```

## Iterasi

```java
for (int i = 0; i < m.length; i++) {
    for (int j = 0; j < m[i].length; j++) {
        System.out.print(m[i][j] + " ");
    }
    System.out.println();
}
```

Versi for-each lebih ringkas:

```java
for (int[] baris : m)
    for (int nilai : baris)
        System.out.print(nilai + " ");
```

## Array Bergigi

```java
int[][] segitiga = new int[3][];
segitiga[0] = new int[1];
segitiga[1] = new int[2];
segitiga[2] = new int[3];
```

Panjang tiap baris berbeda — selalu pakai `baris.length`, jangan asumsikan sama.

## Arrays.toString / deepToString

```java
import java.util.Arrays;

System.out.println(Arrays.toString(m[0]));     // [1, 2, 3]
System.out.println(Arrays.deepToString(m));    // [[1, 2, 3], [4, 5, 6]]
```

<div class="note">💡 Untuk data berbentuk tabel dengan ukuran berubah, pertimbangkan `List<List<T>>` atau library matriks seperti EJML/Apache Commons Math — array 2D ukurannya tetap setelah dibuat.</div>
