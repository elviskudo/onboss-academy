Enum adalah tipe khusus untuk sekumpulan nilai konstan yang sudah diketahui: hari dalam minggu, status pesanan, level akses.

## Enum Dasar

```java
enum Hari { SENIN, SELASA, RABU, KAMIS, JUMAT, SABTU, MINGGU }

Hari h = Hari.RABU;
if (h == Hari.RABU) { ... }
```

## Enum dengan Data

```java
enum Level {
    RENDAH(1, "Dasar"),
    SEDANG(2, "Menengah"),
    TINGGI(3, "Mahir");

    private final int kode;
    private final String nama;

    Level(int kode, String nama) {
        this.kode = kode;
        this.nama = nama;
    }

    int kode() { return kode; }
    String nama() { return nama; }
}
```

Constructor enum selalu `private` — tidak bisa dipanggil dari luar.

## Enum dalam switch

```java
switch (status) {
    case BARU   -> System.out.println("Antrian");
    case AKTIF  -> System.out.println("Diproses");
    case SELESAI -> System.out.println("Arsip");
}
```

Sejak Java 14, switch expression bisa mengembalikan nilai:

```java
String pesan = switch (status) {
    case BARU -> "Menunggu";
    default -> "Unknown";
};
```

## Enum vs Konstanta String

| Aspek | Enum | `static final String` |
|---|---|---|
| Type-safe | Ya | Tidak (salah ketik tetap compile) |
| Jumlah nilai | Terbatas & diketahui | Bebas |
| Bisa punya method | Ya | Tidak |
| Cocok untuk | Status, mode, kategori | Kunci konfigurasi, URL |

<div class="note">💡 Enum secara internal adalah class, jadi bisa mengimplementasikan interface. Ini berguna untuk pola strategi: tiap konstanta mengoverride method yang sama dengan perilaku berbeda.</div>
