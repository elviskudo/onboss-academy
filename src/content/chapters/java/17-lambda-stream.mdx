Lambda (Java 8) membuat kode lebih ringkas, terutama bersama Stream API. Kombinasi keduanya menggantikan banyak loop boilerplate.

## Lambda

```java
// tanpa lambda
Comparator<String> c = new Comparator<>() {
    public int compare(String a, String b) { return a.length() - b.length(); }
};

// dengan lambda
Comparator<String> c = (a, b) -> a.length() - b.length();
```

Bentuk: `(parameter) -> ekspresi` atau `(parameter) -> { blok }`.

## Functional Interface Bawaan

| Interface | Method | Contoh |
|---|---|---|
| `Runnable` | `run()` | thread |
| `Consumer<T>` | `accept(T)` | `forEach` |
| `Supplier<T>` | `get()` | lazy value |
| `Function<T,R>` | `apply(T)` | `map` |
| `Predicate<T>` | `test(T)` | `filter` |

```java
Predicate<String> panjang = s -> s.length() > 3;
System.out.println(panjang.test("halo"));  // true
```

## Method Reference

```java
daftar.forEach(System.out::println);
daftar.sort(String::compareToIgnoreCase);
```

`::` adalah pintasan untuk lambda yang hanya memanggil method yang sudah ada.

## Pipeline Stream

```java
List<String> hasil = data.stream()
    .filter(s -> s.startsWith("A"))     // intermediate
    .map(String::toUpperCase)            // intermediate
    .sorted()                            // intermediate
    .collect(Collectors.toList());       // terminal
```

Operasi **intermediate** bersifat lazy dan bisa dirantai. Operasi **terminal** (`collect`, `count`, `reduce`, `forEach`, `anyMatch`) yang memicu eksekusi.

## Map vs flatMap

```java
stream.map(s -> s.split(" "))       // Stream<String[]>
stream.flatMap(s -> Arrays.stream(s.split(" ")))  // Stream<String>
```

flatMap meratakan struktur bersarang.

<div class="note">💡 Stream tidak menyimpan data dan biasanya hanya bisa dipakai sekali. Untuk transformasi kompleks dengan efek samping atau exception yang rumit, loop biasa sering lebih mudah di-debug.</div>
