Java Collection Framework adalah seperangkat interface dan implementasi untuk menyimpan sekumpulan object. Memilih implementasi yang tepat berdampak besar pada performa.

## Peta Interface

```
Collection
├── List    → ArrayList, LinkedList, Vector
├── Set     → HashSet, LinkedHashSet, TreeSet
└── Queue   → LinkedList, PriorityQueue, ArrayDeque

Map (terpisah) → HashMap, LinkedHashMap, TreeMap
```

## Perbandingan Cepat

| Implementasi | Urutan | Duplikat | Akses | Kapan dipakai |
|---|---|---|---|---|
| ArrayList | sisipan | ya | O(1) | default umum |
| LinkedList | sisipan | ya | O(n) | sering insert/delete di tengah |
| HashSet | tidak | tidak | O(1) | cek keanggotaan cepat |
| LinkedHashSet | sisipan | tidak | O(1) | unik + urutan |
| TreeSet | terurut | tidak | O(log n) | butuh sorting |
| HashMap | tidak | key unik | O(1) | lookup cepat |
| TreeMap | key terurut | key unik | O(log n) | butuh rentang/urutan |

## Iterasi

```java
for (String s : daftar) { ... }

daftar.forEach(s -> System.out.println(s));

Iterator<String> it = daftar.iterator();
while (it.hasNext()) {
    if (it.next().isEmpty()) it.remove();  // hapus saat iterasi
}
```

## Sort & Comparator

```java
daftar.sort(Comparator.naturalOrder());
daftar.sort((a, b) -> b.length() - a.length());

class Siswa {
    String nama;
    int nilai;
}
daftarSiswa.sort(Comparator.comparingInt(s -> s.nilai).reversed());
```

## Of/Factory Methods (Java 9+)

```java
List<String> l = List.of("a", "b");
Set<Integer> s = Set.of(1, 2);
Map<String,Integer> m = Map.of("a", 1, "b", 2);
```

Hasilnya immutable — `add()` akan melempar `UnsupportedOperationException`.

<div class="note">💡 Default yang aman: <b>ArrayList</b> untuk list, <b>HashSet</b> untuk set, <b>HashMap</b> untuk map. Ganti ke varian Linked/Tree hanya kalau kamu benar-benar butuh urutan atau sorting.</div>
