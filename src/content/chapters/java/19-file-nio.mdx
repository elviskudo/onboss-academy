Package `java.nio.file` (NIO.2, Java 7+) adalah cara modern bekerja dengan file dan direktori. API-nya lebih konsisten daripada `java.io.File`.

## Path

```java
import java.nio.file.*;

Path p = Path.of("dokumen", "laporan.txt");
System.out.println(p.getFileName());  // laporan.txt
System.out.println(p.toAbsolutePath());
```

Tidak seperti `File`, `Path` murni representasi lokasi — operasi aktual ada di kelas `Files`.

## Baca & Tulis

```java
String isi = Files.readString(p, StandardCharsets.UTF_8);
List<String> baris = Files.readAllLines(p, StandardCharsets.UTF_8);

Files.writeString(p, "teks baru", StandardCharsets.UTF_8);
Files.writeString(p, "tambahan
", StandardCharsets.UTF_8,
                  StandardOpenOption.CREATE, StandardOpenOption.APPEND);
```

Selalu tentukan charset eksplisit agar hasil sama di Windows dan Linux.

## Operasi Umum

```java
Files.exists(p);
Files.createFile(p);
Files.createDirectories(p.getParent());
Files.copy(dari, ke, StandardCopyOption.REPLACE_EXISTING);
Files.move(dari, ke);
Files.deleteIfExists(p);
Files.size(p);
```

## Traversal

```java
try (Stream<Path> stream = Files.walk(Path.of("."))) {
    stream.filter(Files::isRegularFile)
          .filter(p -> p.toString().endsWith(".mdx"))
          .forEach(System.out::println);
}
```

`Files.walk` harus ditutup (try-with-resources) karena memegang resource direktori.

<div class="note">💡 Untuk file besar, jangan `readString()` seluruh isi. Gunakan `Files.newBufferedReader()` dan baca baris demi baris, atau `Files.lines()` sebagai stream.</div>
