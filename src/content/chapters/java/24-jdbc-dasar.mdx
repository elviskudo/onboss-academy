JDBC adalah jembatan standar Java ke database SQL. Walaupun sekarang banyak ORM (Hibernate, JPA), memahami JDBC penting untuk debugging dan query khusus.

## Alur Umum

```java
try (Connection conn = DriverManager.getConnection(url, user, pass);
     PreparedStatement ps = conn.prepareStatement("SELECT * FROM siswa WHERE kelas = ?")) {

    ps.setString(1, "XII");
    try (ResultSet rs = ps.executeQuery()) {
        while (rs.next()) {
            System.out.println(rs.getString("nama"));
        }
    }
}
```

## PreparedStatement vs Statement

```java
// BAHAYA: injection
Statement s = conn.createStatement();
s.executeQuery("SELECT * FROM user WHERE nama='" + input + "'");

// AMAN
PreparedStatement ps = conn.prepareStatement("SELECT * FROM user WHERE nama=?");
ps.setString(1, input);
```

Selain aman, PreparedStatement sering lebih cepat karena query sudah ter-compile dan di-cache database.

## Transaksi

```java
conn.setAutoCommit(false);
try {
    debit(conn, 100);
    kredit(conn, 100);
    conn.commit();
} catch (SQLException e) {
    conn.rollback();
    throw e;
} finally {
    conn.setAutoCommit(true);
}
```

## ResultSet

```java
while (rs.next()) {
    int id = rs.getInt("id");
    String nama = rs.getString("nama");
}
```

Kursor awal berada **sebelum** baris pertama — selalu panggil `next()` dulu.

## Connection Pool

Di produksi jangan membuat koneksi per request. Gunakan pool seperti **HikariCP**:

```java
HikariConfig cfg = new HikariConfig();
cfg.setJdbcUrl(url);
HikariDataSource ds = new HikariDataSource(cfg);
Connection c = ds.getConnection();
```

<div class="note">💡 Password jangan pernah ditulis di source code. Simpan di environment variable atau secret manager, lalu baca dengan `System.getenv("DB_PASSWORD")`.</div>
