Testing otomatis memberi kepercayaan saat mengubah kode. JUnit 5 adalah standar de facto di ekosistem Java.

## Test Pertama

```java
import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class MatematikaTest {
    @Test
    void kuadratPositif() {
        assertEquals(9, Matematika.kuadrat(3));
    }
}
```

## Assertion Umum

| Assertion | Cek |
|---|---|
| `assertEquals(expected, actual)` | kesamaan nilai |
| `assertNotEquals` | ketidaksamaan |
| `assertTrue` / `assertFalse` | kondisi boolean |
| `assertNull` / `assertNotNull` | null |
| `assertThrows(E.class, () -> ...)` | exception |
| `assertArrayEquals` | isi array |
| `assertAll(...)` | beberapa assertion sekaligus |

## Lifecycle

```java
@BeforeAll static void sekaliDiAwal() { ... }
@BeforeEach void sebelumTiapTest() { ... }
@AfterEach  void sesudahTiapTest() { ... }
@AfterAll  static void sekaliDiAkhir() { ... }
```

## Parameterized Test

```java
@ParameterizedTest
@ValueSource(ints = {1, 2, 3})
void ganjilAtauGenap(int n) {
    assertTrue(n > 0);
}
```

## Naming

Pakai nama yang mengatakan **skenario + ekspektasi**:

```java
void tarikSaldoLebihBesar_melemparException() { ... }
void loginSalahPassword_mengembalikanFalse() { ... }
```

<div class="note">💡 Pola **AAA** membantu kerapian test: **Arrange** (siapkan data), **Act** (panggil method), **Assert** (cek hasil). Satu test sebaiknya menguji satu perilaku.</div>
