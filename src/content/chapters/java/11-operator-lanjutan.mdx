Java mewarisi banyak operator dari C, termasuk bitwise dan ternary. Memahaminya penting untuk membaca kode level rendah dan menulis ekspresi ringkas.

## Bitwise

| Operator | Arti | Contoh `6`(110) & `3`(011) |
|---|---|---|
| `&` | AND | `2` |
| `|` | OR | `7` |
| `^` | XOR | `5` |
| `~` | NOT | `-7` |
| `<<` | geser kiri | `12` |
| `>>` | geser kanan (arithmetik) | `3` |
| `>>>` | geser kanan (logical) | `3` |

```java
int flag = BACA | TULIS;        // menggabungkan flag
if ((flag & TULIS) != 0) { ... } // mengecek flag
```

## Short-Circuit

```java
if (x != 0 && 10 / x > 2) { ... }
```

Karena `&&` short-circuit, pembagian tidak pernah terjadi saat `x == 0`. Operator `&` tetap mengevaluasi kedua sisi — gunakan hanya untuk bitwise pada integer (atau AND boolean non-short-circuit yang disengaja).

## Ternary

```java
String status = nilai >= 75 ? "Lulus" : "Gagal";
```

Bisa bersarang, tapi jangan berlebihan — lebih dari dua level sebaiknya diganti `if/else`.

## Precedence

Dari tinggi: `()` → unari `++ -- ! ~` → `* / %` → `+ -` → shift `<&lt; >>` → perbandingan → `== !=` → `&` → `^` → `|` → `&&` → `||` → ternary → assignment.

<div class="note">💡 Gunakan kurung eksplisit saat mencampur bitwise dengan perbandingan. `a & b == 0` berarti `a & (b == 0)` dan akan error karena `&` pada boolean bukan short-circuit.</div>
