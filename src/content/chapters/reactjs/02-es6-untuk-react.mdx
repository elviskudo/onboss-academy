Setiap contoh React modern memakai JavaScript modern. Bab ini memastikan kamu nyaman dengan 7 fitur ES6+ yang muncul berulang di seluruh track React.

## 7 Fitur ES6+ yang Wajib Dikuasai

| Fitur | Contoh singkat | Peran di React |
|-------|----------------|----------------|
| `const` / `let` | `const nama = "Sari"` | Deklarasi state, props, konfigurasi |
| Arrow function | `(a, b) => a + b` | Handler, callback, isi map/filter |
| Template literal | `` `Halo ${nama}` `` | Teks dinamis, className bersyarat |
| Destructuring | `const { judul } = props` | Membongkar props & hasil hooks |
| Spread / rest | `...state` | Update state immutable |
| Default parameter | `(aktif = true)` | Props dengan nilai bawaan |
| Modules | `import { useState }` | Impor hook & komponen |

## const dan let

```js
const judul = "OnBoss"; // tidak boleh di-assign ulang
let hitung = 0;         // boleh berubah
hitung = hitung + 1;

for (let i = 0; i < 3; i++) {
  console.log(i); // i hilang di akhir tiap iterasi
}
```

Kebiasaan React: hampir semua deklarasi memakai `const`; `let` hanya saat nilai benar-benar berubah. `var` praktis tidak dipakai lagi karena scope-nya membocor keluar function.

## Arrow Function

```js
const tambah = (a, b) => a + b;
const kuadrat = (n) => n * n;
const sapa = (nama) => `Halo ${nama}`;
const halo = () => console.log("halo");

// multi baris perlu kurung kurawal + return
const nilaiTertinggi = (daftar) => {
  const maks = Math.max(...daftar);
  return maks;
};
```

Arrow function ringkas dan tidak membuat `this` baru — dua alasan React hooks memakainya. Satu jebakan: arrow yang mengembalikan object literal wajib dibungkus kurung, `() => ({ a: 1 })`, karena `{` tanpa kurung dibaca sebagai blok.

## Template Literal

```js
const nama = "Sari";
console.log(`Halo, ${nama}!`);
console.log(`Hasil: ${2 + 3 * 4}`);
```

Tanda kutip backtick membuat string multi-baris dan interpolasi variabel jadi mudah — sangat sering dipakai di className dinamis, mis. `` className={`kartu ${aktif ? "aktif" : ""}`} ``.

## Destructuring

```js
const user = { nama: "Budi", umur: 25, kota: "Bandung" };
const { nama, umur } = user;

const [pertama, kedua] = ["a", "b"];

function sapa({ nama, umur }) {
  return `${nama} (${umur})`;
}
sapa(user);
```

React hooks punya pola sama: `const [count, setCount] = useState(0);` — destructuring array hasil hook. Props juga hampir selalu dibongkar langsung di parameter.

## Spread dan Rest

```js
const asli = { judul: "Kartu", aktif: false };
const disalin = { ...asli, aktif: true }; // immutable update
const digabung = { ...asli, label: "Baru" };

const angka = [1, 2, 3];
const ditambah = [...angka, 4, 5];

const jumlah = (...semua) => semua.reduce((a, b) => a + b, 0);
```

React melarang mutasi state langsung. Pola salin-lalu-ubah dengan spread adalah cara standarnya — baik untuk object maupun array.

## Default Parameter & Modules

```js
// default parameter — pola props bersifat bawaan
function sapa2(nama, sapaan = "Kak") {
  return `${sapaan} ${nama}`;
}

// modules — cara React membagi file
import { useState, useEffect } from "react";
import Kartu from "./Kartu.jsx";
export default function App() { /* ... */ }
```

Setiap komponen React adalah modul: `import` untuk memakai, `export default` untuk menyediakan.

## Di Dunia Nyata

- **Update state user**: `{ ...user, nama: "Baru" }` — bukan `user.nama = "Baru"` yang dilarang React.
- **Menyusun filter produk**: `filter((p) => p.stok > 0)` memakai arrow function langsung di argumen.
- **Menampilkan nama dari props**: `function Profil({ nama })` — destruktur di parameter, bukan `props.nama` berulang.
- **className dinamis**: `` `btn ${utama ? "btn-primary" : "btn-ghost"}` `` untuk tombol dua gaya.
- **Impor komponen lintas file**: `import Navbar from "./components/Navbar"` — satu file satu komponen.

<div class="note">💡 Tanda ... punya dua wajah: spread (menyalin isi array/object) dan rest (mengumpulkan sisa argumen). Di React, spread lebih sering muncul — terutama saat meng-update state array tanpa merusak data lama.</div>
