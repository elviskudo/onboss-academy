Custom hook adalah cara paling rapi untuk memakai ulang **logika berstate**. Bukan komponen, bukan utilitas biasa — tapi fungsi yang memanggil hook lain.

## Aturan Emas

1. Nama diawali `use` (misal `useFetch`, `useLocalStorage`).
2. Dipanggil hanya di top level komponen atau hook lain.
3. Tidak dipanggil di dalam kondisi, loop, atau callback.

## Contoh: useFetch

```jsx
function useFetch(url) {
  const [data, setData] = React.useState(null);
  const [error, setError] = React.useState("");
  const [loading, setLoading] = React.useState(true);

  React.useEffect(() => {
    const controller = new AbortController();
    setLoading(true);

    fetch(url, { signal: controller.signal })
      .then((res) => {
        if (!res.ok) throw new Error("Request gagal");
        return res.json();
      })
      .then((hasil) => setData(hasil))
      .catch((e) => {
        if (e.name !== "AbortError") setError(e.message);
      })
      .finally(() => setLoading(false));

    return () => controller.abort();
  }, [url]);

  return { data, error, loading };
}
```

Pemakaiannya:

```jsx
function DaftarUser() {
  const { data, loading, error } = useFetch("/api/user");
  if (loading) return <p>Memuat…</p>;
  if (error) return <p>{error}</p>;
  return <ul>{data.map((u) => <li key={u.id}>{u.nama}</li>)}</ul>;
}
```

## Contoh: useLocalStorage

```jsx
function useLocalStorage(kunci, awal) {
  const [nilai, setNilai] = React.useState(() => {
    const simpan = localStorage.getItem(kunci);
    return simpan ? JSON.parse(simpan) : awal;
  });

  React.useEffect(() => {
    localStorage.setItem(kunci, JSON.stringify(nilai));
  }, [kunci, nilai]);

  return [nilai, setNilai];
}
```

Sekarang `const [tema, setTema] = useLocalStorage("tema", "terang")` — state otomatis bertahan setelah refresh.

## Kapan Membuat Custom Hook?

- Logika yang sama dipakai minimal dua komponen.
- Ada kombinasi `useState` + `useEffect` yang berulang.
- Ingin menyembunyikan detail teknis (fetch, timer, storage) dari tampilan.

<div class="note">💡 Custom hook membuat komponen kembali fokus pada tampilan. Kalau nama hook-mu sulit dijelaskan dalam satu kalimat, mungkin logikanya masih terlalu lebar.</div>
