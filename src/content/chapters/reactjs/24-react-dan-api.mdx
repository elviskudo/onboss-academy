Hampir semua aplikasi React modern berbicara dengan API. Kuncinya adalah menjaga komunikasi itu tetap teratur.

## Lapisan API

```js
// api/produk.js
const DASAR = "/api";

export async function ambilProduk(id) {
  const res = await fetch(`${DASAR}/produk/${id}`);
  if (!res.ok) throw new Error("Gagal memuat produk");
  return res.json();
}

export async function simpanProduk(data) {
  const res = await fetch(`${DASAR}/produk`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(data),
  });
  if (!res.ok) throw new Error("Gagal menyimpan");
  return res.json();
}
```

## Memakai di Komponen

```jsx
function Detail({ id }) {
  const [produk, setProduk] = useState(null);
  const [error, setError] = useState("");

  useEffect(() => {
    ambilProduk(id).then(setProduk).catch((e) => setError(e.message));
  }, [id]);

  if (error) return <p className="error">{error}</p>;
  if (!produk) return <p>Memuat…</p>;
  return <h1>{produk.nama}</h1>;
}
```

## Update Optimistik

```jsx
async function tambahKeranjang(item) {
  setKeranjang((lama) => [...lama, item]); // tampil lebih dulu

  try {
    await simpanKeranjang(item);
  } catch (e) {
    setKeranjang((lama) => lama.filter((i) => i.id !== item.id)); // rollback
    setPesan("Gagal menambah ke keranjang");
  }
}
```

## Header dan Autentikasi

```js
fetch(url, {
  headers: { Authorization: `Bearer ${token}` },
});
```

Simpan token dengan aman (httpOnly cookie lebih disarankan daripada localStorage untuk data sensitif).

<div class="note">💡 Pisahkan urusan jaringan dari urusan tampilan. Komponen hanya perlu memanggil `ambilProduk()`, bukan tahu alamat endpoint atau format header.</div>
