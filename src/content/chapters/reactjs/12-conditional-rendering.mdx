React tidak punya sintaks khusus untuk `if` di JSX. Kamu memakai JavaScript biasa.

## Tiga Pola Utama

| Pola | Contoh | Cocok untuk |
|------|--------|-------------|
| Early return | `if (!user) return <Login />` | Cabang besar, seluruh halaman |
| Ternary | `{aktif ? <Aktif /> : <Nonaktif />}` | Dua pilihan sejajar |
| Logical AND | `{error && <Alert />}` | Tampil atau tidak sama sekali |

```jsx
function StatusPesanan({ pesanan, memuat }) {
  if (memuat) return <p className="muted">Memuat pesanan…</p>;
  if (!pesanan) return <p>Pesanan tidak ditemukan.</p>;

  return (
    <div>
      <h2>{pesanan.kode}</h2>
      {pesanan.lunas
        ? <span className="badge hijau">Lunas</span>
        : <span className="badge merah">Belum bayar</span>}
      {pesanan.catatan && <p>{pesanan.catatan}</p>}
    </div>
  );
}
```

## Jebakan Nilai Falsy

```jsx
const jumlah = 0;
{jumlah && <p>{jumlah} item</p>}   // tidak muncul!

{jumlah > 0 && <p>{jumlah} item</p>} // benar
```

Angular dan Vue punya direktif khusus; React mengandalkan kebiasaan JavaScript. Karena itu paham truthy/falsy itu wajib.

## Render Daftar

```jsx
function DaftarProduk({ produk }) {
  if (!produk.length) return <p>Belum ada produk.</p>;

  return (
    <ul>
      {produk.map((p) => (
        <li key={p.id}>
          {p.nama} <strong>Rp{p.harga.toLocaleString("id-ID")}</strong>
        </li>
      ))}
    </ul>
  );
}
```

Jangan memakai index sebagai `key` bila daftar bisa diurut ulang, disisip, atau dihapus. React bisa salah mencocokkan state lokal tiap baris.

<div class="note">💡 Saat ragu memilih pola, mulai dari early return. Kode menjadi lebih pendek dan pembaca tidak perlu menelusuri ternary bersarang.</div>
