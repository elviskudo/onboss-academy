## Kartu Metrik

```jsx
function KartuMetrik({ label, nilai, naik }) {
  return (
    <article className="metrik">
      <small>{label}</small>
      <strong>{nilai.toLocaleString("id-ID")}</strong>
      <span className={naik ? "hijau" : "merah"}>
        {naik ? "▲" : "▼"} dibanding bulan lalu
      </span>
    </article>
  );
}
```

## Halaman Dashboard

```jsx
function Dashboard() {
  const { data, loading, error } = useFetch("/api/ringkasan");

  if (loading) return <p>Memuat ringkasan…</p>;
  if (error) return <p className="error">{error}</p>;

  return (
    <div>
      <h1>Ringkasan Toko</h1>
      <section className="grid-metrik">
        <KartuMetrik label="Pesanan" nilai={data.pesanan} naik />
        <KartuMetrik label="Omzet" nilai={data.omzet} naik={false} />
      </section>
      <TabelPesanan data={data.terbaru} />
    </div>
  );
}
```

## Rute dan Layout

```jsx
<BrowserRouter>
  <AuthProvider>
    <Routes>
      <Route element={<Layout />}>
        <Route index element={<Dashboard />} />
        <Route path="laporan" element={
          <Protected><Laporan /></Protected>
        } />
      </Route>
      <Route path="login" element={<Login />} />
    </Routes>
  </AuthProvider>
</BrowserRouter>
```

## Checklist Sebelum Selesai

- [ ] Semua daftar punya `key` yang stabil.
- [ ] Fetch dibatalkan saat komponen unmount.
- [ ] Form punya label dan validasi.
- [ ] Error punya tampilan fallback.
- [ ] `npm run build` berhasil.

<div class="note">💡 Proyek kecil yang selesai jauh lebih berharga daripada proyek besar yang setengah jadi. Mulai dari tiga metrik dan satu tabel, lalu kembangkan bertahap.</div>
