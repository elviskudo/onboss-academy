Dari sini kita mulai menulis React yang sesungguhnya. Fondasi JS dan state dari bab sebelumnya tetap dipakai — hanya bentuknya kini menjadi komponen dan JSX.

## 4 Bagian Komponen Modern

| Bagian | Bentuk | Fungsi | Kapan dipakai |
|--------|--------|--------|---------------|
| Function component | `function Kartu() {}` | Mendefinisikan unit UI | Selalu untuk komponen baru |
| Props | `function Kartu({ item })` | Input read-only dari induk | Variasi data/perilaku |
| State | `useState(nilaiAwal)` | Memori lokal yang reaktif | Data yang berubah karena interaksi |
| JSX return | `return <article>…</article>` | Deskripsi tampilan | Hasil akhir tiap render |

React lama juga punya class component dengan `extends React.Component`, tetapi kini jarang dipakai kecuali error boundary dan pemeliharaan kode lama. Function component lebih ringkas dan memakai hooks.

## Struktur Komponen

```jsx
function Sapa() {
  return <h1>Halo, OnBoss!</h1>;
}
```

Komponen = fungsi bernama PascalCase yang mengembalikan JSX. Memanggilnya di JSX:

```jsx
export default function App() {
  return (
    <main>
      <Sapa />
    </main>
  );
}
```

## JSX yang Benar

```jsx
const judul = "Kopi Susu";

<img src="/kopi.jpg" alt={judul} />
<input type="text" placeholder="Cari..." disabled />
<br />

// wajib satu root
<>
  <h2>{judul}</h2>
  <p>Enak disajikan dingin.</p>
</>
```

Aturan penting: semua kurung tutup harus lengkap (`<br />`), atribut memakai `className`, `htmlFor`, dan `dangerouslySetInnerHTML` bukan default untuk konten user.

## Props di Komponen

```jsx
function Kartu({ judul, isi }) {
  return (
    <article className="card">
      <h3>{judul}</h3>
      <p>{isi}</p>
    </article>
  );
}

<Kartu judul="Promo" isi="Diskon 20% hari ini" />
```

Ekspresi di dalam kurung kurawal `{...}` bisa berupa variabel, hasil fungsi, atau kondisi — selama tetap JavaScript.

## Merender Daftar

```jsx
function Menu({ items }) {
  return (
    <ul>
      {items.map((item) => (
        <li key={item.id}>
          {item.nama} — Rp{item.harga}
        </li>
      ))}
    </ul>
  );
}
```

Rantai `map` dari bab array method langsung terpakai di sini. `key` harus unik per item — jangan pakai index bila daftar bisa berubah urutan.

## Conditional Rendering

React memakai percabangan JavaScript biasa. Ada **3 pola utama**:

| Pola | Contoh | Kapan dipakai |
|------|--------|---------------|
| Early return | `if (!user) return <Login />` | Seluruh tampilan berbeda |
| Ternary | `{stok ? <Beli /> : <Habis />}` | Dua alternatif |
| Logical AND | `{error && <Pesan />}` | Tampilkan atau tidak |

```jsx
function Status({ stok, memuat }) {
  if (memuat) return <p>Memuat…</p>;
  return stok > 0 ? <button>Beli</button> : <p>Stok habis</p>;
}
```

Hindari ternary bertingkat karena sulit dibaca; pecah ke variabel atau early return.

## Kapan Memecah Komponen?

Panduan praktis:

- Satu file satu tanggung jawab: navbar, kartu, formulir terpisah
- Komponen menerima props, jangan terlalu banyak
- Bagian yang dipakai ulang minimal dua kali layak dijadikan komponen sendiri

Jangan memecah setiap `<div>` menjadi komponen. Pecah ketika bagian punya tanggung jawab jelas, logika sendiri, atau benar-benar digunakan ulang.

## Di Dunia Nyata

- **E-commerce**: `DaftarProduk` melakukan map, `KartuProduk` menerima satu item lewat props.
- **Dashboard**: `Sidebar`, `Header`, `TabelPesanan`, dan `Pagination` berubah independen.
- **Autentikasi**: early return menampilkan halaman login sebelum dashboard bila user kosong.
- **Notifikasi**: `errors.map` menghasilkan alert dengan `key` ID error yang stabil.
- **Design system**: satu `Button` menerima variant, disabled, dan callback agar gaya konsisten.
