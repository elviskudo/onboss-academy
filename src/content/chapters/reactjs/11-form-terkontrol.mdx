Form terkontrol membuat state sebagai **satu sumber kebenaran**. Apa yang terlihat di layar selalu sama dengan apa yang ada di state.

## Input Teks

```jsx
function NamaField() {
  const [nama, setNama] = React.useState("");

  return (
    <label>
      Nama lengkap
      <input
        type="text"
        value={nama}
        onChange={(e) => setNama(e.target.value)}
      />
    </label>
  );
}
```

Alurnya: user mengetik → `onChange` → `setNama` → render ulang → input menampilkan nilai baru.

## Checkbox dan Radio

```jsx
const [setuju, setSetuju] = React.useState(false);
const [kontak, setKontak] = React.useState("email");

<input type="checkbox" checked={setuju}
       onChange={(e) => setSetuju(e.target.checked)} />

<label><input type="radio" name="kontak" value="email"
  checked={kontak === "email"}
  onChange={(e) => setKontak(e.target.value)} /> Email</label>
```

## Select dan Textarea

```jsx
const [kota, setKota] = React.useState("jakarta");
const [catatan, setCatatan] = React.useState("");

<select value={kota} onChange={(e) => setKota(e.target.value)}>
  <option value="jakarta">Jakarta</option>
  <option value="bandung">Bandung</option>
</select>

<textarea value={catatan}
          onChange={(e) => setCatatan(e.target.value)} />
```

## Satu State untuk Banyak Field

```jsx
const [form, setForm] = React.useState({ nama: "", email: "", kota: "" });

function ubah(event) {
  const { name, value } = event.target;
  setForm((lama) => ({ ...lama, [name]: value }));
}

<input name="nama" value={form.nama} onChange={ubah} />
<input name="email" value={form.email} onChange={ubah} />
```

Polanya scale dengan baik: tambah field cukup menambah kunci di object.

## Validasi Sederhana

```jsx
const error = !form.email.includes("@") ? "Email belum valid" : "";
{error && <small className="error">{error}</small>}
```

<div class="note">💡 Hindari mencampur `value` dan `defaultValue`. Pilih satu: terkontrol untuk form yang perlu divalidasi, tidak terkontrol (`defaultValue`) untuk input yang benar-benar sekali baca.</div>
