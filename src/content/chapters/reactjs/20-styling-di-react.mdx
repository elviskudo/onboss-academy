React tidak memaksa gaya tertentu. Kamu bisa memakai CSS biasa, CSS Module, atau CSS-in-JS.

## CSS Biasa

```css
/* kartu.css */
.kartu { padding: 16px; border-radius: 12px; }
.kartu.aktif { border-color: teal; }
```

```jsx
import "./kartu.css";

<div className={"kartu" + (aktif ? " aktif" : "")}>...</div>
```

Risikonya: nama `.kartu` bisa bentrok dengan file lain.

## CSS Module

```css
/* Kartu.module.css */
.kartu { padding: 16px; }
.aktif { outline: 2px solid teal; }
```

```jsx
import s from "./Kartu.module.css";

function Kartu({ aktif }) {
  return (
    <div className={`${s.kartu} ${aktif ? s.aktif : ""}`}>
      Isi kartu
    </div>
  );
}
```

Nama kelas diubah menjadi sesuatu seperti `Kartu_kartu__x7a2b`, jadi tidak bentrok.

## Inline Style

```jsx
const gaya = { backgroundColor: "#fff", marginTop: 12, fontWeight: 600 };
<div style={gaya}>Halo</div>
```

Cocok untuk nilai dinamis sederhana (misal lebar dari state), bukan untuk seluruh tema.

## Memilih Pendekatan

| Kebutuhan | Pilihan |
|-----------|---------|
| Proyek kecil | CSS biasa |
| Komponen banyak, tim besar | CSS Module |
| Styling bergantung props | CSS-in-JS / CSS variable |
| Utilitas cepat | Tailwind CSS |

<div class="note">💡 Rekomendasi praktis: CSS Module untuk struktur, CSS variable untuk warna/tema, dan inline style hanya untuk nilai yang benar-benar berubah saat runtime.</div>
