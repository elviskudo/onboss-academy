JSX terlihat seperti HTML, tapi sebenarnya ekspresi JavaScript. Memahami detail kecilnya membuat komponen lebih mudah dirawat.

## Children

Apa pun yang kamu tulis di antara tag komponen dikirim sebagai `props.children`.

```jsx
function Panel({ children, judul }) {
  return (
    <section className="panel">
      <h2>{judul}</h2>
      <div className="isi">{children}</div>
    </section>
  );
}

<Panel judul="Ringkasan">
  <p>Ditulis bebas di sini.</p>
  <button>Lihat detail</button>
</Panel>
```

Ini berguna untuk komponen pembungkus: card, modal, layout, dan dropdown.

## Atribut Dinamis

Semua atribut bisa menerima ekspresi di dalam kurung kurawal.

```jsx
const lebar = 240;
const aktif = true;

<div
  className={aktif ? "pill aktif" : "pill"}
  style={{ width: lebar, marginTop: 12 }}
  data-role={aktif ? "on" : "off"}
>
  Status
</div>
```

Perhatikan gaya inline: `style` menerima **object**, dengan nama properti camelCase (`marginTop`, bukan `margin-top`).

## Spread Props

```jsx
const pengaturan = { judul: "Promo", warna: "gold", ukuran: 18 };

<Kartu {...pengaturan} />
// sama dengan
<Kartu judul="Promo" warna="gold" ukuran={18} />
```

Spread memangkas penulisan, tapi hati-hati: kuncinya bisa menimpa props yang sudah kamu berikan sebelumnya.

## Konten Mentah

```jsx
<div dangerouslySetInnerHTML={{ __html: markupDariServer }} />
```

Nama prop itu sengaja dibuat menakutkan. Gunakan hanya jika `markupDariServer` sudah disanitasi. Untuk teks biasa, cukup `{teks}` — React meng-escape-nya secara otomatis.

## Komentar dan Kunci

| Kebutuhan | Penulisan |
|-----------|-----------|
| Komentar di JSX | `{/* ... */}` |
| Tag tanpa anak | `<input />`, `<br />` |
| Tag dengan anak | `<p>...</p>` |
| Daftar | `key` unik per elemen |

<div class="note">💡 JSX mengubah cara kamu membaca kode: "`&lt;Kartu /&gt;`" bukan perintah, melainkan deskripsi "tampilkan Kartu dengan data ini". React yang menentukan kapan dan bagaimana DOM diperbarui.</div>
