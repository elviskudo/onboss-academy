React merender ulang komponen saat state berubah. Kebanyakan kasus sudah cukup cepat; dua hook ini dipakai saat ada pekerjaan yang benar-benar mahal.

## useMemo

```jsx
function Ringkasan({ items }) {
  const total = React.useMemo(() => {
    console.log("hitung ulang total");
    return items.reduce((sum, i) => sum + i.harga * i.qty, 0);
  }, [items]);

  return <p>Total: Rp{total.toLocaleString("id-ID")}</p>;
}
```

Kalau `items` tidak berubah, fungsi di dalamnya tidak dijalankan lagi.

## useCallback

```jsx
const tambah = React.useCallback((id) => {
  setItems((lama) => lama.map((i) =>
    i.id === id ? { ...i, qty: i.qty + 1 } : i
  ));
}, []);

const Baris = React.memo(function Baris({ item, onTambah }) {
  return <button onClick={() => onTambah(item.id)}>+</button>;
});
```

`useCallback` menjaga identitas fungsi tetap, sehingga `React.memo` pada anak benar-benar bisa melewati render.

## Kapan Dipakai

| Situasi | Pilihan |
|---------|---------|
| Hitung sederhana | biarkan saja |
| Sort/filter ribuan baris | `useMemo` |
| Fungsi dikirim ke komponen memo | `useCallback` |
| Efek samping / fetch | `useEffect` |

## Kebiasaan Baik

1. Ukur dulu dengan React DevTools Profiler.
2. Cantumkan semua nilai yang dipakai di dalam callback di dependency array.
3. Jangan menyimpan objek state di `useMemo` — itu bukan pengganti `useState`.

<div class="note">💡 `useMemo` bukan cache ajaib. React boleh membuang cache kapan saja; jadi jangan dipakai untuk menyimpan data yang harus selalu ada.</div>

<TryIt lang="javascript" runtime="client-js" code={`// Perbandingan perhitungan biasa vs memo (disimulasikan)
let hitunganBiasa = 0;
function totalBiasa(items) {
  hitunganBiasa++;
  return items.reduce((s, i) => s + i, 0);

function buatMemo() {
  let cache = null;
  let terakhir = null;
  return (items) => {
    if (terakhir === items) return cache;
    terakhir = items;
    cache = items.reduce((s, i) => s + i, 0);

  };
}
