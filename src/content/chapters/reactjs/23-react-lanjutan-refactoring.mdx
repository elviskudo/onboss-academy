Menulis komponen itu mudah. Menjaga tetap rapi saat aplikasi tumbuh adalah tantangan sebenarnya.

## Tanda Perlu Refactor

- File lebih dari ~200 baris dan sulit dicari bagiannya.
- Satu komponen mengambil data, mengolah, dan menampilkan sekaligus.
- Props bertambah terus sampai sulit diingat.
- Logika yang sama muncul di tiga tempat.

## Memecah Berdasarkan Tanggung Jawab

```jsx
// Sebelum
function HalamanPesanan() {
  const [pesanan, setPesanan] = useState([]);
  const [filter, setFilter] = useState("");
  // 120 baris logika + JSX ...
}

// Sesudah
function HalamanPesanan() {
  const [filter, setFilter] = useState("");

  return (
    <main>
      <PanelFilter value={filter} onChange={setFilter} />
      <DaftarPesanan filter={filter} />
    </main>
  );
}
```

`DaftarPesanan` boleh memakai `useFetch` sendiri — tanggung jawabnya jelas.

## Ekstrak Logika ke Hook

```jsx
// useFilter.js
export function useFilter(items, kata) {
  return items.filter((i) =>
    i.nama.toLowerCase().includes(kata.toLowerCase())
  );
}
```

## Pemberian Nama

| Buruk | Baik |
|-------|------|
| `data` | `daftarPesanan` |
| `handle` | `handleSimpanPesanan` |
| `Comp` | `KartuRingkasan` |
| `flag` | `sedangMemuat` |

## Langkah Aman

1. Pastikan ada test yang lolos.
2. Pindahkan satu potong kecil.
3. Jalankan test lagi.
4. Ulangi.
