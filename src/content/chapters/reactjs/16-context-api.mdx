## Membuat Context

```jsx
const TemaContext = React.createContext("terang");
```

Nilai di `createContext` adalah default bila tidak ada Provider di atasnya.

## Provider

```jsx
function App() {
  const [tema, setTema] = React.useState("terang");

  return (
    <TemaContext.Provider value={{ tema, setTema }}>
      <Header />
      <Halaman />
      <button onClick={() => setTema(tema === "terang" ? "gelap" : "terang")}>
        Ganti tema
      </button>
    </TemaContext.Provider>
  );
}
```

## Consumer

```jsx
function Kartu() {
  const { tema } = React.useContext(TemaContext);
  return (
    <div className={`kartu kartu--${tema}`}>
      Kartu mengikuti tema aktif.
    </div>
  );
}
```

Siapa pun di bawah Provider bisa mengaksesnya, berapa level pun jaraknya.

## Beberapa Context

```jsx
<TemaContext.Provider value={tema}>
  <BahasaContext.Provider value={bahasa}>
    <App />
  </BahasaContext.Provider>
</TemaContext.Provider>
```

Pisahkan context berdasarkan domain: tema, autentikasi, preferensi, keranjang. Satu context raksasa membuat render ulang meluas.

## Alternatif

Untuk state yang kompleks dan sering berubah, pertimbangkan library khusus (Zustand, Redux, atau Pinia di Vue). Context tetap sangat baik untuk data yang stabil.

<div class="note">💡 Context bukan pengganti props. Pakai props untuk data lokal antar induk-anak, dan context untuk data yang benar-benar dibutuhkan banyak cabang UI.</div>

function buatContext(defaultValue) {
  return { defaultValue };

  return providerValue === undefined ? ctx.defaultValue : providerValue;
