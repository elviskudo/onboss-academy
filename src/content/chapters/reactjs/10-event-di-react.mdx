Event di React tidak jauh berbeda dari event DOM, hanya penulisannya yang diseragamkan.

## Nama Event camelCase

| DOM | React |
|-----|-------|
| `onclick` | `onClick` |
| `onchange` | `onChange` |
| `onsubmit` | `onSubmit` |
| `onmouseover` | `onMouseEnter` |

```jsx
function TombolSuka() {
  const [suka, setSuka] = React.useState(false);

  return (
    <button onClick={() => setSuka(!suka)}>
      {suka ? "❤️ Disukai" : "🤍 Suka"}
    </button>
  );
}
```

## Menerima Argumen

Ada dua gaya umum:

```jsx
// arrow function — argumen bebas
<button onClick={() => hapus(id)}>Hapus</button>

// bind lewat parameter event
<button onClick={(event) => console.log(event.target)}>Klik</button>
```

Arrow function membuat fungsi baru tiap render. Untuk daftar besar, pola ini bisa dioptimasi dengan `useCallback` (dibahas di bab tersendiri).

## Event Form

```jsx
function FormCari({ onSubmit }) {
  const [kata, setKata] = React.useState("");

  function kirim(event) {
    event.preventDefault();
    if (!kata.trim()) return;
    onSubmit(kata.trim());
    setKata("");
  }

  return (
    <form onSubmit={kirim}>
      <input
        value={kata}
        onChange={(e) => setKata(e.target.value)}
        placeholder="Cari produk…"
      />
      <button type="submit">Cari</button>
    </form>
  );
}
```

`preventDefault()` penting agar halaman tidak memuat ulang saat form dikirim.

## Bubble dan Stop

Event React menjalar (bubble) ke atas. `event.stopPropagation()` menghentikan perjalanan itu.

```jsx
<div onClick={() => console.log("induk")}>
  <button onClick={(e) => { e.stopPropagation(); console.log("anak"); }}>
    Klik
  </button>
</div>
```

<div class="note">💡 Event handler sebaiknya tetap kecil: baca data, lalu panggil fungsi lain. Logika bisnis yang panjang lebih enak diuji bila berdiri sendiri.</div>
