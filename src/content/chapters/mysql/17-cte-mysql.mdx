MySQL 8 membawa dua fitur penting: CTE dan window function. Keduanya membuat query analitik yang dulu perlu subquery bertumpuk menjadi jauh lebih rapi.

## CTE Dasar

```sql
WITH rata_dept AS (
  SELECT dept, AVG(gaji) AS rata FROM karyawan GROUP BY dept
)
SELECT k.nama, k.gaji, rata_dept.rata
FROM karyawan k
JOIN rata_dept ON k.dept = rata_dept.dept
WHERE k.gaji > rata_dept.rata;
```

CTE hidup hanya dalam satu statement dan bisa direferensikan berkali-kali.

## CTE Rekursif

```sql
WITH RECURSIVE angka(n) AS (
  SELECT 1
  UNION ALL
  SELECT n + 1 FROM angka WHERE n < 5
)
SELECT n FROM angka;
```

Bagian anchor dan recursive member dipisah `UNION ALL`. Kondisi berhenti wajib ada.

## Window Function

```sql
SELECT nama, dept, gaji,
       ROW_NUMBER() OVER (PARTITION BY dept ORDER BY gaji DESC) AS urut,
       RANK()       OVER (PARTITION BY dept ORDER BY gaji DESC) AS peringkat
FROM karyawan;
```

`PARTITION BY` membagi baris menjadi kelompok; `ORDER BY` mengurutkan dalam kelompok. Baris asli tidak dicampur menjadi satu seperti GROUP BY.

## Fungsi Jendela yang Umum

| Fungsi | Kegunaan |
| --- | --- |
| `ROW_NUMBER()` | nomor unik tiap baris |
| `RANK()` | peringkat, ada loncatan saat tie |
| `DENSE_RANK()` | peringkat tanpa loncatan |
| `LAG()` / `LEAD()` | nilai baris sebelumnya/sesudahnya |
| `SUM() OVER` | total berjalan (running total) |

```sql
SELECT tanggal, omzet,
       SUM(omzet) OVER (ORDER BY tanggal) AS kumulatif
FROM penjualan;
```

## Top N per Grup

```sql
WITH urut AS (
  SELECT nama, dept, gaji,
         ROW_NUMBER() OVER (PARTITION BY dept ORDER BY gaji DESC) AS posisi
  FROM karyawan
)
SELECT * FROM urut WHERE posisi <= 2;
```

Pola ini menggantikan correlated subquery yang lambat untuk mencari beberapa baris teratas tiap kategori.

<div class="note">💡 MySQL sebelum 8.0 tidak mendukung CTE dan window function. Cek versi dengan `SELECT VERSION();` sebelum memakai fitur ini.</div>

## Di Dunia Nyata

- **Leaderboard**: RANK() memberi peringkat dengan tie yang adil.
- **Top produk per kategori**: ROW_NUMBER() + CTE.
- **Pertumbuhan bulan**: LAG() membandingkan omzet bulan ini dengan sebelumnya.
- **Running total**: SUM() OVER untuk akumulasi harian.
