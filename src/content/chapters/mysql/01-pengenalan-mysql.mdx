**MySQL** adalah *relational database management system* (RDBMS) open-source yang populer untuk aplikasi web. Ia menyimpan data terstruktur, menjalankan SQL, dan menjaga banyak pengguna membaca/menulis bersamaan.

## Arsitektur Ringkas

MySQL memisahkan 4 lapisan utama:

| Lapisan | Fungsi | Contoh |
|---------|--------|--------|
| Client | mengirim SQL | CLI `mysql`, aplikasi PHP |
| Server | autentikasi dan parsing | proses `mysqld` |
| Optimizer | memilih rencana query | index scan vs full scan |
| Storage engine | menyimpan/lock data | InnoDB |

Pemisahan server dan client memungkinkan aplikasi di mesin lain terhubung melalui jaringan. Optimizer memutuskan cara tercepat menjalankan SQL deklaratif; kita menjelaskan hasil yang dibutuhkan, bukan langkah membacanya.

## 4 Kelompok SQL di MySQL

| Kelompok | Perintah Inti | Kegunaan |
|----------|---------------|----------|
| DDL | `CREATE`, `ALTER`, `DROP` | struktur database |
| DML | `SELECT`, `INSERT`, `UPDATE`, `DELETE` | isi tabel |
| DCL | `GRANT`, `REVOKE` | hak akses |
| TCL | `START TRANSACTION`, `COMMIT`, `ROLLBACK` | transaksi |

MySQL menjalankan SQL standar plus ekstensi khas seperti `AUTO_INCREMENT`, `ENGINE=InnoDB`, `ENUM`, `JSON`, dan `DATE_FORMAT`.

## Warisan LAMP

LAMP punya tepat 4 komponen: Linux (OS), Apache (web server), MySQL (database), PHP/Python/Perl (aplikasi). Request browser masuk ke Apache, kode aplikasi memvalidasi input dan mengirim query berparameter ke MySQL, lalu hasilnya dirender sebagai HTML/JSON.

## Pemodelan Relasional

Tabel adalah padanan koleksi objek, kolom adalah properti, dan baris adalah satu instance. Hubungan antardata disimpan sebagai foreign key, bukan array bersarang.

| Relasi | Implementasi | Contoh |
|--------|--------------|--------|
| one-to-one | foreign key UNIQUE | pengguna–profil |
| one-to-many | foreign key di sisi many | karyawan–proyek |
| many-to-many | tabel penghubung | produk–kategori |

Normalisasi menjaga satu fakta disimpan sekali; JOIN menyusunnya kembali saat dibaca.

## MySQL, PostgreSQL, dan SQLite

| Database | Model Operasi | Kekuatan Utama | Cocok untuk |
|----------|---------------|----------------|-------------|
| MySQL | server | web matang, replikasi luas | API dan CMS |
| PostgreSQL | server | fitur SQL dan tipe data kaya | analitik/transaksi kompleks |
| SQLite | satu file, embedded | tanpa administrasi server | mobile, desktop, demo |

MariaDB adalah turunan komunitas yang kompatibel dengan protokol MySQL, tetapi fitur dan perilakunya makin berbeda; baca dokumentasi versi yang benar.

## Alur Query Pertama

```sql
SELECT nama, jabatan, gaji
FROM karyawan
WHERE dept = 'Engineering'
ORDER BY gaji DESC
LIMIT 3;
```

Server mem-parsing query, optimizer memilih cara membaca tabel, storage engine mengambil baris, lalu server mengirim maksimum 3 hasil ke client. Parameter dari pengguna harus dikirim lewat *prepared statement*, bukan dirangkai ke string SQL, untuk mencegah SQL injection.

## Di Dunia Nyata

- **WordPress** menyimpan posting, pengguna, dan metadata di tabel MySQL.
- **API toko online** membaca katalog dan menyimpan pesanan melalui transaksi InnoDB.
- **Dashboard operasional** menjalankan GROUP BY untuk omzet harian tanpa memindahkan seluruh data.
- **Sistem login** mencari email lewat index dan memverifikasi hash password di aplikasi.
