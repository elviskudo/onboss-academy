MySQL menyimpan logika tidak hanya di aplikasi, tetapi juga di dalam database lewat view, stored procedure, function, dan trigger. Gunakan dengan bijak: ini bisa menyederhanakan, tapi juga menyembunyikan kompleksitas.

## View

```sql
CREATE VIEW v_karyawan_publik AS
SELECT id, nama, jabatan FROM karyawan;

SELECT * FROM v_karyawan_publik WHERE jabatan LIKE '%Developer%';
CREATE OR REPLACE VIEW v_karyawan_publik AS SELECT id, nama FROM karyawan;
DROP VIEW IF EXISTS v_karyawan_publik;
```

View bisa membatasi kolom sensitif dan menyederhanakan join berulang.

## Stored Procedure

```sql
DELIMITER //
CREATE PROCEDURE ringkas_dept(IN p_dept VARCHAR(50))
BEGIN
  SELECT COUNT(*) AS jumlah, AVG(gaji) AS rata
  FROM karyawan
  WHERE dept = p_dept;
END//
DELIMITER ;

CALL ringkas_dept('Engineering');
```

`DELIMITER //` diperlukan di klien mysql agar titik koma di dalam badan prosedur tidak mengakhiri statement pembuat.

## Stored Function

```sql
DELIMITER //
CREATE FUNCTION level_gaji(g DECIMAL(12,2))
RETURNS VARCHAR(10)
DETERMINISTIC
BEGIN
  IF g >= 10000000 THEN RETURN 'Tinggi';
  ELSE RETURN 'Standar';
  END IF;
END//
DELIMITER ;
```

Fungsi bisa dipakai di SELECT seperti fungsi bawaan. Hindari fungsi yang melakukan query berat per baris.

## Trigger

```sql
CREATE TABLE audit_karyawan (
 id INT AUTO_INCREMENT PRIMARY KEY,
 aksi VARCHAR(20), id_karyawan INT, waktu DATETIME DEFAULT NOW()
);

DELIMITER //
CREATE TRIGGER trg_karyawan_ai AFTER INSERT ON karyawan
FOR EACH ROW
BEGIN
  INSERT INTO audit_karyawan(aksi, id_karyawan)
  VALUES ('INSERT', NEW.id);
END//
DELIMITER ;
```

## Kapan Dipakai

| Kebutuhan | Pilihan |
| --- | --- |
| Menyederhanakan query laporan | View |
| Validasi lintas tabel di DB | Trigger |
| Proses berulang dengan transaksi | Procedure |
| Perhitungan kecil dipakai query | Function |

<div class="note">💡 Simpan definisi routine di file SQL yang masuk version control. Routine yang hanya ada di server dan tidak didokumentasikan sangat sulit dipelihara.</div>

## Di Dunia Nyata

- **RBAC**: view tanpa kolom gaji untuk akun tertentu.
- **Audit**: trigger mencatat perubahan data sensitif.
- **Laporan**: view standar dipakai banyak dashboard.
- **Batch**: procedure menjalankan serangkaian UPDATE dalam transaksi.
