MySQL adalah sistem manajemen database relasional yang paling banyak dipakai untuk aplikasi web. Sebelum menulis query, pastikan server berjalan dan kamu bisa masuk dengan akun yang tepat.

## Menghubungkan Diri

```bash
mysql -u root -p
mysql -h 127.0.0.1 -P 3306 -u app -p academy
```

Flag `-h` host, `-P` port, `-u` user, `-p` meminta kata sandi. Menaruh kata sandi langsung setelah `-p` tanpa spasi berisiko terekam di riwayat shell.

## Perintah Awal

```sql
SHOW DATABASES;
CREATE DATABASE academy CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE academy;
SHOW TABLES;
SELECT DATABASE(), VERSION(), USER();
```

Gunakan `utf8mb4` bukan `utf8` — `utf8` di MySQL hanya mendukung 3 byte dan gagal menyimpan emoji serta beberapa aksara.

## Struktur Lapisan

```text
Server MySQL
 └─ Database (schema)
     └─ Table
         ├─ Column
         ├─ Index
         └─ Row
```

Satu server bisa menampung banyak database; satu database berisi banyak tabel. Hak akses bisa diberikan per database atau per tabel.

## File Konfigurasi

| File | Fungsi |
| --- | --- |
| `my.cnf` / `my.ini` | konfigurasi server |
| data directory | menyimpan file tabel dan log |
| error log | diagnosis saat server gagal start |
| slow query log | query yang melewati `long_query_time` |

```sql
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL long_query_time = 1;
```

## Backup dan Restore

```bash
mysqldump -u root -p academy > academy.sql
mysql -u root -p academy < academy.sql
```

Untuk produksi, tambahkan `--single-transaction` agar backup konsisten tanpa mengunci seluruh tabel InnoDB.

<div class="note">💡 Jangan menjalankan server MySQL dengan akun root sistem operasi. Berikan akun khusus dengan hak minimal pada direktori data.</div>

## Di Dunia Nyata

- **Lokal development**: Docker Compose memudahkan versi MySQL yang konsisten antar developer.
- **Staging**: salin struktur dari produksi tanpa data sensitif.
- **Produksi**: backup otomatis dan uji restore rutin.
- ** debugging**: error log dan slow query log dua sumber pertama saat ada masalah.
