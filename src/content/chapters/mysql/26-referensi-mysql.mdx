Chapter penutup ini merangkum perintah MySQL yang paling sering dipakai dan memberi arah belajar lanjutan. Jadikan daftar ini pengingat cepat, bukan pengganti praktik.

## Perintah Inti

| Kategori | Perintah |
| --- | --- |
| Database | CREATE, DROP, USE, SHOW DATABASES |
| Tabel | CREATE, ALTER, DROP, DESCRIBE |
| Data | SELECT, INSERT, UPDATE, DELETE |
| Filter | WHERE, LIKE, IN, BETWEEN, IS NULL |
| Agregat | COUNT, SUM, AVG, GROUP BY, HAVING |
| Gabung | JOIN, UNION |
| Lanjutan | CTE, window function, view, procedure |
| Transaksi | START TRANSACTION, COMMIT, ROLLBACK |
| Performa | EXPLAIN, ANALYZE TABLE, OPTIMIZE TABLE |
| Hak | CREATE USER, GRANT, REVOKE

## Template Query

```sql
WITH ringkas AS (
  SELECT dept, COUNT(*) AS jumlah, AVG(gaji) AS rata
  FROM karyawan
  WHERE gaji >= 7000000
  GROUP BY dept
)
SELECT dept, jumlah, ROUND(rata) AS rata,
       CASE WHEN jumlah >= 3 THEN 'Besar' ELSE 'Kecil' END AS ukuran
FROM ringkas
HAVING jumlah >= 2
ORDER BY rata DESC
LIMIT 10;
```

## Storage Engine

| Engine | Cocok untuk |
| --- | --- |
| InnoDB | transaksi, foreign key, aplikasi umum |
| MyISAM | legacy, read-heavy tanpa transaksi |
| MEMORY | data sementara sangat cepat |
| ARCHIVE | log jarang dibaca |

Gunakan InnoDB kecuali ada alasan khusus.

## Rencana Latihan

1. SELECT + WHERE + ORDER BY + LIMIT.
2. Agregasi dengan GROUP BY dan HAVING.
3. INNER/LEFT JOIN sampai bisa anti join.
4. Subquery, lalu CTE dan window function.
5. Index + EXPLAIN.
6. Transaksi, prepared statement, dan migrasi aman.

## Langkah Berikutnya

- Pelajari *query optimization* dengan EXPLAIN ANALYZE.
- Pahami replication dan backup restore.
- Gunakan ORM dengan bijak — tetap pahami SQL yang dihasilkan.
- Biasakan menulis tes integrasi terhadap MySQL versi produksi.

<div class="note">💡 MySQL dan PostgreSQL itu mirip di permukaan, tetapi berbeda pada detail penting. Membaca chapter PostgreSQL setelah ini akan memperkuat pemahaman dialek keduanya.</div>

## Di Dunia Nyata

- **Backend web**: CRUD dengan prepared statement dan transaksi.
- **Analitik ringan**: agregasi + CTE untuk laporan.
- **Operasional**: backup, monitoring, dan migrasi.
- **Skala**: replikasi dan partisi saat data bertumbuh.
