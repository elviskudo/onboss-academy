Transaksi menjaga beberapa perubahan tetap konsisten. InnoDB adalah storage engine MySQL yang mendukung transaksi dan foreign key; MyISAM tidak.

## Alur Transaksi

```sql
START TRANSACTION;
UPDATE rekening SET saldo = saldo - 50000 WHERE id = 1;
UPDATE rekening SET saldo = saldo + 50000 WHERE id = 2;
COMMIT;
```

Jika salah satu gagal: `ROLLBACK;`. Gunakan `SAVEPOINT nama;` untuk rollback sebagian.

## Isolation Level

```sql
SET SESSION TRANSACTION ISOLATION LEVEL READ COMMITTED;
SELECT @@transaction_isolation;
```

| Level | Fenomena yang dicegah |
| --- | --- |
| READ UNCOMMITTED | hampir tidak ada jaminan |
| READ COMMITTED | dirty read |
| REPEATABLE READ | dirty + non-repeatable read (default InnoDB) |
| SERIALIZABLE | semua, dengan konkurensi terendah

## Locking

```sql
SELECT * FROM produk WHERE id = 1 FOR UPDATE;
SELECT * FROM produk WHERE id = 1 LOCK IN SHARE MODE;
```

`FOR UPDATE` mengunci baris yang dibaca agar transaksi lain tidak mengubahnya sampai selesai. Gunakan hanya di dalam transaksi.

## Deadlock

```text
Transaksi A: kunci baris 1 → minta baris 2
Transaksi B: kunci baris 2 → minta baris 1
→ siklus; MySQL membatalkan salah satu
```

Cara mengurangi:

1. Selalu akses tabel dan baris dalam urutan yang sama.
2. Perpendek transaksi.
3. Pastikan kolom filter ter-index agar lock tidak melebar.
4. Siapkan retry di aplikasi saat error 1213 (deadlock).

## Autocommit

```sql
SELECT @@autocommit;
SET autocommit = 0;   -- hati-hati, berlaku untuk sesi
```

Sebaiknya biarkan autocommit = 1 dan gunakan `START TRANSACTION` eksplisit hanya untuk operasi yang memang perlu.

<div class="note">💡 Transaksi yang dibiarkan terbuka sambil menunggu input pengguna adalah resep untuk lock berjam-jam. Kumpulkan data dulu, lalu buka transaksi, kerjakan, dan tutup segera.</div>

## Di Dunia Nyata

- **Transfer saldo**: dua UPDATE dalam satu transaksi.
- **Pemesanan**: stok berkurang + pesanan dibuat + log dicatat.
- **Import data**: ROLLBACK bila ada baris invalid.
- **Stok konkuren**: FOR UPDATE mencegah dua pembeli mengambil barang terakhir.
