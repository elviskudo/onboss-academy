Agregasi merangkum banyak baris menjadi satu angka atau ringkasan per grup. MySQL menambahkan `GROUP_CONCAT` yang sangat berguna untuk mengumpulkan daftar nilai.

## Fungsi Agregat

| Fungsi | Arti |
| --- | --- |
| `COUNT(*)` | jumlah baris termasuk NULL |
| `COUNT(kolom)` | jumlah nilai non-NULL |
| `SUM` | total |
| `AVG` | rata-rata |
| `MIN`/`MAX` | nilai ekstrem |
| `GROUP_CONCAT` | gabung nilai string |

```sql
SELECT dept, COUNT(*) AS jumlah, SUM(gaji) AS total,
       ROUND(AVG(gaji)) AS rata, MIN(gaji) AS terendah, MAX(gaji) AS tertinggi
FROM karyawan GROUP BY dept;
```

## GROUP_CONCAT

```sql
SELECT dept, GROUP_CONCAT(nama ORDER BY nama SEPARATOR ', ') AS anggota
FROM karyawan
GROUP BY dept;
```

Panjang hasil dibatasi `group_concat_max_len` (default 1024). Untuk daftar panjang, naikkan dengan `SET SESSION group_concat_max_len = 10000;`.

## WHERE vs HAVING

```sql
SELECT dept, COUNT(*) AS jumlah, AVG(gaji) AS rata
FROM karyawan
WHERE gaji >= 7000000
GROUP BY dept
HAVING COUNT(*) >= 2
ORDER BY rata DESC;
```

WHERE menyaring baris sebelum dihitung; HAVING menyaring grup setelah dihitung.

## ROLLUP

```sql
SELECT dept, COUNT(*) AS jumlah
FROM karyawan
GROUP BY dept WITH ROLLUP;
```

Baris tambahan dengan `dept = NULL` adalah total keseluruhan. Bedakan dengan NULL asli memakai `GROUPING(dept)` di MySQL 8.0+.

## ONLY_FULL_GROUP_BY

MySQL 8 mengaktifkan mode SQL `ONLY_FULL_GROUP_BY`: kolom di SELECT harus masuk GROUP BY atau agregat. Ini mencegah hasil yang ambigu dan sejalan dengan standar SQL.

<div class="note">💡 `HAVING jumlah >= 2` boleh memakai alias di MySQL. Di database lain, alias belum tersedia di HAVING sehingga agregat harus diulang.</div>

## Di Dunia Nyata

- **Ringkasan SDM**: jumlah dan rata-rata gaji per departemen.
- **Daftar anggota**: GROUP_CONCAT untuk menampilkan tim dalam satu sel.
- **Penjualan**: total omzet per wilayah dan produk terlaris.
- **Log**: jumlah error per endpoint per hari.
