JOIN menggabungkan data dari beberapa tabel. Di MySQL, bentuk paling umum adalah INNER JOIN dan LEFT JOIN; RIGHT JOIN tersedia tetapi jarang diperlukan.

## Contoh Join

```sql
SELECT k.nama, p.nama AS proyek, p.budget
FROM karyawan k
INNER JOIN proyek p ON p.lead_id = k.id;
```

Gunakan alias agar query tetap pendek dan kolom tidak ambigu.

## LEFT JOIN dan Anti Join

```sql
SELECT k.nama
FROM karyawan k
LEFT JOIN proyek p ON p.lead_id = k.id
WHERE p.id IS NULL;
```

Ini mencari karyawan yang belum memimpin proyek apa pun.

## USING

```sql
SELECT *
FROM karyawan k
JOIN proyek p USING (id);
```

`USING` hanya bisa dipakai bila nama kolom kunci identik di kedua tabel. Hasilnya kolom kunci tidak duplikat.

## RIGHT dan CROSS

```sql
-- RIGHT JOIN: semua baris tabel kanan (jarang diperlukan)
SELECT * FROM karyawan k RIGHT JOIN proyek p ON p.lead_id = k.id;

-- CROSS JOIN: semua kombinasi, hati-hati ukurannya
SELECT k.nama, h.nama AS hari
FROM karyawan k CROSS JOIN hari h;
```

CROSS JOIN berguna untuk membuat kalender atau kombinasi produk-ukuran.

## Kardinalitas

Jika tabel kanan punya 3 baris untuk satu kunci, hasil join punya 3 baris. Sebelum agregasi, cek duplikat:

```sql
SELECT lead_id, COUNT(*) FROM proyek GROUP BY lead_id HAVING COUNT(*) > 1;
```

<div class="note">💡 Filter pada tabel kanan di LEFT JOIN sebaiknya ditaruh di klausa ON, bukan WHERE. Jika tidak, baris yang tidak cocok akan terbuang dan LEFT JOIN berubah menjadi INNER JOIN.</div>

## Di Dunia Nyata

- **Katalog**: `produk JOIN kategori` menampilkan nama kategori.
- **Laporan penjualan**: `pelanggan LEFT JOIN transaksi` tetap memuat pelanggan baru.
- **Kalender**: CROSS JOIN tanggal dan cabang menghasilkan baris untuk setiap kombinasi.
- **Rekonsiliasi**: anti join menemukan data yang belum tersinkron.
