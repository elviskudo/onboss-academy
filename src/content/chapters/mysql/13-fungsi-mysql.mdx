MySQL menyediakan ratusan fungsi bawaan. Tiga kelompok yang paling sering dipakai adalah fungsi string, angka, dan tanggal.

## String

| Fungsi | Contoh | Hasil |
| --- | --- | --- |
| `CONCAT` | `CONCAT('A','B')` | AB |
| `UPPER`/`LOWER` | `UPPER('ana')` | ANA |
| `LENGTH` | `LENGTH('Rani')` | 4 |
| `SUBSTRING` | `SUBSTRING('2026-11',1,4)` | 2026 |
| `TRIM` | `TRIM(' R ')` | R |
| `REPLACE` | `REPLACE('a-b','-','')` | ab |

```sql
SELECT CONCAT(nama, ' (', jabatan, ')') AS label FROM karyawan;
```

## Angka

```sql
SELECT ROUND(AVG(gaji), 0) AS rata,
       CEIL(12.3) AS atas,
       FLOOR(12.8) AS bawah,
       MOD(17, 5) AS sisa;
```

`ROUND(x, d)` membulatkan ke d desimal. Untuk uang selalu pakai `DECIMAL`, bukan `FLOAT`.

## Tanggal

```sql
SELECT NOW() AS saat_ini,
       CURDATE() AS hari_ini,
       YEAR('2026-11-20') AS tahun,
       MONTH('2026-11-20') AS bulan,
       DATE_ADD('2026-11-20', INTERVAL 7 DAY) AS minggu_depan;
```

`DATEDIFF(a, b)` menghitung selisih hari; `TIMESTAMPDIFF(HOUR, a, b)` memberi selisih jam.

## Format Tanggal

```sql
SELECT DATE_FORMAT('2026-11-20', '%d/%m/%Y') AS tampilan;
-- 20/11/2026
```

Simpan tanggal dalam tipe DATE/DATETIME, bukan string. Format tampilan diurus saat query, bukan saat penyimpanan.

## NULL dan Condition

```sql
SELECT COALESCE(dept, 'Tanpa unit') AS unit,
       IF(gaji >= 10000000, 'Tinggi', 'Standar') AS level,
       NULLIF(stok, 0) AS stok_aman
FROM karyawan;
```

`IF()` adalah versi ringkas CASE untuk dua cabang; `NULLIF()` membantu menghindari pembagian dengan nol.

<div class="note">💡 Memanggil fungsi pada kolom yang ter-index di WHERE sering membuat index tidak dipakai. `WHERE YEAR(tanggal)=2026` lebih lambat daripada `WHERE tanggal >= '2026-01-01' AND tanggal < '2027-01-01'`.</div>

## Di Dunia Nyata

- **Label UI**: `CONCAT()` merakit nama lengkap dan jabatan.
- **Laporan bulanan**: `DATE_FORMAT()` mengelompokkan transaksi per bulan.
- **Validasi**: `LENGTH()` memeriksa panjang kode.
- **SLA**: `TIMESTAMPDIFF()` mengukur durasi respons.
