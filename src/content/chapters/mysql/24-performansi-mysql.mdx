Diagnostik performansi dimulai dari bukti: query mana yang lambat, berapa sering, dan apa rencananya. MySQL menyediakan slow query log, EXPLAIN, dan berbagai status variable.

## Slow Query Log

```sql
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL long_query_time = 1;
SET GLOBAL log_queries_not_using_indexes = 'ON';
SHOW VARIABLES LIKE 'slow_query%';
```

Di produksi, sebaiknya gunakan konfigurasi file agar tetap aktif setelah restart. Analisis dengan `mysqldumpslow` atau tools lain.

## EXPLAIN

```sql
EXPLAIN SELECT nama, gaji FROM karyawan WHERE dept = 'Engineering';
```

Kolom penting:

| Kolom | Arti |
| --- | --- |
| `type` | ALL = full scan; const/ref/range = baik |
| `key` | index yang dipakai |
| `rows` | estimasi baris dibaca |
| `Extra` | Using index bagus; Using temporary/filesort perlu perhatian

## EXPLAIN ANALYZE

```sql
EXPLAIN ANALYZE
SELECT dept, COUNT(*) FROM karyawan GROUP BY dept;
```

Berbeda dengan EXPLAIN biasa, perintah ini benar-benar menjalankan query dan menunjukkan waktu serta jumlah baris aktual.

## Konfigurasi Utama

| Variabel | Fungsi |
| --- | --- |
| `innodb_buffer_pool_size` | cache data + index |
| `innodb_log_file_size` | ukuran redo log |
| `max_connections` | batas koneksi bersamaan |
| `query_cache_size` | dihapus di MySQL 8 |

Ubah satu variabel pada satu waktu dan ukur dampaknya.

## Pola Query yang Sering Lambat

```sql
-- Fungsi pada kolom menghalangi index
WHERE YEAR(tanggal) = 2026

-- Wildcard di awal
WHERE nama LIKE '%kopi'

-- Select kolom tak perlu
SELECT * FROM pesanan

-- OFFSET besar
LIMIT 10000, 20
```

<div class="note">💡 Optimizer bisa salah memilih index bila statistik basi. Jalankan `ANALYZE TABLE` setelah perubahan data besar sebelum menyimpulkan index itu "tidak berguna".</div>

## Di Dunia Nyata

- **Endpoint lambat**: slow log menunjukkan query yang dipanggil 500 kali per menit.
- **Dashboard**: GROUP BY tanpa index menyebabkan temporary table.
- **Paging**: keyset pagination menggantikan OFFSET besar.
- **Kapasitas**: buffer pool terlalu kecil membuat I/O disk tinggi.
