Saatnya menggabungkan semuanya menjadi aplikasi katalog produk dengan keranjang dan navigasi.

## Struktur

```
src/
  main.js
  App.vue
  router/index.js
  stores/keranjang.js
  composables/useFetch.js
  components/KartuProduk.vue
  views/Daftar.vue
  views/Detail.vue
```

## Store Keranjang

```js
import { defineStore } from 'pinia'

export const useKeranjang = defineStore('keranjang', {
  state: () => ({ items: [] }),
  getters: {
    jumlah: (s) => s.items.length,
    total: (s) => s.items.reduce((a, i) => a + i.harga, 0),
  },
  actions: {
    tambah(p) { this.items.push(p) },
  },
})
```

## Halaman Daftar

```vue
<script setup>
import { computed, ref } from 'vue'
import { useFetch } from '@/composables/useFetch'
import KartuProduk from '@/components/KartuProduk.vue'
import { useKeranjang } from '@/stores/keranjang'

const kata = ref('')
const { data, loading } = useFetch('/api/produk')
const keranjang = useKeranjang()

const tersaring = computed(() =>
  (data.value ?? []).filter((p) =>
    p.nama.toLowerCase().includes(kata.value.toLowerCase())
  )
)
</script>

<template>
  <h1>Katalog Produk</h1>
  <input v-model="kata" placeholder="Cari…">

  <p v-if="loading">Memuat…</p>
  <div v-else class="grid">
    <KartuProduk
      v-for="p in tersaring"
      :key="p.id"
      :produk="p"
      @tambah="keranjang.tambah"
    />
  </div>

  <footer>{{ keranjang.jumlah }} item — Rp{{ keranjang.total }}</footer>
</template>
```

## Checklist

- [ ] Semua `v-for` punya `:key` stabil.
- [ ] Data API ada di composable/service.
- [ ] State lintas halaman ada di Pinia.
- [ ] Rute sensitif punya guard.
- [ ] `npm run build` sukses.

<div class="note">💡 Bangun bertahap: daftar statis → fetch API → keranjang → routing → validasi. Setiap tahap bisa dijalankan dan dicek sebelum lanjut.</div>
