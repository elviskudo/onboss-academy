Vue adalah **framework UI progresif**: kamu bisa memakainya sedikit (satu komponen di halaman lama) atau penuh (SPA dengan router dan state manager).

## 4 Konsep Inti Vue

| Konsep | Bentuk | Fungsi | Padanan pondasi JS |
|--------|--------|--------|--------------------|
| State reaktif | `ref`, `reactive` | Data berubah → UI ikut berubah | Variabel/object |
| Template | `{{ nilai }}`, directive | Mendeskripsikan tampilan | Ekspresi & percabangan |
| Component | file `.vue` | Unit UI yang reusable | Function/module |
| Props & emit | `defineProps`, `defineEmits` | Komunikasi induk ↔ anak | Argumen & callback |

Vue juga memiliki Vue Router untuk navigasi dan Pinia untuk state global. Keduanya terpisah tetapi dirawat sebagai bagian ekosistem resmi.

## Kenapa Vue?

- **Belajar cepat**: sintaks HTML, JS, dan CSS yang sudah kamu kenal.
- **Reaktif**: ubah data, tampilan ikut berubah tanpa menyentuh DOM.
- **Komponen**: UI dipecah jadi potongan kecil yang bisa dipakai ulang.
- Dipakai: Laravel Livewire/Volt, Nuxt, banyak startup Asia, dan antarmuka admin di seluruh dunia.

## Anatomi Komponen (.vue)

```html
<template>
  <h1>Halo, {{ nama }}!</h1>
  <button @click="tambah">Tambah</button>
</template>

<script setup>
import { ref } from "vue";

const nama = ref("Sari");
const jumlah = ref(0);

function tambah() {
  jumlah.value++;
}
</script>

<style scoped>
h1 { color: #42b883; }
</style>
```

- `template` — tampilan (HTML yang diperluas dengan directive Vue).
- `script setup` — logika dan state reaktif.
- `style scoped` — CSS yang hanya berlaku untuk komponen ini.

## Mounting ke Halaman

```javascript
import { createApp } from "vue";
import App from "./App.vue";

createApp(App).mount("#app");
```

## Data Reactif: ref dan reactive

```javascript
import { ref, reactive } from "vue";

const jumlah = ref(0);          // primitif — akses lewat .value
const user = reactive({         // object — akses langsung
  nama: "Sari",
  umur: 20,
});

jumlah.value++;
user.umur++;
```

`ref` membungkus satu nilai (termasuk object/array) dan diakses lewat `.value` dalam script. `reactive` membuat proxy object/array yang propertinya diakses langsung. Keduanya menggantikan variabel biasa saat perubahan harus memicu render.

## OOP vs Komponen

Vue modern memakai **function dan closure**, bukan class component. Options API menulis object `data`, `methods`, dan `computed`; Composition API mengelompokkan state dan handler berdasarkan fitur. Class hanya relevan bila domain aplikasinya memang memakai class JavaScript — bukan untuk mendefinisikan komponen Vue.

## Di Dunia Nyata

- **Panel admin**: tabel, filter, dan pagination menjadi komponen dengan state reaktif.
- **Form pendaftaran**: `v-model` mengikat input; validasi dirender segera tanpa query DOM manual.
- **Katalog toko**: array produk di-loop menjadi kartu; stok menentukan conditional rendering tombol.
- **Dashboard real-time**: data WebSocket memperbarui `ref`, grafik dan angka ikut berubah.
- **Migrasi halaman lama**: satu widget Vue di-mount ke elemen tertentu tanpa menulis ulang seluruh situs.
