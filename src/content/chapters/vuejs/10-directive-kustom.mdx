Directive adalah cara Vue memberi "perilaku tambahan" pada elemen DOM. Bawaan seperti `v-if` dan `v-model` sudah banyak, tapi kamu bisa membuat sendiri.

## Mendaftarkan

```vue
<script setup>
const vFokus = {
  mounted(el) {
    el.focus();
  },
};
</script>

<template>
  <input v-fokus placeholder="Auto fokus">
</template>
```

Dengan `<script setup>`, variabel `vFokus` otomatis tersedia sebagai `v-fokus`.

## Menerima Nilai

```vue
<script setup>
const vWarna = {
  mounted(el, binding) {
    el.style.color = binding.value;
    if (binding.modifiers.tebal) el.style.fontWeight = 'bold';
  },
  updated(el, binding) {
    el.style.color = binding.value;
  },
};
</script>

<template>
  <p v-warna.tebal="'teal'">Teks berwarna</p>
</template>
```

## Hook yang Tersedia

| Hook | Saat |
|------|------|
| `created` | sebelum atribut terpasang |
| `beforeMount` | sebelum elemen masuk DOM |
| `mounted` | sesudah masuk DOM |
| `beforeUpdate` | sebelum update |
| `updated` | sesudah update |
| `beforeUnmount` | sebelum dihapus |
| `unmounted` | sesudah dihapus |

## Contoh: Klik di Luar

```js
const vKlikLuar = {
  mounted(el, binding) {
    el._handler = (e) => {
      if (!el.contains(e.target)) binding.value(e);
    };
    document.addEventListener('click', el._handler);
  },
  unmounted(el) {
    document.removeEventListener('click', el._handler);
  },
};
```

<div class="note">💡 Cleanup di `unmounted` wajib bila directive menambah event listener global. Kalau tidak, listener bisa tetap hidup setelah komponen hilang.</div>
