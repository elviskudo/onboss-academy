Saatnya proyek penutup: **aplikasi to-do** yang memakai seluruh materi Vue — state reaktif, computed, event, percabangan, looping, props, dan emit.

## 6 Bagian Proyek

| Bagian | Konsep Vue | Fungsi |
|--------|------------|--------|
| `teks` | `ref("")` | State input tugas baru |
| `daftar` | `ref([])` | Satu sumber kebenaran array tugas |
| `sisa` | `computed` | Nilai turunan dari daftar |
| `tambah/toggle/hapus` | Function handler | Mengubah state saat event |
| `v-if` / `v-for` | Conditional & list rendering | Pilih dan ulang tampilan |
| `TugasItem` | Props + emit | Pisahkan item dan komunikasi ke induk |

Tidak diperlukan class OOP: object tugas adalah data, function handler adalah perilaku, dan komponen mengemas tampilan. Ini lebih sederhana daripada membuat class `Todo` untuk data sekecil ini.

## State Aplikasi

```html
<script setup>
import { ref, computed } from "vue";

const teks = ref("");
const daftar = ref([]);

const sisa = computed(() => daftar.value.filter((t) => !t.selesai).length);
const selesaiSemua = computed(() => daftar.value.length > 0 && sisa.value === 0);

function tambah() {
  const bersih = teks.value.trim();
  if (!bersih) return;
  daftar.value.push({ id: Date.now(), teks: bersih, selesai: false });
  teks.value = "";
}
</script>
```

Satu `daftar` sebagai **satu sumber kebenaran** — semua tampilan diturunkan dari sana.

## Aksi pada Daftar

```html
<script setup>
function toggle(t) {
  t.selesai = !t.selesai;   // reactive object: perubahan langsung terlihat
}

function hapus(id) {
  daftar.value = daftar.value.filter((t) => t.id !== id);
}

function bersihkanSelesai() {
  daftar.value = daftar.value.filter((t) => !t.selesai);
}
</script>
```

## Template Lengkap

```html
<template>
  <form @submit.prevent="tambah">
    <input v-model="teks" placeholder="Tugas baru..." />
    <button type="submit">Tambah</button>
  </form>

  <p>{{ sisa }} tugas tersisa</p>

  <ul>
    <li v-for="t in daftar" :key="t.id">
      <label>
        <input type="checkbox" v-model="t.selesai" />
        <span :class="{ coret: t.selesai }">{{ t.teks }}</span>
      </label>
      <button @click="hapus(t.id)">Hapus</button>
    </li>
  </ul>

  <button v-if="daftar.length" @click="bersihkanSelesai">
    Hapus yang selesai
  </button>
</template>

<style scoped>
.coret { text-decoration: line-through; opacity: 0.6; }
</style>
```

## Pecah Menjadi Komponen

Saat aplikasi membesar, pisahkan `TugasItem.vue`. Induk melakukan `v-for`, mengirim `:tugas="t"`, lalu menangkap `@toggle` dan `@hapus`. Anak hanya menerima props dan emit ID; array tetap dimiliki induk. Pola satu arah ini mencegah state ganda.

## Persistensi dan Filter

Gunakan `watch(daftar, ...)` dengan opsi `{ deep: true }` untuk menyimpan JSON ke `localStorage`. Saat mount, parse data dengan fallback array kosong. Filter **Semua | Aktif | Selesai** cukup berupa satu state `filter` dan satu computed `daftarTampil`; jangan buat tiga salinan array.

## Di Dunia Nyata

- **Task pribadi**: localStorage menjaga daftar setelah browser ditutup.
- **Tim proyek**: emit dari item mengirim ID; induk menyinkronkan perubahan ke API.
- **Daftar belanja**: pola sama, status selesai diganti status sudah dibeli.
- **Antrian support**: computed memfilter tiket aktif/selesai dan menghitung badge sisa.
- **Checklist onboarding**: conditional rendering menampilkan progres 100% ketika semua item selesai.

## Latihan Pengembangan

- Simpan `daftar` ke `localStorage` dengan `watch` (`JSON.stringify` / `JSON.parse`).
- Tambah filter: **Semua | Aktif | Selesai** — cukup satu computed tambahan.
- Pisahkan `<li>` jadi komponen `TugasItem.vue` dengan props `tugas` dan emit `hapus`.
