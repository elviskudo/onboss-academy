Komponen adalah **fungsi yang mengembalikan tampilan**. Besar kecil layar aplikasi modern semuanya dipecah jadi komponen, bukan class OOP.

## 4 Bagian Kontrak Komponen

| Bagian | Arah | Fungsi | Contoh |
|--------|------|--------|--------|
| Props | Induk → anak | Mengirim data read-only | `:item="produk"` |
| Emit | Anak → induk | Mengirim event/payload | `emit("hapus", id)` |
| Slot | Induk → area anak | Mengirim fragmen template | `<template #header>` |
| State lokal | Internal anak | Menyimpan data milik anak | status panel terbuka |

Bab ini fokus pada props. Emit dan slot dibahas berikutnya. Pembagian kontrak mencegah anak mengubah state induk secara diam-diam.

## Mengimpor & Memakai Komponen

```html
<!-- App.vue -->
<template>
  <Kartu judul="Selamat datang" isi="Belajar Vue" />
  <Kartu judul="Tips" isi="Pecah UI jadi bagian kecil" />
</template>

<script setup>
import Kartu from "./Kartu.vue";
</script>
```

Nama file menjadi nama tag — `Kartu.vue` → `<Kartu />`.

## Mendeklarasikan Props

```html
<!-- Kartu.vue -->
<template>
  <article class="kartu">
    <h3>{{ judul }}</h3>
    <p>{{ isi }}</p>
    <small v-if="penulis">oleh {{ penulis }}</small>
  </article>
</template>

<script setup>
defineProps({
  judul: { type: String, required: true },
  isi: { type: String, default: "" },
  penulis: { type: String, default: "Anonim" },
});
</script>
```

Props bersifat **satu arah**: induk → anak. Anak hanya membaca.

## Props dengan Tipe Sederhana

```html
<script setup>
// Singkat: hanya menyatakan tipe
const props = defineProps(["judul", "isi"]);
console.log(props.judul);
</script>
```

## Mengirim Data Dinamis

```html
<template>
  <!-- string biasa -->
  <Kartu judul="Promo" />

  <!-- binding ke data -->
  <Kartu :judul="judulAktif" :isi="isiAktif" />
</template>
```

Tanpa `:`, nilai dibaca sebagai teks literal.

## Pola JavaScript-nya

```javascript
// Komponen pada dasarnya function yang memproses props
function Kartu(props) {
  const judul = props.judul ?? "Tanpa judul";
  const isi = props.isi ?? "";
  return { render: judul + ": " + isi };
}

console.log(Kartu({ judul: "Info", isi: "Halo Vue" }).render);
```

## Komponen dan List Rendering

```html
<Kartu
  v-for="produk in daftar"
  :key="produk.id"
  :judul="produk.nama"
  :isi="'Rp' + produk.harga"
/>
```

`v-for` adalah looping, sementara props adalah argumen untuk setiap "pemanggilan" komponen. Jika produk habis, anak bisa memakai `v-if` untuk conditional rendering tombol.

## Di Dunia Nyata

- **Katalog**: satu `KartuProduk` menerima object produk untuk ratusan item.
- **Dashboard**: `KartuStatistik` menerima label, nilai, dan tren yang berbeda.
- **Form reusable**: `InputField` menerima label, type, error, dan disabled.
- **Navigasi**: `MenuItem` menerima URL dan status aktif dari router.
- **Tabel data**: induk loop baris; tiap `BarisPengguna` hanya membaca props user.

<div class="note">💡 Jangan mengubah `props.x` di dalam komponen anak — Vue akan memperingatkan. Kirim event ke induk (`$emit`) agar induk yang memperbarui datanya; materi bab berikutnya.</div>
