Test memberi kepercayaan diri saat mengubah kode. Vue Test Utils memudahkan merender komponen tanpa browser sungguhan.

## Persiapan

```bash
npm i -D vitest @vue/test-utils jsdom
```

```js
// vitest.config.js
export default {
  test: { environment: 'jsdom', globals: true },
};
```

## Test Komponen

```vue
<!-- Counter.vue -->
<script setup>
import { ref } from 'vue'
const n = ref(0)
</script>

<template>
  <output>{{ n }}</output>
  <button @click="n++">Tambah</button>
</template>
```

```js
import { mount } from '@vue/test-utils'
import { test, expect } from 'vitest'
import Counter from './Counter.vue'

test('tombol menambah angka', async () => {
  const wrapper = mount(Counter)
  expect(wrapper.text()).toContain('0')

  await wrapper.find('button').trigger('click')
  expect(wrapper.text()).toContain('1')
})
```

## Test Form

```js
const input = wrapper.find('input');
await input.setValue('Sari');
await wrapper.find('form').trigger('submit.prevent');
expect(wrapper.text()).toContain('Halo, Sari');
```

## Mock Store / Router

```js
const keranjang = { items: [], tambah: vi.fn() };

mount(Komponen, {
  global: {
    provide: { [KunciKeranjang]: keranjang },
    mocks: { $router: { push: vi.fn() } },
  },
});
```

<div class="note">💡 Uji satu perilaku per test dan beri nama yang menjelaskan skenario. Test yang gagal lalu harus langsung memberi tahu apa yang rusak.</div>
