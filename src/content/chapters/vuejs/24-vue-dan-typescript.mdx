TypeScript membuat kontrak komponen Vue menjadi jelas: props apa yang masuk, event apa yang keluar.

## Props Bertipe

```vue
<script setup lang="ts">
interface Props {
  judul: string
  qty?: number
}

const props = withDefaults(defineProps<Props>(), {
  qty: 1,
})
</script>
```

## Emits Bertipe

```vue
<script setup lang="ts">
const emit = defineEmits<{
  pilih: [id: number]
  tutup: []
}>()

function kirim() {
  emit('pilih', 42) // ✅
  // emit('pilih', '42') // ❌ error TS
}
</script>
```

## Ref dan Reactive

```ts
import { ref, reactive } from 'vue'

const jumlah = ref<number>(0)
const form = reactive<{ nama: string; umur?: number }>({ nama: '' })
```

## Composable Bertipe

```ts
export function useFetch<T>(url: Ref<string>) {
  const data = ref<T | null>(null)
  const error = ref('')
  return { data, error }
}
```

```ts
const { data } = useFetch<Produk[]>(url)
```

## Tips

- Aktifkan `vue-tsc` untuk pemeriksaan tipe di template.
- Gunakan `import type` untuk tipe saja.
- Hindari `any` kecuali memang tidak ada pilihan.
