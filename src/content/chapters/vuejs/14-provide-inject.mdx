`provide`/`inject` adalah versi Vue dari context: induk menyediakan data, keturunan mana pun bisa mengambilnya.

## Dasar

```vue
<!-- App.vue -->
<script setup>
import { provide, ref, readonly } from 'vue'

const tema = ref('terang')
provide('tema', readonly(tema))
</script>
```

```vue
<!-- Tombol.vue, berapa level pun di bawahnya -->
<script setup>
import { inject } from 'vue'

const tema = inject('tema', 'terang')
</script>

<template>
  <button :class="tema">Lanjut</button>
</template>
```

Argumen kedua `inject` adalah default bila tidak ada provider.

## Reactive Value

```js
const user = ref(null);
provide('user', user);
```

Anak bisa membaca `user.value`, dan perubahan di induk langsung terlihat.

## Symbol sebagai Kunci

```js
// kunci.js
export const KunciTema = Symbol('tema');

// pemakaian
provide(KunciTema, tema);
const tema = inject(KunciTema);
```

Symbol mencegah bentrok nama antar fitur.

## Simpan di File Terpisah

```
src/
  composables/
    useTema.js   -> provide + inject dibungkus rapi
```

```js
export function sediakanTema() {
  const tema = ref('terang');
  provide(KunciTema, readonly(tema));
  return { tema };
}

export function pakaiTema() {
  return inject(KunciTema, ref('terang'));
}
```

<div class="note">💡 Gunakan provide/inject untuk data "infrastruktur" seperti tema, bahasa, atau sesi. Untuk data fitur biasa, props tetap lebih jelas alurnya.</div>
