Setiap komponen Vue punya siklus hidup. Composition API menyediakan hook dalam bentuk fungsi.

## Peta Hook

| Options API | Composition API |
|-------------|-----------------|
| `beforeCreate` / `created` | `setup` langsung |
| `beforeMount` | `onBeforeMount` |
| `mounted` | `onMounted` |
| `beforeUpdate` | `onBeforeUpdate` |
| `updated` | `onUpdated` |
| `beforeUnmount` | `onBeforeUnmount` |
| `unmounted` | `onUnmounted` |

## Contoh

```vue
<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const detik = ref(0)
let timer

onMounted(() => {
  timer = setInterval(() => detik.value++, 1000)
})

onUnmounted(() => {
  clearInterval(timer)
})
</script>

<template>
  <p>Sudah {{ detik }} detik.</p>
</template>
```

## Mengakses Elemen

```vue
<script setup>
import { ref, onMounted } from 'vue'

const input = ref(null)

onMounted(() => input.value?.focus())
</script>

<template>
  <input ref="input">
</template>
```

Saat `onMounted` berjalan, `input.value` sudah berisi elemen DOM.

## KeepAlive

```vue
<KeepAlive>
  <component :is="komponenAktif" />
</KeepAlive>
```

Komponen yang disembunyikan tidak dihancurkan, sehingga mempertahankan state. Hook `onActivated` dan `onDeactivated` tersedia untuk kasus ini.

<div class="note">💡 Daftarkan cleanup di tempat yang sama dengan tempat kamu membuat efek. Kode jadi mudah diaudit: setiap `setInterval` bersebelahan dengan `clearInterval`.</div>
