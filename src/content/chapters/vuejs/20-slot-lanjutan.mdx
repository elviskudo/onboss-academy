Slot membuat komponen menjadi wadah fleksibel. Scoped slot membawanya lebih jauh: anak memberi data, induk yang menggambar.

## Slot Dasar

```vue
<!-- Kartu.vue -->
<template>
  <div class="kartu">
    <slot>Isi default bila kosong</slot>
  </div>
</template>
```

```vue
<Kartu>
  <p>Konten dari induk</p>
</Kartu>
```

## Named Slot

```vue
<!-- Layout.vue -->
<template>
  <header><slot name="header" /></header>
  <main><slot /></main>
  <footer><slot name="footer" /></footer>
</template>
```

```vue
<Layout>
  <template #header><h1>Judul Halaman</h1></template>
  <p>Konten utama</p>
  <template #footer><small>© 2026</small></template>
</Layout>
```

## Scoped Slot

```vue
<!-- Daftar.vue -->
<script setup>
const items = [{ id: 1, nama: 'Kopi' }, { id: 2, nama: 'Roti' }]
</script>

<template>
  <ul>
    <li v-for="item in items" :key="item.id">
      <slot name="baris" :item="item" :index="item.id" />
    </li>
  </ul>
</template>
```

```vue
<Daftar>
  <template #baris="{ item, index }">
    <strong>{{ index }}.</strong> {{ item.nama }}
  </template>
</Daftar>
```

Konsumen bisa mengubah tampilan baris tanpa mengubah komponen `Daftar`.

## Kasus Nyata

Komponen tabel, dropdown, dan layout sering memakai scoped slot. Library seperti Vuetify dan Element Plus dibangun di atas pola ini.

<div class="note">💡 Scoped slot adalah "render props" ala Vue. Komponen anak tetap menguasai data dan logika, induk bebas menentukan tampilan.</div>
