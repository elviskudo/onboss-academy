`computed` untuk nilai turunan. `watch` untuk efek samping saat nilai berubah.

## watch Dasar

```vue
<script setup>
import { ref, watch } from 'vue'

const kata = ref('')
const hasil = ref([])

watch(kata, async (baru, lama, onCleanup) => {
  const controller = new AbortController()
  onCleanup(() => controller.abort())

  const res = await fetch(`/api/cari?q=${baru}`, { signal: controller.signal })
  hasil.value = await res.json()
})
</script>
```

`onCleanup` membatalkan request lama saat user mengetik cepat.

## Beberapa Sumber

```js
watch([kata, halaman], ([k, h], [kLama, hLama]) => {
  console.log(k, h);
});
```

## Objek Bersarang

```js
watch(
  () => form.value.alamat.kota,
  (baru) => console.log(baru)
);
```

Atau `watch(form, handler, { deep: true })`, tapi lebih mahal.

## watchEffect

```js
const userId = ref(1);
const user = ref(null);

watchEffect(async () => {
  const res = await fetch(`/api/user/${userId.value}`);
  user.value = await res.json();
});
```

Vue otomatis melacak `userId` karena dibaca di dalam fungsi.

## Perbandingan

| | computed | watch | watchEffect |
|---|----------|-------|-------------|
| Return nilai | ya | tidak | tidak |
| Sumber eksplisit | ya | ya | tidak |
| Cocok untuk | turunan | efek terarah | efek otomatis |

<div class="note">💡 Kalau kamu bisa menulisnya sebagai `computed`, lakukan itu. watch sebaiknya hanya untuk hal yang benar-benar "terjadi" setelah perubahan, seperti request atau penyimpanan.</div>
