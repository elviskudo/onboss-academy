Vue sudah cepat secara default. Optimasi yang tepat dimulai dari pengukuran dan kebiasaan sederhana.

## Kebiasaan Sehari-hari

| Situasi | Pilihan |
|---------|---------|
| Nilai turunan | `computed` |
| Perhitungan sekali saat event | method |
| Sering tampil/sembunyi | `v-show` |
| Jarang tampil, berat | `v-if` |
| Daftar ribuan baris | virtual list |

## Contoh Computed

```vue
<script setup>
const items = ref([/* ... */])
const kata = ref('')

const tersaring = computed(() =>
  items.value.filter((i) => i.nama.includes(kata.value))
)
</script>
```

## Virtual List Sederhana

```js
const tinggiBaris = 40;
const mulai = computed(() => Math.floor(scrollTop.value / tinggiBaris));
const akhir = computed(() => mulai.value + 20);
const terlihat = computed(() => items.value.slice(mulai.value, akhir.value));
```

Untuk produksi, gunakan `vue-virtual-scroller` atau `@tanstack/vue-virtual`.

## Hindari Mutasi dalam Computed

```js
// ❌ computed sebaiknya murni
const total = computed(() => {
  log.push("dipanggil"); // efek samping
  return items.value.length;
});
```

Efek samping taruh di `watch`.

<div class="note">💡 Mulai dari struktur data yang benar: jangan menyimpan turunan sebagai state terpisah. Biarkan computed yang menghitung — otomatis dan bebas bug sinkronisasi.</div>
