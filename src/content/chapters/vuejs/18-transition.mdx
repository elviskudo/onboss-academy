Transisi membuat perubahan state terasa lebih halus. Vue menyediakan pembungkus yang mengelola kelas CSS otomatis.

## Transition Sederhana

```vue
<script setup>
import { ref } from 'vue'
const tampil = ref(true)
</script>

<template>
  <button @click="tampil = !tampil">Toggle</button>

  <Transition name="fade">
    <p v-if="tampil">Selamat datang!</p>
  </Transition>
</template>

<style scoped>
.fade-enter-active, .fade-leave-active { transition: opacity .3s ease; }
.fade-enter-from, .fade-leave-to { opacity: 0; }
</style>
```

## Enam Kelas

| Masuk | Keluar |
|-------|--------|
| `v-enter-from` | `v-leave-from` |
| `v-enter-active` | `v-leave-active` |
| `v-enter-to` | `v-leave-to` |

Ganti `v` dengan nama pada `name="fade"`.

## Daftar

```vue
<TransitionGroup name="daftar" tag="ul">
  <li v-for="item in items" :key="item.id">{{ item.nama }}</li>
</TransitionGroup>
```

```css
.daftar-move { transition: transform .3s; }
.daftar-enter-active, .daftar-leave-active { transition: all .3s; }
.daftar-enter-from, .daftar-leave-to { opacity: 0; transform: translateX(20px); }
```

## Ganti Komponen

```vue
<Transition name="geser" mode="out-in">
  <component :is="komponenSaatIni" :key="komponenSaatIni" />
</Transition>
```

## Hook JavaScript

```vue
<Transition
  @enter="(el, done) => { el.animate([...]).finished.then(done) }"
>
  ...
</Transition>
```

Call `done()` saat animasi selesai supaya Vue tahu kapan menghapus elemen.

<div class="note">💡 Selalu sertakan `prefers-reduced-motion` bila animasinya kuat. Sebagian pengguna lebih nyaman tanpa gerakan.</div>
