`v-model` terlihat sederhana, tapi punya banyak opsi untuk kasus nyata.

## Modifier

```vue
<input v-model.trim="nama" placeholder="Nama">
<input v-model.number="umur" type="number">
<input v-model.lazy="catatan">
```

| Modifier | Efek |
|----------|------|
| `.trim` | memangkas spasi |
| `.number` | konversi ke angka |
| `.lazy` | pakai event `change` |

## Checkbox Grup

```vue
<script setup>
import { ref } from 'vue'
const hobi = ref([])
</script>

<template>
  <label><input type="checkbox" v-model="hobi" value="membaca"> Membaca</label>
  <label><input type="checkbox" v-model="hobi" value="lari"> Lari</label>
  <p>{{ hobi }}</p>
</template>
```

## Radio dan Select

```vue
<label><input type="radio" v-model="kontak" value="email"> Email</label>
<label><input type="radio" v-model="kontak" value="wa"> WhatsApp</label>

<select v-model="kota">
  <option disabled value="">Pilih kota</option>
  <option>Jakarta</option>
  <option>Bandung</option>
</select>
```

## v-model pada Komponen

```vue
<!-- InputNama.vue -->
<script setup>
defineProps({ modelValue: String })
const emit = defineEmits(['update:modelValue'])
</script>

<template>
  <input
    :value="modelValue"
    @input="emit('update:modelValue', $event.target.value)"
  >
</template>
```

Pemakaian:

```vue
<InputNama v-model="nama" />
```

## Beberapa v-model

```vue
<FilterPanel v-model:halaman="halaman" v-model:cari="kata" />
```

Anak menerima props `halaman`, `cari` dan memancarkan `update:halaman`, `update:cari`.

<div class="note">💡 Ingat arahnya: induk mengirim `modelValue` lewat props, anak mengirim kembali perubahan lewat event. Itu sebabnya v-model bisa dipakai di komponen kustom.</div>
