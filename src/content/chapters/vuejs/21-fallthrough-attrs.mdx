Vue secara otomatis meneruskan atribut yang tidak didefinisikan sebagai props ke elemen root. Ini disebut *fallthrough*.

## Perilaku Default

```vue
<!-- Tombol.vue -->
<template>
  <button class="tombol">Klik</button>
</template>
```

```vue
<Tombol class="utama" id="simpan" @click="simpan" />
```

Hasilnya elemen `<button>` mendapat `class="tombol utama"`, `id="simpan"`, dan listener klik.

## Mengambil Kendali

```vue
<script setup>
import { useAttrs } from 'vue'

defineOptions({ inheritAttrs: false })
const attrs = useAttrs()
</script>

<template>
  <div class="wrapper">
    <button v-bind="attrs">Klik</button>
  </div>
</template>
```

Sekarang atribut jatuh ke `<button>`, bukan ke `<div>` wrapper.

## Multi-root

```vue
<template>
  <h2>Judul</h2>
  <p>Paragraf</p>
</template>
```

Kalau komponen punya dua root, Vue tidak tahu harus meneruskan atribut ke mana. Kamu harus memakai `v-bind="$attrs"` secara eksplisit di salah satu elemen.

<div class="note">💡 Fallthrough menghemat penulisan props untuk atribut umum seperti `class`, `id`, dan event. Ambil kendali hanya bila struktur DOM-mu menuntut begitu.</div>
