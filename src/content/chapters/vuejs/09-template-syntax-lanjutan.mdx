Template Vue menangani banyak kebutuhan binding tanpa harus menulis logika DOM manual.

## Binding Kelas

```vue
<script setup>
import { ref } from 'vue'

const sudah = ref(true)
const prioritas = ref('tinggi')
</script>

<template>
  <div :class="['kartu', { aktif: sudah, prioritas: prioritas === 'tinggi' }]">
    Isi kartu
  </div>
</template>
```

Objek `{ namaKelas: kondisi }` menambahkan kelas hanya bila kondisinya true.

## Binding Style

```vue
<div :style="{ color: warna, fontSize: ukuran + 'px' }">
  Teks dinamis
</div>
```

Array juga bisa dipakai bila ada beberapa object gaya.

## Modifier Event

| Modifier | Efek |
|----------|------|
| `.prevent` | `event.preventDefault()` |
| `.stop` | `event.stopPropagation()` |
| `.once` | handler hanya sekali |
| `.self` | hanya bila target tepat elemen itu |
| `.capture` | mode capture |

```vue
<form @submit.prevent="kirim">
  <button @click.stop.once="pilih">Pilih</button>
</form>
```

## Key Modifier

```vue
<input @keyup.enter="kirim" @keyup.esc="batal">
```

## Ekspresi di Template

```vue
<p>{{ jumlah > 0 ? `${jumlah} item` : 'Kosong' }}</p>
<p>{{ teks.split('').reverse().join('') }}</p>
```

Tetapi hindari perhitungan berat — pindahkan ke `computed`.

<div class="note">💡 Binding yang rapi membuat template tetap deklaratif: kamu mengatakan "kelas ini aktif bila..." bukan "tambahkan kelas lalu hapus lagi".</div>
