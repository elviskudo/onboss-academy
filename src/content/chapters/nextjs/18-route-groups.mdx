Seiring pertumbuhan proyek, folder `app/` bisa berantakan. Route group dan private folder menjaga kerapian tanpa mengubah URL.

## Route Group

```
app/
  (marketing)/
    layout.tsx
    page.tsx       -> /
    about/page.tsx -> /about
  (dashboard)/
    layout.tsx
    laporan/page.tsx -> /laporan
```

Kedua grup memiliki layout berbeda, tapi URL-nya tetap bersih.

## Root Layout Ganda

```tsx
// (marketing)/layout.tsx
<html lang="id"><body>{children}</body></html>
```

```tsx
// (dashboard)/layout.tsx
<html lang="id"><body className="dashboard">{children}</body></html>
```

Kalau kamu punya beberapa root layout, pastikan setiap grup memilikinya.

## Private Folder

```
app/produk/
  _components/
    KartuProduk.tsx
    FilterHarga.tsx
  page.tsx
```

File di `_components` tidak dianggap rute. Import langsung dari komponen sejalan:

```tsx
import KartuProduk from "./_components/KartuProduk";
```

## Konvensi yang Disarankan

| Awalan | Arti |
|--------|------|
| `(nama)` | grup, tidak masuk URL |
| `_nama` | private folder |
| `[nama]` | parameter dinamis |
| `@nama` | slot parallel |

<div class="note">💡 Route group sangat membantu saat satu aplikasi punya dua "wajah": situs pemasaran dan area aplikasi yang login. Masing-masing bisa punya layout sendiri.</div>
