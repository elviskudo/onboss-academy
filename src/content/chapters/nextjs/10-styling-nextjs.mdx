Next.js tidak memaksa satu metode styling. Yang penting tahu di mana meletakkan tiap jenis CSS.

## CSS Global

```css
/* app/globals.css */
:root { --warna: #61dafb; }
* { box-sizing: border-box; }
body { margin: 0; font-family: system-ui, sans-serif; }
```

```tsx
// app/layout.tsx
import "./globals.css";
```

## CSS Module

```css
/* Kartu.module.css */
.kartu {
  padding: 16px;
  border-radius: 12px;
  border: 1px solid #ddd;
}
```

```tsx
import s from "./Kartu.module.css";

export function Kartu({ children }: { children: React.ReactNode }) {
  return <div className={s.kartu}>{children}</div>;
}
```

## Tailwind

```bash
npx create-next-app --tailwind
```

```tsx
<div className="rounded-xl border p-4 shadow-sm">
  <h2 className="text-lg font-semibold">Judul</h2>
</div>
```

## CSS Variable untuk Tema

```css
:root { --latarbelakang: white; --teks: #111; }
[data-tema="gelap"] { --latarbelakang: #111; --teks: #eee; }
```

```tsx
<body data-tema="gelap">...</body>
```

<div class="note">💡 Simpan reset dan token desain di CSS global, gaya komponen di CSS Module/Tailwind. Pemisahan ini membuat perubahan tema tidak menyentuh tiap komponen.</div>
