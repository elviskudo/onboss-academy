Autentikasi yang aman di Next.js memanfaatkan Server Action dan cookie httpOnly.

## Server Action Login

```tsx
// app/login/action.ts
"use server";

import { cookies } from "next/headers";
import { redirect } from "next/navigation";

export async function login(formData: FormData) {
  const email = formData.get("email") as string;
  const password = formData.get("password") as string;

  const session = await verifikasiKeApi(email, password);
  if (!session) throw new Error("Kredensial salah");

  const jar = await cookies();
  jar.set("session", session.token, {
    httpOnly: true,
    secure: process.env.NODE_ENV === "production",
    sameSite: "lax",
    path: "/",
    maxAge: 60 * 60 * 24 * 7,
  });

  redirect("/dashboard");
}
```

## Form

```tsx
<form action={login}>
  <input name="email" type="email" required />
  <input name="password" type="password" required />
  <button type="submit">Masuk</button>
</form>
```

## Membaca Session

```tsx
import { cookies } from "next/headers";

export default async function Dashboard() {
  const token = (await cookies()).get("session")?.value;
  const user = token ? await ambilUser(token) : null;

  if (!user) redirect("/login");
  return <p>Halo, {user.nama}</p>;
}
```

## Logout

```ts
"use server";

export async function logout() {
  (await cookies()).delete("session");
  redirect("/login");
}
```

<div class="note">💡 Jangan menyimpan token sesi di localStorage bila bisa memakai cookie httpOnly. Cookie tidak bisa dibaca skrip, sehingga risiko XSS jauh lebih kecil.</div>
