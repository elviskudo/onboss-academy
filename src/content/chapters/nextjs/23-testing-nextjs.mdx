Next.js tidak punya test runner bawaan, tapi mudah dipasangi alat standar.

## Unit Test Fungsi

```ts
import { describe, test, expect } from "vitest";
import { formatHarga } from "@/lib/format";

test("format rupiah", () => {
  expect(formatHarga(25000)).toBe("Rp25.000");
});
```

## Test Komponen

```tsx
import { render, screen } from "@testing-library/react";
import Kartu from "./Kartu";

test("menampilkan judul", () => {
  render(<Kartu judul="Kopi" />);
  expect(screen.getByText("Kopi")).toBeTruthy();
});
```

## Test Route Handler

```ts
import { GET } from "@/app/api/produk/route";

test("GET mengembalikan 200", async () => {
  const response = await GET();
  expect(response.status).toBe(200);
  const data = await response.json();
  expect(Array.isArray(data)).toBe(true);
});
```

## Mock fetch

```ts
import { vi } from "vitest";

vi.stubGlobal("fetch", vi.fn(async () => ({
  ok: true,
  json: async () => [{ id: 1 }],
})));
```

## End-to-End

```bash
npx playwright test
```

```ts
test("user bisa menambah produk", async ({ page }) => {
  await page.goto("/produk");
  await page.getByRole("button", { name: "Tambah" }).click();
  await expect(page.getByText("Berhasil")).toBeVisible();
});
```

<div class="note">💡 Kombinasikan: unit test untuk logika, komponen test untuk tampilan, dan Playwright untuk alur penting. Tidak perlu semua lapisan untuk setiap fitur.</div>
