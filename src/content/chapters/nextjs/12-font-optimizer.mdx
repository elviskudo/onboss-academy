Font bisa diam-diam memperlambat situs. `next/font` memindahkan unduhan font ke waktu build.

## Google Font

```tsx
// app/layout.tsx
import { Inter, Playfair_Display } from "next/font/google";

const inter = Inter({ subsets: ["latin"], variable: "--font-inter" });
const playfair = Playfair_Display({
  subsets: ["latin"],
  variable: "--font-playfair",
});

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="id" className={`${inter.variable} ${playfair.variable}`}>
      <body>{children}</body>
    </html>
  );
}
```

```css
body { font-family: var(--font-inter), sans-serif; }
h1 { font-family: var(--font-playfair), serif; }
```

## Font Lokal

```tsx
import localFont from "next/font/local";

const onboss = localFont({
  src: [
    { path: "./fonts/OnBoss-Regular.woff2", weight: "400" },
    { path: "./fonts/OnBoss-Bold.woff2", weight: "700" },
  ],
  variable: "--font-onboss",
  display: "swap",
});
```

## Variable Font

Satu file variable font bisa mencakup banyak weight:

```tsx
const inter = Inter({ subsets: ["latin"], axes: ["slnt"] });
```

## Praktik Baik

- Batasi jumlah keluarga font (dua sudah cukup).
- Gunakan `subsets` seminimal mungkin.
- Simpan font di `next/font`, bukan `@import` CSS eksternal.

<div class="note">💡 Font yang di-self-host lewat next/font mengurangi ketergantungan pada jaringan pihak ketiga — lebih cepat dan lebih ramah privasi.</div>
