Next.js mengandalkan konvensi folder. Begitu kamu mengenali polanya, struktur proyek menjadi peta rute itu sendiri.

## Peta Folder

| Path | Fungsi |
|------|--------|
| `app/` | halaman, layout, rute API (App Router) |
| `pages/` | gaya lama Pages Router |
| `public/` | aset statis |
| `src/` | opsional, wadah kode aplikasi |
| `components/` | komponen reusable |

## File Khusus di app/

| Nama | Peran |
|------|-------|
| `page.tsx` | membuat rute dan konten |
| `layout.tsx` | pembungkus bersama |
| `loading.tsx` | UI saat Suspense menunggu |
| `error.tsx` | fallback error client |
| `not-found.tsx` | halaman 404 |
| `route.ts` | endpoint API |

## Contoh Layout

```tsx
// app/layout.tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="id">
      <body>
        <header><a href="/">OnBoss Academy</a></header>
        {children}
      </body>
    </html>
  );
}
```

Layout root wajib berisi tag `<html>` dan `<body>`.

## Konfigurasi

```js
// next.config.mjs
const nextConfig = {
  images: { remotePatterns: [{ hostname: "images.example.com" }] },
  reactStrictMode: true,
};
export default nextConfig;
```

## alias TS

```json
{
  "compilerOptions": {
    "paths": { "@/*": ["./src/*"] }
  }
}
```

<div class="note">💡 Nama folder di dalam `app/` langsung menjadi URL. Menuliskan `app/produk/[id]/page.tsx` berarti kamu sudah mendefinisikan rute `/produk/:id` tanpa daftar rute manual.</div>
