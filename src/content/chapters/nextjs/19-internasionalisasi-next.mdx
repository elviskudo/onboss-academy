Aplikasi multi-bahasa bukan hanya mengganti label. Rute, metadata, dan format juga ikut menyesuaikan.

## Struktur

```
app/
  [lang]/
    layout.tsx
    page.tsx
dictionaries/
  id.json
  en.json
middleware.ts
```

## Memuat Dictionary

```ts
// lib/dictionary.ts
const dictionaries = {
  id: () => import("@/dictionaries/id.json").then((m) => m.default),
  en: () => import("@/dictionaries/en.json").then((m) => m.default),
};

export const getDictionary = (lang: string) =>
  dictionaries[lang]?.() ?? dictionaries.id();
```

```tsx
export default async function Page({ params }) {
  const dict = await getDictionary(params.lang);
  return <h1>{dict.selamatDatang}</h1>;
}
```

## Atribut html lang

```tsx
export default async function Layout({ children, params }) {
  return (
    <html lang={params.lang}>
      <body>{children}</body>
    </html>
  );
}
```

## Redirect Awal

```ts
// middleware.ts
if (request.nextUrl.pathname === "/") {
  return NextResponse.redirect(new URL("/id", request.url));
}
```

## Format Lokal

```ts
new Intl.NumberFormat("id-ID", { style: "currency", currency: "IDR" })
  .format(25000);

new Intl.DateTimeFormat("id-ID", { dateStyle: "long" })
  .format(new Date());
```

<div class="note">💡 Simpan terjemahan sebagai data, bukan cabang `if` di komponen. Menambah bahasa baru cukup membuat satu file JSON.</div>
