Metadata menentukan bagaimana halamanmu dikenali oleh browser, mesin pencari, dan platform sosial.

## Metadata Statis

```tsx
// app/tentang/page.tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "Tentang Kami | OnBoss",
  description: "Kenalan dengan tim di balik materials kami.",
  openGraph: {
    title: "Tentang OnBoss Academy",
    description: "Belajar teknologi dengan contoh praktis.",
    type: "website",
  },
};
```

## Metadata Dinamis

```tsx
export async function generateMetadata({ params }): Promise<Metadata> {
  const produk = await ambilProduk(params.id);
  return {
    title: produk.nama,
    description: produk.deskripsi,
    openGraph: { images: [`/og/${produk.id}`] },
  };
}
```

## Gambar OG Otomatis

```tsx
// app/og/[id]/route.tsx
import { ImageResponse } from "next/og";

export async function GET(_req, { params }) {
  const produk = await ambilProduk(params.id);
  return new ImageResponse(
    <div style={{ background: "#111", color: "white", padding: 40 }}>
      {produk.nama}
    </div>,
    { width: 1200, height: 630 }
  );
}
```

## Robots dan Canonical

```ts
export const metadata = {
  alternates: { canonical: "/produk/kopi" },
  robots: { index: true, follow: true },
};
```

<div class="note">💡 Sebagian besar URL sosial tidak mendukung gambar relatif. Selalu tentukan `metadataBase` agar Next.js bisa membangun URL absolut dengan benar.</div>
