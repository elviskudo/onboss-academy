## Metadata Statis dan Dinamis

```typescript
// app/layout.tsx — berlaku global
import type { Metadata } from "next";

export const metadata: Metadata = {
  metadataBase: new URL("https://toko.example.id"),
  title: {
    default: "OnBoss Toko",
    template: "%s — OnBoss Toko",
  },
  description: "Belanja kebutuhan harian dengan cepat",
  openGraph: {
    images: ["/og.jpg"],
  },
};
```

```typescript
// app/produk/[id]/page.tsx — menimpa judul per halaman
export async function generateMetadata({ params }) {
  const { id } = await params;
  const produk = await getProduk(id);
  return { title: produk?.nama ?? "Produk" };
}
```

Judul halaman detail otomatis menjadi "Kopi Susu — OnBoss Toko" berkat `title.template`.

## Gambar dan Font Optimasi

```typescript
import Image from "next/image";
import { Inter } from "next/font/google";

const inter = Inter({ subsets: ["latin"] });

export default function Hero() {
  return (
    <section className={inter.className}>
      <Image src="/hero.jpg" alt="Promo mingguan" width={1200} height={600} priority />
    </section>
  );
}
```

`next/image` menghasilkan srcset otomatis; `next/font` menghindari layout shift dari font eksternal.

## Sitemap dan Robots

```typescript
// app/sitemap.ts
import type { MetadataRoute } from "next";

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const produk = await getSemuaProduk();

  return [
    { url: "https://toko.example.id", priority: 1 },
    ...produk.map((p) => ({
      url: `https://toko.example.id/produk/${p.id}`,
      lastModified: new Date(),
    })),
  ];
}
```

```typescript
// app/robots.ts
export default function robots() {
  return {
    rules: { userAgent: "*", allow: "/", disallow: "/admin" },
    sitemap: "https://toko.example.id/sitemap.xml",
  };
}
```

## Build dan Deploy

```bash
npm run build
npm start        # jalankan hasil build di :3000
```

Atau dorong ke git dan hubungkan ke Vercel — build dan deploy berjalan otomatis. Variabel rahasia (`DATABASE_URL`, API key) cukup diisi di pengaturan environment.

## Empat Pilar SEO Teknis

SEO produksi setidaknya memiliki **4 pilar teknis**.

| Pilar | Fungsi | Contoh | Kapan diperiksa |
|---|---|---|---|
| Metadata | Menjelaskan halaman | title, description, OG | Setiap template halaman |
| Crawlability | Mengarahkan crawler | robots, sitemap | Saat URL berubah |
| Canonical | Mencegah duplikasi URL | `alternates.canonical` | Filter atau domain ganda |
| Performance | Mempercepat pengalaman | Image, font, caching | Sebelum dan sesudah rilis |

Metadata tidak menggantikan konten yang berguna. Setiap halaman harus punya satu judul deskriptif, heading yang logis, alt gambar bermakna, dan tautan internal yang dapat diikuti crawler.

```typescript
export const metadata: Metadata = {
  alternates: { canonical: "/produk" },
  robots: { index: true, follow: true },
  openGraph: {
    title: "Katalog Produk",
    description: "Temukan kebutuhan harian",
    images: [{ url: "/og-produk.jpg", width: 1200, height: 630 }],
  },
};
```

## Tiga Target Deploy

Next.js umum dijalankan pada **3 target**: platform terkelola, Node.js server mandiri, atau container. Static export hanya cocok bila aplikasi tidak membutuhkan fitur server saat request.

```bash
npm run build
npm start
```

Saat deploy, environment variable tanpa prefix `NEXT_PUBLIC_` hanya tersedia di server; variabel berprefix tersebut masuk bundle browser dan tidak boleh berisi secret. Jalankan migrasi database sebagai langkah terkontrol, lalu lakukan smoke test pada halaman dan endpoint penting.

## Di Dunia Nyata

- Toko membuat sitemap dari seluruh slug produk aktif.
- Situs multi-domain memakai canonical agar ranking tidak terbagi.
- Portal privat memberi `noindex` pada halaman akun dan memeriksa otorisasi di server.
- Tim memantau Core Web Vitals setelah deploy, bukan hanya skor lokal.

## Checklist Sebelum Rilis

- Metadata dan OG image terisi di semua halaman penting
- Gambar besar dikirim lewat `next/image`
- Error boundary tersedia per segmen
- Route admin dilindungi autentikasi dan otorisasi server
- Core Web Vitals diperiksa pada halaman utama
