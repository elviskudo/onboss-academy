Next.js memberi banyak kemudahan, tapi tanggung jawab keamanan tetap ada di tangan kita.

## Validasi Input

```ts
import { z } from "zod";

const Skema = z.object({
  email: z.string().email(),
  pesan: z.string().min(5).max(500),
});

export async function kirim(formData: FormData) {
  const hasil = Skema.safeParse(Object.fromEntries(formData));
  if (!hasil.success) return { error: "Data tidak valid" };

  await simpan(hasil.data);
  return { error: "" };
}
```

## Rate Limit Sederhana

```ts
const percobaan = new Map<string, number>();

export function bolehCoba(ip: string) {
  const n = percobaan.get(ip) ?? 0;
  if (n >= 5) return false;
  percobaan.set(ip, n + 1);
  return true;
}
```

Untuk produksi, gunakan store bersama seperti Redis.

## Header keamanan

```js
// next.config.mjs
async headers() {
  return [{
    source: "/(.*)",
    headers: [
      { key: "X-Content-Type-Options", value: "nosniff" },
      { key: "Referrer-Policy", value: "strict-origin-when-cross-origin" },
      { key: "X-Frame-Options", value: "SAMEORIGIN" },
    ],
  }];
}
```

## Prinsip

- Validasi di server, bukan hanya di form.
- Jangan pernah mempercayai data dari client.
- Simpan rahasia hanya di server.
- Batasi apa yang bisa dikirim ke browser.

<div class="note">💡 Keamanan adalah lapisan, bukan fitur tunggal. Validasi, cookie yang benar, header, dan pembatasan akses bekerja bersama.</div>
