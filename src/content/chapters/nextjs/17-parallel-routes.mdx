Parallel dan intercepting route terlihat menakutkan, tapi sangat berguna untuk UI kompleks seperti dashboard dan modal.

## Parallel Routes

Struktur:

```
app/dashboard/
  @grafik/page.tsx
  @statistik/page.tsx
  layout.tsx
  page.tsx
```

```tsx
export default function Layout({
  children,
  grafik,
  statistik,
}: {
  children: React.ReactNode;
  grafik: React.ReactNode;
  statistik: React.ReactNode;
}) {
  return (
    <div className="grid">
      <main>{children}</main>
      <aside>{statistik}</aside>
      <section>{grafik}</section>
    </div>
  );
}
```

Tiap slot bisa punya state loading/error sendiri.

## default.tsx

```tsx
// app/dashboard/@grafik/default.tsx
export default function Default() {
  return <p>Pilih periode untuk melihat grafik.</p>;
}
```

Tanpa ini, refresh pada rute tertentu bisa membuat slot kosong atau 404.

## Intercepting Route

```
app/foto/
  page.tsx              -> daftar foto
  [id]/page.tsx         -> halaman detail penuh
  @modal/
    (.)[id]/page.tsx    -> modal saat diklik dari daftar
    default.tsx         -> null
```

Layout:

```tsx
export default function Layout({ children, modal }) {
  return <>{children}{modal}</>;
}
```

Saat user mengklik foto dari daftar, modal muncul di atas daftar. Saat URL dibuka langsung, halaman detail penuh yang tampil.

<div class="note">💡 Mulai dari parallel route biasa. Intercepting route sebaiknya ditambahkan setelah rute dasar stabil — kombinasi keduanya bisa membingungkan kalau belum terbiasa.</div>
