Build yang sukses di lokal belum tentu langsung siap produksi. Ada beberapa pemeriksaan tambahan.

## Build

```bash
npm run build
npm start
```

Perhatikan ringkasan rute: yang ditandai statically rendered lebih cepat daripada yang dinamis.

## Standalone

```js
// next.config.mjs
const nextConfig = {
  output: "standalone",
};
export default nextConfig;
```

Docker:

```dockerfile
FROM node:20-alpine AS runner
WORKDIR /app
COPY --from=builder /app/.next/standalone ./
COPY --from=builder /app/.next/static ./.next/static
COPY --from=builder /app/public ./public
EXPOSE 3000
CMD ["node", "server.js"]
```

## Checklist

- [ ] Semua environment variable tersedia di platform deploy.
- [ ] `next build` tanpa error.
- [ ] Gambar dan font dari domain yang diizinkan.
- [ ] Metadata dan OG image bisa diakses publik.
- [ ] Error boundary tersedia.

## Platform

Vercel memberi integrasi paling mulus. Untuk server sendiri, gunakan `npm start` di balik reverse proxy seperti Nginx.

<div class="note">💡 Deploy bertahap: rilis ke preview environment, uji alur utama, lalu promosikan ke produksi. Langkah kecil mengurangi risiko.</div>
