Environment variable memisahkan konfigurasi dari kode. Next.js punya aturan tegas soal mana yang boleh sampai ke browser.

## Menulis

```bash
# .env.local
DATABASE_URL=postgres://user:pass@localhost:5432/app
API_SECRET=rahasia123
NEXT_PUBLIC_API_URL=https://api.contoh.com
```

```gitignore
.env*.local
```

## Membaca di Server

```ts
const url = process.env.DATABASE_URL;
const rahasia = process.env.API_SECRET;
```

Keduanya tidak dikirim ke browser.

## Membaca di Client

```ts
const api = process.env.NEXT_PUBLIC_API_URL;
```

Hanya variabel berawalan `NEXT_PUBLIC_` yang disematkan ke bundle. Semua orang bisa melihat nilainya — jangan taruh rahasia di sini.

## Validasi

```ts
// lib/env.ts
const DATABASE_URL = process.env.DATABASE_URL;
if (!DATABASE_URL) throw new Error("DATABASE_URL belum disetel");

export { DATABASE_URL };
```

Validasi lebih awal membuat error lebih mudah dilacak daripada saat request pertama kali.

<div class="note">💡 Anggap setiap `NEXT_PUBLIC_` sebagai informasi publik. Kalau nilainya tidak boleh diketahui orang lain, jangan gunakan awalan itu.</div>
