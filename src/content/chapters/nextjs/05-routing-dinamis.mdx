Routing dinamis membuat satu file mewakili ribuan URL. Bab ini mempelajari params, pembangunan statis, dan navigasi antar halaman.

## Membaca Params

```typescript
// app/produk/[id]/page.tsx → /produk/42
export default async function DetailProduk({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const produk = await getProduk(id);

  if (!produk) return notFound();

  return (
    <article>
      <h1>{produk.nama}</h1>
      <p>Rp{produk.harga}</p>
    </article>
  );
}
```

Sejak Next.js 15, `params` dan `searchParams` adalah Promise — await dulu sebelum dipakai.

## Search Params

```typescript
export default async function Katalog({
  searchParams,
}: {
  searchParams: Promise<{ q?: string; halaman?: string }>;
}) {
  const { q = "", halaman = "1" } = await searchParams;
  const produk = await cariProduk(q, Number(halaman));

  return <HasilPencarian produk={produk} kata={q} />;
}
```

URL `/katalog?q=kopi&halaman=2` langsung terbaca tanpa library query string.

## Pre-render Rute Dinamis

```typescript
// app/produk/[id]/page.tsx
export async function generateStaticParams() {
  const produk = await fetch(`${API_URL}/produk`, { next: { revalidate: 3600 } }).then((r) => r.json());

  return produk.map((p: { id: string }) => ({ id: p.id }));
}
```

Produk unggulan dibangun statis saat build; produk baru menyusul saat diminta (fallback biasa).

## Metadata Dinamis

```typescript
export async function generateMetadata({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const produk = await getProduk(id);

  return {
    title: produk?.nama ?? "Produk tidak ditemukan",
    description: produk ? `Beli ${produk.nama} seharga Rp${produk.harga}` : undefined,
  };
}
```

## Route Group

```
app/
  (kedai)/
    page.tsx        tetap "/" 
    produk/page.tsx tetap "/produk"
```

Folder dalam kurung biasa menyusun kode tanpa menambah segmen URL — berguna memisahkan area aplikasi.

## Tiga Bentuk Segmen Dinamis

App Router memiliki **3 bentuk segmen dinamis**.

| Bentuk | Nilai params | Contoh URL | Kapan dipakai |
|---|---|---|---|
| `[id]` | satu string | `/produk/42` | Detail satu entitas |
| `[...slug]` | array wajib | `/docs/a/b` | Hierarki kedalaman bebas |
| `[[...slug]]` | array opsional | `/docs` atau `/docs/a` | Root dan turunan satu handler |

```typescript
export default async function Docs({
  params,
}: {
  params: Promise<{ slug?: string[] }>;
}) {
  const { slug = [] } = await params;
  return <p>Lokasi: /{slug.join("/")}</p>;
}
```

Validasi parameter tetap diperlukan. `id` dari URL adalah string yang tidak tepercaya; cek format sebelum query dan panggil `notFound()` saat resource tidak ada. Untuk navigasi programatik dari client component, gunakan `useRouter`; untuk tautan biasa tetap pilih `Link` agar prefetch dan aksesibilitas bekerja.

## Di Dunia Nyata

- Toko memakai `[id]` untuk ribuan detail produk dari satu file.
- Dokumentasi memakai `[...slug]` untuk struktur bab bertingkat.
- Katalog menyimpan filter dan halaman di `searchParams` agar URL dapat dibagikan.
- Artikel populer memakai `generateStaticParams`, sedangkan artikel baru dirender saat diminta.

<div class="note">💡 Dua API yang sering dibutuhkan bersamaan: generateStaticParams untuk kecepatan build, generateMetadata untuk SEO. Keduanya menerima params yang sama dengan halamannya — tidak perlu logika pengambilan data dobel.</div>
