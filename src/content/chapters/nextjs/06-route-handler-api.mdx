Selain halaman, App Router juga bisa menjadi API. Route handler memungkinkan satu proyek Next.js melayani frontend dan backend endpoint sekaligus.

## GET Pertama

```typescript
// app/api/produk/route.ts → GET /api/produk
import { NextResponse } from "next/server";

export async function GET() {
  const produk = await db.produk.findMany();
  return NextResponse.json(produk);
}
```

Nama export menentukan method. Tidak perlu router eksternal — lokasi file = URL endpoint.

## POST dengan Body

```typescript
import { NextResponse } from "next/server";

export async function POST(request: Request) {
  const body = await request.json();

  if (!body.nama || typeof body.harga !== "number") {
    return NextResponse.json({ error: "Data tidak valid" }, { status: 400 });
  }

  const baru = await db.produk.create({ data: body });
  return NextResponse.json(baru, { status: 201 });
}
```

`request` adalah objek Request standar — `request.json()`, `request.headers.get("authorization")`, semuanya familiar.

## Route Dinamis

```typescript
// app/api/produk/[id]/route.ts → /api/produk/42
import { NextResponse } from "next/server";

export async function GET(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  const produk = await db.produk.findUnique({ where: { id } });

  if (!produk) {
    return NextResponse.json({ error: "Tidak ditemukan" }, { status: 404 });
  }
  return NextResponse.json(produk);
}

export async function DELETE(
  request: Request,
  { params }: { params: Promise<{ id: string }> }
) {
  const { id } = await params;
  await db.produk.delete({ where: { id } });
  return new NextResponse(null, { status: 204 });
}
```

Satu file bisa mengekspor beberapa method untuk rute yang sama.

export async function GET(request: Request) {
  const { searchParams } = new URL(request.url);
  const q = searchParams.get("q") ?? "";

## Kapan Pakai Route Handler?

- Webhook pembayaran dan notifikasi eksternal
- Endpoint yang dipakai aplikasi lain (mobile, integrasi)
- Proxy aman ke API pihak ketiga

Untuk interaksi dalam halaman React murni, server action (bab berikutnya) biasanya lebih ringkas.

## Tujuh Method HTTP

Route handler mendukung **7 method standar**: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, dan `OPTIONS`.

| Method | Fungsi | Respons umum | Kapan dipakai |
|---|---|---|---|
| GET | Membaca resource | 200 | Daftar atau detail |
| POST | Membuat resource | 201 | Pesanan baru |
| PUT | Mengganti penuh | 200/204 | Sinkronisasi object |
| PATCH | Mengubah sebagian | 200/204 | Status pesanan |
| DELETE | Menghapus | 204 | Hapus item |
| HEAD | Membaca header saja | 200 | Cek metadata |
| OPTIONS | Menjelaskan method/CORS | 204 | Preflight browser |

Endpoint adalah trust boundary: parse JSON dapat gagal, tipe harus divalidasi, autentikasi diperiksa sebelum query, dan pesan internal jangan dibocorkan.

```typescript
export async function POST(request: Request) {
  try {
    const body: unknown = await request.json();
    if (!body || typeof body !== "object" || !("nama" in body) || typeof body.nama !== "string") {
      return Response.json({ error: "Nama wajib berupa teks" }, { status: 400 });
    }
    return Response.json({ id: crypto.randomUUID(), nama: body.nama }, { status: 201 });
  } catch {
    return Response.json({ error: "JSON tidak valid" }, { status: 400 });
  }
}
```

## Di Dunia Nyata

- Payment gateway mengirim webhook POST yang diverifikasi tanda tangannya.
- Aplikasi mobile membaca katalog melalui GET berformat JSON.
- Backend mem-proxy API vendor agar secret tidak pernah tiba di browser.
- Integrasi status pesanan memakai PATCH idempotent dan autentikasi server.

<div class="note">💡 Route handler berjalan di server — semua rahasia aman di sini. Manfaatkan juga Web API standar (Request, Response, Headers) sehingga keterampilanmu di route handler langsung bisa dipakai di edge runtime atau lingkungan server modern lain.</div>
