Tanpa streaming, halaman menunggu semua data selesai sebelum apa pun tampil. Dengan streaming, bagian ringan langsung muncul.

## loading.tsx

```tsx
// app/produk/loading.tsx
export default function Loading() {
  return (
    <div className="skeleton">
      <div className="skeleton-judul" />
      <div className="skeleton-garis" />
    </div>
  );
}
```

Next.js otomatis membungkus `page.tsx` dengan Suspense menggunakan fallback ini.

## Suspense Eksplisit

```tsx
import { Suspense } from "react";

export default async function Halaman() {
  return (
    <main>
      <h1>Judul Artikel</h1>
      <Suspense fallback={<p>Memuat komentar…</p>}>
        <Komentar />
      </Suspense>
      <Suspense fallback={<p>Memuat rekomendasi…</p>}>
        <Rekomendasi />
      </Suspense>
    </main>
  );
}

async function Komentar() {
  const data = await ambilKomentar();
  return <ul>{data.map((k) => <li key={k.id}>{k.isi}</li>)}</ul>;
}
```

Bagian `<h1>` langsung tampil meski komentar belum selesai.

## Pola yang Baik

- Pisahkan data cepat dan lambat ke komponen berbeda.
- Skeleton menyerupai bentuk konten asli agar tidak meloncat.
- Jangan menaruh seluruh halaman dalam satu Suspense bila bisa dipecah.

<div class="note">💡 Streaming bukan pengganti optimasi query. Kalau satu API sangat lambat, perbaiki juga API-nya — Suspense hanya membuat pengguna tidak menunggu secara total.</div>
