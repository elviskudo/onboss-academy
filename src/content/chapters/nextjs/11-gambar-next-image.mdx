Gambar sering menjadi penyebab halaman berat. `next/image` mengoptimalkannya tanpa kamu menulis skrip resize sendiri.

## Gambar Lokal

```tsx
import Image from "next/image";
import logo from "@/public/logo.png";

<Image src={logo} alt="Logo OnBoss" priority />;
```

## Gambar dari URL

```js
// next.config.mjs
images: {
  remotePatterns: [{ hostname: "images.example.com" }];
}
```

```tsx
<Image
  src="https://images.example.com/produk/kopi.jpg"
  alt="Kopi susu"
  width={600}
  height={400}
  sizes="(max-width: 600px) 100vw, 50vw"
/>
```

## Fill

```tsx
<div style={{ position: "relative", width: 300, height: 200 }}>
  <Image src="/banner.jpg" alt="Banner" fill style={{ objectFit: "cover" }} />
</div>
```

## Placeholder

```tsx
<Image
  src="/foto.jpg"
  alt="Foto"
  width={400}
  height={300}
  placeholder="blur"
  blurDataURL="data:image/..."
/>
```

## Kapan Memakai priority

- Logo navigasi.
- Gambar hero di atas lipatan.
- Gambar yang langsung terlihat saat halaman dibuka.

Selain itu biarkan lazy loading default.

<div class="note">💡 Jangan menaruh `priority` pada semua gambar — malah menghilangkan manfaat lazy load. Berikan hanya untuk beberapa gambar pertama yang benar-benar penting.</div>
