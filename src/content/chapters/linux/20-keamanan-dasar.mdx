Server yang baru terpasang belum aman secara default. **Hardening** berarti mengurangi permukaan serangan langkah demi langkah.

## Update

```bash
sudo apt update
sudo apt upgrade -y
sudo apt autoremove
```

```bash
sudo dnf update -y      # RHEL/Fedora
sudo pacman -Syu        # Arch
```

## SSH

Edit `/etc/ssh/sshd_config`:

```text
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
Port 22
AllowUsers admin
```

```bash
sudo sshd -t
sudo systemctl restart ssh
```

<div class="note">💡 Pastikan kunci SSH Anda sudah berhasil login sebelum menonaktifkan password. Kalau tidak, Anda bisa terkunci di luar server.</div>

## Firewall

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw enable
sudo ufw status verbose
```

```bash
sudo firewall-cmd --state
sudo firewall-cmd --list-ports
```

## Audit Sederhana

```bash
who
last
sudo grep "Failed password" /var/log/auth.log
sudo find / -perm -4000 -type f 2>/dev/null
ls -l /etc/passwd /etc/shadow
```

| Item | Yang diperiksa |
|---|---|
| `/etc/shadow` | bukan world-readable |
| setuid file | hanya yang diperlukan |
| akun dengan shell | tidak ada akun aneh |
| port terbuka | sesuai kebutuhan layanan |

## Prinsip

- Pasang hanya paket yang dibutuhkan.
- Jalankan layanan sebagai user khusus, bukan root.
- Simpan log dan kirim ke sistem terpusat.
- Buat backup sebelum perubahan besar.

Keamanan bukan produk sekali pasang, melainkan **proses berulang**.
