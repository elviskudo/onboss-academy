Shell Unix dibangun di atas ide sederhana: **setiap perintah adalah filter**. Dengan pipe dan redirection, filter-filter itu dirangkai.

## Pipa

```bash
ps aux | grep nginx | head -5
cat data.txt | sort | uniq -c | sort -rn
```

Setiap perintah hanya melakukan satu hal, tetapi rangkaiannya kuat.

## Redirection

```bash
perintah > hasil.txt        # stdout, timpa
perintah >> hasil.txt       # stdout, tambah
perintah 2> error.txt       # stderr
perintah > semua.txt 2>&1   # keduanya
perintah < input.txt        # stdin dari file
perintah > /dev/null        # buang output
```

## tee

```bash
make build 2>&1 | tee build.log
```

Anda tetap melihat progres build di layar dan log tersimpan untuk investigasi.

## Here-doc

```bash
cat > config.yaml <<EOF
app: belajar
mode: development
EOF
```

Kata `EOF` bebas asal sama di awal dan akhir. Tanda `<<-` mengizinkan indentasi tab.

## File Descriptor

| Nomor | Nama | Default |
|---|---|---|
| 0 | stdin | keyboard |
| 1 | stdout | layar |
| 2 | stderr | layar |

```bash
exec 3> laporan.txt
echo "awal" >&3
exec 3>&-
```

<div class="note">💡 Urutan matters: `2>&1` harus ditulis **setelah** `> file`, kalau tidak error tetap masuk ke layar lama.</div>

## Contoh Praktis

```bash
{
  echo "=== Disk ==="
  df -h
  echo "=== Memori ==="
  free -h
} > laporan-sistem.txt
```

Kurung kurawal menggabungkan beberapa perintah dalam satu blok output.
