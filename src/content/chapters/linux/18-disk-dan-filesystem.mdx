Server bisa kehabisan ruang kapan saja. Tiga perintah awal yang selalu dipakai: `df`, `du`, dan `lsblk`.

## Melihat Kapasitas

```bash
df -h
df -i              # penggunaan inode
du -sh /var/*
du -h --max-depth=1 /home
```

```text
Filesystem  Size  Used  Avail  Use%  Mounted on
/dev/sda1   100G   82G   12G   88%  /
```

Perhatikan juga inode. Disk bisa “penuh” walau ruang tersisa bila terlalu banyak file kecil.

## Perangkat dan Partisi

```bash
lsblk
sudo fdisk -l
sudo blkid
```

```text
NAME   SIZE TYPE MOUNTPOINT
sda    256G disk
├─sda1 512M part /boot/efi
└─sda2 255G part /
sdb    1T   disk /mnt/data
```

## Mount

```bash
sudo mkdir -p /mnt/data
sudo mount /dev/sdb1 /mnt/data
sudo umount /mnt/data
```

Agar permanen, tambahkan ke `/etc/fstab`:

```text
UUID=abcd-1234  /mnt/data  ext4  defaults  0  2
```

Lebih aman memakai UUID daripada `/dev/sdb1` karena nama perangkat bisa berubah setelah reboot.

## Filesystem Umum

| Nama | Catatan |
|---|---|
| ext4 | standar Linux, stabil |
| XFS | baik untuk file besar |
| Btrfs | snapshot dan checksum |
| ZFS | fitur kaya, butuh modul tambahan |

```bash
sudo mkfs.ext4 /dev/sdb1
```

<div class="note">💡 `mkfs` menghancurkan data lama. Pastikan target perangkat sudah benar sebelum menjalankannya.</div>

## Investigasi Cepat

```bash
du -ah / | sort -rh | head -20
```

Perintah ini menemukan direktori atau file terbesar — biasanya log, cache, atau dump database.
