Banyak pekerjaan server dilakukan tanpa editor grafis. Linux menyediakan perintah kecil yang bisa dirangkai.

## Membaca

```bash
cat file.txt
head -n 20 file.txt
tail -n 20 file.txt
tail -f /var/log/nginx/access.log
less file.txt
```

`less` menampilkan halaman demi halaman. Tekan `q` untuk keluar, `/kata` untuk mencari.

## Pipa (Pipe)

```bash
cat access.log | grep "404" | wc -l
```

Simbol `|` meneruskan output perintah sebelumnya sebagai input perintah berikutnya. Ini kekuatan utama shell.

## Redirection

| Simbol | Fungsi |
|---|---|
| `>` | tulis output, timpa file |
| `>>` | tambahkan ke akhir file |
| `<` | baca input dari file |
| `2>` | alihkan error |
| `&>` | alihkan output dan error |

```bash
ls /tidak/ada 2> error.log
echo "baris baru" >> catatan.txt
```

## grep

```bash
grep "error" app.log
grep -i "error" app.log        # abaikan huruf besar/kecil
grep -n "error" app.log        # tampilkan nomor baris
grep -r "TODO" src/            # rekursif
grep -v "DEBUG" app.log        # barang yang tidak cocok
```

<div class="note">💡 `tail -f` sangat berguna saat mengamati log langsung. Tekan Ctrl+C untuk berhenti.</div>

## Perintah Pendukung

```bash
sort data.txt | uniq -c | sort -rn
cut -d: -f1 /etc/passwd
awk '{print $1}' access.log
```

`awk` dan `sed` adalah alat pemroses teks tingkat lanjut yang layak dipelajari setelah perintah dasar nyaman dipakai.
