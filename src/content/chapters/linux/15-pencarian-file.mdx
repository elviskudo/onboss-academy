Tahu nama file tapi lupa lokasinya? `find` dan `locate` menyelesaikan masalah itu dengan cara berbeda.

## find

```bash
find /var/log -type f -name "*.log"
find . -type d -name "node_modules"
find . -type f -iname "readme*"
find . -type f -size +50M
find . -mtime -7
```

| Opsi | Fungsi |
|---|---|
| `-type f` | file biasa |
| `-type d` | direktori |
| `-name` | pola nama |
| `-iname` | abaikan huruf besar |
| `-size +10M` | lebih dari 10 MB |
| `-mtime -7` | diubah &lt; 7 hari lalu |
| `-empty` | kosong |

## Aksi

```bash
find . -name "*.tmp" -delete
find . -name "*.sh" -exec chmod +x {} \;
find . -type f -name "*.log" -exec ls -lh {} +
```

`{}` diganti dengan nama file yang ditemukan, `\;` mengakhiri perintah per file, `+` mengelompokkan.

## locate

```bash
locate nginx.conf
sudo updatedb
```

`locate` membaca database indeks, sehingga jauh lebih cepat daripada `find /`, tetapi bisa ketinggalan file baru.

## Mencari Isi

```bash
grep -r "ERROR" /var/log
grep -rn "TODO" src/
grep -rl "rahasia" .
```

<div class="note">💡 Mulai pencarian dari direktori serendah mungkin. `find / -name ...` bisa memakan waktu lama dan memicu banyak error permission.</div>

## Kombinasi Berguna

```bash
find . -name "*.js" -not -path "./node_modules/*" | xargs grep "TODO"
```

`xargs` mengubah daftar hasil menjadi argumen perintah lain secara efisien.
