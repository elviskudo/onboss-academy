Shell melakukan **ekspansi** sebelum menjalankan perintah. Memahaminya mencegah kejutan seperti file yang salah terhapus.

## Wildcard Dasar

| Pola | Arti |
|---|---|
| `*` | nol atau lebih karakter |
| `?` | tepat satu karakter |
| `[abc]` | salah satu dari a, b, c |
| `[0-9]` | rentang angka |
| `[!a]` | bukan `a` |

```bash
echo *.md
echo foto[1-3].jpg
echo data?.csv
```

## Brace Expansion

```bash
echo {server,db,app}.conf
# server.conf db.conf app.conf

mkdir -p proyek/{src,docs,test}
```

Berbeda dengan glob, brace expansion **tidak perlu file yang sudah ada**.

## Kutipan

```bash
echo "$HOME"     # variabel di-expansi
echo '$HOME'     # tidak di-expansi
echo "*.txt"     # wildcard tidak di-expansi di dalam kutip
echo \*.txt      # escaping, sama seperti literal
```

## Contoh Aman

```bash
# melihat dulu siapa yang akan terkena
echo *.log

# baru menghapus
rm *.log
```

<div class="note">💡 Kebiasaan `echo <pola>` sebelum `rm <pola>` adalah cara murah mencegah penghapusan yang tidak diinginkan.</div>

## Ekspansi Lain

- `~` → home pengguna.
- `$VAR` → nilai variabel.
- `$(perintah)` → output perintah sebagai argumen.
- `!!` → perintah sebelumnya.

```bash
echo "Hari ini: $(date +%A)"
```
