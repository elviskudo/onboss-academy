Jaringan adalah bagian besar dari pekerjaan server. Beberapa perintah cukup untuk menjawab sebagian besar pertanyaan diagnostik.

## Konektivitas

```bash
ping -c 3 8.8.8.8
ping -c 3 example.com
traceroute example.com
mtr example.com
```

Jika IP langsung berhasil tetapi domain gagal, masalahnya ada di DNS.

## DNS

```bash
dig example.com
dig example.com +short
dig @8.8.8.8 example.com
nslookup example.com
cat /etc/resolv.conf
```

| Record | Fungsi |
|---|---|
| A | domain -> IPv4 |
| AAAA | domain -> IPv6 |
| CNAME | alias domain |
| MX | server email |
| TXT | teks verifikasi |

## Port

```bash
ss -tuln
ss -tulnp | grep 80
lsof -i :5432
nc -zv host 443
```

```text
State   Recv-Q Send-Q Local Address:Port
LISTEN  0      128    0.0.0.0:80
```

## HTTP dari Terminal

```bash
curl -I https://example.com
curl -s https://api.example.com/data | jq .
curl -X POST -d '{"a":1}' -H 'Content-Type: application/json' url
```

## Transfer File

```bash
scp file.txt user@server:/tmp/
scp user@server:/var/log/app.log .
rsync -avz ./app/ user@server:/srv/app/
rsync -avz --delete ./build/ user@server:/var/www/
```

<div class="note">💡 Perhatikan slash di akhir `rsync`: `app/` menyalin **isi** folder, `app` menyalin **foldernya** ke dalam tujuan.</div>

## Konfigurasi IP

```bash
ip addr show
ip route show
ip link set eth0 up
```

Pada distro modern, `ip` menggantikan `ifconfig`.
