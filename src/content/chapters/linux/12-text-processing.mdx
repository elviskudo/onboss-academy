`sed` dan `awk` adalah dua alat klasik Linux untuk memanipulasi teks. `sed` mengubah aliran baris, `awk` memahami kolom.

## sed

```bash
sed 's/apel/mangga/' daftar.txt
sed 's/apel/mangga/g' daftar.txt
sed -n '2,5p' daftar.txt
sed '/^#/d' konfigurasi.conf
```

| Perintah | Arti |
|---|---|
| `s/lama/baru/` | substitusi |
| `g` | semua kemunculan |
| `-n` | jangan cetak otomatis |
| `p` | cetak baris |
| `d` | hapus baris |

```bash
sed -i.bak 's/localhost/127.0.0.1/g' app.conf
```

`.bak` membuat salinan sebelum perubahan — kebiasaan yang sangat disarankan.

## awk

```bash
awk '{print $1}' access.log
awk -F, '{print $2}' data.csv
awk '$3 > 100 {print $1, $3}' penjualan.txt
awk '{total += $2} END {print total}'angka.txt
```

```text
nama     = $0 (seluruh baris)
field 1  = $1
field 2  = $2
pemisah  = -F, untuk koma
```

## Kombinasi

```bash
cat log.txt | grep "ERROR" | awk '{print $4}' | sort | uniq -c
```

Rangkaian ini menghitung berapa kali tiap komponen menghasilkan error.

<div class="note">💡 `awk` bukan sekadar formatter — ia bahasa pemrograman kecil dengan variabel, percabangan, dan loop. Mulai dari print sederhana, lalu berkembang sesuai kebutuhan.</div>

## Kapan Pakai Apa

- `grep` → mencari baris.
- `sed` → mengganti teks pada baris.
- `awk` → bekerja dengan kolom dan agregasi.
- `cut` → mengambil kolom dengan pemisah tetap.
