CTE rekursif mengulang query terhadap hasilnya sendiri sampai kondisi berhenti terpenuhi. Ini alat alami untuk hierarki, graf sederhana, dan deret.

## Deret Angka

```sql
WITH RECURSIVE angka(n) AS (
  SELECT 1
  UNION ALL
  SELECT n + 1 FROM angka WHERE n < 10
)
SELECT n FROM angka;
```

Anchor `SELECT 1` menghasilkan baris pertama. Recursive member menambah satu sampai `n &lt; 5` tidak lagi benar.

## Hierarki Karyawan

```sql
WITH RECURSIVE pohon AS (
  SELECT id, nama, manager_id, 1 AS kedalaman
  FROM karyawan WHERE manager_id IS NULL
  UNION ALL
  SELECT k.id, k.nama, k.manager_id, p.kedalaman + 1
  FROM karyawan k JOIN pohon p ON k.manager_id = p.id
)
SELECT repeat('  ', kedalaman - 1) || nama AS struktur, kedalaman
FROM pohon ORDER BY kedalaman, nama;
```

Baris dengan `manager_id IS NULL` adalah akar. Rekursi menuruni level berikutnya.

## Deret Tanggal

```sql
WITH RECURSIVE tanggal(hari) AS (
  SELECT DATE '2026-11-01'
  UNION ALL
  SELECT hari + INTERVAL '1 day'
  FROM tanggal WHERE hari < DATE '2026-11-07'
)
SELECT hari FROM tanggal;
```

Deret tanggal berguna untuk mengisi tanggal yang tidak punya transaksi sebelum digabung dengan data aktual.

## Menjaga Siklus

```sql
WITH RECURSIVE jalur AS (
  SELECT id, ARRAY[id] AS visited
  FROM simpul WHERE id = 1
  UNION ALL
  SELECT e.to, j.visited || e.to
  FROM edge e JOIN jalur j ON e.from = j.id
  WHERE NOT e.to = ANY(j.visited)
)
SELECT * FROM jalur;
```

Kolom `visited` menyimpan jalur. Kondisi `NOT ... = ANY` mencegah mengunjungi simpul yang sudah dilalui.

<div class="note">💡 Rekursi tanpa kondisi berhenti bisa berjalan sangat lama. Saat prototyping, tambahkan `LIMIT` sementara atau batas kedalaman untuk berjaga-jaga.</div>

## Di Dunia Nyata

- **Struktur organisasi**: atasan → bawahan beberapa level.
- **Kategori bertingkat**: katalog produk dengan subkategori.
- **Kalender**: mengisi tanggal kosong untuk grafik.
- **Graf dependensi**: menelusuri rute atau relasi.
