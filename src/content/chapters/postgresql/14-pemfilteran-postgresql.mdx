PostgreSQL punya operator filter yang tidak ada di banyak database lain. Memahamannya membuat query lebih ringkas sekaligus menghindari jebakan NULL.

## ANY dan ALL

```sql
SELECT * FROM produk
WHERE harga > ANY(ARRAY[10000, 20000, 30000]);

SELECT * FROM produk
WHERE harga > ALL(ARRAY[10000, 20000, 30000]);
```

`ANY` benar bila satu perbandingan benar; `ALL` harus benar untuk semua elemen.

## EXISTS dan NOT EXISTS

```sql
SELECT k.nama FROM karyawan k
WHERE EXISTS (SELECT 1 FROM proyek p WHERE p.lead_id = k.id);
```

EXISTS berhenti setelah menemukan satu baris. Gunakan NOT EXISTS daripada NOT IN bila subquery mungkin menghasilkan NULL.

## Jebakan NULL

```sql
SELECT NULL = NULL;               -- NULL (unknown)
SELECT NULL IS DISTINCT FROM NULL; -- false
SELECT 1 IS DISTINCT FROM NULL;    -- true
```

`IS NOT DISTINCT FROM` adalah kebalikannya: NULL dianggap sama dengan NULL.

## Pattern Matching

| Operator | Keterangan |
| --- | --- |
| `LIKE` | case-sensitive, `%` dan `_` |
| `ILIKE` | case-insensitive |
| `SIMILAR TO` | pola regex SQL |
| `~` | regex Posix case-sensitive |
| `~*` | regex Posix case-insensitive |

```sql
SELECT * FROM karyawan WHERE nama ~* '^(ana|budi)';
```

## BETWEEN dan IN

```sql
SELECT * FROM karyawan
WHERE gaji BETWEEN 8000000 AND 12000000
  AND dept IN ('Engineering', 'Data');
```

BETWEEN inklusif pada kedua batas. Untuk timestamp, gunakan `>=` dan `<` agar batas atas tidak memotong sebagian detik.

<div class="note">💡 `LIKE '%kata'` tidak bisa memakai index B-Tree biasa. Untuk pencarian teks berskala besar, pertimbangkan trigram index atau full-text search.</div>

## Di Dunia Nyata

- **Filter multi-nilai**: `= ANY(array)` dari parameter aplikasi.
- **Pencarian nama**: ILIKE untuk input pengguna.
- **Data opsional**: IS DISTINCT FROM membandingkan nilai lama/baru dalam audit.
- **Validasi**: regex ~* untuk format kode.
