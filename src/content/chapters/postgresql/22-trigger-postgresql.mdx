Trigger secara otomatis memanggil fungsi saat peristiwa INSERT, UPDATE, DELETE, atau TRUNCATE terjadi. Gunakan untuk aturan yang harus berlaku dari mana pun data diubah.

## Membuat Trigger

```sql
CREATE OR REPLACE FUNCTION normalisasi_nama()
RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
  NEW.nama := lower(trim(NEW.nama));
  RETURN NEW;
END;
$$;

CREATE TRIGGER trg_normalisasi
BEFORE INSERT OR UPDATE ON produk
FOR EACH ROW EXECUTE FUNCTION normalisasi_nama();
```

Trigger BEFORE harus mengembalikan `NEW`; mengembalikan NULL membatalkan operasi.

## AFTER Trigger dan Audit

```sql
CREATE TABLE audit_produk (
 id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
 produk_id integer, aksi text, waktu timestamptz DEFAULT now()
);

CREATE OR REPLACE FUNCTION catat_audit()
RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
  INSERT INTO audit_produk(produk_id, aksi)
  VALUES (NEW.id, TG_OP);
  RETURN NULL;
END;
$$;

CREATE TRIGGER trg_audit AFTER INSERT ON produk
FOR EACH ROW EXECUTE FUNCTION catat_audit();
```

## Row vs Statement

| Level | Dipanggil | Cocok untuk |
| --- | --- | --- |
| `FOR EACH ROW` | per baris | validasi per record |
| `FOR EACH STATEMENT` | sekali per query | ringkasan, notifikasi

## Transition Table

```sql
CREATE TRIGGER trg_ringkas
AFTER UPDATE ON produk
REFERENCING OLD TABLE AS lama NEW TABLE AS baru
FOR EACH STATEMENT EXECUTE FUNCTION bandingkan_stok();
```

Transition table memberi akses ke kumpulan baris lama/baru, cocok untuk batch update.

## Constraint Trigger

```sql
CREATE CONSTRAINT TRIGGER cek_stok
AFTER INSERT ON pesanan
DEFERRABLE INITIALLY DEFERRED
FOR EACH ROW EXECUTE FUNCTION validasi_stok();
```

Dengan `INITIALLY DEFERRED`, pengecekan terjadi saat COMMIT, setelah semua baris selesai diubah.

<div class="note">💡 Trigger yang melakukan query ke tabel yang sama bisa memicu rekursi. Gunakan `pg_trigger_depth()` atau nonaktifkan trigger sementara bila memang diperlukan.</div>

## Di Dunia Nyata

- **Normalisasi**: nama dan email dibersihkan sebelum disimpan.
- **Audit**: setiap perubahan data sensitif tercatat.
- **Denormalisasi**: stok di tabel ringkas diperbarui otomatis.
- **Validasi**: aturan yang harus berlaku untuk semua client.
