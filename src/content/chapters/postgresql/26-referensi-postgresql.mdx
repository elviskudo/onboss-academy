Chapter penutup merangkum fitur PostgreSQL yang paling sering dipakai dan mengarahkan langkah belajar berikutnya.

## Perintah Inti

| Kategori | Perintah |
| --- | --- |
| Objek | CREATE, ALTER, DROP |
| Data | SELECT, INSERT, UPDATE, DELETE, MERGE |
| Filter | WHERE, ANY/ALL, EXISTS, LIKE/ILIKE, IS DISTINCT FROM |
| Ringkasan | GROUP BY, HAVING, window function |
| Perantara | CTE, subquery, LATERAL |
| Lanjutan | jsonb, array, PL/pgSQL, trigger |
| Transaksi | BEGIN, COMMIT, ROLLBACK, SAVEPOINT |
| Index | CREATE INDEX, INCLUDE, GIN, BRIN |
| Perawatan | VACUUM, ANALYZE, REINDEX |
| Backup | pg_dump, pg_restore, pg_basebackup

## Template Analitik

```sql
WITH urut AS (
  SELECT dept, nama, gaji,
         ROW_NUMBER() OVER (PARTITION BY dept ORDER BY gaji DESC) AS pos
  FROM karyawan
  WHERE gaji IS NOT NULL
)
SELECT dept, nama, gaji
FROM urut
WHERE pos = 1
ORDER BY gaji DESC;
```

## Kebiasaan Baik

1. Gunakan `timestamptz` untuk waktu absolut.
2. Simpan uang sebagai `numeric`.
3. Tulis nama objek snake_case tanpa kutip.
4. Utamakan CTE untuk query bertahap.
5. Ukur dengan EXPLAIN sebelum menambah index.
6. Biarkan autovacuum aktif.

## Rencana Latihan

- SELECT, filter, dan urutan klausa.
- Agregat + GROUP BY + HAVING.
- JOIN, anti join, dan LATERAL.
- CTE rekursif dan window function.
- JSONB dan array.
- Index, EXPLAIN, VACUUM.
- Transaksi, trigger, dan backup.

<div class="note">💡 PostgreSQL dan MySQL sama-sama SQL, tetapi berbeda pada default isolasi, tipe boolean, RETURNING, dan ekosistem index. Mempelajari keduanya membuatmu lebih adaptif.</div>

## Di Dunia Nyata

- **Backend aplikasi**: CRUD + transaksi + RETURNING.
- **Analitik**: window function + CTE + jsonb.
- **Data engineering**: CDC lewat logical decoding dan WAL.
- **Operasional**: backup PITR, monitoring, autovacuum.
