Window function menghitung nilai lintas baris **tanpa** menggabungkan baris seperti GROUP BY. Setiap baris tetap ada, dengan kolom tambahan hasil kalkulasi.

## Sintaks Umum

```sql
fungsi() OVER (
  [PARTITION BY kolom]
  [ORDER BY kolom]
  [ROWS frame]
)
```

`PARTITION BY` mirip GROUP BY tetapi tidak menyatukan baris. `ORDER BY` menentukan urutan dalam partisi.

## Peringkat

```sql
SELECT nama, dept, gaji,
       ROW_NUMBER() OVER (PARTITION BY dept ORDER BY gaji DESC) AS urut,
       RANK()       OVER (PARTITION BY dept ORDER BY gaji DESC) AS rank,
       DENSE_RANK() OVER (PARTITION BY dept ORDER BY gaji DESC) AS dense
FROM karyawan;
```

Dengan dua orang bergaji sama, RANK bisa menghasilkan 1, 1, 3; DENSE_RANK menghasilkan 1, 1, 2.

## LAG dan LEAD

```sql
SELECT tanggal, omzet,
       LAG(omzet, 1) OVER (ORDER BY tanggal) AS sebelumnya,
       omzet - LAG(omzet, 1) OVER (ORDER BY tanggal) AS selisih
FROM penjualan;
```

Argumen kedua LAG adalah offset; argumen ketiga nilai pengganti bila tidak ada baris sebelumnya.

## Aggregate sebagai Window

```sql
SELECT nama, gaji,
       AVG(gaji) OVER (PARTITION BY dept) AS rata_dept,
       SUM(gaji) OVER (ORDER BY id ROWS UNBOUNDED PRECEDING) AS berjalan
FROM karyawan;
```

`ROWS UNBOUNDED PRECEDING` berarti frame dimulai dari baris pertama sampai baris saat ini — cocok untuk running total.

## Frame

| Frame | Arti |
| --- | --- |
| `ROWS BETWEEN 2 PRECEDING AND CURRENT ROW` | 3 baris terakhir |
| `ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW` | dari awal sampai sekarang |
| `ROWS BETWEEN CURRENT ROW AND UNBOUNDED FOLLOWING` | sekarang sampai akhir

<div class="note">💡 Jika ORDER BY tidak diberikan pada frame, PostgreSQL memakai seluruh partisi untuk setiap baris. Selalu tentukan ORDER BY bila结果 bergantung pada urutan.</div>

## Di Dunia Nyata

- **Leaderboard**: RANK untuk peringkat yang adil.
- **Pertumbuhan**: LAG untuk membandingkan periode sebelumnya.
- **Running total**: SUM window untuk saldo berjalan.
- **Top N per grup**: ROW_NUMBER lalu filter di CTE.
