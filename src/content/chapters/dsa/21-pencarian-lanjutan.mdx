Binary search sudah kuat, tetapi ada situasi khusus di mana variannya lebih cocok.

## Exponential Search

```python
def exponential(a, target):
    if not a:
        return -1
    if a[0] == target:
        return 0
    i = 1
    while i < len(a) and a[i] < target:
        i *= 2
    lo, hi = i // 2, min(i, len(a) - 1)
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        if a[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

```text
indeks: 1  2  4  8  16 ...
         ^  ^  ^  ^
              berhenti saat nilai >= target
```

Kompleksitas O(log i) dengan i posisi target — sangat cocok untuk array sangat besar atau stream terurut.

## Interpolation Search

```python
def interpolasi(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi and a[lo] <= target <= a[hi]:
        if a[lo] == a[hi]:
            return lo
        pos = lo + (target - a[lo]) * (hi - lo) // (a[hi] - a[lo])
        if a[pos] == target:
            return pos
        if a[pos] < target:
            lo = pos + 1
        else:
            hi = pos - 1
    return -1
```

| Metode | Waktu | Syarat |
|---|---|---|
| Linear | O(n) | tidak perlu terurut |
| Binary | O(log n) | terurut |
| Exponential | O(log i) | terurut, tak terhingga |
| Interpolation | O(log log n) rata-rata | terurut + merata |

<div class="note">💡 Interpolation search bisa lebih lambat dari binary search pada data yang sangat tidak merata. Ukur dulu distribusinya sebelum memilih.</div>

## Contoh Dunia Nyata

- Log terurut berdasarkan timestamp → exponential search.
- Buku telepon dengan nama tersebar merata → interpolation search.
- Array biasa berukuran sedang → binary search tetap paling sederhana.
