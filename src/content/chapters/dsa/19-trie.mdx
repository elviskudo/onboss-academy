**Trie** (prefix tree) menyimpan kata karakter demi karakter. Cocok saat kita sering bertanya: “kata apa saja yang diawali ...?”

## Struktur

```text
        (akar)
         /   \
        k     m
       / \     \
      a   u     a
     /     \     \
    r      c     k
   /        \
  u         i
 /           \
s             n
```

```python
class Node:
    def __init__(self):
        self.anak = {}
        self.akhir = False

def sisip(akar, kata):
    node = akar
    for ch in kata:
        node = node.anak.setdefault(ch, Node())
    node.akhir = True

def cari(akar, kata):
    node = akar
    for ch in kata:
        if ch not in node.anak:
            return False
        node = node.anak[ch]
    return node.akhir
```

## Autocomplete

```python
def prefiks(akar, awal):
    node = akar
    for ch in awal:
        if ch not in node.anak:
            return []
        node = node.anak[ch]
    hasil = []
    def kumpulkan(n, s):
        if n.akhir:
            hasil.append(s)
        for ch, nxt in n.anak.items():
            kumpulkan(nxt, s + ch)
    kumpulkan(node, awal)
    return hasil
```

| Operasi | Kompleksitas |
|---|---|
| Insert | O(m) |
| Cari kata | O(m) |
| Cari prefiks | O(m + hasil) |
| Ruang | O(total karakter) |

<div class="note">💡 Trie menghemat waktu tetapi mengorbankan memori. Untuk vocabulary jutaan kata, pertimbangkan compact trie / radix tree yang menggabungkan rantai node tunggal.</div>

## Aplikasi Lain

- Spell checker dan koreksi ejaan.
- Routing IP (longest prefix match).
- Pencarian kata kunci real-time.
- Kompresi teks dengan encoding kamus.
