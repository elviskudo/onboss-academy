**Bloom filter** adalah struktur probabilitas yang sangat hemat memori. Ia bisa mengatakan “pasti tidak ada” dengan kepastian penuh, tetapi hanya “mungkin ada” untukpositif.

## Cara Kerja

```text
bit array: 0 0 0 0 0 0 0 0

tambah "apel" -> hash 3, 7, 11 -> nyalakan bit tersebut

cek "apel" -> hash 3, 7, 11 -> semua 1 -> mungkin ada
cek "jeruk" -> hash 3, 7, 12 -> bit 12 = 0 -> pasti tidak ada
```

```python
class Bloom:
    def __init__(self, ukuran):
        self.bit = [0] * ukuran

    def tambah(self, nilai, hash_vals):
        for h in hash_vals:
            self.bit[h % len(self.bit)] = 1

    def mungkin_ada(self, nilai, hash_vals):
        return all(self.bit[h % len(self.bit)] for h in hash_vals)

filter = Bloom(16)
filter.tambah("apel", [3, 7, 11])
print(filter.mungkin_ada("apel", [3, 7, 11]))
print(filter.mungkin_ada("jeruk", [3, 7, 12]))
```

## Trade-Off

| Parameter | Efek |
|---|---|
| bit array lebih besar | false positive turun, memori naik |
| lebih banyak hash | false positive turun, waktu naik |
| terlalu banyak elemen | false positive naik |

<div class="note">💡 Bloom filter sangat cocok sebagai **lapisan pertama**. Kalau hasilnya “mungkin ada”, baru lakukan pengecekan pasti ke database atau hash set.</div>

## Keterbatasan

- Tidak bisa menghapus elemen (kecuali Counting Bloom Filter).
- Tidak bisa mengembalikan daftar elemen.
- False positive harus diterima oleh desain sistem.

## Penggunaan Nyata

- Browser memberi tahu URL berbahaya tanpa mengunduh daftar penuh.
- Database menghindari lookup disk untuk kunci yang tidak ada.
- Sistem distributed memeriksa apakah suatu kunci mungkin ada di node lain.
- Web crawler menghindari mengunjungi URL yang sudah pernah dilihat.
