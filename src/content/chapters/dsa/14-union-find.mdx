**Union-Find** menjawab pertanyaan sederhana yang muncul di banyak algoritma: “Apakah dua elemen berada dalam kelompok yang sama?”

## Representasi

Setiap elemen punya `parent`. Awalnya setiap elemen adalah akar bagi dirinya sendiri.

```python
parent = list(range(6))
print(parent)  # [0, 1, 2, 3, 4, 5]
```

## Find dan Union

```python
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]  # path halving
        x = parent[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra != rb:
        parent[rb] = ra
```

## Dua Optimasi

| Teknik | Efek |
|---|---|
| Path compression | node langsung menunjuk akar |
| Union by size/rank | pohon pendek menempel ke pohon panjang |

```python
size = [1] * len(parent)

def union_ukuran(a, b):
    ra, rb = find(a), find(b)
    if ra == rb:
        return
    if size[ra] < size[rb]:
        ra, rb = rb, ra
    parent[rb] = ra
    size[ra] += size[rb]
```

Tanpa optimasi, operasi bisa O(n). Dengan keduanya, kompleksitas amortized mendekati O(1).

## Contoh: Komponen Graf

```python
tepi = [(0,1), (2,3), (1,2)]
for a, b in tepi:
    union(a, b)
print(find(0) == find(3))  # True
print(find(0) == find(4))  # False
```

<div class="note">💡 Union-Find hanya bisa **menggabungkan**, tidak memisahkan. Untuk konektivitas dinamis dengan penghapusan, diperlukan struktur lain.</div>

## Aplikasi Nyata

- Algoritma Kruskal untuk minimum spanning tree.
- Deteksi siklus pada graf tak berbobot.
- Mengelompokkan akun yang terhubung oleh transaksi.
- Label komponen pada citra digital.
