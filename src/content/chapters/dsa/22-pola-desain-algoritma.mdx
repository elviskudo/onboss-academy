Banyak algoritma bukan varian baru, melainkan **pola yang sama** dengan kostum berbeda. Mengenali pola mempercepat penyelesaian soal.

## Greedy

```python
def koin_terbanyak(nilai, koin):
    koin = sorted(koin, reverse=True)
    hasil = []
    for k in koin:
        while nilai >= k:
            hasil.append(k)
            nilai -= k
    return hasil

print(koin_terbanyak(27, [10, 5, 1]))
```

Greedy bekerja bila ada bukti bahwa pilihan terbesar lokal tidak merusak hasil akhir. Untuk sistem koin sembarangan, greedy bisa salah — gunakan DP.

## Two Pointers

```python
def dua_jumlah(a, target):
    a = sorted(a)
    l, r = 0, len(a) - 1
    while l < r:
        jumlah = a[l] + a[r]
        if jumlah == target:
            return (a[l], a[r])
        if jumlah < target:
            l += 1
        else:
            r -= 1
    return None
```

## Sliding Window

```python
def jumlah_maks(a, k):
    if len(a) < k:
        return None
    jumlah = sum(a[:k])
    terbaik = jumlah
    for i in range(k, len(a)):
        jumlah += a[i] - a[i - k]
        terbaik = max(terbaik, jumlah)
    return terbaik
```

| Pola | Ciri khas soal |
|---|---|
| Greedy | “minimum/maximum jumlah operasi” |
| Two pointers | array terurut, pasangan, palindrom |
| Sliding window | subarray terbesar/terkecil berukuran k |
| Fast-slow pointer | siklus linked list, midpoint |
