**Backtracking** mencoba solusi sedikit demi sedikit. Jika suatu pilihan membujuk ke jalan buntu, algoritma mundur dan mencoba pilihan lain.

## Pola Umum

```text
pilih -> cek valid -> rekursi -> batalkan pilihan
```

```python
def permutasi(s, jalur=""):
    if not s:
        print(jalur)
        return
    for i, ch in enumerate(s):
        sisa = s[:i] + s[i+1:]
        permutasi(sisa, jalur + ch)

permutasi("abc")
```

## N-Queen

```python
def aman(papan, baris, kolom):
    for i in range(baris):
        if papan[i] == kolom or abs(papan[i] - kolom) == baris - i:
            return False
    return True

def n_queen(n, baris=0, papan=[]):
    if baris == n:
        print(papan)
        return 1
    jumlah = 0
    for kolom in range(n):
        if aman(papan, baris, kolom):
            jumlah += n_queen(n, baris + 1, papan + [kolom])
    return jumlah

print(n_queen(4))
```

## Pruning

Pruning memeriksa lebih awal apakah cabang masih bisa menghasilkan solusi. Pada N-Queen, pengecekan serangan diagonal adalah bentuk pruning.

| Tanpa pruning | Dengan pruning |
|---|---|
| semua kombinasi dicoba | cabang invalid langsung ditinggalkan |
| waktu eksponensial penuh | jauh lebih sedikit node |

<div class="note">💡 Backtracking berbeda dengan brute force: keduanya menjelajahi kemungkinan, tetapi backtracking membatalkan lebih awal begitu aturan dilanggar.</div>

## Kapan Dipakai

- Sudoku, teka-teki kata, dan pencarian kombinasi.
- Parsing grammar dan pencocokan pola kompleks.
- Optimasi diskrit dengan ruang solusi tidak terlalu besar.

Untuk ruang sangat besar, pertimbangkan dynamic programming atau branch-and-bound yang lebih terarah.
