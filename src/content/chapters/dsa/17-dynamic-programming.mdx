Rekursi Fibonacci naif menghitung ulang nilai yang sama berkali-kali. **Dynamic programming (DP)** menyimpan hasilnya agar tiap submasalah dihitung sekali.

## Rekursi Boros

```python
def fib_naif(n):
    if n <= 1:
        return n
    return fib_naif(n - 1) + fib_naif(n - 2)
```

Pohon pemanggilannya tumbuh eksponensial.

## Memoization (Top-Down)

```python
def fib(n, memo=None):
    if memo is None:
        memo = {}
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fib(n - 1, memo) + fib(n - 2, memo)
    return memo[n]
```

## Tabulation (Bottom-Up)

```python
def fib_tabel(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b
```

| Aspek | Memoization | Tabulation |
|---|---|---|
| Arah | atas -> bawah | bawah -> atas |
| Implementasi | rekursi + cache | loop + array |
| Semua state dihitung | tidak harus | ya |
| Risiko | kedalaman rekursi | perlu urutan tepat |

## Contoh Knapsack Ringkas

```python
def knapsack(bobot, nilai, kapasitas):
    n = len(bobot)
    dp = [[0] * (kapasitas + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for k in range(kapasitas + 1):
            dp[i][k] = dp[i-1][k]
            if bobot[i-1] <= k:
                dp[i][k] = max(dp[i][k],
                               nilai[i-1] + dp[i-1][k-bobot[i-1]])
    return dp[n][kapasitas]
```

<div class="note">💡 DP bukan sekadar “pakai array”. Kuncinya adalah merumuskan **state** dan **transisi** dengan benar sebelum menulis kode.</div>
