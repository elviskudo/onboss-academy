**Rekursi** memecah masalah menjadi versi lebih kecil dari dirinya. Pola ini menjadi fondasi divide-and-conquer.

## Anatomi Rekursi

```python
def faktorial(n):
    if n <= 1:            # base case
        return 1
    return n * faktorial(n - 1)  # recursive case

print(faktorial(5))
```

Dua syarat wajib: **base case** dan langkah yang mendekati base case.

## Divide-and-Conquer

```text
Divide   -> pecah masalah
Conquer  -> selesaikan submasalah secara rekursif
Combine  -> gabungkan hasil
```

```python
def merge_sort(a):
    if len(a) <= 1:
        return a
    tengah = len(a) // 2
    kiri = merge_sort(a[:tengah])
    kanan = merge_sort(a[tengah:])
    return gabung(kiri, kanan)

def gabung(kiri, kanan):
    hasil, i, j = [], 0, 0
    while i < len(kiri) and j < len(kanan):
        if kiri[i] <= kanan[j]:
            hasil.append(kiri[i]); i += 1
        else:
            hasil.append(kanan[j]); j += 1
    return hasil + kiri[i:] + kanan[j:]
```

## Rekursi vs Iterasi

| Aspek | Rekursi | Iterasi |
|---|---|---|
| Kode | sering lebih pendek | lebih eksplisit |
| Memori | stack frame per level | variabel tetap |
| Risiko | stack overflow | loop tak berujung |
| Cocok untuk | tree, divide-conquer | state sederhana |

<div class="note">💡 Python membatasi kedalaman rekursi (sekitar 1000). Untuk urutan sangat panjang, gunakan iterasi atau naikkan batas dengan `sys.setrecursionlimit` secara bijak.</div>

## Teknik Optimization

- **Memoization** — simpan hasil submasalah yang berulang.
- **Tail recursion** — bentuk khusus yang bisa diubah ke loop (belum dioptimasi Python).
- **Explicit stack** — mensimulasikan rekursi dengan list.
