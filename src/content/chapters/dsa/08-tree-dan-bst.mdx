Tree adalah struktur hierarki: satu **root**, tiap node bisa punya **anak kiri** dan **anak kanan**. Varian paling terkenal: **Binary Search Tree (BST)**.

## Anatomi Tree

```
        50
       /  \
     30    70
    / \   / \
  20  40 60  80
```

- **Node** — simpul berisi data
- **Root** — node paling atas
- **Leaf** — node tanpa anak (20, 40, 60, 80)
- **Height** — jumlah level; memengaruhi kompleksitas operasi

## Insert di BST

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None

def insert(root, data):
    if root is None:
        return Node(data)
    if data < root.data:
        root.left = insert(root.left, data)
    else:
        root.right = insert(root.right, data)
    return root

root = None
for x in [50, 30, 70, 20, 40, 60, 80]:
    root = insert(root, x)
```

Kecil ke kiri, besar ke kanan — properti inilah yang membuat pencarian efisien.

## Pencarian

```python
def cari(root, target):
    if root is None or root.data == target:
        return root
    if target < root.data:
        return cari(root.left, target)
    return cari(root.right, target)

print(cari(root, 60) is not None)   # True
print(cari(root, 65) is not None)   # False
```

Tiap langkah membuang separuh subtree: **O(log n)** pada BST seimbang.

## Tiga Traversal

```python
def inorder(root):
    if root:
        inorder(root.left)
        print(root.data, end=" ")
        inorder(root.right)

def preorder(root):
    if root:
        print(root.data, end=" ")
        preorder(root.left)
        preorder(root.right)

def postorder(root):
    if root:
        postorder(root.left)
        postorder(root.right)
        print(root.data, end=" ")

inorder(root)     # 20 30 40 50 60 70 80  -> terurut
preorder(root)    # 50 30 20 40 70 60 80  -> root di depan
postorder(root)   # 20 40 30 60 80 70 50  -> root di belakang
```

| Traversal | Urutan | Kasus pakai |
|-----------|--------|-------------|
| Inorder | kiri, root, kanan | data terurut |
| Preorder | root, kiri, kanan | salin/serialisasi tree |
| Postorder | kiri, kanan, root | hapus tree, hitung subtree |

## Jenis Tree dan Operasi

Ada **4 keluarga yang sering ditemui**: binary tree membatasi dua anak, BST menambahkan aturan urutan, heap menjaga minimum/maksimum di root, dan balanced BST menjaga tinggi O(log n). Tree umum seperti struktur folder boleh memiliki banyak anak.

| Struktur | Aturan | Operasi utama | Kapan dipakai |
|---|---|---|---|
| Binary tree | maksimal dua anak | traversal | ekspresi dan keputusan |
| BST | kiri < root < kanan | search/insert/delete | data terurut dinamis |
| Heap | parent minimum/maksimum | push/pop O(log n) | priority queue |
| Balanced BST | tinggi dijaga logaritmik | operasi O(log n) | ordered map/set |

Ada **4 traversal dasar**: inorder, preorder, postorder, dan level-order. Tiga pertama lazim memakai stack atau rekursi; level-order memakai queue. Semua mengunjungi n node sehingga waktunya O(n). Memori tambahan O(h) untuk DFS dengan tinggi h, sedangkan BFS dapat menyimpan O(w) node selebar level terbesar.

## Di Dunia Nyata

- Tree folder merender navigasi dan menghitung ukuran subtree.
- Abstract syntax tree mewakili ekspresi sebelum compiler mengeksekusinya.
- BST seimbang mendukung pencarian rentang dan urutan key.
- Heap memilih job berprioritas tertinggi tanpa mengurutkan seluruh antrean.
