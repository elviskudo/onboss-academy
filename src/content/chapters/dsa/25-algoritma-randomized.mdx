 Sebagian algoritma sengaja memakai **keacakan** untuk menghindari kasus terburuk atau memilih sampel yang adil.

## Dua Keluarga

| Keluarga | Waktu | Jawaban | Contoh |
|---|---|---|---|
| Las Vegas | bisa berubah | selalu benar | randomized quicksort |
| Monte Carlo | relatif tetap | benar dengan probabilitas tinggi | Miller-Rabin |

## Pivot Acak

```python
import random

def quicksort(a):
    if len(a) <= 1:
        return a
    pivot = random.choice(a)
    kiri = [x for x in a if x < pivot]
    tengah = [x for x in a if x == pivot]
    kanan = [x for x in a if x > pivot]
    return quicksort(kiri) + tengah + quicksort(kanan)
```

Tanpa acakan, input sudah terurut bisa memicu O(n²). Dengan pivot acak, **expected** waktu O(n log n).

## Reservoir Sampling

```python
def reservoir(stream, k):
    hasil = []
    for i, item in enumerate(stream):
        if i < k:
            hasil.append(item)
        else:
            j = random.randint(0, i)
            if j < k:
                hasil[j] = item
    return hasil
```

Setiap item memiliki probabilitas `k/n` terpilih, walau total `n` tidak diketahui di awal.

## Kapan Dipakai

- Quick sort dan hash table untuk menghindari input adversarial.
- Estimasi besar himpunan dengansampel terbatas (HyperLogLog, MinHash).
- Testing dengan input acak untuk menemukan edge case.
- Simulasi dan algoritma approximate.

<div class="note">💡 Randomized != tidak bisa dianalisis. Kita tetap bisa menyatakan jaminan *expected* atau *dengan probabilitas tinggi* secara matematis.</div>

## Penutup DSA

Dari Big-O sampai algoritma randomized, inti perjalanan ini sama: **mengenali pola, mengukur biaya, dan memilih trade-off yang sadar**. Terus latih dengan soal baru, tetapi selalu jelaskan alasan di balik pilihan struktur data Anda.
