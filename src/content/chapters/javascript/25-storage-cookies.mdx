Browser menyediakan beberapa tempat menyimpan data sisi klien. Memilih yang tepat bergantung pada **siapa yang perlu membacanya** dan **berapa lama data harus bertahan**.

## Perbandingan

| Fitur | localStorage | sessionStorage | Cookie |
|-------|--------------|----------------|--------|
| Umur | Sampai dihapus | Sesi tab | Bisa diatur expiry |
| Dikirim ke server | Tidak | Tidak | Ya (header) |
| Kapasitas | ±5 MB | ±5 MB | ±4 KB |
| Akses | JavaScript saja | JavaScript saja | JS + server |
| HttpOnly | Tidak | Tidak | Bisa |

## Web Storage API

```js
localStorage.setItem("nama", "Sari");
localStorage.getItem("nama");      // "Sari"
localStorage.removeItem("nama");
localStorage.clear();              // semua data origin ini

sessionStorage.setItem("draft", "tulisan...");
```

Semua nilai adalah **string**. Simpan objek dengan JSON:

```js
const keranjang = [{ id: 1, qty: 2 }];
localStorage.setItem("keranjang", JSON.stringify(keranjang));

const data = JSON.parse(localStorage.getItem("keranjang") || "[]");
```

## Event storage

Perubahan localStorage di tab lain bisa didengar:

```js
window.addEventListener("storage", e => {
  console.log(e.key, e.oldValue, e.newValue);
});
```

Ini tidak terpicu di tab yang melakukan perubahan sendiri.

## Cookies

```js
document.cookie = "tema=gelap; max-age=86400; path=/; SameSite=Lax";
```

Atribut penting:

- `max-age` / `expires` — umur cookie (detik / tanggal).
- `path` — cakupan URL.
- `domain` — cakupan host.
- `Secure` — hanya lewat HTTPS.
- `HttpOnly` — tidak bisa dibaca JavaScript (wajib untuk session token).
- `SameSite=Lax|Strict|None` — perlindungan CSRF.

Membaca cookie:

```js
document.cookie.split("; ").reduce((acc, item) => {
  const [k, ...v] = item.split("=");
  acc[k] = v.join("=");
  return acc;
}, {});
```

## IndexedDB (Singkat)

Untuk data besar dan terstruktur, ada IndexedDB — database NoSQL di browser. Kapasitasnya jauh lebih besar dan mendukung transaksi, tapi API-nya lebih rumit (biasanya dibungkus library seperti Dexie).

## Keamanan

<div class="note">💡 Jangan pernah menyimpan token akses atau kata sandi di localStorage. Rentan terhadap XSS. Simpan session token di cookie `HttpOnly; Secure; SameSite` yang diatur server.</div>

## Di Dunia Nyata

- Preferensi tema (terang/gelap) disimpan di localStorage.
- Draft artikel sementara disimpan di sessionStorage.
- Cookie session mengautentikasi pengguna pada request ke server.
- "Jangan tampilkan lagi" untuk banner promo memakai cookie dengan expiry 30 hari.
