JSON (*JavaScript Object Notation*) adalah format teks untuk bertukar data. Meski berasal dari JavaScript, JSON dipakai hampir semua bahasa pemrograman.

## Aturan Sintaks

```json
{
  "nama": "Sari",
  "umur": 20,
  "aktif": true,
  "hobi": ["membaca", "berenang"],
  "alamat": null
}
```

- Kunci dan string memakai **tanda kutip ganda**.
- Tidak ada komentar dan tidak ada koma di akhir.
- Nilai yang sah: string, number, boolean, null, array, objek.
- Tanggal direpresentasikan sebagai string ISO.

## Stringify

```js
const data = { nama: "Sari", jumlah: 3, aside: undefined };
JSON.stringify(data);
// '{"nama":"Sari","jumlah":3}' — aside hilang

JSON.stringify(data, null, 2); // pretty print dengan indentasi 2 spasi
```

Argumen kedua bisa berupa array (whitelist kunci) atau fungsi replacer.

```js
JSON.stringify(pengguna, (k, v) =>
  k === "password" ? undefined : v
);
```

## Parse

```js
const teks = '{"nama":"Sari","skor":[8,9]}';
const obj = JSON.parse(teks);
obj.skor[0]; // 8

JSON.parse(teks, (k, v) =>
  typeof v === "string" ? v.toUpperCase() : v
);
```

`JSON.parse` melempar `SyntaxError` kalau teks bukan JSON valid — selalu bungkus dengan `try/catch` saat menerima data dari luar.

## reviver untuk Tanggal

```js
const data = JSON.parse(teks, (k, v) =>
  /^\d{4}-\d{2}-\d{2}T/.test(v) ? new Date(v) : v
);
```

## Menyimpan di localStorage

```js
const keranjang = [{ id: 1, qty: 2 }];
localStorage.setItem("keranjang", JSON.stringify(keranjang));

const dibaca = JSON.parse(localStorage.getItem("keranjang") || "[]");
```

Selalu sediakan fallback `"[]"` supaya `JSON.parse(null)` tidak menghasilkan `null` yang merepotkan.

## JSON vs Objek JS

| Aspek | Objek JS | JSON |
|-------|----------|------|
| Bentuk | Struktur data di memori | String teks |
| Kunci | String/Symbol | String saja |
| Fungsi | Boleh | Tidak boleh |
| Komentar | Boleh (di kode) | Tidak boleh |
| Tanda kutip kunci | Opsional | Wajib ganda |

<div class="note">💡 Jangan pernah memakai `eval()` untuk membaca JSON. Selain berbahaya (bisa mengeksekusi kode), `JSON.parse` juga lebih cepat dan ketat.</div>

## Di Dunia Nyata

- Request/response REST API hampir selalu JSON.
- Konfigurasi `package.json`, `tsconfig.json`, dan data statis memakai JSON.
- Menyimpan state sederhana di browser memakai JSON + localStorage.
