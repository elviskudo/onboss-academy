*Regular expression* (regex) adalah pola untuk mencocokkan teks. Kuat, padat, dan terkenal sulit dibaca — tapi sangat berguna untuk validasi dan pencarian.

## Membuat Regex

```js
const pola1 = /halo/i;              // literal
const pola2 = new RegExp("halo", "i"); // konstruktor
```

Konstruktor berguna kalau polanya berasal dari variabel atau input pengguna.

## Flag

| Flag | Arti |
|------|------|
| `g` | global — semua kecocokan |
| `i` | case-insensitive |
| `m` | multiline — `^`/`$` per baris |
| `s` | dotAll — `.` juga cocok newline |
| `u` | unicode |
| `y` | sticky — mulai dari lastIndex |

## Character Class

| Pola | Arti |
|------|------|
| `\d` | Angka 0–9 |
| `\D` | Bukan angka |
| `\w` | Huruf, angka, underscore |
| `\W` | Bukan `\w` |
| `\s` | Spasi, tab, newline |
| `[abc]` | a, b, atau c |
| `[^abc]` | Selain a, b, c |
| `[a-z]` | Rentang huruf kecil |

## Quantifier

```js
/a/    // satu a
/a*/   // nol atau lebih
/a+/   // satu atau lebih
/a?/   // nol atau satu
/a{3}/ // tepat tiga
/a{2,4}/ // dua sampai empat
/a{2,}/  // minimal dua
```

Secara default quantifier bersifat **greedy** (mengambil sebanyak mungkin). Tambahkan `?` untuk lazy: `.*?`.

## Anchor & Group

```js
/^Halo/        // diawali "Halo"
/dunia$/       // diakhiri "dunia"
/(ab)+/        // grup berulang
/foo|bar/      // foo ATAU bar
/(?:\d{4})/    // grup non-capturing
```

## Method RegExp & String

```js
const pola = /\d+/g;
pola.test("abc123");       // true
"abc123".match(pola);      // ["123"]
"a1 b2".replace(/\d/g, "X"); // "aX bX"
"a,b,c".split(",");        // ["a","b","c"]
pola.exec("abc123");       // detail kecocokan pertama
```

Hati-hati: regex dengan flag `g` menyimpan `lastIndex`, jadi `test()` berulang bisa memberi hasil berbeda. Buat regex baru atau reset `lastIndex = 0`.

## Contoh Validasi

```js
const email = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const kuat = /^(?=.*[A-Z])(?=.*\d).{8,}$/;
const telepon = /^(\+62|0)8\d{8,11}$/;

email.test("sari@example.com"); // true
```

<div class="note">💡 Regex cocok untuk pola sederhana, tapi jangan dipakai untuk mem-parse HTML atau URL kompleks. Untuk itu, gunakan parser yang tepat.</div>

## Di Dunia Nyata

- Validasi format input sebelum dikirim ke server.
- Mengganti semua occurrence dengan `replaceAll(/regex/g, ...)`.
- Log parser mengekstrak tanggal, IP, dan kode status dari baris teks.
