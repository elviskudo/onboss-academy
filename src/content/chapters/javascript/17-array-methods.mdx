Method array modern membuat kode lebih deklaratif: kamu menjelaskan **apa** yang ingin dilakukan, bukan **bagaimana** melakukan loop-nya.

## Map, Filter, Reduce

```js
const produk = [
  { nama: "Kopi", harga: 20000, aktif: true },
  { nama: "Teh", harga: 15000, aktif: false },
];

const aktif = produk.filter(p => p.aktif);
const nama = produk.map(p => p.nama);
const total = produk.reduce((sum, p) => sum + p.harga, 0);
```

| Method | Input | Output | Kegunaan |
|--------|-------|--------|----------|
| `map` | semua elemen | array sama panjang | Transformasi |
| `filter` | semua elemen | array lebih pendek/sama | Seleksi |
| `reduce` | semua elemen | satu nilai | Agregasi |
| `find` | sampai ketemu | satu elemen/undefined | Pencarian |
| `some` | sampai ketemu | boolean | "ada yang…?" |
| `every` | sampai gagal | boolean | "semua…?" |

## Find & Friends

```js
const kopi = produk.find(p => p.nama === "Kopi");
const adaMurah = produk.some(p => p.harga < 18000);
const semuaAktif = produk.every(p => p.aktif);
const indeks = produk.findIndex(p => p.nama === "Teh");
```

## Sort yang Benar

```js
const angka = [10, 2, 1];
angka.sort();              // [1, 10, 2] ❌
angka.sort((a, b) => a - b); // [1, 2, 10] ✅

const nama = ["Sari", "Budi", "Andi"];
nama.sort((a, b) => a.localeCompare(b, "id"));
```

`sort()` **mengubah array asli**. Kalau ingin menyalin, pakai `[...arr].sort(...)` atau `arr.toSorted()` (fitur baru).

## Utility Lain

```js
[1, 2, 3].at(-1)          // 3
[1, 2, 3].includes(2)     // true
[1, 2].concat([3, 4])     // [1,2,3,4]
Array.from("abc")         // ['a','b','c']
Array(5).fill(0)          // [0,0,0,0,0]
[1,2,3].join("-")         // "1-2-3"
[1,2,3].reverse()         // [3,2,1] (mutasi!)
```

## Chaining

```js
const hasil = produk
  .filter(p => p.harga > 10000)
  .map(p => ({ ...p, harga: p.harga * 1.1 }))
  .sort((a, b) => b.harga - a.harga);
```

Rantai ini mudah dibaca, tapi ingat tiap method membuat array baru (kecuali `sort`/`reverse`). Pada data sangat besar, loop biasa bisa lebih efisien.

<div class="note">💡 `reduce` tanpa nilai awal akan memakai elemen pertama sebagai akumulator. Untuk array kosong, itu melempar TypeError — selalu berikan nilai awal.</div>
