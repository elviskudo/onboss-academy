## Dasar addEventListener

```js
const btn = document.querySelector("button");

btn.addEventListener("click", () => {
  console.log("Diklik!");
});

// dengan parameter event
btn.addEventListener("click", (e) => {
  console.log("Target:", e.target);
});
```

Bisa memuat lebih dari satu listener pada elemen yang sama. Alternatif gaya lama `btn.onclick = fn` masih berjalan, tapi menimpa listener sebelumnya — karena itu `addEventListener` menang.

```js
// klik dua kali dalam 300ms → abaikan (debounce sederhana)
let klikTerakhir = 0;
btn.addEventListener("click", () => {
  const now = Date.now();
  if (now - klikTerakhir < 300) return;
  klikTerakhir = now;
  console.log("Klik valid");
});
```

## Opsi & Melepas Listener

```js
// opsi ke-3 addEventListener
btn.addEventListener("click", fn, { once: true });   // sekali lalu lepas sendiri
btn.addEventListener("wheel", fn, { passive: true }); // tak memanggil preventDefault → scroll lebih mulus
list.addEventListener("click", fn, { capture: true }); // fase turun (capture) lebih dulu

btn.removeEventListener("click", fn); // wajib referensi fungsi yang sama
```

PENTING: `removeEventListener` butuh **referensi fungsi yang sama** — `(e) => console.log("x")` yang ditulis dua kali adalah dua fungsi berbeda.

## 4 Fase Event

| Fase | Alur | Kegunaan |
|------|------|----------|
| Capturing | `window` → turun ke target | Intercept lebih awal (jarang) |
| Target | Elemen pemicu | Penanganan normal di sini |
| Bubbling | Target → naik ke `window` | Dasar event delegation |
| Default | Aksi bawaan browser | Dibatasi dengan `preventDefault()` |

## Event Umum

| Event | Kapan terjadi |
|-------|---------------|
| `click` | Klik mouse / tap |
| `keydown` / `keyup` | Tekan tombol keyboard |
| `input` | Nilai input berubah |
| `submit` | Form dikirim |
| `mouseenter` / `mouseleave` | Kursor masuk/keluar |
| `scroll` | Halaman/element di-scroll |
| `DOMContentLoaded` | HTML selesai di-parse |

## Event Object

```js
input.addEventListener("input", (e) => {
  console.log(e.target.value);  // nilai saat ini
});

document.addEventListener("keydown", (e) => {
  if (e.key === "Escape") tutupModal();
});
```

Properti penting `event`: `target` (elemen pemicu), `currentTarget` (elemen tempat listener dipasang), `key`/`code` (keyboard), `clientX`/`clientY` (mouse), `preventDefault()` (batal aksi bawaan), `stopPropagation()` (hentikan bubbling).

## Event Sering Dipakai Bersama Form

| Skenario | Event | Catatan |
|----------|-------|---------|
| Deteksi ketikan | `input` | Berubah tiap karakter |
| Submit Enter | `keydown` + `e.key === "Enter"` | Bukan menunggu klik tombol |
| Kirim form | `submit` + `preventDefault` | Wajib, kalau tidak reload |
| Validasi blur | `focusout` | Cek saat user meninggalkan field |
| Pilih opsi | `change` | Berubah setelah selesai memilih |

## Form Tanpa Reload

```js
form.addEventListener("submit", (e) => {
  e.preventDefault(); // cegah reload
  const data = new FormData(form);
  console.log(Object.fromEntries(data));
});
```

## Membatasi Perilaku Bawaan Browser

```js
link.addEventListener("click", (e) => {
  e.preventDefault();     // batal navigasi
  e.stopPropagation();    // berhenti menyebar ke induk
});
document.addEventListener("contextmenu", (e) => e.preventDefault()); // blokir klik kanan
window.addEventListener("scroll", () => { /* catat posisi */ }, { passive: true });
```

`preventDefault` membatalkan aksi bawaan (navigasi link, submit form, scroll momentum); `stopPropagation` menghentikan event menyebar — dua hal berbeda yang sering tertukar.

## Delegation (Satu Listener untuk Banyak Anak)

```js
list.addEventListener("click", (e) => {
  const item = e.target.closest("li");
  if (item) item.classList.toggle("selesai");
});
```

Listener di induk — anak baru yang ditambahkan nanti otomatis ikut terdeteksi.

## Di Dunia Nyata

- **Validasi form realtime**: event `input` mengecek format email tiap ketikan dan menampilkan error merah.
- **Modal tutup dengan Escape**: listener `keydown` global mengecek `e.key === "Escape"`.
- **Simpan otomatis (auto-save)**: `debounce` pada event `input` → PATCH ke server tiap 800ms jeda.
- **Drag & drop pindah kartu**: gabungan `mousedown`, `mousemove`, `mouseup` (atau API Drag and Drop).
- **Infinite scroll**: `scroll` + `IntersectionObserver` memicu muat halaman berikutnya.

<div class="note">💡 Event berbusa (*bubbling*): klik tombol di dalam kartu juga dianggap klik kartu. Itulah sebabnya delegation bekerja — dan sebabnya listener di induk kadang terpicu dua kali kalau kamu juga pasang di anak.</div>
