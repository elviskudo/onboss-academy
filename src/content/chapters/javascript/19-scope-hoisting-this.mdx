## Hoisting

```js
sapa(); // "Halo" — function declaration diangkat
function sapa() { console.log("Halo"); }

terbang(); // TypeError — function expression tidak
var terbang = function () {};
```

`var` diangkat dengan nilai `undefined`; `let`/`const` berada dalam TDZ sampai deklarasinya dijalankan.

```js
console.log(x); // undefined
var x = 1;

console.log(y); // ReferenceError
let y = 1;
```

## Nilai this Berdasarkan Cara Panggil

| Cara panggil | Nilai this (non-strict) |
|--------------|-------------------------|
| `fungsi()` | `window` / global |
| `obj.fungsi()` | `obj` |
| `fungsi.call(obj)` | `obj` |
| Arrow function | Leksikal (dari scope luar) |
| Event handler DOM | Elemen yang menerima event |

```js
const orang = {
  nama: "Sari",
  sapa() { return `Halo ${this.nama}`; },
  sapaPanah: () => `Halo ${this.nama}` // this bukan orang!
};
```

## Arrow Function dan this

```js
const timer = {
  count: 0,
  mulai() {
    setInterval(() => {
      this.count++; // ✅ menangkap this dari mulai()
    }, 1000);
  }
};
```

Sebelum arrow function, orang menulis `const self = this` atau `.bind(this)`. Kini arrow function menyelesaikan kasus callback dengan elegan — tapi **jangan** dipakai sebagai method objek yang membutuhkan `this` dinamis.

## call, apply, bind

```js
function perkenal(salam, tanda) {
  return `${salam}, ${this.nama}${tanda}`;
}
const sari = { nama: "Sari" };

perkenal.call(sari, "Halo", "!");       // argumen satu per satu
perkenal.apply(sari, ["Hai", "..."]);  // argumen array
const fn = perkenal.bind(sari);        // fungsi baru dengan this tetap
fn("Halo", "!");
```

## Closure

```js
function buatPenghitung() {
  let n = 0;
  return () => ++n;
}
const hitung = buatPenghitung();
hitung(); // 1
hitung(); // 2
```

Fungsi dalam tetap mengingat variabel dari scope luarnya meski fungsi luar sudah selesai dijalankan. Ini dasar dari state privat di JavaScript.

<div class="note">💡 Gunakan `"use strict";` di awal file atau modul ES (strict otomatis). Ini mengubah `this` fungsi biasa jadi `undefined` dan membuat bug typos lebih cepat terlihat.</div>

## Di Dunia Nyata

- Class method memakai `this` untuk mengakses instance.
- Callback `setTimeout`/array method sering memakai arrow function supaya `this` tidak hilang.
- Library seperti jQuery dulu memakai `.call()` untuk mengikat elemen DOM sebagai `this`.
