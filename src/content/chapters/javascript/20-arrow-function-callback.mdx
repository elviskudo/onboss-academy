Arrow function adalah sintaks ringkas untuk fungsi. Selain lebih pendek, ia membawa **perilaku `this` leksikal** yang sangat berguna untuk callback.

## Bentuk-Bentuk Arrow

```js
const tanpaArgumen = () => 42;
const satuArgumen  = x => x * 2;
const duaArgumen   = (a, b) => a + b;
const denganBlok   = (x) => {
  const y = x * 2;
  return y;
};
const objek        = id => ({ id, aktif: true });
```

Kalau langsung mengembalikan objek literal, bungkus dengan kurawal tambahan.

## Kapan Tetap Pakai Function Biasa

- Method objek yang butuh `this` dinamis.
- Constructor / class method.
- Ketika perlu `arguments` (arrow tidak memilikinya).
- Event handler yang ingin `this` = elemen DOM.

## Callback

```js
const angka = [1, 2, 3];
angka.forEach(n => console.log(n));
angka.map(n => n * 2);
angka.filter(n => n > 1);

function proses(data, callback) {
  const hasil = data.map(x => x * 2);
  callback(hasil);
}
proses([1, 2], hasil => console.log(hasil));
```

## Callback vs Promise

Callback bersarang mudah berubah menjadi *callback hell*:

```js
ambilUser(id, user => {
  ambilPesanan(user.id, pesanan => {
    ambilDetail(pesanan.id, detail => {
      console.log(detail);
    });
  });
});
```

Promise dan `async/await` (sudah kamu lihat di chapter 09) menggantikan pola ini dengan rantai yang lebih rapi. Callback tetap muncul di method seperti `forEach`, `map`, dan event listener.

## Event Loop Secara Singkat

```js
console.log("1");
setTimeout(() => console.log("3"), 0);
console.log("2");
// 1, 2, 3
```

`console.log` sinkron jalan dulu. Callback `setTimeout` masuk antrean task dan dijalankan setelah stack kosong meski delay-nya 0.

<div class="note">💡 Hindari arrow function untuk method pada objek literal: `nama: () => this.nama` akan mengambil `this` dari scope luar, bukan dari objeknya.</div>

## Di Dunia Nyata

- `array.map(x => ...)` adalah pemandangan sehari-hari di React.
- `useEffect(() => {...}, [])` memakai arrow sebagai callback.
- `setTimeout(() => ..., 300)` dipakai untuk debounce sederhana.
