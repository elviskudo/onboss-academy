Objek adalah kumpulan pasangan **kunci–nilai**. Ia adalah fondasi hampir semua struktur data di JavaScript, termasuk array dan fungsi (keduanya juga objek).

## Membuat Objek

```js
const pengguna = {
  nama: "Sari",
  umur: 20,
  aktif: true,
  alamat: { kota: "Bandung", kodepos: "40111" },
  hobi: ["membaca", "berenang"],
  sapa() {
    return `Halo, ${this.nama}`;
  }
};
```

## Mengakses Properti

```js
pengguna.nama          // dot notation
pengguna["nama"]       // bracket notation
const kunci = "umur";
pengguna[kunci]        // dinamis
pengguna?.alamat?.kota // aman kalau alamat bisa null
```

## Mengubah & Menambah

```js
pengguna.umur = 21;
pengguna.email = "sari@example.com";
delete pengguna.aktif;

const salinan = { ...pengguna, kota: "Jakarta" };
```

Spread operator menyalin pasangan kunci ke objek baru. Ini bukan deep clone.

## Destructuring

```js
const { nama, umur, alamat: { kota } } = pengguna;
const { nama: namaDepan, ...sisa } = pengguna;
```

Rest `...sisa` mengumpulkan properti yang tidak diambil.

```js
const [pertama, , ketiga] = ["a", "b", "c"]; // destructuring array
```

## Method Penting Object

```js
Object.keys(pengguna)      // ["nama", "umur", ...]
Object.values(pengguna)    // ["Sari", 20, ...]
Object.entries(pengguna)   // [["nama","Sari"], ...]
Object.hasOwn(pengguna, "nama") // true
Object.assign({}, a, b)    // gabungkan (mutasi argumen pertama)
Object.freeze(pengguna)    // cegah perubahan
```

## Perulangan

```js
for (const [kunci, nilai] of Object.entries(pengguna)) {
  console.log(kunci, nilai);
}
```

Jangan memakai `for...in` tanpa `hasOwn` — ia juga mengambil properti yang diwariskan dari prototype.

## JSON

```js
const teks = JSON.stringify(pengguna);
const kembali = JSON.parse(teks);
```

JSON tidak mengenal `undefined`, fungsi, atau `Date` khusus (Date menjadi string ISO). Saat `JSON.stringify` diberi fungsi replacer, kamu bisa mengontrol apa yang disimpan.

<div class="note">💡 Kunci objek selalu string atau Symbol. Menulis `{ 1: "satu" }` akan disimpan sebagai kunci `"1"`.</div>

## Di Dunia Nyata

- Response API hampir selalu objek/array of objects.
- State aplikasi (React, Vue) berupa objek yang diperbarui immutable dengan spread.
- Konfigurasi aplikasi disimpan sebagai objek lalu di-`destructure` saat dipakai.
