Event listener yang kamu lihat di chapter 08 baru permulaan. Memahami **alur event** memungkinkan teknik seperti delegation yang jauh lebih efisien.

## Alur Event

Saat kamu mengklik elemen, event melewati tiga fase:

1. **Capturing** — dari `window` turun ke elemen target.
2. **Target** — di elemen yang diklik.
3. **Bubbling** — naik lagi ke `window`.

```js
induk.addEventListener("click", () => console.log("induk"), true);  // capturing
anak.addEventListener("click", () => console.log("anak"));         // bubbling
```

Argumen ketiga `true` mengaktifkan capturing. Default-nya `false` (bubbling).

## Membatalkan Aksi

```js
link.addEventListener("click", e => {
  e.preventDefault();    // jangan ikuti href
  e.stopPropagation();   // jangan beri tahu induk
});
```

Keduanya berbeda: `preventDefault` membatalkan **perilaku browser**, `stopPropagation` menghentikan **penjalaran event**.

## Event Delegation

Daripada memasang listener di 1000 baris tabel, pasang satu di induknya:

```js
document.querySelector("#tabel").addEventListener("click", e => {
  const baris = e.target.closest("tr");
  if (!baris) return;
  console.log("Klik baris", baris.dataset.id);
});
```

`closest()` mencari leluhur terdekat yang cocok. Keuntungannya: elemen baru yang ditambahkan kemudian otomatis ikut ter-cover.

## Opsi addEventListener

```js
el.addEventListener("click", handler, {
  once: true,      // hanya sekali
  capture: false,  // fase bubbling
  passive: true,   // janji tidak memanggil preventDefault (scroll lebih halus)
  signal: controller.signal // bisa dihapus lewat AbortController
});
```

## Menghapus Listener

```js
const handler = () => console.log("klik");
el.addEventListener("click", handler);
el.removeEventListener("click", handler); // harus fungsi yang sama
```

Fungsi anonymous tidak bisa dihapus dengan `removeEventListener` karena referensinya berbeda.

## Event yang Sering Dipakai

| Kategori | Event |
|----------|-------|
| Mouse | `click`, `dblclick`, `mousedown`, `mouseup`, `mousemove` |
| Keyboard | `keydown`, `keyup`, `keypress` |
| Form | `submit`, `change`, `input`, `focus`, `blur` |
| Touch | `touchstart`, `touchmove`, `touchend` |
| Window | `resize`, `scroll`, `load` |

```js
input.addEventListener("input", e => {
  console.log(e.target.value); // jalan tiap ketikan
});
```

<div class="note">💡 `input` jalan setiap karakter, `change` hanya saat nilai di-commit (blur atau pilih opsi). Pilih yang sesuai kebutuhan.</div>

## Di Dunia Nyata

- Menu dropdown ditutup saat klik di luar dengan listener pada `document`.
- Form mencegah reload halaman lewat `submit` + `preventDefault()`.
- Daftar dinamis memakai delegation supaya tidak perlu pasang ulang listener.
