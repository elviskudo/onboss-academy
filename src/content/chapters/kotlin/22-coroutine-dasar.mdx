## Model Mental

```kotlin
import kotlinx.coroutines.*

fun main() = runBlocking {
    val jobs = List(3) { i ->
        launch(Dispatchers.Default) {
            delay(100L * i)
            println("Selesai $i di ${Thread.currentThread().name}")
        }
    }
    jobs.joinAll()

    val hasil = async { 6 * 7 }
    println("Hasil: ${hasil.await()}")
}
```

Coroutine adalah **thread ringan** yang dijadwalkan oleh Kotlin. Banyak coroutine bisa berbagi satu thread karena mereka menunda diri (suspend) alih-alih memblokir.

| Fungsi | Hasil | Kapan dipakai |
|---|---|---|
| `launch` | `Job` | efek samping tanpa nilai |
| `async` | `Deferred<T>` | butuh nilai lewat `await()` |
| `runBlocking` | `T` | menjembatani kode blocking |
| `coroutineScope` | `T` | mengelompokkan child coroutine |

## Dispatcher

| Dispatcher | Kegunaan |
|---|---|
| `Main` | UI di Android |
| `IO` | jaringan dan disk |
| `Default` | komputasi CPU |

## Suspend Function

```kotlin
suspend fun ambilData(): String {
    delay(500)   // tidak memblokir thread
    return "Data siap"
}
```

Fungsi `suspend` hanya bisa dipanggil dari coroutine atau fungsi suspend lain.

## Structuring dan Pembatalan

```kotlin
coroutineScope {
    val a = async { ambilA() }
    val b = async { ambilB() }
    println(a.await() + b.await())
}
```

Bila satu child gagal, scope membatalkan child lain secara otomatis (structured concurrency).

<div class="note">💡 Jangan memakai <code>Thread.sleep()</code> di dalam coroutine — itu memblokir thread. Gunakan <code>delay()</code> supaya thread bisa dipakai coroutine lain.</div>
