## Spesifikasi Singkat

```kotlin
data class Todo(val id: Int, val judul: String, var selesai: Boolean = false)

fun main() {
    val daftar = mutableListOf<Todo>()
    var id = 1

    while (true) {
        println("1. Tambah  2. Selesai  3. Lihat  4. Keluar")
        when (readLine()) {
            "1" -> {
                print("Judul: ")
                daftar += Todo(id++, readLine().orEmpty())
            }
            "2" -> daftar.firstOrNull { !it.selesai }?.selesai = true
            "3" -> daftar.forEach { println("${it.id}. ${it.judul} " + if (it.selesai) "[x]" else "[ ]") }
            "4" -> return
            else -> println("Pilihan tidak dikenal")
        }
    }
}
```

Aplikasi konsol ini harus bisa:

| Fitur | Konsep Kotlin |
|---|---|
| Menyimpan todo | `data class` + `mutableListOf` |
| Menambah todo | operator `+=` |
| Menandai selesai | `firstOrNull` + properti mutable |
| Menampilkan daftar | `forEach` + string template |
| Memilih menu | `when` |

## Model

```kotlin
data class Todo(
    val id: Int,
    val judul: String,
    var selesai: Boolean = false
)
```

`val` untuk id dan judul, `var` untuk status yang boleh berubah.

## Logika Utama

```kotlin
fun selesaikan(daftar: MutableList<Todo>, id: Int): Boolean {
    val todo = daftar.firstOrNull { it.id == id } ?: return false
    todo.selesai = true
    return true
}
```

`Elvis operator ?:` mengembalikan false lebih awal bila todo tidak ditemukan.

## Ringkasan

```kotlin
val selesai = daftar.count { it.selesai }
println("Selesai: $selesai dari ${daftar.size}")
```

Proyek kecil ini merangkum hampir semua dasar Kotlin: variabel, tipe, koleksi, lambda, when, perulangan, dan data class.
