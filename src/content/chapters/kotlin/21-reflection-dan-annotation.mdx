## KClass dan KProperty

```kotlin
import kotlin.reflect.full.memberProperties

data class Produk(val nama: String, val harga: Int)

annotation class Endpoint(val path: String)

@Endpoint("/produk")
class ProdukController

fun main() {
    val props = Produk::class.memberProperties.map { it.name }
    println(props) // [nama, harga]

    val ann = ProdukController::class.annotations
        .filterIsInstance<Endpoint>().firstOrNull()
    println(ann?.path)
}
```

```kotlin
val kelas = Produk::class
println(kelas.simpleName)        // Produk
println(kelas.memberProperties.map { it.name })
```

`::class` menghasilkan `KClass<*>`, pintu masuk ke reflection Kotlin.

## Membaca Anotasi

```kotlin
annotation class Route(val path: String, val method: String = "GET")

@Route("/users", method = "POST")
class BuatUser
```

Nilai anotasi bisa berupa konstanta, kelas, atauenum — bukan objek sembarangan.

## Batasan Reflection

| Aspek | Keterangan |
|---|---|
| Ukuran | `kotlin-reflect` menambah artefak ke aplikasi |
| Kinerja | lebih lambat daripada akses langsung |
| R8/ProGuard | nama bisa dihapus bila tidak di-keep |

Di Android, reflection sering dihindari dalam jalur kritis. Library seperti Room dan Moshi memakai kode yang di-generate saat kompilasi sebagai gantinya.

<div class="note">💡 Reflection sangat berguna untuk framework dan alat, tapi untuk kode aplikasi sehari-hari, function dan sealed class biasanya lebih jelas serta lebih aman terhadap obfuskasi.</div>
