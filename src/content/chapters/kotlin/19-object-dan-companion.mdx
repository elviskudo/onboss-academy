## Object Declaration

```kotlin
object Konfigurasi {
    const val APP_NAME = "OnBoss"
    var mode = "development"
}

class Pengguna private constructor(val nama: String) {
    companion object {
        fun dari(nama: String): Pengguna = Pengguna(nama.trim())
    }
}

fun main() {
    println(Konfigurasi.APP_NAME)
    println(Pengguna.dari("  Budi  ").nama)
}
```

```kotlin
object Database {
    val url = "jdbc:sqlite:app.db"
    fun konek() = println("Terhubung ke $url")
}
```

Tidak ada kata `class`. Instance dibuat otomatis sekali dan diakses lewat nama object.

## Companion Object

```kotlin
class MataUang private constructor(val kode: String) {
    companion object {
        val IDR = MataUang("IDR")
        val USD = MataUang("USD")

        fun dari(kode: String) = MataUang(kode.uppercase())
    }
}
```

Companion cocok untuk konstanta dan factory method. `const val` hanya bisa dipakai untuk tipe primitif dan String.

## Object Expression

```kotlin
val pendengar = object : OnClickListener {
    override fun onClick() = println("Klik!")
}
```

Bentuk ini membuat objek anonim yang langsung mengimplementasi antarmuka.

| Fitur | Jumlah instance | Dipakai untuk |
|---|---|---|
| `object` | satu | singleton, utilitas |
| `companion object` | satu per kelas | factory, konstanta kelas |
| `object : Tipe` | satu, anonim | callback sekali pakai |

<div class="note">💡 Sejak Kotlin 1.3, anggota companion bisa dipanggil langsung dari kelas bila diberi anotasi <code>@JvmStatic</code> — berguna untuk interop dengan Java.</div>
