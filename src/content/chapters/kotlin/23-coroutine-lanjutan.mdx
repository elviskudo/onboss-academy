## Cold vs Hot

```kotlin
import kotlinx.coroutines.*
import kotlinx.coroutines.flow.*

fun angka(): Flow<Int> = flow {
    for (i in 1..3) {
        delay(100)
        emit(i)
    }
}

fun main() = runBlocking {
    angka()
        .filter { it % 2 == 1 }
        .map { "Angka $it" }
        .collect { println(it) }
}
```

| Jenis | Mulai saat | Contoh |
|---|---|---|
| Cold | `collect` dipanggil | `flow { }` |
| Hot | dibuat, aktif terus | `StateFlow`, `SharedFlow` |

Cold flow membuat ulang sumber setiap kali dikonsumsi — cocok untuk operasi one-shot seperti request jaringan.

## Operator Flow

```kotlin
flowOf(1, 2, 3)
    .map { it * 10 }
    .filter { it > 10 }
    .collect { println(it) }
```

`map`, `filter`, `take`, dan `debounce` adalah operator menengah. `collect`, `first`, dan `toList` adalah operator terminal.

## StateFlow di ViewModel

```kotlin
class VM : ViewModel() {
    private val _uiState = MutableStateFlow("Muat")
    val uiState: StateFlow<String> = _uiState.asStateFlow()

    fun muat() {
        viewModelScope.launch {
            _uiState.value = ambilData()
        }
    }
}
```

`asStateFlow()` menyembunyikan sisi mutable dari pemanggil.

## Error Handling

```kotlin
flow { emit(1); throw IllegalStateException("Gagal") }
    .catch { e -> emit(-1) }
    .collect { println(it) }
```

Operator `catch` menangkap exception di upstream dan bisa menggantinya dengan nilai fallback.

<div class="note">💡 Context pada Flow tetap mengikuti pemanggilnya. Gunakan <code>flowOn(Dispatchers.IO)</code> untuk memindahkan bagian produksi tanpa mengubah tempat <code>collect</code> dijalankan.</div>
