## For-in

```kotlin
fun main() {
    for (i in 1..5) print(i)          // 12345
    println()
    for (i in 10 downTo 1 step 2) print(i) // 108642
    println()

    var hitung = 3
    while (hitung > 0) {
        print(hitung--)
    }
}
```

```kotlin
for (angka in 1..5) {
    println(angka)
}

val nama = listOf("Budi", "Sari")
for (n in nama) println(n)
```

Setiap iterasi membuat variabel `n` yang hanya berlaku di dalam blok.

## Range

| Penulisan | Hasil |
|---|---|
| `1..5` | 1, 2, 3, 4, 5 |
| `1 until 5` | 1, 2, 3, 4 |
| `5 downTo 1` | 5, 4, 3, 2, 1 |
| `1..10 step 3` | 1, 4, 7, 10 |

Range juga berlaku untuk `Char`: `'a'..'d'` menghasilkan a, b, c, d.

## While dan Do-While

```kotlin
var energi = 3
while (energi > 0) {
    println("Energi: $energi")
    energi--
}

do {
    println("Pasti tampil minimal sekali")
} while (energi > 0)
```

## Repeat dan Indeks

```kotlin
repeat(3) { println("Halo ke-${it + 1}") }

for ((indeks, nilai) in nama.withIndex()) {
    println("$indeks -> $nilai")
}
```

`it` adalah nama otomatis untuk parameter lambda tunggal.

<div class="note">💡 Hati-hati dengan <code>while (true)</code> tanpa kondisi keluar. Pastikan ada <code>break</code>, <code>return</code>, atau perubahan variabel yang pada akhirnya membuat kondisi menjadi false.</div>
