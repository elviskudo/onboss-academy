| Anotasi / Fungsi | Fungsi |
|---|---|
| `@Serializable` | menandai kelas untuk diserialisasi |
| `@SerialName` | mengganti nama kunci JSON |
| `Json.encodeToString` | objek → string JSON |
| `Json.decodeFromString` | string JSON → objek |

## Menyiapkan Proyek

```kotlin
import kotlinx.serialization.*
import kotlinx.serialization.json.*

@Serializable
data class Siswa(val nama: String, val nilai: Int, val aktif: Boolean = true)

fun main() {
    val s = Siswa("Budi", 88)
    val json = Json.encodeToString(s)
    println(json)

    val balik = Json.decodeFromString<Siswa>(json)
    println(balik)
}
```

```kotlin
plugins {
    kotlin("jvm") version "1.9.24"
    kotlin("plugin.serialization") version "1.9.24"
}

dependencies {
    implementation("org.jetbrains.kotlinx:kotlinx-serialization-json:1.6.3")
}
```

## Data Class + @Serializable

```kotlin
@Serializable
data class Produk(
    val id: Int,
    @SerialName("nama_produk") val nama: String,
    val harga: Double,
    val tags: List<String> = emptyList()
)
```

Nilai default membuat field opsional saat proses decode.

## Encode dan Decode

```kotlin
val json = Json { prettyPrint = true; ignoreUnknownKeys = true }

val teks = json.encodeToString(Produk(1, "Kopi", 18000.0))
val objek = json.decodeFromString<Produk>(teks)
```

`ignoreUnknownKeys = true` membuat field baru dari server tidak menyebabkan error.

## Sealed Class dan Polymorphism

```kotlin
@Serializable
sealed class Hasil {
    @Serializable data class Sukses(val data: String) : Hasil()
    @Serializable data class Gagal(val pesan: String) : Hasil()
}
```

Serializer untuk sealed class otomatis menyertakan informasi tipe.

<div class="note">💡 kotlinx.serialization bekerja tanpa reflection, sehingga ukuran aplikasi lebih kecil dan aman saat R8/ProGuard menghapus nama kelas.</div>
