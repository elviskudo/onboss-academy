## When Sederhana

```kotlin
fun kategori(usia: Int): String = when {
    usia < 13 -> "Anak"
    usia in 13..17 -> "Remaja"
    usia in 18..59 -> "Dewasa"
    else -> "Lansia"
}

fun main() {
    println(kategori(15))  // Remaja
    println(kategori(42))  // Dewasa
}
```

```kotlin
when (hari) {
    "Senin" -> println("Awal pekan")
    "Jumat" -> println("Hampir libur")
    else -> println("Hari biasa")
}
```

Tidak seperti `switch` di banyak bahasa, Kotlin tidak memerlukan `break` — hanya satu cabang yang dijalankan.

## When sebagai Ekspresi

```kotlin
val pesan = when (skor) {
    in 90..100 -> "Luar biasa"
    in 70..89 -> "Baik"
    else -> "Perlu belajar lagi"
}
```

Bila dipakai sebagai ekspresi, semua cabang harus menghasilkan tipe yang sama dan `else` biasanya wajib ada.

## Pencocokan Lanjutan

```kotlin
when {
    x > 0 && y > 0 -> println("Kuadran I")
    x < 0 -> println("Kuadran kiri")
    else -> println("Di sumbu")
}
```

Bentuk tanpa argumen ini mengevaluasi setiap kondisi boolean dari atas — mirip rantai `if/else if`.

| Fitur | Contoh |
|---|---|
| Beberapa nilai | `1, 3, 5 -> "ganjil kecil"` |
| Rentang | `in 10..20 -> "sedang"` |
| Tipe | `is String -> panjang` |
| Fungsi | `isValid(x) -> "valid"` |

<div class="note">💡 when dengan sealed class sangat kuat: compiler bisa membuktikan semua subtypes sudah ditangani, sehingga <code>else</code> tidak diperlukan.</div>
