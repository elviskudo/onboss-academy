## Grouping dan Agregasi

```kotlin
data class Siswa(val nama: String, val kelas: String, val nilai: Int)

fun main() {
    val siswa = listOf(
        Siswa("Budi", "A", 85),
        Siswa("Sari", "B", 92),
        Siswa("Andi", "A", 78)
    )

    println(siswa.groupBy { it.kelas })
    println(siswa.sortedByDescending { it.nilai }.map { it.nama })
}
```

```kotlin
val nilaiPerKelas = siswa.groupBy { it.kelas }
// {A=[Budi, Andi], B=[Sari]}

val rataPerKelas = siswa.groupBy { it.kelas }
    .mapValues { (_, daftar) -> daftar.map { it.nilai }.average() }
```

## Sorting

| Fungsi | Kegunaan |
|---|---|
| `sorted()` | urutan natural |
| `sortedBy { }` | berdasarkan kunci |
| `sortedDescending()` | urutan natural terbalik |
| `sortedByDescending { }` | kunci terbalik |

Pengurutan menghasilkan list baru — list asli tidak berubah.

## Partition dan Chunked

```kotlin
val (lulus, gagal) = siswa.partition { it.nilai >= 75 }
val kelompok = (1..7).chunked(3) // [[1,2,3],[4,5,6],[7]]
```

`partition` memisahkan jadi dua list; `chunked` memotong menjadi grup berukuran tetap.

## Sequence untuk Data Besar

```kotlin
val hasil = (1..1_000_000)
    .asSequence()
    .filter { it % 2 == 0 }
    .map { it * it }
    .take(5)
    .toList()
```

Tanpa `asSequence`, semua satu juta angka akan diproses di setiap tahap. Dengan Sequence, proses berhenti setelah lima hasil ditemukan.

<div class="note">💡 Sequence hemat memori tetapi tidak bisa diakses dengan indeks dan hanya bisa dikonsumsi sekali. Konversi ke List dengan <code>toList()</code> bila perlu dipakai berulang.</div>
