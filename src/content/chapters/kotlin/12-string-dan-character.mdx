## String Biasa dan Template

```kotlin
fun main() {
    val nama = "OnBoss"
    println("Halo, $nama!")
    println("Panjang: ${nama.length}")

    val teks = """
        Baris pertama
        Baris kedua
    """.trimIndent()
    println(teks)

    println(nama.uppercase())
    println(nama.replace("Boss", "Siswa"))
}
```

```kotlin
val kota = "Bandung"
println("Saya tinggal di $kota")
println("Panjangnya ${kota.length} karakter")
```

Bentuk `${...}` dipakai untuk ekspresi yang lebih panjang dari sekadar nama variabel.

## Raw String

```kotlin
val sql = """
  SELECT * FROM users
  WHERE aktif = true
""".trimIndent()
```

Tiga tanda kutip menghasilkan teks multiline tanpa perlu `\n`. `trimIndent()` menghapus indentasi umum di awal setiap baris.

## Metode yang Sering Dipakai

| Metode | Fungsi | Contoh |
|---|---|---|
| `length` | jumlah karakter | `"abc".length` → 3 |
| `uppercase()` / `lowercase()` | mengubah huruf | `"Kotlin".lowercase()` |
| `trim()` | membuang spasi tepi | `"  hai  ".trim()` |
| `replace()` | mengganti teks | `"a-b".replace("-", "/")` |
| `split()` | memecah jadi list | `"a,b".split(",")` |
| `contains()` | mengecek keberadaan | `"kotlin".contains("lin")` |

## Char dan Escape

```kotlin
val huruf = 'A'
val tab = '\t'
val garisBaru = '\n'
```

`Char` selalu satu karakter dan ditulis dengan tanda kutip tunggal.

<div class="note">💡 String di Kotlin bersifat immutable. Metode seperti <code>uppercase()</code> mengembalikan string baru — hasilnya harus ditampung bila ingin dipakai.</div>
