| Fitur | Contoh | Manfaat |
|---|---|---|
| Default parameter | `fun sapa(nama: String = "Teman")` | mengurangi overload |
| Named argument | `sapa(nama = "Budi")` | urutan tidak kaku |
| `vararg` | `fun jumlah(vararg x: Int)` | argumen jumlah bebas |
| Expression body | `fun kuadrat(x: Int) = x * x` | fungsi pendek tanpa `return` |

## Parameter Default

```kotlin
fun sapa(nama: String = "Teman", sapaan: String = "Halo"): String {
    return "$sapaan, $nama!"
}

fun jumlah(vararg angka: Int): Int = angka.sum()

fun main() {
    println(sapa())
    println(sapa(sapaan = "Selamat pagi", nama = "Sari"))
    println(jumlah(1, 2, 3, 4))
}
```

```kotlin
fun sapa(nama: String = "Teman") = "Halo, $nama!"

sapa()          // Halo, Teman!
sapa("Budi")    // Halo, Budi!
```

Default parameter menggantikan pola overload yang berulang di Java.

## Named Argument

```kotlin
formatTanggal(hari = 12, bulan = "Mei", tahun = 2026)
```

Named argument membuat kode lebih jelas, terutama saat fungsi memiliki beberapa parameter bertipe sama.

## Vararg

```kotlin
fun rataRata(vararg nilai: Double): Double {
    return if (nilai.isEmpty()) 0.0 else nilai.sum() / nilai.size
}
```

Di dalam fungsi, `vararg` menjadi array. Untuk meneruskan array yang sudah ada, gunakan operator spread `*array`.

## Expression Body

```kotlin
fun kuadrat(x: Int) = x * x
fun dewasa(usia: Int): Boolean = usia >= 18
```

Bila hasil bisa ditulis dalam satu ekspresi, kurung kurawal tidak diperlukan.

## Local Function

```kotlin
function utama() {
    fun bantu(x: Int) = x * 2
    println(bantu(5))
}
```

Fungsi lokal berguna untuk logik pembantu yang hanya dipakai di satu tempat.

<div class="note">💡 Utamakan expression body untuk fungsi pendek. Kode jadi lebih padat dan mengurangi kemungkinan lupa menulis <code>return</code>.</div>
