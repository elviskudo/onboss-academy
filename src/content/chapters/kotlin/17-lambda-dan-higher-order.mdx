## Fungsi sebagai Nilai

```kotlin
fun main() {
    val angka = listOf(1, 2, 3, 4, 5)

    val genap = angka.filter { it % 2 == 0 }
    val kuadrat = angka.map { it * it }
    val total = angka.fold(0) { akumulasi, nilai -> akumulasi + nilai }

    println(genap)    // [2, 4]
    println(kuadrat)  // [1, 4, 9, 16, 25]
    println(total)    // 15
}
```

```kotlin
val kaliDua: (Int) -> Int = { x -> x * 2 }
println(kaliDua(5)) // 10
```

Tipe fungsi ditulis `(Parameter) -> Return`. Lambda adalah cara ringkas menulis fungsi anonim.

## Parameter Terakhir

```kotlin
angka.filter { it > 3 }
```

Bila lambda adalah parameter terakhir, ia boleh ditulis di luar tanda kurung. Ini gaya yang sangat umum di Kotlin.

## Operator Koleksi

| Fungsi | Fungsi | Contoh hasil |
|---|---|---|
| `filter` | memilih elemen | `[2, 4]` |
| `map` | mengubah tiap elemen | `[2, 4, 6]` |
| `find` | elemen pertama yang cocok | `2` atau null |
| `any` | apakah ada yang cocok | `true` |
| `all` | apakah semua cocok | `false` |
| `fold` | mengakumulasi | `15` |

## Lambda dengan Dua Parameter

```kotlin
val total = listOf(1, 2, 3).fold(0) { akumulasi, nilai ->
    akumulasi + nilai
}
```

Saat ada dua parameter, `it` tidak tersedia — keduanya harus diberi nama.

<div class="note">💡 Rantai <code>map</code> dan <code>filter</code> bersifat lazy pada <code>Sequence</code>, tetapi eager pada <code>List</code>. Untuk data besar, <code>asSequence()</code> bisa mengurangi alokasi sementara.</div>
