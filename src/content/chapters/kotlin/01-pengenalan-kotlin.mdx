Kotlin adalah bahasa statis yang dirancang agar ringkas tanpa kehilangan keamanan tipe — dan sepenuhnya kompatibel dengan ekosistem Java.

## Hello World

```kotlin
fun main() {
    println("Halo, Dunia!")
}
```

Kurung kurawal menandai blok, titik koma opsional, dan `fun` menandai deklarasi function. Lima istilah yang baru saja kamu lihat:

| Istilah | Peran | Contoh |
| --- | --- | --- |
| `fun` | penanda deklarasi function | `fun main()` |
| `main` | titik masuk program | dipanggil otomatis saat program mulai |
| `val` | variabel baca-saja | `val nama = "OnBoss"` |
| `println` | mencetak satu baris | `println("Halo")` |
| `$nama` | string template | menyisipkan nilai ke teks |

## Kenapa Kotlin?

- **Ringkas**: banyak pola Java berkurang separuh di Kotlin
- **Aman terhadap null**: tipe nullable dinyatakan eksplisit
- **Interop**: memanggil library Java tanpa wrapper
- **Modern**: default parameter, data class, extension

## Fakta Singkat

| Fakta | Isi |
| --- | --- |
| Pembuat | JetBrains (dirilis 2011); resmi untuk Android sejak 2019 |
| Sifat bahasa | Statis, null-safe, ringkas |
| Target kompilasi | JVM bytecode, JavaScript, dan Kotlin/Native |
| Ekstensi file | `.kt` untuk sumber, `.kts` untuk script |
| Kompatibilitas | Library Java bisa dipanggil langsung tanpa wrapper |

## Perbandingan Singkat dengan Java

```kotlin
// Java: deklarasi variabel panjang
// String nama = "Sari";

// Kotlin: satu baris, tipe ditebak
val nama = "Sari"
println(nama)
```

| Java | Kotlin | Catatan |
| --- | --- | --- |
| `String nama = "Sari";` | `val nama = "Sari"` | tipe ditebak otomatis |
| `public static void main(String[] a)` | `fun main()` | argumen boleh dihilangkan |
| getter/setter manual | properti `val`/`var` | pembaca-penulis dibuat compiler |
| `equals()` manual | `data class` menghasilkan `equals` | perbandingan per isi, bukan per referensi |

```bash

```

## fun main dengan Argumen

```kotlin
fun main(args: Array<String>) {
    println("Jumlah argumen: " + args.size)
}
```

`args` berisi parameter baris perintah bila program dipanggil dengan opsi.

## Di Dunia Nyata

- **Aplikasi Android baru** — Android Studio membuat proyek Kotlin secara bawaan; hampir semua contoh resmi Google sekarang ditulis Kotlin.
- **Layanan backend** — framework Ktor dibangun sepenuhnya di Kotlin, dan Spring mendukung Kotlin sebagai bahasa pertama.
- **Migrasi bertahap** — tim dengan basis kode Java besar memindahkan file satu per satu; keduanya berjalan di JVM yang sama sehingga bisa bercampur.
- **Konfigurasi build** — Gradle Kotlin DSL menulis script build memakai Kotlin alih-alih Groovy.
- **Script otomasi** — file `.kts` berjalan tanpa struktur proyek, cocok untuk tugas kecil seperti konversi data.

<div class="note">💡 Kotlin membedakan val (tidak bisa diubah) dan var (bisa diubah). Mulailah dengan val — variabel yang tidak bisa diubah menghilangkan banyak bug sejak awal.</div>
