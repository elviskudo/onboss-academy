## Arah Kotlin → Java

```kotlin
class Api @JvmOverloads constructor(
    val baseUrl: String,
    val timeout: Int = 30
) {
    companion object {
        @JvmStatic fun buat() = Api("https://api.onboss.test")
    }

    @JvmName("getNamaUser")
    fun namaUser(id: Int): String = "User-$id"
}
```

Kotlin menghasilkan bytecode yang bisa dipakai Java, tetapi beberapa fitur perlu bantuan anotasi:

| Fitur Kotlin | Anotasi | Alasan |
|---|---|---|
| Companion function | `@JvmStatic` | dipanggil seperti static method |
| Default parameter | `@JvmOverloads` | menghasilkan overload untuk Java |
| Properti | `@JvmField` | field langsung, tanpa getter |
| Nama fungsi | `@JvmName` | menghindari name mangling |

## Arah Java → Kotlin

```kotlin
val daftar: List<String> = javaUtil.getNames()
```

Tipe dari Java disebut **platform type** (`String!`). Kotlin tidak tahu apakah boleh null, jadi terserah kamu:

```kotlin
val aman = javaUtil.getNama()?.trim()   // perlakukan nullable
val yakin = javaUtil.getNama()!!.trim() // pastikan tidak null
```

## SAM Conversion

```kotlin
button.setOnClickListener { println("Klik") }
```

Antarmuka Java dengan satu abstract method (SAM) bisa ditulis sebagai lambda di Kotlin.

<div class="note">💡 Saat migrasi bertahap, simpan model dan API di Kotlin, lalu biarkan file Java lama memanggilnya. Compilation bersama JVM memastikan keduanya tetap sinkron.</div>
