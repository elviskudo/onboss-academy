## Kelas Generik

```kotlin
class Kotak<out T>(val isi: T) {
    fun lihat(): T = isi
}

class Penerima<in T> {
    fun terima(nilai: T) = println("Menerima $nilai")
}

fun <T : Number> duaKali(nilai: T): Double = nilai.toDouble() * 2

fun main() {
    val angka: Kotak<Int> = Kotak(5)
    val umum: Kotak<Number> = angka       // aman karena out
    println(duaKali(7))
}
```

```kotlin
class Kotak<T>(val isi: T)

val k1 = Kotak<String>("Halo")
val k2 = Kotak<Int>(42)
```

Tipe ditebak dari argumen sehingga sering tidak perlu ditulis eksplisit.

## Constraint

```kotlin
fun <T : CharSequence> panjang(x: T): Int = x.length
```

`T : CharSequence` berarti argumen harus memiliki metode `length`. Bisa juga beberapa bound dengan klausa `where`.

## Variance

| Kata | Arti | Contoh |
|---|---|---|
| `out T` | hanya menghasilkan T | `Producer<out T>` |
| `in T` | hanya menerima T | `Consumer<in T>` |
| tanpa kata | invariant | `MutableList<T>` |

Aturan ini mencegah kasus berbahaya seperti memasukkan `String` ke `MutableList<Int>` yang sedang dilihat sebagai `MutableList<Any>`.

## Star Projection

```kotlin
fun tampilkan(list: List<*>) {
    for (item in list) println(item)
}
```

`*` berarti "tipe apa pun", mirip `<?>` di Java.

<div class="note">💡 Ingat pepatah: **producer out, consumer in**. Bila kelas hanya mengembalikan T, tandai `out`; bila hanya menerima T, tandai `in`.</div>
