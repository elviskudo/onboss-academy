## Empat Jenis Koleksi

```kotlin
fun main() {
    val angka = listOf(3, 1, 2, 1)
    println(angka.sorted())       // [1, 1, 2, 3]
    println(angka.distinct())     // [3, 1, 2]

    val unik = setOf("a", "b", "a")
    println(unik)                 // [a, b]

    val nilai = mapOf("Budi" to 85, "Sari" to 92)
    println(nilai["Sari"])        // 92
}
```

| Jenis | Urutan | Duplikat | Fungsi pembuat |
|---|---|---|---|
| `List` | ya | ya | `listOf()` |
| `Set` | tidak dijamin | tidak | `setOf()` |
| `Map` | kunci → nilai | kunci unik | `mapOf()` |
| `Array` | ya, ukuran tetap | ya | `arrayOf()` |

## Read-only versus Mutable

```kotlin
val tetap = listOf(1, 2, 3)
// tetap.add(4)  // error saat kompilasi

val ubah = mutableListOf(1, 2, 3)
ubah.add(4)
ubah[0] = 9
```

Perlu dicatat: `val` berarti referensi tidak bisa diganti, bukan isi koleksi tidak bisa berubah. `listOf` benar-benar tidak menyediakan metode mutasi.

## Map

```kotlin
val harga = mapOf("kopi" to 18000, "teh" to 12000)
println(harga["kopi"])
println(harga.getOrDefault("susu", 0))
```

`to` adalah infix function yang membuat pasangan `Pair`.

## Operasi Umum

```kotlin
val angka = listOf(5, 2, 8, 1)
println(angka.maxOrNull())  // 8
println(angka.sum())        // 16
println(angka.filter { it > 3 }) // [5, 8]
println(angka.map { it * 2 })     // [10, 4, 16, 2]
```

<div class="note">💡 Utamakan <code>List</code> daripada <code>Array</code> untuk data sehari-hari. List punya banyak operator (filter, map, sorted) dan ukurannya bisa berubah bila memakai versi mutable.</div>
