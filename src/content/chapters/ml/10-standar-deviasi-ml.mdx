## Varians

Varians adalah rata-rata kuadrat selisih terhadap mean.

```python
data = [10, 12, 14]
mean = sum(data) / len(data)
var = sum((x - mean) ** 2 for x in data) / (len(data) - 1)
print(var)
```

Kuadrat dipakai agar selisih negatif tidak saling menghilangkan.

## Standar Deviasi

```python
std = var ** 0.5
print(std)
```

Karena di-akar, std kembali ke satuan asli — lebih mudah dijelaskan daripada varians.

## Populasi versus Sampel

| Fungsi Python | Pembagi | Dipakai untuk |
| --- | --- | --- |
| `statistics.pvariance` | n | seluruh populasi |
| `statistics.variance` | n − 1 | sampel |

## Kaitan dengan Model

Algoritma berbasis jarak seperti KNN sensitif terhadap skala. Fitur `gaji` (jutaan) akan mendominasi `umur` (puluhan) bila tidak dinormalisasi.

<div class="note">💡 Cek standar deviasi tiap fitur sebelum melatih model. Fitur dengan std nol tidak memberi informasi dan bisa dibuang.</div>
