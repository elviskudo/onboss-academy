## Cara Kerja

Untuk satu titik baru, cari `k` titik latih terdekat, lalu ambil mayoritas kelas (klasifikasi) atau rata-rata (regresi).

## Jarak Euclidean

```python
import math

def euclid(a, b):
    return math.sqrt(sum((x - y) ** 2 for x, y in zip(a, b)))

print(euclid((1, 2), (4, 6)))  # 5.0
```

## Memilih k

| k | Efek |
| --- | --- |
| 1 | sangat fleksibel, sensitif noise |
| 3–7 | umumnya stabil |
| besar | terlalu halus, bisa underfitting |

Gunakan ganjil untuk klasifikasi biner agar tidak seri.

## Contoh Voting

```python
tetangga = ["A", "A", "B"]
prediksi = max(set(tetangga), key=tetangga.count)
print(prediksi)  # A
```

<div class="note">💡 Scaling adalah bagian dari KNN, bukan opsi. Tanpa itu, fitur dengan angka besar akan mendominasi jarak.</div>
