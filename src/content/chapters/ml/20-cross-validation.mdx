## Ide K-Fold

Data dibagi `k` bagian. model dilatih `k` kali, setiap kali menyisakan satu bagian sebagai uji. Rata-rata skor lebih stabil daripada satu kali split.

```python
def kfold(data, k=5):
    n = len(data)
    for i in range(k):
        uji = data[i*n//k:(i+1)*n//k]
        latih = data[:i*n//k] + data[(i+1)*n//k:]
        yield latih, uji

for latih, uji in kfold(list(range(10))):
    print("uji", uji, "latih", latih)
```

## Varian

| Varian | Cocok untuk |
| --- | --- |
| K-fold | regresi, klasifikasi umum |
| Stratified | kelas tidak seimbang |
| Leave-one-out | data sangat kecil |
| Time-series | data berurutan waktu |

## Trade-off

k besar → estimasi lebih stabil, tapi waktu latih lebih lama. k = 5 atau 10 adalah pilihan umum.

<div class="note">💡 Lakukan scaling dan feature selection **di dalam** tiap fold. Kalau dilakukan sebelum split, informasi uji bocor ke latih.</div>
