## Min-Max

```python
def minmax(data):
    lo, hi = min(data), max(data)
    return [(x - lo) / (hi - lo) if hi != lo else 0 for x in data]

print(minmax([10, 20, 30]))  # [0.0, 0.5, 1.0]
```

## Standardisasi

```python
def zscore(data):
    m = sum(data) / len(data)
    s = (sum((x - m) ** 2 for x in data) / len(data)) ** 0.5
    return [(x - m) / s if s else 0 for x in data]
```

Hasilnya berarti rata-rata 0 dan standar deviasi 1.

## Kapan Diperlukan

| Model | Scaling |
| --- | --- |
| KNN, SVM, k-means | wajib |
| Regresi linear | disarankan |
| Decision tree, random forest | tidak perlu |

## Urutan yang Benar

1. Bagi data latih dan uji.
2. Hitung min/mean/std **hanya dari latih**.
3. Terapkan transformasi ke latih dan uji.

<div class="note">💡 Menghitung rata-rata dari seluruh data sebelum split adalah kebocoran halus: informasi data uji ikut masuk ke proses latih.</div>
