## Bentuk Distribusi

Distribusi normal simetris di sekitar mean. Mean, median, dan modus berada di titik yang sama.

```python
def z(x, mean, std):
    return (x - mean) / std

print(z(60, 50, 10))  # 1.0
print(z(30, 50, 10))  # -2.0
```

## Aturan Empiris

| Rentang | Persentase perkiraan |
| --- | --- |
| mean ± 1 std | 68% |
| mean ± 2 std | 95% |
| mean ± 3 std | 99.7% |

## Kenapa Penting di ML

Beberapa metode statistik dan model linear mengasumsikan error berdistribusi normal. Ini lebih masuk akal untuk **residual**, bukan selalu untuk data mentah.

<div class="note">💡 Jangan memaksa data menjadi normal hanya karena "aturan". Gunakan plot dan uji asumsi, atau pilih model yang tidak bergantung pada asumsi tersebut.</div>
