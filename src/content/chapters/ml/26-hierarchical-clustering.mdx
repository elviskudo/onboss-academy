## Cara Kerja

| Langkah | Aksi |
| --- | --- |
| 1 | tiap titik = satu klaster |
| 2 | cari dua klaster terdekat |
| 3 | gabung |
| 4 | ulangi sampai satu klaster |

## Linkage

| Metode | Arti |
| --- | --- |
| Single | jarak minimum |
| Complete | jarak maksimum |
| Average | rata-rata jarak |
| Ward | minimalkan varians gabungan |

## Memilih Jumlah Klaster

Potong dendrogram pada tinggi tertentu. Makin rendah potongan, makin banyak klaster.

## Perbandingan

| Aspek | K-Means | Hierarki |
| --- | --- | --- |
| k di awal | wajib | tidak wajib |
| Skalabilitas | lebih baik | terbatas |
| Visual | scatter | dendrogram |

<div class="note">💡 Untuk data ribuan titik, k-means biasanya lebih praktis. Hierarki bersinar saat data kecil dan kamu ingin memahami struktur bertingkat.</div>
