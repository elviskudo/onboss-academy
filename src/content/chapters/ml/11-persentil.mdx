## Definisi

Persentil membagi data menjadi 100 bagian. Kuartil membagi menjadi 4 bagian, desil menjadi 10 bagian.

```python
import statistics

data = [10, 12, 14, 16, 18, 20]
q1, q2, q3 = statistics.quantiles(data, n=4)
print(q1, q2, q3)
```

## IQR

```python
iqr = q3 - q1
bawah = q1 - 1.5 * iqr
atas = q3 + 1.5 * iqr
outlier = [x for x in data if x < bawah or x > atas]
print(outlier)
```

## Membaca Posisi

| Informasi | Arti |
| --- | --- |
| P50 | median |
| P95 | 95% data lebih rendah |
| P99 | sering dipakai untuk latensi aplikasi |

<div class="note">💡 Dalam analisis performa, P95 lebih informatif daripada rata-rata: ia menggambarkan pengalaman pengguna yang paling lambat.</div>
