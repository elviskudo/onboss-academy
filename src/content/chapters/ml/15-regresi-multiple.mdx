## Persamaan

```text
y = b0 + b1·x1 + b2·x2 + ... + error
```

Contoh prediksi harga rumah memakai luas, jumlah kamar, dan jarak ke pusat kota.

## Hitung Manual Sederhana

```python
b0, b1, b2 = 2, 3, 5
x1, x2 = 2, 4
y = b0 + b1*x1 + b2*x2
print(y)  # 28
```

## Interpretasi Koefisien

Dengan model di atas, menambah `x1` satu unit menaikkan prediksi 3 — **selama x2 tetap**. Kalau x1 dan x2 bergerak bersama, interpretasi ini tidak bisa dipercaya.

## Multikolinearitas

| Gejala | Penanganan |
| --- | --- |
| Dua fitur korelasi > 0.9 | buang salah satu |
| Koefisien berubah drastis | gabungkan fitur / regularisasi |
| Tanda koefisien aneh | cek skalanya |

<div class="note">💡 scaling fitur penting pada regresi multiple agar koefisien bisa dibandingkan dan optimasi numerik stabil.</div>
