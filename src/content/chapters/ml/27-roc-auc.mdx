## TPR dan FPR

```text
TPR = TP / (TP + FN)   → recall
FPR = FP / (FP + TN)
```

Dengan menggeser threshold dari 0 sampai 1, kita mendapat banyak pasangan (FPR, TPR) lalu menghubungkannya.

## Contoh Geser Threshold

```python
skor = [0.9, 0.7, 0.4, 0.2]
label = [1, 1, 0, 0]

for ambang in [0.8, 0.5, 0.3]:
    pred = [1 if s >= ambang else 0 for s in skor]
    tp = sum(1 for p, y in zip(pred, label) if p == 1 and y == 1)
    fp = sum(1 for p, y in zip(pred, label) if p == 1 and y == 0)
    print(ambang, tp, fp)
```

## Arti AUC

| AUC | Interpretasi |
| --- | --- |
| 0.9–1.0 | sangat baik |
| 0.7–0.9 | baik |
| 0.5–0.7 | lemah |
| 0.5 | acak |

<div class="note">💡 AUC tidak menggambarkan kalibrasi probabilitas. Model bisa punya AUC tinggi tetapi probabilitasnya perlu dikalibrasi sebelum dipakai sebagai keyakinan.</div>
