## Kapan Dipakai

Kalau scatter plot membentuk lengkung, garis lurus akan underfitting. Regresi polinomial menambah fitur pangkat sehingga model bisa membengkok.

```python
def fitur_polinomial(x, derajat=2):
    return [x ** i for i in range(1, derajat + 1)]

print(fitur_polinomial(3, 3))  # [3, 9, 27]
```

## Derajat dan Fleksibilitas

| Derajat | Bentuk | Risiko |
| --- | --- | --- |
| 1 | garis | underfitting pada data lengkung |
| 2–3 | lengkung sedang | sering pas |
| ≥ 5 | sangat berliku | overfitting |

## Evaluasi

Bandingkan error pada data latih **dan** data uji. Kalau error latih turun tetapi error uji naik, derajat sudah terlalu tinggi.

<div class="note">💡 Derajat tinggi ditambah sedikit data adalah resep klasik overfitting. Model tampak sempurna di latih, tapi gagal di dunia nyata.</div>
