## Gini Sederhana

```python
def gini(labels):
    n = len(labels)
    if n == 0:
        return 0
    return 1 - sum((labels.count(c) / n) ** 2 for c in set(labels))

print(gini([0, 0, 0]))      # 0, murni
print(gini([0, 1, 0, 1]))   # 0.5, campuran
```

Pemisahan dipilih yang menurunkan Gini paling besar.

## Kedalaman

Batasi `max_depth`, `min_samples_leaf`, atau gunakan pruning. Pohon yang terlalu dalam mengikuti noise.

## Kapan Cocok

- Aturan bisnis yang perlu dijelaskan ke manusia.
- Data tabular dengan hubungan non-linear.
- Sebagai baseline sebelum model kompleks.

<div class="note">💡 Satu pohon sering tidak stabil: mengubah sedikit data bisa mengubah struktur. Random forest mengatasi ini dengan menggabungkan banyak pohon.</div>
