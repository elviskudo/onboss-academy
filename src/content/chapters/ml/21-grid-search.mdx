## Parameter vs Hyperparameter

| Jenis | Contoh | Siapa menentukan |
| --- | --- | --- |
| Parameter | bobot regresi | dipelajari dari data |
| Hyperparameter | `k` di KNN, `max_depth` | dipilih manusia |

## Grid Search Sederhana

```python
grid = {
    "k": [1, 3, 5],
    "jarak": ["euclid", "manhattan"],
}

for k in grid["k"]:
    for jarak in grid["jarak"]:
        print(k, jarak)  # di sini akan dilatih & dievaluasi
```

Enam kombinasi → enam kali pelatihan. Tambah satu parameter dengan 4 nilai → 24 kombinasi.

## Random Search

```python
import random

kombinasi = [(random.choice(grid["k"]), random.choice(grid["jarak"]))
             for _ in range(4)]
print(kombinasi)
```

Kalau hanya `k` yang benar-benar berpengaruh, random search menemukan nilai baik lebih cepat.

<div class="note">💡 Jangan tuning sampai data uji "bagus". Itu bentuk overfitting terhadap uji. Sisihkan satu set terakhir yang benar-benar tidak pernah disentuh.</div>
