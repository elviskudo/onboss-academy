## Membaca Pola

| Bentuk | Interpretasi |
| --- | --- |
| Naik | korelasi positif |
| Turun | korelasi negatif |
| Awacan | hubungan lemah/tiada |
| Lengkung | hubungan nonlinear |
| Gugus | kemungkinan klaster |

## Scatter Tekstual

```python
titik = [(1, 2), (2, 4), (3, 6), (4, 9)]
for x, y in titik:
    print(" " * (x * 3) + f"({x},{y})")
```

Versiproduksi memakai matplotlib, tetapi pola dasarnya tetap sama.

## Outlier dan Leverage

Titik yang jauh di kanan atas bisa menarik garis regresi dengan kuat. Ini disebut **leverage point**. Periksa apakah ia data sah atau kesalahan input.

<div class="note">💡 Selalu lihat scatter plot sebelum mempercayai koefisien korelasi. Angka tunggal tidak bisa membedakan hubungan linear dan lengkung.</div>
