## Split Sederhana

```python
import random

data = list(range(20))
random.seed(42)
random.shuffle(data)

batas = int(0.8 * len(data))
latih, uji = data[:batas], data[batas:]
print(len(latih), len(uji))
```

## Kenapa Diacak

Kalau data asli sudah diurutkan menurut waktu atau kelas, mengambil 80% pertama akan menghasilkan sampel yang bias.

## Stratifikasi

```python
kelas_a = [("A", i) for i in range(10)]
kelas_b = [("B", i) for i in range(2)]

# ambil proporsi yang sama dari tiap kelas
latih = kelas_a[:8] + kelas_b[:1]
uji = kelas_a[8:] + kelas_b[1:]
print(latih, uji)
```

## Kumpulan Data Kecil

Kalau data cuma 30 baris, split 80/20 menyisakan 6 baris uji — terlalu kecil untuk kesimpulan stabil. Gunakan **cross-validation** atau kumpulkan lebih banyak data.

<div class="note">💡 Data uji adalah "ujian akhir". Kalau kamu mengintip dan mengubah model berdasarkan nilainya berulang kali, hasilnya tidak lagi objektif.</div>
