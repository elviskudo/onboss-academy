## Algoritma

1. Pilih `k` centroid awal.
2. Tetapkan tiap titik ke centroid terdekat.
3. Geser centroid ke rata-rata anggotanya.
4. Ulangi sampai stabil.

## Menetapkan Titik

```python
titik = [(1, 1), (1, 2), (8, 8), (9, 8)]
pusat = [(1, 1), (8, 8)]

def jarak(a, b):
    return (a[0]-b[0])**2 + (a[1]-b[1])**2

for p in titik:
    klaster = min(range(len(pusat)), key=lambda i: jarak(p, pusat[i]))
    print(p, "->", klaster)
```

## Memilih k

Hitung inertia (jumlah jarak kuadrat ke centroid) untuk Several nilai k. Pilih titik "siku" tempat penurunan mulai melambat.

## Keterbatasan

- Sensitif terhadap outlier.
- Butuh scaling.
- Tidak bisa klaster berbentuk elongasi atau bulan sabit.

<div class="note">💡 Karena inisialisasi acak, jalankan k-means beberapa kali dengan seed berbeda lalu pilih hasil dengan inertia terendah.</div>
