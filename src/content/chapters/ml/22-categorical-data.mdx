## Jenis Encoding

| Metode | Cocok untuk |
| --- | --- |
| One-hot | kategori tanpa urutan |
| Ordinal | kategori berurutan |
| Binary | kardinalitas tinggi |

## One-Hot Manual

```python
kategori = ["merah", "biru", "merah"]
unik = sorted(set(kategori))

encoded = [[1 if v == u else 0 for u in unik] for v in kategori]
print(unik)
print(encoded)
```

## Ordinal

```python
peta = {"rendah": 0, "sedang": 1, "tinggi": 2}
print([peta[x] for x in ["sedang", "tinggi"]])
```

Gunakan hanya bila urutan memang bermakna.

## Kategori Tak Dikenal

Saat data baru berisi kategori yang tidak ada saat latih, model one-hot bisa bingung. Siapkan kolom `unknown` atau strategi fallback.

<div class="note">💡 Jangan memakai label encoding untuk warna atau kota: model akan mengira "biru = 1" lebih kecil dari "merah = 2", padahal tidak ada urutan那样的 makna.</div>
