## Sigmoid

```python
import math

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

for z in [-5, 0, 5]:
    print(z, round(sigmoid(z), 3))
```

Output selalu antara 0 dan 1 sehingga bisa dibaca sebagai probabilitas.

## Keputusan Kelas

```python
prob = 0.72
threshold = 0.5
prediksi = 1 if prob >= threshold else 0
print(prediksi)
```

Threshold bukan angka suci. Pada deteksi fraud, threshold 0.2 mungkin lebih masuk akal agar kasus mencurigakan tidak terlewat.

## Beda dengan Regresi Linear

| Aspek | Linear | Logistik |
| --- | --- | --- |
| Output | angka bebas | probabilitas |
| Tugas | regresi | klasifikasi |
| Fungsi | garis | sigmoid |

<div class="note">💡 Probabilitas model tidak otomatis "terkalibrasi". Kalau aplikasi membutuhkan probabilitas yang benar-benar bermakna, lakukan calibration terpisah.</div>
