## Empat Kotak

|  | Prediksi Positif | Prediksi Negatif |
| --- | --- | --- |
| Kenyataan Positif | TP | FN |
| Kenyataan Negatif | FP | TN |

```python
tp, fp, fn, tn = 40, 10, 5, 45
total = tp + fp + fn + tn

akurasi = (tp + tn) / total
presisi = tp / (tp + fp)
recall = tp / (tp + fn)
f1 = 2 * presisi * recall / (presisi + recall)

print(akurasi, presisi, recall, f1)
```

## Arti Metrik

| Metrik | Fokus |
| --- | --- |
| Akurasi | semua prediksi benar |
| Presisi | kualitas prediksi positif |
| Recall | tidak melewatkan positif |
| F1 | keseimbangan presisi-recall |

## Kenapa Akurasi Menipu

Dalam data 1% positif, model yang memprediksi "negatif semua" sudah punya akurasi 99% — tapi tidak berguna. Lihat confusion matrix.

<div class="note">💡 Pilih metrik dari biaya kesalahan. Spam: presisi tinggi agar email penting tidak masuk folder spam. Kanker: recall tinggi agar tidak ada kasus terlewat.</div>
