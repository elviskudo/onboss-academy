**Fine-tuning** mengubah model umum menjadi spesialis. Bukan selalu harus melatih ulang seluruh miliaran parameter.

## Spektrum Strategi

| Strategi | Parameter dilatih | Biaya | Cocok untuk |
|---|---|---|---|
| Prompt engineering | nol | sangat rendah | tugas ringan |
| RAG | nol | rendah | butuh data terbaru |
| LoRA / QLoRA | &lt;1% | sedang | domain khusus |
| Fine-tuning penuh | 100% | tinggi | perubahan perilaku besar |

## LoRA

```text
W' = W + (alpha / r) · B · A
```

Bobot `W` dibekukan. Hanya matriks `A` dan `B` dengan rank kecil `r` yang dilatih.

```python
r, d_in, d_out = 8, 512, 512
A = [[0.0] * d_out for _ in range(r)]  # r x d_out
B = [[0.0] * r for _ in range(d_in)]   # d_in x r
print("parameter LoRA:", r * d_in + r * d_out)
```

QLoRA menambah kuantisasi 4-bit pada bobot dasar sehingga model besar bisa dilatih pada GPU konsumen.

## Instruction Tuning

Dataset berisi pasangan seperti:

```text
Instruksi: "Ringkas kalimat berikut menjadi satu ayat."
Input:    "..."
Jawaban:  "..."
```

Format yang konsisten penting agar model tahu mana perintah, mana data, mana batas jawaban.

## RLHF dan DPO

RLHF melatih model hadiah (reward model) dari preferensi manusia, lalu mengoptimalkan kebijakan dengan PPO. DPO menyederhanakan dengan langsung mengoptimalkan pasangan jawaban disukai/tidak disukai.

<div class="note">💡 Mulai dari prompt dan RAG. Fine-tuning baru diperlukan bila gaya, format, atau pola yang diinginkan tidak bisa dicapai hanya dengan konteks.</div>

## Checklist Praktis

- Siapkan data bersih dan beragam, bukan ribuan contoh yang hampir sama.
- Sisihkan validation set untuk mendeteksi overfitting.
- Simpan adapter bersama versi model dasar dan tokenizer yang dipakai.
- Uji regresi: kemampuan lama tidak boleh hilang saat model menjadi spesialis.
