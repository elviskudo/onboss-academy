Self-attention melihat semua token sekaligus. Tanpa informasi posisi, model tidak bisa membedakan urutan kata. Berbagai skema positional encoding menyelesaikan ini.

## Sinusoidal (Paper Asli)

```text
PE(pos, 2i)   = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
```

```python
import math

def sinusoidal(pos, d=8):
    out = []
    for i in range(d):
        freq = 10000 ** (-(2 * (i // 2)) / d)
        out.append(math.sin(pos * freq) if i % 2 == 0 else math.cos(pos * freq))
    return [round(x, 3) for x in out]

print(sinusoidal(3))
```

Frekuensi rendah merepresentasikan jarak jauh; frekuensi tinggi membedakan posisi berdekatan.

## Learned Embedding

Cara paling sederhana: siapkan tabel `posisi -> vektor` yang ikut dilatih. Mudah, tetapi umumnya hanya bekerja sampai panjang yang terlihat saat training.

## RoPE

```text
Q'_m = rotate(Q_m, m * theta)
K'_n = rotate(K_n, n * theta)
skor = Q'_m · K'_n   -> bergantung pada (m - n)
```

Rotary memutar pasangan dimensi dengan sudut proporsional posisi. Dot product akhir hanya bergantung pada **selisih posisi**, bukan posisi absolut. Dipakai Llama, Mistral, dan Qwen.

| Metode | Jenis info | Ekstrapolasi panjang |
|---|---|---|
| Sinusoidal | absolut + relatif implisit | lumayan |
| Learned | absolut | buruk |
| RoPE | relatif | baik dengan modifikasi |
| ALiBi | bias jarak linear | baik |

<div class="note">💡 RoPE tidak menambah parameter yang bisa dilatih. Posisi disisipkan murni lewat transformasi geometris pada Q dan K.</div>

## Dampak Praktis

- Model dengan RoPE sering bisa diperpanjang konteksnya lewat teknik seperti NTK-aware scaling.
- ALiBi terkenal karena bisa dilatih pada panjang pendek lalu dipakai lebih panjang.
- Pilihan positional encoding memengaruhi perilaku extrapolasi, bukan sekadar detail implementasi.
