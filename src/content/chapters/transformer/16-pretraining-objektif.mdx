Sebelum berguna untuk tugas spesifik, model menjalani **pretraining** pada korpus masif. Objektif yang dipilih membentuk kemampuan dasarnya.

## Causal Language Modeling (CLM)

```text
Input:  "Hari ini cerah"
Target: "ini cerah <eos>"   (geser satu posisi)
```

Model melihat token sebelum posisi lalu memprediksi token berikutnya. Ini alami untuk generasi dan dipakai GPT, Llama, dan sejenisnya.

```python
tokens = ["Hari", "ini", "cerah"]
for i in range(len(tokens) - 1):
    print("lihat:", tokens[:i+1], "-> tebak:", tokens[i+1])
```

## Masked Language Modeling (MLM)

```text
Input:  "Kucing [MASK] atap tidur"
Target: "di"
```

Sebagian token disamarkan. Model memakai konteks kiri **dan** kanan — itulah sebabnya BERT unggul pada klasifikasi dan pemahaman.

## Denoising

T5 dan BART merusak teks (menghapus span, mengacak urutan, mengganti token), lalu meminta rekonstruksi.

```text
Rusak:  "kucing <extra> tidur atap"
Asli:   "kucing tidur di atap"
```

| Objektif | Arah konteks | Kekuatan | Contoh |
|---|---|---|---|
| CLM | kiri -> kanan | generasi lancar | GPT |
| MLM | dua arah | pemahaman mendalam | BERT |
| Denoising | dua arah | fleksibel untuk many tugas | T5, BART |

<div class="note">💡 Model MLM tidak langsung bisa menulis paragraf panjang seperti GPT. Arsitektur dan objective membentuk “kebiasaan” model sejak pretraining.</div>

## Skala dan Data

Kualitas pretraining ditentukan oleh **3 hal**: ukuran dan kebersihan korpus, objective yang sesuai, serta kapasitas model. Data duplikat, teks kerangka situs, dan konten berbahaya sering menjadi penyebab model masih menghasilkan keluaran buruk meski parameternya besar.
