Blok Transformer bukan sekadar tumpukan attention. Tanpa **residual** dan **normalisasi**, model dalam sulit dilatih: gradien memudar dan distribusi aktivasi berubah di setiap lapis.

## Koneksi Residual

```text
output = LayerNorm(x + Sublayer(x))
```

Jalur `x` langsung dilewatkan sehingga informasi asli tidak hilang. Saat melakukan backpropagation, gradien juga punya jalan pintas.

```python
class Residual:
    def forward(self, x, sublayer):
        return x + sublayer(x)
```

## Layer Normalization

LayerNorm menstandarkan nilai fitur pada **satu token** agar rata-rata近 0 dan varians近 1, lalu memakai parameter skala dan bias yang dipelajari.

```text
norm(x) = gamma * (x - mean) / sqrt(var + eps) + beta
```

| Aspek | BatchNorm | LayerNorm |
|---|---|---|
| Sumbu statistik | lintas batch | per token |
| Cocok untuk urutan | kurang | ya |
| Bergantung ukuran batch | ya | tidak |
| Pemakaian di Transformer | jarang | standar |

## Pre-norm vs Post-norm

```text
Post-norm: LayerNorm(x + Sublayer(x))
Pre-norm:  x + Sublayer(LayerNorm(x))
```

Pre-norm lebih populer pada LLM modern karena pelatihannya lebih stabil saat kedalaman meningkat.

<div class="note">💡 Residual bukan berarti sublayer tidak penting. Jika sublayer menghasilkan nol, blok berubah menjadi identitas — itulah alasan jalur ini aman sebagai fondasi.</div>

## Di Dunia Nyata

- Model dengan ratusan blok memakai pre-norm agar training tidak divergen.
- Residual connection membantu fine-tuning: lapis awal bisa tetap berguna walau lapis atas berubah.
- Normalisasi juga dipakai pada representasi akhir sebelum cosine similarity di pencarian vektor.
