Pada arsitektur encoder–decoder asli, decoder tidak hanya mendengar dirinya sendiri. Ia juga **membaca encoder** lewat cross-attention.

## Alur Informasi

```text
Encoder:  sumber -> self-attention -> representasi sumber
Decoder:  target -> masked self-attention -> cross-attention -> FFN
```

```python
def cross_attention(dec_hidden, enc_output, Wq, Wk, Wv):
    Q = dec_hidden @ Wq
    K = enc_output @ Wk
    V = enc_output @ Wv
    skor = Q @ K.T / (Q.shape[-1] ** 0.5)
    return softmax(skor) @ V
```

| Komponen | Sumber | Peran |
|---|---|---|
| Query | decoder | “bagian mana sumber yang relevan?” |
| Key | encoder | identitas tiap token sumber |
| Value | encoder | isi informasi token sumber |

## Perbedaan dengan Self-Attention

- Self-attention: Q, K, V berasal dari **urutan yang sama**.
- Cross-attention: Q dari decoder, K/V dari **urutan lain**.

Pada terjemahan, kata tujuan “kucing” bisa memberi perhatian besar pada kata sumber “cat”, walau posisinya jauh.

## Model Modern

| Model | Arsitektur | Cross-attention |
|---|---|---|
| BERT | encoder-only | tidak ada |
| GPT | decoder-only | tidak ada |
| T5 / BART | encoder-decoder | ya |
| Whisper | encoder-decoder | ya |

<div class="note">💡 Decoder-only bisa melakukan many tugas karena prompt berisi instruksi dan contoh. Namun untuk terjemahan dan ringkasan dengan sumber terpisah, encoder-decoder tetap efisien.</div>

## Aplikasi

- Terjemahan mesin dengan kalimat sumber panjang.
- Ringkasan dokumen: encoder membaca artikel, decoder menulis ringkasan.
- Speech-to-text: encoder memproses audio, decoder menghasilkan transkrip.
