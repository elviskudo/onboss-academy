Attention memberi setiap token akses ke token lain, tetapi terkadang akses itu harus **dibatasi**. Di sinilah masking berperan.

## Dua Jenis Mask

| Mask | Tujuan | Dipakai di |
|---|---|---|
| Padding mask | mengabaikan token pengisi | encoder dan decoder |
| Causal mask | melarang melihat masa depan | decoder autoregresif |

## Causal Mask

```text
token 1 boleh melihat: 1
token 2 boleh melihat: 1 2
token 3 boleh melihat: 1 2 3
```

```python
n = 4
causal = [[1 if j <= i else 0 for j in range(n)] for i in range(n)]
for row in causal:
    print(row)
```

Matriks segitiga bawah ini ditambahkan ke skor sebelum softmax dengan nilai `-inf` pada posisi terlarang.

## Padding Mask

Kalimat pendek dalam satu batch diberi token `<pad>` sampai panjangnya sama. Tanpa mask, model akan “memperhatikan” token palsu itu.

```text
skor = Q·K / sqrt(d_k)
skor = skor + (-1e9 jika terlarang)
bobot = softmax(skor)
```

<div class="note">💡 Causal masklah yang membuat decoder bersifat autoregresif. Tanpa itu, model bisa “membaca” jawaban saat dilatih dan gagal saat diminta menghasilkan teks baru.</div>

## Variasi Modern

- **Prefix LM** — awal prompt boleh saling melihat, bagian jawaban memakai causal mask.
- **Sliding window** — token hanya melihat tetangga terdekat agar biaya tetap linier.
- **Doc mask** — topik berbeda dalam satu batch tidak saling mengganggu.
