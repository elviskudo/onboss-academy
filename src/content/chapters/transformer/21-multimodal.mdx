Manusia memahami dunia lewat banyak indra. **Model multimodal** mencoba melakukan hal yang sama: menggabungkan teks, gambar, audio, dan video.

## Token Visual

```text
gambar 224×224 -> patch 16×16 -> 196 token visual
```

```python
lebar, tinggi, patch = 224, 224, 16
jumlah_patch = (lebar // patch) * (tinggi // patch)
print("token visual:", jumlah_patch)
```

Setiap patch direktifikasi menjadi vektor, lalu diperlakukan seperti token kata oleh Transformer.

## Arsitektur Umum

| Komponen | Fungsi |
|---|---|
| Image encoder | mengubah piksel jadi embedding |
| Text embedding | mengubah token teks jadi vektor |
| Projector | menyelaraskan ruang visual dan teks |
| LLM backbone | melakukan penalaran lintas modal |

## Kemampuan yang Muncul

- Menjelaskan isi foto dan membaca teks di dalam gambar (OCR).
- Menjawab pertanyaan berbasis diagram atau grafik.
- Memahami perintah suara yang disertai video.
- Menghasilkan deskripsi gambar untuk aksesibilitas.

<div class="note">💡 Model multimodal tetap bisa salah “melihat”. Detail kecil pada gambar, tulisan miring, atau objek di tepi frame sering terlewat — periksa kembali untuk keputusan penting.</div>

## Pertimbangan Praktis

- Token visual bisa jauh lebih banyak dari token teks; biaya dan konteks cepat terpakai.
- Resolusi gambar tinggi menambah jumlah patch secara kuadratik.
- Privasi data penting: foto medis atau dokumen pribadi harus diproses sesuai kebijakan.
