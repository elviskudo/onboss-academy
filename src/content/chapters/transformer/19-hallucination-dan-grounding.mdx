Model bahasa dioptimalkan untuk menghasilkan teks yang **mungkin**, bukan teks yang **benar**. Karena itu ia bisa terdengar sangat yakin walau mengarang.

## Mengapa Halusinasi Terjadi

- Data training mengandung informasi usang atau kontradiktif.
- Model tidak punya akses ke dunia nyala saat inference.
- Prompt meminta detail yang memang tidak ada di konteks.
- Sampling kreatif memilih token yang terdengar masuk akal.

## Contoh Kasus

```text
Pertanyaan: "Berapa kuota internet paket X tahun ini?"
Tanpa data: "Paket X memberikan 25 GB."   <- bisa karangan
Dengan RAG: "Berdasarkan halaman 4 dokumen produk, kuota 25 GB."
```

## Strategi Mitigasi

| Strategi | Cara kerja |
|---|---|
| RAG | ambil dokumen relevan sebelum menjawab |
| Kutipan | sertakan sumber tiap klaim |
| Constraint prompt | perintah “jawab hanya dari konteks” |
| Tools | hitung dengan kalkulator, cari dengan database |
| Verifier | model kedua memeriksa konsistensi |

```python
prompt = """
Jawab HANYA berdasarkan konteks di bawah.
Jika tidak ada jawaban, tulis: 'Informasi tidak tersedia'.

Konteks: {dokumen}
Pertanyaan: {pertanyaan}
"""
```

<div class="note">💡 Kutipan bukan jaminan benar — model tetap bisa salah membaca sumber. Tetapi kutipan membuat kesalahan lebih mudah ditemukan oleh manusia.</div>

## Budaya Produksi

- Tampilkan label “dikenakan dari dokumen” dan tautan sumber.
- Catat versi dokumen yang dipakai tiap jawaban.
- Sediakan jalur eskalasi ke manusia untuk keputusan berisiko tinggi.
- Uji secara berkala dengan pertanyaan yang jawabannya memang tidak tersedia.
