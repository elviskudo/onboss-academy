## Kenapa Etika Masuk Materi Data

Analis memegang data orang sungguhan. Kesalahan kecil bisa merugikan individu, bukan hanya merusak grafik.

## Jenis Data Sensitif

| Jenis | Contoh |
| --- | --- |
| Identitas | nama, NIK, email |
| Lokasi | alamat, koordinat |
| Finansial | saldo, kartu kredit |
| Kesehatan | diagnosis, riwayat obat |

## Anonimisasi Sederhana

```python
data = [
    {"nama": "Ana", "kota": "Jakarta", "nilai": 88},
    {"nama": "Budi", "kota": "Bandung", "nilai": 92},
]

amat = [
    {"id": i, "kota": r["kota"], "nilai": r["nilai"]}
    for i, r in enumerate(data, 1)
]
print(amat)
```

Menghapus nama saja sering tidak cukup. Kombinasi kota + tanggal lahir + kode pos bisa mengidentifikasi seseorang.

## Bias dan Kejelasan

- Laporkan bagaimana data dikumpulkan.
- Sebutkan kelompok yang mungkin tidak terwakili.
- Jangan menghapus hasil yang tidak sesuai harapan tanpa alasan.
