## Series

Series adalah array berlabel. Label disebut **index**.

```python
import pandas as pd

s = pd.Series([80, 90, 75], index=["Ana", "Budi", "Rani"])
print(s["Budi"])
print(s.mean())
```

## DataFrame

```python
df = pd.DataFrame([
    {"nama": "Ana", "kelas": "A", "nilai": 88},
    {"nama": "Budi", "kelas": "B", "nilai": 92},
    {"nama": "Rani", "kelas": "A", "nilai": 79},
])
print(df.head())
print(df.shape)
print(df.dtypes)
```

## Memilih dan Menyaring

```python
print(df["nama"])
print(df[["nama", "nilai"]])
print(df[df["nilai"] >= 85])
```

Filter menghasilkan DataFrame baru. Gunakan `&` untuk AND dan `|` untuk OR, lengkapi dengan tanda kurung.

## Ringkasan

```python
print(df.describe())
print(df.groupby("kelas")["nilai"].mean())
```

`groupby` memisahkan data per kategori lalu menerapkan fungsi agregat.

<div class="note">💡 Tanpa Pandas pun semua operasi ini bisa ditulis dengan list dan dict seperti bab-bab sebelumnya. Pandas dipakai karena ringkas dan dioptimasi untuk data besar.</div>
