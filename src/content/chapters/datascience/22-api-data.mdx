## Permintaan GET

```python
import requests

r = requests.get("https://api.contoh.test/cuaca", params={"kota": "Jakarta"}, timeout=5)
print(r.status_code)
print(r.json())
```

`timeout` wajib dicantumkan agar program tidak menggantung selamanya bila server lambat.

## Status dan Error

| Kode | Arti |
| --- | --- |
| 200 | sukses |
| 400 | permintaan salah |
| 401/403 | otorisasi gagal |
| 404 | tidak ditemukan |
| 429 | terlalu banyak permintaan |
| 500 | error server |

```python
r.raise_for_status()  # memunculkan exception untuk kode 4xx/5xx
```

## Rate Limit

Banyak API membatasi jumlah permintaan. Tambahkan jeda atau gunakan pagination yang disediakan server. jangan menembak ratusan request secara bersamaan.

## Menyimpan Hasil

```python
import json

with open("cuaca.json", "w", encoding="utf-8") as f:
    json.dump(r.json(), f, ensure_ascii=False, indent=2)
```

`ensure_ascii=False` menjaga karakter Indonesia tetap terbaca.

<div class="note">💡 Simpan kunci API di variabel lingkungan, bukan di kode. Kunci yang tumpah ke repositori bisa disalahgunakan orang lain.</div>
