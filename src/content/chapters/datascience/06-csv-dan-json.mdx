Dataset nyata hampir selalu datang sebagai **CSV** atau **JSON**. Python menyediakan modul keduanya secara bawaan (standard library) — cukup `import`.

## Dua Format, Dua Bentuk

| Aspek | CSV | JSON |
|-------|-----|------|
| Bentuk | tabel datar (baris & kolom) | bersarang (object/array) |
| Ekstensi | `.csv` | `.json` |
| Header | baris pertama | nama properti tiap objek |
| Untuk apa | data tabular, ekspor spreadsheet | respons API, konfigurasi |
| Modul | `csv` | `json` |

## Anatomi CSV

```csv
nama,kelas,nilai
Andi,A,80
Bia,A,90
Citra,B,75
```

Baris pertama adalah **header** (nama kolom), sisanya data. Untuk contoh latihan di TryIt kita baca CSV dari string, tanpa file eksternal.

## Membaca CSV dengan csv.DictReader

```python
import csv
import io

teks = "nama,nilai\nAndi,80\nBia,90\n"
pembaca = csv.DictReader(io.StringIO(teks))

for row in pembaca:
    print(row["nama"], "->", row["nilai"])
```

`io.StringIO` membuat string terasa seperti file. Catatan: hasil DictReader selalu **string**, jadi konversi ke angka diperlukan bila mau dihitung.

## Menghitung dari CSV

```python
total = 0
jumlah = 0
for row in csv.DictReader(io.StringIO(teks)):
    total += int(row["nilai"])
    jumlah += 1

print("Rata-rata:", total / jumlah)
```

Pola "baca -> konversi -> akumulasi" ini dipakai untuk hampir semua laporan ringkas.

## 4 Fungsi Utama Modul csv

| Fungsi | Arah | Kapan dipakai |
|--------|------|---------------|
| `csv.reader` | baca | data tanpa header, akses indeks |
| `csv.DictReader` | baca | akses kolom lewat nama |
| `csv.writer` | tulis | ekspor ke `.csv` sederhana |
| `csv.DictWriter` | tulis | ekspor dengan nama header |

## JSON: Data Bersarang

```python
import json

teks = '{"kota": "Bandung", "penduduk": 2500, "daftar": [1, 2, 3]}'
objek = json.loads(teks)

print(objek["kota"])
print(objek["penduduk"])
print(objek["daftar"][0])
```

JSON mendukung objek bersarang — cocok untuk respons API.

## 4 Fungsi Utama Modul json

| Fungsi | Input -> Output | Contoh |
|--------|-----------------|--------|
| `json.loads(teks)` | string -> objek Python | parse respons API |
| `json.dumps(objek)` | objek -> string | kirim data ke server |
| `json.load(fp)` | file -> objek Python | baca `config.json` |
| `json.dump(objek, fp)` | objek -> file | simpan hasil analisis |

## Menulis Kembali

```python
laporan = {"rata_rata": 81.5, "jumlah": 3}
teks_baru = json.dumps(laporan, indent=2)
print(teks_baru)
```

Gunakan `indent=2` agar hasil JSON mudah dibaca manusia saat disimpan atau dikirim.

## Di Dunia Nyata

- **Ekspor data penjualan** — `csv.DictWriter` membuat laporan bulanan yang bisa dibuka Excel tanpa kustomisasi.
- **Konfigurasi aplikasi** — `json.load(open("config.json"))` membaca pengaturan saat program start.
- **Konsumsi API cuaca** — `json.loads(responses.text)` mengubah respons HTTP menjadi dict yang bisa difilter.
- **Migrasi data lama** — CSV tahun lalu dibaca ulang lalu ditulis sebagai JSON untuk layanan baru.
- **Laporan otomatis** — hasil hitung disimpan `json.dump` supaya dashboard web tinggal membangunkannya.

<div class="note">💡 Selalu konversi kolom angka dengan int() atau float() sesaat setelah dibaca. Menjumlahkan string angka ("80" + "90") akan menggabungkan teks, bukan menjumlahkan.</div>
