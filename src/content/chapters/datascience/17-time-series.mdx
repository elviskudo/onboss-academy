## Komponen Deret Waktu

| Komponen | Arti |
| --- | --- |
| Trend | arah jangka panjang |
| Musiman | pola berulang tetap |
| Siklus | naik-turun tidak periodik |
| Noise | fluktuasi acak |

## Moving Average

```python
def moving_average(data, jendela=3):
    return [sum(data[i-jendela+1:i+1]) / jendela
            for i in range(jendela-1, len(data))]

data = [10, 12, 11, 13, 14, 13, 15]
print([round(x, 2) for x in moving_average(data)])
```

Jendela lebih besar menghasilkan garis lebih halus, tetapi respons terhadap perubahan baru lebih lambat.

## Indeks

```python
dasar = data[0]
indeks = [round(100 * x / dasar, 1) for x in data]
print(indeks)
```

Indeks memudahkan perbandingan dua deret dengan skala berbeda.

## Pertanyaan yang Biasa Diajukan

- Apakah lonjakan bulan ini di luar pola musiman?

<div class="note">💡 Moving average "terlambat" mendeteksi perubahan. Untuk forecasting yang lebih baik, kombinasikan dengan musiman atau model yang mempertimbangkan tren secara eksplisit.</div>
