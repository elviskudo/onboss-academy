## Memilih Grafik

| Pertanyaan | Grafik |
| --- | --- |
| Kategori mana tertinggi? | bar |
| Apakah x berhubungan dengan y? | scatter |
| Bagaimana nilai berubah tiap bulan? | line |
| Berapa porsi tiap bagian? | pie (hati-hati) |

## Bar Chart ASCII

```python
data = {"Senin": 30, "Selasa": 45, "Rabu": 25}
maks = max(data.values())
for kategori, nilai in data.items():
    panjang = round(nilai / maks * 30)
    print(f"{kategori:>8} | {'█' * panjang} {nilai}")
```

Skala relatif terhadap nilai maksimum membuat grafik tetap muat di layar.

## Scatter Sederhana

```python
titik = [(1, 2), (2, 4), (3, 5), (4, 8)]
for x, y in titik:
    print(" " * (x * 3) + f"({x},{y})")
```

Versi produksi memakai matplotlib, tetapi prinsipnya sama: satu titik untuk satu pasangan nilai.

## Label dan Konteks

Sertakan judul, satuan, dan sumber data. Grafik tanpa judul bisa ditafsirkan berbeda oleh pembaca.

<div class="note">💡 Hindari pie chart dengan lebih dari lima potongan. Manusia sangat buruk membedakan sudut yang hampir sama — bar chart lebih jujur.</div>
