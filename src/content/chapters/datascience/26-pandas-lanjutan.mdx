## groupbyBeberapa Kolom

```python
ringkas = df.groupby(["kelas", "mapel"])["nilai"].agg(["mean", "count"])
print(ringkas)
```

Hasilnya bertingkat: kombinasi `kelas` + `mapel` menjadi index.

## pivot_table

```python
tabel = df.pivot_table(
    values="nilai", index="kelas", columns="mapel", aggfunc="mean"
)
```

Sel kosong otomatis diisi `NaN`. Gunakan `fill_value=0` bila更适合.

## Rolling

```python
df["rata3"] = df["omzet"].rolling(window=3).mean()
```

Baris pertama yang belum punya tiga data menghasilkan `NaN` — ini wajar.

## Kategorikal

```python
df["kelas"] = df["kelas"].astype("category")
print(df["kelas"].cat.categories)
```

Urutan kategori bisa diatur agar `A &lt; B &lt; C` bukan berdasarkan abjad semata.

<div class="note">💡 `groupby` tidak mengubah DataFrame asli; ia menghasilkan objek baru. Simpan hasilnya ke variabel bila ingin dipakai lanjut.</div>
