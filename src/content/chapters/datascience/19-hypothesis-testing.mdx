## Menyusun Hipotesis

```text
H0: rata-rata baru = rata-rata lama
H1: rata-rata baru ≠ rata-rata lama
```

## Selisih dan Effect Size

```python
from statistics import mean, stdev

awal = [10, 11, 12, 11]
baru = [13, 14, 14, 15]

selisih = mean(baru) - mean(awal)
print("Selisih:", selisih)
print("Std awal:", stdev(awal), "Std baru:", stdev(baru))
```

Sebelum bicara signifikansi, lihat dulu besarnya selisih. Dengan sampel sangat besar, selisih 0.01 bisa "signifikan" tetapi tidak berguna secara praktis.

## p-value Secara Intuitif

Bayangkan H0 benar. Seberapa sering kita melihat selisih sebesar ini atau lebih hanya karena kebetulan? Itulah p-value.

## Kesimpulan yang Benar

- `p &lt; alpha` → **tolak H0**, ada bukti perbedaan.
- `p ≥ alpha` → **gagal menolak H0**, bukan "membuktikan H0 benar".

<div class="note">💡 Signifikan statistik ≠ penting bisnis. Selalu sertakan estimasi effect size dan konteks sebelum mengambil keputusan.</div>
