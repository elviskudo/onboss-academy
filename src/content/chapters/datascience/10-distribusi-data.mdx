## Mengapa Distribusi Penting

Dua dataset bisa punya mean sama tetapi bentuk sangat berbeda. Ringkasan tunggal menyembunyikan cerita tersebut — histogram membukanya.

## Histogram Sederhana

```python
data = [1, 2, 2, 3, 3, 3, 4, 4, 5]

for nilai in sorted(set(data)):
    bintang = "#" * data.count(nilai)
    print(f"{nilai}: {bintang}")
```

Output teks seperti ini mudah dibaca tanpa library grafis dan tetap dipahami pemula.

## Bentuk Distribusi

| Bentuk | Ciri | Contoh |
| --- | --- | --- |
| Simetris | kiri ≈ kanan | tinggi badan |
| Positive skew | ekor kanan panjang | penghasilan |
| Negative skew | ekor kiri panjang | usia pensiunan |
| Seragam | semua nilai mirip | angka dadu adil |

## Outlier dengan IQR

```python
import statistics

data = [12, 13, 13, 14, 14, 15, 15, 16, 60]
q1, q3 = statistics.quantiles(data, n=4)[0], statistics.quantiles(data, n=4)[2]
iqr = q3 - q1
batas = iqr * 1.5
outlier = [x for x in data if x < q1 - batas or x > q3 + batas]
print(outlier)
```

Aturan 1.5 × IQR adalah konvensi umum, bukan hukum alam. Tetap pertimbangkan konteks bisnis.

<div class="note">💡 Jangan langsung membuang outlier. Nilai 60 di contoh bisa jadi kesalahan input, atau bisa jadi transaksi besar yang justru paling penting untuk dianalisis.</div>
