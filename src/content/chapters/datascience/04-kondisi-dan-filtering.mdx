Begitu data masuk, hampir selalu ada yang harus **disederhanakan**: sisihkan baris yang tidak relevan, kelompokkan berdasarkan kategori, lalu hitung.

## Operator Perbandingan

Python punya **6 operator perbandingan**:

| Operator | Arti | Contoh | Hasil |
|----------|------|--------|-------|
| `==` | sama dengan | `78 == 78` | `True` |
| `!=` | tidak sama | `78 != 90` | `True` |
| `>` | lebih besar | `90 > 80` | `True` |
| `<` | lebih kecil | `70 < 75` | `True` |
| `>=` | lebih besar/sama | `75 >= 75` | `True` |
| `<=` | lebih kecil/sama | `70 <= 75` | `True` |

Digabung dengan **3 operator logika** — `and`, `or`, `not` — semua syarat filter bisa dirangkai.

## Percabangan Dasar

```python
nilai = 78

if nilai >= 90:
    label = "A"
elif nilai >= 80:
    label = "B"
elif nilai >= 70:
    label = "C"
else:
    label = "D"

print(label)
```

Urutan cabang penting: uji dari syarat paling ketat ke paling longgar agar tidak ada nilai yang salah masuk kategori.

## Filter Baris dengan Loop

```python
penjualan = [
    {"kota": "Bandung", "unit": 45},
    {"kota": "Jakarta", "unit": 120},
    {"kota": "Medan", "unit": 30},
]

besar = []
for baris in penjualan:
    if baris["unit"] >= 40:
        besar.append(baris)

print(besar)
```

Pola "loop + if + append" adalah filter manual yang paling mudah dibaca saat baru belajar.

## 3 Cara Memfilter Data

| Cara | Bentuk | Kapan dipakai |
|------|--------|---------------|
| Loop + `if` | `for ... if ... append` | syarat panjang, butuh logika |
| List comprehension | `[x for x in data if ...]` | filter ringkas, satu baris |
| `filter()` | `filter(lambda x: ..., data)` | syarat sudah berupa fungsi |

```python
# 1. comprehension
besar = [b for b in penjualan if b["unit"] >= 40]
nama_kota = [b["kota"] for b in penjualan]

# 2. filter()
genap = list(filter(lambda n: n % 2 == 0, [70, 75, 81, 90]))
print(genap)
```

Comprehension menggantikan empat baris menjadi satu. Gunakan untuk filter sederhana; bila syaratnya panjang, kembalikan ke loop biasa agar tetap terbaca.

## Beberapa Syarat Sekaligus

```python
syarat = [b for b in penjualan if b["unit"] >= 40 and b["kota"] != "Medan"]
print(syarat)
```

`and`, `or`, dan `not` menggabungkan kondisi. Untuk syarat yang sangat panjang, simpan dulu ke variabel:

```python
aktif = True
minimum = 40
lolos = [b for b in penjualan if aktif and b["unit"] >= minimum]
```

## Menghitung Hasil Filter

```python
nilai = [78, 92, 65, 88, 71]
rata = sum(nilai) / len(nilai)

di_atas = [n for n in nilai if n > rata]
persen = len(di_atas) / len(nilai) * 100
print(f"{len(di_atas)}/{len(nilai)} = {persen:.0f}% di atas rata-rata")
```

## Di Dunia Nyata

- **Kupon khusus pelanggan VIP** — filter transaksi dengan `total >= 1_000_000` sebelum kirim promo.
- **Dashboard absensi** — tampilkan hanya baris dengan `status == "hadir"` dan tanggal hari ini.
- **Validasi input form** — `if umur < 17:` sebelum data dikirim ke server.
- **Saring error log** — komprehension `[b for b in log if b["level"] == "ERROR"]` sebelum dilaporkan ke tim.
- **Daftar siswa remedial** — `[s for s in siswa if s["nilai"] < 75]` sebagai antrean bimbingan.

<div class="note">💡 Saat menyaring data, hitung juga berapa baris yang tersisa. Filter yang terlalu ketat bisa menyisakan nol baris dan membuat rata-rata jadi membagi nol.</div>
