## Membangun Pivot Manual

```python
data = [
    ("A", "Matematika", 80),
    ("A", "IPA", 70),
    ("B", "Matematika", 90),
    ("B", "IPA", 85),
]

pivot = {}
for kelas, mapel, nilai in data:
    pivot[(kelas, mapel)] = pivot.get((kelas, mapel), 0) + nilai

print(pivot)
```

Kunci berupa tuple membuat struktur tetap jelas tanpa library tambahan.

## Menampilkan sebagai Tabel

```python
kelas_list = sorted({k[0] for k in pivot})
mapel_list = sorted({k[1] for k in pivot})

print("Kelas", *mapel_list)
for kelas in kelas_list:
    baris = [pivot.get((kelas, mapel), 0) for mapel in mapel_list]
    print(kelas, *baris)
```

## Agregasi Lain

| Agregasi | Fungsi |
| --- | --- |
| COUNT | jumlah kejadian |
| SUM | total nilai |
| AVG | rata-rata |
| MIN/MAX | ekstrem |

```python
pengunjung = {}
for tanggal, kota in data_kunjungan:
    pengunjung[(tanggal, kota)] = pengunjung.get((tanggal, kota), 0) + 1
```
