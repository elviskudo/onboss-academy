## Skenario

Seorang manajer toko online bertanya: "Kategori apa yang paling menyumbang omzet, dan apakah diskon berkorelasi dengan penjualan?"

## 1. Data Fiktif

```python
transaksi = [
    {"id": 1, "kategori": "Elektronik", "harga": 100, "qty": 2, "diskon": 10},
    {"id": 2, "kategori": "Furniture",  "harga": 50,  "qty": 1, "diskon": 0},
    {"id": 3, "kategori": "Elektronik", "harga": 80,  "qty": 1, "diskon": 5},
    {"id": 4, "kategori": "Makanan",    "harga": 20,  "qty": 5, "diskon": 0},
]
```

## 2. Bersihkan

```python
filtered = [t for t in transaksi if t["harga"] > 0 and t["qty"] > 0]
```

## 3. Hitung Omzet

```python
for t in filtered:
    t["omzet"] = t["harga"] * t["qty"] * (100 - t["diskon"]) / 100

per_kategori = {}
for t in filtered:
    per_kategori[t["kategori"]] = per_kategori.get(t["kategori"], 0) + t["omzet"]

print(per_kategori)
```

## 4. Ringkas

```python
total = sum(per_kategori.values())
for kategori, nilai in sorted(per_kategori.items(), key=lambda x: -x[1]):
    print(f"{kategori:12} {nilai:8.1f} ({nilai/total*100:.1f}%)")
```

## 5. Rekomendasi

> Elektronik menyumbang porsi terbesar. Diskon muncul pada transaksi elektronik, tetapi jumlah transaksi masih terlalu sedikit untuk menyimpulkan diskon menyebabkan omzet naik. Kumpulkan data 3 bulan sebelum mengubah strategi harga.
