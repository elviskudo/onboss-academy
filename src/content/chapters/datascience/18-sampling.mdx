## Populasi versus Sampel

Mengukur seluruh populasi sering mahal atau mustahil. Kita mengambil **sampel**, lalu membuat kesimpulan untuk populasi dengan pengakuan ada ketidakpastian.

## Random Sampling

```python
import random

populasi = list(range(1, 101))
sampel = random.sample(populasi, 10)
print(sampel)
```

`random.sample` mengambil tanpa penggantian, sehingga satu anggota tidak muncul dua kali.

## Stratified Sampling

```python
fakultas = {
    "Teknik": list(range(1, 21)),
    "Ekonomi": list(range(21, 41)),
}
sampel = []
for anggota in fakultas.values():
    sampel += random.sample(anggota, 5)
print(sampel)
```

Ini memastikan tiap kelompok terwakili, terutama bila ukurannya tidak seimbang.

## Sumber Bias

| Bias | Contoh |
| --- | --- |
| Selection | survei hanya di jam kantor |
| Non-response | yang menjawab hanya orang puas |
| Measurement | pertanyaan yang menuntut jawaban tertentu |

<div class="note">💡 Sampel besar tidak menyelamatkan desain yang bias. Lebih baik 500 responden representatif daripada 10.000 responden dari satu kelompok saja.</div>
