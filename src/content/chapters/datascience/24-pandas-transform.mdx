## Membersihkan Kolom

```python
df = df.rename(columns={"nilai": "skor"})
df["nama"] = df["nama"].str.strip().str.title()
df["skor"] = df["skor"].astype(float)
```

Akses `.str` hanya berlaku untuk Series berisi string.

## apply dan map

```python
df["predikat"] = df["skor"].apply(
    lambda x: "A" if x >= 90 else "B" if x >= 75 else "C"
)

kode_kelas = {"A": "Teknik", "B": "Ekonomi"}
df["fakultas"] = df["kelas"].map(kode_kelas)
```

`map` cocok untuk pemetaan nilai; `apply` untuk fungsi yang lebih kompleks.

## Urutan

```python
df = df.sort_values(["kelas", "skor"], ascending=[True, False])
```

## Gabung Data

```python
hasil = df.merge(kelas_df, on="kelas", how="left")
```

`how="left"` mempertahankan semua baris di kiri meski pasangan kanan tidak ada.

## Wide ke Long

```python
panjang = df.melt(
    id_vars=["nama"],
    value_vars=["matematika", "ipa"],
    var_name="mapel", value_name="skor"
)
```

<div class="note">💡 Rantai operasi yang panjang sebaiknya dipecah menjadi beberapa baris dengan nama variabel antara. Lebih mudah di-debug daripada satu baris raksasa.</div>
