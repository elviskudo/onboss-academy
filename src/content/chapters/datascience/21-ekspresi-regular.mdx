## Pola Dasar

| Pola | Arti |
| --- | --- |
| `\d` | digit |
| `\w` | huruf/angka/garis bawah |
| `\s` | spasi |
| `.` | karakter apa pun |
| `^` / `$` | awal / akhir teks |
| `+` | satu atau lebih |
| `*` | nol atau lebih |
| `?` | opsional |
| `{n,m}` | antara n dan m |

## Mencari dan Mengambil

```python
import re

teks = "Kode: AB-123, CD-456"
kode = re.findall(r"[A-Z]{2}-\d{3}", teks)
print(kode)
```

## Mengganti

```python
bersih = re.sub(r"\s+", " ", "  banyak   spasi  ").strip()
print(bersih)
```

`\s+` mencocokkan satu atau lebih spasi, sehingga whitespace beruntun menjadi satu.

## Validasi Sederhana

```python
def email_valid(s):
    return bool(re.fullmatch(r"[\w.]+@[\w.]+\.[a-z]{2,}", s))

print(email_valid("ana@contoh.com"))
```

Regex bukan parser email lengkap, tetapi cukup untuk menyaring kesalahan format umum.

<div class="note">💡 Gunakan raw string `r"..."` untuk pola regex agar backslash tidak dikonsumsi Python. Simpan pola yang rumit dalam variabel bernama agar mudah dirawat.</div>
