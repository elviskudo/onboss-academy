## Mean, Median, Modus

| Ukuran | Cara | Tahan outlier? |
| --- | --- | --- |
| Mean | jumlah / banyak data | tidak |
| Median | nilai tengah setelah diurutkan | ya |
| Modus | nilai paling sering | ya |

```python
from statistics import mean, median, mode

data = [70, 80, 80, 85, 90, 100]
print(mean(data))    # 84.17
print(median(data))  # 82.5
print(mode(data))    # 80
```

## Rentang dan Kuartil

```python
data = sorted([7, 2, 9, 4, 6, 8, 5])
rentang = data[-1] - data[0]
print(rentang)
```

Kuartil membagi data menjadi empat bagian. `statistics.quantiles(data, n=4)` menghasilkan tiga titik potong.

## Varians dan Standar Deviasi

```python
from statistics import variance, pvariance, stdev

sampel = [10, 12, 14, 16]
print(variance(sampel))    # sampel (n-1)
print(pvariance(sampel))   # populasi (n)
print(stdev(sampel))
```

Gunakan `variance` bila data adalah contoh dari populasi besar, `pvariance` bila data sudah mencakup seluruh populasi.

## Mana yang Dipakai?

- Distribusi simetris tanpa outlier → **mean + std**.
- Ada nilai ekstrem (gaji, harga rumah) → **median + IQR**.
- Data kategori → **modus**.

<div class="note">💡 Rata-rata gaji bisa melonjak karena satu direktur; median tetap menggambarkan karyawan biasa. Selalu lihat sebaran data sebelum memilih ringkasan.</div>
