## Ruang Sampel

Kumpulan semua hasil yang mungkin disebut **ruang sampel**. Lempar dua koin menghasilkan `HH, HT, TH, TT`.

```python
from itertools import product
sampel = list(product("HT", repeat=2))
print(sampel)
```

## Menghitung Probabilitas

```python
from fractions import Fraction

p_kepala = Fraction(1, 2)
p_dua_kepala = Fraction(1, 4)
print(p_kepala + p_ekor if False else p_kepala)
```

Untuk kejadian saling lepas, `P(A atau B) = P(A) + P(B)`. Untuk kejadian independen, `P(A dan B) = P(A) × P(B)`.

## Expected Value

```python
nilai = [10, 20, 30]
prob  = [0.2, 0.5, 0.3]
ekspektasi = sum(n * p for n, p in zip(nilai, prob))
print(ekspektasi)
```

E[X] adalah rata-rata jangka panjang bila percobaan diulang banyak kali.

## Simulasi Sederhana

```python
import random

has = sum(random.random() < 0.5 for _ in range(10000)) / 10000
print(has)  # mendekati 0.5
```

Simulasi membantu memeriksa intuisi, terutama pada soal yang sulit dihitung langsung.

<div class="note">💡 Probabilitas tidak menjamin hasil satu percobaan. Peluang hujan 70% tetap bisa cerah hari ini — ia menggambarkan kecenderungan banyak hari serupa.</div>
