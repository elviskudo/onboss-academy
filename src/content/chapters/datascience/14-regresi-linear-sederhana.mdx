## Ide Dasar

Regresi linear mencari garis terbaik yang melewati titik-titik data. "Terbaik" di sini berarti jumlah kuadrat residual paling kecil — metode **least squares**.

## Rumus Slope dan Intercept

```python
x = [1, 2, 3, 4, 5]
y = [2, 4, 5, 4, 5]
n = len(x)

b = (n*sum(xi*yi for xi, yi in zip(x, y)) - sum(x)*sum(y)) /     (n*sum(xi*xi for xi in x) - sum(x)**2)
a = sum(y)/n - b*sum(x)/n

print(f"y = {a:.2f} + {b:.2f}x")
```

## Prediksi dan Residual

```python
prediksi = [a + b*xi for xi in x]
residual = [yi - pi for yi, pi in zip(y, prediksi)]
print(prediksi)
print(residual)
```

Residual yang tersebar acak di sekitar nol adalah tanda model masuk akal. Kalau ada pola (misalnya U-shaped), hubungannya tidak linear.

## R²

```python
rata = sum(y)/n
sst = sum((yi-rata)**2 for yi in y)
sse = sum(e*e for e in residual)
r2 = 1 - sse/sst
print(r2)
```

R² tinggi tidak otomatis berarti model bagus — bisa saja karena terlalu banyak parameter (overfitting).

<div class="note">💡 Regresi menunjukkan asosiasi, bukan kausalitas. Es krim dan tenggelam sama-sama naik di musim panas, tetapi es krim tidak menyebabkan tenggelam.</div>
