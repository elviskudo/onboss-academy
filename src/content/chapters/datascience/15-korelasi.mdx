## Koefisien Korelasi

Rumus Pearson membandingkan penyimpangan dua variabel terhadap rata-ratanya masing-masing.

```python
def korelasi(x, y):
    mx, my = sum(x)/len(x), sum(y)/len(y)
    atas = sum((a-mx)*(b-my) for a, b in zip(x, y))
    bawah = (sum((a-mx)**2 for a in x) * sum((b-my)**2 for b in y)) ** 0.5
    return atas / bawah if bawah else 0
```

## Interpretasi Kasar

| Nilai | Arti |
| --- | --- |
| 0.8 – 1.0 | sangat kuat |
| 0.5 – 0.8 | kuat |
| 0.2 – 0.5 | lemah |
| 0 – 0.2 | sangat lemah |

Tanda positif/negatif menunjukkan arah, bukan kualitas.

## Matriks

```python
kolom = {
    "jam": [1, 2, 3, 4],
    "nilai": [50, 60, 70, 80],
    "tidur": [7, 6, 8, 5],
}
nama = list(kolom)
for a in nama:
    print(a, [round(korelasi(kolom[a], kolom[b]), 2) for b in nama])
```

Matriks membantu melihat banyak pasangan variabel sekaligus sebelum memilih fitur untuk model.

<div class="note">💡 Lihat scatter plot sebelum mempercayai angka korelasi. Dua variabel bisa berkorelasi kuat karena satu outlier, padahal pola mayoritas datar.</div>
