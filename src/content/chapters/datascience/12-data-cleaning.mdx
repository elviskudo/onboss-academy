## Langkah Pembersihan

1. Periksa struktur dan tipe.
2. Temukan duplikat.
3. Tangani nilai kosong.
4. Seragamkan format teks.
5. Validasi aturan bisnis.

## Mendeteksi Duplikat

```python
baris = [
    {"kode": "A1", "nama": "Keyboard"},
    {"kode": "A1", "nama": "Keyboard"},
]
kode = set()
for r in baris:
    if r["kode"] in kode:
        print("Duplikat:", r["kode"])
    kode.add(r["kode"])
```

## Nilai Kosong

```python
nilai = [10, None, 20, None]
bersih = [x for x in nilai if x is not None]
rata = sum(bersih) / len(bersih)

diisi = [rata if x is None else x for x in nilai]
print(diisi)
```

Memilih antara **membuang** dan **mengisi** bergantung pada jumlah data hilang. Kalau lebih dari 30% kolom kosong, mengisi dengan angka buatan bisa menyesatkan.

## Menyamakan Teks

```python
data = [" jakarta ", "JAKARTA", "Jakarta"]
bersih = sorted({x.strip().title() for x in data})
print(bersih)  # ['Jakarta']
```

## Validasi

```python
def valid(umur, email):
    return 0 <= umur <= 120 and "@" in email

print(valid(25, "a@b.com"))
```

<div class="note">💡 Simpan log pembersihan: berapa baris dibuang, kolom apa diisi, dan dengan nilai apa. Tanpa log, hasil analisis sulit direproduksi.</div>
