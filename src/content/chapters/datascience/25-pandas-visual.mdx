## Plot Garis

```python
import matplotlib.pyplot as plt

bulan = [1, 2, 3, 4]
omzet = [10, 15, 13, 20]

plt.plot(bulan, omzet, marker="o", label="Omzet")
plt.title("Omzet Bulanan")
plt.xlabel("Bulan")
plt.ylabel("Juta Rupiah")
plt.legend()
plt.grid(True)
plt.show()
```

## Bar

```python
kategori = ["A", "B", "C"]
nilai = [30, 45, 25]
plt.bar(kategori, nilai, color="steelblue")
plt.show()
```

## Histogram

```python
data = [62, 70, 75, 80, 80, 85, 90, 95]
plt.hist(data, bins=4, edgecolor="black")
plt.show()
```

## Scatter

```python
jam = [1, 2, 3, 4]
nilai = [55, 62, 70, 77]
plt.scatter(jam, nilai)
plt.xlabel("Jam belajar")
plt.ylabel("Nilai")
plt.show()
```

<div class="note">💡 Simpan file dengan `dpi=150` atau lebih untuk hasil yang tajam. Sertakan label sumbu dan satuan — pembaca tidak boleh menebak apa yang ditampilkan.</div>
