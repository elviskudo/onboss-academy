| Operasi | Sintaks | Hasil |
|---|---|---|
| Deklarasi | `arr=(a b c)` | tiga elemen |
| Akses | `${arr[0]}` | `a` |
| Semua elemen | `${arr[@]}` | `a b c` |
| Jumlah | `${#arr[@]}` | `3` |
| Tambah | `arr+=(d)` | elemen baru di akhir |

## Array Indeksed

```bash
#!/usr/bin/env bash
warna=(merah hijau biru)
echo "${warna[0]}"        # merah
echo "${warna[@]}"        # merah hijau biru
echo "${#warna[@]}"       # 3

warna+=(kuning)
for w in "${warna[@]}"; do
  echo "Warna: $w"
done

declare -A harga
harga[kopi]=18000
harga[teh]=12000
echo "Kopi: ${harga[kopi]}"
```

```bash
buah=(apel pisang mangga)
echo "${buah[1]}"      # pisang
echo "${buah[@]}"      # semua elemen
echo "${#buah[@]}"     # 3
```

Spasi adalah pemisah elemen. `"${buah[@]}"` dengan kutip ganda menjaga setiap elemen tetap utuh.

## Menambah dan Mengubah

```bash
buah+=(durian)         # tambah di akhir
buah[0]="apel merah"   # ubah elemen pertama
unset 'buah[1]'        # hapus elemen (indeks jadi kosong)
```

## Iterasi

```bash
for item in "${buah[@]}"; do
  echo "Butir: $item"
done

for i in "${!buah[@]}"; do
  echo "$i -> ${buah[$i]}"
done
```

`${!arr[@]}` menghasilkan daftar indeks, bukan nilai.

## Array Associative

```bash
declare -A ibukota
ibukota[Jawa]="Jakarta"
ibukota[Bali]="Denpasar"

for provinsi in "${!ibukota[@]}"; do
  echo "$provinsi: ${ibukota[$provinsi]}"
done
```

Fitur ini memerlukan Bash 4 ke atas (macOS bawaan masih Bash 3, jadi sering perlu `brew install bash`).

<div class="note">💡 Awali array dengan `local -a` di dalam fungsi agar tidak menimpa variabel global. Selalu kutip `"${arr[@]}"` saat meneruskannya sebagai argumen.</div>
