## Anatomi getopts

```bash
#!/usr/bin/env bash
nama="Dunia"
verbose=0

while getopts "n:v" opsi; do
  case "$opsi" in
    n) nama="$OPTARG" ;;
    v) verbose=1 ;;
    *) echo "Pemakaian: $0 [-n nama] [-v]" >&2; exit 1 ;;
  esac
done

shift $((OPTIND - 1))

[ "$verbose" -eq 1 ] && echo "[debug] argumen: $*"
echo "Halo, $nama!"
```

```bash
while getopts "n:v" opt; do
  ...
done
```

String `"n:v"` berarti ada dua opsi: `-n` yang butuh nilai, dan `-v` yang berupa flag tanpa nilai.

| Variabel | Isi |
|---|---|
| `opt` | huruf opsi yang sedang diproses |
| `OPTARG` | nilai argumen opsi |
| `OPTIND` | indeks argumen berikutnya |

## Memisahkan Argumen

```bash
shift $((OPTIND - 1))
echo "Sisa: $*"
```

Tanpa `shift`, argumen posisi masih menyertakan flag yang sudah diproses.

## Opsi Panjang

`getopts` hanya mendukung opsi pendek. Untuk `--nama`, biasanya dipakai loop manual:

```bash
while [[ $# -gt 0 ]]; do
  case "$1" in
    --nama) nama="$2"; shift 2 ;;
    --verbose) verbose=1; shift ;;
    *) break ;;
  esac
done
```

## Pesan Bantuan

```bash
penggunaan() {
  echo "Pemakaian: $0 [-n nama] [-v]" >&2
  exit 1
}
```

Tulis error ke stderr (`>&2`) dan kembalikan kode keluar bukan nol agar script bisa dipakai dalam pipeline otomasi.

<div class="note">💡 `getopts` berhenti pada argumen pertama yang bukan opsi. Itu sebabnya opsi biasanya ditaruh sebelum argumen posisi, kecuali kamu memakai `--` sebagai pemisah eksplisit.</div>
