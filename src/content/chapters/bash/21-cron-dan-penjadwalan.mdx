## Formulirat Crontab

```bash
# contoh isi crontab (jalankan: crontab -e)
SHELL=/bin/bash
PATH=/usr/local/bin:/usr/bin:/bin

# setiap hari jam 03.00
0 3 * * * /opt/app/backup.sh >> /var/log/backup.log 2>&1

# setiap 15 menit
*/15 * * * * /opt/app/cek-status.sh

# setiap Senin jam 08.30
30 8 * * 1 /opt/app/laporan.sh
```

```
menit jam hari bulan hari_minggu perintah
```

| Field | Rentang | Contoh |
|---|---|---|
| menit | 0-59 | `*/15` |
| jam | 0-23 | `3` |
| hari | 1-31 | `1,15` |
| bulan | 1-12 | `1-6` |
| hari minggu | 0-7 | `1` = Senin |

## Operator

| Simbol | Arti |
|---|---|
| `*` | semua nilai |
| `,` | daftar nilai |
| `-` | rentang |
| `*/n` | setiap n unit |

## Lingkungan Cron

Cron berjalan dengan lingkungan minimal. Selalu gunakan path absolut dan tetapkan `PATH` di bagian atas crontab.

```bash
PATH=/usr/local/bin:/usr/bin:/bin
```

Jangan mengandalkan variabel dari `.bashrc` karena cron tidak memuatnya.

## Catatanging dan Kesalahan

```bash
0 3 * * * /opt/app/backup.sh >> /var/log/backup.log 2>&1
```

Tanpa redireksi, output cron bisa hilang atau dikirim lewat email sistem. Selalu arahkan log ke file yang bisa kamu periksa.

<div class="note">💡 Gunakan `crontab -l` sebelum mengubah jadwal, lalu simpan salinannya. Kesalahan satu karakter bisa membuat job berjalan setiap menit instead of setiap jam.</div>
