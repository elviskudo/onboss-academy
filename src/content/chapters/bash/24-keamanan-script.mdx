## Prinsip Dasar

```bash
#!/usr/bin/env bash
set -euo pipefail

# rahasia dari environment, bukan hardcode
: "${API_TOKEN:?API_TOKEN wajib diisi}"

umask 077
TMP=$(mktemp)
trap 'rm -f "$TMP"' EXIT

# hindari eval; kutip setiap variabel
curl -fsS -H "Penulisization: Bearer $API_TOKEN" \
  "https://api.example.test/data" -o "$TMP"

sha256sum -c checksum.txt
```

| Prinsip | Penerapan |
|---|---|
| Jangan percaya input | validasi sebelum dipakai |
| Jangan hardcode rahasia | environment / secret manager |
| Least privilege | izin file dan user seminimal mungkin |
| Gagal keras | `set -euo pipefail` |
| Audit | log aktivitas penting |

## Hindari eval

```bash
# berbahaya
eval "echo $USER_INPUT"

# aman
printf 'Nilai: %s\n' "$USER_INPUT"
```

Bila input berisi `; rm -rf /`, eval akan benar-benar menjalankannya.

## Rahasia

```bash
: "${API_TOKEN:?API_TOKEN wajib diisi}"
```

Sintaks ini menghentikan skrip bila variabel belum diset. Jangan pernah mencetak token ke log atau menyimpannya di file dengan izin dunia-baca.

## Izin dan umask

```bash
umask 077   # file baru hanya bisa dibaca pemilik
chmod 700 skrip.sh
```

## Jalur Absolut

```bash
/usr/bin/curl ...
/opt/app/script.py
```

Tidak ada jaminan PATH di lingkungan cron atau systemd sama dengan PATH interaktif kamu.

<div class="note">💡 Gunakan `command -v` untuk memastikan perintah tersedia sebelum memakainya, dan pertimbangkan `sudo -n` bila skrip perlu hak elevate tanpa prompt.</div>
