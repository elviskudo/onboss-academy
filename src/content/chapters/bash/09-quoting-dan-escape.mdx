## Tiga Mode Kutip

```bash
#!/usr/bin/env bash
nama="OnBoss Academy"

echo "$nama"        # nilai variabel
echo '$nama'        # teks literal $nama
echo "Halo, ${nama}!"
echo "Hari ini: $(date +%A)"
echo "Harga: \$10"
```

| Mode | Contoh | Ekspansi variabel | Ekspansi perintah |
|---|---|---|---|
| Tanpa kutip | `echo $x` | ya | ya, tapi rentan spasi |
| Kutip ganda | `echo "$x"` | ya | ya |
| Kutip tunggal | `echo '$x'` | tidak | tidak |

## Kenapa Kutip Ganda Penting

```bash
nama="OnBoss Academy"
echo $nama        # dua argumen: OnBoss dan Academy
echo "$nama"      # satu argumen: OnBoss Academy
```

Tanpa kutip, shell memecah hasil ekspansi berdasarkan spasi. Ini menyebabkan error pada path yang mengandung spasi.

## Escape

```bash
echo "Harga \$10"
echo "Baris pertama\nBaris kedua"   # 
 tidak otomatis jadi baris baru
echo -e "Baris pertama\nBaris kedua" # -e mengaktifkan escape
```

Backslash melepaskan makna karakter berikutnya di dalam kutip ganda.

## Perintah Substitution

```bash
sekarang=$(date +%Y-%m-%d)
jumlah=$(wc -l < data.txt)
echo "$sekarang — $jumlah baris"
```

Bentuk `$(...)` lebih disarankan daripada backtick karena bisa bersarang dan lebih mudah dibaca.

<div class="note">💡 Kutip hampir semua ekspansi variabel dengan ganda: <code>"$variabel"</code>. Kebiasaan ini mencegah bug pada nama file dengan spasi dan karakter khusus.</div>
