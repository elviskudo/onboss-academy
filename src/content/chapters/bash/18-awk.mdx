## Struktur Program awk

```bash
#!/usr/bin/env bash
# data.csv: nama,jumlah,harga
awk -F, 'NR > 1 { total += $2 * $3 }
         END { print "Total:", total }' data.csv

# baris dengan jumlah lebih dari 10
awk -F, '$2 > 10 { print $1, $2 }' data.csv

# rata-rata nilai dari kolom ketiga
awk '{ sum += $3; n++ } END { print sum/n }' nilai.txt
```

```
awk 'pola { aksi }' file
```

Awk membaca baris demi baris. Bila pola bernilai benar, blok aksi dijalankan. Tanpa pola, aksi berjalan untuk setiap baris.

| Variabel | Arti |
|---|---|
| `$0` | seluruh baris |
| `$1`, `$2` | field pertama, kedua |
| `NF` | jumlah field |
| `NR` | nomor baris global |
| `FNR` | nomor baris per file |
| `FS` | field separator |
| `OFS` | output field separator |

## Contoh Praktis

```bash
# tampilkan nama (field 1) dan ukuran (field 5) dari ls -l
ls -l | awk '{print $9, $5}'

# baris dengan lebih dari 3 field
awk 'NF > 3' data.txt
```

## BEGIN dan END

```bash
awk 'BEGIN { print "Mulai..." }
     { jum++ }
     END { print "Selesai:", jum, "baris" }' file.txt
```

`BEGIN` cocok untuk inisialisasi dan header; `END` untuk ringkasan akhir.

## Agregasi

```bash
awk -F, '{ gaji[$1] += $2 }
         END { for (n in gaji) print n, gaji[n] }' gaji.csv
```

Awk menyediakan array asosiatif tanpa deklarasi — kuncinya bisa berupa string.

<div class="note">💡 Awk sangat cepat untuk data berformat kolom. Untuk kebutuhan yang lebih kompleks (join antar file, struktur data besar), pertimbangkan Python.</div>
