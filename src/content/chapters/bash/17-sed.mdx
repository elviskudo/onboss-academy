## Sintaks Substitusi

```bash
#!/usr/bin/env bash
# ganti kata di semua baris
sed 's/kopi/teh/g' minuman.txt

# hapus baris kosong dan komentar
sed '/^$/d; /^#/d' konfigurasi.conf

# tampilkan baris 2 sampai 4 saja
sed -n '2,4p' data.txt

# sunting langsung dengan backup
sed -i.bak 's/8080/3000/g' app.conf
```

```
s/pola/pengganti/flag
```

Pola memakai regular expression. Karakter `/` bisa diganti dengan delimiter lain bila teks mengandung slash:

```bash
sed 's|/var/www|/srv/app|g' config.txt
```

## Flag yang Umum

| Flag | Arti |
|---|---|
| `g` | ganti semua kemunculan dalam satu baris |
| `i` | abaikan huruf besar/kecil |
| `2` | ganti kemunculan kedua saja |

## Alamat dan Rentang

```bash
sed -n '1,10p' file.txt       # baris 1-10
sed '/error/p' log.txt        # baris mengandung error
sed '/START/,/END/d' file.txt # hapus blok berlabel
```

`-n` mematikan pencetakan otomatis; tanpa itu, setiap baris tetap muncul walaupun sudah dicetak dengan `p`.

## In-place Editing

```bash
sed -i.bak 's/lama/baru/g' file.txt
```

Bash di Linux memakai `-i`, sedangkan macOS (BSD sed) memerlukan argumen ekstensi seperti `-i.bak`. Cadangan membantu saat perubahan ternyata salah.

<div class="note">💡 sed memproses per baris. Untuk mengganti teks yang melintang beberapa baris, gunakan awk atau perl dengan mode slurp.</div>
