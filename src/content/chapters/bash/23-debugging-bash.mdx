## Alat Bawaan

```bash
#!/usr/bin/env bash
set -euo pipefail

PS4='+ [${BASH_SOURCE}:${LINENO}] '
set -x

nama="OnBoss"
echo "Halo, $nama"

set +x
echo "Bagian sensitif tidak dicetak di trace"
```

| Perintah | Fungsi |
|---|---|
| `bash -n skrip.sh` | cek sintaks |
| `bash -x skrip.sh` | trace ekspansi perintah |
| `set -x` / `set +x` | nyalakan / matikan trace |
| `echo "$?"` | lihat kode keluar terakhir |

## Lacak yang Mudah Dibaca

```bash
PS4='+ ${BASH_SOURCE[0]}:${LINENO}: '
set -x
```

`LINENO` menunjukkan nomor baris sehingga jejak debug langsung menuju lokasi yang tepat.

## ShellCheck

```bash
shellcheck skrip.sh
```

ShellCheck memberi peringatan seperti variabel tanpa kutip, penggunaan `[ ]` yang salah, atau redireksi yang tertukar. Ini seperti linter untuk Bash.

## Strategi Umum

1. Jalankan `bash -n` untuk memastikan sintaks valid.
2. Tambahkan `set -euo pipefail`.
3. Jalankan dengan `bash -x` pada data kecil.
4. Sempitkan dengan `set -x` hanya di sekitar bagian bermasalah.
5. Periksa kode keluar setiap tahap pipeline.

<div class="note">💡 Bug Bash paling sering berasal dari variabel yang tidak dikutip. Sebelum mencari yang rumit, coba kutip semua <code>"$variabel"</code> dan jalankan ShellCheck.</div>
