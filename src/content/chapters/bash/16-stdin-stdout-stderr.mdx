## Tiga Aliran Standar

```bash
#!/usr/bin/env bash
echo "info: mulai" >&2
echo "hasil utama"

# redireksi ke file
echo "baris satu" > output.txt
echo "baris dua" >> output.txt

# gabungkan stderr dan stdout
ls /tidak/ada > gabung.log 2>&1

# here-string
wc -c <<< "Belajar Bash"

# buang output
perintah_berisik >/dev/null 2>&1
```

| Nama | Descriptor | Fungsi |
|---|---|---|
| stdin | 0 | input, biasanya keyboard |
| stdout | 1 | output normal |
| stderr | 2 | pesan error dan diagnostic |

Memisahkan error dari hasil penting agar pipeline tidak mencampur data dengan pesan.

## Redireksi

```bash
perintah > file       # timpa stdout
perintah >> file      # tambahkan ke stdout
perintah 2> error.log # stderr ke file
perintah &> semua.log # stdout + stderr (Bash)
perintah < input.txt  # stdin dari file
```

## Urutan Penting

```bash
perintah > hasil.log 2>&1   # benar: keduanya ke hasil.log
perintah 2>&1 > hasil.log   # stderr ke stdout lama, stdout ke file
```

Urutan evaluasi kiri ke kanan membuat dua baris di atas berbeda secara fundamental.

## Here-doc dan Here-string

```bash
cat <<'EOF'
Teks apa adanya, $tidak_diekspansi
EOF

grep "kata" <<< "$variabel"
```

Kutip pada `<<'EOF'` mencegah ekspansi variabel di dalam here-doc.

<div class="note">💡 Gunakan <code>>/dev/null 2>&1</code> untuk membuang semua output perintah yang memang tidak ingin dilihat. Jangan membuang stderr saat kamu masih perlu mendiagnosa masalah.</div>
