## Tiga Bentuk Gelung

```bash
#!/usr/bin/env bash
for ((i=1; i<=5; i++)); do
  echo "Hitungan $i"
done

n=0
until [ "$n" -ge 3 ]; do
  echo "n=$n"
  ((n++))
done

while read -r baris; do
  [ -z "$baris" ] && continue
  echo "Baris: $baris"
done < data.txt
```

| Bentuk | Kapan dipakai |
|---|---|
| `for x in daftar` | iterasi atas nilai yang sudah ada |
| `for ((...))` | iterasi dengan indeks numerik |
| `while` / `until` | jumlah iterasi belum diketahui |

## Aritmetika

```bash
((i++))         # naikkan i
i=$((i + 2))    # tambah 2
(( total += i ))
```

Ekspresi `((...))` menghasilkan status 0 bila hasilnya bukan nol.

## Membaca Berkas

```bash
while IFS= read -r baris; do
  printf '%s\n' "$baris"
done < data.txt
```

`IFS=` mencegah penghapusan spasi awal/akhir, dan `-r` menjaga backslash tetap literal.

## Break dan Continue

```bash
for n in 1 2 3 4 5; do
  [ "$n" -eq 3 ] && continue
  [ "$n" -eq 5 ] && break
  echo "$n"
done
```

Output: 1, 2, 4. `break` menghentikan loop, `continue` hanya melewati iterasi saat ini.

<div class="note">💡 Hindari `cat file | while read ...` bila kamu perlu mengubah variabel di dalam loop — pipeline membuat subshell sehingga perubahan hilang. Pakai redireksi `< file`.</div>
