## Tahapan Deploy

```bash
#!/usr/bin/env bash
set -euo pipefail

APP_DIR="/opt/app"
BACKUP_DIR="/opt/backup"

log() { printf '[%s] %s\n' "$(date +%FT%T)" "$*" >&2; }

backup() {
  local arsip="$BACKUP_DIR/app-$(date +%Y%m%d%H%M%S).tar.gz"
  mkdir -p "$BACKUP_DIR"
  tar -czf "$arsip" -C "$APP_DIR" .
  echo "$arsip"
}

test_app() {
  log "Menjalankan test..."
  (cd "$APP_DIR" && make test)
}

deploy() {
  log "Mulai deploy"
  test_app
  backup
  (cd "$APP_DIR" && git pull --ff-only)
  systemctl restart app
  log "Deploy selesai"
}

deploy
```

| Tahap | Tujuan | Kegagalan menyebabkan |
|---|---|---|
| Cek prasyarat | memastikan tool & hak ada | berhenti lebih awal |
| Uji | memverifikasi kode | deploy dibatalkan |
| Cadangan | menyimpan versi lama | rollback bisa dilakukan |
| Pull/rsync | memperbarui file | versi baru tidak aktif |
| Ulangi layanan | memuat versi baru | perubahan belum dipakai |

## Fungsi Utilitas

```bash
log() {
  printf '[%s] %s\n' "$(date +%FT%T)" "$*" >&2
}

gagal() {
  log "ERROR: $*"
  exit 1
}
```

Catatanging ke stderr memisahkan pesan dari output yang mungkin dipakai pipeline lain.

## Prasyarat

```bash
command -v git >/dev/null || gagal "git tidak ditemukan"
[ -d "$APP_DIR" ] || gagal "Folder aplikasi tidak ada"
```

Cek lebih awal memberi pesan yang jelas daripada error "command not found" di tengah jalan.

## Kembali

```bash
rollback() {
  local arsip="$1"
  [ -f "$arsip" ] || gagal "Cadangan tidak ditemukan"
  tar -xzf "$arsip" -C "$APP_DIR"
  systemctl restart app
}
```

Simpan daftar backup terakhir dan uji prosedur rollback secara berkala — backup yang tidak pernah diuji bukan jaminan.

<div class="note">💡 Jadikan skrip idempoten: menjalankannya dua kali boleh, asalkan hasil akhirnya sama. Hindari aksi yang menambah entri duplikat setiap kali dijalankan.</div>
