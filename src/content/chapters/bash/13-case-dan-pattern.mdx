## Sintaks Case

```bash
#!/usr/bin/env bash
read -p "Pilih (start/stop/status): " aksi

case "$aksi" in
  start)
    echo "Menyalakan layanan..."
    ;;
  stop|halt)
    echo "Mematikan layanan..."
    ;;
  sta*)
    echo "Status: berjalan"
    ;;
  *)
    echo "Perintah tidak dikenal: $aksi"
    exit 1
    ;;
esac
```

```bash
case "$nilai" in
  pola1) perintah ;;
  pola2) perintah ;;
  *)     perintah default ;;
esac
```

Case mengevaluasi pola dari atas sampai ada yang cocok. Hanya satu cabang yang dijalankan.

## Pola yang Didukung

| Pola | Arti |
|---|---|
| `*` | sembarang teks |
| `?` | satu karakter apa pun |
| `[abc]` | salah satu dari a, b, c |
| `[0-9]` | satu digit |
| `a|b` | a atau b |

## Contoh Praktis

```bash
case "$file" in
  *.jpg|*.png) echo "Gambar" ;;
  *.txt|*.md)  echo "Teks" ;;
  *.sh)        echo "Skrip" ;;
  *)           echo "Jenis tidak dikenal" ;;
esac
```

Saat memakai glob seperti `*.jpg` di dalam case, tanda kutip tidak dipakai karena pola harus diinterpretasi shell.

## Case vs If

- Gunakan `case` bila membandingkan satu nilai dengan banyak pola.
- Gunakan `if` bila setiap kondisi melibatkan variabel atau perbandingan berbeda.

<div class="note">💡 Awali setiap cabang dengan spasi dan akhiri dengan <code>;;</code>. Lupa titik koma adalah error syntax yang paling sering terjadi pada blok case.</div>
