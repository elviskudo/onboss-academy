## Parametereter Expansion

```bash
#!/usr/bin/env bash
teks="Belajar Bash itu menyenangkan"

echo "${#teks}"              # panjang
echo "${teks:0:7}"           # Belajar
echo "${teks#Belajar }"      # Bash itu menyenangkan
echo "${teks/menyenangkan/seru}"
echo "${teks^^}"             # BELAJAR BASH ITU MENYENANGKAN

file="arsip.tar.gz"
echo "${file%.*}"            # arsip.tar
echo "${file##*.}"           # gz
```

| Sintaks | Fungsi |
|---|---|
| `${#var}` | panjang string |
| `${var:awal}` | potong dari indeks awal |
| `${var:awal:panjang}` | potong dengan panjang tertentu |
| `${var#pola}` | hapus awalan terpendek |
| `${var##pola}` | hapus awalan terpanjang |
| `${var%pola}` | hapus akhiran terpendek |
| `${var%%pola}` | hapus akhiran terpanjang |
| `${var/lama/baru}` | ganti pertama |
| `${var//lama/baru}` | ganti semua |

## Contoh Praktis

```bash
nama_file="foto-liburan-2026.jpg"
echo "${nama_file%%-*}"   # foto
echo "${nama_file##*.}"   # jpg
```

Pola `*` adalah wildcard, sehingga `%%-*` menghapus dari tanda hubung pertama sampai akhir.

## Kasus Huruf

```bash
echo "${teks,,}"   # huruf kecil semua
echo "${teks^^}"   # huruf besar semua
```

## Nilai Bawaan

```bash
echo "${nama:-Tamu}"     # pakai Tamu bila nama kosong
echo "${nama:=Tamu}"     # sekaligus mengisi variabel
echo "${nama:+Ada}"      # cetak Ada bila nama berisi
```

<div class="note">💡 Parametereter expansion lebih cepat daripada memanggil <code>sed</code> atau <code>cut</code> karena dijalankan langsung oleh shell tanpa membuat proses baru.</div>
