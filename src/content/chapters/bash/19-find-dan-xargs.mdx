## Dasar find

```bash
#!/usr/bin/env bash
# temukan file .log lebih dari 7 hari
find /var/log -name "*.log" -mtime +7 -type f

# hapus file sementara (hati-hati!)
find . -name "*.tmp" -type f -delete

# ubah izin semua file .sh
find . -name "*.sh" -type f -exec chmod +x {} \;

# tangani nama dengan spasi
find . -name "*.jpg" -print0 | xargs -0 -n 1 echo "Gambar:"
```

```bash
find path [ekspresi] [aksi]
```

Ekspresi bisa dikombinasikan dengan `-a` (dan), `-o` (atau), serta `!` (negasi).

| Ekspresi | Arti |
|---|---|
| `-name "*.log"` | nama cocok pola |
| `-type f` | file biasa |
| `-type d` | direktori |
| `-mtime +7` | dimodifikasi lebih dari 7 hari lalu |
| `-size +10M` | lebih besar dari 10 MB |
| `-empty` | kosong |

## Aksi

```bash
find . -name "*.tmp" -print
find . -name "*.tmp" -delete
find . -name "*.sh" -exec chmod +x {} \;
find . -name "*.bak" -exec rm -i {} \;
```

`-exec ... \;` menjalankan perintah sekali per hasil. `-exec ... +` mengumpulkan banyak hasil dalam satu pemanggilan — lebih efisien.

## xargs

```bash
find . -name "*.txt" -print0 | xargs -0 grep "TODO"
```

`-print0` memisahkan hasil dengan byte null; `-0` memberi tahu xargs untuk membaca format itu. Ini penting karena nama file boleh mengandung spasi dan baris baru.

## Kedalaman

```bash
find . -maxdepth 1 -type f   # hanya direktori saat ini
find . -mindepth 2           # lewati level pertama
```

<div class="note">💡 Uji dulu dengan `-print` sebelum memakai `-delete` atau `-exec rm`. Satu pola yang terlalu luas bisa menghapus file penting.</div>
