## UNION

```sql
SELECT kota FROM dbo.pelanggan
UNION
SELECT kota FROM dbo.supplier;
```

Dua query harus menghasilkan jumlah kolom sama dan tipe yang bisa dikonversi. Header hasil memakai nama kolom dari query pertama.

## UNION ALL

```sql
SELECT kota FROM dbo.pelanggan
UNION ALL
SELECT kota FROM dbo.supplier;
```

`UNION` hemoduplikasi dan karenanya butuh kerja sort/hash tambahan. `UNION ALL` lebih cepat dan dipakai kalau duplikat memang diinginkan atau data sudah dipastikan berbeda.

## EXCEPT dan INTERSECT

```sql
SELECT produk_id FROM dbo.terjual
EXCEPT
SELECT produk_id FROM dbo.diretur;

SELECT produk_id FROM dbo.terjual
INTERSECT
SELECT produk_id FROM dbo.promo;
```

Keduanya membandingkan baris lengkap dan secara bawaan menghilangkan duplikat.

## Mengurutkan Hasil

```sql
SELECT nama, 1 AS urutan FROM dbo.karyawan
UNION ALL
SELECT nama, 2 FROM dbo.mantan_karyawan
ORDER BY urutan, nama;
```

Kolom tambahan berupa konstanta sering dipakai untuk menjaga urutan grup sebelum mengurutkan nama.

<div class="note">💡 `UNION` mengubah tipe hasil mengikuti aturan prioritas tipe SQL Server. kalau satu query menghasilkan `INT` dan lainnya `DECIMAL`, hasil akhirnya `DECIMAL` — kadang dengan Pembulatan yang tidak terduga.</div>
