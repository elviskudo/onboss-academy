## Login dan User

```sql
CREATE LOGIN appuser WITH PASSWORD = 'SandiKuat123!';
GO
USE AcademyDB;
CREATE USER appuser FOR LOGIN appuser;
```

**Login** memberi akses masuk ke server. **User** adalah pemetaan login itu di dalam database. Satu login bisa menjadi user di beberapa database.

## Role

| Role bawaan | Hak |
| --- | --- |
| `db_datareader` | SELECT semua tabel |
| `db_datawriter` | INSERT/UPDATE/DELETE |
| `db_ddladmin` | membuat/mengubah objek |
| `db_owner` | segalanya dalam database |

```sql
ALTER ROLE db_datareader ADD MEMBER appuser;
ALTER ROLE db_datareader DROP MEMBER appuser;
```

Hindari `db_owner` untuk akun aplikasi. Satu bug SQL injection akan langsung berubah menjadi penghapusan seluruh database.

## Grant Terarah

```sql
GRANT SELECT ON dbo.produk TO appuser;
GRANT INSERT, UPDATE ON dbo.pesanan TO appuser;
DENY DELETE ON dbo.pesanan TO appuser;
```

`DENY` mengalahkan `GRANT`, bahkan bila user termasuk role yang memberi hak. Gunakan dengan hati-hati.

## Skema

```sql
CREATE SCHEMA laporan;
GRANT SELECT ON SCHEMA::laporan TO analis;
```

Skema memudahkan pengelolaan hak untuk banyak objek sekaligus dan memberi namespace agar nama tabel tidak tabrakan.

## Mengaudit Hak

```sql
EXEC sp_helpuser 'appuser';
SELECT * FROM sys.database_permissions;
```

Periksa hak secara berkala, terutama setelah pergantian personel atau migrasi aplikasi.

<div class="note">💡 Jangan pernah memakai akun `sa` untuk koneksi aplikasi. Buat akun khusus dengan kata sandi kuat, simpan kredensial di secret manager, dan rotasi secara berkala.</div>
