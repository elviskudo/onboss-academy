## INSERT Dasar

```sql
INSERT INTO dbo.siswa (nama, nilai)
VALUES (N'Ana', 88);
```

Awalan `N` menandakan literal Unicode — penting untuk `NVARCHAR`. Sebaiknya sebutkan daftar kolom agar perintah tetap benar saat tabel mendapat kolom baru.

## Beberapa Baris

```sql
INSERT INTO dbo.siswa (nama, nilai, kelas)
VALUES (N'Ana', 88, 'A'),
       (N'Budi', 92, 'B'),
       (N'Rani', 79, 'A');
```

Satu perintah multi-row lebih efisien daripada tiga perintah terpisah karena log transaksi ditulis lebih sedikit.

## OUTPUT

```sql
INSERT INTO dbo.siswa (nama, nilai)
OUTPUT inserted.id, inserted.nama
VALUES (N'Sari', 95);
```

`inserted` adalah tabel virtual berisi baris baru. Ini cara terbaik mengambil nilai `IDENTITY` tanpa query tambahan seperti `SCOPE_IDENTITY()`.

## IDENTITY_INSERT

```sql
SET IDENTITY_INSERT dbo.siswa ON;
INSERT INTO dbo.siswa (id, nama) VALUES (100, N'Data lama');
SET IDENTITY_INSERT dbo.siswa OFF;
```

Hanya satu tabel yang boleh aktif per sesi. Fitur ini terutama dipakai saat migrasi data dari sistem lama.

## DEFAULT VALUES

```sql
INSERT INTO dbo.log DEFAULT VALUES;
```

Berguna untuk tabel yang seluruh kolomnya punya `DEFAULT`, misalnya kolom waktu dibuat dan status awal.

<div class="note">💡 Untuk ribuan baris, jangan membangun string INSERT yang sangat panjang. Gunakan `bcp`, `BULK INSERT`, atau Table-Valued Parameter agar lebih cepat dan aman.</div>
