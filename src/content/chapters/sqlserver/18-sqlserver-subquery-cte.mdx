## Subquery Scalar

```sql
SELECT nama, gaji,
       (SELECT AVG(gaji) FROM dbo.karyawan) AS rata_rata
FROM dbo.karyawan;
```

Subquery di daftar `SELECT` harus mengembalikan tepat satu nilai. Ia dievaluasi per baris, jadi subquery yang mahal sebaiknya dihitung sekali dalam variabel atau CTE.

## IN dan EXISTS

```sql
SELECT nama FROM dbo.karyawan
WHERE id IN (SELECT id_karyawan FROM dbo.pesanan);

SELECT nama FROM dbo.karyawan k
WHERE EXISTS (SELECT 1 FROM dbo.pesanan p WHERE p.id_karyawan = k.id);
```

`EXISTS` sering lebih cepat karena berhenti begitu menemukan satu baris. `NOT EXISTS` lebih aman daripada `NOT IN` bila subquery可能 menghasilkan NULL.

## Derived Table

```sql
SELECT r.divisi, r.jumlah
FROM (
  SELECT divisi, COUNT(*) AS jumlah
  FROM dbo.karyawan GROUP BY divisi
) AS r
WHERE r.jumlah > 3;
```

Subquery di `FROM` wajib punya alias.

## CTE

```sql
WITH Ringkas AS (
  SELECT divisi, COUNT(*) AS jumlah
  FROM dbo.karyawan GROUP BY divisi
)
SELECT * FROM Ringkas WHERE jumlah > 3;
```

CTE membuat query bertingkat lebih mudah dibaca dan bisa dipakai ulang dalam satu pernyataan.

## CTE Rekursif

```sql
WITH Hierarki AS (
  SELECT id, nama, 0 AS level FROM dbo.karyawan WHERE atasan_id IS NULL
  UNION ALL
  SELECT k.id, k.nama, h.level + 1
  FROM dbo.karyawan k JOIN Hierarki h ON k.atasan_id = h.id
)
SELECT * FROM Hierarki
OPTION (MAXRECURSION 100);
```

Bagian sebelum `UNION ALL` adalah anchor; bagian sesudahnya memanggil CTE sendiri sampai tidak ada baris baru.

<div class="note">💡 CTE hanya hidup selama satu pernyataan. Kalau ingin dipakai banyak query, jadikan VIEW atau table-valued function.</div>
