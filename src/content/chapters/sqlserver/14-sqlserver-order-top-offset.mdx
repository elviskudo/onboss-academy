## ORDER BY

```sql
SELECT nama, divisi, gaji
FROM dbo.karyawan
ORDER BY divisi ASC, gaji DESC;
```

Urutan di evaluasi kiri ke kanan. `ASC` adalah bawaan. Untuk hasil yang stabil, sertakan kunci unik seperti `id` di akhir daftar sort.

## TOP

```sql
SELECT TOP (10) nama, gaji FROM dbo.karyawan ORDER BY gaji DESC;
SELECT TOP (5) PERCENT nama FROM dbo.karyawan ORDER BY gaji DESC;
```

Tanda kurung sekitar angka bukan wajib, tetapi disarankan khususnya saat memakai variabel: `TOP (@n)`.

## WITH TIES

```sql
SELECT TOP (3) WITH TIES nama, gaji
FROM dbo.karyawan
ORDER BY gaji DESC;
```

Kalau tiga orang tertinggi memiliki gaji yang sama dengan orang keempat, orang keempat ikut tampil. Cocok untuk daftar "top performer" yang adil.

## OFFSET FETCH

```sql
SELECT nama
FROM dbo.karyawan
ORDER BY id
OFFSET (@halaman - 1) * @perHalaman ROWS
FETCH NEXT @perHalaman ROWS ONLY;
```

Ini pengganti `LIMIT ... OFFSET` di database lain. Paginasi memakai `OFFSET` menjadi lambat pada halaman sangat dalam; untuk data besar, pertimbangkan **keyset pagination**: `WHERE id > @terakhir ORDER BY id`.

<div class="note">💡 `TOP` dan `OFFSET FETCH` tidak bisa dipakai bersama dalam satu query. Pilih `TOP` untuk potongan sederhana, `OFFSET FETCH` untuk halaman.</div>
