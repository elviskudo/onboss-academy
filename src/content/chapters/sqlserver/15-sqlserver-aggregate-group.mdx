## Fungsi Agregat

| Fungsi | Fungsi |
| --- | --- |
| `COUNT(*)` | jumlah baris |
| `COUNT(kolom)` | jumlah nilai bukan NULL |
| `SUM` | total |
| `AVG` | rata-rata |
| `MIN` / `MAX` | nilai terkecil / terbesar |
| `COUNT(DISTINCT ...)` | jumlah nilai unik |

```sql
SELECT COUNT(*) AS total, COUNT(email) AS punya_email
FROM dbo.karyawan;
```

## GROUP BY

```sql
SELECT divisi, COUNT(*) AS jumlah, SUM(gaji) AS total_gaji
FROM dbo.karyawan
GROUP BY divisi;
```

Setiap kolom di `SELECT` harus muncul di `GROUP BY` atau berada di dalam fungsi agregat. SQL Server akan menolak query yang melanggar aturan ini.

## HAVING versus WHERE

```sql
SELECT divisi, COUNT(*) AS jumlah
FROM dbo.karyawan
WHERE aktif = 1
GROUP BY divisi
HAVING COUNT(*) >= 5;
```

Urutan logis: `WHERE` → `GROUP BY` → `HAVING` → `SELECT` → `ORDER BY`.

## GROUP BY dengan Ekspresi

```sql
SELECT YEAR(tanggal) AS tahun, MONTH(tanggal) AS bulan, SUM(total) AS omzet
FROM dbo.pesanan
GROUP BY YEAR(tanggal), MONTH(tanggal)
ORDER BY tahun, bulan;
```

Ekspresi harus ditulis persis sama di `SELECT` dan `GROUP BY`, kecuali kamu memakai alias lewat subquery atau CTE.

<div class="note">💡 `AVG(gaji)` bisa meleset bila gaji bertipe `INT` — hasil pembagian integer dibulatkan. Cast ke `DECIMAL` dulu: `AVG(CAST(gaji AS DECIMAL(18,2)))`.</div>
