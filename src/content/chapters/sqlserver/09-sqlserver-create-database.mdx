## Membuat Database

```sql
CREATE DATABASE AcademyDB;
GO
```

Perintah `GO` bukan T-SQL — ia adalah pemisah batch yang dikenal SSMS dan `sqlcmd`. Baris-baris sebelum `GO` dikirim ke server sebagai satu batch.

## File Fisik di Balik Database

| Ekstensi | Fungsi |
| --- | --- |
| `.mdf` | file data utama |
| `.ndf` | file data tambahan |
| `.ldf` | log transaksi |

```sql
CREATE DATABASE Toko
ON PRIMARY (
  NAME = Toko_Data,
  FILENAME = 'C:\Data\Toko.mdf',
  SIZE = 100MB,
  FILEGROWTH = 20MB
)
LOG ON (
  NAME = Toko_Log,
  FILENAME = 'C:\Data\Toko.ldf',
  SIZE = 50MB,
  FILEGROWTH = 10MB
);
```

Menentukan ukuran awal dan pertumbuhan mencegah auto-grow kecil yang sering terjadi berulang kali dan memecah file.

## Mengubah Database

```sql
ALTER DATABASE Toko MODIFY NAME = TokoOnline;
ALTER DATABASE TokoOnline SET READ_ONLY;
ALTER DATABASE TokoOnline SET READ_WRITE;
ALTER DATABASE TokoOnline SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
```

Mode `SINGLE_USER` sering dipakai sebelum restore atau perbaikan, tetapi hati-hati: aplikasi yang masih terhubung akan terputus.

## Menghapus

```sql
DROP DATABASE IF EXISTS TokoLama;
```

Klausa `IF EXISTS` membuat skrip aman dijalankan berulang kali — sangat berguna dalam pipeline deployment.

<div class="note">💡 Jangan menghapus database untuk "mengosongkan" data. `DROP` menghilangkan file fisik dan tidak bisa dibatalkan. Untuk keperluan uji, buat database terpisah yang memang boleh dihapus.</div>
