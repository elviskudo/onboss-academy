## #Tabel Temporary

```sql
CREATE TABLE #ringkas (
  id INT PRIMARY KEY,
  total INT
);

INSERT INTO #ringkas
SELECT id, SUM(jumlah) FROM dbo.penjualan GROUP BY id;

SELECT * FROM #ringkas;
DROP TABLE #ringkas;
```

Tabel ini benar-benar dibuat di `tempdb`, boleh diberi indeks dan statistik, serta otomatis hilang saat sesi koneksi ditutup. Menambahkan `DROP TABLE` di akhir skrip adalah kebiasaan baik bila sesi akan dipakai ulang (pooling).

## ##Tabel Global

```sql
CREATE TABLE ##bersama (pesan NVARCHAR(200));
```

Terlihat oleh semua sesi. Umumnya dipakai untuk pertukaran data sementara antar koneksi, tetapi rawan tabrakan nama dan jarang diperlukan.

## Table Variable

```sql
DECLARE @tabel TABLE (
  kode VARCHAR(10),
  jumlah INT
);

INSERT INTO @tabel (kode, jumlah)
SELECT kode, SUM(jumlah) FROM dbo.penjualan GROUP BY kode;

SELECT * FROM @tabel;
```

Berada di `tempdb` secara internal, tetapi sphere hidupnya sesuai batch/prosedur. Tidak perlu `DROP`.

## Memilih

| Kebutuhan | Pilihan |
| --- | --- |
| Data besar, butuh indeks/statistik | `#temp` |
| Beberapa ratus baris dalam fungsi/prosedur | `@table` |
| Dipakai lintas sesi | `##temp` (hati-hati) |
| Hanya satu query | CTE |

<div class="note">💡 Sejak SQL Server 2019 ada **table variable deferred compilation** yang membuat estimasi baris lebih akurat. Tetap ukur dengan actual plan sebelum memutuskan.</div>
