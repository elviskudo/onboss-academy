## Konsep

Window function menghitung nilai **lintas baris** tanpa menggabungkan baris menjadi satu seperti `GROUP BY`. Setiap baris tetap tampil, tapi mendapat kolom tambahan hasil perhitungan jendela.

```sql
SELECT nama, divisi, gaji,
       ROW_NUMBER() OVER (PARTITION BY divisi ORDER BY gaji DESC) AS urut
FROM dbo.karyawan;
```

## Fungsi Peringkat

| Fungsi | Contoh urutan dengan nilai 100,100,90 |
| --- | --- |
| `ROW_NUMBER()` | 1, 2, 3 |
| `RANK()` | 1, 1, 3 |
| `DENSE_RANK()` | 1, 1, 2 |
| `NTILE(4)` | membagi menjadi 4 kelompok |

## Nilai Tetangga

```sql
SELECT tanggal, omzet,
       LAG(omzet) OVER (ORDER BY tanggal) AS omzet_kemarin,
       omzet - LAG(omzet) OVER (ORDER BY tanggal) AS selisih
FROM dbo.harian;
```

`LEAD` kebalikan dari `LAG`. Nilai baris pertama untuk `LAG` adalah `NULL` — bisa diganti dengan argumen default ketiga.

## Agregat sebagai Window

```sql
SELECT nama, gaji,
       SUM(gaji) OVER (PARTITION BY divisi) AS total_divisi,
       AVG(gaji) OVER () AS rata_perusahaan
FROM dbo.karyawan;
```

`PARTITION BY` menggantikan peran `GROUP BY`, tetapi hasil tetap per baris.

## Filter Hasil Window

Window function tidak bisa dipakai di `WHERE`. Bungkus dengan CTE atau derived table:

```sql
WITH Urut AS (
  SELECT nama, ROW_NUMBER() OVER (ORDER BY gaji DESC) AS rn
  FROM dbo.karyawan
)
SELECT * FROM Urut WHERE rn <= 5;
```

<div class="note">💡 Ingin mengambil karyawan tertinggi **per divisi**? Pakai `ROW_NUMBER() OVER (PARTITION BY divisi ORDER BY gaji DESC)` lalu filter `rn = 1` di CTE luar — ini pola yang jauh lebih cepat daripada correlated subquery.</div>
