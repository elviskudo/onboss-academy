**SQL Server** adalah RDBMS Microsoft yang menghidupi sistem perbankan, ERP, dan aplikasi korporasi di seluruh dunia. Query dasarnya sama dengan SQL standar; kekhasannya ada di **T-SQL** dan ekosistem Microsoft.

## Apa itu SQL Server?

SQL Server menyimpan data dalam tabel relasional, menjalankan SQL standar (SELECT, JOIN, WHERE), dan menambah lapisan T-SQL: variabel server-side, prosedur tersimpan, transaksi penuh, dan fungsi sistem yang kaya. Ia terintegrasi rapat dengan Windows Server, Azure, dan alat Microsoft lain.

## T-SQL: SQL yang Diperluas

```sql
DECLARE @gaji DECIMAL(12, 2);
SET @gaji = 8500000;

IF @gaji > 5000000
    PRINT N'Gaji di atas UMR';
ELSE
    PRINT N'Perlu peninjauan';
```

T-SQL memungkinkan logika pemrograman (variabel, percabangan, perulangan) berjalan **di dalam database** — bukan hanya deklarasi data.

## Batch dan GO

```sql
CREATE DATABASE perusahaan;
GO

USE perusahaan;
GO

CREATE TABLE dbo.karyawan (
    id INT IDENTITY(1, 1) PRIMARY KEY,
    nama NVARCHAR(100) NOT NULL
);
```

`GO` memisahkan batch dan dipahami SSMS/sqlcmd, bukan Database Engine. Beberapa perintah modul seperti `CREATE PROCEDURE` harus menjadi statement pertama dalam batch; `CREATE DATABASE` sendiri tidak wajib selalu dipisahkan. Driver aplikasi tidak boleh mengirim `GO` sebagai SQL.

## Enam Kemampuan T-SQL

| Kemampuan | Fungsi | Contoh | Kapan dipakai |
| --- | --- | --- | --- |
| Variabel | menyimpan nilai batch | `DECLARE @id INT` | prosedur dan skrip admin |
| Percabangan | memilih alur | `IF ... ELSE` | aturan bisnis sederhana |
| Perulangan | mengulang statement | `WHILE` | administrasi; utamakan set-based |
| TRY/CATCH | menangani error | `BEGIN TRY` | transaksi aman |
| Stored procedure | menyimpan program database | `CREATE PROCEDURE` | API database terkontrol |
| Function | menghasilkan nilai/tabel | `CREATE FUNCTION` | logika yang dapat dipakai ulang |

T-SQL dapat menjadi bahasa prosedural, tetapi query *set-based* tetap pilihan pertama: satu UPDATE untuk seribu baris lebih efisien daripada WHILE seribu kali.

## Ekosistem dan Edisi

| Produk/alat | Fungsi | Kapan dipakai |
| --- | --- | --- |
| SSMS | GUI query, backup, monitoring | admin/pengembangan Windows |
| sqlcmd | klien command line | otomasi dan CI |
| SQL Server Express | edisi gratis terbatas | belajar/aplikasi kecil |
| SQL Server Developer | fitur Enterprise, non-produksi | development/testing |
| Azure SQL Database | layanan managed | produksi cloud Microsoft |
| SQL Server Agent | penjadwalan job | backup, ETL, maintenance |

Express boleh untuk produksi kecil; Developer tidak berlisensi untuk produksi. Di Linux dan container SQL Server juga tersedia, jadi tidak lagi terbatas ke Windows.

## Di Dunia Nyata

- **Core banking dan ledger** — transaksi, constraint, dan isolation level menjaga perpindahan saldo tetap atomik.
- **ERP perusahaan** — stored procedure menyatukan aturan persediaan, pembelian, dan akuntansi dekat dengan data.
- **Aplikasi .NET** — driver Microsoft dan Azure identity memberi integrasi langsung dengan ekosistem perusahaan.
- **Business intelligence** — SQL Server Agent menjadwalkan ETL dan Query Store membantu menemukan laporan yang lambat.
- **Aplikasi kantor kecil** — Express menyediakan mesin produksi gratis ketika batas kapasitasnya masih cukup.

<div class="note">💡 Awalan `N` pada literal seperti `N'José'` memberi tipe Unicode NVARCHAR. Gunakan saat literal dapat mengandung karakter non-ASCII; tanpa `N`, konversi melalui code page VARCHAR berisiko kehilangan karakter.</div>
