## Scalar Function

```sql
CREATE FUNCTION dbo.LuasPersegi (@panjang INT, @lebar INT)
RETURNS INT
AS
BEGIN
  RETURN @panjang * @lebar;
END;
GO

SELECT dbo.LuasPersegi(4, 5);
```

Pemanggilan harus menyertakan skema (`dbo.`). Scalar function yang dipanggil per baris pada query besar bisa lambat — pertimbangkan ekspresi inline atau computed column.

## Table-Valued Function

```sql
CREATE FUNCTION dbo.KaryawanDivisi (@divisi NVARCHAR(50))
RETURNS TABLE
AS RETURN (
  SELECT id, nama, gaji
  FROM dbo.karyawan
  WHERE divisi = @divisi
);
GO

SELECT * FROM dbo.KaryawanDivisi(N'Teknik');
```

Inline TVF sering dioptimasi seperti view dan lebih cepat daripada multi-statement TVF.

## View

```sql
CREATE VIEW dbo.vKaryawanAktif
AS
SELECT id, nama, gaji
FROM dbo.karyawan
WHERE aktif = 1;
GO

SELECT * FROM dbo.vKaryawanAktif;
```

View menyederhanakan query kompleks, menyembunyikan kolom sensitif, dan memberi lapisan kompatibilitas saat struktur tabel berubah.

## Trigger

```sql
CREATE TRIGGER dbo.trgAuditSiswa
ON dbo.siswa
AFTER UPDATE
AS
BEGIN
  INSERT INTO dbo.audit_siswa (id, nilai_lama, nilai_baru, waktu)
  SELECT i.id, d.nilai, i.nilai, SYSDATETIME()
  FROM inserted i JOIN deleted d ON i.id = d.id;
END;
```

Trigger memproses **seluruh batch baris**, bukan satu per satu. Selalu tulis logic berbasis set seperti contoh di atas.

<div class="note">💡 Trigger mudah menjadi "magic" yang tidak terlihat aplikasi. Dokumentasikan dengan jelas dan hindari trigger untuk aturan bisnis yang bisa diletakkan di stored procedure.</div>
