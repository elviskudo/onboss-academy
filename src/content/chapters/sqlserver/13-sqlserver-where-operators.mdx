## Filter Dasar

```sql
SELECT nama, gaji
FROM dbo.karyawan
WHERE gaji > 5000000;
```

`WHERE` dievaluasi sebelum `SELECT` dan `ORDER BY`, sehingga hanya baris yang lolos yang dihitung atau diurutkan.

## Logika

```sql
WHERE divisi = N'Teknik' AND aktif = 1
WHERE divisi = N'Teknik' OR divisi = N'IT'
WHERE NOT (status = N'Nonaktif')
```

Ketika `AND` dan `OR` dicampur, selalu pakai tanda kurung. Pembaca query tidak perlu menghafal aturan precedence untuk memahami niatmu.

## IN dan BETWEEN

```sql
WHERE kota IN (N'Jakarta', N'Bandung', N'Surabaya')
WHERE umur BETWEEN 20 AND 35
WHERE umur NOT BETWEEN 20 AND 35
```

`IN` setara dengan beberapa `OR`, tetapi lebih ringkas dan often lebih mudah dioptimasi.

## LIKE

| Pola | Arti |
| --- | --- |
| `'A%'` | diawali A |
| `'%ah'` | diakhiri ah |
| `'%budi%'` | mengandung budi |
| `'A_i'` | A + satu karakter + i |
| `'%[0-9]%'` | mengandung angka |

```sql
WHERE nama LIKE N'%[0-9]%'
```

## NULL

```sql
WHEREEmail IS NULL
WHERE email IS NOT NULL
```

Karena `NULL` berarti "tidak diketahui", `NULL = NULL` menghasilkan `UNKNOWN`, bukan TRUE. Gunakan `IS NULL`.

<div class="note">💡 `NOT IN` dengan daftar yang mengandung `NULL` selalu menghasilkan hasil kosong. Pakai `NOT EXISTS` bila datanya mungkin mengandung NULL.</div>
