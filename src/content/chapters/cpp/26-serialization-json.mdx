Data yang keluar dari program C++ sering dikonsumsi bahasa lain. Format tekstual seperti JSON menghindari masalah endianness dan padding yang melekat pada dump struct biner.

## Kenapa JSON?

| Aspek | Dump struct biner | JSON |
|---|---|---|
| Portabilitas | rendah | tinggi |
| Ukuran | kecil | lebih besar |
| Kecepatan | cepat | lebih lambat |
| Debugging | sulit | mudah dibaca |

## Struktur JSON

```json
{
  "nama": "Sari",
  "nilai": 90,
  "aktif": true,
  "hobi": ["membaca", "lari"],
  "alamat": null
}
```

## Menggunakan nlohmann/json

```cpp
#include <nlohmann/json.hpp>
using json = nlohmann::json;

json j;
j["nama"] = "Sari";
j["nilai"] = 90;

std::string teks = j.dump(2);     // pretty print
json balik = json::parse(teks);
std::cout << balik["nama"] << '
';
```

Mapping otomatis ke struct bisa dengan macro `NLOHMANN_DEFINE_TYPE_INTRUSIVE`.

## Versi & Kompatibilitas

```json
{ "versi": 2, "nama": "Sari", "nilai": 90 }
```

Saat format berubah:

- Tambah field baru (jangan hapus yang lama mendadak).
- Baca dengan nilai default bila field tidak ada.
- Tolong catat schema (JSON Schema) bila bekerja tim.

<div class="note">💡 Escape string dengan benar — tanda kutip, backslash, dan newline harus dilewatkan parser. Lebih baik pakai library JSON daripada menggabungkan string manual.</div>
