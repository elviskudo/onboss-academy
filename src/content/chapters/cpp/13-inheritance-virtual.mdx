Pewarisan dan virtual function adalah inti polymorphism C++. Gunakan dengan bijak — komposisi sering lebih sederhana.

## Bentuk Pewarisan

```cpp
class B : public A    { };  // is-a, antarmuka A tetap public
class B : protected A { };  // jarang dipakai
class B : private A   { };  // has-a terimplementasi (lebih baik pakai komposisi)
```

## Virtual & override

```cpp
class Base {
public:
    virtual void gambar() const { std::cout << "base\n"; }
    virtual ~Base() = default;
};

class Turunan : public Base {
public:
    void gambar() const override { std::cout << "turunan\n"; }
};

Base *p = new Turunan();
p->gambar();   // "turunan" — dynamic dispatch
delete p;      // destructor Turunan ikut jalan
```

## Abstract Class

```cpp
class Bentuk {
public:
    virtual double luas() const = 0;  // wajib diisi turunan
    virtual ~Bentuk() = default;
};
```

Class dengan pure virtual tidak bisa dibuat objeknya — ia berfungsi sebagai kontrak.

## Multiple Inheritance

```cpp
class A { ... };
class B { ... };
class C : public A, public B { ... };
```

Masalah "diamond problem" muncul bila A muncul dua kali. Solusinya **virtual inheritance**:

```cpp
class B : virtual public A { };
class C : virtual public A { };
class D : public B, public C { };
```

## Komposisi vs Inheritance

| Pertanyaan | Pilihan |
|---|---|
| "Kucing **adalah** Hewan" | inheritance |
| "Mobil **mempunyai** Mesin" | komposisi |

<div class="note">💡 Selalu tandai method yang me-override dengan `override`, dan buat destructor base `virtual` bila class punya fungsi virtual. Dua kebiasaan ini mencegah bug yang sulit dilacak.</div>
