Smart pointer mengubah manajemen memori dari "ingat untuk `delete`" menjadi "ikutinya aturan ownership". Ini adalah practices default C++ modern.

## unique_ptr

```cpp
#include <memory>

auto p = std::make_unique<int>(10);
std::cout << *p;

auto q = std::move(p);   // q memiliki objek, p jadi null
```

Tidak bisa disalin — hanya satu pemilik. Biayanya sama dengan raw pointer.

## shared_ptr

```cpp
auto a = std::make_shared<std::string>("halo");
auto b = a;              // count = 2
b.reset();               // count = 1
```

Counter dikelola secara atomik. Cocok bila masa hidup objek sulit ditentukan satu pemiliknya.

## weak_ptr & Cycle

```cpp
struct Node {
    std::shared_ptr<Node> next;
    std::weak_ptr<Node> prev;   // jangan shared_ptr → cycle!
};
```

Dua `shared_ptr` saling menunjuk membuat reference count tidak pernah nol → memory leak. `weak_ptr` memutus cycle.

## Pilihan Cepat

| Kebutuhan | Pilihan |
|---|---|
| Satu pemilik | `unique_ptr` |
| Beberapa pemilik | `shared_ptr` |
| Observasi saja | referensi/`*`/`weak_ptr` |
| Kumpulan objek | `vector<T>` (bukan `vector<new T>`) |

## Array

```cpp
auto buf = std::make_unique<int[]>(100);
buf[0] = 7;
```

Tapi untuk kebanyakan kasus, `std::vector<int>` lebih baik.

<div class="note">💡 Hindari `std::shared_ptr` sebagai default. Mulai dari `unique_ptr`; naik ke `shared_ptr` hanya bila memang ada beberapa pemilik dengan masa hidup yang tidak jelas.</div>
