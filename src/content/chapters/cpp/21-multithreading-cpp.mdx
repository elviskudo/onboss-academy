C++11 menjadikan multithreading bagian dari standar — tidak lagi bergantung pada POSIX pthread atau Windows API.

## Thread Dasar

```cpp
#include <thread>

void tugas(int id) { std::cout << id << '
'; }

std::thread t(tugas, 1);
t.join();     // tunggu selesai
// t.detach();  // lepas, jalan mandiri (hati-hati!)
```

`std::thread` yang masih joinable saat destructor dipanggil menyebabkan `std::terminate`.

## Mutex & RAII

```cpp
std::mutex m;

void aman() {
    std::lock_guard<std::mutex> lock(m);
    /* kritis */
}   // lock otomatis dilepas
```

Alternative: `std::unique_lock` (bisa di-unlock manual & dipindah) dipakai dengan `condition_variable`.

## Atomic

```cpp
std::atomic<int> counter{0};
counter++;                  // atomik
counter.fetch_add(5);
```

Lebih ringan daripada mutex untuk operasi sederhana. Bisa menentukan memory order bila dibutuhkan.

## Condition Variable

```cpp
std::condition_variable cv;
std::queue<int> antrian;

// konsumen
std::unique_lock<std::mutex> lock(m);
cv.wait(lock, []{ return !antrian.empty(); });
int v = antrian.front(); antrian.pop();

// produser
{ std::lock_guard<std::mutex> l(m); antrian.push(1); }
cv.notify_one();
```

## Async & Future

```cpp
auto f = std::async(std::launch::async, hitung, 10);
int hasil = f.get();
```

<div class="note">💡 Data race adalah undefined behavior. Lindungi semua state bersama dengan mutex/atomic, atau desain ulang agar tiap thread punya data sendiri (thread-local / reduce di akhir).</div>
