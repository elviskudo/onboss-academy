C++ menyediakan stream API untuk file dan string. Pola yang sama dipakai untuk `cin`, `cout`, dan file — mudah dipelajari sekali.

## Kelas Stream

| Kelas | Fungsi |
|---|---|
| `ifstream` | baca file |
| `ofstream` | tulis file |
| `fstream` | keduanya |
| `istringstream` | parse dari string |
| `ostringstream` | format ke string |

## Membaca

```cpp
std::ifstream f("data.txt");
if (!f) { /* gagal dibuka */ }

std::string baris;
while (std::getline(f, baris)) {
    // proses baris
}
```

Jangan loop dengan `while (!f.eof())` — sering memproses baris terakhir dua kali.

## Menulis

```cpp
std::ofstream f("log.txt", std::ios::app);
f << "Baris log " << 42 << '
';
```

## Parsing dengan stringstream

```cpp
std::string teks = "2026-11-20";
std::istringstream ss(teks);
int y, m, d;
char dash1, dash2;
ss >> y >> dash1 >> m >> dash2 >> d;
```

## Format Modern (C++20)

```cpp
#include <format>
std::string s = std::format("Nama: {}, Nilai: {}", nama, nilai);
```

Alternatif sebelum C++20: `std::ostringstream` atau `{fmt}` library.

<div class="note">💡 Stream otomatis menutup file saat objek keluar scope (RAII). Tidak perlu `close()` manual kecuali kamu ingin segera membuka ulang dengan mode berbeda.</div>
