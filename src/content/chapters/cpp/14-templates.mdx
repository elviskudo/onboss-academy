Template adalah fondasi STL. Ia memungkinkan satu implementasi dipakai banyak tipe tanpa kehilangan type safety.

## Template Function

```cpp
template <typename T>
T absolut(T x) {
    return x < 0 ? -x : x;
}

int a = absolut(-5);       // T = int
double b = absolut(-2.5);  // T = double
```

Compiler membuat instansi fungsi terpisah untuk tiap kombinasi tipe.

## Template Class

```cpp
template <typename T>
class Kotak {
    T isi;
public:
    explicit Kotak(T v) : isi(v) {}
    T ambil() const { return isi; }
};

Kotak<int> a(5);
Kotak<std::string> b("halo");
```

## Parameter Non-Tipe

```cpp
template <typename T, std::size_t N>
class Buffer {
    T data[N];
public:
    constexpr std::size_t ukuran() const { return N; }
};

Buffer<int, 10> b;
```

Nilai `N` harus konstanta saat compile.

## typename vs class

Pada deklarasi `template<typename T>` dan `template<class T>` identik. `typename` juga dipakai untuk menandai nested type yang bergantung:

```cpp
typename T::iterator it;   // memberitahu ini adalah tipe
```

## Specialisasi

```cpp
template <>
bool maks<bool>(bool a, bool b) {
    return a || b;   // perlakuan khusus
}
```

## Kelebihan & Kekurangan

| Kelebihan | Kekurangan |
|---|---|
| Type-safe | Error bisa panjang & sulit dibaca |
| Tanpa overhead runtime | Waktu compile naik |
| Bisa di-inline | Kode hasil bisa membengkak |

<div class="note">💡 Sejak C++20, **concepts** membatasi tipe yang diterima template: `template<std::integral T> T maks(T a,T b)`. Error jadi jauh lebih ramah.</div>
