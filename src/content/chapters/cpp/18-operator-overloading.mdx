Operator overloading membuat tipe buatanmu terasa seperti tipe bawaan: `a + b`, `cout <&lt; obj`, `v[0]`. Gunakan dengan selera — kejutan membuat kode sulit dibaca.

## Aturan Emas

1. Jangan mengubah arti operator yang sudah jelas (`+` untuk penjumlahan).
2. Hormati prezendensi dan asosiativitas bawaan.
3. Kembali ke fungsi bernama bila operasinya tidak alami.

## Member vs Free Function

```cpp
class Vektor {
public:
    Vektor operator+(const Vektor& o) const;   // member
};

std::ostream& operator<<(std::ostream& os, const Vektor& v); // free
```

`operator<<` harus free karena operand kiri adalah `ostream`, bukan class-mu.

## Operator yang Sering Di-overload

| Operator | Kegunaan |
|---|---|
| `<<`, `>>` | I/O |
| `==`, `!=` | perbandingan |
| `<` | sorting |
| `[]` | akses indeks |
| `()` | functor/callable |
| `+ - * /` | aritmetika |
| `++ --` | iterator |
| `->` | smart pointer |

## Functor

```cpp
struct LebihKecil {
    bool operator()(int a, int b) const { return a < b; }
};

std::sort(v.begin(), v.end(), LebihKecil{});
```

Functor bisa menyimpan state, berbeda dengan fungsi biasa.

## Konversi

```cpp
class Derajat {
public:
    explicit operator double() const { return nilai; }  // no implicit
private:
    double nilai;
};
```

Gunakan `explicit` agar tidak terjadi konversi diam-diam yang menyesatkan.

<div class="note">💡 Overload `==` dan `<` konsisten (transitif, simetris). Kalau tidak, `std::sort` dan `std::set` bisa berperilaku aneh.</div>
