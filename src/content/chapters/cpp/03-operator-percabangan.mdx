Percabangan C++ mirip C, dengan tambahan **operator bool yang lebih ketat**. Bab ini menghitung operator per kategori lalu memakainya di `if`, `switch`, dan ternary.

## Operator Aritmatika & Perbandingan

C++ punya **7 operator aritmatika**: `+`, `-`, `*`, `/`, `%`, `++`, `--`.

```cpp
int a = 10, b = 3;
cout << a + b << endl;    // 13
cout << a / b << endl;    // 3   (pembagian int membuang pecahan)
cout << a % b << endl;    // 1   (sisa bagi)
cout << ++a << endl;      // 11  (tambah 1, lalu ambil nilai)
cout << b-- << endl;      // 3   (ambil nilai, lalu kurangi)
cout << (a == b) << endl; // 0 → false
```

**6 operator perbandingan**: `==`, `!=`, `<`, `>`, `<=`, `>=` (plus `<=>` di C++20 untuk perbandingan tiga arah). Selalu beri tanda kurung saat mencetak hasil perbandingan — tanpa itu `cout << a == b` dibaca `(cout << a) == b`.

## Operator Logika & Bitwise

C++ punya **3 operator logika**: `&&` (AND), `||` (OR), `!` (NOT) — keduanya *short-circuit*: `x != 0 && 10 / x > 1` tidak akan membagi nol karena sisi kanan dilewati saat `x == 0`.

```cpp
int umur = 20;
bool punyaTiket = true;
bool boleh = (umur >= 17) && punyaTiket;   // AND
bool diskon = (umur < 5) || (umur > 60);   // OR
bool batal = !boleh;                       // NOT

int x = 12, y = 10;
cout << (x & y) << endl;   // 8   bitwise AND
cout << (x | y) << endl;   // 14  bitwise OR
cout << (x ^ y) << endl;   // 6   bitwise XOR
```

**6 operator bitwise**: `&`, `|`, `^`, `~`, `<<`, `>>` — untuk flag, mask, dan kompresi bit, bukan aritmetika harian.

## Operator Penugasan & Lainnya

C++ punya **1 operator penugasan utama** (`=`) dan **10 varian gabungan**: `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `|=`, `^=`, `<<=`, `>>=`.

| Kategori | Jumlah | Contoh | Kapan dipakai |
|---|---|---|---|
| Aritmatika | 7 | `total += harga` | hitung, akumulasi |
| Perbandingan | 6 (+ `<=>`) | `umur >= 17` | validasi, filter |
| Logika | 3 | `aktif && saldo > 0` | gabung syarat |
| Bitwise | 6 | `flag & MASK` | bit, mask, protocol |
| Penugasan | 1 + 10 gabungan | `x <<= 1` | tulis + ubah sekaligus |
| Ternary | 1 | `a > b ? a : b` | nilai singkat |
| Spesial | `sizeof`, `new`, `delete` | `new int` | memori & scope |

## Bentuk Percabangan

C++ mendukung **5 bentuk percabangan**: `if`, `if-else`, rantai `else if`, `switch`, dan ternary `?:` (C++17 menambah varian `if` dengan inisialisasi).

```cpp
int hari = 3;
if (hari == 1) {
    cout << "Senin" << endl;
} else if (hari == 6 || hari == 7) {
    cout << "Akhir pekan" << endl;
} else {
    cout << "Hari kerja" << endl;
}

switch (hari) {
    case 1: cout << "Awal minggu" << endl; break;
    case 3: cout << "Tengah minggu" << endl; break;
    default: cout << "Hari lain" << endl;
}
```

Urutan membaca kondisi: evaluasi dari atas ke bawah, begitu ada yang `true` cabang lain dilewati. Karena itu **rentang nilai ditulis dari yang paling ketat** — `nilai >= 90` sebelum `nilai >= 80`.

**Kapan memakai mana:**

| Bentuk | Pakai saat | Contoh kasus |
|---|---|---|
| `if / else if` | kondisi beda-beda, bukan nilai tetap | peringkat nilai, validasi form |
| `switch` | satu variabel vs banyak nilai tetap | menu CLI, kode status HTTP |
| ternary | butuh nilai, bukan aksi | `status = lulus ? "Lulus" : "Remedial"` |
| `if` bersarang | hanya untuk syarat tambahan | cek role + cek saldo |

**Anti-pattern**: sarang `if` 4 tingkat. Solusinya tulis guard clause di awal (`if (data kosong) return;`) supaya logika utama berjalan di level dangkal. Juga awas `if (x = 5)` — itu penugasan, bukan perbandingan. Perbandingan string memakai aturan leksikografis: `if (a < b)` membandingkan kode karakter demi karakter.

## Di Dunia Nyata

- Validasi form registrasi: cek `email != "" && panjang >= 5 && umur >= 17` dalam satu syarat.
- Menu kasir: `switch (pilihan)` memilih `case '1'`…`case '5'` untuk 5 menu transaksi.
- Biaya kirim: ternary `berat > 1 ? berat * 10000 : 5000`.
- Filter data sensor: `if (suhu < -40 || suhu > 85) flagTidakNormal = true;`
- Game: `hp <= 0 ? mati() : lanjut()` memutuskan status pemain tiap frame.

<div class="note">💡 Bedakan <code>=</code> (menugaskan nilai) dan <code>==</code> (membandingkan). C++ membantu dengan peringatan kompilator, tetapi tetap periksa hasil <code>-Wall</code> — dan selalu bungkus ekspresi dengan kurung saat mencetak hasil perbandingan.</div>
