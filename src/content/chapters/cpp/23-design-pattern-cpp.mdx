Pattern dalam C++ sering terlihat berbeda dari versi Java karena ada RAII, template, dan fungsi sebagai first-class citizen (`std::function`, lambda).

## Strategy dengan std::function

```cpp
#include <functional>

using Strategi = std::function<double(double)>;

class Checkout {
    Strategi diskon;
public:
    explicit Checkout(Strategi s) : diskon(std::move(s)) {}
    double total(double harga) const { return diskon(harga); }
};

Checkout c([](double h){ return h * 0.85; });
```

Lebih ringkas daripada hierarki class Strategy formal.

## Singleton

```cpp
class Konfigurasi {
public:
    static Konfigurasi& instance() {
        static Konfigurasi k;   // thread-safe sejak C++11
        return k;
    }
    Konfigurasi(const Konfigurasi&) = delete;
private:
    Konfigurasi() = default;
};
```

Local static dijamin inisialisasi sekali secara thread-safe.

## Factory

```cpp
std::unique_ptr<Bentuk> buat(const std::string &jenis) {
    if (jenis == "lingkaran") return std::make_unique<Lingkaran>();
    if (jenis == "kotak")     return std::make_unique<Kotak>();
    return nullptr;
}
```

Mengembalikan `unique_ptr` membuat ownership eksplisit.

## PIMPL

```cpp
// widget.h
class Widget {
    struct Impl;
    std::unique_ptr<Impl> p;
public:
    Widget();
    ~Widget();
    void gambar();
};

// widget.cpp
struct Widget::Impl { /* detail, library mahal */ };
Widget::Widget() : p(std::make_unique<Impl>()) {}
Widget::~Widget() = default;
```

Perubahan di Impl tidak memaksa seluruh proyek rebuild.
