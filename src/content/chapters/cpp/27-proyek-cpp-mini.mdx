Proyek penutup ini merangkum hampir seluruh materi: class, STL, RAII, referensi, dan pemisahan modul.

## Fitur yang Dibangun

1. Tambah buku (judul, penulis, tahun).
2. Pinjam & kembalikan buku.
3. Cari berdasarkan judul/penulis.
4. Simpan/muat dari file JSON.
5. Menu CLI interaktif.

## Model

```cpp
struct Buku {
    std::string id;
    std::string judul;
    std::string penulis;
    int tahun;
    bool dipinjam = false;
};

struct Anggota {
    std::string id;
    std::string nama;
    std::vector<std::string> dipinjam;  // simpan ID, bukan object
};
```

## Service Layer

```cpp
class Perpustakaan {
    std::unordered_map<std::string, Buku> buku;
    std::unordered_map<std::string, Anggota> anggota;
public:
    bool pinjam(const std::string &idBuku, const std::string &idAnggota);
    bool kembalikan(const std::string &idBuku);
};
```

Semua aturan (maksimal 3 buku, denda terlambat, dll) tinggal di sini — UI hanya memanggil method.

## Struktur Folder

```
perpustakaan/
├── CMakeLists.txt
├── include/  ← header publik
├── src/      ← implementasi
├── tests/    ← test dengan Catch2/GoogleTest
└── data/     ← JSON contoh
```

## CMake Minimal

```cmake
cmake_minimum_required(VERSION 3.16)
project(perpustakaan LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 20)
add_executable(app src/main.cpp src/perpustakaan.cpp)
target_include_directories(app PRIVATE include)
```

1. Console CRUD tanpa penyimpanan.
