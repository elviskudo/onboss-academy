Move semantics (C++11) mengizinkan resource dipindahkan dari objek sementara, bukan disalin. Ini menghemat alokasi memori yang mahal.

## Konsep

```cpp
std::string buat() {
    return std::string("teks panjang...");  // objek sementara (rvalue)
}

std::string s = buat();   // compiler bisa elisi / move
```

Sebelum C++11, ini menyalin seluruh isi string. Sekarang pointer internalnya yang dipindahkan.

## std::move

```cpp
#include <utility>

std::string a = "halo";
std::string b = std::move(a);
```

`std::move` hanyalah `static_cast<T&&>` — ia tidak memindahkan apa pun sendiri. Penerima yang melakukan pemindahan lewat move constructor/assignment.

## Move Constructor Buatan

```cpp
class Buffer {
    int *data;
    std::size_t n;
public:
    Buffer(Buffer&& other) noexcept
        : data(other.data), n(other.n) {
        other.data = nullptr;   // biar destructor-nya tidak free
        other.n = 0;
    }

    ~Buffer() { delete[] data; }
};
```

## Perfect Forwarding

```cpp
template <typename T>
void wrapper(T&& arg) {
    fungsi(std::forward<T>(arg));  // pertahankan lvalue/rvalue
}
```

`std::forward` menjaga kategori nilai asli — dasar dari `emplace_back` di STL.

## Kapan Dipakai

- Mengembalikan objek besar dari fungsi.
- Menyimpan objek ke container (`push_back(std::move(x))`).
- Mengimplementasikan class yang mengelola resource.

<div class="note">💡 Jangan memanggil `std::move` pada objek yang masih akan dipakai. Setelah dipindahkan, objek berada dalam state "valid tapi tidak ditentukan".</div>
