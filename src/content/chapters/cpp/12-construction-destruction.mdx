C++ mengikat masa hidup resource ke masa hidup object (RAII). Memahami constructor/destructor adalah kunci menulis kode yang bebas leak tanpa `free` manual.

## Initializer List

```cpp
class Titik {
    int x, y;
public:
    Titik(int a, int b) : x(a), y(b) {}   // dipakai
    // Titik(int a, int b) { x=a; y=b; }  // kurang baik
};
```

Wajib pakai initializer list untuk field `const`, reference, dan class tanpa default constructor.

## Delegating Constructor

```cpp
class User {
public:
    User() : User("Anonim", 0) {}
    User(std::string n, int u) : nama(std::move(n)), umur(u) {}
private:
    std::string nama;
    int umur;
};
```

## Destructor

```cpp
class File {
    FILE *f;
public:
    File(const char *p) : f(std::fopen(p, "r")) {}
    ~File() { if (f) std::fclose(f); }
};
```

Destructor dipanggil otomatis saat object keluar scope — inilah inti RAII.

## Rule of Three / Five / Zero

| Rule | Isi |
|---|---|
| Three | destructor, copy ctor, copy assignment |
| Five | + move ctor, move assignment |
| Zero | pakai RAII types, jangan definisikan kelimanya |

Kalau class kamu hanya berisi `std::string`, `std::vector`, `unique_ptr`, biarkan compiler yang mengurus copy/move.

## explicit

```cpp
explicit Buffer(int n);   // cegah konversi implisit
```

<div class="note">💡 Hindari `new`/`delete` manual di kode aplikasi. Gunakan `std::vector`, `std::string`, dan smart pointer — rule of zero membuat class jauh lebih pendek dan aman.</div>
