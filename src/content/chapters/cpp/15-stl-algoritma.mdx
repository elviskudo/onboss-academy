STL algorithm bekerja pada rentang iterator, sehingga bisa dipakai untuk vector, array, deque, dan container lain yang kompatibel.

## Konsep Rentang

```cpp
std::vector<int> v{3,1,2};
std::sort(v.begin(), v.end());
```

`begin()` dan `end()` membentuk rentang **[begin, end)** — `end()` tidak pernah dimasukkan.

## Algoritma Umum

| Algoritma | Fungsi |
|---|---|
| `find` | cari elemen |
| `count` | hitung kemunculan |
| `sort` | urutkan |
| `reverse` | balik urutan |
| `copy` | salin |
| `transform` | ubah tiap elemen |
| `remove_if` | pindahkan elemen terhapus ke belakang |
| `unique` | hilangkan duplikat berurutan |

## Lambda sebagai Predikat

```cpp
auto ada = std::any_of(v.begin(), v.end(),
                       [](int x){ return x % 2 == 0; });

std::sort(v.begin(), v.end(),
          [](int a, int b){ return a > b; });   // descending
```

## erase-remove Idiom

```cpp
v.erase(std::remove_if(v.begin(), v.end(),
                       [](int x){ return x < 0; }),
        v.end());
```

`remove_if` hanya memindahkan elemen; `erase` yang benar-benar memotong ukuran container.

## Numeric

```cpp
#include <numeric>
int total = std::accumulate(v.begin(), v.end(), 0);
int gcd = std::gcd(12, 18);   // C++17
```

<div class="note">💡 C++20 memperkenalkan **ranges**: `v | std::views::filter(...) | std::views::transform(...)`. Pipelines lebih mudah dibaca daripada rentang begin/end manual.</div>
