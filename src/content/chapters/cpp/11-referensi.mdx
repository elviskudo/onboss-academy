Reference (`&`) adalah alias untuk objek yang sudah ada. Ia membuat kode lebih bersih daripada pointer untuk parameter yang wajib ada.

## Dasar

```cpp
int x = 10;
int &r = x;     // r adalah x
r = 20;         // x sekarang 20
std::cout << &x << " " << &r;  // alamat sama
```

Aturan:

- Harus diinisialisasi saat deklarasi.
- Tidak bisa diubah untuk merujuk objek lain.
- Tidak ada reference kosong (berbeda dengan pointer NULL).

## Reference sebagai Parameter

```cpp
void naikkan(int &nilai) {
    nilai += 1;   // mengubah variabel pemanggil
}

int a = 5;
naikkan(a);       // a jadi 6
```

## const Reference

```cpp
void tampil(const std::string &s) {
    std::cout << s;
}
```

Menghindari salinan string/vektor besar, sekaligus mencegah fungsi mengubah isinya. Ini bentuk default untuk parameter "baca saja".

## Reference vs Pointer

| Aspek | Reference | Pointer |
|---|---|---|
| Null | tidak bisa | bisa |
| Reassign | tidak bisa | bisa |
| Sintaks | `x` | `*p` |
| Cocok untuk | parameter wajib | optional / ownership |

## Rvalue Reference

```cpp
void terima(std::string &&s) {
    // s adalah objek sementara, boleh "dicuri" isinya
}
```

`&&` (C++11) adalah fondasi move semantics — dibahas di chapter 19.

<div class="note">💡 Kembalikan reference dari fungsi hanya jika objek yang dirujuk masa hidupnya lebih panjang dari pemanggil. Mengembalikan reference ke variabel lokal = undefined behavior.</div>
