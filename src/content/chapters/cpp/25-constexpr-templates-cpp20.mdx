C++20 membawa perubahan besar: compile-time programming yang lebih kuat, kode generik yang lebih ramah, dan gaya fungsional lewat ranges.

## constexpr

```cpp
constexpr int pangkat(int b, int e) {
    int hasil = 1;
    for (int i=0;i<e;i++) hasil *= b;
    return hasil;
}

static_assert(pangkat(2, 10) == 1024);  // dicek saat compile
```

Fungsi `constexpr` bisa dipanggil dengan nilai runtime juga — saat itu perilakunya biasa.

## consteval & constinit

- `consteval` → hanya compile time.
- `constinit` → inisialisasi statis dijamin saat compile (tidak ada static initialization order fiasco).

## Concepts

```cpp
#include <concepts>

template <std::integral T>
T rata(T a, T b) { return (a+b)/2; }
```

Sebelum concepts, error template bisa berisi ratusan baris. Sekarang compiler berkata "T tidak memenuhi std::integral".

## Ranges

```cpp
#include <ranges>

auto genap = v | std::views::filter([](int n){ return n%2==0; });
```

View bersifat **lazy** dan tidak menyalin data. Bisa dirantai: `filter | transform | take`.

## Modules

```cpp
// hitung.cppm
export module hitung;
export int tambah(int a, int b) { return a+b; }

// main.cpp
import hitung;
```

Module menggantikan `#include` untuk kode sendiri — tidak ada header guard, tidak ada makro bocor, compile lebih cepat.

## Coroutine (Sekilas)

```cpp
// co_await, co_yield, co_return
```

Dasar dari async/await modern C++ (masih butuh library pendukung seperti cppcoro/asio).

<div class="note">💡 Adopsi C++20 bertahap: mulai dari `constexpr`, `std::string_view`, structured binding, dan ranges. Module & coroutine bisa menyusul setelah toolchain tim mendukung penuh.</div>
