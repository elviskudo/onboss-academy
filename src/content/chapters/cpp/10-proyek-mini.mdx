## Model Data

```cpp
struct Produk {
    string nama;
    int harga;
    int stok;

    bool tersedia() const { return stok > 0; }
};
```

Satu struct merepresentasikan satu record — menambah kolom berarti menambah satu baris, bukan merombak program. Method `const` menjamin tidak ada yang diam-diam mengubah data saat sekadar menampilkan.

## Menambah & Menampilkan

```cpp
vector<Produk> katalog;
katalog.push_back({"Kopi", 25000, 10});
katalog.push_back({"Teh", 15000, 0});

for (const auto &p : katalog) {
    cout << p.nama << " - Rp" << p.harga
         << (p.tersedia() ? " (ada)" : " (habis)") << endl;
}
```

Range-based for dengan `const &` menampilkan semua produk tanpa menyalin satu pun — pola yang sama dipakai untuk loop mana pun yang hanya membaca.

## Mencari & Mengurutkan

```cpp
sort(katalog.begin(), katalog.end(),
     [](const Produk &a, const Produk &b) {
         return a.harga < b.harga;      // termurah dulu
     });

auto it = find_if(katalog.begin(), katalog.end(),
    [](const Produk &p) { return p.nama == "Kopi"; });
if (it != katalog.end()) {
    cout << "Ketemu: " << it->nama << endl;
}
```

Lambda sebagai pembanding membuat pengurutan sesuai kriteria apa pun dalam satu baris. `find_if` mengembalikan iterator — bandingkan dengan `end()` untuk mengetahui apakah ketemu.

## Statistik dengan map

```cpp
map<string, int> hitungPerKategori;
hitungPerKategori["Minuman"] = 2;
hitungPerKategori["Makanan"] = 1;

for (const auto &[kategori, jumlah] : hitungPerKategori) {
    cout << kategori << ": " << jumlah << " produk" << endl;
}
```

Pola yang sama dipakai untuk hitung frekuensi penjualan, jumlah produk habis, atau total penjualan per bulan — cukup ganti kuncinya.

## Rancangan Program Lengkap

Urutan menyusun proyek: (1) tentukan `struct Produk`, (2) siapkan `vector<Produk>` sebagai storage, (3) tulis fungsi tampilkan, (4) tambahkan sort + find, (5) hitung total, (6) rapikan output. Program di bawah sudah lengkap — jalankan, lalu lanjutkan dengan fitur **hapus produk** dan **filter kategori** sebagai latihan akhir.

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <map>
using namespace std;

struct Produk {
    string nama, kategori;
    int harga, stok;
    bool tersedia() const { return stok > 0; }
};

int main() {
    vector<Produk> katalog = {
        {"Kopi", "Minuman", 25000, 10},
        {"Teh", "Minuman", 15000, 0},
        {"Jus", "Minuman", 20000, 5},
        {"Roti", "Makanan", 12000, 8}
    };

    cout << "=== KATALOG ===" << endl;
    for (const auto &p : katalog) {
        cout << p.nama << " (Rp" << p.harga << ") "
             << (p.tersedia() ? "[ada]" : "[habis]") << endl;
    }

    sort(katalog.begin(), katalog.end(),
         [](const Produk &a, const Produk &b) { return a.harga < b.harga; });
    cout << "Termurah: " << katalog.front().nama << endl;

    auto it = find_if(katalog.begin(), katalog.end(),
        [](const Produk &p) { return p.nama == "Jus"; });
    if (it != katalog.end()) cout << "Ditemukan: " << it->nama << endl;

    int total = 0, unit = 0;
    map<string, int> perKategori;
    for (const auto &p : katalog) {
        total += p.harga * p.stok;
        unit += p.stok;
        perKategori[p.kategori] += p.stok;
    }
    cout << "Total stok: " << unit << " unit" << endl;
    cout << "Nilai stok: Rp" << total << endl;

    for (const auto &[kat, jumlah] : perKategori) {
        cout << kat << ": " << jumlah << " unit" << endl;
    }
    return 0;
}
```

## Di Dunia Nyata

- Aplikasi kasir warung memakai pola persis ini: daftar produk + pencarian cepat + total belanja.
- Dashboard inventaris gudang menampilkan nilai stok per kategori — hanya ganti sumber data jadi file/database.
- Katalog e-commerce memakai `sort` dengan kriteria ganti (harga, rating, terbaru) lewat lambda yang berbeda.
- Sistem pengadaan sekolah mencari produk termurah lewat `min_element` pada vektor penawaran.
- Laporan penjualan bulanan memakai `map<string,int>` untuk menghitung transaksi per cabang.
