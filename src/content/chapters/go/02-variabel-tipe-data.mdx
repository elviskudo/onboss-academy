Go menuntut **kejelasan**: tipe tidak perlu ditulis setiap kali, tapi konversi tipe harus selalu kamu tulis sendiri.

## 3 Cara Mendeklarasikan Variabel

Go punya tepat **3 cara** menaruh nilai ke nama variabel:

| Cara | Sintaks | Kapan dipakai |
| --- | --- | --- |
| Short declaration | `nama := nilai` | Di dalam fungsi, saat nilai langsung diketahui |
| Deklarasi `var` | `var nama Tipe = nilai` | Di level package, atau saat butuh tipe eksplisit |
| Konstanta | `const nama = nilai` | Nilai yang tidak boleh berubah |

```go
nama := "Sari"          // tipe ditebak jadi string
var kota = "Bandung"    // var tanpa tipe juga boleh
var tahun int           // nilainya 0 (zero value)
const PI = 3.14         // tidak bisa diubah
```

Aturan `:=`: hanya di dalam fungsi, dan minimal ada satu nama baru di sebelah kiri. `var` berguna di level package (di luar fungsi). `const` nilainya dihitung saat kompilasi.

## Mutabilitas dan Scope

Go tidak punya kata kunci immutable khusus — semua variabel bisa diubah, **kecuali `const`**. Cakupan (scope) ditentukan tempat deklarasi:

- **Package scope**: dideklarasi di luar fungsi, terlihat di seluruh file satu package
- **Block scope**: dideklarasikan di dalam `{ ... }`, hilang setelah blok tutup
- Tidak ada "global variable" lintas package — data antar package lewat fungsi berhuruf kapital (exported)

Aturan penamaan: huruf **kapital di awal** (mis. `Nilai`) berarti bisa dipakai package lain; huruf kecil (`nilai`) hanya lokal. Go menggabungkan penamaan dan akses dalam satu aturan ini.

## 17 Tipe Dasar

Go punya **17 tipe dasar** (plus 2 alias):

| Kategori | Tipe | Contoh | Buat apa |
| --- | --- | --- | --- |
| Boolean | `bool` | `true`, `false` | Status ya/tidak — satu-satunya tipe boolean |
| Teks | `string` | `"Halo"` | Teks UTF-8, tak berubah isinya |
| Integer bertanda | `int8, int16, int32, int64, int` | `-5`, `20` | Bilangan bulat; `int` = 32/64 bit sesuai platform |
| Integer tak bertanda | `uint8, uint16, uint32, uint64, uint, uintptr` | `255` | Nilai positif saja (ukuran jaringan, byte) |
| Pecahan | `float32, float64` | `3.14` | Semua perhitungan desimal — default `float64` |
| Kompleks | `complex64, complex128` | `1+2i` | Matematika ilmiah (jarang dipakai) |

Dua alias: `byte` = `uint8`, `rune` = `int32` (kode karakter Unicode). **Zero value** tiap tipe: `int` → `0`, `float` → `0`, `string` → `""`, `bool` → `false`, pointer/slice/map → `nil`. Go selalu mengisi nilai awal — tidak ada "variabel kosong".

## Konversi Tipe: Selalu Eksplisit

Go **tidak pernah mengonversi diam-diam**. Semua pakai `T(x)`:

```go
a := 7
b := 2

fmt.Println(a / b)              // 3 — pembagian int membuang sisa
fmt.Println(float64(a) / 2)     // 3.5 — salah satu di-float

f := 3.99
x := int(f)                     // 3 — dipotong ke bawah
s := string(rune(65))           // "A" — 65 adalah kode 'A'
```

Tiga kejatuhan yang wajib diingat:

1. **`int / int` = `int`** — 7/2 menghasilkan 3, bukan 3.5
2. **Pemotongan desimal** — `int(f)` (dengan `f := 3.99`) jadi 3, tidak dibulatkan; konstanta pecahan langsung ditolak compiler
3. **String bukan angka** — `"12" + 1` tidak ada; parse dulu dengan `strconv.Atoi`

## Di Dunia Nyata

- **Validasi form**: baca input sebagai string, parse ke `int`, cek rentang usia 17–60
- **Konfigurasi server**: `const Port = 8080` agar port tidak bisa tertimpa kode lain
- **Perhitungan uang**: konversi rupiah ke `int64` (satuan terkecil) supaya tidak kena pembulatan float
- **API respons**: `skor := 90.5` disimpan sebagai `float64` sebelum dikirim JSON
- **Konversi RGB**: `uint8` untuk warna 0–255 — tipe sempit yang hemat memori
