Percabangan Go terlihat ringkas: **tanpa kurung, tanpa break**, dan kondisi selalu bernilai bool.

## 6 Operator Perbandingan

Go punya tepat **6 operator perbandingan**: `==`, `!=`, `<`, `<=`, `>`, `>=` — semuanya menghasilkan `bool`.

| Kategori | Jumlah | Anggota | Fungsi |
| --- | --- | --- | --- |
| Perbandingan | 6 | `==` `!=` `<` `<=` `>` `>=` | Bandingkan dua nilai → bool |
| Logika | 3 | `&&` `\|\|` `!` | Gabungkan kondisi (short-circuit) |
| Aritmatika | 5 | `+` `-` `*` `/` `%` | Hitung nilai untuk dibandingkan |
| Ternary | 0 | — | Tidak ada; pakai if-else |

```go
a := 5
b := 10

fmt.Println(a < b)              // true
fmt.Println(a >= b)             // false
fmt.Println(a != b)             // true
fmt.Println(a < b && b < 20)    // true
fmt.Println(a > b || a == 5)    // true
```

Di luar itu ada **3 operator logika** (`&&`, `||`, `!`) yang bekerja short-circuit: kalau `&&` sudah ketemu `false`, evaluasi kanan dihentikan.

## if dan else

```go
suhu := 35

if suhu > 30 {
    fmt.Println("Panas sekali")
} else if suhu > 25 {
    fmt.Println("Hangat")
} else {
    fmt.Println("Nyaman")
}
```

Kurawal buka `{` harus menempel di baris `if`, bukan pindah ke baris berikutnya.

## Kondisi dengan Inisialisasi

```go
if skor := 78; skor >= 75 {
    fmt.Println("Lulus, skor", skor)
} else {
    fmt.Println("Remedial")
}
```

Variabel `skor` hanya berlaku di dalam blok tersebut — pola ini sangat sering dipakai saat menangani error (`if err := ...; err != nil`).

## switch

```go
hari := "Senin"

switch hari {
case "Senin":
    fmt.Println("Awal minggu")
case "Jumat":
    fmt.Println("Hari terakhir")
default:
    fmt.Println("Hari biasa")
}
```

Case boleh menampung beberapa nilai dengan koma: `case "Sabtu", "Minggu":`. Tambahkan `fallthrough` hanya jika ingin jatuh ke case berikutnya.

## switch Tanpa Kondisi

```go
umur := 17

switch {
case umur >= 17:
    fmt.Println("Boleh mengemudi")
case umur >= 13:
    fmt.Println("Remaja")
default:
    fmt.Println("Anak-anak")
}
```

Bentuk ini menggantikan rangkaian `else if` panjang dan lebih mudah dibaca.

## Tidak Ada Ternary

Go sengaja **tidak punya `?:`**. Pilihan dibuat dengan if-else biasa:

```go
status := "Lulus"
if nilai < 75 {
    status = "Remedial"
}
```

Keputusan model juga tegas: **if** untuk 2–3 cabang, **switch** untuk mencocokkan satu nilai ke banyak kemungkinan. Anti-pattern yang harus dihindari: bersarang `if` lebih dari 3 level — pecah jadi fungsi `if ... { return ... }` agar keluar lebih awal.

## Di Dunia Nyata

- **Grade ujian**: rentang 90–100 → A, 80–89 → B, dst. dengan `else if` berurutan dari batas terbesar
- **Validasi input**: cek panjang password, karakter khusus, lalu `switch` untuk tipe user (admin/member/guest)
- **Routing HTTP**: `switch r.Method` memilih GET/POST/PUT/OPTIONS di server
- **Klasifikasi suhu**: manajemen datacenter menentukan alarm bila suhu > 30°C
- **Kalkulator**: `switch op` memilih `+`, `-`, `*`, `/` dari input pengguna
