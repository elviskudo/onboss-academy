Tanpa kata kunci `class`, Go tetap punya OOP: **struct untuk data, method untuk perilaku**.

## Mendefinisikan Struct

```go
type Siswa struct {
    Nama string
    Umur int
}
```

`type` mendeklarasikan tipe baru. Nama field ditulis PascalCase agar bisa diakses dari package lain.

## Membuat dan Mengakses

```go
s := Siswa{Nama: "Sari", Umur: 20}
s2 := Siswa{}
s2.Nama = "Budi"

fmt.Println(s.Nama)  // Sari
fmt.Println(s2.Nama) // Budi (default string kosong)
```

Field yang tidak diisi otomatis mendapat zero value sesuai tipenya.

## Method dengan Receiver

```go
func (s Siswa) Perkenalan() {
    fmt.Println("Halo, saya", s.Nama)
}

func main() {
    s := Siswa{Nama: "Sari"}
    s.Perkenalan()
}
```

Receiver ditulis di kurung sebelum nama method — pendekatan Go menggantikan `this` atau `self`.

## Receiver Nilai vs Pointer

```go
func (s *Siswa) TambahSkor(n int) {
    s.Skor += n
}

s := Siswa{Skor: 80}
s.TambahSkor(10)
fmt.Println(s.Skor) // 90
```

Jika method mengubah isi struct, gunakan receiver pointer `*Siswa`. Untuk method yang hanya membaca, receiver nilai sudah cukup.

## Interface, Bukan Inheritance

Go **tidak punya inheritance**. Polymorphism datang dari interface yang dipenuhi otomatis:

```go
type Bentuk interface {
    Luas() float64
}

type Persegi struct{ Sisi float64 }

func (p Persegi) Luas() float64 { return p.Sisi * p.Sisi }

func cetak(b Bentuk) {
    fmt.Println("Luas:", b.Luas())
}
```

Cukup punya method `Luas()` — tidak perlu kata `implements`. Untuk "mewarisi" field, Go memakai **embedding**: struct yang memuat struct lain otomatis mempromosikan field dan method-nya.

## Status 4 Pilar OOP di Go

| Pilar | Status di Go | Mekanismenya |
| --- | --- | --- |
| Encapsulation | ✅ Ada | Field huruf kecil = privat untuk package |
| Inheritance | ❌ Tidak ada | Digantikan embedding + komposisi |
| Polymorphism | ✅ Ada | Interface, dipenuhi implicit |
| Abstraction | ✅ Ada | Interface menyembunyikan detail |

Jadi tidak ada `class`, `extends`, atau constructor bawaan — konstruktor hanya konvensi fungsi `NewSiswa(...)`.

## Di Dunia Nyata

- **Layer repository**: interface `Penyimpanan` dengan implementasi in-memory & PostgreSQL, ditukar lewat config
- **Model API**: struct `Produk` + method `Validasi()` sebelum disimpan ke database
- **Embedding**: `struct { Loggers }` menanam logger ke 20 tipe layanan sekaligus
- **Renderer**: fungsi menerima interface `Tampilan` — mendukung HTML dan JSON tanpa if-else
- **Domain hitung**: `Titik` dengan method `Jarak()` menyimpan data sekaligus cara menghitungnya

<div class="note">💡 Go juga punya interface yang terpenuhi otomatis (implicit satisfaction). Tidak perlu menulis kata kunci implements — cukup punya method dengan nama dan tipe yang sama.</div>
