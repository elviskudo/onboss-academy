Semua materi Go kini dipakai bersama: **struct sebagai wadah, method sebagai perilaku, error sebagai nilai balik**.

## Desain: 4 Operasi

| Operasi | Method | Tipe return | Alasan |
| --- | --- | --- | --- |
| Tambah | `Tambah(a, b int)` | `int` | Tidak mungkin gagal |
| Kurang | `Kurang(a, b int)` | `int` | Tidak mungkin gagal |
| Kali | `Kali(a, b int)` | `int` | Tidak mungkin gagal |
| Bagi | `Bagi(a, b int)` | `(float64, error)` | Pembagi nol harus dilaporkan |

## Struktur Kalkulator

```go
type Kalkulator struct{}

func (k Kalkulator) Tambah(a, b int) int { return a + b }
func (k Kalkulator) Kurang(a, b int) int { return a - b }
func (k Kalkulator) Kali(a, b int) int   { return a * b }

func (k Kalkulator) Bagi(a, b int) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("pembagi nol")
    }
    return float64(a) / float64(b), nil
}
```

Operasi berisiko (pembagian) mengembalikan error, sisanya cukup nilai tunggal.

## Memilih Operasi dengan switch

```go
func Hitung(op string, a, b int) (int, error) {
    k := Kalkulator{}
    switch op {
    case "+":
        return k.Tambah(a, b), nil
    case "-":
        return k.Kurang(a, b), nil
    default:
        return 0, fmt.Errorf("operasi %q tidak dikenal", op)
    }
}
```

`return` langsung keluar dari fungsi, sehingga setiap case tidak perlu `break`.

## Menjalankan Banyak Perhitungan

```go
ops := []string{"+", "-", "x"}
for _, op := range ops {
    hasil, err := Hitung(op, 12, 4)
    if err != nil {
        fmt.Println("Gagal:", err)
        continue
    }
    fmt.Println(op, "=>", hasil)
}
```

Perulangan `range` membuat kalkulator melayani daftar operasi tanpa menulis kode berulang. Catatan: versi ini memakai `int`, jadi pembagian ditangani method `Bagi` terpisah yang menghasilkan `float64`.

## Menyatukannya

```go
func main() {
    k := Kalkulator{}
    fmt.Println("12 + 4 =", k.Tambah(12, 4))

    h, err := k.Bagi(12, 4)
    if err != nil {
        fmt.Println(err)
        return
    }
    fmt.Println("12 / 4 =", h)
}
```

Alurnya selalu sama: hitung, cek error, tampilkan. Pola ini akan kamu temui di proyek Go mana pun.

## Di Dunia Nyata

- **Billing**: method per diskon (persen, potong rupiah) di struct `Invoice`
- **Kalkulator cicilan**: `Bagi` menghitung angsuran per bulan, error saat tenor 0
- **Service konversi mata uang**: switch memilih rate berdasarkan kode ISO
- **Otomasi spreadsheet**: proyek nyata berawal persis seperti ini, lalu dibaca dari CSV
- **Latihan TDD**: tiap method ditulis test-nya dulu (`go test`), implementasi menyusul
