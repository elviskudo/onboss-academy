`context.Context` membawa sinyal pembatalan, deadline, dan data kecil lintas batas API. Ia adalah konvensi pertama pada fungsi yang bisa lama atau melakukan I/O.

## Membuat Context

```go
ctx := context.Background()   // akar, tidak pernah dibatalkan

ctx, cancel := context.WithCancel(ctx)
defer cancel()

ctx, cancel = context.WithTimeout(ctx, 2*time.Second)
defer cancel()

ctx, cancel = context.WithDeadline(ctx, waktu)
defer cancel()
```

## Mendengar Pembatalan

```go
select {
case <-ctx.Done():
    return ctx.Err()
case hasil := <-hasilChan:
    return hasil, nil
}
```

## Meneruskan ke Fungsi

```go
func ambil(ctx context.Context, url string) ([]byte, error) {
    req, _ := http.NewRequestWithContext(ctx, "GET", url, nil)
    return http.DefaultClient.Do(req)
}
```

Context selalu menjadi parameter **pertama**.

## WithValue

```go
type key struct{}
ctx = context.WithValue(ctx, key{}, "req-123")
id, _ := ctx.Value(key{}).(string)
```

Gunakan tipe kunci khusus (bukan string biasa) agar tidak bentrok antar package.

## Aturan

- Jangan simpan Context di struct; kirim sebagai argumen
- Jangan pakai `context.TODO()` permanen
- `cancel` wajib dipanggil walau operasi sukses
- WithValue bukan pengganti argumen fungsi

<div class="note">💡 Banyak fungsi standar seperti <code>http</code> dan <code>database/sql</code> sudah menerima context. Manfaatkan untuk menghentikan request saat klien memutus koneksi.</div>


## Try it Yourself

Ubah durasi timeout menjadi lebih panjang atau pendek.

<TryIt lang="go" runtime="piston" pistonName="go" code={`package main
import (
    "context"
    "fmt"
    "time"
)

func kerja(ctx context.Context) {
    for {
        select {
        case <-ctx.Done():
            fmt.Println("dihentikan:", ctx.Err())
            return
        default:
            time.Sleep(10 * time.Millisecond)
        }
    }
}

func main() {
    ctx, cancel := context.WithTimeout(context.Background(), 40*time.Millisecond)
    defer cancel()
    kerja(ctx)
}`} />
