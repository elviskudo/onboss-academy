Operator membuat ekspresi di Go jadi ringkas. Aturannya mirip bahasa C, tapi lebih sedikit dan lebih konsisten.

## Aritmetika

| Operator | Arti | Contoh | Hasil |
|---|---|---|---|
| `+` | Tambah | `7 + 2` | `9` |
| `-` | Kurang | `7 - 2` | `5` |
| `*` | Kali | `7 * 2` | `14` |
| `/` | Bagi | `7 / 2` | `3` untuk int |
| `%` | Sisa | `7 % 2` | `1` |

Untuk hasil desimal, salah satu operand harus `float64`:

```go
fmt.Println(7 / 2.0) // 3.5
```

## Perbandingan

`==`, `!=`, `>`, `<`, `>=`, `&lt;=` menghasilkan `bool`. Nilai dengan tipe berbeda tidak bisa dibandingkan langsung — kompiler akan menolak.

```go
var x int = 5
// fmt.Println(x == 5.0) // error: tipe berbeda
```

## Logika

- `&&` — AND, `||` — OR, `!` — NOT
- Keduanya memakai *short-circuit*

## Bitwise

`&`, `|`, `^`, `<<`, `>>`, dan `&^` (AND NOT) bekerja pada bit. Berguna untuk flag dan optimasi nivel rendah.

```go
const (
    Baca  = 1 << iota // 1
    Tulis             // 2
    Jalankan          // 4
)
fmt.Println(Baca | Tulis) // 3
```

## Penugasan Gabungan

`+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `|=`, `^=`, `<&lt;=`, `>>=`.

## Increment

Go hanya punya `x++` dan `x--` sebagai **statement**, bukan ekspresi. `y := x++` tidakvalid.

<div class="note">💡 Prioritas operator bisa diubah dengan kurung. Bila ragu, tambahkan kurung — kode jadi lebih jelas tanpa biaya performa.</div>
