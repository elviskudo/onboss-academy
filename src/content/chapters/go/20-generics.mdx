Generics hadir di Go 1.18. Mereka memungkinkan fungsi dan tipe ditulis sekali untuk banyak tipe tanpa kehilangan keamanan.

## Fungsi Generik

```go
func Pertama[T any](data []T) T {
    return data[0]
}
```

Tipe disimpulkan dari argumen:

```go
Pertama([]int{1, 2})       // T = int
Pertama([]string{"a", "b"}) // T = string
```

## Constraint

```go
func Maks[T comparable](a, b T) bool {
    return a == b
}
```

`comparable` hanya menerima tipe yang bisa dibandingkan dengan `==`.

## Constraint Kustom

```go
type Angka interface {
    ~int | ~int64 | ~float64
}

func Jumlah[T Angka](data []T) T {
    var total T
    for _, v := range data { total += v }
    return total
}
```

Tanda `~` berarti "semua tipe dengan underlying type ini", jadi `type Meter int` juga diterima.

## Tipe Generik

```go
type Kotak[T any] struct { Isi T }

func (k Kotak[T]) Ambil() T { return k.Isi }

k := Kotak[string]{Isi: "Halo"}
```

## Kapan Tidak Perlu Generics

| Gunakan | Kapan |
|---|---|
| `interface` | Perilaku berbeda per tipe, dispatch dinamis |
| Generics | Algoritma sama untuk banyak tipe |
| `any` | Tipe benar-benar tidak diketahui (JSON) |

Generics bukan pengganti interface. Keduanya saling melengkapi.

<div class="note">💡 Mulailah dengan fungsi konkret. Saat kamu menyalin kode yang sama untuk tiga tipe berbeda, baru pertimbangkan generics.</div>

Coba panggil `Jumlah` dengan `[]float64` atau buat `Kotak[bool]`.

import "fmt"

type Angka interface { ~int | ~int64 | ~float64 }

func Jumlah[T Angka](data []T) T {
    var total T
    for _, v := range data { total += v }
    return total
}

type Kotak[T any] struct{ Isi T }
func (k Kotak[T]) Ambil() T { return k.Isi }

func main() {
    fmt.Println("Int  :", Jumlah([]int{1, 2, 3, 4}))
    fmt.Println("Float:", Jumlah([]float64{1.5, 2.5}))

    k := Kotak[string]{Isi: "generics"}
    fmt.Println("Kotak:", k.Ambil())
}`} />
