Interface di Go adalah **kumpulan signature method**. Tidak ada kata kunci `implements`: jika tipe memiliki semua method yang diminta, tipe itu otomatis memenuhinya.

## Deklarasi & Implementasi

```go
type Suara interface {
    Bersuara() string
}

type Anjing struct{ Nama string }

func (a Anjing) Bersuara() string {
    return a.Nama + " woof"
}
```

`Anjing` tidak pernah menyebut `Suara` secara eksplisit. Hubungan ditemukan oleh kompiler saat penugasan.

## Interface Kecil

```go
type Pembaca interface { Baca([]byte) (int, error) }
type Penulis interface { Tulis([]byte) (int, error) }
```

Bandingkan dengan satu interface besar berisi keduanya: tipe yang hanya bisa membaca tetap bisa dipakai. Ini prinsip *Interface Segregation*.

## Stringer

```go
type Titik struct{ X, Y int }
func (t Titik) String() string {
    return fmt.Sprintf("(%d,%d)", t.X, t.Y)
}
fmt.Println(Titik{2, 3}) // (2,3)
```

## any / interface{}

Sejak Go 1.18, `any` adalah alias untuk `interface{}`. Berguna untuk fungsi generik sebelum ada generics, atau data JSON yang tipenya beragam.

```go
func cetak(v any) { fmt.Println(v) }
```

Tapi hindari memakainya secara berlebihan — kamu kehilangan keamanan tipe.

## Type Assertion

```go
nilai, ok := v.(int)
if ok {
    fmt.Println(nilai + 1)
}
```

Selalu gunakan bentuk dua nilai untuk menghindari panic.

<div class="note">💡 Interface di Go biasanya didefinisikan di sisi **pemakai**, bukan di sisi implementasi. Ini membuat paket tetap mandiri.</div>
