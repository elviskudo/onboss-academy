Go memperlakukan error sebagai **nilai biasa**. Tidak ada exception untuk alur normal, dan kompiler membantu memastikan kamu tidak mengabaikan hasil yang dikembalikan.

## Pola Dasar

```go
f, err := os.Open("data.txt")
if err != nil {
    return err
}
defer f.Close()
```

Pemeriksaan `if err != nil` langsung setelah panggilan adalah ritme khas Go.

## Membuat Error

```go
import "errors"

var ErrTidakAda = errors.New("data tidak ditemukan")

func cari(id int) error {
    if id < 1 { return ErrTidakAda }
    return nil
}
```

Sentinel error (variabel package-level) memungkinkan perbandingan dengan `errors.Is`.

## Menambah Konteks

```go
return fmt.Errorf("gagal memuat pengguna %d: %w", id, err)
```

`%w` membungkus error asli. `%v` hanya mengubahnya jadi teks — rantai hilang.

## errors.Is & errors.As

```go
if errors.Is(err, ErrTidakAda) { ... }

var pathErr *os.PathError
if errors.As(err, &pathErr) {
    fmt.Println(pathErr.Path)
}
```

`Is` mencocokkan sentinel; `As` mengambil error bertipe tertentu dari rantai.

## Error Kustom

```go
type ValidasiError struct { Field string }
func (e *ValidasiError) Error() string {
    return "field tidak valid: " + e.Field
}
```

## Kapan panic?

Error untuk kegagalan yang diharapkan (input, jaringan, file). Panic hanya untuk bug yang membuat program tidak bisa berlanjut.

<div class="note">💡 Jangan menulis <code>if err != nil { panic(err) }</code> di library. Kembalikan error dan biarkan pemanggil memutuskan.</div>


## Try it Yourself

Ubah input menjadi string kosong atau non-kosong untuk melihat cabang error.

<TryIt lang="go" runtime="piston" pistonName="go" code={`package main
import (
    "errors"
    "fmt"
)
var ErrKosong = errors.New("input kosong")

func hitung(s string) (int, error) {
    if s == "" { return 0, ErrKosong }
    return len(s) * 2, nil
}

func main() {
    for _, s := range []string{"Go", ""} {
        n, err := hitung(s)
        if errors.Is(err, ErrKosong) {
            fmt.Println(" dilewati:", err)
            continue
        }
        fmt.Printf(" %q -> %d\n", s, n)
    }
}`} />
