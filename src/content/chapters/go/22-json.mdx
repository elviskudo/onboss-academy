Package `encoding/json` adalah standar untuk bertukar data dengan API. Kuncinya adalah tag struct dan aturan ekspor field.

## Marshal

```go
type Siswa struct {
    Nama  string `json:"nama"`
    Umur  int    `json:"umur"`
    Aktif bool   `json:"aktif,omitempty"`
}

b, err := json.Marshal(Siswa{Nama: "Rani", Umur: 22})
// {"nama":"Rani","umur":22}
```

`omitempty` melewati field bernilai nol (string kosong, 0, false, nil).

## Unmarshal

```go
var s Siswa
err := json.Unmarshal([]byte(`{"nama":"Dimas","umur":20}`), &s)
```

Argumen kedua **harus pointer**, kalau tidak perubahan tidak tersimpan.

## Tag Kustom

| Tag | Efek |
|---|---|
| `json:"nama"` | Ganti kunci |
| `json:"-"` | Abaikan field |
| `json:",omitempty"` | Lewati nilai nol |
| `json:"id,string"` | Angka sebagai string |

## Indentasi

```go
b, _ := json.MarshalIndent(s, "", "  ")
fmt.Println(string(b))
```

## Streaming

Untuk file atau response besar, pakai `Decoder`/`Encoder` agar tidak memuat semua ke memori:

```go
enc := json.NewEncoder(os.Stdout)
enc.Encode(s)

dec := json.NewDecoder(resp.Body)
dec.Decode(&s)
```

## Field Tak Terduga

Secara default field JSON yang tidak dikenal diabaikan. Gunakan `dec.DisallowUnknownFields()` jika ingin ketat.

<div class="note">💡 JSON tidak punya tipe tanggal. Simpan waktu sebagai string RFC3339 dengan <code>time.Time</code> — Marshal/Unmarshal otomatis menangani formatnya.</div>
