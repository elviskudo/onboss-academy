Satu kata kunci, tiga bentuk. Setelah memahami `for`, kamu sudah bisa semua perulangan di Go.

## 3 Bentuk for

| Bentuk | Sintaks | Mirip dengan | Kapan dipakai |
| --- | --- | --- | --- |
| Klasik | `for i := 0; i < n; i++ {}` | for C/Java | Jumlah iterasi diketahui |
| Kondisi saja | `for kondisi {}` | while | Berhenti saat syarat terpenuhi |
| Tanpa kondisi | `for {}` + `break` | loop forever | Syarat baru diketahui di tengah jalan |

```go
for i := 1; i <= 3; i++ {
    fmt.Println("Perulangan ke-", i)
}

hitung := 3
for hitung > 0 {
    fmt.Println("Sisa", hitung)
    hitung--
}
```

## for Tanpa Kondisi

```go
total := 0
i := 1
for {
    if i > 100 {
        break
    }
    total += i
    i++
}
fmt.Println("Jumlah 1..100 =", total)
```

Loop tak berujung yang keluar lewat `break`. Wajib ada syarat keluar agar program tidak menggantung.

## range untuk Koleksi

```go
buah := []string{"Apel", "Mangga", "Jeruk"}

for i, b := range buah {
    fmt.Println(i, b)
}

for _, b := range buah {
    fmt.Println("Buah:", b)
}
```

Tanda `_` menampung index yang tidak dipakai — tanda ini wajib karena Go melarang variabel tak terpakai. `range` juga bekerja pada map, string, dan channel.

## break dan continue

```go
for i := 1; i <= 10; i++ {
    if i == 4 {
        continue // lewati 4
    }
    if i > 6 {
        break // berhenti total
    }
    fmt.Println(i) // 1 2 3 5 6
}
```

`break` keluar dari perulangan terdekat; `continue` langsung ke iterasi berikutnya. Label (`outer:`) bisa ditambahkan bila perlu memutus perulangan bersarang dari dalam.

## 4 Pola Klasik

- **Akumulasi**: `total += nilai` di dalam loop
- **Cari pertama**: `if ketemu { break }` — berhenti begitu ketemu
- **Filter → baru**: kumpulkan yang lolos syarat ke slice baru lewat `append`
- **Hitung frekuensi**: `map[string]int` — tiap kemunculan `hitung[k]++`

```go
angka := []int{3, 8, 3, 1, 8, 3}
frek := map[int]int{}
for _, n := range angka {
    frek[n]++
}
fmt.Println(frek) // map[1:1 3:3 8:2]
```

## Di Dunia Nyata

- **Retry API**: `for i := 0; i < 3; i++ { ... }` dengan `time.Sleep` antar percobaan
- **Batch proses**: `for _, user := range users` mengirim email ke 1000 penerima
- **Menghitung faktorial**: akumulasi `hasil *= i` dari 1 sampai n
- **Scan sampai EOF**: `for { b, err := reader.Read(...); ... }` membaca stream tanpa tahu panjangnya
- **Agregasi penjualan**: frekuensi produk terjual dari daftar transaksi memakai map

<div class="note">💡 for i := range n (Go 1.22+) membuat i berjalan dari 0 sampai n-1. Versi lama menulis for i := 0; i < n; i++ — keduanya benar tergantung versi Go yang dipakai.</div>
