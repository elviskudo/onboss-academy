Go menjadikan testing bagian dari standar library — tidak perlu paket pihak ketiga untuk memulai.

## Test Pertama

```go
// kalkulator_test.go
package kalkulator

import "testing"

func TestTambah(t *testing.T) {
    if hasil := Tambah(2, 3); hasil != 5 {
        t.Errorf("Tambah(2,3) = %d, ingin 5", hasil)
    }
}
```

Jalankan dengan:

```bash
go test ./...
```

## Table-Driven Test

Pola paling populer di komunitas Go:

```go
func TestBagi(t *testing.T) {
    cases := []struct {
        a, b, want int
    }{
        {10, 2, 5},
        {9, 3, 3},
        {7, 0, 0},
    }
    for _, c := range cases {
        t.Run(fmt.Sprintf("%d/%d", c.a, c.b), func(t *testing.T) {
            if got := Bagi(c.a, c.b); got != c.want {
                t.Errorf("dapat %d, ingin %d", got, c.want)
            }
        })
    }
}
```

## Assertion & Fatal

| Method | Efek |
|---|---|
| `t.Error` | Tandai gagal, lanjut |
| `t.Fatal` | Tandai gagal, hentikan test ini |
| `t.Log` | Info tambahan (muncul dengan `-v`) |
| `t.Skip` | Lewati test |
| `t.Helper` | Tandai fungsi pembantu agar lokasi error tepat |

## Coverage

```bash
go test -cover ./...
go test -coverprofile=cover.out ./...
go tool cover -html=cover.out
```

## Benchmark

```go
func BenchmarkTambah(b *testing.B) {
    for i := 0; i < b.N; i++ {
        Tambah(i, 1)
    }
}
```

Jalankan dengan `go test -bench=.`.

<div class="note">💡 Fungsi test harus diawali huruf kapital <code>Test</code> dan berada di package yang sama (atau `_test`) agar terlihat oleh <code>go test</code>.</div>
