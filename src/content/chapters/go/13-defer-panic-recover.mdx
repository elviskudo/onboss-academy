Go tidak punya `try/catch`. Sebagai gantinya ada tiga alat: `defer` untuk membersihkan resource, `panic` untuk kondisi fatal, dan `recover` untuk mencegah program berhenti.

## defer

```go
func baca(nama string) {
    f, err := os.Open(nama)
    if err != nil { return }
    defer f.Close()   // dijalankan tepat sebelum fungsi kembali

    // ... gunakan f ...
}
```

Beberapa `defer` berjalan dengan urutan terbalik:

```go
defer fmt.Println("satu")
defer fmt.Println("dua")
// Output: dua, satu
```

Argumen `defer` dievaluasi **saat didaftarkan**, bukan saat dieksekusi:

```go
i := 1
defer fmt.Println(i) // tetap mencetak 1
i = 2
```

## panic

```go
if divisor == 0 {
    panic("pembagian dengan nol")
}
```

Panic menghentikan eksekusi fungsi, menjalankan semua `defer`, lalu menuliskan stack trace. Gunakan hanya untuk bug yang tidak bisa dipulihkan.

## recover

```go
func aman() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("tertahan:", r)
        }
    }()
    panic("boom")
}
```

Tanpa `defer`, `recover()` selalu mengembalikan `nil`. Setelah pulih, fungsi **tidak** melanjutkan baris setelah `panic` — ia langsung kembali.

## Praktik Baik

| Situasi | Gunakan |
|---|---|
| File tidak ditemukan | `error` |
| Argumen salah dari input pengguna | `error` |
| Invariant internal rusak | `panic` |
| membersihkan resource | `defer` |

<div class="note">💡 Di library, hindari <code>panic</code> untuk kesalahan yang bisa dikembalikan sebagai <code>error</code>. Biarkan aplikasi yang memutuskan cara menangani.</div>
