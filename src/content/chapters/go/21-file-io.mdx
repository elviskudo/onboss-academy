Operasi file di Go memakai package `os` dan `io`. Polanya konsisten: hampir semua fungsi mengembalikan `(nilai, error)`.

## Baca & Tulis Sekali Jalan

```go
data, err := os.ReadFile("data.txt")
if err != nil { return err }
fmt.Println(string(data))

err = os.WriteFile("keluar.txt", []byte("isi baru"), 0644)
```

`os.WriteFile` menimpa file. Untuk mode tambah:

```go
f, err := os.OpenFile("log.txt", os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0644)
defer f.Close()
fmt.Fprintln(f, "baris baru")
```

## Baris per Baris

```go
f, err := os.Open("data.txt")
if err != nil { return err }
defer f.Close()

scanner := bufio.NewScanner(f)
for scanner.Scan() {
    fmt.Println(scanner.Text())
}
if err := scanner.Err(); err != nil { return err }
```

Scanner default membatasi token 64 KB. Untuk baris sangat panjang, gunakan `bufio.Reader`.

## Path & Direktori

```go
path := filepath.Join("data", "user", "profil.json")
os.MkdirAll("data/user", 0755)
filepath.Ext(path) // ".json"
```

`filepath.Join` menghindari masalah slash pada Windows vs Unix.

## Informasi File

```go
info, err := os.Stat(path)
fmt.Println(info.Size(), info.ModTime(), info.IsDir())
```

## JSON

```go
data, _ := json.Marshal(apps)
os.WriteFile("apps.json", data, 0644)
```

<div class="note">💡 Selalu cek error dari <code>scanner.Err()</code> setelah loop. Tanpa itu, file yang terpotong bisa terlihat seolah selesai dengan sukses.</div>
