Channel adalah pipa untuk mengirim nilai antar goroutine. Filosofinya terkenal: *"Jangan berkomunikasi dengan berbagi memori; bagikan memori dengan berkomunikasi."*

## Dasar

```go
ch := make(chan int)        // unbuffered
ch <- 10                    // kirim
nilai := <-ch               // terima
```

Pada channel unbuffered, pengirim menunggu sampai ada penerima — keduanya bertemu (rendezvous).

## Buffered Channel

```go
ch := make(chan int, 3)
ch <- 1
ch <- 2
fmt.Println(len(ch)) // 2
```

Kirim tidak langsung menunggu selama buffer belum penuh.

## Menutup Channel

```go
close(ch)

for nilai := range ch {
    fmt.Println(nilai)
}
```

`range` otomatis berhenti saat channel ditutup dan habis. Hanya **pengirim** yang sebaiknya menutup channel.

## Arah Channel

```go
func kirim(out chan<- int) { out <- 1 }
func baca(in <-chan int) { fmt.Println(<-in) }
```

Membatasi arah membuat kontrak fungsi lebih jelas.

## select

```go
select {
case v := <-ch1:
    fmt.Println("dari ch1:", v)
case ch2 <- "x":
    fmt.Println("ch2 terkirim")
case <-time.After(time.Second):
    fmt.Println("timeout")
}
```

Jika beberapa kasus siap, Go memilih salah satu secara acak. `select {}` tanpa kasus mem-blok selamanya — berguna untuk menjaga goroutine tetap hidup.

## Worker Pool

```go
jobs := make(chan int)
for w := 0; w < 3; w++ {
    go func() {
        for j := range jobs { fmt.Println(j) }
    }()
}
```

<div class="note">💡 Channel bukan pengganti mutex untuk semua kasus. Untuk melindungi satu variabel sederhana, <code>sync.Mutex</code> sering lebih jelas.</div>
