`switch` di Go lebih fleksibel daripada di kebanyakan bahasa. Kamu bisa memakainya sebagai pengganti rantai `if` yang panjang.

## Switch Biasa

```go
switch hari {
case "Senin", "Selasa":
    fmt.Println("Awal pekan")
case "Sabtu", "Minggu":
    fmt.Println("Akhir pekan")
default:
    fmt.Println("Hari kerja biasa")
}
```

Beberapa nilai boleh ditulis dalam satu `case` memakai koma. Tidak ada `break` otomatis — setelah `case` selesai, switch langsung keluar.

## Fallthrough

```go
switch skor {
case 100:
    fmt.Println("Sempurna!")
    fallthrough
default:
    fmt.Println("Tetap lanjut belajar")
}
```

`fallthrough` memaksa masuk ke `case` berikutnya. Gunakan dengan hati-hati; jarang diperlukan dalam kode sehari-hari.

## Switch Tanpa Ekspresi

```go
switch {
case umur < 13:
    fmt.Println("Anak")
case umur < 18:
    fmt.Println("Remaja")
default:
    fmt.Println("Dewasa")
}
```

Ini setara dengan `if / else if / else`, tapi lebih mudah dibaca saat ada banyak kondisi.

## Type Switch

```go
func ketahu(x interface{}) {
    switch v := x.(type) {
    case int:
        fmt.Println("int", v*2)
    case string:
        fmt.Println("string", v)
    default:
        fmt.Printf("tipe lain: %T\n", v)
    }
}
```

`v` otomatis bertipe sesuai `case` yang cocok. Pola ini sering dipakai saat memproses data JSON heterogen.

<div class="note">💡 Letakkan <code>default</code> di mana pun kamu mau — Go tidak mengharuskannya di akhir.</div>
