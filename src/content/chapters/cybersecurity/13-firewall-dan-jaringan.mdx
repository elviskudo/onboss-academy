Firewall mengendalikan lalu lintas, tetapi kekuatannya bergantung pada aturan yang dibuat. Aturan yang terlalu longgar membuat investasi perangkat menjadi sia-sia.

## Default Deny

```text
[ blokir semua ]
[ izinkan HTTP/HTTPS dari publik ke DMZ ]
[ izinkan DMZ -> database hanya di port 5432 ]
[ izinkan admin -> DMZ lewat bastion ]
```

Aturan dievaluasi dari atas; aturan pertama yang cocok biasanya menang.

## Zona

| Zona | Isi | Akses keluar |
|---|---|---|
| Internet | Publik | Terbatas ke DMZ |
| DMZ | Web, mail, API publik | Hanya ke service yang dibutuhkan |
| Internal | Karyawan & aplikasi | Internet lewat proxy |
| Management | Bastion, monitoring | Sangat terbatas |

## Stateful vs Stateless

Stateless memeriksa tiap paket secara mandiri. Stateful menyimpan tabel koneksi sehingga paket balasan diizinkan otomatis. Kebanyakan firewall modern stateful, tetapi aturan eksplisit tetap diperlukan untuk trafik baru.

## Segmentasi Mikro

```text
web  ──> api  ──> db
 │       │       │
 └── hanya port yang dibutuhkan yang dibuka
```

Micro-segmentasi membatasi jalur antar layanan. Penyerang yang menguasai web tidak otomatis bisa masuk database.

<div class="note">💡 Aturan firewall perlu ditinjau saat aplikasi berubah. Aturan "sementara untuk debugging" yang dibiarkan sering menjadi pintu masuk permanen.</div>
