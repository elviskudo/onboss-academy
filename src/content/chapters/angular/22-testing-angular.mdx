Testing membuat refactor lebih aman. Angular sudah menyediakan TestBed untuk merakit komponen dalam lingkungan terkontrol.

## Test Service

```typescript
import { TestBed } from "@angular/core/testing";
import { KeranjangService } from "./keranjang.service";

describe("KeranjangService", () => {
  it("menambah item", () => {
    TestBed.configureTestingModule({});
    const service = TestBed.inject(KeranjangService);

    service.tambah("Kopi");
    expect(service.daftar()).toEqual(["Kopi"]);
  });
});
```

## Test Komponen

```typescript
import { ComponentFixture, TestBed } from "@angular/core/testing";
import { KartuComponent } from "./kartu.component";

describe("KartuComponent", () => {
  let fixture: ComponentFixture<KartuComponent>;

  beforeEach(async () => {
    await TestBed.configureTestingModule({
      imports: [KartuComponent],
    }).compileComponents();

    fixture = TestBed.createComponent(KartuComponent);
  });

  it("menampilkan judul", () => {
    fixture.componentInstance.judul = "Promo";
    fixture.detectChanges();
    expect(fixture.nativeElement.textContent).toContain("Promo");
  });
});
```

`detectChanges()` memicu change detection agar template diperbarui.

## Mock Service

```typescript
const apiFake = { daftar: () => of([{ id: 1, nama: "Kopi" }]) };

TestBed.configureTestingModule({
  imports: [DaftarComponent],
  providers: [{ provide: ProdukService, useValue: apiFake }],
});
```

## Test HTTP

```typescript
provideHttpClient(),
provideHttpClientTesting(),

const http = TestBed.inject(HttpTestingController);
service.daftar().subscribe();
http.expectOne("/api/produk").flush([{ id: 1 }]);
http.verify();
```

<div class="note">💡 Uji hasil yang terlihat pengguna (teks, atribut, perilaku), bukan detail implementasi. Test yang terlalu rapuh akan sering gagal saat kode diperbaiki.</div>
