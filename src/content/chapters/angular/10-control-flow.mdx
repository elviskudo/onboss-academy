Angular 17 memperkenalkan sintaks control flow yang lebih mudah dibaca daripada direktif struktural lama.

## @if

```html
@if (sudahLogin) {
  <p>Selamat datang kembali!</p>
} @else if (memuat) {
  <p>Memeriksa sesi…</p>
} @else {
  <a routerLink="/login">Masuk</a>
}
```

## @for

```html
<ul>
  @for (produk of produkList; track produk.id; let i = $index) {
    <li>
      {{ i + 1 }}. {{ produk.nama }} — Rp{{ produk.harga }}
    </li>
  } @empty {
    <li>Belum ada produk.</li>
  }
</ul>
```

`track` bersifat wajib. Pilih ID yang stabil, jangan index bila daftar bisa diurut ulang.

## @switch

```html
@switch (status) {
  @case ("lunas") { <span class="hijau">Lunas</span> }
  @case ("pending") { <span class="kuning">Menunggu</span> }
  @default { <span>Status tidak diketahui</span> }
}
```

## Perbandingan dengan Direktif Lama

| Lama | Baru |
|------|------|
| `*ngIf="kondisi"` | `@if (kondisi) { }` |
| `*ngFor="let i of items"` | `@for (i of items; track i.id) { }` |
| `ngSwitch` | `@switch` |

Keduanya masih didukung, tapi blok baru lebih disarankan untuk proyek baru.

<div class="note">💡 Control flow baru tidak perlu mengimpor `CommonModule` untuk `@if`/`@for` — compiler Angular menangani langsung bloknya.</div>
