Setiap komponen punya siklus hidup: dibuat, diperbarui, lalu dihancurkan. Hook memberi titik masuk di setiap fase.

## Peta Hook

| Hook | Dipanggil saat | Kegunaan |
|------|----------------|----------|
| `ngOnChanges` | input berubah | reaksi terhadap perubahan props |
| `ngOnInit` | setelah inisialisasi | ambil data awal |
| `ngDoCheck` | tiap pengecekan | deteksi kustom (jarang) |
| `ngAfterViewInit` | view siap | akses DOM/@ViewChild |
| `ngOnDestroy` | sebelum dihapus | cleanup |

## Contoh Lengkap

```typescript
import { Component, OnInit, OnDestroy, Input, OnChanges, SimpleChanges } from "@angular/core";

@Component({
  selector: "app-penghitung",
  standalone: true,
  template: `<p>{{ detik }}</p>`,
})
export class PenghitungComponent implements OnInit, OnChanges, OnDestroy {
  @Input() mulai = 0;
  detik = 0;
  private timer?: ReturnType<typeof setInterval>;

  ngOnChanges(changes: SimpleChanges) {
    if (changes["mulai"]) {
      this.detik = changes["mulai"].currentValue;
    }
  }

  ngOnInit() {
    this.timer = setInterval(() => this.detik++, 1000);
  }

  ngOnDestroy() {
    if (this.timer) clearInterval(this.timer);
  }
}
```

## Mengakses View

```typescript
import { Component, ElementRef, ViewChild, AfterViewInit } from "@angular/core";

@Component({
  standalone: true,
  template: `<input #kolom>`,
})
export class FokusComponent implements AfterViewInit {
  @ViewChild("kolom") kolom?: ElementRef<HTMLInputElement>;

  ngAfterViewInit() {
    this.kolom?.nativeElement.focus();
  }
}
```

## Efek dengan destroyRef

```typescript
import { inject, DestroyRef } from "@angular/core";

const destroyRef = inject(DestroyRef);
destroyRef.onDestroy(() => console.log("komponen dibersihkan"));
```

<div class="note">💡 Inisialisasi yang bergantung pada input sebaiknya di `ngOnChanges`, bukan di constructor — pada saat constructor, input belum tentu tersedia.</div>
