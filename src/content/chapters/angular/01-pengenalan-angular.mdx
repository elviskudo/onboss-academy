Angular adalah framework untuk membangun aplikasi web skala besar dengan struktur yang konsisten. Bab ini memetakan cara kerjanya sebelum kita menyentuh kode komponen.

## Apa Itu Angular?

Angular mengurus hampir semua kebutuhan aplikasi di dalam satu tempat:

- **Komponen** untuk tampilan
- **Service & Dependency Injection** untuk logika dan data
- **Routing** bawaan untuk navigasi antar halaman
- **Form** bawaan untuk input dan validasi
- **HTTP client** untuk berbicara dengan API

Karena keputusannya sudah dibuat framework, tim tinggal mengikuti konvensi — bagus untuk proyek besar dengan banyak developer.

## TypeScript: JavaScript yang Terstruktur

```typescript
function sapa(nama: string, ulang: number = 1): string {
  return nama.repeat(ulang);
}

interface Produk {
  id: number;
  nama: string;
  harga: number;
  stok?: boolean; // tanda ? = boleh kosong
}

const kopi: Produk = { id: 1, nama: "Kopi", harga: 25000 };
```

Anotasi tipe (`: string`) membuat IDE menangkap kesalahan sebelum kode dijalankan — manfaat utama TypeScript di proyek nyata.

## Dua Bagian Utama Komponen

```typescript
@Component({
  selector: "app-sapa",
  template: `<h1>Halo, {{ nama }}!</h1>`,
})
class SapaComponent {
  nama = "OnBoss";
}
```

Setiap komponen Angular punya **decorator** `@Component` yang memuat template (tampilan) dan class TypeScript (logika). Pola ini muncul terus di bab-bab berikutnya.

## Arsitektur Proyek

Struktur hasil `ng new` umumnya:

```
src/app/
  app.component.ts   komponen akar
  app.routes.ts      daftar rute
  app.config.ts      konfigurasi provider
  produk/            fitur dalam folder sendiri
```

Kode disusun per **fitur**, bukan per jenis file — memudahkan navigasi tim.

## Enam Konsep Inti

Angular modern memiliki **6 konsep inti** yang akan selalu bertemu dalam aplikasi nyata.

| Konsep | Fungsi | Contoh | Kapan dipakai |
|---|---|---|---|
| Component | Membentuk bagian UI | kartu produk | Setiap tampilan mandiri |
| Signal | Menyimpan state reaktif | `signal(0)` | Nilai berubah dan dibaca template |
| Template | Mendeskripsikan HTML | `@if`, `@for` | Menampilkan data dan kondisi |
| Service | Memusatkan logika | `ProdukService` | Logika dipakai banyak komponen |
| Dependency injection | Menyediakan dependensi | `inject(ProdukService)` | Menghindari pembuatan instance manual |
| Router | Memetakan URL | `/produk/:id` | Aplikasi punya beberapa halaman |

State lokal modern disimpan dengan signal. Berbeda dari variabel biasa, pembacaan signal dilacak Angular sehingga bagian template yang bergantung padanya diperbarui.

```typescript
import { Component, signal } from "@angular/core";

@Component({
  selector: "app-counter",
  standalone: true,
  template: `<button (click)="tambah()">Klik {{ jumlah() }}</button>`,
})
export class CounterComponent {
  jumlah = signal(0);
  tambah() {
    this.jumlah.update((nilai) => nilai + 1);
  }
}
```

## Alur Kerja Angular

Ada **4 tahap utama**: browser membuka URL, router memilih komponen, template membaca state, lalu event pengguna memperbarui state. Angular menjalankan change detection dan menyelaraskan DOM. Untuk aplikasi baru, mulai dengan standalone component; NgModule terutama relevan ketika memelihara kode lama.

## Di Dunia Nyata

- Dasbor operasional memakai component dan signal untuk memperbarui angka pesanan.
- Katalog toko memakai router untuk halaman daftar dan detail produk.
- Portal bank menaruh autentikasi dan akses API di service terinjeksi.
- Form administrasi memakai TypeScript agar bentuk data salah terdeteksi sebelum rilis.
