Routing Angular lebih dari sekadar pindah halaman. Dengan lazy loading dan parameter, rute menjadi fondasi arsitektur aplikasi.

## Rute dengan Parameter

```typescript
export const routes: Routes = [
  { path: "produk/:id", component: DetailComponent },
];
```

```typescript
const route = inject(ActivatedRoute);

route.paramMap.subscribe((params) => {
  const id = Number(params.get("id"));
  this.api.detail(id).subscribe((p) => this.produk = p);
});
```

## Query Params

```typescript
// /produk?cari=kopi&halaman=2
route.queryParamMap.subscribe((q) => {
  this.kata = q.get("cari") ?? "";
  this.halaman = Number(q.get("halaman") ?? 1);
});

// memperbarui URL dari kode
router.navigate([], { queryParams: { cari: "kopi" } });
```

Query params bagus untuk filter karena bisa disalin dan dibuka ulang.

## Lazy Loading

```typescript
{
  path: "admin",
  loadChildren: () => import("./admin/admin.routes")
    .then((m) => m.ADMIN_ROUTES),
}
```

Atau untuk satu komponen:

```typescript
{
  path: "laporan",
  loadComponent: () => import("./laporan/laporan.component")
    .then((m) => m.LaporanComponent),
}
```

## Child Route

```typescript
{
  path: "akun",
  component: AkunLayoutComponent,
  children: [
    { path: "profil", component: ProfilComponent },
    { path: "pesanan", component: PesananComponent },
  ],
}
```

Di `AkunLayoutComponent` tetap perlu `<router-outlet />` untuk menampilkan anak.

## Wildcard

```typescript
{ path: "**", component: TidakDitemukanComponent }
```

Taruh paling bawah — rute dibaca berurutan.

<div class="note">💡 Anggap URL sebagai bagian dari UI. Kalau filter dan status halaman tercermin di URL, user bisa refresh atau membagikan tautan tanpa kehilangan konteks.</div>
