Template Angular adalah HTML yang diperluas dengan expression binding. Memahami empat bentuk dasarnya membuat halaman menjadi hidup.

## Empat Jenis Binding

| Bentuk | Nama | Arah |
|--------|------|------|
| `{{ nilai }}` | Interpolasi | data → teks |
| `[src]="url"` | Properti | data → DOM |
| `(click)="simpan()"` | Event | DOM → komponen |
| `[(ngModel)]="nama"` | Dua arah | keduanya |

## Interpolasi

```html
<h1>Halo, {{ nama }}!</h1>
<p>Total: {{ harga * jumlah | currency:'IDR' }}</p>
```

Expression di dalam `{{ }}` dievaluasi ulang saat data berubah. Jangan taruh perhitungan berat di sana.

## Properti vs Atribut

```html
<!-- properti DOM -->
<img [src]="fotoProduk" [disabled]="tidakAktif">

<!-- atribut HTML -->
<div [attr.aria-label]="judul">...</div>

<!-- kelas dan style -->
<div [class.aktif]="sudahBayar" [style.color]="warna">...</div>
```

Gunakan `[attr.x]` bila memang ingin menulis atribut HTML, misalnya `aria-*` atau `data-*`.

## Event Binding

```html
<button (click)="tambah()">Tambah</button>
<input (input)="onCari($event)">
```

Di komponen:

```typescript
onCari(event: Event) {
  const nilai = (event.target as HTMLInputElement).value;
  console.log(nilai);
}
```

## Dua Arah dengan ngModel

```typescript
import { FormsModule } from "@angular/forms";

@Component({
  standalone: true,
  imports: [FormsModule],
  template: `<input [(ngModel)]="nama"><p>Halo {{ nama }}</p>`,
})
class ProfilComponent {
  nama = "Sari";
}
```

`[(ngModel)]` adalah singkatan dari `[ngModel]` + `(ngModelChange)`.

<div class="note">💡 Baca `[x]` sebagai "masukkan nilai ke x", `(x)` sebagai "saat x terjadi", dan `[(x)]` sebagai "keduanya". Pola ini berlaku konsisten di seluruh Angular.</div>
