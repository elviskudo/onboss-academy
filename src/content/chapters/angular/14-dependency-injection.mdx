Dependency Injection (DI) membuat komponen tidak perlu membuat sendiri objek yang ia butuhkan. Angular yang menyediakannya.

## Service Singleton

```typescript
import { Injectable } from "@angular/core";

@Injectable({ providedIn: "root" })
export class KeranjangService {
  private items: string[] = [];

  tambah(nama: string) { this.items.push(nama); }
  daftar() { return [...this.items]; }
}
```

Pemakaian di komponen:

```typescript
export class HeaderComponent {
  private keranjang = inject(KeranjangService);

  get jumlah() { return this.keranjang.daftar().length; }
}
```

## InjectionToken

```typescript
import { InjectionToken } from "@angular/core";

export const API_URL = new InjectionToken<string>("API_URL");

// di app.config.ts
export const appConfig: ApplicationConfig = {
  providers: [{ provide: API_URL, useValue: "/api/v1" }],
};

// di service
const url = inject(API_URL);
```

## Beberapa Bentuk Provider

| Bentuk | Fungsi |
|--------|--------|
| `useValue` | nilai tetap |
| `useClass` | kelas pengganti |
| `useFactory` | dibuat lewat fungsi |
| `useExisting` | alias ke provider lain |

```typescript
{ provide: Logger, useClass: LoggerProduksi }
{ provide: MODE, useFactory: () => isDevMode() ? "dev" : "prod" }
```

## Hierarki

Provider di root terlihat semua komponen. Provider di komponen hanya terlihat komponen itu dan anaknya. Ini berguna untuk state yang memang lokal per fitur.

<div class="note">💡 DI bukan sekadar "new otomatis". Dengan token dan provider, kamu bisa mengganti implementasi saat testing tanpa mengubah kode komponen.</div>
