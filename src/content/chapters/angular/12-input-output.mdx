Komponen yang baik tidak mengetahui terlalu banyak tentang induknya. Ia menerima data lewat input dan melaporkan kejadian lewat output.

## Input Klasik

```typescript
import { Component, Input } from "@angular/core";

@Component({
  selector: "app-kartu",
  standalone: true,
  template: `<h3>{{ judul }}</h3><p>{{ deskripsi }}</p>`,
})
export class KartuComponent {
  @Input() judul = "";
  @Input() deskripsi = "";
}
```

## Output Klasik

```typescript
import { Component, Output, EventEmitter } from "@angular/core";

export class KartuComponent {
  @Output() dipilih = new EventEmitter<string>();

  pilih() {
    this.dipilih.emit("Kartu dipilih");
  }
}
```

Di induk:

```html
<app-kartu
  judul="Promo"
  (dipilih)="bukaDetail($event)"
/>
```

## Gaya Signal Modern

```typescript
import { Component, input, output } from "@angular/core";

@Component({
  selector: "app-kartu",
  standalone: true,
  template: `
    <h3>{{ judul() }}</h3>
    <button (click)="pilih.emit(judul())">Pilih</button>
  `,
})
export class KartuComponent {
  judul = input.required<string>();
  pilih = output<string>();
}
```

## Two-way dengan model()

```typescript
export class InputNamaComponent {
  nama = model("");
}
```

```html
<app-input-nama [(nama)]="namaUser" />
```

Anak bisa mengubah `nama()` dan nilainya langsung kembali ke induk.

<div class="note">💡 Jangan mengubah `@Input` secara langsung di dalam anak. Kirim event agar induk yang memutuskan — data tetap mengalir satu arah dan lebih mudah dilacak.</div>
