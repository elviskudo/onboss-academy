Aplikasi yang siap pakai banyak wilayah perlu memisahkan teks dari kode. Angular memiliki dukungan i18n bawaan.

## Menandai Teks

```html
<h1 i18n="judul||Judul di halaman utama">Selamat datang</h1>
<p i18n>Pesanan kamu sudah diproses.</p>
```

`ng extract-i18n` menghasilkan `messages.xlf` berisi semua teks yang ditandai.

## Menyiapkan Locale

```typescript
import { registerLocaleData } from "@angular/common";
import localeId from "@angular/common/locales/id";

registerLocaleData(localeId, "id");

export const appConfig: ApplicationConfig = {
  providers: [{ provide: LOCALE_ID, useValue: "id" }],
};
```

## Format Tanggal dan Uang

```html
{{ 25000 | currency:'IDR':'symbol':'1.0-0' }}
{{ hariIni | date:'EEEE, dd MMMM yyyy':'':'id-ID' }}
{{ 0.125 | percent }}
```

## Struktur Terjemahan

```
src/
  i18n/
    messages.id.xlf
    messages.en.xlf
```

Build per bahasa:

```bash
ng build --localize
```

Angular menghasilkan folder terpisah untuk tiap locale.

## Tips

- Beri deskripsi pada `i18n` agar penerjemah mengerti konteks.
- Hindari menggabungkan dua kalimat dalam satu interpolasi.
- Simpan format tanggal di pipe, bukan string manual.

<div class="note">💡 i18n bukan hanya mengganti kata. Urutan kata, format tanggal, dan arah tulis juga bagian dari pengalaman lokal.</div>
