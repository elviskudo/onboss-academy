Mari satukan semua konsep menjadi aplikasi katalog produk dengan login dan keranjang.

## Struktur

```
src/app/
  app.config.ts
  app.routes.ts
  core/
    auth.service.ts
    produk.service.ts
    keranjang.store.ts
  features/
    produk/daftar.component.ts
    produk/detail.component.ts
    auth/login.component.ts
  shared/
    kartu.component.ts
```

## Rute

```typescript
export const routes: Routes = [
  { path: "", component: DaftarComponent },
  { path: "produk/:id", component: DetailComponent },
  {
    path: "admin",
    canActivate: [authGuard],
    loadComponent: () => import("./admin/admin.component")
      .then((m) => m.AdminComponent),
  },
  { path: "login", component: LoginComponent },
  { path: "**", component: TidakDitemukanComponent },
];
```

## Daftar Produk

```typescript
@Component({
  standalone: true,
  imports: [KartuComponent, AsyncPipe],
  template: `
    <h1>Katalog Produk</h1>
    @if (produk$ | async; as daftar) {
      <div class="grid">
        @for (p of daftar; track p.id) {
          <app-kartu [judul]="p.nama" [harga]="p.harga" />
        } @empty {
          <p>Belum ada produk.</p>
        }
      </div>
    }
  `,
})
export class DaftarComponent {
  private api = inject(ProdukService);
  produk$ = this.api.daftar();
}
```

## Keranjang

```typescript
export class RingkasanComponent {
  private keranjang = inject(KeranjangStore);
  total = this.keranjang.total;
  jumlah = this.keranjang.jumlah;
}
```

## Checklist

- [ ] Semua `@for` punya `track`.
- [ ] Service dipakai untuk semua request API.
- [ ] Rute sensitif punya guard.
- [ ] Form punya validasi.
- [ ] `ng build` sukses.

<div class="note">💡 Bangun bertahap: mulai dari daftar statis, lalu tambahkan API, lalu guard, lalu keranjang. Setiap langkah bisa diuji sebelum lanjut.</div>
