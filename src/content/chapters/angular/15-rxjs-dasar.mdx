RxJS adalah fondasi reactive programming di Angular. HttpClient, router, dan form semuanya mengembalikan Observable.

## Observable

```typescript
import { Observable } from "rxjs";

const aliran = new Observable<string>((subscriber) => {
  subscriber.next("Halo");
  subscriber.next("Dunia");
  subscriber.complete();
});

aliran.subscribe({
  next: (n) => console.log(n),
  complete: () => console.log("selesai"),
});
```

Berbeda dengan Promise, Observable bisa mengirim banyak nilai.

## Operator Umum

```typescript
import { of, map, filter, reduce } from "rxjs";

of(1, 2, 3, 4).pipe(
  filter((n) => n % 2 === 0),
  map((n) => n * 10),
  reduce((a, b) => a + b, 0)
).subscribe(console.log); // 60
```

| Operator | Fungsi |
|----------|--------|
| `map` | ubah nilai |
| `filter` | pilih nilai |
| `take` | ambil N nilai |
| `debounceTime` | tunggu jeda |
| `distinctUntilChanged` | lewati nilai sama |
| `switchMap` | pindah ke stream baru |

## Contoh Pencarian

```typescript
this.kataCari.valueChanges.pipe(
  debounceTime(300),
  distinctUntilChanged(),
  switchMap((kata) => this.api.cari(kata))
).subscribe((hasil) => this.hasil = hasil);
```

`switchMap` membatalkan pencarian lama saat user mengetik lagi.

## Cleanup

```typescript
private destroy$ = new Subject<void>();

ngOnDestroy() {
  this.destroy$.next();
  this.destroy$.complete();
}

// di pipe: takeUntil(this.destroy$)
```

Atau pakai `take(1)` bila hanya butuh satu nilai.

<div class="note">💡 Pikirkan Observable sebagai "pipa". Operator adalah saringan dan pengubah di sepanjang pipa; subscriber adalah keran yang membuka aliran.</div>
