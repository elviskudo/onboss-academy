Pipe mengubah data tepat sebelum ditampilkan. Angular sudah punya `date`, `currency`, `uppercase`, dan lain-lain — kamu juga bisa membuat sendiri.

## Membuat Pipe

```typescript
import { Pipe, PipeTransform } from "@angular/core";

@Pipe({ name: "pangkas" })
export class PangkasPipe implements PipeTransform {
  transform(nilai: string, panjang = 20): string {
    if (!nilai) return "";
    return nilai.length > panjang
      ? nilai.slice(0, panjang).trimEnd() + "…"
      : nilai;
  }
}
```

Daftarkan di `imports` komponen standalone:

```typescript
@Component({
  standalone: true,
  imports: [PangkasPipe],
  template: `<p>{{ deskripsi | pangkas:40 }}</p>`,
})
export class KartuComponent {
  deskripsi = "Belajar Angular itu menyenangkan dan terstruktur.";
}
```

## Async Pipe

```typescript
export class BeritaComponent {
  private api = inject(ApiService);
  berita$ = this.api.daftarBerita();
}
```

```html
@if (berita$ | async; as daftar) {
  <ul>
    @for (b of daftar; track b.id) { <li>{{ b.judul }}</li> }
  </ul>
} @else {
  <p>Memuat…</p>
}
```

Angular berlangganan saat komponen tampil dan berhenti saat dihancurkan.

## Pure vs Impure

```typescript
@Pipe({ name: "cepat", pure: true })  // default
```

Pipe pure hanya dijalankan bila referensi input berubah. Hindari pipe impure kecuali memang perlu memantau perubahan dalam objek yang dimutasi.

<div class="note">💡 Pisahkan perhitungan dan tampilan: pipe cocok untuk format, tetapi logika bisnis sebaiknya tetap di service atau method komponen.</div>
