Guard menjaga rute tertentu agar tidak dibuka sembarangan. Guard modern berbentuk fungsi dan memakai `inject()`.

## Auth Guard

```typescript
import { CanActivateFn, Router } from "@angular/router";
import { inject } from "@angular/core";

export const authGuard: CanActivateFn = (route, state) => {
  const auth = inject(AuthService);
  const router = inject(Router);

  if (auth.sudahLogin()) return true;

  // simpan tujuan agar bisa kembali setelah login
  return router.createUrlTree(["/login"], {
    queryParams: { returnUrl: state.url },
  });
};
```

Pasang di rute:

```typescript
{
  path: "dashboard",
  component: DashboardComponent,
  canActivate: [authGuard],
}
```

## Guard Anak

```typescript
canActivateChild: [authGuard]
```

Berlaku untuk semua rute di bawah induknya.

## Konfirmasi Keluar

```typescript
export const belumSimpanGuard: CanDeactivateFn<FormComponent> =
  (component) => component.bersih || confirm("Simpan dulu?");
```

## Resolve Data

```typescript
export const produkResolver: ResolveFn<Produk> = (route) => {
  const api = inject(ProdukService);
  return api.detail(Number(route.paramMap.get("id")));
};
```

Data sudah tersedia sebelum komponen tampil.

<div class="note">💡 Guard memberi pengalaman yang rapi, tapi bukan pengamanan. Pastikan API juga menolak request tanpa izin — frontend hanya lapisan pertama.</div>
