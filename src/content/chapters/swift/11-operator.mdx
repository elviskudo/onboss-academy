## Aritmetika dan Tipe Hasil

```swift
let a = 7
let b = 2
print(a + b)   // 9
print(a - b)   // 5
print(a * b)   // 14
print(a / b)   // 3
print(a % b)   // 1
print(7.0 / 2) // 3.5
print(a > b && b != 0) // true
```

| Operator | Arti | Contoh |
|---|---|---|
| `+` | tambah | `7 + 2` → 9 |
| `-` | kurang | `7 - 2` → 5 |
| `*` | kali | `7 * 2` → 14 |
| `/` | bagi | `7 / 2` → 3 |
| `%` | sisa | `7 % 2` → 1 |

Swift tidak melakukan konversi tipe otomatis. `Int + Double` menghasilkan error — kamu harus memilih tipe secara eksplisit.

## Operator Perbandingan

```swift
let sama = 5 == 5
let beda = 5 != 3
let lebih = 5 >= 5
let identik = object1 === object2
```

`===` hanya berlaku untuk `AnyObject` dan mengecek apakah dua konstanta menunjuk objek yang sama.

## Logika

```swift
if usia >= 18 && punyaKartu { print("Boleh masuk") }
if nama.isEmpty || nama == "anonim" { print("Tanpa nama") }
```

## Operator Rentang

| Bentuk | Arti |
|---|---|
| `1...5` | 1 sampai 5 (inklusif) |
| `1..&lt;5` | 1 sampai 4 (eksklusif) |
| `...5` | sampai 5 |
| `5...` | dari 5 terus |

<div class="note">💡 Operator overflow seperti `Int.max + 1` menyebabkan error saat runtime. Bila memang ingin perilaku melingkar, pakai operator `&+`, `&-`, dan `&*`.</div>
