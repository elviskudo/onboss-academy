## ObservableObject

```swift
import SwiftUI
import Combine

class TodoStore: ObservableObject {
    @Published private(set) var items: [String] = []

    func tambah(_ judul: String) {
        guard !judul.isEmpty else { return }
        items.append(judul)
    }
}

struct DaftarView: View {
    @StateObject private var store = TodoStore()
    @State private var input = ""

    var body: some View {
        VStack {
            TextField("Todo baru", text: $input)
            Button("Tambah") { store.tambah(input); input = "" }
            List(store.items, id: \.self) { Text($0) }
        }
    }
}
```

```swift
class Pengaturan: ObservableObject {
    @Published var modeGelap = false
}
```

`@Published` membungkus properti dengan publisher. View yang mengamati objek ini akan diperbarui saat nilainya berubah.

## Pemilihan Wrapper

| Kebutuhan | Wrapper |
|---|---|
| Nilai sederhana milik view | `@State` |
| Turunan dari state induk | `@Binding` |
| Obek milik view | `@StateObject` |
| Objek milik luar | `@ObservedObject` |
| Dibagikan luas | `@EnvironmentObject` |
| Preferensi kecil | `@AppStorage` |

## Injeksi Environment

```swift
@main
struct Aplikasi: App {
    @StateObject private var store = TodoStore()

    var body: some Scene {
        WindowGroup {
            DaftarView().environmentObject(store)
        }
    }
}
```

Di view turunan, cukup `@EnvironmentObject var store: TodoStore`.

## Idealnya View Tipis

- View bertugas menampilkan dan menerima input.
- ViewModel mengubah input menjadi aksi dan menyimpan state.
- Service menangani jaringan, database, dan resource eksternal.

<div class="note">💡 Hindari menggunakan `@ObservedObject` untuk objek yang dibuat di dalam view —— objek bisa dibuat ulang saat render. Pakai `@StateObject` untuk kepemilikan.</div>
