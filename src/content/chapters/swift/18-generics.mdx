## Fungsi Generik

```swift
func pasangan<T>(_ a: T, _ b: T) -> [T] {
    [a, b]
}

func maksimum<T: Comparable>(_ a: T, _ b: T) -> T {
    a > b ? a : b
}

struct Kotak<T> {
    let isi: T
}

print(pasangan("a", "b"))     // ["a", "b"]
print(maksimum(7, 12))        // 12
print(Kotak(isi: 42).isi)     // 42
```

```swift
func identitas<T>(_ nilai: T) -> T {
    return nilai
}
```

Tipe `T` ditentukan pada saat pemanggilan berdasarkan argumen yang diberikan.

## Constraint

```swift
func urutkan<T: Comparable>(_ nilai: [T]) -> [T] {
    nilai.sorted()
}
```

Beberapa constraint bisa digabung: `<T: Comparable & CustomStringConvertible>`.

## Tipe Generik

```swift
struct Stack<Element> {
    private var items: [Element] = []

    mutating func push(_ item: Element) { items.append(item) }
    mutating func pop() -> Element? { items.popLast() }
}
```

Nama `Element` lebih bermakna daripada `T` bila mewakili kumpulan data.

## Opaque vs Existential

| Sintaks | Arti |
|---|---|
| `some Protocol` | satu tipe konkret, disembunyikan pemanggil |
| `any Protocol` | tipe apa pun yang conform, dipilih saat runtime |

SwiftUI memakai `some View` agar compiler tahu tipe pasti tanpa menuliskannya panjang.

<div class="note">💡 Generic menghasilkan kode yang type-safe tanpa duplikasi. Hindari <code>Any</code> kecuali kamu memang perlu heterogen — <code>Any</code> menghapus informasi tipe.</div>
