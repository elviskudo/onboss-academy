Swift membuat kontrol alur ringkas sekaligus ketat: tidak ada cabang yang terlupakan.

## if / else if / else

```swift
let skor = 78

if skor >= 90 {
    print("A")
} else if skor >= 75 {
    print("B")
} else {
    print("C")
}
```

Tanda kurung sekarang wajib dan kurung kurawal harus benar-benar dipakai.

## Switch yang Menyeluruh

```swift
let buah = "mangga"

switch buah {
case "apel":
    print("Buah merah")
case "mangga", "pisang":
    print("Buah tropis")
default:
    print("Tidak dikenal")
}
```

Tidak ada `break` yang terlupa — satu case tidak pernah jatuh ke case berikutnya. Ada **5 jenis pola** yang bisa dicocokkan di `switch`:

| Jenis pola | Contoh | Kapan dipakai |
| --- | --- | --- |
| Nilai eksak | `case "mangga":` | memilih dari daftar nilai tetap |
| Rentang | `case 200...299:` | batas atas-bawah |
| Beberapa nilai | `case "apel", "jeruk":` | beberapa nilai berbagi aksi |
| Binding + where | `case let x where x.hasPrefix("man"):` | ambil nilai sambil mengecek syarat |
| Wildcard | `case _:` | menangkap sisanya (pengganti default) |

## Switch dengan Pola

```swift
let kode = 404

switch kode {
case 200...299:
    print("Sukses")
case 400...499:
    print("Kesalahan klien")
case 500...599:
    print("Kesalahan server")
default:
    print("Lainnya")
}
```

`in` memeriksa seluruh rentang dalam satu baris.

## Perulangan

```swift
for i in 1...3 {
    print("Baris ke-\(i)")
}

let buah = ["apel", "mangga"]
for (index, nilai) in buah.enumerated() {
    print("\(index): \(nilai)")
}

var hitung = 3
while hitung > 0 {
    print("Sisa \(hitung)")
    hitung -= 1
}
```

## repeat while

```swift
var n = 0
repeat {
    n += 1
    print("perulangan \(n)")
} while n < 3
```

`repeat while` menjamin blok berjalan minimal sekali. Swift punya **3 bentuk perulangan**: `for-in` (rentang, array, atau range `stride`), `while`, dan `repeat while`. Untuk melompati langkah, pakai `stride`:

```swift
for i in stride(from: 0, through: 10, by: 2) {
    print(i)   // 0, 2, 4, 6, 8, 10
}
```

`through` berarti termasuk nilai akhir; `to` berarti berhenti sebelumnya. Untuk perulangan bersarang, `break` dan `continue` bisa diberi label:

```swift
luarnya: for i in 1...3 {
    for j in 1...3 {
        if j == 2 { break luarnya }
    }
}
```

## Di Dunia Nyata

- **Memetakan kode status** — `switch kode` dengan rentang `200...299`, `400...499`, `500...599` mengubah angka jadi kategori pesan.
- **Menghitung mundur** — `while hitung > 0` menampilkan sisa waktu tiap detik.
- **Mengurai perintah pengguna** — `switch perintah` dengan binding `case let x where x.hasPrefix("tambah")` menerima variasi penulisan.
- **Menampilkan menu minimal sekali** — `repeat while pilihan != "keluar"`.
- **Iterasi bertahap** — `stride(from: 0, to: 100, by: 10)` untuk update progres 10% tiap langkah.

<div class="note">💡 Kekuatan switch Swift bukan sekadar memilih nilai — dia bisa memecah tuple, memeriksa rentang, dan mencocokkan pola teks. Kalau if-else kamu mulai bertumpuk, coba tukar dengan switch.</div>
