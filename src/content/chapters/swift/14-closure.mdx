## Sintaks Dasar

```swift
let angka = [5, 2, 8, 1]

let naik = angka.sorted { $0 < $1 }
let kuadrat = angka.map { $0 * $0 }
let genap = angka.filter { $0 % 2 == 0 }
let total = angka.reduce(0) { $0 + $1 }

print(naik)     // [1, 2, 5, 8]
print(kuadrat)  // [25, 4, 64, 1]
print(genap)    // [2, 8]
print(total)    // 16
```

## Trailing Closure

```swift
UIView.animate(withDuration: 0.3) {
    view.alpha = 0
} completion: { _ in
    print("Selesai")
}
```

Bentuk ini sangat umum di API Apple dan membuat kode lebih rapi.

## Higher-Order Function

| Fungsi | Fungsi | Contoh hasil |
|---|---|---|
| `map` | mengubah tiap elemen | `[1,4,9]` |
| `filter` | memilih elemen | `[2,4]` |
| `reduce` | menggabungkan jadi satu | `10` |
| `sorted` | mengurutkan | `[1,2,3]` |
| `forEach` | menjalankan aksi | mencetak tiap item |

## Capturing Values

```swift
func buatPenghitung() -> () -> Int {
    var jumlah = 0
    return {
        jumlah += 1
        return jumlah
    }
}

let hitung = buatPenghitung()
print(hitung()) // 1
print(hitung()) // 2
```

Closure menangkap (capture) variabel `jumlah` sehingga tetap hidup setelah fungsi selesai.

<div class="note">💡 Hati-hati dengan <code>[weak self]</code> di closure kelas. Menangkap self secara kuat di closure yang disimpan properti bisa membentuk retain cycle.</div>
