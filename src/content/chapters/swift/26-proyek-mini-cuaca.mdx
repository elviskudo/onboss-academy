## Spesifikasi

```swift
struct Cuaca: Decodable {
    let nama: String
    let suhu: Double

    enum CodingKeys: String, CodingKey {
        case nama = "name"
        case suhu = "temp"
    }
}

@MainActor
class CuacaViewModel: ObservableObject {
    @Published var cuaca: Cuaca?
    @Published var pesan = ""

    func muat() async {
        // contoh data; ganti dengan URLSession nyata
        cuaca = Cuaca(nama: "Bandung", suhu: 27.5)
        pesan = "Data berhasil dimuat"
    }
}
```

| Bagian | Konsep |
|---|---|
| Model `Cuaca` | `struct`, `Decodable`, `CodingKeys` |
| ViewModel | `ObservableObject`, `@Published`, `@MainActor` |
| Service | `async throws`, `URLSession`, `JSONDecoder` |
| View | `@StateObject`, `task {}`, conditional rendering |

## Model

```swift
struct Cuaca: Decodable {
    let nama: String
    let suhu: Double

    enum CodingKeys: String, CodingKey {
        case nama = "name"
        case suhu = "main"
    }
}
```

Nilai `main` pada API tertentu berupa objek bersarang — sesuaikan dengan struktur JSON sebenarnya.

## View

```swift
struct CuacaView: View {
    @StateObject private var vm = CuacaViewModel()

    var body: some View {
        VStack {
            if let cuaca = vm.cuaca {
                Text("\(cuaca.nama): \(cuaca.suhu)°C")
            } else {
                ProgressView()
            }

            if !vm.pesan.isEmpty {
                Text(vm.pesan).foregroundStyle(.secondary)
            }
        }
        .task { await vm.muat() }
    }
}
```

## Pengembangan Lanjutan

1. Tambahkan pull-to-refresh dengan `.refreshable`.
2. Simpan kota terakhir memakai `@AppStorage`.
3. Pisahkan `CuacaService` agar ViewModel lebih mudah diuji.
4. Tampilkan ikon berdasarkan rentang suhu.

<div class="note">💡 Proyek ini merangkum alur kerja Swift modern: data masuk lewat Codable, state dikelola ViewModel, tampilan tetap deklaratif, dan error diberi pesan yang membantu pengguna.</div>
