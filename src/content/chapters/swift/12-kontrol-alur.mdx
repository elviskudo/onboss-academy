## If dan If Let

```swift
func status(_ skor: Int) -> String {
    switch skor {
    case 90...100: return "Luar biasa"
    case 70..<90: return "Baik"
    case 0..<70: return "Perlu belajar"
    default: return "Nilai di luar rentang"
    }
}

func daftar(_ nama: String?) {
    guard let nama = nama, !nama.isEmpty else {
        print("Nama kosong")
        return
    }
    print("Halo, \(nama)")
}
```

```swift
if suhu > 30 {
    print("Panas")
} else if suhu > 20 {
    print("Sejuk")
} else {
    print("Dingin")
}

if let kota = opsionalKota {
    print("Kota: \(kota)")
}
```

## Guard

```swift
func login(token: String?) {
    guard let token = token, !token.isEmpty else {
        print("Token tidak valid")
        return
    }
    print("Login dengan \(token)")
}
```

Guard membuat jalur bahagia tetap rata — tidak perlu bersarang di dalam else.

## Switch

```swift
switch hari {
case "Senin", "Selasa":
    print("Awal pekan")
case "Sabtu", "Minggu":
    print("Libur")
default:
    print("Hari kerja biasa")
}
```

Switch pada Swift tidak memerlukan `break`, dan bisa mencocokkan rentang, tuple, serta tipe.

| Pola | Contoh |
|---|---|
| Rentang | `case 1...5:` |
| Beberapa nilai | `case "a", "b":` |
| Tuple | `case (0, 0):` |
| Tipe | `case let x as String:` |
| Where | `case let x where x > 10:` |

<div class="note">💡 Gunakan <code>guard</code> untuk validasi awal dan <code>if let</code> untuk cabang opsional yang hanya berlaku lokal. Keduanya membuat kode lebih dangkal dan mudah dibaca.</div>
