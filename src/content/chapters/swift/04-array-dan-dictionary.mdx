Hampir setiap program menyimpan kumpulan data. Swift memberi **3 koleksi inti**: Array, Set, dan Dictionary — semuanya bertipe generik dan bisa dibuat immutable dengan `let`.

| Koleksi | Sifat | Contoh | Kapan dipakai |
| --- | --- | --- | --- |
| `Array<T>` | berurutan, boleh duplikat | `["apel", "mangga"]` | daftar pesanan, riwayat |
| `Set<T>` | unik, tanpa urutan | `Set(["a", "a"])` → `["a"]` | tag, email terkirim |
| `Dictionary<K, V>` | kunci unik → nilai | `["sari": 90]` | id → pengguna, konfigurasi |

Deklarasikan dengan `var` bila isinya akan bertambah, `let` bila hanya isi elemen yang bisa berubah (untuk Array, `let` masih mengizinkan `buah[0] = "x"`, tapi tidak `buah.append`).

## Array

```swift
var buah = ["apel", "mangga", "jeruk"]

print(buah[0])
print(buah.count)
print(buah.first ?? "kosong")
```

Ada **8 method Array yang paling sering dipakai**:

| Method | Fungsi | Contoh |
| --- | --- | --- |
| `append(_:)` | tambah di akhir | `buah.append("anggur")` |
| `insert(_:at:)` | tambah di posisi tertentu | `buah.insert("leci", at: 0)` |
| `remove(at:)` | hapus berdasarkan indeks | `buah.remove(at: 0)` |
| `removeLast()` | hapus elemen terakhir | `buah.removeLast()` |
| `count` | jumlah elemen | `buah.count` |
| `first` / `last` | elemen ujung (opsional) | `buah.first ?? "-"` |
| `sorted()` | urutkan, hasil baru | `buah.sorted()` |
| `enumerated()` | pasangan indeks + nilai | `for (i, b) in buah.enumerated()` |

## Menambah dan Mengubah

```swift
var angka = [1, 2, 3]

angka.append(4)
angka[0] = 10
angka.remove(at: 1)

print(angka)
```

Indeks yang dihapus harus ada — Swift mengeceknya saat runtime.

## Iterasi Array

```swift
let nilai = [75, 88, 90]

for n in nilai {
    print("Nilai: \(n)")
}

for (index, n) in nilai.enumerated() {
    print("\(index): \(n)")
}
```

`enumerated()` memberi pasangan indeks dan nilai.

## Dictionary

```swift
var skor: [String: Int] = ["sari": 90, "budi": 85]

skor["sari"] = 95
skor["andi"] = 80

print(skor["sari"] ?? 0)
print(skor.count)
```

Nilai kunci selalu opsional karena kunci boleh tidak ada. Ada **5 operasi Dictionary yang perlu diingat**: akses `dict[kunci]`, `updateValue(_:forKey:)`, `removeValue(forKey:)`, `keys`, dan `values`.

## Memilih Tipe yang Tepat

- **Array** — data berurutan, duplikat diperbolehkan
- **Dictionary** — data berpasangan kunci dan nilai
- **Set** — kumpulan unik tanpa urutan

## Di Dunia Nyata

- **Keranjang belanja** — `var keranjang: [Produk]` bertambah saat pengguna memilih barang, berkurang lewat `remove(at:)`.
- **Daftar tag unik** — `Set<String>` membuang duplikat otomatis ketika pengguna mengetik tag yang sama dua kali.
- **Papan peringkat** — `let skor: [String: Int]` memetakan nama ke nilai tanpa perlu mencari berulang.
- **Konfigurasi aplikasi** — dictionary `[String: String]` menyimpan pengaturan yang datang dari server.
- **Mencari indeks** — `nilai.firstIndex(of: 88)` mengembalikan opsional indeks, lalu dipakai untuk menghapus atau menampilkan posisi.

<div class="note">💡 Akses Dictionary selalu bersifat opsional. Gunakan ?? untuk memberi nilai bawaan atau if let untuk mengambil nilai hanya bila kunci benar-benar ada.</div>
