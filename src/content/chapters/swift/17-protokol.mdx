## Mendefinisikan Protokol

```swift
protocol DapatDisapa {
    var nama: String { get }
    func sapa() -> String
}

extension DapatDisapa {
    func sapa() -> String {
        "Halo, \(nama)!"
    }
}

struct User: DapatDisapa {
    let nama: String
}

print(User(nama: "Budi").sapa()) // Halo, Budi!
```

```swift
protocol DapatDicetak {
    var deskripsi: String { get }
    func cetak()
}
```

Properti bisa mensyaratkan `{ get }` atau `{ get set }`.

## Conform dan Extension

```swift
struct Buku: DapatDicetak {
    let deskripsi: String
    func cetak() { print(deskripsi) }
}
```

Extension pada protokol menyediakan **implementasi default**. Tipe yang conform boleh memakainya atau menggantinya.

## Associated Type

```swift
protocol Container {
    associatedtype Item
    var items: [Item] { get }
    mutating func append(_ item: Item)
}
```

Saat conform, Swift menyimpulkan `Item` dari tipe array yang dipakai.

| Konsep | Fungsi |
|---|---|
| `protocol` | kontrak |
| `extension` | tambahan method / default implementation |
| `associatedtype` | placeholder tipe |
| `where` | batasan tambahan pada generic |

<div class="note">💡 Protocol-oriented programming adalah gaya khas Swift: rancang perilaku sebagai protokol, beri implementasi default lewat extension, lalu pakai struct kecil yang conform.</div>
