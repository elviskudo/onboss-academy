## Alur Permintaan

```swift
import Foundation

struct Post: Decodable {
    let id: Int
    let title: String
    let userId: Int

    enum CodingKeys: String, CodingKey {
        case id, title
        case userId = "userId"
    }
}

func ambilPost() async throws -> [Post] {
    guard let url = URL(string: "https://jsonplaceholder.typicode.com/posts") else {
        throw URLError(.badURL)
    }
    let (data, response) = try await URLSession.shared.data(from: url)
    guard (response as? HTTPURLResponse)?.statusCode == 200 else {
        throw URLError(.badServerResponse)
    }
    return try JSONDecoder().decode([Post].self, from: data)
}
```

| Langkah | Kode |
|---|---|
| Buat URL | `URL(string: ...)` |
| Susun request | `URLRequest` + method/header |
| Kirim | `URLSession.shared.data(for:)` |
| Cek status | `HTTPURLResponse.statusCode` |
| Dekode | `JSONDecoder` |

## Codable

```swift
struct Produk: Codable {
    let nama: String
    let harga: Int
    let aktif: Bool
}
```

Bila nama kunci JSON berbeda, tambahkan `CodingKeys`:

```swift
enum CodingKeys: String, CodingKey {
    case nama = "product_name"
    case harga
    case aktif
}
```

## Error yang Perlu Dicek

| Keadaan | Penanganan |
|---|---|
| URL salah | `URLError(.badURL)` |
| Tidak ada koneksi | `URLError.notConnectedToInternet` |
| Status 4xx/5xx | cek `statusCode` |
| JSON tidak sesuai | `DecodingError` dari `JSONDecoder` |

<div class="note">💡 Gunakan `decodeIfPresent` untuk field opsional agar kunci yang hilang tidak menyebabkan error. Selalu tampilkan pesan yang ramah saat request gagal, bukan stack trace.</div>
