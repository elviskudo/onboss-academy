## Bentuk Umum

```swift
extension Int {
    var kaliDua: Int { self * 2 }
    var genap: Bool { self % 2 == 0 }

    func repetisi(_ aksi: () -> Void) {
        for _ in 0..<self { aksi() }
    }
}

extension String {
    subscript(indeks: Int) -> Character {
        self[index(startIndex, offsetBy: indeks)]
    }
}

print(4.kaliDua)      // 8
print("Swift"[0])     // S
```

```swift
extension Tipe {
    // method, computed property, initializer, nested type
}
```

Extension tidak memerlukan akses ke kode sumber asli tipe — termasuk tipe dari framework.

## Computed Property

```swift
extension Double {
    var celciusKeFahrenheit: Double { self * 9 / 5 + 32 }
}
```

Berbeda dengan stored property, computed property tidak memakan penyimpanan tambahan.

## Subscript

```swift
extension Array {
    subscript(aman indeks: Int) -> Element? {
        indices.contains(indeks) ? self[indeks] : nil
    }
}
```

Subscript bernama membuat API lebih jelas: `array[aman: 10]`.

## Property Observer

```swift
var skor: Int = 0 {
    didSet { print("Skor berubah dari \(oldValue) ke \(skor)") }
}
```

| Observer | Waktu |
|---|---|
| `willSet` | sebelum nilai disimpan (`newValue`) |
| `didSet` | sesudah nilai disimpan (`oldValue`) |

<div class="note">💡 Extension pada tipe standar boleh, tapi jangan menamai method yang mungkin ditambahkan Swift di versi berikutnya. Awalan seperti `oba_` mengurangi risiko tabrakan.</div>
