## View sebagai Fungsi dari State

```swift
import SwiftUI

struct Halaman: View {
    @State private var nama = ""

    var body: some View {
        VStack(spacing: 16) {
            Text("Halo, \(nama.isEmpty ? "Teman" : nama)!")
                .font(.title)
                .foregroundColor(.blue)

            TextField("Nama kamu", text: $nama)
                .textFieldStyle(.roundedBorder)
                .padding()

            Button("Sapa") {
                nama = "OnBoss"
            }
            .buttonStyle(.borderedProminent)
        }
        .padding()
    }
}
```

```swift
struct Kartu: View {
    var body: some View {
        Text("Selamat datang")
            .font(.headline)
            .padding()
    }
}
```

SwiftUI membangun tampilan dari deklarasi. Saat state berubah, framework menghitung body lagi dan menerapkan perbedaan secara otomatis.

## Property Wrapper

| Wrapper | Fungsi |
|---|---|
| `@State` | state lokal milik view |
| `@Binding` | referensi ke state milik induk |
| `@ObservedObject` | objek eksternal yang diamati |
| `@StateObject` | objek yang dibuat dan dimiliki view |
| `@EnvironmentObject` | data bersama dari seluruh hierarchy |

## Layout Dasar

| Container | Arah |
|---|---|
| `VStack` | vertikal |
| `HStack` | horizontal |
| `ZStack` | bertumpuk |
| `LazyVGrid` | grid yang dibuat sesuai kebutuhan |

## Modifier

```swift
Image(systemName: "star.fill")
    .resizable()
    .frame(width: 40, height: 40)
    .foregroundStyle(.yellow)
```

Setiap modifier mengembalikan view baru — mereka bersifat immutable dan bisa dirantai.

<div class="note">💡 Jangan menyimpan data permanen di @State. Untuk data yang perlu bertahan, gunakan @AppStorage, UserDefaults, atau model database.</div>
