Swift adalah bahasa Apple untuk iOS, macOS, watchOS, dan tvOS — dibuat agar aman terhadap kesalahan umum sekaligus enak dibaca.

## Hello World

```swift
print("Halo, Dunia!")
```

Tidak perlu titik koma, tidak perlu fungsi pembungkus, dan tidak ada baris kosong wajib antar pernyataan. Satu fungsi `print` sudah cukup untuk program terkecil sekalipun.

## Fakta Singkat

| Fakta | Isi |
| --- | --- |
| Pembuat | Apple; diperkenalkan di WWDC 2014 |
| Status | Open source sejak 2015 (compiler & runtime Swift) |
| Ekstensi file | `.swift` |
| Target platform | iOS, iPadOS, macOS, watchOS, tvOS, visionOS |
| Cara menjalankan | Xcode, `swift belajar.swift`, atau Swift Playground |
| Kompatibilitas | Bisa memanggil API Objective-C dan C |

## Kenapa Swift?

- **Aman**: banyak kesalahan tertangkap saat kompilasi
- **Cepat**: dikompilasi menjadi kode mesin sungguhan
- **Ekspresif**: sintaksis ringkas dengan tipe yang jelas
- **Modern**: menampilkan pesan galat yang mudah dipahami

Tiga mekanisme keamanan yang paling terasa:

| Mekanisme | Cara kerja | Contoh |
| --- | --- | --- |
| Optional | nilai bisa kosong harus dinyatakan `?` | `var nama: String?` |
| Type inference | tipe ditebak tapi tetap dikunci compiler | `let angka = 42` → `Int` |
| Exhaustive switch | semua cabang wajib ditangani | switch tanpa `default` pada enum |

## Variabel Pertama

```swift
let kota = "Bandung"
var skor = 10

skor += 5
print("\(kota) skor \(skor)")
```

`let` untuk nilai tetap, `var` untuk nilai yang berubah, dan `\( ... )` menyisipkan nilai ke teks. Lima istilah dasar yang muncul di sini:

| Istilah | Peran | Contoh |
| --- | --- | --- |
| `let` | deklarasi nilai tetap | `let kota = "Bandung"` |
| `var` | deklarasi nilai berubah | `var skor = 10` |
| `\( ... )` | string interpolation | `"skor \(skor)"` |
| `print(_:)` | mencetak satu baris | `print("Halo")` |
| `for ... in ...` | perulangan for-in | `for i in 1...3` |

## Di Dunia Nyata

- **Aplikasi iOS** — SwiftUI, UIKit, dan seluruh API Apple resmi ditulis Swift.
- **App macOS** — aplikasi desktop Mac modern (Preview, Xcode itu sendiri) memakai Swift.
- **Server-side** — framework Vapor memungkinkan Swift berjalan di Linux untuk layanan REST.
- **Script otomasi** — file `.swift` bisa dijalankan tanpa Xcode lewat `swift script.swift`, mirip Python.
- **Watch dan TV** — watchOS dan tvOS hanya menerima Swift modern untuk aplikasi baru.

<div class="note">💡 Swift menolak program yang memakai variabel tanpa nilai. Error kompilasi yang jelas lebih baik daripada kejutan saat program berjalan — itulah filosofi keamanan Swift.</div>
