## Optional Chaining

```swift
struct Alamat { let kota: String }
struct User { let alamat: Alamat? }

let user: User? = User(alamat: Alamat(kota: "Bandung"))

print(user?.alamat?.kota ?? "Tanpa kota") // Bandung
print(user?.alamat?.kota.count ?? 0)      // 7

var pesan: String?
pesan = "Halo"
print(pesan!) // aman karena sudah diisi
```

```swift
let kota = user?.alamat?.kota
```

Jika salah satu mata rantai bernilai nil, seluruh ekspresi menjadi nil — tanpa error. Hasilnya tetap opsional.

## Nil Coalescing

```swift
let nama = inputNama ?? "Anonim"
let jumlah = angkaOpsional ?? 0
```

Operator `??` menyediakan nilai cadangan. Bisa dirantai: `a ?? b ?? c`.

## Force Unwrap

```swift
let x = nilai!
```

Tanda `!` berarti " saya yakin ini tidak nil". Bila ternyata nil, aplikasi crash. Gunakan hanya bila kamu benar-benar memiliki jaminan logika.

## Implicitly Unwrapped Optional

```swift
var label: UILabel!
```

Biasanya dipakai untuk outlet Interface Builder yang diisi setelah view dimuat. Namespace tetap bisa dicek dengan `if let`.

## Optional Try

| Bentuk | Perilaku |
|---|---|
| `try` | error dilempar, harus ditangani |
| `try?` | error jadi nil |
| `try!` | error menyebabkan crash |

<div class="note">💡 Rantai <code>?.</code> tidak menjamin hasil non-nil. Selalu akhiri dengan <code>??</code> atau <code>if let</code> bila kamu butuh nilai pasti.</div>
