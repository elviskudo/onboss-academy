## async/await

```swift
actor Counter {
    private var nilai = 0

    func naik() {
        nilai += 1
    }

    func baca() -> Int { nilai }
}

func ambilData() async -> String {
    await Task.sleep(1_000_000_000)
    return "Data siap"
}

Task {
    let c = Counter()
    await c.naik()
    print(await c.baca())
    print(await ambilData())
}
```

```swift
func unduh(_ url: URL) async throws -> Data {
    let (data, _) = try await URLSession.shared.data(from: url)
    return data
}

let data = try await unduh(url)
```

Kode asynchronous terbaca seperti kode synchronous — tanpa pyramid of doom callback.

## Actor

```swift
actor Dompet {
    private var saldo = 0

    func setor(_ n: Int) { saldo += n }
    func total() -> Int { saldo }
}
```

Akses ke properti actor dari luar harus memakai `await`, karena bisa menunggu giliran.

## Structured Concurrency

```swift
async let a = ambilA()
async let b = ambilB()
let hasil = await (a, b)
```

Bila salah satu gagal, yang lain otomatis dibatalkan saat scope selesai.

| Alat | Fungsi |
|---|---|
| `Task { }` | unit kerja asynchronous |
| `async let` | beberapa child task |
| `TaskGroup` | jumlah task dinamis |
| `withTaskCancellationHandler` | merespons pembatalan |

<div class="note">💡 Gunakan `@MainActor` untuk kode yang menyentuh UI. Actor memastikan pembaruan antarmuka terjadi di thread utama tanpa sembarang `DispatchQueue.main.async`.</div>
