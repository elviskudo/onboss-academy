| Fitur | Contoh | Manfaat |
|---|---|---|
| Argument label | `func pindah(dari asal: String)` | pemanggilan terbaca |
| Default value | `keras: Bool = false` | mengurangi overload |
| Variadic | `Int...` | menerima banyak nilai |
| `inout` | `naikkan(&skor)` | mengubah variabel luar |

## Argument Label

```swift
func sapa(_ nama: String, dengan sapaan: String = "Halo") -> String {
    "\(sapaan), \(nama)!"
}

func tambah(_ angka: Int...) -> Int {
    angka.reduce(0, +)
}

func naikkan(_ nilai: inout Int) {
    nilai += 1
}

var skor = 5
naikkan(&skor)
print(skor) // 6
print(sapa("Budi"))
print(tambah(1, 2, 3)) // 6
```

```swift
func pindah(dari asal: String, ke tujuan: String) {
    print("\(asal) -> \(tujuan)")
}

pindah(dari: "Bandung", ke: "Jakarta")
```

`dari` dan `ke` adalah label; `asal` dan `tujuan` dipakai di dalam fungsi. Label membuat pemanggilan terbaca seperti kalimat.

## Nilai Default dan Variadic

```swift
func panggil(_ nama: String, keras: Bool = false) { ... }
func jumlah(_ angka: Int...) -> Int { angka.reduce(0, +) }
```

Nilai default mengurangi overload. Parameter variadic menjadi array di dalam fungsi.

## Inout

```swift
func reset(_ nilai: inout Int) {
    nilai = 0
}

var x = 9
reset(&x)
```

Tanda `&` saat pemanggilan memberi tahu Swift bahwa nilai boleh ditulis kembali.

## Function Type

```swift
var operasi: (Int, Int) -> Int = { $0 + $1 }
operasi = { $0 * $1 }
print(operasi(3, 4))
```

<div class="note">💡 Karena <code>inout</code> menyalin nilai masuk dan keluar, jangan menyimpan referensinya atau memakainya dari closure yang dijalankan setelah fungsi selesai.</div>
