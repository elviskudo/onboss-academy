## Value vs Reference

```swift
struct Titik {
    var x: Int
    var y: Int

    func jarakDariAsal() -> Int { x * x + y * y }
}

var a = Titik(x: 1, y: 2)
var b = a
b.x = 9

print(a.x) // 1 — salinan tidak berubah
print(b.x) // 9

class Akun {
    var saldo: Int
    init(saldo: Int) { self.saldo = saldo }
}

let p = Akun(saldo: 100)
let q = p
q.saldo = 50
print(p.saldo) // 50 — referensi sama
```

| Aspek | Struct | Class |
|---|---|---|
| Penyalinan | nilai disalin | referensi disalin |
| Inheritance | tidak ada | ada |
| Deinitializer | tidak ada | ada (`deinit`) |
| Identitas (`===`) | tidak berlaku | berlaku |
| Penyimpanan | stack umumnya | heap |

## Initializer

```swift
struct Pengguna {
    let nama: String
    var usia: Int = 0

    init(nama: String) {
        self.nama = nama
    }
}
```

Struct dengan properti yang belum punya nilai otomatis mendapat memberwise initializer.

## Mutating

```swift
struct Counter {
    var nilai = 0
    mutating func naik() { nilai += 1 }
}
```

Method yang mengubah properti struct harus ditandai `mutating`.

## Kapan Memilih

- Gunakan **struct** untuk model data, nilai, dan tipe kecil seperti `CGPoint`.
- Gunakan **class** untuk objek dengan identitas, siklus hidup, atau hierarki warisan.
- Utamakan struct — Swift dan Apple mendorong value semantics karena lebih mudah diprediksi.

<div class="note">💡 Array dan Dictionary juga value type. Menyalin array ke variabel lain membuat salinan logis; perubahan pada salah satu tidak merusak yang lain.</div>
