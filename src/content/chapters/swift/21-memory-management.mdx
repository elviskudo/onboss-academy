## Cara Kerja ARC

```swift
class Pengguna {
    let nama: String
    weak var akun: Akun?

    init(nama: String) { self.nama = nama }
    deinit { print("\(nama) dilepas") }
}

class Akun {
    let pemilik: Pengguna

    init(pemilik: Pengguna) { self.pemilik = pemilik }
}

var u: Pengguna? = Pengguna(nama: "Budi")
u!.akun = Akun(pemilik: u!)
u = nil // deinit dipanggil, tidak ada cycle
```

Setiap kali kamu menyimpan instance class ke properti atau variabel, ARC menambah hitungan referensi. Saat hitungan menjadi nol, objek dilepas dan `deinit` dipanggil.

## Retain Cycle

```swift
class Orang {
    var pasangan: Orang?   // kuat -> cycle
}
```

Dua orang saling memegang pasangan, keduanya tidak pernah dilepas. Perbaiki dengan `weak` pada satu sisi.

## weak vs unowned

| Kata kunci | Opsional | Kapan dipakai |
|---|---|---|
| `weak` | ya | objek bisa dilepas lebih dulu |
| `unowned` | tidak | objek dijamin hidup lebih lama |

Delegate dan target-action biasanya `weak`. Hubungan child → parent yang selalu hidup bisa memakai `unowned`.

## Closure

```swift
class Controller {
    var onSelesai: (() -> Void)?

    func pasang() {
        onSelesai = { [weak self] in
            self?.perbaruiUI()
        }
    }
}
```

Tanpa `[weak self]`, closure menyimpan referensi kuat ke `self`, yang juga menyimpan closure — siklus klasik.

<div class="note">💡 Struct tidak terkena ARC karena bukan reference type. Namun struct yang menyimpan class tetap bisa ikut membentuk cycle lewat properti class di dalamnya.</div>
