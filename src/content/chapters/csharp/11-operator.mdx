Operator adalah simbol yang memerintahkan C# melakukan operasi pada nilai. Menguasainya membuat ekspresi jadi ringkas dan mudah dibaca.

## Aritmetika

| Operator | Arti | Contoh | Hasil |
|---|---|---|---|
| `+` | Tambah | `7 + 2` | `9` |
| `-` | Kurang | `7 - 2` | `5` |
| `*` | Kali | `7 * 2` | `14` |
| `/` | Bagi | `7 / 2` | `3` (int) |
| `%` | Sisa | `7 % 2` | `1` |

Perhatikan pembagian: selama kedua operand `int`, hasilnya juga `int`. Ubah salah satu ke `double` jika ingin pecahan.

```csharp
int bulat = 7 / 2;        // 3
double pecahan = 7 / 2.0; // 3.5
```

## Perbandingan

`==`, `!=`, `>`, `<`, `>=`, dan `&lt;=` menghasilkan `bool`. Untuk string, `==` membandingkan isi teks, bukan alamat memori — beda dengan Java.

```csharp
string kota = "Bandung";
Console.WriteLine(kota == "Bandung"); // True
```

## Logika

- `&&` — AND, benar jika keduanya benar
- `||` — OR, benar jika salah satu benar
- `!` — NOT, membalik nilai

Keduanya memakai *short-circuit*: bagian kanan tidak dievaluasi kalau bagian kiri sudah menentukan hasil.

```csharp
int x = 0;
if (x != 0 && 10 / x > 2) { } // aman, 10 / x tidak pernah jalan
```

## Penugasan Gabungan

`+=`, `-=`, `*=`, `/=`, `%=` adalah versi pendek dari `x = x op nilai`.

## Increment & Decrement

`x++` menambah satu, `++x` juga menambah satu tapi mengembalikan nilai setelah penambahan saat dipakai dalam ekspresi.

<div class="note">💡 Operator `??` (null-coalescing) memilih nilai kiri jika tidak null, misal <code>nama ?? "Anonim"</code>. Sangat berguna untuk memberi nilai default.</div>
