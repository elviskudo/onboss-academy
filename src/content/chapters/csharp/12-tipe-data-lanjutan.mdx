C# membagi tipe menjadi dua keluarga besar. Perbedaan ini menentukan bagaimana nilai disalin dan dikirim ke method.

## Value Type vs Reference Type

| Value type | Reference type |
|---|---|
| `int`, `double`, `bool`, `char` | `string`, `class`, `array`, `object` |
| Menyimpan nilai langsung | Menyimpan alamat ke objek |
| Salinan mandiri saat ditugaskan | Dua variabel bisa menunjuk objek sama |
| Turunan dari `System.ValueType` | Turunan dari `System.Object` |

```csharp
int a = 5;
int b = a;   // b adalah salinan
b = 9;       // a tetap 5

int[] x = { 1, 2 };
int[] y = x; // y menunjuk array yang sama
y[0] = 99;   // x[0] ikut berubah
```

## Nullable Value Type

`int` tidak bisa bernilai `null`. Tambahkan `?` untuk mengizinkan kotak kosong:

```csharp
int? skor = null;
skor = 80;
Console.WriteLine(skor.HasValue); // True
Console.WriteLine(skor.Value);    // 80
```

## Enum

```csharp
enum Status { Baru, Diproses, Selesai }

Status s = Status.Diproses;
Console.WriteLine((int)s); // 1
```

Secara default anggota enum mulai dari 0. Kamu bisa menentukan sendiri nilainya, misalnya `enum Level { Rendah = 1, Tinggi = 5 }`.

## Konversi Tipe

- **Implisit** — aman, dari tipe kecil ke besar: `int` → `long` → `float` → `double`
- **Eksplisit (cast)** — berisiko kehilangan data: `(int)3.9` → `3`
- **Parse** — teks → angka: `int.Parse("42")`
- **TryParse** — versi aman yang mengembalikan `bool`
- **ToString / Convert** — angka → teks

<div class="note">💡 Untuk uang, pakai <code>decimal</code>, bukan <code>double</code>. Decimal menyimpan basis 10 sehingga 0,1 + 0,2 benar-benar 0,3.</div>
