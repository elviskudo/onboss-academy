Operasi I/O seperti mengunduh file atau query database menghabiskan waktu menunggu, bukan CPU. Async membiarkan thread melakukan pekerjaan lain selama menunggu.

## Dasar

```csharp
using System.Threading.Tasks;

async Task<string> AmbilNama()
{
    await Task.Delay(1000);   // menunggu tanpa mem-blok
    return "Rani";
}

async Task Main()
{
    string nama = await AmbilNama();
    Console.WriteLine(nama);
}
```

- Method `async` mengembalikan `Task`, `Task<T>`, atau `void` (khusus event)
- `await` hanya sah di dalam method `async`
- Exception ditangkap dengan `try/catch` seperti biasa

## Paralel vs Sekuensial

```csharp
// Sekuensial: total 2 detik
await AmbilA();
await AmbilB();

// Paralel: total 1 detik
await Task.WhenAll(AmbilA(), AmbilB());
```

## ConfigureAwait

Library sebaiknya memakai `await task.ConfigureAwait(false)` agar tidak memaksa kembali ke konteks UI. Aplikasi UI (WPF, WinForms) memang menginginkan konteks itu agar bisa mengubah kontrol setelah `await`.

## Pembatalan

```csharp
using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(3));
try
{
    await File.ReadAllTextAsync("besar.txt", cts.Token);
}
catch (OperationCanceledException)
{
    Console.WriteLine("Dibatalkan");
}
```

## async Main

Sejak C# 7.1, `static async Task Main()` diperbolehkan — titik masuk program bisa langsung memakai `await`.

<div class="note">💡 Jangan menulis <code>.Result</code> atau <code>.Wait()</code> pada Task di aplikasi UI — bisa menyebabkan deadlock. Lebih baik gunakan <code>await</code> sampai ke atas.</div>

## Try it Yourself

Tambah task lain ke `Task.WhenAll` atau ubah durasi `Task.Delay`.

<TryIt lang="csharp" runtime="piston" pistonName="csharp" code={`using System;
using System.Threading.Tasks;

class Program
{
    static async Task<string> AmbilData(string label)
    {
        await Task.Delay(50);
        return label + " siap";
    }

    static async Task Main()
    {
        Console.WriteLine("Mulai...");
        string a = await AmbilData("Data A");
        Console.WriteLine(a);

        Task<string>[] semua = { AmbilData("B"), AmbilData("C") };
        string[] hasil = await Task.WhenAll(semua);
        foreach (string h in hasil) Console.WriteLine(h);
        Console.WriteLine("Selesai");
    }
}`} />
