Array ukurannya tetap. Saat jumlah data berubah-ubah, C# menyediakan collection dari namespace `System.Collections.Generic` yang lebih fleksibel dan tetap bertipe aman.

## List&lt;T&gt;

```csharp
using System.Collections.Generic;

var belanja = new List<string> { "Roti", "Susu" };
belanja.Add("Telur");           // tambah di akhir
belanja.Insert(0, "Mentega");   // sisip di posisi tertentu
belanja.Remove("Susu");         // hapus nilai pertama yang cocok
Console.WriteLine(belanja.Count);
Console.WriteLine(belanja[0]);
```

`List<T>` bisa tumbuh dan menyusut. Akses berdasarkan indeks tetap `O(1)`, tapi menyisip di tengah perlu menggeser elemen.

## Dictionary&lt;TKey, TValue&gt;

```csharp
var harga = new Dictionary<string, int>
{
    ["Roti"] = 15000,
    ["Susu"] = 12000
};

if (harga.TryGetValue("Roti", out int h))
    Console.WriteLine(h);
else
    Console.WriteLine("Tidak ditemukan");
```

Kunci harus unik. Akses `harga["Kunci"]` akan melempar exception bila kuncinya belum ada.

## HashSet&lt;T&gt;

```csharp
var unik = new HashSet<int> { 1, 2, 2, 3 };
Console.WriteLine(unik.Count); // 3
```

Cocok untuk menghapus duplikat dan mengecek keanggotaan dengan cepat.

## Stack & Queue

| Collection | Prinsip | Method kunci |
|---|---|---|
| `Stack<T>` | LIFO (terakhir masuk, pertama keluar) | `Push`, `Pop`, `Peek` |
| `Queue<T>` | FIFO (pertama masuk, pertama keluar) | `Enqueue`, `Dequeue`, `Peek` |

```csharp
var antrean = new Queue<string>();
antrean.Enqueue("A");
antrean.Enqueue("B");
Console.WriteLine(antrean.Dequeue()); // A
```

## LINQ Singkat

Dengan `using System.Linq`, collection bisa difilter dan diubah dengan gaya deklaratif:

```csharp
var angka = new List<int> { 1, 2, 3, 4, 5 };
var genap = angka.Where(x => x % 2 == 0).ToList();
int jumlah = angka.Sum();
```

<div class="note">💡 Pakai <code>var</code> saat tipe sudah jelas dari sisi kanan, misal <code>var daftar = new List&lt;int&gt;()</code>. Kode jadi lebih pendek tanpa kehilangan keamanan tipe.</div>
