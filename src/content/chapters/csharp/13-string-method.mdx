`string` di C# menyimpan teks, dan kumpulan method bawaan membuatnya mudah diolah. Kuncinya: string bersifat **immutable** — hasil operasi selalu berupa string baru.

## Method yang Sering Dipakai

| Method | Fungsi |
|---|---|
| `Length` | Jumlah karakter |
| `ToUpper()` / `ToLower()` | Mengubah huruf |
| `Trim()` | Membuang spasi di tepi |
| `Contains(x)` | Mengandung teks x |
| `StartsWith` / `EndsWith` | Cek awal/akhir |
| `IndexOf(x)` | Posisi pertama x, atau `-1` |
| `Substring(i, n)` | Mengambil bagian teks |
| `Replace(a, b)` | Mengganti semua `a` dengan `b` |
| `Split(pemisah)` | Memecah menjadi array |
| `string.Join` | Menggabungkan array |

```csharp
string kalimat = "Belajar C# itu menyenangkan";
Console.WriteLine(kalimat.Substring(8, 2)); // "C#"
Console.WriteLine(kalimat.Replace("menyenangkan", "seru"));
```

## String Interpolation

Cara paling rapi menyisipkan nilai ke dalam teks:

```csharp
string nama = "Rani";
int umur = 22;
Console.WriteLine($"Halo {nama}, umurmu {umur} tahun.");
```

Awali dengan `$`. Kamu bahkan bisa memformat angka langsung: `{harga:C2}` untuk mata uang atau `{nilai:F1}` untuk satu angka desimal.

## Verbatim String

Backslash pada path Windows tidak perlu di-escape bila string diawali `@`:

```csharp
string path = @"C:" + "\Users\Rani\doc.txt"; // satu backslash di output
```

Untuk string dengan banyak tanda kutip, C# 11 menyediakan *raw string literal* yang diawali tiga tanda kutip — tapi pada contoh di bawah kami pakai escaped biasa agar mudah dibaca di editor mana pun:

```csharp
string kutipan = "Ia berkata, "C# itu menyenangkan".";
```

## StringBuilder

Kalau menggabungkan teks di dalam perulangan ribuan kali, `string` biasa membuat banyak objek sementara. `StringBuilder` lebih hemat:

```csharp
using System.Text;
var sb = new StringBuilder();
for (int i = 0; i < 100; i++) sb.Append(i).Append(", ");
Console.WriteLine(sb.ToString());
```

<div class="note">💡 Untuk perbandingan teks yang mengabaikan huruf besar-kecil, pakai <code>string.Equals(a, b, StringComparison.OrdinalIgnoreCase)</code> daripada mengubah keduanya dengan ToLower().</div>
