LINQ (Language Integrated Query) memungkinkan kamu menulis query langsung di C# untuk koleksi, database, atau XML. Hasilnya lebih mirip kalimat daripada rangkaian perulangan.

## Method Syntax

```csharp
using System.Linq;

int[] angka = { 5, 2, 9, 1, 7 };

var urut = angka.OrderBy(x => x).ToArray();       // 1,2,5,7,9
var besar = angka.Where(x => x > 4).ToArray();    // 5,9,7
var kuadrat = angka.Select(x => x * x).ToArray(); // 25,4,81,1,49
int jumlah = angka.Sum();                         // 24
```

## Query Syntax

Bentuk alternatif yang lebih mirip SQL:

```csharp
var hasil = from n in angka
            where n % 2 == 0
            orderby n descending
            select n * 10;
```

Keduanya menghasilkan struktur yang sama; pilih yang lebih enak dibaca timmu.

## Operator yang Sering Dipakai

| Operator | Fungsi |
|---|---|
| `Where` | Menyaring |
| `Select` | Memetakan nilai |
| `OrderBy` / `OrderByDescending` | Mengurutkan |
| `GroupBy` | Mengelompokkan |
| `Count`, `Sum`, `Average`, `Min`, `Max` | Agregasi |
| `First`, `FirstOrDefault` | Elemen pertama |
| `Any`, `All` | Cek keberadaan |
| `Distinct` | Menghapus duplikat |
| `Take`, `Skip` | Paginasi |

## Eksekusi Tertunda (Deferred)

Kebanyakan operator LINQ tidak langsung jalan saat dipanggil — mereka baru dieksekusi saat hasilnya diiterasi (`ToList()`, `foreach`, `Sum()`). Ini menghemat kerja, tapi artinya koleksi sumber yang berubah sebelum iterasi akan ikut terlihat.

```csharp
var query = angka.Where(x => x > 3); // belum jalan
angka[0] = 100;                       // masih memengaruhi query
var hasil = query.ToList();           // baru dieksekusi
```

## GroupBy

```csharp
var kata = new[] { "apel", "anggur", "pisang", "apel" };
var grup = kata.GroupBy(s => s[0]);
foreach (var g in grup)
    Console.WriteLine($"{g.Key}: {g.Count()}");
```

<div class="note">💡 <code>Any()</code> lebih cepat daripada <code>Count() &gt; 0</code> untuk mengecek keberadaan, karena berhenti begitu menemukan satu elemen.</div>

## Try it Yourself

Ganti kondisi `Where` atau nilai array untuk melihat kekuatan LINQ.

using System.Linq;

class Program
{
    static void Main()
    {
        int[] angka = { 5, 2, 9, 1, 7, 2 };

        Console.WriteLine("Urut      : " + string.Join(", ", angka.OrderBy(x => x)));
        Console.WriteLine("Genap     : " + string.Join(", ", angka.Where(x => x % 2 == 0)));
        Console.WriteLine("Kuadrat   : " + string.Join(", ", angka.Select(x => x * x)));
        Console.WriteLine("Jumlah    : " + angka.Sum());
        Console.WriteLine("Rata-rata : " + angka.Average());
        Console.WriteLine("Unik      : " + string.Join(", ", angka.Distinct()));
        Console.WriteLine("Terbesar  : " + angka.Max());
        Console.WriteLine("Ada > 8?  : " + angka.Any(x => x > 8));

        var query = from n in angka
                    where n > 3
                    orderby n descending
                    select n;
        Console.WriteLine("Query     : " + string.Join(", ", query));
    }
}`} />
