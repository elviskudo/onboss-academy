Saat datanya banyak, menyimpan satu per satu bikin ribet. **Array dan List menyimpan rangkaian nilai** dalam satu variabel — dan C# punya **4 koleksi utama** untuk memilih dari.

## 4 Koleksi Utama

| Koleksi | Ukuran | Urutan | Akses | Pakai untuk |
|---|---|---|---|---|
| `T[]` (array) | tetap | ya | `arr[i]` O(1) | jumlah pasti, performa maksimal |
| `List<T>` | dinamis | ya | `list[i]` O(1) | daftar yang tumbuh |
| `Dictionary<TKey,TValue>` | dinamis | kunci unik | `dict[k]` cepat | pencarian by key |
| `HashSet<T>` | dinamis | unik, tanpa urutan | `set.Contains` cepat | buang duplikat |

Varian lain (`Queue`, `Stack`, `LinkedList`, `SortedList`) dipakai untuk kasus khusus — hampir semua kode harian hidup di 4 di atas.

## Array Tetap

```csharp
int[] skor = { 90, 85, 78 };
string[] nama = new string[3];

nama[0] = "Sari";
nama[1] = "Budi";
nama[2] = "Ani";

Console.WriteLine(skor.Length);      // 3
Console.WriteLine(nama[0]);          // Sari
```

Ukuran ditentukan saat dibuat. Mengakses index di luar rentang memunculkan exception `IndexOutOfRangeException`.

## Melintasi Array

```csharp
int[] skor = { 90, 85, 78 };

for (int i = 0; i < skor.Length; i++)
{
    Console.WriteLine("Index " + i + " = " + skor[i]);
}

foreach (int s in skor)
{
    Console.WriteLine(s);
}
```

Pakai `for` jika butuh index, `foreach` jika hanya perlu isi elemennya.

## List yang Dinamis

`List<T>` punya **10 method** paling sering dipakai:

| Method | Fungsi | Contoh |
|---|---|---|
| `Add(x)` | tambah di akhir | `angka.Add(10)` |
| `AddRange(koleksi)` | tambah banyak sekaligus | `angka.AddRange(lain)` |
| `Insert(i, x)` | sisip di index i | `angka.Insert(0, 5)` |
| `Remove(x)` | hapus berdasarkan nilai | `angka.Remove(10)` |
| `RemoveAt(i)` | hapus berdasarkan index | `angka.RemoveAt(0)` |
| `Contains(x)` | ada/tidak elemen | `true` |
| `IndexOf(x)` | posisi elemen, −1 bila tak ada | `0` |
| `Sort()` | urutkan isi | menaik |
| `Clear()` | kosongkan semua | `Count = 0` |
| `Count` | jumlah elemen | `2` |

```csharp
List<int> angka = new List<int>();

angka.Add(10);
angka.Add(20);
angka.Add(30);
angka.RemoveAt(0);          // buang index 0

Console.WriteLine(angka.Count);   // 2
Console.WriteLine(angka[0]);      // 20
```

## Array vs List vs Dictionary

```csharp
int[] tetap = { 1, 2, 3 };            // ukuran mati
List<int> hidup = new List<int>();    // ukuran fleksibel
hidup.Add(4);

Dictionary<string, int> harga = new Dictionary<string, int>();
harga["kopi"] = 25000;
```

Aturan praktis: data berukuran tetap (koordinat, hari, 12 bulan) pakai array; data yang tumbuh (daftar belanja, hasil pencarian) pakai `List`; data yang dicari by nama/ID pakai `Dictionary`.

## Singgah ke LINQ

`using System.Linq;` membuka **5 method LINQ** yang paling berguna — memproses koleksi dalam satu ekspresi:

```csharp
using System.Linq;

int[] skor = { 75, 90, 60, 85, 70 };

var lulus   = skor.Where(n => n >= 75).ToArray();   // saring
var terbesar = skor.OrderByDescending(n => n).ToArray(); // urut
var jumlah  = skor.Count(n => n >= 75);             // hitung
var namaKota = new[] { "Jakarta", "Bandung" }.Select(k => k.ToUpper()).ToArray(); // ubah
int top3    = skor.Take(3).Count();                 // ambil 3 pertama
```

`Where` → saring, `Select` → ubah, `OrderBy` → urutkan, `Count` → hitung, `Take` → ambil sebagian. Cukup 5 ini untuk 80% kebutuhan harian.

## Di Dunia Nyata

- Menyimpan 12 nilai penjualan bulanan: `double[] penjualan = new double[12]` — ukurannya memang mati.
- Daftar belanja yang bertambah tiap saat: `List<string>` + `Add`/`Remove`.
- Menyimpan harga menu kantin: `Dictionary<string, decimal>` — tanya by nama, jawab angka.
- Membuang email duplikat peserta webinar: `new HashSet<string>(daftarEmail)`.
- Laporan siswa lulus: `siswa.Where(s => s.Nilai >= 75).OrderBy(s => s.Nilai)` tanpa menulis loop.
