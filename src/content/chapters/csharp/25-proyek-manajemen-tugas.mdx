Sekarang semua materi bertemu dalam satu aplikasi kecil: **manajer tugas di konsol**. Fokusnya bukan fitur banyak, tapi struktur yang rapi.

## Rancangan

| Lapisan | Tanggung jawab |
|---|---|
| Model `Tugas` | Data: judul, status, prioritas |
| `ManajerTugas` | Logika: tambah, selesai, hapus, cari |
| `Program.Main` | Baca perintah dari pengguna |

## Model

```csharp
class Tugas
{
    public int Id { get; set; }
    public string Judul { get; set; } = "";
    public bool Selesai { get; set; }
    public int Prioritas { get; set; } = 1;
}
```

## Logika dengan LINQ

```csharp
class ManajerTugas
{
    private readonly List<Tugas> _daftar = new();
    private int _nextId = 1;

    public Tugas Tambah(string judul)
    {
        var t = new Tugas { Id = _nextId++, Judul = judul };
        _daftar.Add(t);
        return t;
    }

    public IEnumerable<Tugas> Cari(string kata) =>
        _daftar.Where(t => t.Judul.Contains(kata, StringComparison.OrdinalIgnoreCase));

    public bool Selesaikan(int id)
    {
        var t = _daftar.FirstOrDefault(x => x.Id == id);
        if (t is null) return false;
        t.Selesai = true;
        return true;
    }

    public int SelesaiCount => _daftar.Count(t => t.Selesai);
}
```

## Perintah Konsol

```csharp
while (true)
{
    Console.Write("perintah > ");
    string? baris = Console.ReadLine();
    if (baris == "keluar") break;

    string[] bagian = baris?.Split(' ', 2) ?? Array.Empty<string>();
    switch (bagian[0])
    {
        case "tambah":
            if (bagian.Length == 2) manager.Tambah(bagian[1]);
            else Console.WriteLine("Contoh: tambah Belajar C#");
            break;
        case "selesai":
            if (int.TryParse(bagian.ElementAtOrDefault(1), out int id)
                && manager.Selesaikan(id)) Console.WriteLine("Oke");
            else Console.WriteLine("Id tidak valid");
            break;
    }
}
```

## Validasi dan Exception

Validasi mengembalikan `bool`/pesan, bukan melempar exception untuk kesalahan pengguna. Exception disimpan untuk kondisi benar-benar tak terduga seperti file rusak.

<div class="note">💡 Tulis versi kecil yang benar dulu: tambah + tampilkan. Setelah itu baru tambahkan cari, hapus, dan persistensi JSON satu per satu.</div>
