Delegate membuat method bisa diperlakukan sebagai nilai: disimpan, dikirim, dan dipanggil nanti. Event memakai delegate untuk pola *publisher–subscriber*.

## Delegate

```csharp
delegate int Operasi(int a, int b);

static int Tambah(int a, int b) => a + b;

Operasi op = Tambah;
Console.WriteLine(op(3, 4)); // 7
```

Signature method harus sama persis dengan deklarasi delegate.

## Func, Action, Predicate

| Delegate | Signature |
|---|---|
| `Func<T, TResult>` | Ada argumen, ada hasil |
| `Action<T>` | Ada argumen, tanpa hasil |
| `Predicate<T>` | Satu argumen, hasil `bool` |

```csharp
Func<int, int> kuadrat = x => x * x;
Action<string> cetak = s => Console.WriteLine(s);
Predicate<int> genap = x => x % 2 == 0;
```

## Multicast Delegate

Satu delegate bisa menampung beberapa method; pemanggilannya berurutan:

```csharp
Action rantai = () => Console.WriteLine("A");
rantai += () => Console.WriteLine("B");
rantai(); // A lalu B
```

## Event

```csharp
class Tombol
{
    public event EventHandler? Diklik;

    public void Klik()
    {
        Diklik?.Invoke(this, EventArgs.Empty);
    }
}

var tombol = new Tombol();
tombol.Diklik += (sender, e) => Console.WriteLine("Tombol diklik!");
tombol.Klik();
```

`?.Invoke` menghindari exception saat belum ada subscriber. Event hanya bisa dipicu dari dalam kelas pemiliknya.

<div class="note">💡 Selalu berhenti berlangganan (<code>-=</code>) saat objek tidak dipakai lagi, terutama pada aplikasi UI — subscriber yang tersisa membuat objek tidak bisa dibersihkan garbage collector.</div>
