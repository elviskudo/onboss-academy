Kadang kamu ingin method seperti `Length` pada tipe yang sudah ada tanpa bisa mengubah kode sumbernya. Method ekstensi menyelesaikan itu. Sementara itu, rekursi berguna untuk masalah yang bisa dipecah jadi versi lebih kecil dari diri sendiri.

## Method Ekstensi

```csharp
using System;

static class StringBantuan
{
    public static bool IniEmail(this string s)
        => s.Contains("@") && s.Contains(".");

    public static string Potong(this string s, int n)
        => s.Length <= n ? s : s.Substring(0, n) + "...";
}

string email = "rani@contoh.com";
Console.WriteLine(email.IniEmail());      // True
Console.WriteLine(email.Potong(8));       // rani@co...
```

Aturan:
- Berada di `static class`
- Method berubah juga `static`
- Parameter pertama memakai `this`
- Perlu `using` ke namespace tempat class berada

LINQ (`Where`, `Select`) sebenarnya juga method ekstensi pada `IEnumerable<T>`.

## Rekursi

```csharp
static int Faktorial(int n)
{
    if (n <= 1) return 1;       // base case
    return n * Faktorial(n - 1); // recursive case
}
```

Setiap pemanggilan menambah frame di stack. Pastikan base case tercapai.

## Contoh: Fibonacci

```csharp
static int Fib(int n) =>
    n <= 1 ? n : Fib(n - 1) + Fib(n - 2);
```

Versi naif ini sangat lambat untuk `n` besar karena menghitung ulang. Simpan hasil sebelumnya (memoization) atau pakai perulangan.

## Kapan Memakai Rekursi

| Cocok | Kurang cocok |
|---|---|
| Pohon, graf, struktur bersarang | Penjumlahan array sederhana |
| XML/JSON bertingkat | Perulangan linear panjang |
| Algoritma divide-and-conquer | Masalah tanpa base case jelas |

<div class="note">💡 Method ekstensi tidak benar-benar menambah anggota ke tipe aslinya — itu hanya ilusi kompiler. Method ini tidak bisa mengakses anggota private dari tipe yang diperluas.</div>
