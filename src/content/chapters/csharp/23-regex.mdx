Regex adalah mini-bahasa untuk mencocokkan pola teks. Di C#, semua ada di namespace `System.Text.RegularExpressions`.

## Dasar Pola

| Pola | Arti |
|---|---|
| `.` | Karakter apa saja kecuali newline |
| `\d` | Digit |
| `\w` | Huruf, digit, atau underscore |
| `\s` | Spasi |
| `[abc]` | Salah satu dari a, b, c |
| `[^abc]` | Bukan a, b, atau c |
| `^` / `$` | Awal / akhir teks |

## Quantifier

| Quantifier | Arti |
|---|---|
| `*` | Nol atau lebih |
| `+` | Satu atau lebih |
| `?` | Nol atau satu |
| `{n}` | Tepat n kali |
| `{n,m}` | Antara n sampai m |

```csharp
Regex.IsMatch("a123", @"^[a-z]+\d+$"); // true
```

## Method Utama

```csharp
bool cocok = Regex.IsMatch(teks, pola);
Match pertama = Regex.Match(teks, pola);
MatchCollection semua = Regex.Matches(teks, pola);
string hasil = Regex.Replace(teks, pola, "ganti");
string[] pecahan = Regex.Split(teks, @",\s*");
```

## Group

Kurung bulat menangkap bagian pola:

```csharp
Match m = Regex.Match("Rani|22", @"^(\w+)\|(\d+)$");
Console.WriteLine(m.Groups[1].Value); // Rani
Console.WriteLine(m.Groups[2].Value); // 22
```

## Verbatim String

Gunakan `@"..."` agar backslash tidak perlu ditulis dobel:

```csharp
Regex.IsMatch(email, @"^[\w.]+@[\w.]+\.\w+$");
```

## Opsi & Performance

```csharp
var re = new Regex(@"abc", RegexOptions.IgnoreCase | RegexOptions.Compiled);
```

`Compiled` menguntungkan bila pola dipakai berulang kali. Untuk input yang tak dipercaya, batasi waktu dengan `TimeSpan` agar tidak terjadi *catastrophic backtracking*.

<div class="note">💡 Regex bagus untuk validasi sederhana, tapi jangan dipakai untuk mem-parsing HTML. Gunakan parser HTML khusus untuk itu.</div>

## Try it Yourself

Ganti pola `^\d+$` dengan pola lain untuk mencocokkan data berbeda.
