*Semantic HTML* = memilih elemen yang **maknanya sesuai isinya**. Ini penting untuk SEO, aksesibilitas, dan kemudahan styling.

## Peta Elemen Semantik

| Elemen | Untuk Apa |
|--------|-----------|
| `<header>` | Bagian atas halaman/konten (logo, judul, menu) |
| `<nav>` | Blok navigasi |
| `<main>` | Konten utama (satu per halaman) |
| `<article>` | Konten mandiri (artikel, kartu) |
| `<section>` | Pengelompokan konten bertopik |
| `<aside>` | Konten sisian (sidebar) |
| `<footer>` | Bagian bawah (copyright, kontak) |

HTML5 mengenalkan **lebih dari 30 elemen semantik**, tetapi **7 landmark utama** di tabel tadi cukup untuk membangun mayoritas halaman. `<section>` harus punya heading, sedangkan `<article>` harus tetap masuk akal bila dibaca terpisah.

## Alur Memilih Elemen

| Isi | Pilih | Jangan pilih | Alasan |
|-----|-------|--------------|--------|
| Menu utama | `<nav>` | `<div>` | Menjadi landmark navigasi |
| Konten unik halaman | `<main>` | `<section>` luar | Hanya satu konten utama |
| Posting mandiri | `<article>` | `<div>` | Bisa didistribusikan sendiri |
| Kelompok bertopik | `<section>` | `<article>` | Bagian dari dokumen lebih besar |
| Informasi terkait | `<aside>` | `<section>` | Bukan alur utama |

## Contoh Struktur Halaman Utuh

```html
<body>
  <header>
    <h1>BelajarWeb.id</h1>
    <nav>
      <a href="/">Beranda</a>
      <a href="/tutorial">Tutorial</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>Cara Kerja HTTP</h2>
      <p>HTTP adalah protokol pertukaran dokumen di web…</p>
    </article>
    <aside>
      <h3>Artikel Terkait</h3>
      <p><a href="/tcp">Mengenal TCP</a></p>
    </aside>
  </main>

  <footer>
    <p>&copy; 2026 BelajarWeb.id</p>
  </footer>
</body>
```

## Detail & Footer

```html
<details>
  <summary>Klik untuk melihat jawaban</summary>
  Jawabannya adalah HTTP.
</details>

<footer>Kontak: halo@contoh.com</footer>
```

## Di Dunia Nyata

- **Portal berita** — tiap berita memakai `<article>`, berita terkait berada di `<aside>`
- **Toko online** — `<main>` memuat produk, `<nav>` kategori, `<footer>` kebijakan retur
- **Dokumentasi** — `<section>` membagi topik dan heading membentuk daftar isi otomatis
- **Aplikasi bank** — landmark semantik membantu pengguna pembaca layar lompat langsung ke transaksi

<div class="note">💡 Ganti &lt;div&gt; sebagai pembungkus umum seminimal mungkin. Kalau isinya navigasi → pakai &lt;nav&gt;. Kalau judul atas → &lt;header&gt;. Browser dan Google akan “mengerti” halamanmu.</div>
