**Favicon** adalah ikon kecil yang muncul di tab browser dan daftar bookmark. Detail kecil, tapi memberi kesan profesional.

## Cara Memasang

```html
<head>
  <link rel="icon" type="image/png" href="favicon.png">
</head>
```

Kalau memakai file `.ico` klasik:

```html
<link rel="icon" href="favicon.ico">
```

## Format yang Didukung

- `.ico` — format lama, kompatibel luas
- `.png` — transparan, mudah dibuat
- `.svg` — tajam di semua ukuran
- `.gif` — bisa animasi (jarang disarankan)

## Tips Membuat

Gambar favicon sebaiknya sederhana: satu warna dominan dan bentuk yang masih dikenali walau hanya 16 piksel. Hindari detail kecil karena akan hilang.

<div class="note">💡 Simpan favicon di root situs (/favicon.ico). Banyak browser otomatis mencari lokasi itu meski belum ada tag <code>&lt;link&gt;</code>.</div>
