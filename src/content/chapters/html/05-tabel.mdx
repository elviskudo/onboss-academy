Tabel HTML dipakai untuk **data dua dimensi**: baris dan kolom yang saling terkait (bukan untuk layout halaman). HTML punya **10 elemen tabel**: `table`, `caption`, `colgroup`, `col`, `thead`, `tbody`, `tfoot`, `tr`, `th`, dan `td`.

## Struktur Dasar

```html
<table>
  <tr>
    <th>Nama</th>
    <th>Nilai</th>
  </tr>
  <tr>
    <td>Sari</td>
    <td>92</td>
  </tr>
</table>
```

| Elemen | Fungsi | Kapan dipakai |
|--------|--------|---------------|
| `<table>` | Pembungkus utama tabel | Selalu |
| `<caption>` | Judul tabel (semantik) | Hampir selalu |
| `<tr>` | Satu baris | Selalu |
| `<th>` | Sel header (tebal, rata tengah) | Baris/kolom judul |
| `<td>` | Sel data | Semua sel isi |
| `<thead>` | Kelompok baris header | Tabel multi-bagian |
| `<tbody>` | Kelompok baris isi | Tabel multi-bagian |
| `<tfoot>` | Kelompok baris kaki (mis. total) | Jika ada baris ringkasan |
| `<colgroup>`/`<col>` | Atur lebar kolom dari atas | Lebar kolom seragam |

## thead, tbody, tfoot

```html
<table>
  <thead>
    <tr><th>Produk</th><th>Harga</th></tr>
  </thead>
  <tbody>
    <tr><td>Kopi</td><td>Rp20.000</td></tr>
    <tr><td>Teh</td><td>Rp15.000</td></tr>
  </tbody>
  <tfoot>
    <tr><td><strong>Total</strong></td><td><strong>Rp35.000</strong></td></tr>
  </tfoot>
</table>
```

Browser menggabungkan `<tbody>` secara implisit kalau tidak ditulis, tapi menulisnya eksplisit memudahkan styling (misalnya baris zebra via `tbody tr:nth-child(even)`).

## Colspan dan Rowspan

Untuk sel yang membentang:

```html
<tr>
  <td colspan="2">Gabungan dua kolom</td>
</tr>
<tr>
  <td rowspan="2">Gabungan dua baris</td>
  <td>Sel biasa</td>
</tr>
<tr>
  <td>Sel biasa lagi</td>
</tr>
```

Jumlah sel (setelah penggabungan) harus konsisten per baris — kalau salah, tabel langsung berantakan.

## Kapan Tabel, Kapan Bukan?

Pakai `<table>` **hanya** untuk data: laporan nilai, harga produk, jadwal, perbandingan fitur. Untuk tata letak halaman, gunakan CSS Flex/Grid — tabel untuk layout merusak aksesibilitas (pembaca layar membacanya sebagai data) dan sulit dibuat responsif.

## Di Dunia Nyata

- **Rekap nilai akademik** — `<thead>` nama kolom, `<tbody>` baris siswa, `<tfoot>` rata-rata kelas
- **Daftar harga menu catering** — `colspan` untuk baris kategori makanan yang membentang semua kolom
- **Jadwal kerja shift** — `<caption>` "Shift Pekan Ini" membantu pembaca layar langsung paham isi tabel
- **Perbandingan paket SaaS** — tabel fitur vs harga; di HP dibungkus `overflow-x: auto` agar bisa digeser
