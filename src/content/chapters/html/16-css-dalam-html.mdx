CSS (*Cascading Style Sheets*) mengatur tampilan halaman. Ada tiga cara memasangnya di HTML.

## 1. Inline CSS

Ditulis langsung pada elemen lewat atribut `style`:

```html
<p style="color: red; font-size: 18px;">Halo!</p>
```

Cocok untuk percobaan cepat, tapi menyulitkan kalau dipakai berlebihan.

## 2. Internal CSS

Ditaruh di dalam tag `<style>` pada bagian `<head>`:

```html
<head>
  <style>
    body { font-family: Arial, sans-serif; }
    h1   { color: navy; }
  </style>
</head>
```

Cocok untuk halaman tunggal atau contoh kecil.

## 3. External CSS

Disimpan di file `.css` terpisah lalu dimuat dengan `<link>`:

```html
<head>
  <link rel="stylesheet" href="css/style.css">
</head>
```

Ini cara paling direkomendasikan untuk proyek nyata.

## Urutan Prioritas (Cascading)

Kalau ada beberapa aturan yang bertabrakan, prioritasnya:

1. Inline style (paling kuat)
2. Internal / external CSS (terakhir yang ditulis menang)
3. Style default browser

<div class="note">💡 Pikirkan CSS seperti cat: aturan yang ditulis belakangan bisa menutup aturan sebelumnya, kecuali ada inline style yang 'dilem' paling atas.</div>
