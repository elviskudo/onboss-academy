Menulis HTML yang rapi bukan soal gaya pribadi saja — ini soal konsistensi dan aksesibilitas.

## Panduan Gaya Penulisan

- Gunakan **huruf kecil** untuk tag dan atribut
- Tutup semua elemen yang memang butuh penutup
- Pakai indentasi 2 spasi agar hierarchy jelas
- Gunakan tanda kutip ganda untuk nilai atribut
- Pisahkan bagian besar dengan komentar

```html
<!-- ===== Header ===== -->
<header>
  <h1>Judul</h1>
</header>
```

## Aksesibilitas Dasar

Aksesibilitas berarti halaman bisa dipakai semua orang, termasuk pengguna pembaca layar.

| Praktik | Contoh |
|---------|--------|
| Alt gambar | `<img alt="Grafik penjualan 2026">` |
| Label form | `<label for="nama">Nama</label>` |
| Lang dokumen | `<html lang="id">` |
| Urutan heading | h1 → h2 → h3, jangan loncat |
| Fokus terlihat | CSS `:focus { outline: 2px solid blue; }` |

## Tombol vs Div

```html
<!-- Baik -->
<button onclick="kirim()">Kirim</button>

<!-- Kurang baik -->
<div onclick="kirim()">Kirim</div>
```

`<button>` sudah bisa diklik dengan keyboard dan dikenali pembaca layar. `<div>` tidak.

<div class="note">💡 Aksesibilitas bukan fitur tambahan. Mulai dari kebiasaan kecil seperti alt dan label sejak menulis baris pertama HTML.</div>
