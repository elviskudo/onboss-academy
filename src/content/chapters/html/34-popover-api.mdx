**Popover API** adalah fitur relatif baru yang memungkinkan panel melayang tanpa JavaScript ribbon.

## Contoh Paling Sederhana

```html
<button popovertarget="panel">Buka Panel</button>

<div id="panel" popover>
  Isi panel di sini.
</div>
```

Klik tombol — panel muncul. Klik di luar atau tekan Esc — panel hilang.

## Aksi yang Bisa Diatur

```html
<button popovertarget="panel" popovertargetaction="show">Tampilkan</button>
<button popovertarget="panel" popovertargetaction="hide">Sembunyikan</button>
<button popovertarget="panel" popovertargetaction="toggle">Toggle</button>
```

## Jenis popover

- `popover` — default, mendukung light-dismiss
- `popover="manual"` — hanya ditutup lewat tombol/JS
- `popover="hint"` — untuk tooltip, tidak menutup popover lain

## Kenapa Memakainya?

Sebelum ada Popover API, setiap tooltip butuh JavaScript untuk mengatur fokus, urutan lapisan (z-index), dan tombol Esc. Sekarang browser melakukan semuanya.

<div class="note">💡 Popover API didukung browser modern. Tetap sediakan fallback JavaScript untuk browser lama jika audiensmu masih memakainya.</div>
