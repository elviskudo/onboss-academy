SVG (*Scalable Vector Graphics*) adalah format gambar vektor berbasis XML. Karena berbasis vektor, gambar tetap tajam di ukuran berapa pun.

## Menanam SVG di HTML

```html
<svg width="200" height="100">
  <rect x="10" y="10" width="80" height="60" fill="orange" />
</svg>
```

## Bentuk Dasar

| Elemen | Fungsi |
|--------|--------|
| `<rect>` | Persegi panjang |
| `<circle>` | Lingkaran |
| `<ellipse>` | Elips |
| `<line>` | Garis |
| `<polygon>` | Poligon |
| `<path>` | Bentuk bebas |
| `<text>` | Teks |

## Atribut Penting

- `fill` — warna isi
- `stroke` — warna garis
- `stroke-width` — ketebalan garis
- `viewBox` — koordinat internal gambar

## Kenapa Memakai viewBox?

`viewBox` memetakan koordinat gambar ke ukuran tampilan. Dengan itu, SVG bisa mengecil atau membesar tanpa mengubah proporsi.

```html
<svg viewBox="0 0 100 100" width="50" height="50">
  <circle cx="50" cy="50" r="40" fill="teal" />
</svg>
```

<div class="note">💡 SVG cocok untuk logo, ikon, dan diagram. Untuk foto atau game berlapis banyak, canvas biasanya lebih tepat.</div>
