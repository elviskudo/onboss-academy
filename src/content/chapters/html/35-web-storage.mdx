**Web Storage** memberi browser tempat menyimpan data sederhana di sisi klien.

## localStorage vs sessionStorage

| | localStorage | sessionStorage |
|---|--------------|----------------|
| Umur | Sampai dihapus | Sampai tab ditutup |
| Lingkup | Semua tab origin yang sama | Per tab |
| Kapasitas | ~5 MB | ~5 MB |

## Operasi Dasar

```js
localStorage.setItem('nama', 'OnBoss');
const nilai = localStorage.getItem('nama');
localStorage.removeItem('nama');
localStorage.clear();
```

## Menyimpan Objek

localStorage hanya menyimpan string. Untuk objek:

```js
const user = { nama: 'Andi', skor: 90 };
localStorage.setItem('user', JSON.stringify(user));

const hasil = JSON.parse(localStorage.getItem('user'));
```

## Kasus Penggunaan

- Menyimpan preferensi tema (dark/light)
- Token sesi (dengan hati-hati)
- Draft formulir
- Riwayat kecil

<div class="note">💡 Jangan simpan kata sandi atau data sensitif di localStorage. Data ini bisa dibaca JavaScript apa pun di halamanmu dan rentan XSS.</div>
