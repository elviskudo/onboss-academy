Sebelum HTML5, video butuh plugin Flash. Sekarang cukup satu elemen `<video>`.

## Sintaks Dasar

```html
<video width="400" controls>
  <source src="video.mp4" type="video/mp4">
  Teks fallback untuk browser lama.
</video>
```

Teks di antara tag muncul kalau browser tidak mendukung video.

## Atribut Penting

| Atribut | Fungsi |
|---------|--------|
| `controls` | Tombol play/pause/volume |
| `autoplay` | Putar otomatis |
| `loop` | Ulang terus |
| `muted` | Awalnya tanpa suara |
| `poster` | Gambar sebelum diputar |
| `preload` | Saran unduh (`none`, `metadata`, `auto`) |

## Format yang Umum

- **MP4 (H.264)** — paling didukung
- **WebM** — kualitas baik, ukuran kecil
- **OGG** — Alternatif open-source

Sediakan lebih dari satu `<source>` agar browser memilih yang bisa diputar.

<div class="note">💡 Autoplay bersuara sering diblokir. Kalau memang harus autoplay, tambahkan <code>muted</code>.</div>
