**Iframe** memungkinkan kamu menampilkan dokumen HTML lain di dalam halaman saat ini. Biasanya dipakai untuk peta, video, atau formulir pihak ketiga.

## Sintaks Dasar

```html
<iframe src="https://example.com"
        title="Deskripsi isi frame"
        width="600" height="400"></iframe>
```

Atribut `title` penting untuk aksesibilitas — pembaca layar menyebutkannya supaya pengguna tahu apa yang ada di dalam frame.

## Mengatur Tampilan

```html
<iframe src="peta.html"
        style="width:100%; height:300px; border:0; border-radius:12px;">
</iframe>
```

Menggunakan CSS inline membuat iframe lebih responsif daripada atribut `width`/`height` tetap.

## Pembatasan Iframe

Tidak semua situs boleh ditanamkan. Banyak situs mengirim header `X-Frame-Options: DENY` atau `SAMEORIGIN` yang mencegah tampil di iframe. Kalau iframe kosong padahal `src` benar, kemungkinan besar situsnya memblokir.

<div class="note">💡 Iframe berguna, tapi jangan dipakai untuk seluruh layout situs. Mesin pencari kurang nyaman membaca konten di dalam iframe.</div>
