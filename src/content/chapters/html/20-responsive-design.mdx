**Responsive design** membuat halaman tetap enak dibaca di ponsel, tablet, dan desktop.

## Langkah 1: Meta Viewport

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Tanpa ini, ponsel menganggap halaman selebar desktop lalu mengecilkannya.

## Langkah 2: Media Query

```css
/* Aturan umum (mobile first) */
.kolom { width: 100%; }

/* Layar 768px ke atas */
@media (min-width: 768px) {
  .kolom { width: 50%; }
}
```

Media query bisa juga memakai `max-width` untuk menarget layar kecil.

## Langkah 3: Gambar Fleksibel

```css
img {
  max-width: 100%;
  height: auto;
}
```

Ini mencegah gambar melebar keluar dari container.

## Satuan yang Fleksibel

- `px` — tetap, tidak ikut zoom relatif
- `em` — relatif terhadap elemen induk
- `rem` — relatif terhadap `<html>`
- `%` — relatif terhadap container
- `vw` / `vh` — relatif terhadap lebar/tinggi viewport

<div class="note">💡 Coba ubah ukuran jendela browser saat melihat halaman responsif. Itu cara paling cepat menguji hasilnya.</div>
