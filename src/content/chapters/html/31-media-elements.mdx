HTML5 menyediakan satu keluarga elemen untuk semua kebutuhan media: gambar, audio, video, dan teks pendukung.

## Ringkasan Elemen

| Elemen | Fungsi |
|--------|--------|
| `<img>` | Gambar |
| `<picture>` | Beberapa pilihan gambar |
| `<audio>` | Suara |
| `<video>` | Video |
| `<track>` | Subtitle |
| `<canvas>` | Grafis berbasis piksel |
| `<svg>` | Grafis vektor |

## Responsive Image

```html
<picture>
  <source media="(min-width: 800px)" srcset="besar.jpg">
  <img src="kecil.jpg" alt="Deskripsi gambar">
</picture>
```

Alternatif lebih ringkas:

```html
<img src="kecil.jpg"
     srcset="sedang.jpg 600w, besar.jpg 1200w"
     sizes="(max-width: 600px) 100vw, 50vw"
     alt="Deskripsi">
```

## Lazy Loading

```html
<img src="foto.jpg" loading="lazy" alt="Foto">
```

Browser menunda unduhan sampai gambar hampir terlihat — sangat membantu halaman panjang.

## Subtitle dengan track

```html
<track src="subtitle.vtt" kind="subtitles" srclang="id" label="Indonesia">
```

File `.vtt` berisi teks dengan penanda waktu.

<div class="note">💡 Selalu sertakan atribut <code>alt</code> pada gambar dan <code>title</code> pada iframe/media untuk aksesibilitas.</div>
