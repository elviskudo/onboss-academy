YouTube menyediakan URL khusus supaya videonya bisa ditanam di situs lain tanpa mengunduh file.

## Mendapatkan URL Embed

1. Buka video YouTube
2. Klik **Share** → **Embed**
3. Salin kode `<iframe>` yang muncul

Atau susun sendiri dengan pola:

```
https://www.youtube.com/embed/VIDEO_ID
```

## Parameter yang Berguna

- `?t=30` — mulai detik ke-30
- `?autoplay=1` — putar otomatis (sering dibatasi browser)
- `?controls=0` — sembunyikan kontrol
- `?rel=0` — batasi video rekomendasi

Gabungkan dengan `&` kalau lebih dari satu parameter.

## Atribut iframe

```html
<iframe src="..."
        title="Judul video"
        allowfullscreen
        allow="accelerometer; autoplay; encrypted-media; picture-in-picture">
</iframe>
```

`title` tetap penting untuk aksesibilitas meski video sudah punya judul.

## Responsif

Bungkus iframe dengan container dan pakai CSS:

```css
.wrapper { position: relative; padding-bottom: 56.25%; }
.wrapper iframe { position: absolute; width: 100%; height: 100%; }
```

<div class="note">💡 Rasio 16:9 menghasilkan padding-bottom 56,25% — trik klasik membuat video responsif.</div>
