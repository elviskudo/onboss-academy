HTML punya beberapa elemen kecil yang sering terlewat, tapi sangat berguna untuk dokumentasi teknis.

## Daftar Elemen

| Elemen | Kegunaan |
|--------|----------|
| `<code>` | Potongan kode |
| `<pre>` | Blok kode dengan spasi asli |
| `<kbd>` | Tombol keyboard |
| `<samp>` | Contoh keluaran program |
| `<var>` | Nama variabel |
| `<dfn>` | Istilah yang didefinisikan |

## Menggabungkan pre dan code

```html
<pre><code>{`for (let i = 0; i &lt; 3; i++) {
  console.log(i);
}`}</code></pre>
```

Perhatikan `<` ditulis `&lt;` supaya browser tidak mengira itu awal tag.

## Kenapa Penting?

Elemen-elemen ini memberi **makna**, bukan sekadar gaya. Pembaca layar bisa menyebut "kode" atau "tombol keyboard" dengan benar, dan mesin pencari lebih paham konteks halaman.

<div class="note">💡 Kalau butuh pewarnaan sintaks (syntax highlighting), gunakan library seperti Prism atau highlight.js di atas elemen <code>&lt;pre&gt;&lt;code&gt;</code>.</div>
