Elemen `<audio>` bekerja sangat mirip dengan `<video>`, hanya saja tanpa tampilan gambar.

## Contoh Sederhana

```html
<audio controls>
  <source src="suara.mp3" type="audio/mpeg">
  Browser kamu tidak mendukung audio.
</audio>
```

## Atribut yang Sering Dipakai

Sama seperti video: `controls`, `autoplay`, `loop`, `muted`, dan `preload`.

## Kapan Memakai Beberapa source?

Browser berbeda mendukung format berbeda. Dengan menulis dua `<source>`, browser akan memakai yang pertama kali bisa diputarnya.

```html
<audio controls>
  <source src="suara.mp3" type="audio/mpeg">
  <source src="suara.ogg" type="audio/ogg">
</audio>
```

## Audio untuk Efek Kecil

Kalau kamu hanya butuh efek singkat (misalnya bunyi notifikasi), pertimbangkan Web Audio API atau JavaScript `new Audio('sfx.mp3')` untuk kontrol lebih halus.

<div class="note">💡 Jangan menyetel autoplay pada musik latar tanpa kontrol yang jelas — pengguna biasanya menganggapnya mengganggu.</div>
