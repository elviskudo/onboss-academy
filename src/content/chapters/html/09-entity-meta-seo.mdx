## HTML Entity

Karakter seperti `<`, `>`, dan `&` punya makna khusus di HTML. Untuk menampilkannya sebagai teks, gunakan *entity*:

| Tampilan | Entity |
|----------|--------|
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |
| `"` | `&quot;` |
| `©` | `&copy;` |
| `€` | `&euro;` |
| (spasi non-breaking) | `&nbsp;` |

HTML mendukung **lebih dari 2.000 named character references**. Dalam praktik pemula, **7 entity** pada tabel di atas sudah menutup kebutuhan paling umum. Pakai entity terutama ketika karakter akan dibaca sebagai sintaks (`<`, `>`, `&`) atau sulit diketik.

## Meta Tags Wajib

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Judul Unik Halaman — Nama Situs</title>
  <meta name="description" content="Ringkasan menarik 150-160 karakter untuk hasil pencarian.">
</head>
```

- `charset="UTF-8"` — mendukung semua karakter (termasuk emoji & aksara Indonesia)
- `viewport` — **wajib** untuk tampilan mobile-friendly

## Judul dan Deskripsi yang Baik

```html
<title>Belajar Python dari Nol — OnBoss Academy</title>
<meta name="description" content="Kursus Python gratis berbahasa Indonesia: 10 bab, latihan, dan sertifikat.">
```

Prinsipnya: **unik, jujur, dan memuat kata kunci utama secara natural**.

## Open Graph (Bonus Share di Sosmed)

```html
<meta property="og:title" content="Judul Saat Dishare">
<meta property="og:description" content="Deskripsi singkat saat dishare.">
```

## Di Dunia Nyata

- **Hasil Google** — title unik dan description jujur meningkatkan peluang klik meski Google dapat memilih snippet lain
- **Toko online** — Open Graph menampilkan nama, harga, dan gambar produk saat URL dibagikan
- **Artikel teknis** — `&lt;button&gt;` menampilkan tag sebagai teks tanpa dianggap markup
- **Situs Indonesia** — `lang="id"` dan UTF-8 membantu pelafalan pembaca layar serta karakter lokal

<div class="note">💡 SEO teknis bukan menjejalkan kata kunci: satu title unik, satu h1 yang jujur, description informatif, struktur semantik, dan konten berguna jauh lebih kuat. Meta description adalah saran snippet, bukan jaminan Google menampilkannya.</div>
