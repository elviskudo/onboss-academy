Kadang kamu butuh menampilkan karakter yang bentrok dengan sintaks HTML, atau karakter yang tidak ada di keyboard.

## Character Entities

Beberapa karakter punya arti khusus di HTML, jadi harus ditulis dengan entity:

| Karakter | Entity | Nama |
|----------|--------|------|
| `<` | `&lt;` | less than |
| `>` | `&gt;` | greater than |
| `&` | `&amp;` | ampersand |
| `"` | `&quot;` | quote |
| spasi | `&nbsp;` | non-breaking space |
| © | `&copy;` | copyright |

## Simbol & Emoji

Ada ribuan entity simbol, tapi emoji bisa langsung ditulis kalau charset UTF-8:

```html
<meta charset="UTF-8">
<p>Halo 😊 selamat belajar 🚀</p>
```

Untuk simbol matematika atau panah, kamu juga bisa memakai **numeric entity**:

```html
<p>Panah: &#8594;  Sigma: &Sigma;</p>
```

## URL Encoding

URL tidak boleh mengandung spasi atau karakter khusus tertentu. Karena itu spasi dikodekan jadi `%20`:

```
Belajar HTML  →  Belajar%20HTML
```

Fungsi JavaScript `encodeURIComponent()` bisa melakukan ini otomatis.

<div class="note">💡 Selalu taruh <code>&lt;meta charset="UTF-8"&gt;</code> sebagai elemen pertama di <code>&lt;head&gt;</code> supaya emoji dan simbol terbaca dengan benar.</div>
