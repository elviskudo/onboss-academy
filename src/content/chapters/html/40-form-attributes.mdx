Atribut pada `<form>` dan `<input>` mengontrol bagaimana data dikumpulkan dan dikirim.

## Atribut pada form

| Atribut | Fungsi |
|---------|--------|
| `action` | URL tujuan |
| `method` | `get` atau `post` |
| `target` | Di mana hasil ditampilkan |
| `autocomplete` | Izinkan saran browser |
| `enctype` | Encoding untuk upload file |

## GET vs POST

- **GET** — data di URL, bisa di-bookmark, cocok untuk pencarian
- **POST** — data di body, tidak terlihat di URL, cocok untuk data sensitif

## Atribut pada input

- `name` — kunci data saat dikirim
- `value` — nilai awal
- `placeholder` — petunjuk singkat
- `required` — wajib diisi
- `readonly` — bisa dibaca, tidak diubah
- `disabled` — tidak ikut dikirim
- `autofocus` — fokus otomatis
- `pattern` — pola regex untuk validasi

## Label yang Benar

```html
<label for="email">Email:</label>
<input id="email" type="email" name="email">
```

`for` pada label harus sama dengan `id` input. Ini membuat label bisa diklik dan dibaca pembaca layar.

<div class="note">💡 Untuk upload file, wajib pakai <code>method="post"</code> dan <code>enctype="multipart/form-data"</code>.</div>
