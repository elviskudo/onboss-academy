**Geolocation API** memberi tahu koordinat perangkat pengguna — dengan izin mereka.

## Cara Kerja

```js
navigator.geolocation.getCurrentPosition(berhasil, gagal);
```

Fungsi `berhasil` menerima objek `position`:

```js
function berhasil(position) {
  console.log(position.coords.latitude);
  console.log(position.coords.longitude);
}
```

## Opsi Tambahan

```js
navigator.geolocation.getCurrentPosition(berhasil, gagal, {
  enableHighAccuracy: true,
  timeout: 10000,
  maximumAge: 60000
});
```

## Penting: Izin & Privasi

- Browser akan menampilkan prompt izin
- Pengguna bisa menolak — aplikasi harus tetap berfungsi
- Lokasi dianggap data sensitif
- Hampir semua browser mewajibkan HTTPS

<div class="note">💡 Jangan meminta lokasi saat halaman baru dibuka jika belum jelas gunanya. Minta saat pengguna benar-benar menekan tombol "Lokasi Saya".</div>

## Pantau Perubahan

```js
const id = navigator.geolocation.watchPosition(berhasil);
// nanti: navigator.geolocation.clearWatch(id);
```

Cocok untuk navigasi atau tracking pergerakan.

Klik tombol untuk mencoba (browser akan meminta izin).

<TryIt lang="html" runtime="client-html" pistonName="html" code={`<!DOCTYPE html>
<html>
<body style="font-family: sans-serif; padding: 16px;">
  <h1>Geolocation</h1>
  <button onclick="lokasi()">Tampilkan Lokasiku</button>
  <p id="hasil">Belum ada data.</p>
  <script>
    function lokasi() {
      if (!navigator.geolocation) {
        document.getElementById('hasil').textContent = 'Tidak didukung.';
        return;
      }
      navigator.geolocation.getCurrentPosition(
        p => document.getElementById('hasil').textContent =
          'Latitude: ' + p.coords.latitude.toFixed(4) +
          '<br>Longitude: ' + p.coords.longitude.toFixed(4),
        e => document.getElementById('hasil').textContent = 'Error: ' + e.message
      );
    }
  </script>
</body>
