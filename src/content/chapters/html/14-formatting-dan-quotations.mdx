HTML menyediakan elemen khusus untuk memberi **makna** pada teks, bukan sekadar mengubah tampilannya.

## Formatting Semantik

| Elemen | Makna |
|--------|-------|
| `<strong>` | Teks penting |
| `<em>` | Penekanan |
| `<mark>` | Teks yang ditandai/disorot |
| `<small>` | Teks kecil (catatan) |
| `<del>` | Teks yang dihapus |
| `<ins>` | Teks yang disisipkan |
| `<sub>` / `<sup>` | Subskrip / superskrip |

## Kutipan

```html
<!-- Kutipan singkat sebaris -->
<p>Dia bilang <q>Halo dunia</q> dengan senyum.</p>

<!-- Kutipan blok -->
<blockquote cite="https://contoh.com/artikel">
  <p>HTML adalah tulang punggung web.</p>
</blockquote>

<!-- Judul karya -->
<p><cite>Belajar HTML dari Nol</cite> — OnBoss Academy</p>
```

Atribut `cite` berisi URL sumber, meski tidak selalu terlihat di browser.

## Teks Teknis

```html
<p>Gunakan <code>&lt;p&gt;</code> untuk paragraf.</p>
<pre><code>{`function halo() {
  console.log("Halo!");
}`}</code></pre>
<p>Tekan <kbd>Ctrl</kbd> + <kbd>S</kbd> untuk menyimpan.</p>
```

`<pre>` mempertahankan spasi dan baris, cocok untuk kode panjang.
