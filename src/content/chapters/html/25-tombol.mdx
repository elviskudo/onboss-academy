Tombol adalah cara pengguna berinteraksi. HTML menyediakan dua cara membuatnya: `<button>` dan `<input type="button">`. Yang pertama lebih fleksibel.

## Elemen button

```html
<button type="button">Klik Aku</button>
```

Di dalam `<button>` kamu boleh menaruh teks, emoji, bahkan ikon SVG:

```html
<button type="button">
  <span>💾</span> Simpan
</button>
```

## Tiga Jenis type

| type | Fungsi |
|------|--------|
| `submit` | Mengirim form (default di dalam form) |
| `reset` | Mengembalikan nilai form ke awal |
| `button` | Tidak melakukan apa-apa kecuali ada JavaScript |

## Atribut Berguna

- `disabled` — tombol tidak aktif
- `name` / `value` — dikirim bersama form
- `form` — menghubungkan tombol ke form berdasarkan id

## Aksesibilitas

`<button>` sudah fokus-otomatis saat ditekan Tab dan bisa diaktifkan dengan Enter/Spasi. Itu sebabnya jangan menggantinya dengan `<div onclick>`.

<div class="note">💡 Kalau tombol ada di dalam form dan tidak boleh mengirim, selalu tulis <code>type="button"</code> secara eksplisit.</div>
