Drag and Drop API membuat elemen bisa diseret dengan mouse dan dijatuhkan di area lain — tanpa library tambahan.

## Alur Event

| Event | Terjadi saat |
|-------|--------------|
| `dragstart` | Mulai menyeret |
| `drag` | Selama menyeret |
| `dragenter` | Masuk area target |
| `dragover` | Di atas target |
| `dragleave` | Keluar target |
| `drop` | Dilepas di target |
| `dragend` | Selesai menyeret |

## Langkah Minimal

1. Tambahkan `draggable="true"` pada elemen
2. Di `dragstart`, simpan identitas dengan `dataTransfer.setData()`
3. Di target, panggil `event.preventDefault()` pada `dragover`
4. Di `drop`, ambil data dan pindahkan elemen

## Kenapa dragover Harus dicegah?

Secara default browser tidak mengizinkan drop. Memanggil `preventDefault()` pada `dragover` memberi sinyal bahwa area ini menerima elemen.

## Kasus Penggunaan

- Upload file dengan cara menyeret file ke area
- Mengurutkan item (to-do list, kanban)
- Memindahkan foto antar album

<div class="note">💡 Drag and Drop kurang ramah di layar sentuh. Selalu sediakan alternatif seperti tombol "Pindahkan" untuk pengguna mobile.</div>
