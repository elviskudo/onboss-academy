HTML5 menambahkan banyak `type` pada input sehingga browser bisa memberi antarmuka dan validasi bawaan.

## Daftar Input Type Populer

| type | Fungsi |
|------|--------|
| `text` | Teks biasa (default) |
| `password` | Teks tersembunyi |
| `email` | Alamat email |
| `tel` | Nomor telepon |
| `url` | URL |
| `number` | Angka |
| `date` / `time` | Tanggal / waktu |
| `checkbox` | Pilihan ganda |
| `radio` | Pilihan tunggal dalam grup |
| `file` | Upload berkas |
| `color` | Pemilih warna |
| `range` | Slider |
| `hidden` | Tidak terlihat, tetap dikirim |

## Validasi Bawaan

```html
<input type="email" required minlength="5">
<input type="number" min="1" max="100" step="1">
<input type="text" pattern="[A-Za-z]{3,}">
```

Atribut `required`, `min`, `max`, `pattern`, dan lain-lain dicek browser sebelum form dikirim.

## Keyboard Mobile

`type="email"` memunculkan keyboard dengan tombol `@`; `type="tel"` memunculkan keypad angka. Detail kecil yang meningkatkan pengalaman pengguna.

<div class="note">💡 Validasi browser hanya lapisan pertama. Tetap validasi di server karena pengguna bisa mem-bypass HTML.</div>
