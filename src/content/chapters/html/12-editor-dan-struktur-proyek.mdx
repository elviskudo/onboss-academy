Menulis HTML tidak butuh software berat. Yang kamu butuhkan hanyalah **teks editor** dan **browser**.

## Teks Editor yang Disarankan

- **Visual Studio Code** — gratis, punya ekstensi HTML & Live Server
- **Sublime Text** — ringan dan cepat
- **Notepad++** — populer di Windows
- **TextEdit / nano** — bawaan macOS/Linux (pastikan mode teks biasa)

Hindari Word atau editor kaya teks lain: mereka menyisipkan format tersembunyi yang membuat browser bingung membaca kode.

## Membuat File Pertama

1. Buat folder baru, misalnya `belajar-html`
2. Di dalamnya, buat file `index.html`
3. Ketik kerangka dasar, lalu simpan
4. Klik dua kali file itu — browser akan menampilkannya

<div class="note">💡 Gunakan <code>index.html</code> sebagai nama file utama.nginx, Apache, dan GitHub Pages otomatis mencari nama ini saat membuka sebuah folder.</div>

## Struktur Folder yang Rapi

```
belajar-html/
├── index.html
├── about.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── script.js
│   └── images/
│       └── foto.jpg
```

Memisahkan aset sejak awal membuat proyek mudah dikembangkan. Saat nanti kamu menambah banyak halaman, semua gambar dan style tetap tertata.

## Live Server

Ekstensi **Live Server** di VS Code menjalankan server lokal (biasanya di `http://127.0.0.1:5500`) dan memuat ulang halaman otomatis setiap kali kamu menyimpan file. Ini jauh lebih nyaman daripada membuka file dengan `file://` karena perilakunya lebih mirip server sungguhan.
