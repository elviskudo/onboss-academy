**Atribut** memberi informasi tambahan tentang elemen. Atribut selalu ditulis dalam pasangan `nama="nilai"` di dalam tag pembuka.

## Atribut Umum

| Atribut | Dipakai di | Fungsi |
|---------|-----------|--------|
| `src` | `<img>`, `<script>`, `<iframe>` | Sumber file |
| `href` | `<a>`, `<link>` | Alamat tautan |
| `alt` | `<img>` | Teks alternatif |
| `title` | hampir semua elemen | Tooltip saat di-hover |
| `class` | hampir semua elemen | Pengelompokan untuk CSS |
| `id` | hampir semua elemen | Identitas unik |

## Path Relatif vs Absolut

**Path relatif** dihitung dari posisi file HTML saat ini:

```html
<img src="foto.jpg">              <!-- file di folder yang sama -->
<img src="images/foto.jpg">       <!-- di dalam subfolder -->
<img src="../foto.jpg">           <!-- naik satu folder -->
```

**Path absolut** dimulai dari root server:

```html
<img src="/assets/img/foto.jpg">
```

Gunakan path relatif untuk proyek lokal yang sederhana. Path absolut lebih aman saat aplikasi punya banyak halaman di berbagai level folder.

## Atribut untuk Tautan

```html
<a href="https://example.com" target="_blank" rel="noopener">
  Buka di tab baru
</a>
```

`target="_blank"` membuka tautan di tab baru. Selalu tambahkan `rel="noopener"` untuk alasan keamanan.
