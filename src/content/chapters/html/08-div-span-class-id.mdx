Saat styling dan JavaScript masuk permainan, kamu perlu penanda elemen.

## `<div>` dan `<span>`

```html
<div class="kartu">
  <h3>Judul Kartu</h3>
  <p>Isi dengan <span class="tebal">penekanan</span> di tengah teks.</p>
</div>
```

- `<div>` — kontainer *block* (memakan lebar penuh, mulai baris baru)
- `<span>` — pembungkus *inline* (hanya membungkus potongan teks)

Keduanya **tidak bermakna apa pun** secara semantik — sekadar kotak.

## Atribut `class` dan `id`

```html
<div class="kartu kartu-gelap" id="promo-lebaran">
  ...
</div>
```

| | `class` | `id` |
|---|---------|------|
| Jumlah | Boleh banyak elemen | **Unik**, satu per halaman |
| Dipakai untuk | Styling berulang (CSS) | Target skrip (JS), anchor, label form |
| Di CSS | `.kartu` | `#promo-lebaran` |

Satu elemen boleh punya banyak class (pisahkan dengan spasi), tapi hanya satu id.

HTML memiliki **sekitar 20 atribut global**; `class` dan `id` adalah dua yang paling sering menghubungkan HTML ke CSS dan JavaScript.

| Penanda | Boleh berulang? | Jumlah per elemen | Target CSS | Kegunaan nyata |
|---------|-----------------|-------------------|------------|----------------|
| `class` | Ya | Banyak, dipisah spasi | `.kartu` | Gaya dan kelompok komponen |
| `id` | Tidak, harus unik | Satu | `#promo` | Anchor, label, target JS |
| `data-*` | Ya | Banyak | `[data-status]` | Data khusus untuk skrip |

## Praktik yang Baik

```html
<!-- ✔ deskriptif -->
<div class="product-card product-card--sale">

<!-- ✗ ambigu -->
<div class="box1 red big-text">
```

Nama class yang menjelaskan **peran**, bukan tampilan, akan memudahkanmu saat proyek membesar.

## Di Dunia Nyata

- **Katalog produk** — semua kartu berbagi class `product-card`; produk promo mendapat class tambahan `sale`
- **Navigasi satu halaman** — link `#kontak` melompat ke elemen unik `id="kontak"`
- **Dashboard** — `data-status="paid"` menyimpan status yang dibaca JavaScript tanpa mengubah teks
- **Artikel** — `<span class="highlight">` menandai beberapa kata tanpa memutus paragraf

<div class="note">💡 Mulai dari elemen semantik; gunakan `<div>` atau `<span>` hanya saat tidak ada elemen HTML yang menjelaskan maknanya. Class adalah kontrak gaya yang bisa dipakai ulang, sedangkan id adalah alamat unik.</div>
