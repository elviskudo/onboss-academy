`<canvas>` adalah 'kanvas' kosong berukuran tertentu. Semua gambar dilakukan lewat JavaScript.

## Membuat Canvas

```html
<canvas id="gambar" width="400" height="200"></canvas>
```

Lalu ambil konteksnya:

```js
const canvas = document.getElementById('gambar');
const ctx = canvas.getContext('2d');
```

## Menggambar Bentuk

```js
ctx.fillStyle = 'skyblue';
ctx.fillRect(10, 10, 100, 50);

ctx.strokeStyle = 'red';
ctx.strokeRect(130, 10, 100, 50);

ctx.beginPath();
ctx.arc(80, 130, 40, 0, Math.PI * 2);
ctx.fill();
```

## Menulis Teks

```js
ctx.font = '24px Arial';
ctx.fillText('Halo!', 10, 180);
```

## Perbedaan Canvas vs SVG

| Canvas | SVG |
|--------|-----|
| Berbasis piksel | Berbasis vektor |
| Cocok untuk game | Cocok untuk ikon & diagram |
| Tidak punya DOM per bentuk | Tiap bentuk bisa diklik |
| Performa tinggi untuk banyak objek | Mudah di-CSS |

<div class="note">💡 Ubah ukuran canvas lewat atribut HTML, bukan CSS, supaya koordinat gambar tidak ikut ter-skala.</div>
