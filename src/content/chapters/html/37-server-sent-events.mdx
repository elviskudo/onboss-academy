**Server-Sent Events (SSE)** memungkinkan server 'mendorong' data ke browser secara real-time melalui satu koneksi HTTP yang tetap terbuka.

## Kapan Memakai SSE?

- Feed notifikasi
- Harga saham / crypto
- Status progres pekerjaan
- Log server langsung

Kalau butuh komunikasi dua arah (chat), gunakan **WebSocket**.

## Klien

```js
const source = new EventSource('/events');

source.onmessage = e => {
  console.log(e.data);
};

source.addEventListener('update', e => {
  console.log('Event bernama update:', e.data);
});
```

## Format Pesan dari Server

Server mengirim teks dengan format sederhana:

```
data: Halo dunia

event: update
data: 42
```

Tiap pesan dipisah baris kosong.

## Perbandingan Singkat

| | SSE | WebSocket |
|---|-----|-----------|
| Arah | Server → klien | Dua arah |
| Protokol | HTTP biasa | ws:// |
| Reconnect | Otomatis | Manual |
| Kompleksitas | Sederhana | Lebih kompleks |

<div class="note">💡 SSE tidak didukung Internet Explorer. Untuk browser modern, ini pilihan yang sangat ringan dibanding WebSocket kalau hanya butuh aliran satu arah.</div>
