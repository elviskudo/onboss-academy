Bagian `<head>` adalah 'kotak informasi' halaman. Isinya tidak terlihat pengunjung, tapi sangat berpengaruh pada browser dan mesin pencari.

## Elemen yang Sering Dipakai

| Elemen | Fungsi |
|--------|--------|
| `<title>` | Judul tab & hasil pencarian |
| `<meta charset>` | Set karakter (pakai UTF-8) |
| `<meta name="viewport">` | Kontrol tampilan mobile |
| `<meta name="description">` | Ringkasan halaman |
| `<link rel="stylesheet">` | Memuat CSS |
| `<link rel="icon">` | Favicon di tab |
| `<script>` | Memuat JavaScript |
| `<base>` | URL dasar tautan relatif |

## Contoh Head Lengkap

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Belajar HTML dari nol, gratis.">
  <title>Belajar HTML | OnBoss</title>
  <link rel="stylesheet" href="css/style.css">
</head>
```

## Kenapa Viewport Penting?

Tanpa meta viewport, browser mobile menganggap halaman selebar desktop lalu mengecilkan tampilan. dengan viewport, lebar halaman mengikuti perangkat sehingga teks tetap terbaca.

<div class="note">💡 Selalu pakai <code>&lt;meta charset="UTF-8"&gt;</code> supaya karakter seperti é, 日本語, dan emoji tampil benar.</div>
