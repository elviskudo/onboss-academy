Layout yang rapi membuat halaman mudah dipahami baik oleh manusia maupun mesin pencari.

## Elemen Semantik untuk Layout

```html
<header>  <!-- kepala halaman -->
<nav>     <!-- navigasi -->
<main>    <!-- konten utama (hanya satu) -->
  <article>...</article>
  <aside>...</aside>   <!-- sidebar -->
</main>
<footer>  <!-- kaki halaman -->
```

## Flexbox

```css
.container {
  display: flex;
  gap: 16px;
}
.item { flex: 1; }
```

Flexbox cocok untuk tata letak satu dimensi: baris **atau** kolom.

## CSS Grid

```css
.grid {
  display: grid;
  grid-template-columns: 2fr 1fr;
  gap: 16px;
}
```

Grid cocok untuk layout dua dimensi: baris **dan** kolom sekaligus.

## Float (Cara Lama)

```css
.sidebar { float: right; width: 30%; }
.content { float: left; width: 70%; }
```

Float masih sering ditemui di kode lama, tapi Flexbox dan Grid lebih disarankan untuk proyek baru.

<div class="note">💡 Gunakan elemen semantik dulu untuk 'makna', lalu CSS untuk 'tampilan'. Keduanya saling melengkapi.</div>
