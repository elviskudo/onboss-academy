Dulu sempat populer perdebatan: HTML atau XHTML? Sekarang jawabannya jelas — **HTML5** yang dipakai hampir semua situs. Tapi memahami XHTML tetap berguna saat membaca kode lama.

## Perbedaan Utama

| Aspek | HTML5 | XHTML |
|-------|-------|-------|
| Sintaks | Longgar | Ketat (XML) |
| Tag penutup | Boleh diabaikan sebagian | Wajib |
| Huruf | Bebas | Huruf kecil |
| Atribut | Boleh tanpa tanda kutip | Wajib dikutip |
| Void element | `<br>` | `<br />` |

## Contoh XHTML yang Valid

```html
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
  "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="id">
<head>
  <title>Contoh</title>
</head>
<body>
  <p>Ini paragraf.</p>
  <img src="foto.jpg" alt="Foto" />
</body>
</html>
```

## Kenapa HTML5 Menang?

HTML5 lebih pragmatis: browser tetap bisa merender halaman meski ada tag yang lupa ditutup. XHTML memaksa penulisan sempurna, dan satu kesalahan kecil bisa membuat halaman kosong.

<div class="note">💡 Kamu tetap bisa menulis HTML5 dengan disiplin ala XHTML (tag ditutup, atribut dikutip). Itu kebiasaan bagus, tanpa harus memakai DTD XHTML.</div>
