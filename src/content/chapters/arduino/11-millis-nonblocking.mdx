`delay()` sederhana, tetapi membekukan MCU. Pola `millis()` memungkinkan banyak tugas berjalan bersamaan secara cooperatif.

## Perbandingan

| Pendekatan | Efek | Cocok untuk |
|---|---|---|
| `delay(1000)` | MCU diam 1 detik | Eksperimen sangat sederhana |
| `millis()` | MCU tetap aktif | Tombol + LED + sensor sekaligus |

## Pola Dasar

```cpp
unsigned long waktuTerakhir = 0;
const long interval = 1000;

void loop() {
  if (millis() - waktuTerakhir >= interval) {
    waktuTerakhir = millis();
    jalankanTugas();
  }
  bacaTombol();   // tetap responsif
}
```

Gunakan **pengurangan**, bukan `millis() > waktu + interval`, agar aman saat nilai melacak (overflow).

## Dua Jadwal

```cpp
unsigned long tLed = 0, tSensor = 0;

void loop() {
  if (millis() - tLed >= 250) { tLed = millis(); toggleLed(); }
  if (millis() - tSensor >= 2000) { tSensor = millis(); bacaSensor(); }
}
```

## State Machine Sederhana

```cpp
enum State { MENUNGGU, BERDENYUT };
State state = MENUNGGU;
```

Kombinasikan `millis()` dengan keadaan untuk perilaku kompleks tanpa `delay`.

<div class="note">💡 Jika butuh presisi mikrodetik atau interupsi nyata, gunakan timer hardware atau `attachInterrupt()`—bukan loop `millis()`.</div>
