Servo cocok untuk gerakan sudut tertentu; motor DC cocok untuk rotasi terus-menerus. Keduanya butuh daya lebih besar daripada pin GPIO.

## Servo

```cpp
#include <Servo.h>
Servo servo;

servo.attach(9);
servo.write(90);                // derajat
servo.writeMicroseconds(1500);  // kontrol lebih presisi
```

Berikan daya servo dari sumber eksternal 5 V, dan hubungkan **GND bersama** dengan Arduino.

## Kalibrasi Servo

Tidak semua servo mencapai sudut penuh pada pulsa 1000–2000 µs. Temukan batas aman dengan `writeMicroseconds()` dan simpan nilainya sebagai konstanta.

## Motor DC dengan L298N

```cpp
pinMode(IN1, OUTPUT);
pinMode(IN2, OUTPUT);
pinMode(ENA, OUTPUT);

digitalWrite(IN1, HIGH);
digitalWrite(IN2, LOW);
analogWrite(ENA, 150);   // kecepatan
```

## Rangkaian Transistor

```text
Arduino pin -> resistor 1k -> basis transistor
motor -> supply 5-12 V -> kolektor
dioda 1N4007 paralel dengan motor
emitter -> GND
```

<div class="note">💡 Jangan memberi daya motor dari pin 5V Arduino saat motor menarik arus besar—regulator bisa panas dan board reset sendiri.</div>
