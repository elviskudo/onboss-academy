Debugging yang sistematis menghemat waktu. Ubah satu hal, amati hasilnya, lalu lanjut—jangan menebak dan mengubah semuanya sekaligus.

## Daftar Cek Cepat

```text
[ ] Kabel GND terhubung
[ ] Polaritas LED benar (kaki panjang ke pin)
[ ] Resistor sesuai
[ ] PinMode sudah diatur
[ ] Board & port dipilih benar
[ ] Serial baud cocok
```

## Multimeter

| Mode | Yang dicek |
|---|---|
| Continuity | Kabel dan sambungan |
| DC Voltage | Tegangan pin & catu daya |
| Resistance | Nilai resistor |
| Diode test | Polaritas LED/dioda |

## Serial Debugging

```cpp
Serial.print('A0=');
Serial.print(analogRead(A0));
Serial.print(' state=');
Serial.println(state);
```

Tambahkan label agar angka tidak membingungkan saat banyak nilai.

## Isolasi Bertahap

1. Uji LED built-in pin 13 → verifikasi board & sketch.
2. Tambah resistor + LED eksternal → verifikasi rangkaian.
3. Tambah sensor satu per satu → verifikasi library & alamat.
4. Gabungkan semua di sketch akhir.

<div class="note">💡 Setelah selesai debug, hapus atau beri komentar pada Serial.print yang tidak perlu—terutama jika board berjalan otonom.</div>
