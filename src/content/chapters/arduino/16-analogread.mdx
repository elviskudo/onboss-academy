Pin analog mengubah tegangan menjadi angka. Memahami rentang dan referensi membuat konversi ke satuan dunia nyata menjadi tepat.

## ADC Uno

| Parameter | Nilai |
|---|---|
| Resolusi | 10 bit (0–1023) |
| Referensi default | 5 V |
| Step tegangan | ~4,9 mV |
| Input impedance | ~100 MΩ |

## Konversi

```cpp
float volt = analogRead(A0) * (5.0 / 1023.0);
```

Untuk sensor 3,3 V pada Uno, gunakan pembagi tegangan atau ubah referensi ke `INTERNAL`—jangan langsung memberi 3,3 V ke pin yang dikonfigurasi untuk 5 V tanpa perhitungan ulang.

## Referensi

```cpp
analogReference(DEFAULT);   // 5 V (Uno)
analogReference(INTERNAL);  // 1,1 V (Uno)
```

Tunggu beberapa milidetik setelah mengganti referensi sebelum membaca.

## Rata-rata

```cpp
long total = 0;
for (int i = 0; i < 16; i++) {
  total += analogRead(A0);
}
float hasil = total / 16.0;
```

## Potensiometer

```text
5V ----[ pot 10k ]---- GND
           |
           +---- A0
```

Nilai berubah sesuai posisi tuas. Ini cara termudah mencoba input analog.

<div class="note">💡 Pin A0–A5 juga bisa dipakai sebagai digital I/O dengan `digitalRead(A0)`. Namun sekali dipakai untuk ADC, jumlah pin digital berkurang.</div>
