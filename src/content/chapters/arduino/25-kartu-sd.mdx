Logging ke kartu SD membuat proyek bisa berjalan jauh dari komputer. Format CSV sederhana dan bisa langsung dibuka di spreadsheet.

## Rangkaian

```text
SD CS  -> pin 4 (contoh)
MOSI   -> 11
MISO   -> 12
SCK    -> 13
VCC    -> 5 V atau 3,3 V sesuai modul
GND    -> GND
```

Modul dengan regulator dan level shifter lebih aman dengan Uno.

## Menulis Baris

```cpp
File f = SD.open('data.csv', FILE_WRITE);
if (f) {
  f.print(millis());
  f.print(',');
  f.println(suhu);
  f.close();
} else {
  Serial.println('Gagal membuka file');
}
```

## Membaca Kembali

```cpp
File f = SD.open('data.csv');
while (f.available()) {
  Serial.write(f.read());
}
f.close();
```

## Nama File

Nama file 8.3 lebih kompatibel: `DATA.CSV`, bukan nama panjang dengan spasi.

<div class="note">💡 Selalu matikan daya sebelum mencabut kartu SD. Kartu yang dicabut saat sedang menulis bisa corrupt.</div>
