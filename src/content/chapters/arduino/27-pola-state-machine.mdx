Saat proyek bertambah kompleks, kumpulan if bersarang menjadi sulit diikuti. State machine menyusun perilaku sebagai keadaan yang jelas dengan transisi yang terukur.

## Konsep

```text
IDLE --tombol--> JALAN --sensor selesai--> SELESAI --reset--> IDLE
```

## Implementasi

```cpp
enum State { IDLE, JALAN, SELESAI };
State state = IDLE;

void loop() {
  switch (state) {
    case IDLE:
      if (digitalRead(TOMBOL) == LOW) {
        state = JALAN;
        mulaiWaktu = millis();
      }
      break;
    case JALAN:
      jalankan();
      if (millis() - mulaiWaktu > DURASI) state = SELESAI;
      break;
    case SELESAI:
      berhenti();
      if (digitalRead(TOMBOL) == LOW) state = IDLE;
      break;
  }
}
```

## Aksi Entry dan Exit

Saat memasuki keadaan, lakukan inisialisasi (misal mulai timer). Saat keluar, matikan aktuator. Ini mencegah motor tetap jalan setelah keadaan berubah.

## Memberi Nama Keadaan

Gunakan `enum class` pada C++11 untuk menghindari tabrakan nama:

```cpp
enum class Mode { SIAP, JALAN, ERROR };
Mode m = Mode::SIAP;
```

<div class="note">💡 Hindari blocking di setiap keadaan. Kalau sebuah keadaan butuh menunggu, simpan waktunya dan gunakan pola `millis()`.</div>
