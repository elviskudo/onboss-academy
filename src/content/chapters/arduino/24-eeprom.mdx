EEPROM adalah memori kecil yang bertahan setelah board dimatikan. Cocok untuk kalibrasi, batas ambang, atau pengaturan pengguna.

## Dasar

```cpp
#include <EEPROM.h>

EEPROM.write(0, 42);
byte nilai = EEPROM.read(0);
```

Alamat 0–1023 pada Uno.

## Struct

```cpp
struct Settings {
  int suhuMaks;
  int suhuMin;
  byte mode;
};

Settings s{30, 24, 1};
EEPROM.put(0, s);

Settings baca;
EEPROM.get(0, baca);
```

## Update Hemat

```cpp
if (EEPROM.read(alamat) != nilaiBaru) {
  EEPROM.write(alamat, nilaiBaru);
}
```

Hindari menulis nilai yang sama—perpanjang umur EEPROM.

## Checksum

Tambahkan checksum sederhana untuk mendeteksi data rusak:

```cpp
byte checksum = a ^ b ^ c;
```

<div class="note">💡 EEPROM bukan pengganti database. Untuk log sensor yang terus bertambah, gunakan kartu SD atau kirim ke komputer.</div>
