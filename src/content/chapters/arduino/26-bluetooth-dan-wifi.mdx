Modul nirkabel mengubah Arduino menjadi perangkat IoT. Dua pilihan murah: HM-10 (BLE) dan ESP-01 (Wi-Fi), keduanya memakai UART.

## HM-10

```text
Perintah AT (dari Serial Monitor pada 9600 baud):
AT             -> OK
AT+NAMEArduku  -> mengubah nama
AT+ROLE0       -> peripheral
```

## ESP-01

```text
AT                    -> OK
AT+CWMODE=1           -> station
AT+CWJAP="wifi","sandi" -> hubung ke router
```

## SoftwareSerial

```cpp
#include <SoftwareSerial.h>
SoftwareSerial modul(2, 3);   // RX=2, TX=3

modul.begin(9600);
modul.println('Halo');
```

Gunakan baud 9600 untuk memulai. Pin RX modul harus menerima TX Arduino, dan sebaliknya.

## Level Shifter

Modul ESP-01 beroperasi di 3,3 V. Pin TX Arduino 5 V perlu diturunkan dengan pembagi tegangan sebelum masuk ke RX ESP-01.

<div class="note">💡 Untuk proyek Wi-Fi yang lebih besar, pertimbangkan ESP32 sebagai pengganti Arduino+ESP-01—terintegrasi, lebih cepat, dan banyak pin.</div>
