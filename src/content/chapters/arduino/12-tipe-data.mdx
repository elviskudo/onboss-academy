Memori Arduino sangat terbatas. Memilih tipe yang tepat membuat program lebih kecil dan lebih cepat.

## Tipe Umum

| Tipe | Rentang (Uno) | Ukuran |
|---|---|---|
| `byte` | 0–255 | 1 byte |
| `int` | -32.768–32.767 | 2 byte |
| `unsigned int` | 0–65.535 | 2 byte |
| `long` | ±2,1 miliar | 4 byte |
| `float` | ~6 digit desimal | 4 byte |
| `bool` | true/false | 1 byte |
| `char` | -128–127 | 1 byte |

## Konversi

```cpp
int x = 65;
char c = (char)x;       // 'A'
float f = x / 2.0;      // 32.5, karena 2.0 float
int g = x / 2;          // 32, pembagian integer
```

## String vs char Array

```cpp
char teks[] = 'Halo';   // 5 byte termasuk '\0'
String s = 'Halo';      // lebih fleksibel, tapi boros & fragmentasi
```

Pada Uno, hindari `String` untuk input yang berubah-ubah—pakai array `char` dengan ukuran tetap.

## Konstanta

```cpp
const int PIN_LED = 13;
#define PIN_TOMBOL 2
```

`const` lebih aman karena tetap memeriksa tipe; `#define` hanya pengganti teks.

<div class="note">💡 `sizeof(int)` berbeda antara Uno (2) dan Due/ESP32 (4). Jangan mengasumsikan ukuran saat berpindah board.</div>
