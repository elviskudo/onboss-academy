`analogWrite()` tidak menghasilkan tegangan analog sungguhan. Ia menghasilkan sinyal PWM—nyala dan mati cepat—yang dirasakan sebagai kecerahan rata-rata.

## Duty Cycle

```text
0   -> 0%  (mati)
64  -> 25%
128 -> 50%
255 -> 100%
```

## Pin PWM

| Board | Pin PWM |
|---|---|
| Uno | 3, 5, 6, 9, 10, 11 |
| Nano | sama dengan Uno |
| Mega | 2–13 plus 44–46 |

## Contoh Fade

```cpp
for (int nilai = 0; nilai <= 255; nilai++) {
  analogWrite(9, nilai);
  delay(10);
}
```

## Servo vs LED

Servo memakai PWM dengan frekuensi 50 Hz dan lebar pulsa tertentu, bukan sekadar duty cycle. Gunakan library `Servo` agar timing presisi.

<div class="note">💡 Driver motor dan LED strip bisa memakai PWM yang sama, tetapi sering membutuhkan frekuensi berbeda. Ubah timer hanya bila kamu memahami efeknya ke `millis()` dan `delay()`.</div>
