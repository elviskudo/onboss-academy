Setiap sketch memiliki kerangka yang sama: deklarasi, `setup()`, lalu `loop()`. Memahami alurnya membuat program lebih mudah dibaca dan di-debug.

## Kerangka Minimal

```cpp
void setup() {
  // dijalankan sekali
}

void loop() {
  // dijalankan berulang
}
```

`setup()` dipanggil setelah reset. `loop()` tidak pernah berhenti kecuali board mati.

## Variabel

```cpp
const int LED = 13;     // konstan, tidak bisa diubah
int suhu = 0;           // global
bool nyala = false;

void loop() {
  int lokal = analogRead(A0);  // hanya ada di dalam loop
}
```

Gunakan `const` untuk pin dan batas agar niat kode jelas.

## Fungsi Tambahan

```cpp
void kedip(int pin, int lama) {
  digitalWrite(pin, HIGH);
  delay(lama);
  digitalWrite(pin, LOW);
  delay(lama);
}
```

Fungsi membantu menghindari duplikasi kode saat pola yang sama dipakai berulang.

## Compile dan Upload

1. Pilih **Board** dan **Port** di menu Tools.
2. Klik **Verify** untuk kompilasi.
3. Klik **Upload** untuk mengirim sketch.
4. Lihat hasil di Serial Monitor bila perlu.

<div class="note">💡 `delay()` membekukan seluruh program. Untuk sistem yang harus merespons tombol sambil menunggu, gunakan `millis()` seperti yang akan dibahas di chapter berikutnya.</div>
