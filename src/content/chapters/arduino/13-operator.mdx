Operator meliputi hitungan, perbandingan, dan manipulasi bit. Awasi pembagian integer dan perbedaan `=` versus `==`—dua sumber bug klasik.

## Aritmatika

| Operator | Contoh | Hasil |
|---|---|---|
| `+` | `5+2` | 7 |
| `-` | `5-2` | 3 |
| `*` | `5*2` | 10 |
| `/` | `5/2` | 2 (int) |
| `%` | `5%2` | 1 |

## Perbandingan dan Logika

```cpp
if (suhu > 30 && nyala == false) { ... }
if (tombol == HIGH || baterai < 20) { ... }
if (!selesai) { ... }
```

Operator `&&` dan `||` melakukan short-circuit: bagian kanan tidak dievaluasi bila bagian kiri sudah menentukan hasil.

## Increment

```cpp
i++;     // tambah 1
i--;     // kurang 1
i += 5;  // i = i + 5
```

## Bitwise

```cpp
byte nilai = 0b1010;
byte terbalik = ~nilai;        // 0b0101 (dalam 8 bit)
byte atas = nilai & 0xF0;      // ambil 4 bit atas
byte aplikasi = nilai | 0x01;  // nyalakan bit 0
```

Bitwise sering dipakai untuk menghemat pin—misalnya menyimpan delapan status LED dalam satu `byte`.

<div class="note">💡 Jika ingin hasil desimal dari pembagian, jadikan salah satu operand `float`: `7 / 2.0` menghasilkan `3.5`.</div>
