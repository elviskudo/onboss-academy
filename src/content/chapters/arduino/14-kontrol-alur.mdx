Kontrol alur menentukan keputusan dan pengulangan. Arduino memakai sintaks C/C++, jadi strukturnya sama dengan bahasa turunan C lainnya.

## if / else

```cpp
if (suhu >= 30) {
  nyalakanKipas();
} else if (suhu >= 25) {
  kipasPelan();
} else {
  matikanKipas();
}
```

## switch

```cpp
switch (mode) {
  case 1:
    merah();
    break;
  case 2:
    hijau();
    break;
  default:
    mati();
}
```

## for

```cpp
for (int i = 0; i < 5; i++) {
  digitalWrite(LED, i % 2);
  delay(200);
}
```

Perhatikan kondisi `&lt; 5`: iterasi berjalan untuk i = 0,1,2,3,4.

## while dan do-while

```cpp
while (digitalRead(TOMBOL) == LOW) {
  // tunggu tombol ditekan
}

do {
  baca();
} while (adaData());
```

do-while menjamin blok dijalankan minimal sekali.

<div class="note">💡 Hindari `while` tanpa jalan keluar di dalam `loop()`. Tombol yang tidak pernah tertekan membuat board tampak hang.</div>
