Proyek gerbang menggabungkan hampir semua konsep dasar: digital input, PWM servo, state machine, dan keamanan fisik.

## Komponen

| Komponen | Fungsi |
|---|---|
| Arduino Uno | Kontrol logika |
| Servo | Menggerakkan palang |
| Tombol / sensor IR | Pemicu |
| LED 3 warna | Indikator keadaan |
| Catu 5 V eksternal | Daya servo |

## Keadaan

```text
TUTUP --tombol--> BUKA --3 detik--> KELUAR --sensor kosong--> TUTUP
```

## Indikator

```cpp
switch (s) {
  case TUTUP:  merah(); break;
  case BUKA:   hijau(); break;
  case KELUAR: kuning(); break;
}
```

LED memberi informasi tanpa harus membuka Serial Monitor.

## Perlindungan

- Batasi sudut servo agar palang tidak membentur meja.
- Tambahkan tombol darurat yang langsung memutus daya servo.
- Jangan biarkan anak kecil berada di dekat mekanisme saat pengujian.

<div class="note">💡 Rangkaian awal sebaiknya memakai servo kecil dan palang dari kertas. Uji logika dulu sebelum memakai mekanisme yang lebih kuat.</div>
