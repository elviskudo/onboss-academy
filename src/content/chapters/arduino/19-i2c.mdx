I2C memungkinkan banyak perangkat berbagi dua kabel. Setiap perangkat punya alamat, sehingga master bisa memilih tujuan transaksi.

## Pin

| Board | SDA | SCL |
|---|---|---|
| Uno / Nano | A4 | A5 |
| Mega | 20 | 21 |
| Leonardo | 2 | 3 |

## Transaksi Tulis

```cpp
Wire.beginTransmission(0x3C);
Wire.write(0x00);      // register
Wire.write(0xAB);      // data
Wire.endTransmission();
```

## Transaksi Baca

```cpp
Wire.beginTransmission(0x48);
Wire.write(0x00);            // pilih register
Wire.endTransmission(false); // repeated start

Wire.requestFrom(0x48, 2);
int hi = Wire.read();
int lo = Wire.read();
```

## Resistor Pull-up

Bus I2C membutuhkan resistor pull-up ke 5 V (umumnya 4,7 kΩ). Banyak modul sudah menyediakannya; bila tidak, tambahkan sendiri. Tanpa pull-up, sinyal tidak naik ke level HIGH.

## Memindai Alamat

```cpp
for (byte a = 1; a < 127; a++) {
  Wire.beginTransmission(a);
  if (Wire.endTransmission() == 0) {
    Serial.println(a, HEX);
  }
}
```

<div class="note">💡 Modul 5 V dan board 3,3 V perlu level shifter I2C dua arah. Jangan langsung menyambungkan SDA/SCL 5 V ke Due.</div>
