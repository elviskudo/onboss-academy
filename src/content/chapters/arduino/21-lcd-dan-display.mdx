Layar kecil memberi umpan balik langsung tanpa komputer. LCD karakter murah dan tahan lama; OLED memberi grafis yang lebih fleksibel.

## LCD I2C

```cpp
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);

lcd.init();
lcd.backlight();
lcd.print('Halo Dunia');
lcd.setCursor(0, 1);
lcd.print('Baris dua');
```

Jika alamat tidak diketahui, jalankan I2C scanner dari chapter sebelumnya.

## OLED

```cpp
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

display.clearDisplay();
display.setTextSize(1);
display.setCursor(0, 0);
display.println('Suhu: 27.3 C');
display.display();
```

## Perbandingan

| Aspek | LCD 16x2 | OLED 128x64 |
|---|---|---|
| Antarmuka | I2C (dengan adapter) | I2C/SPI |
| Konsumsi | Backlight konstan | Per piksel |
| Grafik | Tidak | Ya |
| Harga | Murah | Sedang |

## Menampilkan Nilai Sensor

```cpp
lcd.clear();
lcd.setCursor(0, 0);
lcd.print('Suhu: ');
lcd.print(suhu, 1);
lcd.print(' C');
```

<div class="note">💡 Pembaruan layar terlalu sering bisa membuat tampilan berkedip. Batasi ke 1–2 kali per detik.</div>
