Interrupt memungkinkan Arduino merespons kejadian eksternal tanpa terus-menerus mengecek pin. Namun ISR punya aturan ketat agar sistem tetap stabil.

## Pin Interrupt

| Board | Pin interrupt eksternal |
|---|---|
| Uno / Nano | 2, 3 |
| Mega | 2, 3, 18, 19, 20, 21 |
| Leonardo | 0, 1, 2, 3, 7 |

## Mode Trigger

```cpp
attachInterrupt(pin, isr, RISING);   // LOW ke HIGH
attachInterrupt(pin, isr, FALLING);  // HIGH ke LOW
attachInterrupt(pin, isr, CHANGE);   // keduanya
```

## ISR yang Baik

```cpp
volatile unsigned long jumlah = 0;

void isr() {
  jumlah++;     // singkat, tanpa delay
}
```

Lakukan publikasi ke Serial atau tampilan di `loop()`, bukan di ISR.

## Debounce Tetap Perlu

Interrupt tidak menghilangkan bouncing. Tambahkan filter waktu di ISR menggunakan `micros()`, atau gunakan hardware RC.

<div class="note">💡 Matikan interrupt sementara dengan `noInterrupts()` saat mengakses variabel multi-byte yang diubah ISR, lalu aktifkan lagi dengan `interrupts()`.</div>
