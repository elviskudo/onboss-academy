Serial Monitor adalah jendela debugging paling sederhana. Dengan format yang rapi, kamu bisa melihat apa yang dipikirkan Arduino.

## Inisialisasi

```cpp
void setup() {
  Serial.begin(9600);
  while (!Serial) { }  // board dengan USB native
}
```

Pada Uno, `while(!Serial)` umumnya tidak diperlukan.

## Format Keluaran

```cpp
Serial.print(42);            // 42
Serial.print(42, HEX);       // 2A
Serial.print(3.14159, 2);    // 3.14
Serial.println('selesai');   // baris baru
```

## Membaca Perintah

```cpp
if (Serial.available() > 0) {
  String perintah = Serial.readStringUntil('\n');
  perintah.trim();
  if (perintah == 'on') digitalWrite(13, HIGH);
}
```

`readStringUntil` menunggu sampai karakter pemisah diterima; atur timeout dengan `Serial.setTimeout(50)` bila perlu.

## Plotter

Serial Plotter menampilkan grafik dari nilai numerik yang dicetak satu per baris:

```text
25.1
25.3
25.2
```

<div class="note">💡 Serial menggunakan pin 0 (RX) dan 1 (TX). Hindari memakai keduanya untuk komponen lain saat Serial Monitor aktif.</div>
