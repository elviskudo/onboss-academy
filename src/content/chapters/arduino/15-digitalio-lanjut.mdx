Membaca tombol terlihat mudah, tetapi getaran kontak sering membuat satu tekan terbaca berkali-kali. INPUT_PULLUP dan debouncing menyelesaikannya tanpa komponen tambahan.

## Rangkaian Tombol

```text
INPUT_PULLUP:
  pin 2 ---- tombol ---- GND
  (tidak perlu resistor eksternal)

Tanpa pull-up:
  5V -- resistor 10k -- pin 2 -- tombol -- GND
```

## Membaca Keadaan

```cpp
pinMode(2, INPUT_PULLUP);
if (digitalRead(2) == LOW) {
  // tombol ditekan
}
```

## Debouncing dengan millis

```cpp
if (berubah && millis() - waktuTerakhir > 50) {
  waktuTerakhir = millis();
  state = sekarang;
  prosesTombol();
}
```

50 ms biasanya cukup. Terlalu lama membuat tombol terasa lambat.

## Deteksi Tepi

```cpp
if (sekarang == LOW && sebelumnya == HIGH) {
  // tepi turun: tombol baru saja ditekan
}
```

Deteksi tepi memberi satu aksi per tekan, berbeda dengan pembacaan level yang terus mengirim aksi selama tombol dipegang.

<div class="note">💡 Gunakan interrupt untuk tombol yang benar-benar harus merespons seketika, tapi tetap terapkan debouncing agar tidak memicu berkali-kali.</div>
