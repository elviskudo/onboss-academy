Konektivitas membuat Pi bisa diperbarui, dikendalikan dari jarak jauh, dan mengirim data sensor. Dua skenario umum: bergabung ke Wi-Fi existing atau menjadi hotspot sendiri.

## Bergabung ke Wi-Fi

```bash
nmcli device wifi list
nmcli device wifi connect "NamaWiFi" password "kata-sandi"
nmcli connection show
```

Pastikan negara diatur agar kanal Wi-Fi sesuai regulasi:

```bash
sudo raspi-config  # Localisation Options -> WLAN Country
```

## Membuat Hotspot

```bash
sudo apt install hostapd dnsmasq
sudo systemctl unmask hostapd
sudo systemctl enable hostapd
```

Konfigurasi `hostapd.conf` berisi nama jaringan, kata sandi, dan kanal. `dnsmasq` memberi alamat IP ke klien.

## IP Stateless vs Statis

```text
192.168.4.1   -> alamat Pi sebagai gateway hotspot
192.168.4.2+  -> klien yang terhubung
```

## Penyulitan Koneksi

SSH, MQTT, dan HTTP bisa berjalan di hotspot. Untuk jaringan yang lebih luas, pertimbangkan WireGuard atau Tailscale agar akses tetap aman tanpa membuka port di router.

<div class="note">💡 Wi-Fi 2,4 GHz lebih kompatibel dengan modul bawaan Pi. Jaringan 5 GHz hanya didukung oleh model dengan adapter yang sesuai.</div>
