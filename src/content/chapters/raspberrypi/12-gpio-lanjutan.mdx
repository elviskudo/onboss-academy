Pin GPIO adalah jembatan antara dunia digital Pi dan komponen elektronik. Memahami mode dan batas listriknya mencegah kerusakan board.

## Tegangan dan Arus

| Pin | Level | Catatan |
|---|---|---|
| 3V3 | 3,3 V output | Maksimal sekitar 51 mA total |
| 5V | 5 V output | Langsung dari sumber USB |
| GPIO | 3,3 V logika | Jangan beri 5 V |
| GND | 0 V | Referensi bersama |

## Pull-up vs Pull-down

```text
pull-up   : tombol tidak ditekan = HIGH, ditekan = GND (LOW)
pull-down : tombol tidak ditekan = LOW,  ditekan = 3V3 (HIGH)
```

gpiozero secara default memakai `pull_up=True` untuk `Button`, sehingga rangkaian hanya butuh tombol antara pin dan GND.

## Numerasi Pin

```text
BCM  = nomor sesuai chip (17, 18, 27...)
BOARD = nomor urut physical (11, 12, 13...)
```

Tentukan satu skema di awal proyek dan konsisten. gpiozero memakai **BCM** secara default.

## Contoh gpiozero

```python
from gpiozero import LED, Button

led = LED(17)
tombol = Button(2)
tombol.when_pressed = led.toggle
```

## Men cleanup

Selalu hubungkan GNDPi dengan GND modul. Tanpa referensi bersama, pembacaan bisa meloncat-loncat meski kabel sinyal sudah benar.

<div class="note">💡 Sebelum menyambung kabel, matikan Pi. kesalahan 5 V pada pin GPIO bisa merusak SoC secara permanen.</div>
