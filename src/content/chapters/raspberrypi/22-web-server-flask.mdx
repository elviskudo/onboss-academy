Flask mengubah Pi menjadi server kecil yang bisa menyajikan data sensor atau menerima perintah lewat HTTP.

## Aplikasi Minimal

```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route('/')
def index():
    return 'Server Pi siap'

@app.route('/suhu')
def suhu():
    return jsonify({'nilai': baca_suhu(), 'satuan': 'C'})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

## Endpoint POST

```python
from flask import request

@app.route('/led', methods=['POST'])
def led():
    data = request.get_json()
    if data.get('nyala'):
        led_pin.on()
    else:
        led_pin.off()
    return jsonify({'status': 'ok'})
```

## Menjalankan sebagai Service

```ini
[Service]
ExecStart=/home/pi/proyek/venv/bin/gunicorn -b 0.0.0.0:5000 app:app
WorkingDirectory=/home/pi/proyek
Restart=always
User=pi
```

## Reverse Proxy

```nginx
location / {
    proxy_pass http://127.0.0.1:5000;
    proxy_set_header Host $host;
}
```

Nginx di depan memberi HTTPS, kompresi, dan pembatasan request.

<div class="note">💡 Simpan API key di environment variable, bukan di source code. Endpoint yang mengubah hardware sebaiknya memerlukan autentikasi.</div>
