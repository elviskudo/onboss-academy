Modul kamera resmi bisa dipasang langsung ke port CSI. Untuk Pi 4/5, kabelnya masih Standar 15-pin; untuk Pi 5 diperlukan kabel berbeda. Pastikan model kabel sesuai board.

## Aktivasi

```bash
sudo raspi-config
# Interface Options -> Camera -> Enable -> reboot

libcamera-still --list-cameras
```

## Mengambil Foto

```bash
libcamera-still -o gambar.jpg
libcamera-still -o gambar.jpg -w 1280 -h 720 -t 2000
```

`-t` adalah waktu penundaan sebelum mengambil gambar (ms).

## Rekam Video

```bash
libcamera-vid -t 10000 -o klip.h264
libcamera-vid -t 10000 --width 640 --height 480 -o klip.h264
```

## Streaming Sederhana

```bash
libcamera-vid -t 0 --inline -o - | \
  cvlc - --sout '#standard{access=http,mux=ts,dst=:8080}' --sout-keep
```

Untuk proyek pengawasan, pertimbangkan MotionEye atau FTX yang menyediakan deteksi gerakan dan penyimpanan terjadwal.

<div class="note">💡 Kabel kamera sangat sensitif. Sebelum memasang, matikan daya dan pastikan sisi biru kabel menghadap connector dengan benar.</div>
