Sebagian besar konfigurasi Raspberry Pi dilakukan lewat terminal. Menguasai beberapa perintah dasar membuat proses jauh lebih cepat daripada mengklik antarmuka grafis.

## Perintah Navigasi

| Perintah | Fungsi |
|---|---|
| `pwd` | Tampilkan direktori saat ini |
| `ls -lah` | Daftar file lengkap |
| `cd folder` | Pindah direktori |
| `cd ..` | Naik satu level |
| `mkdir nama` | Buat folder |
| `touch file` | Buat file kosong |

## Melihat Isi File

```bash
cat config.txt
less /var/log/syslog     # keluar dengan q
head -n 20 file.log
tail -f /var/log/syslog  # ikuti log baru
```

## Hak Akses

```bash
chmod +x skrip.sh        # jadikan bisa dijalankan
chown pi:pi file.txt     # ubah pemilik
sudo command             # jalankan sebagai root
```

Izin ditampilkan seperti `-rw-r--r--`: pemilik boleh tulis, grup dan lain-lain hanya baca.

## Paket

```bash
sudo apt update          # segarkan daftar paket
sudo apt upgrade         # perbarui paket terpasang
sudo apt install ghc     # pasang paket
sudo apt remove ghc      # hapus paket
apt search kata-kunci    # cari paket
```

## Informasi Sistem

```bash
hostname -I
uname -a
cat /etc/os-release
free -h
df -h
uptime
vcgencmd measure_temp
```

<div class="note">💡 Gunakan `Ctrl+C` untuk menghentikan perintah yang berjalan, dan `Ctrl+D` untuk keluar dari shell. Tab melengkapi nama file secara otomatis.</div>
