Sensor lingkungan memberi Pi "indra". Agar datanya bisa dipercaya, perhatikan cara membaca, jeda, dan kalibrasi.

## Jenis Sensor

| Sensor | Besaran | Bus |
|---|---|---|
| DHT11/DHT22 | Suhu, kelembapan | Single wire |
| BMP280 | Suhu, tekanan | I2C / SPI |
| DS18B20 | Suhu | 1-Wire |
| BH1750 | Intensitas cahaya | I2C |
| MQ-135 | Kualitas udara | Analog via ADC |

## Contoh DHT22

```python
import board
import adafruit_dht

dht = adafruit_dht.DHT22(board.D4)
try:
    print(dht.temperature, dht.humidity)
except RuntimeError:
    print("Pembacaan gagal, coba lagi")
```

## Filter Sederhana

```python
def rata_rata(data):
    return sum(data) / len(data)

data = []
data.append(baca_sensor())
if len(data) > 10:
    data.pop(0)
hasil = rata_rata(data)
```

## Kalibrasi

```text
referensi = 22.0 °C
rata-rata sensor = 21.4 °C
offset = +0.6 °C
```

Simpan offset dalam file konfigurasi agar tidak hilang saat program diperbarui.

<div class="note">💡 HDMI dan USB 3.0 bisa mengganggu pembacaan sensor suhu di Pi 4. Jauhkan sensor dari sumber panas atau gunakan kabel extended.</div>
