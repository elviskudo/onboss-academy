SSH adalah cara standar mengelola Pi tanpa monitor. Dengan kunci dan beberapa pengaturan, akses menjadi nyaman sekaligus aman.

## Koneksi Dasar

```bash
ssh pi@raspberrypi.local
ssh pi@192.168.1.50
ssh -p 2222 pi@host
```

## Kunci SSH

```bash
ssh-keygen -t ed25519 -C "laptop"
ssh-copy-id pi@raspberrypi.local
```

Lalu uji login tanpa kata sandi. Jika berhasil, nonaktifkan login password di `/etc/ssh/sshd_config`:

```text
PasswordAuthentication no
PermitRootLogin no
```

## Config SSH

```text
Host pi
    HostName raspberrypi.local
    User pi
    IdentityFile ~/.ssh/id_ed25519
```

```bash
ssh pi
```

## Port Forwarding

```bash
ssh -L 8080:localhost:80 pi@raspberrypi.local
```

Buka `http://localhost:8080` di komputer untuk mengakses web server yang berjalan di Pi.

## Sesi Panjang

Gunakan `tmux` atau `screen` agar proses tidak terputus saat koneksi putus:

```bash
tmux new -s sensor
# keluar sementara: Ctrl+B lalu D
tmux attach -t sensor
```

<div class="note">💡 Ubah kata sandi default pada installation pertama. Kredensial bawaan adalah target pertama bot yang memindai jaringan.</div>
