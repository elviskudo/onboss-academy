I2C dan SPI adalah dua bus serial yang paling sering dipakai untuk sensor. Memilih keduanya bergantung pada jumlah pin, kecepatan, dan jarak.

## Perbandingan

| Aspek | I2C | SPI |
|---|---|---|
| Kabel | SDA + SCL (+ daya) | MOSI, MISO, SCK, CS |
| Pengalamatan | Alamat 7-bit | Pin CS |
| Kecepatan | 100/400 kHz | Beberapa MHz |
| Jumlah perangkat | Banyak dalam satu bus | Tergantung CS |
| Jarak | Pendek | Pendek–menengah |

## Memindai I2C

```bash
sudo i2cdetect -y 1
```

Angka seperti `48` berarti ada perangkat di alamat `0x48`. Jika kosong, cek kabel, tegangan, dan apakah modul sudah diberi daya.

## Contoh Pembacaan

```python
import board
import busio
import adafruit_bmp280

i2c = busio.I2C(board.SCL, board.SDA)
sensor = adafruit_bmp280.Adafruit_BMP280_I2C(i2c, address=0x76)
print(sensor.temperature)
```

## Level Shifter

Banyak sensor modul beroperasi di 5 V sementara GPIO Pi 3,3 V. Gunakan level shifter I2C dua arah agar jalur SDA/SCL aman. Untuk sensor murni 3,3 V, hubungkan langsung.

<div class="note">💡 Alamat I2C bisa bentrok bila dua modul identik dipasang. Cari modul dengan jumper alamat atau gunakan multiplexer.</div>
