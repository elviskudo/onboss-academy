Perawatan yang ringan tapi rutin lebih efektif daripada perbaikan besar setelah sistem rusak. Siapkan kebiasaan berikut sejak proyek pertama.

## Checklist Mingguan

```text
[ ] vcgencmd measure_temp
[ ] df -h
[ ] systemctl --failed
[ ] journalctl -p err --since "7 days ago"
[ ] cek cadangan terakhir
```

## Backup Image

```bash
# dari komputer, dengan perangkat yang sudah dipastikan
sudo dd if=/dev/sdX of=pi-2026-01-12.img bs=4M status=progress
```

Verifikasi dengan `sha256sum`, lalu simpan di lokasi berbeda dari kartu aslinya.

## Backup Data saja

Untuk proyek yang datanya lebih penting daripada sistem, cukup salin folder proyek dan database:

```bash
tar czf proyek.tar.gz /home/pi/proyek /home/pi/data
```

## Rotasi Log

```bash
sudo journalctl --vacuum-time=14d
sudo journalctl --vacuum-size=200M
```

## Jadwal Pembaruan

```bash
sudo apt update && sudo apt full-upgrade
sudo reboot
```

Lakukan di jam yang tidak mengganggu proyek, dan catat tanggal serta versi sebelum/sesudah.

<div class="note">💡 SIM card rasanya mirip, tapi jangan pernah menebak nama perangkat `/dev/diskN`. Cek dengan `diskutil list` (macOS) atau `lsblk` (Linux).</div>
