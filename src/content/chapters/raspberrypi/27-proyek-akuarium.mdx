Proyek akuarium adalah contoh IoT yang menyentuh dunia nyata: membaca suhu, mengendalikan perangkat listrik, dan menyajikan status ke pengguna.

## Komponen

| Komponen | Fungsi |
|---|---|
| Pi + kartu SD | Otak sistem |
| DS18B20 waterproof | Sensor suhu air |
| Modul relay 1-channel | Mengontrol pemanas |
| Resistor 4,7 kΩ | Pull-up untuk 1-Wire |
| enclosure | Perlindungan listrik |

## Rangkaian 1-Wire

```text
DS18B20 DATA -> GPIO4
3V3 -> sensor
GND -> sensor
4.7k antara 3V3 dan DATA
```

## Logika Kontrol

```python
if suhu < 24.0 and tidak relay.on:
    relay.on()
elif suhu > 26.0 and relay.on:
    relay.off()
```

Jangan membalik relay setiap pembacaan—itu memperpendek umur relay dan membuat pemanas berkedip.

## Dashboard

```text
Suhu air      : 25.1 C
Status pemanas: MATI
Update terakhir: 09:42
```

Bisa disajikan lewat Flask atau dikirim ke MQTT untuk ditampilkan di phone.

## Keamanan

Gunakan relay dengan rating arus di atas beban, kabel yang memadai, dan enclosure. Tambahkan fuse serta pastikan tidak ada kontak terbuka. Untuk beban besar lebih aman memanggil teknisi.

<div class="note">💡 Awali pengujian dengan beban kecil (lampu LED 5 V) sebelum menghubungkan pemanas 220 V.</div>
