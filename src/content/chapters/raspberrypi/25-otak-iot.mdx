Proyek stasiun cuaca menggabungkan hampir semua topik yang sudah dibahas: GPIO, sensor, penyimpanan, tampilan, jaringan, dan otomatisasi.

## Struktur Proyek

```text
cuaca/
├── config.py       # pin, interval, ambang
├── sensor.py       # baca DHT22
├── simpan.py       # SQLite
├── tampilan.py     # OLED
├── kirim.py        # MQTT
└── main.py         # loop utama
```

## Loop Utama

```python
while True:
    try:
        suhu, lembap = baca_dht()
        simpan(suhu, lembap)
        tampilkan(suhu, lembap)
        kirim_mqtt(suhu, lembap)
        if suhu > BATAS and bukan_notifikasi_terakhir:
            kirim_notifikasi()
    except Exception as e:
        log.error("Gagal: %s", e)
    sleep(INTERVAL)
```

## Mengurangi Alarm Palsu

```text
suhu > 30 C selama 3 pembacaan berturut-turut -> kirim alert
suhu < 29 C -> reset penanda alert
```

Pola hysteresis ini mencegah notifikasi berulang ketika nilai berada tepat di ambang.

## Menjalankan Otomatis

```bash
sudo systemctl enable --now cuaca.service
journalctl -u cuaca.service -f
```

## Daftar Perawatan

- Kalibrasi sensor tiap beberapa bulan.
- Cek ruang disk dan retensi database.
- Perbarui sistem secara berkala saat jaringan tersedia.
- Simpan konfigurasi di git agar perubahan bisa dilacak.

<div class="note">💡 Mulai dari versi paling sederhana—satu sensor dan satu log. Tambahkan tampilan dan notifikasi setelah pembacaan stabil.</div>
