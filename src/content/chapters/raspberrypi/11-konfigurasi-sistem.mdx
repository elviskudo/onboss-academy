`raspi-config` merangkum pengaturan yang dulunya harus diedit manual. Menu ini aman untuk pemula karena setiap perubahan diminta konfirmasi.

## Menu yang Sering Dipakai

| Menu | Fungsi |
|---|---|
| System Options | Hostname, kata sandi, boot otomatis |
| Display Options | Resolusi dan overscan |
| Interface Options | SSH, kamera, I2C, SPI, 1-Wire |
| Performance Options | Pembagian memori GPU, overclock |
| Localisation Options | Zona waktu, keyboard, locale |

## Contoh: Aktifkan I2C

```bash
sudo raspi-config
# Interface Options -> I2C -> Yes -> reboot
sudo apt install i2c-tools
i2cdetect -y 1
```

## Cara Lain: config.txt

Pengaturan hardware juga bisa ditulis di `/boot/firmware/config.txt` (Pi 5) atau `/boot/config.txt` (model lama):

```text
enable_i2c=1
dtparam=spi=on
gpu_mem=128
```

## Zona Waktu

```bash
sudo timedatectl set-timezone Asia/Jakarta
timedatectl
```

Waktu yang benar penting untuk penamaan file log dan jadwal cron.

<div class="note">💡 Simpan cadangan `config.txt` sebelum mengubahnya. Baris yang salah bisa membuat layar atau kamera berhenti bekerja.</div>
