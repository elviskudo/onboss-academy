Raspberry Pi menyimpan sistem operasi di kartu microSD (atau SSD lewat USB). Menyiapkan kartu dengan benar menghindari masalah boot yang sering membingungkan pemula.

## Langkah dengan Imager

1. Pasang **Raspberry Pi Imager** di komputer.
2. Pilih **CHOOSE OS** → Raspberry Pi OS (64-bit untuk Pi 4/5).
3. Pilih **CHOOSE STORAGE** → kartu microSD.
4. Klik roda pengaturan: isi hostname, Wi-Fi, username, kata sandi, dan aktifkan SSH.
5. Klik **WRITE** dan tunggu sampai selesai.

## Kartu yang Direkomendasikan

| Spesifikasi | Saran |
|---|---|
| Kapasitas | 32 GB ke atas |
| Kelas | Class 10 / UHS-I |
| Merek | dari daftar resmi komunitas |
| Cadangan | kartu kedua untuk image cadangan |

## Boot Tanpa Monitor

Jika Imager sudah mengatur Wi-Fi dan SSH, cukup cari alamat Pi di router atau gunakan:

```bash
ping raspberrypi.local
ssh user@raspberrypi.local
```

Nama `raspberrypi.local` bekerja lewat mDNS bila komputer mendukungnya.

## Pembaruan Pertama

```bash
sudo apt update
sudo apt full-upgrade
sudo reboot
```

Lalu cek suhu dan ruang disk agar tahu kondisi awal sistem.

<div class="note">💡 Matikan daya sebelum mencabut kartu microSD. Kartu yang dicabut saat masih menulis bisa rusak dan sistem gagal boot.</div>
