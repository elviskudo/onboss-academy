MQTT adalah protokol ringan yang dirancang untuk perangkat dengan daya dan bandwidth terbatas. Sangat cocok untuk jaringan sensor berbasis Pi.

## Konsep

| Elemen | Peran |
|---|---|
| Broker | Pusat penyaluran pesan |
| Publisher | Pengirim data |
| Subscriber | Penerima data |
| Topic | Alamat logis pesan |
| Payload | Isi pesan, biasanya JSON |

## Pasang Broker Lokal

```bash
sudo apt install mosquitto mosquitto-clients
mosquitto_sub -t 'sensor/#' -v &
mosquitto_pub -t 'sensor/suhu' -m '27.3'
```

## Python

```python
import paho.mqtt.client as mqtt
import json

client = mqtt.Client()
client.connect('broker.local', 1883, 60)
client.publish('ruang/tamu/suhu', json.dumps({'c': 27.3}), qos=1)
client.loop_start()
```

## Wildcard

```text
ruang/#       -> semua topik di bawah ruang
ruang/+/suhu  -> satu level di antara ruang dan suhu
```

## Last Will

```python
client.will_set('ruang/tamu/status', 'offline', retain=True)
```

Pesan ini dikirim broker saat klien terputus tidak wajar—cara sederhana mendeteksi sensor mati.

<div class="note">💡 Gunakan TLS dan username/password bila broker bisa diakses dari jaringan selain localhost. Topik juga bisa mengandung data sensitif.</div>
