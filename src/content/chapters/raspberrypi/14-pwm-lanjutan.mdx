PWM (Pulse Width Modulation) memberi "tegangan rata-rata" dengan menyalakan dan mematikan pin sangat cepat. Ini dipakai untuk meredupkan LED, menggerakkan servo, dan mengatur kecepatan motor.

## Istilah Utama

| Istilah | Arti |
|---|---|
| Period | Lamanya satu siklus penuh |
| Frequency | 1 / period, dalam Hz |
| Duty cycle | Persentase waktu HIGH dalam satu periode |

## PWMLED

```python
from gpiozero import PWMLED
led = PWMLED(18)
led.value = 0.3      # 30% terang
led.pulse()          # efek napas
```

## Servo

```python
from gpiozero import Servo
s = Servo(17)
s.min()      # sekitar 0 derajat
s.mid()      # sekitar 90 derajat
s.max()      # sekitar 180 derajat
```

Servo biasanya butuh 5 V pada kabel daya dan **GND bersama** dengan Pi. Sinyal kontrol tetap 3,3 V dari GPIO.

## Motor DC

```text
GPIO -> resistor 1k -> basis transistor
motor -> supply eksternal -> kolektor transistor
dioda 1N4007 paralel dengan motor (flyback)
```

Driver seperti L298N atau TB6612 menyederhanakan kontrol arah dan kecepatan.

<div class="note">💡 gpiozero akan membersihkan PWM saat program selesai. Jika pegawai gpio lain masih aktif, jalankan `sudo pigpiod` hanya bila memang memakai pigpio.</div>
