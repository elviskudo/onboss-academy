Python adalah bahasa paling populer untuk proyek Raspberry Pi. Kombinasi gpiozero untuk perangkat dan pustaka standar untuk data sudah cukup untuk banyak kasus.

## Program Event-Driven

```python
from gpiozero import LED, Button
from signal import pause

led = LED(17)
tombol = Button(2)

tombol.when_pressed = led.toggle
pause()
```

Callback dipanggil otomatis saat kondisi berubah—tidak perlu loop terus-menerus mengecek status.

## Program Berbasis Loop

```python
from time import sleep
from datetime import datetime

while True:
    nilai = baca_sensor()
    with open("data.csv", "a") as f:
        f.write(f"{datetime.now().isoformat()},{nilai}\n")
    sleep(2)
```

## Penanganan Error

```python
try:
    suhu = sensor.temperature
except RuntimeError as e:
    print("Gagal baca:", e)
    suhu = None
```

Jangan biarkan satu pembacaan gagal menghentikan seluruh layanan.

## Merapikan Kode

```text
proyek/
├── sensor.py       # pembacaan hardware
├── penyimpan.py    # CSV / database
├── config.py       # pin & konstanta
└── main.py         # orchestrasi
```

<div class="note">💡gpiozero membersihkan resource saat program keluar normal. Pastikan tidak ada proses lama yang masih memegang pin saat menjalankan skrip baru.</div>
