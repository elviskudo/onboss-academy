Data sensor yang hanya ditampilkan sekali tidak banyak gunanya. Menyimpannya memungkinkan grafik, rata-rata, dan analisis tren.

## SQLite

```python
import sqlite3

conn = sqlite3.connect('/home/pi/data/sensor.db')
conn.execute('''
CREATE TABLE IF NOT EXISTS pembacaan (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  waktu TEXT NOT NULL,
  suhu REAL,
  kelembapan REAL
)
''')
conn.execute('INSERT INTO pembacaan (waktu, suhu) VALUES (?, ?)',
             (datetime.now().isoformat(), suhu))
conn.commit()
```

## Query

```python
cur = conn.execute('SELECT waktu, suhu FROM pembacaan ORDER BY waktu DESC LIMIT 10')
for baris in cur:
    print(baris)
```

## InfluxDB

```text
suhu,ruang=tamu nilai=27.3 1768200000000000000
```

Data time series ditulis dengan timestamp, sehingga query rentang waktu menjadi cepat.

## Retensi

Tentukan berapa lama data mentah disimpan. Data lama bisa diagregat menjadi rata-rata per jam sebelum dihapus—menghemat ruang tanpa kehilangan tren.

<div class="note">💡 Simpan database di direktori yang tidak hilang saat image OS ditulis ulang, atau siapkan prosedur backup otomatis.</div>
