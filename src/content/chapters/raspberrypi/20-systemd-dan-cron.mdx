Otomatisasi membuat Pi bekerja tanpa campur tangan. Gunakan **systemd** untuk proses yang terus berjalan dan **cron** untuk tugas berkala.

## Membuat Service

```ini
[Unit]
Description=Pembaca sensor suhu
After=network-online.target

[Service]
Type=simple
WorkingDirectory=/home/pi/proyek
ExecStart=/usr/bin/python3 /home/pi/proyek/sensor.py
Restart=on-failure
RestartSec=5
User=pi

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now sensor.service
sudo systemctl status sensor.service
journalctl -u sensor.service -f
```

## Crontab

```bash
crontab -e
```

```text
*/5 * * * *  /usr/bin/python3 /home/pi/laporan.py >> /home/pi/laporan.log 2>&1
0 6 * * *    /home/pi/backup.sh
@reboot      /home/pi/startup.sh
```

## Lingkungan Variabel

Systemd tidak membaca `.bashrc`. Jika skrip butuh variabel, tetapkan lewat `Environment=` atau `EnvironmentFile=` di unit.

## Log

```bash
journalctl -u sensor.service --since "1 hour ago"
tail -f /home/pi/laporan.log
```

<div class="note">💡 `Restart=always` bisa menciptakan loop jika skrip langsung error. Gunakan `Restart=on-failure` dan pantau log saat pertama kali aktif.</div>
