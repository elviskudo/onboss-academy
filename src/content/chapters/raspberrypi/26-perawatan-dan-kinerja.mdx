Raspberry Pi tidak punya kipas secara default dan sangat sensitif terhadap kualitas daya. Memantau keduanya mencegah perilaku aneh yang sulit didiagnosis.

## Suhu

```bash
vcgencmd measure_temp
# temp=48.2'C
```

Suhu di atas sekitar 80 °C mulai memicu throttling. Pasang heatsink atau kipas untuk beban berkelanjutan.

## Status Throttling

```bash
vcgencmd get_throttled
# throttled=0x0     -> normal
# throttled=0x50000 -> pernah under-voltage
```

Nilai bukan nol menunjukkan riwayat sejak boot terakhir.

## Daya

```text
Pi 3   : 5 V / 2,5 A
Pi 4/5 : 5 V / 3 A (resmi), lebih banyak USB butuh lebih
```

Kabel USB yang tipis menyebabkan penurunan tegangan walaupun adaptornya cukup.

## Ruang Disk

```bash
df -h
sudo apt clean
sudo journalctl --vacuum-size=100M
```

Kartu SD yang hampir penuh bisa membuat sistem lambat dan logging gagal.

## Pembaruan

```bash
sudo apt update && sudo apt full-upgrade
sudo rpi-eeprom-update        # Pi 4/5
sudo reboot
```

<div class="note">💡 Gunakan SSD USB untuk proyek yang banyak menulis (database, logging intensif). Kartu microSD memiliki batas siklus tulis.</div>
