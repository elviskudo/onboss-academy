Layar kecil membuat proyek bisa berdiri sendiri tanpa monitor. Modul LCD 16x2 dan OLED 128x64 adalah dua pilihan yang paling mudah ditemukan.

## LCD 16x2 I2C

```bash
sudo i2cdetect -y 1
# cari 27 atau 3f
```

```python
import lcddriver
lcd = lcddriver.lcd()
lcd.lcd_display_string("Suhu: 27.3C", 1)
lcd.lcd_display_string("Kelembapan: 60%", 2)
```

## OLED SSD1306

```python
from adafruit_ssd1306 import SSD1306_I2C
oled.text("Baris 1", 0, 0)
oled.text("Baris 2", 0, 10)
oled.show()
```

Perubahan tidak langsung terlihat sampai `show()` dipanggil—ini berbeda dengan LCD karakter yang langsung menampilkan.

## Perbandingan

| Aspek | LCD 16x2 | OLED |
|---|---|---|
| Konsumsi | Lampu latar terus menyala | Tiap piksel menyala sendiri |
| Resolusi | 16 karakter × 2 baris | 128 × 64 piksel |
| Kontras | Terbatas | Sangat tajam |
| Harga | Murah | Sedang |

## Praktik Baik

- Batasi pembaruan layar (misal 1 detik sekali) agar tidak berkedip.
- Gunakan string dengan panjang tetap atau tambahkan spasi untuk menimpa karakter lama.
- Jangan biarkan kabel I2C terlalu panjang.

<div class="note">💡 OLED yang dibiarkan menampilkan gambar statis terlalu lama bisa mengalami burn-in. Tambahkan screensaver atau matikan layar saat tidak dipakai.</div>
