## Lapisan Perlindungan

```ruby
class ApplicationController < ActionController::Base
  protect_from_forgery with: :exception

  before_action :set_headers

  private
  def set_headers
    response.set_header("X-Content-Type-Options", "nosniff")
    response.set_header("X-Frame-Options", "SAMEORIGIN")
  end
end
```

| Ancaman | Perlindungan Rails | Catatan |
|---|---|---|
| CSRF | authenticity token | aktif di `ApplicationController` |
| XSS | escaping di ERB | jangan pakai `html_safe` sembarangan |
| SQL injection | placeholder + ORM | hindari interpolasi string SQL |
| Mass assignment | strong parameter | `require(...).permit(...)` |
| Session fixation | reset session saat login | lakukan di controller sesi |

## CSRF

```erb
<%= form_with model: @article do |f| %>
  ...
<% end %>
```

Rails otomatis menyisipkan token tersembunyi. Untuk request API(JSON) dari klien lain, gunakan otentikasi berbasis token daripada cookie.

## XSS dan html_safe

```erb
<%= @article.body %>              <%# aman: di-escape %>
<%= sanitize(@article.body) %>    <%# hanya tag tertentu yang diizinkan %>
```

`sanitize` mengizinkan daftar tag aman. `raw` dan `html_safe` menghapus perlindungan — pakai hanya untuk konten yang sudah kamu bersihkan sendiri.

## SQL Injection

```ruby
# aman
Article.where("title LIKE ?", "%#{params[:q]}%")

# berbahaya
Article.where("title LIKE '%#{params[:q]}%'")
```

Placeholder membuat nilai dikirim terpisah dari perintah SQL.

## Headers dan Secrets

```ruby
config.action_dispatch.default_headers = {
  "X-Frame-Options" => "SAMEORIGIN",
  "X-Content-Type-Options" => "nosniff"
}
```

Simpan API key di Rails credentials (`bin/rails credentials:edit`) atau environment variable, jangan di source code.
