## Dari Rute Tunggal ke Resources

```ruby
Rails.application.routes.draw do
  resources :articles do
    member do
      post :publish
    end
    collection do
      get :archive
    end
  end

  namespace :admin do
    resources :users
  end

  root "home#index"
end
```

Rute sederhana ditulis satu per satu:

```ruby
get "/tentang", to: "home#about"
```

Untuk data CRUD, Rails menyediakan `resources` yang membuat tujuh rute sekaligus. Tabel di bawah memetakan aksi ke verb dan URL.

| Aksi | Verb | Path | Fungsi |
|---|---|---|---|
| index | GET | `/articles` | daftar semua |
| show | GET | `/articles/:id` | satu artikel |
| new | GET | `/articles/new` | form baru |
| create | POST | `/articles` | simpan artikel |
| edit | GET | `/articles/:id/edit` | form ubah |
| update | PATCH | `/articles/:id` | simpan perubahan |
| destroy | DELETE | `/articles/:id` | hapus |

## Member dan Collection

Terkadang aksi CRUD standar tidak cukup.

```ruby
resources :articles do
  member { post :publish }     # /articles/1/publish
  collection { get :archive }  # /articles/archive
end
```

**Member** menyertakan `:id` karena bekerja pada satu baris. **Collection** tidak memakai `:id` karena bekerja pada kumpulan data.

## Namespace dan Scope

```ruby
namespace :admin do
  resources :users
end
```

Rute di atas menghasilkan `/admin/users` dan mengarah ke `Admin::UsersController`. Controller sebaiknya ditempatkan di `app/controllers/admin/users_controller.rb`.

## Root dan Helper

`root "home#index"` mendefinisikan halaman depan `/`. Rails juga membuat helper seperti `articles_path`, `article_path(@article)`, dan `new_article_path`.

```erb
<%= link_to "Daftar", articles_path %>
<%= link_to "Baca", article_path(@article) %>
```

<div class="note">💡 Jalankan <code>bin/rails routes</code> setelah mengubah config/routes.rb. Urutan rute penting — rute yang lebih atas akan dicocokkan lebih dulu, jadi taruh rute khusus sebelum rute generik.</div>
