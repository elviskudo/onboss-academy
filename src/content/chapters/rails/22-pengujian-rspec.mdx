## Instalasi

```ruby
RSpec.describe Article, type: :model do
  it "menolak judul kosong" do
    article = build(:article, title: nil)
    expect(article).not_to be_valid
  end
end

RSpec.describe "Articles", type: :request do
  it "menampilkan daftar artikel" do
    get "/articles"
    expect(response).to have_http_status(:ok)
  end
end
```

```ruby
group :development, :test do
  gem "rspec-rails"
  gem "factory_bot_rails"
end
```

```bash
bundle install
bin/rails generate rspec:install
```

## Struktur Spec

| Folder | Yang diuji |
|---|---|
| `spec/models` | validasi, asosiasi, method model |
| `spec/requests` | endpoint dan respons HTTP |
| `spec/system` | interaksi browser (Capybara) |
| `spec/jobs` | pekerjaan background |
| `spec/factories` | data uji |

## FactoryBot

```ruby
FactoryBot.define do
  factory :article do
    title { "Judul contoh" }
    body { "Isi artikel" }
    association :author
  end
end
```

`build` membuat objek di memori, `create` menyimpannya ke database. Gunakan `build` bila tidak memerlukan ID.

## Expectation

```ruby
expect(article).to be_valid
expect(response).to have_http_status(:ok)
expect { Article.create!(...) }.to change(Article, :count).by(1)
```

`change` sangat berguna untuk memastikan efek samping benar-benar terjadi.

## System Spec

```ruby
it "bisa membuat artikel" do
  visit "/articles/new"
  fill_in "Title", with: "Belajar RSpec"
  click_button "Simpan"
  expect(page).to have_content("Belajar RSpec")
end
```

<div class="note">💡 Test yang baik menguji perilaku, bukan implementasi. Uji "artikel tidak tersimpan saat judul kosong", bukan "validator presence dipanggil".</div>
