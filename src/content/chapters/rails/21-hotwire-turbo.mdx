## Tiga Pilar Hotwire

```ruby
<%= turbo_frame_tag "keranjang" do %>
  <%= render "keranjang/isi" %>
<% end %>

# controller
respond_to do |format|
  format.turbo_stream { render turbo_stream: turbo_stream.replace("keranjang", partial: "keranjang/isi") }
  format.html { redirect_to cart_path }
end
```

| Teknologi | Fungsi | Analogi |
|---|---|---|
| Turbo Drive | navigasi cepat tanpa full reload | mengganti isi halaman |
| Turbo Frames | memperbarui bagian tertentu | mengganti satu kotak saja |
| Turbo Streams | mengirim perubahan dari server | mengirim perintah update |

## Turbo Drive

Secara bawaan Turbo Drive aktif pada aplikasi Rails modern. Klik link menyebabkan request fetch, lalu `<body>` diganti. Layout dan koneksi WebSocket tetap hidup.

```erb
<%= link_to "Artikel", article_path(@article), data: { turbo: false } %>
```

Gunakan `turbo: false` bila halaman perlu reload penuh, misalnya saat integrasi dengan library pihak ketiga.

## Turbo Frame

```erb
<%= turbo_frame_tag "produk_#{@product.id}" do %>
  <%= @product.name %>
<% end %>
```

Link di dalam frame akan memuat responsnya ke frame itu saja selama respons mengandung frame dengan id yang sama.

## Turbo Stream

```ruby
turbo_stream.append("daftar", partial: "items/item", locals: { item: @item })
turbo_stream.remove("item_#{@item.id}")
```

Aksi umum: `append`, `prepend`, `replace`, `update`, dan `remove`.

## Stimulus

```javascript
// app/javascript/controllers/halo_controller.js
export default class extends Controller {
  sapa() { alert("Halo dari Stimulus"); }
}
```

```html
<div data-controller="halo">
  <button data-action="click->halo#sapa">Klik</button>
</div>
```

<div class="note">💡 Hotwire bekerja paling baik bila server tetap menghasilkan HTML. Kamu mendapat interaksi modern tanpa menulis ulang seluruh aplikasi sebagai SPA.</div>
