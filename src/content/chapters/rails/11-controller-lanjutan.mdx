## Alur Satu Aksi

```ruby
class ArticlesController < ApplicationController
  before_action :set_article, only: [:show, :edit, :update, :destroy]

  def create
    @article = Article.new(article_params)
    if @article.save
      redirect_to @article, status: :see_other
    else
      render :new, status: :unprocessable_entity
    end
  end

  private
  def set_article
    @article = Article.find(params[:id])
  end

  def article_params
    params.require(:article).permit(:title, :body)
  end
end
```

Controller menerima request, mengambil data lewat model, lalu memilih respons.

```ruby
def show
  @article = Article.find(params[:id])
end
```

Secara bawaan Rails mencari view `app/views/articles/show.html.erb` dan meneruskan variabel instance `@article` ke sana.

## Parameter dan Strong Parameter

`params` berisi data request. Jangan pernah menyimpan seluruh `params` langsung ke model:

```ruby
params.require(:article).permit(:title, :body)
```

`require` memastikan kunci `article` ada; `permit` hanya mengizinkan dua kolom itu. Kolom seperti `user_id` atau `admin` tidak bisa disisipkan lewat form palsu.

## Render versus Redirect

| Metode | Status | URL browser | Kapan dipakai |
|---|---|---|---|
| `render :new` | 200 (atau 422) | tetap `/articles/new` | validasi gagal, form harus menampilkan error |
| `redirect_to @article` | 302/303 | berubah ke `/articles/1` | setelah aksi berhasil |

Gunakan `status: :see_other` (303) setelah create/update agar refresh tidak mengirim ulang POST/PATCH.

## Filter Aksi

```ruby
before_action :authenticate!
after_action :log_activity, only: :create
```

Filter menghindari pengulangan kode. Simpan method filter di bagian `private` supaya tidak dianggap sebagai aksi yang bisa dipanggil lewat URL.

## Respons Non-HTML

```ruby
respond_to do |format|
  format.html
  format.json { render json: @article }
end
```

<div class="note">💡 Variabel instance (`@nama`) otomatis tersedia di view, sedangkan variabel lokal biasa tidak. Itu sebabnya controller memakai <code>@article</code>, bukan <code>article</code>.</div>
