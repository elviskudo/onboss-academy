## Relasi Satu ke Banyak

```ruby
class Author < ApplicationRecord
  has_many :articles, dependent: :destroy
  has_many :categories, through: :articles
end

class Article < ApplicationRecord
  belongs_to :author
  has_many :comments, as: :commentable, dependent: :destroy
  has_many :article_categories
  has_many :categories, through: :article_categories
end
```

```ruby
class Author < ApplicationRecord
  has_many :articles, dependent: :destroy
end

class Article < ApplicationRecord
  belongs_to :author
end
```

Rails mengharapkan kolom `author_id` di tabel `articles`. Opsi `dependent: :destroy` menjaga agar tidak ada artikel yatim saat penulis dihapus.

## Many-to-Many dengan Model Penghubung

```ruby
class Article < ApplicationRecord
  has_many :article_categories
  has_many :categories, through: :article_categories
end
```

`article_categories` adalah model penghubung berisi `article_id` dan `category_id`. Lewat `through`, kamu bisa memanggil `article.categories` seolah relasi langsung.

| Asosiasi | Arah | Contoh |
|---|---|---|
| `belongs_to` | child → parent | `article.author` |
| `has_many` | parent → banyak child | `author.articles` |
| `has_one` | parent → satu child | `user.profile` |
| `has_many :through` | lewat model penghubung | `article.categories` |
| `has_many :as` | polymorphic | `comment.commentable` |

## Polymorphic

```ruby
class Comment < ApplicationRecord
  belongs_to :commentable, polymorphic: true
end
```

Tabel `comments` butuh dua kolom: `commentable_id` dan `commentable_type`. Kolom type menyimpan nama kelas seperti `"Article"` atau `"Video"`.

## Inverse dan Autosave

```ruby
has_many :articles, inverse_of: :author
```

Dengan `inverse_of`, `author.articles.build` langsung mengenali `author`-nya tanpa queries tambahan. Sementara `autosave: true` menyimpan record terkait otomatis saat induk disimpan.

<div class="note">💡 Pilih <code>dependent: :restrict_with_error</code> bila data child tidak boleh dihapus sembarangan — Rails akan menolak penghapusan induk dan memberi error yang ramah pengguna.</div>
