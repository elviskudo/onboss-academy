## Membuat Mailer

```ruby
class UserMailer < ApplicationMailer
  default from: "no-reply@onboss.test"

  def welcome(user)
    @user = user
    mail(to: @user.email, subject: "Selamat datang!")
  end
end

# pemanggilan
UserMailer.welcome(user).deliver_later
```

```bash
bin/rails generate mailer UserMailer welcome
```

Generator membuat kelas mailer dan dua template (HTML serta plain text).

```ruby
class UserMailer < ApplicationMailer
  def welcome(user)
    @user = user
    mail(to: user.email, subject: "Selamat datang!")
  end
end
```

Variabel instance `@user` dapat dipakai di template seperti di view biasa.

## Segera atau Antre

| Metode | Eksekusi | Risiko |
|---|---|---|
| `deliver_now` | langsung | request menunggu koneksi SMTP |
| `deliver_later` | lewat Active Job | butuh worker berjalan di produksi |

Email reset password, invoice, dan notifikasi sebaiknya memakai `deliver_later` agar pengguna tidak menunggu.

## Template dan Layout

```erb
<!-- app/views/user_mailer/welcome.html.erb -->
<h1>Halo <%= @user.nama %></h1>
<p>Terima kasih sudah bergabung.</p>
```

Layout email berada di `app/views/layouts/mailer.html.erb`. Berbeda dari layout web, email sebaiknya memakai tabel dan CSS inline agar kompatibel dengan klien email.

## Konfigurasi development

```ruby
config.action_mailer.delivery_method = :smtp
config.action_mailer.default_url_options = { host: "localhost", port: 3000 }
```

Di development, `letter_opener` bisa membuka email di browser daripada benar-benar mengirimkannya.

<div class="note">💡 Jangan menyimpan kredensial SMTP di source code. Rails credentials atau environment variable menjaga rahasia tetap keluar dari repository.</div>
