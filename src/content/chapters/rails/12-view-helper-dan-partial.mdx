## ERB dalam Singkat

```ruby
# app/views/articles/show.html.erb
<%= render "card", article: @article %>

# app/views/articles/_card.html.erb
<article class="card">
  <h2><%= link_to article.title, article %></h2>
  <p><%= truncate(article.body, length: 120) %></p>
</article>
```

ERB menyisipkan Ruby ke dalam HTML. Ada tiga bentuk penanda:

| Penanda | Fungsi | Contoh |
|---|---|---|
| `&lt;% ... %>` | menjalankan kode tanpa mencetak | `&lt;% if user %> ... &lt;% end %>` |
| `&lt;%= ... %>` | menjalankan lalu mencetak | `&lt;%= @article.title %>` |
| `&lt;%# ... %>` | komentar, tidak dieksekusi | `&lt;%# catatan %> |)`

## Partial

Partial adalah potongan view yang bisa dipakai ulang. Nama file diawali `_`:

```erb
<%= render "card", article: @article %>
<%= render partial: "card", collection: @articles, as: :article %>
```

Bentuk kedua merender partial sekali per elemen koleksi — Rails otomatis memilih variabel `article` berkat opsi `as:`.

## Layout

`app/views/layouts/application.html.erb` membungkus semua halaman:

```erb
<body>
  <%= render "shared/navbar" %>
  <main><%= yield %></main>
</body>
```

`yield` diganti dengan isi view yang sedang diminta. Layout lain bisa dipilih lewat `layout "admin"`.

## Helper

```ruby
module ApplicationHelper
  def tanggal_indonesia(tanggal)
    tanggal.strftime("%d %B %Y")
  end
end
```

Lalu di view: `&lt;%= tanggal_indonesia(@article.created_at) %>`. Helper menjaga template tetap mudah dibaca.

<div class="note">💡 ERB otomatis meng-escape output, jadi <code>&lt;script&gt;</code> dari input user tampil sebagai teks, bukan dieksekusi. Jangan memakai <code>html_safe</code> kecuali kamu benar-benar yakin sumbernya aman.</div>
