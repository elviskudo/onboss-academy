## Dua Cara Membuat

Koleksi bisa dibuat **implisit** atau **eksplisit**.

```javascript
// implisit: koleksi muncul saat dokumen pertama masuk
db.kategori.insertOne({ nama: "Elektronik" })

// eksplisit: dibuat lebih dulu
db.createCollection("log_aktifitas")
```

Pembuatan eksplisit berguna kalau kamu ingin mengatur opsi khusus atau ingin koleksi kosong tetap terdaftar.

## Opsi Koleksi

| Opsi | Fungsi |
| --- | --- |
| `capped` | ukuran tetap, menimpa data terlama |
| `size` | batas ukuran dalam byte |
| `max` | batas jumlah dokumen |
| `validator` | aturan schema validation |
| `collation` | aturan perbandingan teks (locale, case) |

```javascript
db.createCollection("antrian", {
  capped: true,
  size: 1048576,
  max: 500
})
```

Capped collection cocok untuk log pendek, bukan untuk data yang harus diarsipkan permanen.

## Mengelola Koleksi

```javascript
db.getCollectionNames()
db.log_aktifitas.renameCollection("log_activity")
db.log_activity.drop()
```

`drop()` langsung menghilangkan semua dokumen dan indeks. Tidak ada konfirmasi tambahan.

<div class="note">💡 Sebelum mengganti nama koleksi di produksi, perbarui juga kode aplikasi dan indeks yang bergantung pada nama lama. Rename koleksi tidak otomatis memperbaiki referensi di aplikasi.</div>
