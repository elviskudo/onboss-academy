## Anatomi Pemanggilan

Hampir semua kode MongoDB mengikuti pola:

```javascript
db.nama_koleksi.metode(filter, opsi)
```

- `db` → database yang sedang aktif.
- `nama_koleksi` → wadah dokumen.
- `metode` → `find`, `insertOne`, `updateMany`, dan sebagainya.
- `filter` → syarat pencarian, berupa objek.
- `opsi` → pengaturan tambahan seperti proyeksi atau urutan.

## Filter Kosong

```javascript
db.produk.find()
db.produk.find({})
```

Keduanya mengembalikan seluruh dokumen. Koleksi besar sebaiknya dibatasi dengan `limit()` saat eksplorasi agar tidak membanjiri layar.

## find versus findOne

| Metode | Hasil | Kapan dipakai |
| --- | --- | --- |
| `find()` | kursor (bisa di-`limit`, `sort`) | daftar, laporan |
| `findOne()` | satu objek atau `null` | cek keberadaan / ambil satu |

```javascript
db.produk.findOne({ kode: "KB-01" })
```

## Proyeksi

Proyeksi memilih field yang ditampilkan. Nilai `1` berarti tampil, `0` berarti disembunyikan.

```javascript
db.produk.find({}, { nama: 1, harga: 1, _id: 0 })
```

Kecuali `_id`, kamu tidak boleh mencampur `1` dan `0` dalam satu proyeksi.

## Rantai Metode

```javascript
db.produk.find({ stok: { $gt: 0 } })
         .sort({ harga: -1 })
         .limit(5)
```

Urutan rantai penting: filter dulu, lalu sort, lalu limit. Kursor bersifat malas — perintah benar-benar dieksekusi saat hasil diiterate.

<div class="note">💡 `db.koleksi.find()` mengembalikan kursor, bukan array. Di mongosh kursor langsung ditampilkan, tetapi di driver Node.js kamu perlu `await cursor.toArray()` atau loop `for await`.</div>
