## deleteOne dan deleteMany

```javascript
db.siswa.deleteOne({ nama: "Budi" })
db.siswa.deleteMany({ aktif: false })
```

Selalu sertakan filter yang spesifik. `deleteMany({})` akan mengosongkan seluruh koleksi.

## Mengambil Dokumen yang Dihapus

```javascript
const dok = db.siswa.findOneAndDelete({ nim: "2026001" })
printjson(dok)
```

`findOneAndDelete` berguna kalau aplikasi perlu menampilkan data yang baru dihapus, misalnya dalam notifikasi "Anda menghapus pesanan #123".

## Hitungan Hasil

```javascript
const hasil = db.siswa.deleteMany({ kelas: "Lulus" })
print(hasil.deletedCount)
```

| Hasil | Arti |
| --- | --- |
| `acknowledged` | server menerima permintaan |
| `deletedCount` | jumlah dokumen terhapus |

## Hati-hati dengan drop

```javascript
db.siswa.deleteMany({})   // koleksi tetap ada, indeks tetap ada
db.siswa.drop()           // koleksi dan indeks hilang
```

Setelah `drop()`, aplikasi yang masih memanggil `db.siswa.find()` akan membuat ulang koleksi secara implisit saat ada `insert`, tetapi indeks lama tidak kembali.

<div class="note">💡 Di produksi, pertimbangkan **soft delete**: tambahkan field `deletedAt` dan `updateOne` daripada benar-benar menghapus. Data tetap tersedia untuk audit dan bisa dipulihkan.</div>
