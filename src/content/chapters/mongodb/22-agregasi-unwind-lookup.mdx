## $unwind

```javascript
db.siswa.insertOne({ nama: "Ana", hobi: ["membaca", "lari"] })

db.siswa.aggregate([{ $unwind: "$hobi" }])
// -> {nama: "Ana", hobi: "membaca"}
// -> {nama: "Ana", hobi: "lari"}
```

Satu dokumen dengan array dua elemen berubah menjadi dua dokumen. Field lain ikut tersalin.

```javascript
{ $unwind: { path: "$hobi", preserveNullAndEmptyArrays: true } }
```

Opsi ini menyimpan dokumen yang array-nya kosong atau tidak ada.

## $lookup

```javascript
db.pesanan.aggregate([
  {
    $lookup: {
      from: "produk",
      localField: "kode_produk",
      foreignField: "kode",
      as: "produk"
    }
  }
])
```

Artinya: untuk setiap pesanan, ambil dokumen dari koleksi `produk` yang `kode`-nya sama dengan `kode_produk` pesanan. Hasilnya menjadi array `produk`.

## Merapikan Hasil Join

```javascript
{ $unwind: { path: "$produk", preserveNullAndEmptyArrays: true } }
{ $project: { kode: 1, nama: "$produk.nama", _id: 0 } }
```

Tanpa `$unwind`, field hasil join tetap berupa array sehingga sulit diolah lebih lanjut.

## Pertimbangan Performa

- Beri indeks pada `foreignField` di koleksi tujuan.
- `$match` sebelum `$lookup` agar hanya sebagian dokumen yang di-join.
- `$lookup` dari koleksi besar ke koleksi besar bisa mahal; denormalisasi sering lebih cepat di MongoDB.

<div class="note">💡 `$lookup` versi terbaru juga mendukung `let` dan Pipeline Lookup dengan `pipeline` untuk join bersyarat, misalnya hanya mengambil produk yang harganya di atas batas tertentu.</div>
