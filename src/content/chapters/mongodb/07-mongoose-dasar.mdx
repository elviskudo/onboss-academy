MongoDB menerima dokumen apa pun. **Mongoose** menambahkan disiplin di sisi aplikasi Node.js: skema, validasi, tipe, dan relasi — dengan API JavaScript yang nyaman.

## Apa itu Mongoose?

Mongoose adalah ODM (*Object Document Mapper*) yang memetakan objek JavaScript ke dokumen MongoDB. Empat komponen dasarnya:

| Komponen | Fungsi | Contoh | Kapan dipakai |
| --- | --- | --- | --- |
| Connection | membuka pool koneksi | `mongoose.connect(uri)` | startup aplikasi |
| Schema | mendefinisikan tipe/aturan | `new Schema({...})` | kontrak data |
| Model | API collection | `mongoose.model(...)` | query CRUD |
| Document | instance satu data | `new Produk(...)` | validasi/save instance |

Schema Mongoose hanya menegakkan aturan pada operasi yang melewati Mongoose. Tulis langsung melalui mongosh atau driver asli tidak otomatis divalidasi; gunakan MongoDB schema validation jika aturan harus berlaku untuk semua klien.

## Koneksi dan Skema

```javascript
const mongoose = require("mongoose");

await mongoose.connect("mongodb://127.0.0.1:27017/toko");

const produkSchema = new mongoose.Schema({
  nama: { type: String, required: true, trim: true },
  harga: { type: Number, required: true, min: 0 },
  stok: { type: Number, default: 0 },
  tags: [String],
  dibuatPada: { type: Date, default: Date.now }
});
```

Setiap field dideklarasikan dengan tipe dan aturan: `required`, `min/max`, `enum`, `trim`, `default` — pelanggaran akan menghasilkan error validasi, bukan data kotor.

## Model dan CRUD

```javascript
const Produk = mongoose.model("Produk", produkSchema);

const baru = await Produk.create({ nama: "Mouse", harga: 150000, stok: 25 });

await Produk.findByIdAndUpdate(id, { $inc: { stok: -1 } }, { new: true });

await Produk.deleteOne({ nama: "Mouse" });
```

Nama model "Produk" otomatis dipetakan ke koleksi `produk`. Method create/find/update/delete tersedia langsung dari model tanpa menulis sintaks MongoDB mentah.

## Query dan Casting

```javascript
await Produk.find({ harga: { $gt: 100000 } }).sort({ harga: 1 }).limit(10);
await Produk.findOne({ nama: "Keyboard" });
await Produk.findById("6512ab34cd77aa0012345678");
```

Mongoose melakukan **casting** otomatis: string yang cocok dengan skema Number otomatis dikonversi, string yang diharapkan Date diparse — mengurangi bug tipe di aplikasi.

## Validasi Error

```javascript
try {
  await Produk.create({ nama: "", harga: -5 });
} catch (err) {
  if (err.name === "ValidationError") {
    console.log(err.errors.nama.message);
    console.log(err.errors.harga.message);
  }
}
```

Error validasi Mongoose terstruktur per field — tinggal dipetakan ke form pengguna tanpa membocorkan stack trace atau detail koneksi.

## Enam Validator Inti

| Validator/opsi | Fungsi | Contoh |
| --- | --- | --- |
| `required` | field wajib ada | nama produk |
| `min` / `max` | batas angka/tanggal | harga ≥ 0 |
| `minLength` / `maxLength` | batas panjang teks | nama 2–100 karakter |
| `enum` | nilai dari daftar | status BARU/LUNAS |
| `match` | pola regex | format kode |
| custom `validate` | aturan sendiri | tanggal akhir > awal |

Validator update tidak selalu berjalan secara default; aktifkan `{ runValidators: true }` pada operasi update bila aturan schema harus diterapkan.

## Di Dunia Nyata

- **Form produk** — required, min, dan enum menolak payload invalid sebelum mencapai database.
- **Endpoint daftar** — query chaining `find().sort().limit()` membentuk filter API yang singkat.
- **Pembuatan akun** — model `create()` menjalankan casting dan validation sebelum menyimpan dokumen.
- **Pengurangan stok** — operator `$inc` tetap atomik, dengan filter stok untuk mencegah nilai negatif.
- **Respons API baca-saja** — `.lean()` mengembalikan objek JavaScript biasa dan mengurangi overhead dokumen Mongoose untuk daftar besar.

<div class="note">💡 Gunakan mode `strict` bawaan agar field di luar schema dibuang. Jika perlu fleksibilitas, letakkan atribut dinamis di satu field `Mixed`/Map yang jelas, bukan mematikan kontrak seluruh dokumen.</div>
