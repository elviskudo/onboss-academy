## $project

```javascript
db.produk.aggregate([
  { $project: { nama: 1, harga: 1, _id: 0 } }
])
```

Sama seperti proyeksi di `find()`. Selain memilih field, `$project` bisa membuat field baru dengan ekspresi.

## Field Turunan

| Ekspresi | Fungsi |
| --- | --- |
| `$add` | penjumlahan |
| `$subtract` | pengurangan |
| `$multiply` | perkalian |
| `$divide` | pembagian |
| `$concat` | menggabungkan string |
| `$toUpper` | huruf kapital |
| `$cond` | if-else |

```javascript
{
  $project: {
    nama: 1,
    total: { $multiply: ["$harga", "$jumlah"] },
    label: { $cond: [{ $gt: ["$stok", 0] }, "Tersedia", "Habis"] }
  }
}
```

## $sort dan $limit

```javascript
db.produk.aggregate([
  { $sort: { kategori: 1, harga: -1 } },
  { $limit: 10 }
])
```

Sort maju-kiri ke kanan. Kamu bisa mengurutkan field hasil `$project` karena tahap dijalankan berurutan.

## $skip

```javascript
db.produk.aggregate([
  { $sort: { _id: 1 } },
  { $skip: 20 },
  { $limit: 10 }
])
```

Kombinasi ini setara dengan halaman ketiga berisi 10 data. Tetap siapkan sort yang stabil.

<div class="note">💡 Mulai MongoDB 4.2 ada tahap `$set` sebagai alternatif `$project` ketika kamu hanya ingin menambah/mengubah field tanpa menyembunyikan yang lain.</div>
