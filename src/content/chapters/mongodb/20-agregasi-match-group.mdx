## $match Lebih Awal Lebih Baik

```javascript
db.penjualan.aggregate([
  { $match: { tahun: 2026, status: "lunas" } },
  { $group: { _id: "$kategori", omzet: { $sum: "$jumlah" } } }
])
```

`$match` di awal memakai indeks dan mengurangi jumlah dokumen yang masuk ke `$group`. Kalau diletakkan setelah `$group`, server sudah menghitung data yang akhirnya dibuang.

## Grup berdasarkan Beberapa Field

```javascript
{
  $group: {
    _id: { kategori: "$kategori", bulan: "$bulan" },
    omzet: { $sum: "$jumlah" }
  }
}
```

Hasilnya berupa dokumen dengan `_id` berupa objek. Aksesnya memakai `_id.kategori` dan `_id.bulan`.

## Akumulator Kumpulan

| Akumulator | Hasil |
| --- | --- |
| `$push` | array semua nilai |
| `$addToSet` | array nilai unik |
| `$first` | nilai pertama dalam grup |
| `$last` | nilai terakhir dalam grup |
| `$stdDevPop` | simpangan baku populasi |

```javascript
{
  $group: {
    _id: "$kategori",
    daftarProduk: { $addToSet: "$nama" },
    semuaTransaksi: { $push: "$kode" }
  }
}
```

Hati-hati: `$push` pada koleksi jutaan dokumen bisa menghasilkan dokumen yang melebihi batas ukuran 16 MB.

## Grup Semua Data

```javascript
db.penjualan.aggregate([
  { $group: { _id: null, total: { $sum: "$jumlah" }, n: { $sum: 1 } } }
])
```

Ini setara dengan `SELECT SUM(jumlah), COUNT(*) FROM penjualan` dalam SQL.

<div class="note">💡 Urutan dokumen di dalam `$group` tidak dijamin. Kalau memakai `$first` atau `$last`, lakukan `$sort` sebelum `$group` agar hasilnya deterministik.</div>
