## Konsep Pipeline

Agregasi adalah **sumber data →若干 tahap → hasil**. Setiap tahap mengubah bentuk dokumen lalu meneruskannya ke tahap berikutnya.

```javascript
db.penjualan.aggregate([
  { $match: { status: "lunas" } },
  { $group: { _id: "$kategori", total: { $sum: "$jumlah" } } },
  { $sort: { total: -1 } }
])
```

Dalam `$group`, tanda `$` di depan `kategori` berarti "nilai dari field kategori".

## Tahap Umum

| Tahap | Fungsi |
| --- | --- |
| `$match` | menyaring dokumen |
| `$project` | memilih/membentuk ulang field |
| `$group` | mengelompokkan + akumulasi |
| `$sort` | mengurutkan |
| `$limit` | membatasi jumlah dokumen |
| `$skip` | melewati sejumlah dokumen |
| `$count` | menghitung dokumen menjadi satu baris |
| `$unwind` | meratakan array |
| `$lookup` | join ke koleksi lain |
| `$out` | menulis hasil ke koleksi |

## Akumulator

```javascript
{
  $group: {
    _id: "$divisi",
    totalGaji: { $sum: "$gaji" },
    rataGaji: { $avg: "$gaji" },
    tertinggi: { $max: "$gaji" },
    terendah: { $min: "$gaji" },
    jumlahOrang: { $sum: 1 }
  }
}
```

`$sum: 1` berarti "tambah satu untuk setiap dokumen dalam grup".

## $out dan $merge

```javascript
db.penjualan.aggregate([
  { $group: { _id: "$kategori", total: { $sum: "$jumlah" } } },
  { $out: "ringkasan_kategori" }
])
```

`$out` mengganti isi koleksi tujuan. `$merge` lebih fleksibel: bisa menggabungkan hasil ke koleksi yang sudah ada berdasarkan kunci.

<div class="note">💡 Letakkan `$match` sedekat mungkin dengan awal pipeline agar indeks bisa dipakai dan dokumen yang tidak perlu tidak ikut diproses tahap berikutnya.</div>
