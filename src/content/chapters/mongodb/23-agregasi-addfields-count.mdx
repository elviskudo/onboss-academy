## $addFields

```javascript
db.produk.aggregate([
  { $addFields: {
      hargaSetelahDiskon: { $multiply: ["$harga", 0.9] },
      statusStok: { $cond: [{ $gt: ["$stok", 0] }, "ada", "habis"] }
  } }
])
```

Field lama tetap ada. Untuk mengganti nama field tanpa kehilangan yang lain, gabungkan `$addFields` dengan `$project`.

## $count

```javascript
db.penjualan.aggregate([
  { $match: { status: "lunas" } },
  { $count: "jumlahLunas" }
])
```

Hasilnya tepat satu dokumen: `{ jumlahLunas: 42 }`. Kalau tidak ada yang cocok, hasilnya array kosong.

## $sample

```javascript
db.produk.aggregate([{ $sample: { size: 3 } }])
```

Berguna untuk mengambil contoh data saat eksplorasi. Pada koleksi besar, MongoDB memakai sampling acak yang efisien.

## $replaceRoot

```javascript
db.pesanan.aggregate([
  { $lookup: { from: "produk", localField: "kode", foreignField: "kode", as: "p" } },
  { $unwind: "$p" },
  { $replaceRoot: { newRoot: "$p" } }
])
```

Dokumen hasil kini berisi field produk langsung di root, bukan bersarang di `p`.

## Menyusun Tahap

| Tujuan | Pola |
| --- | --- |
| Ringkas data | `$match → $group → $sort` |
| Top-N | `$match → $sort → $limit` |
| Join | `$match → $lookup → $unwind → $project` |
| Hitung baris | `$match → $count` |

<div class="note">💡 Tahap dijalankan berurutan. Memindahkan `$limit` ke depan `$match` bisa menghasilkan jawaban yang salah karena yang dibatasi bukan data yang sudah difilter.</div>
