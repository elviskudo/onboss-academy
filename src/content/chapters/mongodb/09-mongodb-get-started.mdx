## Server dan Klien

MongoDB bekerja seperti kebanyakan database: ada **server** yang menyimpan data dan **klien** yang mengirim perintah. Server disebut `mongod`; klien baris perintah resminya `mongosh`.

```bash
mongod --dbpath /data/db --port 27017
mongosh "mongodb://127.0.0.1:27017"
```

Port `27017` adalah port bawaan. Kalau memakai MongoDB Atlas, alamatnya berupa URI `mongodb+srv://...` dan kamu tidak perlu menjalankan `mongod` sendiri.

## Perintah Pertama di Shell

```javascript
db              // database aktif
show dbs        // daftar database
use sekolah     // pindah / membuat konteks database
show collections
```

`use sekolah` tidak langsung membuat database di disk. MongoDB baru menuliskan database saat kamu menyimpan dokumen pertama.

```javascript
use sekolah
db.siswa.insertOne({ nama: "Ana", nilai: 88 })
show dbs
```

## Prompt dan Bantuan

| Perintah | Fungsi |
| --- | --- |
| `help` | daftar perintah shell |
| `db.help()` | bantuan metode database |
| `db.siswa.help()` | bantuan metode koleksi |
| `exit()` | keluar dari shell |

Hasil `find()` di mongosh sudah dibatasi jumlah barisnya. Tambahkan `.pretty()` bila ingin tampilan yang lebih mudah dibaca.

<div class="note">💡 `show collections` hanya menampilkan koleksi yang sudah punya dokumen atau indeks. Koleksi kosong hasil `createCollection()` tetap muncul, tetapi koleksi yang belum dibuat sama sekali tidak akan terlihat.</div>
