## Dua Jalur Akses

Aplikasi modern biasanya memakai salah satu dari dua jalur:

| Jalur | Kelebihan | Catatan |
| --- | --- | --- |
| Driver resmi | performa tinggi, fitur lengkap | perlu package per bahasa |
| Data API (HTTPS) | tanpa driver, cocok serverless | batas ukuran request/response |

## Connection URI

```text
mongodb://127.0.0.1:27017
mongodb+srv://user:sandi@cluster.xxxxx.mongodb.net/?retryWrites=true
```

URI memuat host, port, kredensial, opsi replica set, dan parameter TLS. Jangan menaruh kata sandi asli di repositori — gunakan variabel lingkungan.

## Contoh Node.js

```javascript
import { MongoClient } from "mongodb";

const client = new MongoClient(process.env.MONGO_URI);
await client.connect();

const koleksi = client.db("sekolah").collection("siswa");
await koleksi.insertOne({ nama: "Ana", nilai: 88 });
const hasil = await koleksi.find({ nilai: { $gte: 80 } }).toArray();
console.log(hasil);

await client.close();
```

Buat satu `MongoClient` untuk seluruh aplikasi, bukan satu per permintaan. Driver mengelola connection pool secara internal.

## Data API

```bash
curl -X POST "https://data-api.mongodb.net/data/action/find"   -H "Content-Type: application/json"   -H "Access-Control-Request-Headers: *"   -H "api-key: KUNCI"   -d '{"dataSource":"Cluster0","database":"sekolah","collection":"siswa","filter":{}}'
```

Data API cocok untuk lingkungan yang tidak bisa membuka koneksi TCP panjang, misalnya fungsi serverless atau aplikasi browser yang dipercaya.

<div class="note">💡 Jangan pernah menaruh kunci Data API di JavaScript sisi klien yang bisa dilihat siapa pun. Kunci itu setara dengan kata sandi database.</div>
