## Operator Perbandingan

| Operator | Makna | Contoh |
| --- | --- | --- |
| `$eq` | sama dengan | `{harga: {$eq: 100}}` |
| `$ne` | tidak sama | `{status: {$ne: "lunas"}}` |
| `$gt` | lebih besar | `{nilai: {$gt: 80}}` |
| `$gte` | lebih besar atau sama | `{nilai: {$gte: 80}}` |
| `$lt` | lebih kecil | `{stok: {$lt: 5}}` |
| `$lte` | lebih kecil atau sama | `{stok: {$lte: 5}}` |

Bentuk `{nilai: 80}` adalah singkatan dari `{nilai: {$eq: 80}}`.

## Logika

```javascript
db.produk.find({ $and: [{ stok: { $gt: 0 } }, { aktif: true }] })
db.produk.find({ $or: [{ stok: 0 }, { aktif: false }] })
db.produk.find({ $nor: [{ harga: { $gt: 1000000 } }, { stok: 0 }] })
```

`$and` sering bisa disingkat dengan beberapa field sekaligus. `$or` wajib berupa array ekspresi.

## Keanggotaan

```javascript
db.produk.find({ kategori: { $in: ["Elektronik", "Furniture"] } })
db.produk.find({ kategori: { $nin: ["Makanan"] } })
```

Kalau field berupa array, `$in` mencocokkan salah satu elemennya.

## Keberadaan dan Tipe

```javascript
db.produk.find({ berat: { $exists: true } })
db.produk.find({ harga: { $type: "int" } })
```

`null` dan "field tidak ada" adalah dua hal berbeda. `{field: null}` cocok dengan keduanya, sedangkan `$exists` membedakannya.

<div class="note">💡 Operator query berbeda dengan **operator update**. `$inc` hanya dikenal di dalam `$set`-style update, bukan di `find()`. Mencampurnya akan menghasilkan error.</div>
