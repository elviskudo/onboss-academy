## Update Field Skalar

```javascript
db.pengguna.updateOne(
  { _id: 1 },
  { $set: { nama: "Ana", terakhirLogin: new Date() },
    $inc: { jumlahLogin: 1 },
    $unset: { tokenLama: "" } }
)
```

Beberapa operator bisa dipakai dalam satu dokumen update, tetapi operator yang sama tidak boleh diulang untuk field yang sama.

## Menambah ke Array

```javascript
db.pengguna.updateOne({ _id: 1 }, { $push: { tag: "promo" } })
db.pengguna.updateOne({ _id: 1 }, { $addToSet: { tag: "promo" } })
```

`$push` selalu menambah, sehingga bisa muncul dua kali. `$addToSet` memperlakukan array seperti himpunan.

## Menghapus dari Array

| Operator | Cara kerja |
| --- | --- |
| `$pull` | hapus semua elemen yang nilai/cocok syaratnya |
| `$pop: 1` | hapus elemen terakhir |
| `$pop: -1` | hapus elemen pertama |
| `$pullAll` | hapus beberapa nilai sekaligus |

```javascript
db.pengguna.updateOne({ _id: 1 }, { $pull: { tag: "promo" } })
```

## Elemen yang Cocok

```javascript
db.siswa.updateOne(
  { nim: "001", "nilai.mapel": "Matematika" },
  { $set: { "nilai.$.skor": 95 } }
)
```

`$` merujuk ke elemen array pertama yang cocok dengan syarat pada filter. Untuk semua elemen yang cocok, pakai `$[]` (MongoDB 3.6+) atau `$[identifier]` dengan arrayFilters.

<div class="note">💡 `$` hanya bisa dipakai jika field array tersebut muncul di filter. Tanpa itu MongoDB akan mengeluh karena tidak tahu elemen mana yang dimaksud.</div>
