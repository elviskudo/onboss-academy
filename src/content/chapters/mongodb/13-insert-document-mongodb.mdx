## insertOne

```javascript
const hasil = db.siswa.insertOne({
  nama: "Ana",
  nilai: 88,
  kelas: "A"
})
print(hasil.insertedId)
```

`insertedId` berisi ObjectId yang dihasilkan server. Kamu bisa menyimpan nilai ini untuk referensi di aplikasi.

## insertMany

```javascript
db.siswa.insertMany([
  { nama: "Budi", nilai: 92, kelas: "B" },
  { nama: "Rani", nilai: 79, kelas: "A" }
])
```

Operasi massal jauh lebih cepat daripada memanggil `insertOne` berulang kali karena jaringan hanya dipakai sekali.

## Urutan dan Kegagalan

```javascript
db.siswa.insertMany([
  { _id: 1, nama: "Satu" },
  { _id: 1, nama: "Duplikat" },
  { _id: 3, nama: "Tiga" }
], { ordered: false })
```

Secara bawaan `ordered: true`: begitu dokumen kedua gagal karena `_id` duplikat, sisanya tidak diproses. Dengan `ordered: false`, dokumen ketiga tetap masuk.

## _id Buatan Sendiri

```javascript
db.produk.insertOne({ _id: "KB-01", nama: "Keyboard", harga: 350000 })
```

Boleh memakai nilai sendiri asal unik dalam koleksi. Ini berguna untuk kode produk yang memang stabil, tetapi hati-hati: `_id` tidak bisa diubah setelah disimpan.

<div class="note">💡 `insertOne` bersifat atomik untuk satu dokumen. Kalau kamu butuh banyak dokumen masuk semuanya atau tidak sama sekali, gunakan transaksi MongoDB (multi-document transaction).</div>
