## updateOne dan updateMany

```javascript
db.produk.updateOne(
  { nama: "Keyboard" },
  { $set: { harga: 325000 } }
)

db.produk.updateMany(
  { kategori: "Elektronik" },
  { $set: { aktif: true } }
)
```

Argumen pertama adalah filter, argumen kedua adalah **dokumen update** berisi operator. Kalau kamu menulis `{ harga: 325000 }` tanpa `$set`, MongoDB mengira itu dokumen pengganti dan field lain ikut hilang.

## Operator yang Sering Dipakai

| Operator | Fungsi | Contoh |
| --- | --- | --- |
| `$set` | ubah/tambah field | `{$set: {nama: "Baru"}}` |
| `$inc` | tambah angka | `{$inc: {stok: -1}}` |
| `$unset` | hapus field | `{$unset: {diskon: ""}}` |
| `$rename` | ganti nama field | `{$rename: {lama: "baru"}}` |
| `$min` / `$max` | simpan nilai terkecil/terbesar | `{$max: {skor: 95}}` |
| `$push` | tambah elemen array | `{$push: {tag: "promo"}}` |

## Update Bersyarat

```javascript
db.produk.updateOne(
  { _id: id, stok: { $gt: 0 } },
  { $inc: { stok: -1 } }
)
```

Memasukkan kondisi `stok > 0` ke dalam filter membuat operasi aman terhadap race condition: dua pembeli bersamaan tidak akan membuat stok minus.

## Upsert

```javascript
db.statistik.updateOne(
  { tanggal: "2026-11-20" },
  { $inc: { pengunjung: 1 } },
  { upsert: true }
)
```

Kalau dokumen tanggal itu belum ada, MongoDB membuatnya lalu menerapkan `$inc`. `$setOnInsert` bisa dipakai untuk field yang hanya boleh ada saat dokumen baru dibuat.

## replaceOne

```javascript
db.produk.replaceOne(
  { _id: 1 },
  { nama: "Keyboard Pro", harga: 400000 }
)
```

`replaceOne` mengganti seluruh dokumen kecuali `_id`. Field lama yang tidak disebutkan akan hilang.

<div class="note">💡 `modifiedCount` berbeda dengan `matchedCount`. Update yang menetapkan nilai yang sama persis dengan nilai lama tetap cocok, tetapi tidak dimodifikasi.</div>
