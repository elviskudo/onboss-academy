## Indeks Tunggal dan Komposit

```javascript
db.produk.createIndex({ harga: 1 })
db.produk.createIndex({ kategori: 1, harga: -1 })
```

Tanpa indeks, MongoDB memindai seluruh koleksi (COLLSCAN). Dengan indeks yang tepat, server melakukan IXSCAN lalu langsung mengambil dokumen yang cocok.

## Jenis-jenis Indeks

| Jenis | Contoh | Kegunaan |
| --- | --- | --- |
| Tunggal | `{harga: 1}` | filter satu field |
| Komposit | `{kategori: 1, harga: -1}` | filter + sort |
| Multikey | `{tag: 1}` | field array |
| Unique | `{email: 1}, {unique: true}` | email tidak duplikat |
| Sparse | `{unique: true, sparse: true}` | abaikan dokumen tanpa field |
| TTL | `{dibuat: 1}, {expireAfterSeconds: 3600}` | hapus data lama |
| Text | `{nama: "text"}` | pencarian kata |

## Pencarian Teks

```javascript
db.artikel.createIndex({ judul: "text", isi: "text" })
db.artikel.find({ $text: { $search: "mongodb indeks" } })
```

Hasil bisa diurutkan menurut relevansi dengan `$meta: "textScore"` dalam `$sort`.

## Menguji dengan explain

```javascript
db.produk.find({ kategori: "Elektronik" }).explain("executionStats")
```

Perhatikan `winningPlan.stage`: `IXSCAN` berarti indeks dipakai, `COLLSCAN` berarti tidak. Bandingkan juga `totalDocsExamined` dengan `nReturned`.

<div class="note">💡 Indeks tidak gratis: setiap insert/update harus memperbarui indeks, dan indeks memakan RAM. Buat indeks hanya untuk pola query yang benar-benar sering dipakai.</div>
