## Filter Sederhana

Filter MongoDB adalah objek dengan pasangan field:nilai.

```javascript
db.produk.find({ kategori: "Elektronik" })
db.produk.find({ stok: 0, aktif: true })
```

Beberapa field sekaligus berarti **AND**: semua syarat harus terpenuhi.

## Proyeksi

```javascript
db.produk.find({}, { nama: 1, harga: 1, _id: 0 })
```

Proyeksi menghemat bandwidth ketika dokumen aslinya sangat besar. Ingat pengecualian `_id`: ia tampil kecuali kamu menuliskan `_id: 0`.

## Urutan

```javascript
db.produk.find().sort({ harga: -1, nama: 1 })
```

Urutan sort dievaluasi从左到右 (kiri ke kanan). Di contoh di atas, harga menjadi kunci utama, nama menjadi kunci kedua saat harga sama.

## Halaman Data

```javascript
const halaman = 2, perHalaman = 10
db.produk.find()
  .sort({ _id: 1 })
  .skip((halaman - 1) * perHalaman)
  .limit(perHalaman)
```

`skip()` semakin lambat pada halaman yang dalam karena server tetap harus melewati dokumen di depannya. Untuk dataset besar, pakai **range pagination** berdasarkan `_id` atau field tanggal.

## Iterasi Kursor

```javascript
for (const dok of db.produk.find({ stok: { $gt: 0 } })) {
  print(dok.nama)
}
```

Kursor hanya bisa dikonsumsi sekali. Kalau perlu dipakai berulang, simpan hasilnya dengan `toArray()`.

<div class="note">💡 `find()` tidak pernah mengubah urutan penyimpanan dokumen. Urutan hanya dijamin kalau kamu memanggil `sort()` dengan kunci yang unik, misalnya `_id`.</div>
